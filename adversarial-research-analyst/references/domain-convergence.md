# CONVERGENCE_MAP.md — 相变检测与时间套利

> v3 升级：加入独立性验证 + 辩论驱动的相变判断。
>
> **v2 的缺陷**："独立收敛计数"未验证独立性——同期发表可能是 workshop 传播而非独立发现。
>
> **v3 修复**：每条收敛信号标注信息传播链，引用链相连的算 1 个。
> 相变判断必须经过三视角辩论才能确认。

---

## 设计哲学

核心问题：**"哪些原本独立的信号正在收敛到同一个结论？"**

**关键限定**："独立"必须被验证，不能假设。
- 如果 A 引用了 B，B 引用了 C → A/B/C 是 1 个信号，不是 3 个
- 只有信息来源不同（独立推导/不同实验证据/不同理论路径）的才算独立
- 每条信号标注：`[来源追溯]` + `[独立性判定: ✅/❌]`

**关键张力**：方向明确（统一基座），但**方法论碎片化**——每个团队用不同策略解决动作空间不统一的问题（attention mask / token 映射 / adapter / 统一URDF）。还没有出现"Diffusion Policy 级别"的统一共识方案。

## 约束松弛分析

> "如果魔法般移除某一个约束，VLA 性能提升最大的是哪个？"

| 排名 | 约束 | 松弛后的影响 | 当前松弛难度 |
|------|------|-------------|-------------|
| **1** | 真机数据的采集成本 | 数据飞轮零成本转动 → 指数级改进 | 极难（物理限制） |
| **2** | 实时推理延迟 | 大模型+多步推理直接上机 → 推理能力释放 | 中（硬件进步中） |
| **3** | World Model 物理保真度 | 无限廉价合成数据 → 训练数据不再稀缺 | 难 |
| **4** | 跨形态动作空间统一 | 一次训练所有机器人 → 数据利用率 10x | 中-难 |
| **5** | 触觉传感标准化 | 触觉数据可跨设备复用 → 触觉 VLA 起飞 | 中 |

**洞察**：排名 1（数据采集成本）几乎不可能被技术"松弛"，但可以被**绕过**：
- 路径 A: WM 合成数据（如果物理保真度足够）
- 路径 B: 互联网视频跨模态迁移
- 路径 C: Sim2Real + Domain Randomization
- 路径 D: 高效的少样本学习

**真正的杠杆点不是"获取更多数据"，而是"用更少真实数据达到同样效果"。** 这把约束 #1 转化为约束 #3（WM）和 #4（跨形态）的竞争。

## 收敛交叉检测

> 两个独立的相变如果同时接近临界点，交叉处可能产生突破。

```
当前最危险的交叉（= 最可能产生突破的）：

  Phase 2 (RL后训练)  ×  Phase 4 (World Model)
        ↓                       ↓
  "模型学会自我改进"    ×   "廉价合成经验"
        ↓                       ↓
        ←──── 交叉点 ────→
        "在想象中自我改进"
        (VLAW/RAMP 正在探索)

  如果这两个相变同时完成 → VLA 可能出现类似 AlphaGo 的
  "自博弈涌现"时刻：模型在 WM 中生成经验 → RL 筛选改进
  → 改进后的模型生成更好的经验 → 正反馈循环。

  阻碍因素：WM 物理保真度（循环中的噪声会被放大）。
```

```
被低估的交叉：

  Phase 3 (触觉标准化)  ×  Phase 2 (RL后训练)
        ↓                       ↓
  "接触信息可用"        ×   "从错误中学习"
        ↓                       ↓
        ←──── 交叉点 ────→
        "从接触失败中学习精细操作"

  当前大部分 RL 后训练用视觉 reward。如果触觉 reward 可用
  （如力/滑移/形变信号），RL 在精细操作上的学习效率可能
  提升一个数量级。没人在做这个。
```

## 时间套利机会（当前有效）

### 套利 1: "触觉 × RL = 精细操作的下一跳"
```
你的判断: 触觉reward信号 + RL后训练 = 精细操作突破口
领域主流: 还在分别做触觉和RL，很少交叉
套利窗口: 6-12个月（标准化完成后窗口关闭）
致命条件: 触觉reward信号太噪声/太稀疏，无法有效驱动RL
建议行动: 现在开始建立触觉数据管线+RL框架的结合实验
```

### 套利 2: "约束松弛#2 (推理延迟) 即将被硬件解决"
```
你的判断: 2026下半年专用推理芯片+编译优化将把VLA推理
          延迟降低3-5x，解锁大模型(>7B)实时上机
领域主流: 还在努力做小模型(<3B)来适应算力限制
套利窗口: 6个月（芯片发布后窗口关闭）
致命条件: 芯片延期或性能不达标
建议行动: 不要过度投资小模型蒸馏，预留大模型部署路径
```

### 套利 3: "自我改进闭环的reward specification是被忽视的瓶颈"
```
你的判断: 所有自我改进方案（Recap/RAMP/VLAW）都在回避
          reward定义问题——用人类标注或简单二值reward
领域主流: 关注在闭环架构上，假设reward已解决
套利窗口: 12个月
致命条件: VLM-as-reward-model方案（VLAW的reward model）
          证明足够可靠
建议行动: 深入研究自动reward discovery (Nature Comm)
          + VLM reward model的可靠性边界
```
