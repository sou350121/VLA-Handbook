## 帖 284：LeRobot 双臂采集大 BUG —— quantile normalization 边界问题 🔥🔥

- **作者**：笨蛋队长要变强（湖南）
- **日期**：05-14
- **链接**：https://www.xiaohongshu.com/explore/6a04a1c60000000007013af0
- **关键词**：lerobot 训练 卡顿
- **Score**：10 分（一手 +3、根因 +3、修复方案 +2、评论独立印证 +2）

**核心 BUG**：LeRobot 双臂采集时，**一个臂完全不动 → 统计数据过于理想 → 推理时数据管道拿到极端值 → 那条臂数据爆炸 → 模型整体失效**。

**作者解决办法**：跑一组 ideal 数据管道前后，用**固定值替代静止臂数据，模拟永远静止的臂**。

**作者神奇发现**：把数据单纯做 image 归一化，state 保留原始格式，**全部不再走管道送入模型也能有一定的抓取效果**（ACT 可以，VLA 不行）—— 说明管道前后数据分布不同但 ACT 能处理。

### 评论区精华（独立印证 + 更准的根因）
- **鲨鲨**（关键）：**前段时间遇到了同样的问题**。定位过程：**loss spike → 检查对应 step 的 model input → 发现有巨大值 → preprocessing 前正常 → 定位是 quantile normalization 的问题**。LeRobot 设计的 fallback **只考虑了 division by zero 的情况**，没考虑统计参数极端情况
- 作者补充：推理时左臂第六关节炸到几万，再送模型就直接卡住
- **喵了个喵**："想问下您有没有比较好的 lerobot 数据分析方法？我感觉我的数据里有💩但不知道是哪些"——作者答"一级一级往上 print"

## 帖 286：FrameSkip —— 用 20% 帧 反而训练更好 🔥

- **作者**：Liam（北京）
- **日期**：05-18
- **链接**：https://www.xiaohongshu.com/explore/6a0affbf0000000036002cc4
- **关键词**：VLA 数据增强 抖动
- **Score**：8 分（反直觉发现 +3、具体数据 +3、benchmark 三方对比 +2）

**核心论文**：FrameSkip: Learning from Fewer but More Informative Frames in VLA Training

**核心观察**：密集机器人演示数据中，**学习最关键的时刻（接触/对齐/释放）仅占总帧数的一小部分**。标准均匀采样稀释稀疏关键事件的学习信号 → **"局部监督不足"**。

**FrameSkip 三种重要性指标**：
- **AVI（Action Variation Importance）**：动作变异
- **VAC（Visual-Action Consistency）**：视觉-动作一致性
- **TPI（Task Progress Importance）**：任务进度

**比率感知帧剪枝**：根据重要性分数选子集，**强制保留初始 / 最终 / 夹持器过渡帧**。

**实验数据**（RoboCasa-GR1 / SimplerEnv / LIBERO）：
- **FrameSkip 20% 帧 = 76.15% 平均成功率**
- 标准全帧训练 = 66.50%
- **消融**：完整 FrameSkip > 单一重要性 > 随机剪枝

### 评论区
- **钱泽中**："感觉像工程 trick，期待一些模型层面突破"
- 作者回：**"真落地的话工程感觉也很重要，特别是怎么更好的洗数据这种典型的 dirty work 往往才是最后决定性能上限的关键"**
- **锅巴**："是否违背 bitter lesson"
- 作者回："**这篇应用范围偏 BC，类似大模型的 SFT。如果是预训练感觉就需要让数据尽可能匹配真实分布了**"——这是一个有约束的"反 bitter lesson"

## 帖 290：Qwen 团队 insider —— Qwen-VLA 设计哲学 🔥🔺

- **作者**：风树（Qwen 团队，广东）
- **日期**：2 天前
- **链接**：https://www.xiaohongshu.com/explore/6a18f8670000000035025916
- **关键词**：VLA 微调 显存 OOM（实际是 Qwen-VLA insider 介绍）
- **Score**：9 分（团队一手 +3、设计哲学 +3、与 G0.5 平行对比 +3）

**核心架构**：
- **底座 Qwen3.5-4B + DiT 动作解码器**
- **把不同机器人硬件差异（自由度 / 机械臂数量 / 底盘 / 控制频率）写成文本提示喂给模型**
- **同一组权重，换一段描述就能直接适配 11 种不同的机器人平台**

**实验结果**：
- 5 个仿真基准里 **4 个超过最佳专用模型**
- **导航任务超过导航专用模型**
- 真机颜色 / 物体 / 背景换掉也能泛化
- **没有训过的运动物体追踪，零样本也能跟得上**

**评论区作者答疑（设计哲学）**：
- "训练阶段 flow matching 时间步 t 采样设计成不同阶段两个不同的分布是怎么想到的？" → 风树："**DiT 原本就有个偏向 noise 的分布，顺着这个就好想了**"

**与帖282 G0.5 对比**：
- **G0.5**：跨本体 Action **Tokenizer**（18 本体 → 27 维 token vocab）
- **Qwen-VLA**：硬件差异**写成文本 prompt** 喂模型（11 平台）

两条独立路径都指向**跨本体统一**——成为新一轮范式收敛点。
