## 本轮核心信号（三视角快评）

🔴 **Bull**：本轮最强信号是 **"World Model / latent 预测范式接棒 VLA" 在多个独立一手来源同时收敛**。VLA-JEPA（帖1，ZWY 一作亲述）、JEPA-VLA（帖1 评论区撞名作者 Manchery）、DiT4DiT（帖12，妙动科技 × 港科广）、leworldmodel 复现（帖8，NotBot 单卡复现）、石野 World Action Model（帖2，YesAI 实验室）——五个独立工作/团队全部指向同一个核心思路："在抽象 latent 里预测未来状态，而不是重建像素"。帖12 DiT4DiT 给出硬指标：相比 VLM-VLA **10× 样本效率 + 7× 收敛加速**，LIBERO 98.6% / RoboCasa GR1 50.8%。帖8 证明 **4070 单卡 12G 一天就能复现一个 world model**。这已经不是论文里的趋势——它在消费级硬件上可复现了。配合 2026-05-04 上轮 "测试时优化 VLA" 的势头，可以判断 2026 H2 的 VLA 主线是 "latent world model 骨干 + action expert"。

🔵 **Bear**：但同一轮也给出了**最强的逆共识——World Model 阵营正在被内部攻击**。Fisher（帖4）——LeWorldModel 同方向工作 NewtonGen（ICLR 2026）的作者——直接质疑：LeWorldModel "一个正则就稳定解决 latent 坍缩" 存疑（他自己花两个月没解决同样的坍缩问题）；强行各向同性高斯 latent 可能为了训练稳定牺牲真实物理流形结构；"每个任务单独训 encoder" 不一定是进步，实验还都停在仿真。评论区补刀："jepa 其实是隐式的非生成式样本密度估计器"、"latent gaussian 这种 VAE 的老路"、nwnh 指出 LeWorldModel 在 PushT 这种 5 自由度低维任务上 "属于 hack benchmark"。帖2 的评论区同样戳破 WAM 泡沫——Rorschach："**实际 wam 也没展现出远超 vla 的能力，一样没解决数据问题，甚至推理速度又变成新的瓶颈**"。帖5（"我不确定"，第二次发帖）确认一个真实团队**已主动放弃纯 VLA 业务路线** → 转 real2sim2real + VLA+residual RL + OpenClaw。"纯 VLA 落地撤退" 这条逆共识从 2026-05-04 起又添一个独立印证。

🟢 **Arbiter**：对用户研究方向的意义——
1. **若做 VLA 微调 / 复现**：帖3（Spatial Forcing）给出可照抄的 recipe——30 行代码即插即用，用 VGGT 特征对齐 VLA 视觉特征，**中间偏后层对齐最有效，VGGT 特征 > DINO / SigLIP**，2% 训练步 / 5% 数据即达 SOTA。帖7（CapVector，2026-05-14 发布，最新）更进一步：把 auxiliary SFT 学到的能力做参数差分成 "capability vector"，merge 回预训练模型后跨任务迁移（LIBERO→RoboTwin 成功率 6.7%→31.8%）。这两个是 2026 H1 提升 VLA 数据效率最实操的两条路，且都明确覆盖手册标注的 "视觉编码器定量对比" 盲区。
2. **若做 sim2sim / sim2real**：帖6 给出 humanoid 的具体经验——pd 值在新仿真环境会变，要重新标定 pd 再训（一个 loop）；humanoid gym iteration 可能要 8001 而非默认 3001；左右脚步幅不一致加 target pos reward。帖11（ALOHA）：官方仿真环境缺手腕摄像头导致 diffusion 效果差；**diffusion 比 ACT 需要更多数据**（评论区一手：ACT 真机 50 episode 80% 成功率，dp 同等数据明显更差）。
3. **若做 World Model**：帖8 是目前社区最完整的 leworldmodel 复现——4070 12G 一天，附 t-sne / 时序直线化（0.19→0.88）/ 违背预期惊异度三个诊断指标。帖1（VLA-JEPA）+ 帖12（DiT4DiT）给出两条 latent 路线的对照，帖4 给出最关键的反方论证。
4. **若做方向判断**：三个 🔺逆共识信号本轮升格——(a) 纯 VLA 落地撤退（帖5 第二次印证）；(b) World Model / WAM 内部质疑（帖4 同行作者、帖2 评论）；(c) "什么都叫世界模型了"（帖15 评论）。建议在 §14 标注："World Model 接棒 VLA" 是 2026 H1 最强共识，**但它的工程证据仍主要在仿真，真机泛化证据稀薄**——这与 2025 年 VLA 自己被质疑的路径高度相似。
5. **时间套利**：帖7 CapVector 发布于 2026-05-14（昨天），"capability vector / 反向利用 task vector" 方向极新，评论区只有个位数同行在讨论；帖3 Spatial Forcing（arxiv 2510.12276）的 "VGGT 特征蒸馏给 VLA" 也还在早期。

**对信念网络的影响（后台简报）**：
- **B0（数据策略 > 架构）**：Spatial Forcing / CapVector 用 2-5% 数据达 SOTA、帖11 "diffusion 比 ACT 更吃数据" → 强化方向，建议小幅 +。
- **World Model 范式**：多源独立印证 latent-prediction，但 Bear 的内部质疑（帖4、帖2 评论）要求严守校准纪律——**不要把 "World Model 接棒" 的置信度推过 80%**；新增致命实验观察点："World Model 的真机泛化证据是否在 6 个月内出现，否则置信度回调"。
- **C3（VLA 不需要语言）**：帖2 "动作梯度反向更新 VLM 导致感知变笨" 支持，但帖12 评论 "并没有去掉 L" 反对 → 混合信号，本轮不调。

**核心内容**：针对 "从无标签视频学机器人动作" 的 latent action 路线，作者指出四个问题：训练目标盯像素变化（光照/纹理/背景）与控制无关、镜头晃动被误当动作、latent action 前后帧喂给 IDM 导致信息泄露、流程过长（提取 latent action→pretrain→finetune）。VLA-JEPA 的做法：借鉴 JEPA，**在抽象 latent 里对齐未来而非重建像素，且严格不让模型把未来当输入**（未来只作监督信号），从源头堵住捷径。效果：更抗相机晃动 / 背景变化，训练流程简化为预训练 + 微调两步。Paper arxiv 2602.10098 / Code github.com/ginwind/VLA-JEPA。
