## 历史采集原则

### 核心原则
1. **评论 > 正文**：评论区信息密度高于帖子正文，零评论帖直接跳过
2. **逆共识优先**：挑战主流判断的信号（标记 🔺）比重复共识更有价值
3. **收敛地图联动**：关键词权重跟随 VLA_EXPERT_MEMORY.md 的 Phase 进度动态调整
4. **慢热帖回访**：高赞零评论帖进 watchlist，14 天内回访检查是否长出评论

### 当时记录的覆盖不足

以下话题在社区中几乎无实操分享，需从 GitHub Issues / 知乎 / 论文作者处获取：
- FAST tokenization（DCT+BPE）
- Co-training 数据混合比例
- 视觉编码器定量对比（SigLIP vs DINOv2）
- 量化/蒸馏 VLA 到边缘设备
- World Model 训练工程细节
- 多机器人协同 VLA 部署
