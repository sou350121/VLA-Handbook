# 腾讯 Robotics X 具身智能算法一面（手术场景）高难问题：逐题应答稿 (2026)

> **定位**：把“贼难”的一面问题变成可复述、可落地、可追问的应答脚本。  
> **适用**：具身/手术机器人/高精度操作岗位（VLM+生成式动作头、长时序记忆、闭环控制、Sim2Real）。  
> **题目来源**：小红书（用户整理的一面问题清单）

## 0) 先给面试官的总框架（10 秒开场）

我的系统会按“**慢推理（语义/意图/约束）** + **中速策略（短时动作分布）** + **高速闭环（视觉/力/接触 servo）**”拆层。  
生成模型（Diffusion/Flow）负责**短时可采样的动作分布**，闭环层负责**实时纠错与安全**；长时任务由记忆/状态机/日志索引支撑，而不是无限增长上下文。

## 1) 为什么不 End-to-End？为何要解耦 VLM 与 Diffusion？手术精度场景最大瓶颈在哪？

### 建议回答（可直接复述）

手术是“**毫米以下精度 + 强安全约束 + 强分布外风险**”的场景。纯 E2E 大模型直接从多模态输出坐标/动作，最大的瓶颈通常不是“模型容量”，而是：

- **闭环可观测性与时延**：组织实时形变、工具-组织接触的相位变化，必须靠高频闭环去吸收；E2E 若把一切都塞进同一网络，推理时延与不可解释性会成为安全瓶颈。
- **多源误差叠加**：相机标定/配准误差、软组织非线性、力控与摩擦不确定性，导致“坐标点正确≠动作安全可执行”。
- **验证与监管**：手术要求可验证、可回放、可追责；解耦后每层可独立验收（误差预算、fail-safe、fallback）。

因此我倾向于解耦：
- VLM（或高层模型）负责 **语义理解 + 约束生成（可解释）**：目标、禁区、阶段、风险提示。
- Diffusion/Flow（中层策略）负责 **短时动作分布/多峰采样**（适配多解、抗噪）。
- 高频控制层（servo/阻抗/力控）负责 **把动作“落地”为安全轨迹**（接触后的纠错）。

### 追问准备
- “那 E2E 的优势呢？”：数据足够时 E2E 省人工接口，但在手术更需要**可验收边界**与**安全分层**。

## 2) Action Chunk vs 实时组织形变：chunk 没跑完组织已变，怎么闭环修正？

### 核心思想
Chunk 不是“承诺执行到底”，而是“**短时计划候选**”。执行必须是 **receding horizon（滚动时域）**：

- **每个控制周期只执行 chunk 的前几步/一个微步**，然后用最新观测重新推理下一段（MPC 思路）。
- **在 chunk 内部再套一层高速 servo**：用视觉/力/接触信号做微调（例如视觉伺服 $e \rightarrow \Delta x$，或阻抗控制）。
- **触发式中断/重规划**：若检测到形变超阈值、接触力异常、或目标点漂移，立刻丢弃剩余 chunk，回到“再估计→再采样”。

### 面试官常见追问点
- “你怎么检测组织已经偏了？”：基于 tracking（特征/分割/光流/深度）+ 形变估计 + 工具-组织接触状态（力/电流/视觉接触线索）。
- “这会不会导致频繁抖动？”：用滞回阈值、低通滤波、以及“目标/约束保持 + 只改短时动作”。

## 3) 扩散处理多峰分布：手术例子？两条都合理的避障路径如何避免摇摆？

### 一个具体例子
在显微/腔镜下穿针或绕开血管束时，存在两种都可行的路径：**左侧绕行** vs **右侧绕行**（都满足距离/角度约束，但对视野遮挡、手术器械可达性不同）。

### 避免“决策摇摆”的做法
生成模型能给“多解”，但“选哪个”要靠 **一致性与代价函数**：

- **用高层“意图/约束”锁定模式**：一旦选择左绕，就保持该模式直到到达中间里程碑（减少 mode-flip）。
- **用代价函数做重排**：对多个采样轨迹计算代价（离禁区距离、视野遮挡、器械姿态舒适度、力/能量等），选最小者。
- **用滞回/惯性（hysteresis）**：只有当另一条路径的代价显著更低（超过阈值）才切换。
- **用 uncertainty gating**：若两者接近且不确定度高，则进入“更保守动作”（减速/停稳/请求更多观测角度）。

一句话：扩散解决“有多解”，系统解决“选解要稳定”。

## 4) 手术几小时：KV Cache 爆炸，换 Mamba 但压缩是 lossy，怎么保证不幻觉？

### 关键立场
长时任务里“记忆”不应该完全靠一个序列模型的隐状态承载；应当把长期信息外置为**可审计的结构化记忆**，让模型只做检索与当前决策。

### 可落地方案
- **短期上下文**（分钟级）：最近关键帧 + 最近动作摘要 + 当前阶段 state。
- **长期记忆外置**（小时级）：事件日志（阶段/关键动作/关键观测/并发症标记）+ 向量检索 + 可回放片段索引。
- **状态机/手术流程图作为硬约束**：把“现在该做什么”从纯生成变成“受限决策”。
- **一致性校验**：关键事实（比如“已经止血/已打结/已切除”）必须由可验证信号确认（视觉/力/工具状态/计数器），不靠模型自述。

对 Mamba 的回答重点是：
Mamba 的 state 是压缩的、可能遗忘细节；所以我会让它负责“**连续控制与短期依赖**”，而把关键里程碑与事实放在外部记忆里，靠检索回填。

## 5) Transformer vs Mamba：一个结构区别？

### 一句话版本
- **Transformer**：每一步通过 **attention** 直接访问所有历史 token（显式全局读写）。  
- **Mamba/SSM**：用 **递归状态**把历史压缩成一个 state，通过线性扫描更新（隐式记忆）。

---

## 6) 为什么 Transformer 是 $N^2$，Mamba 是线性？

- Transformer 自注意力要计算所有 query 对所有 key 的相关性：注意力矩阵大小是 $N\times N$，所以时间/显存随 $N^2$ 增长。
- Mamba/SSM 通过递归扫描：每步只做常数维 state 的更新与读出，因此随序列长度 $N$ 近似线性增长。

## 7) 定量实验：Mamba 相比 Transformer 精度会变吗？

建议答法（不编造具体数字）：
- **会有 trade-off**：Mamba 更省算力与长上下文更稳，但在需要精确检索远处细节的任务上，纯压缩可能损失精度。
- **怎么测**：用固定评测集做对照：
  - 长时依赖任务（跨阶段逻辑、工具计数、并发症处理）
  - 视觉定位精度（关键点/分割 IoU/追踪漂移）
  - 行为稳定性（长序列成功率、错误恢复率）
  - 一致性指标（多次运行一致性，类似 $pass^k$）
- **工程折中**：常见做法是“混合”：短窗口用注意力（或检索增强），长跨度用外部记忆/检索，而不是指望单一骨干承载全部。

## 8) 高层规划模型用什么做？

可选回答模板（按你真实项目选其一）：
- **方案 A（常见）**：VLM/VLA 做阶段识别与子目标（手术步骤、工具切换、约束区），输出“下一步技能/目标”，低层负责执行。
- **方案 B**：行为树/状态机 + 小模型（把安全与流程强约束），模型只在需要时生成候选动作或恢复策略。
- **方案 C**：把高层规划做成“检索 + 规则 + LLM 解释器”，确保可审计与可回放。

## 9) 只输入 3–5 张历史图，它能记住之前所有操作吗？为什么？

不能“凭空记住全部细节”。3–5 张图的意义是提供**短期状态与局部几何**，而不是承担小时级记忆。

要做到“记住之前的操作”，需要：
- 外部日志/里程碑（手术阶段、已完成步骤、已放置夹子数量等）
- 检索回填（需要时取回关键片段/关键帧）
- 可验证状态（工具、设备与传感器读数）

## 10) 高层模型训练怎么做？

一个可被认可的回答结构：
- **数据**：分阶段标注（弱标注也行）：步骤标签、子目标、风险事件、工具状态。
- **目标**：阶段分类/子目标预测/约束生成（禁区、优先级）、以及失败恢复策略。
- **训练范式**：SFT（监督）→ 离线评估 →（可选）RL/偏好优化对齐“安全与稳态”。
- **评估**：用可验证的状态机指标（阶段识别准确率、误触发率、恢复成功率、平均干预次数）。

## 11) Selective Scan：怎么定义“该忘/该记”？如果忘了微小关键点怎么办？

答法要点：
- Selective 的本质是 **输入依赖的门控**：不同输入会调整更新强度，让重要信息更久留。
- 但它不是“万能记忆”，所以要有补丁：
  - **关键点升格为显式事件**：一旦检测到“微小但关键”的信号（比如微出血/组织撕裂风险），就写入外部事件日志并触发降速/确认。
  - **多模态冗余**：视觉小点可以用力/阻抗/工具电流等做交叉验证。
  - **再观测策略**：触发主动重新观测（换视角、清理血液、提高曝光），而不是靠记忆硬撑。

## 12) Occlusion 失败：能不能盲操？还是只能挂起等医生？

建议给“分级策略”：
- **可盲操的前提**：任务对可观测性要求低，且有可靠的力/触觉/电流 proxy（例如沿已建立的通道推进、恒力维持、缓慢回撤）。
- **必须挂起/请求医生的情况**：关键结构不可见且风险高（血管/神经附近），或者 proxy 不可靠/冲突。
- **系统设计**：把“盲操”做成明确的安全模式（限速、限力、可随时退出），并记录原因与触发条件。

## 13) 仿真组织力学参数 vs 活体猪差异大，怎么对齐？

答法要点（Sim2Real 的“手术版”）：
- **参数随机化 + 系统辨识**：对杨氏模量/阻尼/摩擦/切割阻力做域随机化，同时用少量真实数据做参数反推（或 residual 学习）。
- **用观测对齐，而不是只对齐参数**：让策略对“可观测量”（形变场、接触力、回弹曲线）鲁棒，而不是指望仿真参数完全准确。
- **在线校准/自适应**：在术中用短小探测动作估计当前组织刚度/摩擦并更新控制增益/模型。
- **安全优先**：对不确定度高的区域自动降速、增大安全裕度，必要时请求人工确认。

## 14) OOD：2 小时后出现“大面积塌陷”，Mamba 会不会被历史惯性带偏？

会有风险：递归 state 可能带来“惯性”。应对策略：
- **显式 OOD 检测**：基于重投影误差、形变残差、力/位移不一致、分割置信度崩塌等信号触发告警。
- **state reset / state branching**：进入异常模式时，降低对历史 state 的依赖（重置部分状态、或切换到更保守控制器）。
- **回退到物理安全控制**：例如阻抗/力控维持稳定、停止推进、撤离到安全姿态。
- **人机协作**：把异常当作“必须升级”的事件，而不是让模型硬解释。

## 16) 手撕

### 16.1 木棍折三段构成三角形的概率
经典结论：**$1/4$**。  
理由（口述版）：随机折两刀相当于在 $[0,1]$ 上选两点，三段能成三角形等价于“最长那段 < 1/2”，可积出面积占比为 1/4。

### 16.2 岛屿数量（2D 网格 1/0）
用 DFS/BFS/并查集都行。面试最稳是 DFS/BFS：
- 扫描每个格子，遇到 `1` 且未访问就启动一次 BFS/DFS，把连通块全标记；计数 +1。
- 时间复杂度：$O(MN)$，空间：$O(MN)$（visited）或 $O(1)$ 原地改写。

参考伪码（Python 思路）：
- 双层循环
- 四邻域扩展（上/下/左/右）

## 17) “你能列一下你的数学方程吗？”（建议按模块给）

### 17.1 扩散/生成式动作头（以 diffusion 为例）
- 前向加噪：$x_t=\sqrt{\bar{\alpha}_t}x_0+\sqrt{1-\bar{\alpha}_t}\epsilon$
- 训练目标（噪声预测）：$\mathcal{L}=\mathbb{E}\|\epsilon-\epsilon_\theta(x_t,t,c)\|^2$

### 17.2 Chunk 的闭环执行（滚动时域）
- 只执行前缀：$a_{t:t+k}\sim \pi_\theta(\cdot\mid o_t)$，执行 $a_t$ 或前 $h$ 步，然后用 $o_{t+1}$ 重新采样/重规划。

### 17.3 Transformer 注意力复杂度
- 注意力矩阵：$\mathrm{Attn}(Q,K,V)=\mathrm{softmax}(QK^\top/\sqrt{d})V$（$QK^\top$ 是 $N\times N$）

### 17.4 Mamba/SSM 递归（概念式）
- 状态更新：$s_{t+1}=A_t s_t + B_t x_t$
- 读出：$y_t=C_t s_t + D_t x_t$
