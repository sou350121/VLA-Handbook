## 1. 核心架构/方法总览 (Overview / Architecture)

WISE 是一个四阶段流水线框架，协调世界模型在 VLA 后训练中的使用时机、范围和反馈方式。

### 1.1 系统对比概览 (System Component Comparison)

| 组件 | 输入 | 输出 | 训练方式 | 推理时作用 |
|------|------|------|----------|-----------|
| **调度器 (Scheduler)** | 腕部+第三人称图像 (DINOv2 编码) | 交互相关性分数 s_t ∈ [0,1] | 弱监督（基于机器人执行信号） | 判断是否触发想象（阈值 κ） |
| **世界模型 (World Model)** | 当前观测 + 指令 + 候选动作 | 未来 H 帧多视角预测 | Rectified Flow (冻结) | 对候选动作做有界闭环推演 |
| **奖励模型 (Reward Model)** | 预测的多视角观测 (DINOv2 编码) | 进度 p / 置信度 c / 完成度 q | 独立训练 | 评估想象轨迹质量 |
| **策略优化器 (Policy Optimizer)** | 候选动作 + 相对优势 A_i + 真实上下文 | 策略参数更新 | Flow Matching loss + 正则化 | 沿优势方向更新 π_θ |

### 1.2 关键机制 (Key Mechanism)

**为什么这样设计？** 核心洞察是：VLA 在执行任务时，粗运动阶段策略已经足够好，不需要世界模型介入；只有在需要精细交互的状态（如抓取、插入、操作铰链）下，反事实推理才有价值。全程启用世界模型是计算浪费，且长程推演会累积预测误差。

**四阶段闭环：**
1. **调度**：调度器判断当前状态是否"交互相关"（s_t > κ），是则进入想象，否则跳过
2. **想象**：采样 M 个候选动作 chunk，用冻结的世界模型做有界闭环推演（L 个 chunk = L×H 帧）
3. **评估**：奖励模型从预测轨迹中提取进度信号和完成信号，计算相对质量
4. **优化**：将相对优势转化为策略更新方向，但只监督真实上下文中的第一个动作 chunk

⚡ **Eureka Moment**：想象不是越多越好——把"何时想象"本身变成一个可学习的调度问题，比盲目堆计算量更有效。

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：

```
g_WISE = (1/M) · Σ_i sgn(A_i) · ∇_θ L_FM(θ; a_{t,i}, h_t) + λ_ref · ∇_θ L_ref
其中 A_i = (R̄_i - μ_R̄) / max(σ_R̄, ε)，R_i = G_i - α·B_i + β·T_i
```

**目标**：最大化任务成功率 y(τ, ℓ)，但不在真实世界中直接优化（太贵），而是通过世界模型的想象轨迹做反事实评估，将相对优劣转化为策略梯度方向。

**核心变量说明**：

| 符号 | 含义 | 来源 |
|------|------|------|
| h_t | 真实交互上下文（观测+状态+指令） | 真实环境 |
| a_{t,i} | 第 i 个候选动作 chunk | π_θ 采样 |
| p_{i,j} | 第 i 条轨迹第 j 帧的进度估计 | 奖励模型 head_p |
| c_{i,j} | 进度估计的置信度 | 奖励模型 head_c |
| q_{i,j} | 轨迹完成度 | 奖励模型 head_q |
| G_i | 前向进度增益（带置信度加权） | Σ c·[Δp]_0^δ |
| B_i | 后退惩罚 | Σ [−Δp]_0^δ |
| T_i | 最大完成度 | max_j q_{i,j} |
| R_i | 综合奖励 | G_i − α·B_i + β·T_i |
| A_i | 标准化优势 | 组内归一化 |

**直觉**：奖励模型给每条想象轨迹打分（前进+完成−后退），然后在 M 个候选之间做组内标准化。优势为正的候选对应的动作得到强化，优势为负的得到抑制。关键约束：只更新真实上下文中的第一个动作 chunk，想象轨迹仅用于评估、不直接生成训练数据。

> 符号与本文保持一致。世界模型使用 Rectified Flow 训练：
> ```
> L_WM = E[ || v_ψ([z̃_obs; z_fut,λ], λ, l, a)_fut − (z_fut − ε) ||^2 ]
> ```

## 3. 带数字走一遍：玩具例子 (Worked Example)

假设当前状态为"机械臂即将抓取杯子"，调度器判定 s_t = 0.82 > κ = 0.5，触发想象。

**Step 1 — 采样候选**：π_θ 采样 M = 4 个动作 chunk：
- a_1: 直接下抓（激进）
- a_2: 微调位置后下抓（保守）
- a_3: 先靠近再抓（中等）
- a_4: 错误方向移动（噪声）

**Step 2 — 世界模型推演**：每个候选推演 L = 2 个 chunk（每 chunk H = 8 帧，共 16 帧）：

| 候选 | 进度 p (首→末) | 置信度 c (均值) | 完成度 q (max) | G_i | B_i | T_i |
|------|---------------|----------------|---------------|-----|-----|-----|
| a_1 | 0.3→0.6 | 0.7 | 0.8 | 0.21 | 0.05 | 0.8 |
| a_2 | 0.3→0.5 | 0.85 | 0.7 | 0.17 | 0.03 | 0.7 |
| a_3 | 0.3→0.55 | 0.8 | 0.75 | 0.20 | 0.04 | 0.75 |
| a_4 | 0.3→0.2 | 0.5 | 0.3 | −0.05 | 0.10 | 0.3 |

**Step 3 — 计算综合奖励**（设 α=1.0, β=0.5, δ=0.3）：

```
R_1 = 0.21 − 1.0×0.05 + 0.5×0.8 = 0.56
R_2 = 0.17 − 1.0×0.03 + 0.5×0.7 = 0.48
R_3 = 0.20 − 1.0×0.04 + 0.5×0.75 = 0.535
R_4 = −0.05 − 1.0×0.10 + 0.5×0.3 = −0.10
```

**Step 4 — 质量门检查**：
- ΔR = 0.56 − (−0.10) = 0.66 ≥ 0.02 ✓
- 假设 ρ_rank = 0.72 ≥ 0.5 ✓，σ_WM = 0.12 ≤ 0.2 ✓
- 组被接受

**Step 5 — 标准化优势**（μ = 0.369, σ = 0.244）：

```
A_1 = (0.56 − 0.369) / 0.244 = +0.78  → 强化 a_1
A_2 = (0.48 − 0.369) / 0.244 = +0.45  → 强化 a_2
A_3 = (0.535 − 0.369) / 0.244 = +0.68 → 强化 a_3
A_4 = (−0.10 − 0.369) / 0.244 = −1.92 → 抑制 a_4
```

**Step 6 — 策略更新**：

```
g_WISE = (1/4) · [sgn(+0.78)∇L_FM(a_1) + sgn(+0.45)∇L_FM(a_2)
                + sgn(+0.68)∇L_FM(a_3) + sgn(−1.92)∇L_FM(a_4)]
       = (1/4) · [+∇L_FM(a_1) + ∇L_FM(a_2) + ∇L_FM(a_3) − ∇L_FM(a_4)]
```

沿 −g_WISE 方向更新 π_θ：a_1（直接下抓）获得最大强化，a_4（错误方向）被抑制。

## 4. 工程视角 (Engineering View)

| 维度 | 数值/约束 | 工程含义 |
|------|----------|----------|
| 世界模型推理调用削减 | ~80% | 从 138 states → 28 states（Table 3），GPU 时间从 11.45h → 2.61h |
| 想象边界 L | 有界（论文未明确给出 chunk 数，附录有详细配置） | 防止预测误差累积；L 越大误差越大但信息越多 |
| 候选数 M | 论文未在主文明确 | M 越大评估越准但推理成本线性增长 |
| 世界模型 | 基于 Open-Sora 的 Rectified Flow 模型（冻结） | 需要预训练视频生成能力；冻结意味着不更新 WM 参数 |
| 奖励模型 | DINOv2 编码 + 3 个轻量 head | 可独立训练，不影响策略前向传播 |
| 调度器 | DINOv2 + 轻量 head + sigmoid | 推理时几乎无额外开销（相比世界模型） |
| 策略更新 | Flow Matching loss + 正则化 | 只更新第一个动作 chunk，想象轨迹不直接生成监督信号 |
| 重复想象 | 每个候选想象 2 次取平均 R̄_i | 增加 2× 世界模型调用但提升评估稳定性 |

**部署约束**：后训练阶段需要同时加载 VLA 策略、世界模型、奖励模型、调度器四个模型。推理时只需 VLA 策略 + 调度器（世界模型和奖励模型仅在后训练时使用）。

## 6. 能力与失败模式 (Capabilities & Failure Modes)

**能做什么**：
- 在 π0 和 π0.5 两个不同强度的 VLA 基座上均取得稳定提升（+9.8pp 和 +7.9pp 仿真平均）
- 真实世界泛化场景下提升尤为显著（π0: 42.5% → 68.8%, +26.3pp）
- 显著降低世界模型计算开销（~80% 调用削减）
- 对分布外条件（光照变化、物体位置偏移、干扰物）有更强鲁棒性

**不能做什么 / 失败模式**：
- 仅在桌面操作任务上验证（5 个仿真 + 4 个真实），未测试移动机器人、双臂协作、人形平台
- 世界模型预测误差在长程任务中仍可能累积（虽然有界推演缓解）
- 调度器的弱监督信号依赖于机器人执行信号作为视觉代理，可能在未见过的操作类型上失效
- 奖励模型在极端分布偏移下可能给出不可靠评分（论文未报告奖励模型本身的泛化能力）

### 6.1 隐含假设 (Hidden Assumptions)

1. **交互相关性可学习**：假设 DINOv2 编码的视觉特征足以预测"何时需要想象"。如果调度器误判（该想象时跳过），策略优化会丢失关键学习信号。
2. **世界模型在候选动作分布上可靠**：假设冻结的世界模型在策略采样出的候选动作上仍能给出合理的预测。如果策略探索到世界模型训练分布外的区域，想象质量会下降。
3. **奖励模型评分可迁移**：奖励模型独立训练后用于评估想象轨迹，假设其在预测（非真实）观测上仍能给出可靠评分。
4. **组内相对排序稳定**：质量门要求 ρ_rank ≥ 0.5（两次想象排序一致性），假设候选之间的相对优劣在重复想象中保持一致。
