### 1.2 关键机制 (Key Mechanism)

论文的核心洞察是：**FM 的速度场几何直接编码了不确定性**。

在理想确定情况下（后验方差为零），FM 速度场是一个仿射各向同性收缩场（affine-isotropic contraction field）：

- 速度场 Jacobian = −I/(1−s)，即负恒等矩阵的标量倍
- 去噪轨迹是直线，速度恒定，加速度为零
- 所有从不同噪声出发的轨迹都笔直汇聚到同一个目标点

当不确定性出现时，速度场偏离这个理想模板：

- Jacobian 不再是 −I/(1−s) 的倍数
- 去噪轨迹开始弯曲
- 弯曲程度与后验协方差成正比

⚡ **Eureka Moment**：**去噪轨迹的弯曲程度 = 不确定性的几何签名**。不需要重采样、不需要训练额外网络——单次前向传递的轨迹本身就携带了丰富的不确定性信息。

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：

```
accel = [ Σ_t ||v_t - v_{t-1}|| ] / [ Σ_t ||v_t|| ]
      ≈ 0  (certain)    vs.    >> 0 (uncertain)
```

### 2.1 从 CFM 基础到几何定理

**条件流匹配 (CFM) 设置**：

```
x_s = s · x_1 + (1-s) · x_0,    x_0 ~ N(0, I),    s ∈ [0, 1]
```

- s=0: 纯噪声 x_0
- s=1: 干净动作 x_1 ~ p(x_1 | o)

**速度场定义**：

```
v(x, s) = E[x_1 - x_0 | x_s = x]
        = [E[x_1 | x_s = x] - x] / (1 - s)
```

速度场是从当前状态指向后验均值的缩放向量。

### 2.2 定理 1（定性）：确定性的几何刻画

```
当 Σ = 0 (后验坍缩为点质量):
  v(x, s) = (a* - x) / (1 - s)
  J = ∂v/∂x = I / (s - 1)    ← 仿射各向同性收缩
  x(s) = a* + (1-s)(x_0 - a*)  ← 直线路径
  accel = 0                     ← 零加速度
```

**直觉**：如果模型对目标完全确定，无论采样什么噪声，去噪路径都是指向同一目标的直线，速度恒定，加速度为零。

### 2.3 定理 2（定量）：偏离模板 = 不确定性

```
Cov(x_1 | x_s = x) = (1-s)³/s · [J + I/(1-s)]
                              ↑
                    偏离仿射模板的量
                    ∝ 条件端点协方差（不确定性）
```

```
tr(Σ) ≥ (1-s)² · E[||v - v_aff||²]
          ↑
    场偏离仿射模板的均方
    下界后验协方差
```

**直觉**：速度场偏离理想仿射模板的程度，直接正比于后验不确定性。偏离越大，不确定性越高。

### 2.4 accel 与后验协方差的理论联系

对路径加速度求导：

```
v'(s) = m_path'(s) / (1-s) + [s / (1-s)³] · v(s) · Cov(x_1 | x_s = x(s))
        ↑ 目标移动项              ↑ 协方差项
```

其中 m_path(s) = E[x_1 | x_s = x(s)] 是去噪器当前瞄准的后验均值。

**关键直觉**：
- 如果目标固定不动（m_path 不变），运动不会产生加速度
- 路径弯曲当且仅当它追逐的后验均值本身在移动
- 加速度 = 场级不确定性沿去噪轨迹的积分

### 2.5 局部单调性

```
E[accel] = κ · σ² + O(σ⁴),    κ > 0
```

在小方差 regime 下，期望 accel 与后验方差 σ² 成线性正比。不确定性越大，accel 越大。

> 符号说明：
> - x: 展平的动作块，x ∈ R^D
> - s: 前向调度参数，s ∈ [0,1]
> - v(x,s): 速度场输出
> - a*: 后验均值 E[x_1 | o]
> - Σ: 后验协方差 Cov(x_1 | o)
> - J: 速度场 Jacobian ∂v/∂x
> - accel: 去噪加速度代理（标量）

## 3. 带数字走一遍：玩具例子 (Worked Example)

考虑一个 2D 动作空间的玩具 FM 模型，假设去噪步数 T=10。

**场景 A：确定性（单模态目标）**

```
观察 o_u → 后验坍缩为 a* = [0.5, 0.3]

去噪轨迹（理想直线）:
  t=0: x_0 = [0.8, -0.2],  v_0 = [-0.03, 0.05]
  t=1: x_1 = [0.77, -0.15], v_1 = [-0.03, 0.05]
  t=2: x_2 = [0.74, -0.10], v_2 = [-0.03, 0.05]
  ...
  t=9: x_9 = [0.50, 0.30],  v_9 = [-0.03, 0.05]

速度变化: ||v_t - v_{t-1}|| ≈ 0  (所有步速度几乎相同)
总速度:   Σ ||v_t|| ≈ 10 × 0.058 ≈ 0.58

accel ≈ 10 × 0 / 0.58 ≈ 0.00  ← 零加速度 = 高确定性
```

**场景 B：Aleatoric 不确定性（多模态目标）**

```
观察 o_m → 后验为双峰混合: a*_1 = [0.5, 0.3] 或 a*_2 = [-0.5, 0.8]

去噪轨迹（弯曲路径）:
  t=0: x_0 = [0.8, -0.2],  v_0 = [-0.05, 0.08]   (初始方向不确定)
  t=1: x_1 = [0.75, -0.12], v_1 = [-0.06, 0.09]
  t=2: x_2 = [0.69, -0.03], v_2 = [-0.08, 0.12]   (开始转向)
  t=3: x_3 = [0.61, 0.09],  v_3 = [-0.10, 0.14]   (方向变化加剧)
  t=4: x_4 = [0.51, 0.23],  v_4 = [-0.06, 0.07]   (收敛到 a*_1)
  ...

速度变化: ||v_t - v_{t-1}|| 显著非零
  t=1→2: ||[−0.02, 0.03]|| ≈ 0.036
  t=2→3: ||[−0.02, 0.02]|| ≈ 0.028
  t=3→4: ||[0.04, −0.07]|| ≈ 0.081

Σ ||v_t - v_{t-1}|| ≈ 0.35
Σ ||v_t|| ≈ 0.70

accel_p = 10 × 0.35 / 0.70 = 5.0  ← 高加速度 = 高不确定性
```

**场景 C：Epistemic 不确定性（OOD 输入）**

```
未见过的观察 o_ood → 场混沌，轨迹急剧弯曲

速度变化剧烈且方向随机:
  t=0→1: Δv ≈ [0.05, -0.10], ||Δv|| ≈ 0.112
  t=1→2: Δv ≈ [-0.08, 0.03], ||Δv|| ≈ 0.085
  t=2→3: Δv ≈ [0.12, 0.06],  ||Δv|| ≈ 0.134
  ...

Σ ||v_t - v_{t-1}|| ≈ 0.80
Σ ||v_t|| ≈ 0.65

accel_p = 10 × 0.80 / 0.65 ≈ 12.3  ← 极高加速度 = OOD
```

**对比总结**：

| 场景 | accel 值 | 不确定性类型 | 检测结论 |
|------|---------|-------------|---------|
| A (确定性) | ≈ 0.00 | 无 | 安全 |
| B (多模态) | ≈ 5.0 | Aleatoric | 需关注 |
| C (OOD) | ≈ 12.3 | Epistemic | 告警 |

### 6.3 隐含假设 (Hidden Assumptions)

1. **CFM 场精确性假设**：理论推导假设网络完美学习了 CFM 速度场。实际训练的 FM 模型存在拟合误差，可能影响 accel 的忠实度。
2. **小方差 regime**：局部单调性定理 (Eq. 14) 仅在 Σ = σ²Σ₀ 且 σ 足够小时成立。对于高度不确定的 OOD 场景，线性关系可能偏离。
3. **固定协方差形状**：理论假设 Σ = σ²Σ₀，即协方差形状固定，仅方差缩放。实际中不同不确定性来源的协方差结构可能不同。
4. **成功轨迹校准集**：CUSUM 阈值需要在 held-out 成功轨迹上校准。如果部署环境与校准集分布差异大，阈值可能失效。
5. **Euler 离散化充分性**：accel 基于 Euler 离散化估计。如果实际推理使用更高阶积分器（如 RK4），轨迹弯曲模式可能不同。

## 8. 精讀建議 (Reading Guide)

**值得精讀原文的人**：
- 部署 FM-based VLA 到真实机器人、需要在线安全监控的研究者/工程师
- 研究流匹配理论性质、对速度场几何感兴趣的理论研究者
- 探索不确定性估计在具身智能中应用的博士生

**建議章節路徑**：
1. 先读 §2（FM 不确定性的几何本质）——理解理论基础
2. 再看 §3（accel 作为不确定性代理）——核心方法
3. 可跳 §4.1（基线细节）——如果只关心 accel 本身，不需要深入了解所有基线

**不值得精讀的理由**：
- 如果你不做 FM/VLA 的动作头，而是用扩散策略或确定性策略，这篇的直接适用性有限
- 如果你已经熟悉 ACE/STAC 等失败检测方法且只在寻找即插即用方案，读 §3.1 和 Table 1 即可
