## 1. 核心架构/方法总览 (Overview / Architecture)

### 1.1 系统对比概览

| 模块 | 输入 | 输出 | 运行频率 | 训练/推理 |
|------|------|------|----------|-----------|
| **VLA 策略 π_θ** | 视觉 o_t + 语言指令 + 本体状态 | 候选动作序列 A_t:t+H-1 | 10 Hz | 预训练（不变） |
| **风险估计器 E_φ** | (x_t, g_t, z_t, A_t:t+H-1) | r_hat ∈ [0,1], d_hat_min, tau_hat_ttc | 10 Hz（VLA 同步） | 两阶段训练 |
| **门控器 (Gate)** | r_hat, τ↑, τ↓ | 执行/拦截/软减速 | 30 Hz（低层控制） | 无训练，阈值调参 |
| **恢复控制器** | s_t, E_φ 梯度 | 恢复动作序列 A^rec | 30 Hz | QP/CBF 求解 |
| **策略微调器** | 安全数据集 D_safe | 风险加权 BC 损失更新 θ | 离线/周期 | DAgger-like 缓冲 |

### 1.2 关键机制 (Key Mechanism)

CoFreeVLA 的核心设计哲学是**"不改动 VLA 主干，而在其外部叠加安全闭环"**。具体三个层次：

1. **执行门控（Execution Gating）**：VLA 产生 N 个候选动作序列（beam search + jitter），风险估计器对每个候选打分，选风险最低者。若 r_hat > τ↑（0.85），拦截该动作；若 r_hat ≤ τ↓（0.30），直接执行；中间区域用 α_t = clip(1 - r_hat/τ↑, 0, 1) 做软减速。滞后阈值（τ↑=0.85, τ↓=0.30）防止振荡。

2. **恢复合成（Recovery Synthesis）**：当动作被拦截时，通过最小化 E_φ(s_t, A) + λ‖A‖² 生成恢复轨迹，将双臂推向安全构型空间 S_safe = {q : d_min(q) ≥ d_0}。恢复持续直到 r_hat ≤ τ↓ 连续 K 个周期。

3. **策略优化（Policy Refinement）**：用风险加权行为克隆损失微调 VLA：min_θ E[(s,a)~D][ℓ_BC(π_θ(s), a) · w(s)]，其中 w(s) = exp[-κ·E_φ(s, A)]。高风险样本获得更低权重，引导策略学习碰撞-free 行为分布。

⚡ **Eureka Moment**：不重新训练 VLA，而是用一个 <5ms 的轻量级风险估计器作为"安全副驾"——即插即用、架构无关、三层闭环（门控+恢复+微调）。

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：

```
L = λ_bce · BCE(r_hat, y_bin) + λ_d · ‖d_hat_min - y_d‖² + λ_ttc · ‖tau_hat_ttc - y_ttc‖₁
```

**目标**：训练一个校准的风险估计器，输出 [0,1] 碰撞概率 + 辅助几何量（最小间距、碰撞剩余时间）。

**变量说明**：

| 符号 | 含义 | 维度/范围 |
|------|------|-----------|
| r_hat_t | 预测碰撞概率 | [0, 1] |
| y_t^bin | 真实碰撞标签（二值） | {0, 1} |
| d_hat_min | 预测最小臂间/臂物间距 | ℝ≥0 (mm) |
| y_t^d | 真实最小间距 | ℝ≥0 (mm) |
| tau_hat_ttc | 预测碰撞剩余时间 | ℝ≥0 (s) |
| y_t^ttc | 真实碰撞剩余时间 | ℝ≥0 (s) |
| λ_bce, λ_d, λ_ttc | 损失权重 | 1.0, 0.5, 0.1 |

**直觉**：三头联合训练——主头做碰撞二分类，两个辅助头回归几何距离和时间到碰撞。辅助头解决"二值标签无法刻画接近程度"的问题：即使没碰撞，距离 2mm 和 200mm 的风险差异巨大，辅助头提供梯度信号让模型学会区分。

**策略微调目标**：

```
min_θ E[(s,a)~D] [ ℓ_BC(π_θ(s), a) · exp(-κ · E_φ(s, A_t:t+H-1)) ]
```

高风险样本被指数衰减加权，策略自然偏向低风险行为。

> 符号与本文保持一致：x_t 末端执行器位姿，g_t 夹爪状态，o_t 观测（RGB-D + 指令），z_t = f_VLA(o_t) 视觉嵌入，A_t:t+H-1 候选动作序列，H=16 为部署时 horizon。

## 3. 带数字走一遍：玩具例子 (Worked Example)

假设一个简化的双臂场景：

**场景**：左臂持杯，右臂持壶，正在执行"倒豆子进杯子"。

**时刻 t**：
- 当前关节构型 q_t = (左臂: [0.2, -0.5, 1.1, ...], 右臂: [0.8, 0.3, -0.2, ...])
- VLA 提议动作 a_t = (左臂: Δx=[+5mm, 0, +2mm], 右臂: Δx=[-3mm, +10mm, -1mm])
- 候选 N=5 个 beam+jitter 变体

**风险估计器推理**：

| 候选 n | r_hat_t^(n) | d_hat_min (mm) | tau_ttc (s) | 决策 |
|--------|-------------|-----------------|-------------|------|
| 1 (nominal) | 0.92 | 8 | 0.2 | ❌ 拦截 |
| 2 (jitter A) | 0.75 | 22 | 0.5 | ⚠️ 软减速 α=0.12 |
| 3 (jitter B) | 0.45 | 45 | 1.2 | ⚠️ 软减速 α=0.47 |
| 4 (jitter C) | 0.18 | 80 | 3.0 | ✅ 执行 |
| 5 (jitter D) | 0.35 | 55 | 2.0 | ⚠️ 软减速 α=0.59 |

**执行**：选择 n*=4（风险最低），r_hat=0.18 ≤ τ↓=0.30 → 直接执行 a_t^(4)。

**假设场景 B**（所有候选风险都高）：

若所有 5 个候选 r_hat > τ↑=0.85 → 进入恢复模式：

```
A^rec = argmin_A [ E_φ(s_t, A) + 0.1·‖A‖² ]
```

通过 3 步投影梯度下降，得到恢复动作 a_t^rec = (左臂后退 15mm, 右臂侧移 10mm)。执行后：
- t+1: r_hat=0.40 → 仍在恢复
- t+2: r_hat=0.22 → r_hat ≤ τ↓，连续 K=2 周期确认 → 恢复结束，VLA 继续

## 4. 工程视角 (Engineering View)

| 指标 | 数值 | 含义 |
|------|------|------|
| VLA 控制频率 | 10 Hz | 100ms/步 |
| 低层控制频率 | 30 Hz | 33ms/步 |
| 风险估计器推理 | <5 ms | 占 VLA 周期 <5%，占低层周期 ~15% |
| 模型大小 | 4-layer Transformer, d=384, 8 heads | 轻量，CPU 可跑 |
| 动作 horizon H | 16 | 预测未来 1.6s 的碰撞风险 |
| 预训练数据 | 200K samples (PyBullet) | 80/10/10 训练/校准/测试 |
| 硬件适配 | 350 条真实轨迹, ≤30 epochs | ~45 min on RTX 4090 |
| 预训练耗时 | ~3 h on RTX 4090 | batch=512, LR=1e-4 |
| 部署格式 | ONNX / TorchScript | 跨平台推理 |

**工程含义**：
- 风险估计器 <5ms 推理延迟是关键设计——它可以在 VLA 的 100ms 周期内完成 N 个候选的评估（5ms × N ≤ 100ms → N ≤ 20），不拖慢主循环。
- 两阶段训练（仿真预训练 + 真实微调）避免了纯仿真到真实的 sim2real gap：FCL 碰撞检测在真实 URDF/CAD 几何上 replay 测量姿态，提供模型基线标签。
- 滞后阈值（τ↑=0.85, τ↓=0.30）防止在决策边界附近振荡——这是实际控制系统的经典设计。
- 固定阈值是主要工程约束：精密任务需要更保守的阈值，大范围操作可以用更激进的阈值。论文承认需要"task-conditioned thresholds"。

## 6. 能力与失败模式 (Capabilities & Failure Modes)

**能做什么**：
- 在双臂大幅度交叉操作（如倒豆子）中大幅降低碰撞率——这是最大收益场景
- 即插即用：不改动 VLA 权重，只需在其输出端加风险估计层
- 架构无关：对轻量模型（TinyVLA）和大模型（π0.6）都有效
- 实时可行：<5ms 推理，不改变 10Hz VLA 控制频率

**不能做什么**：
- 毫米级精密操作（拔笔帽）中，固定阈值会产生假阳性——拦截了合法的近距离动作（论文 Fig 3B 明确展示）
- 不解决双臂与外部环境障碍物的碰撞——只关注 self-collision（臂间、臂与被抓物体）
- 恢复策略是局部的（gradient-based local optimization），可能陷入次优安全构型

### 6.1 隐含假设 (Hidden Assumptions)

1. **VLA 视觉嵌入 z_t 足够表征碰撞相关几何**：估计器使用 VLA 倒数第二层 token 作为视觉特征，假设这些特征包含足够的空间信息来判断碰撞。但如果 VLA 的视觉表征偏向语义（"这是杯子"）而非几何（"杯子在左臂右侧 20mm"），估计器可能遗漏关键信号。

2. **仿真预训练标签足够真实**：FCL 碰撞检测依赖精确的 URDF/CAD 几何模型。如果真实机器人的标定误差 > 5mm，仿真标签和真实碰撞边界之间会有 gap。论文通过 350 条真实轨迹微调来弥补，但样本量有限。

3. **N 个候选中总有一个安全的**：在高度受限空间（如狭窄通道中双手交叉），可能所有候选都有高风险。此时恢复策略能否找到可行路径取决于局部优化的能力——论文未系统评估这种"无安全候选"的极端情况。

4. **阈值 τ↑/τ↓ 可通用**：当前使用全局固定阈值（0.85/0.30）。但不同任务的最佳阈值差异很大（倒豆子 vs 拔笔帽）。论文承认需要 task-conditioned calibration。

| 方法 | 关注点 | 架构 | 训练方式 | 适用场景 |
|------|--------|------|----------|----------|
| **CoFreeVLA (本文)** | 双臂自碰撞安全层 | 4-layer Transformer 风险估计器 + VLA 门控 | 仿真预训练 + 真实微调 | 任何 VLA 双臂部署 |

| Neural self-collision controller | 自碰撞学习检测 | 专用碰撞检测网络 | 仿真+真实数据 | 单臂/双臂碰撞检测 |

**面试 Tip**：如果面试官问"CoFreeVLA 和 CBF 有什么区别？"——CBF 提供形式化安全保证但需要手动设计 barrier function 且作用于低层控制；CoFreeVLA 是数据驱动的、感知到动作端到端、可叠加在任何 VLA 上但不提供形式化保证。两者互补，论文也提到 QP/CBF 作为梯度恢复不可用时的 fallback。
