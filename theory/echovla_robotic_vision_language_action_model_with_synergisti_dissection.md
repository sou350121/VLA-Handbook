### 1.2 关键机制 (Key Mechanism)

**为什么是双记忆？**

人类大脑的声明式记忆系统包含两个互补子系统：
- **旁海马皮层（PHC）**：编码空间结构和场景语义 → 对应 EchoVLA 的 **场景记忆**（3D 体素地图，持久、缓慢演化）
- **海马体**：整合情境输入为时间组织的事件记忆 → 对应 EchoVLA 的 **情景记忆**（FIFO token 缓冲区，精细、快速更新）

单一记忆无法同时满足两种需求：
- 只有场景记忆 → 知道"东西在哪"，但不知道"柜门是否已打开"
- 只有情景记忆 → 知道"刚才做了什么"，但缺乏全局空间规划能力

⚡ **Eureka Moment**：将人脑的双系统声明式记忆（PHC 空间编码 + 海马事件编码）映射为 VLA 的显式场景记忆 + 情景记忆，通过分层注意力（粗粒度场景匹配 + 细粒度时序匹配）实现空间一致性与任务状态追踪的解耦。

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：

```
L = Σ_p∈{base,arm} E_t,z_t [ ||ε - ε_θ^(p)(z_t, H_t, t)||^2 ]
H_t = CrossAttn(q=V_t^3D, k/v=M^scene_sel) ⊕ CrossAttn(q=S_t, k/v=M^epi_sel)
```

**目标**：通过最小化两个独立扩散去噪器的 L2 噪声预测误差，训练一个记忆增强的移动操作策略。

**公式分解**：

| 符号 | 含义 |
|------|------|
| S_t = [L, V_t, P_t, R_t] | 多模态统一 token（语言+视觉+几何+本体） |
| M^scene | 场景记忆：3D 体素地图，Key=(x,y,z), Value=PointAttn 特征 |
| M^epi | 情景记忆：FIFO token 缓冲区，存储最近 k 步的 S_t |
| δ = \|\|V_t^3D - D(M^scene[x,y,z])\|\|^2 | 重建误差，门控场景记忆更新 |
| τ = 0.5 | 重建误差阈值，δ > τ 才更新 |
| α = 0.2 | EMA 更新率 |
| H_t | 记忆增强表征，拼接两个 cross-attention 输出 |
| ε_θ^(p) | 分部去噪器（base 或 arm），输入噪声动作 z_t + 记忆 H_t + 时间步 t |

> 符号与本文保持一致：S_t 为统一 token 序列，M^scene 为场景记忆体素地图，M^epi 为情景记忆 FIFO 缓冲区，H_t 为记忆增强表征。

**直觉**：场景记忆通过重建误差门控 + EMA 逐步构建稳定的 3D 环境地图（"东西在哪"）；情景记忆通过 FIFO 保留最近交互的精细时序信息（"刚才做了什么"）；两个记忆分别通过粗/细粒度 cross-attention 检索后拼接，作为两个独立扩散去噪器的条件输入，实现移动基座和机械臂的解耦但协调的动作生成。

## 3. 带数字走一遍：玩具例子 (Worked Example)

假设一个厨房场景中的「从水槽取水杯放到灶台上」任务（PnPS2C）：

**Timestep t=0**：机器人位于厨房入口
- 观察：3 路 RGB-D + 指令"把水槽的水杯放到灶台"
- 场景记忆 M^scene：初始为空（首次进入），通过 PointAttn 编码局部点云，δ 较大（>0.5），触发 EMA 更新 α=0.2 写入体素地图
- 情景记忆 M^epi：空（刚开始）
- H_t = [Z^scene, Z^epi]：场景检索结果主导（无历史可检索）
- 扩散策略输出：a_0^base = 向前移动 0.3m，a_0^arm = 机械臂收起

**Timestep t=15**：机器人到达水槽旁
- 场景记忆：已累积约 15 个体素更新，覆盖水槽区域
- 情景记忆：M^epi = {(S_0, 0), (S_1, 1), ..., (S_14, 14)}，k=15
- Cross-attention 检索：场景匹配到水槽位置 → Z^scene 提供空间引导；情景匹配到初始状态 → Z^epi 确认"尚未抓取"
- 扩散策略输出：a_15^base = 微调位置 Δx=0.02m，a_15^arm = 伸展抓取

**Timestep t=30**：已抓取水杯，需要导航到灶台
- 场景记忆：已覆盖水槽→灶台路径区域
- 情景记忆：包含"已抓取"状态（关键非马尔可夫信号）
- Cross-attention 检索：情景记忆中的"已抓取"token 被激活 → 策略知道现在是"携带状态"而非"空手状态"
- 扩散策略输出：a_30^base = 转向灶台方向移动，a_30^arm = 保持抓取姿态

**Timestep t=45**：到达灶台，放置水杯
- 场景记忆：灶台区域体素特征匹配
- 情景记忆：确认"已到达"
- 扩散策略输出：a_45^base = 静止，a_45^arm = 释放

**关键**：如果没有情景记忆，t=30 时的 RGB 帧可能与 t=15 时视觉上相似（都在水槽旁），但动作完全不同（一个要抓取，一个要离开）。情景记忆解决了这个非马尔可夫歧义。

- 冻结 SigLIP vs 端到端训练：冻结降低训练成本，但限制了视觉表征与机器人任务的适配

### 不能做什么

| 场景 | 原因 |
|------|------|
| 跨场景泛化（非厨房） | 实验仅在厨房场景验证，场景记忆是环境特定的 |
| 大规模多房间导航 | 场景记忆体素地图随空间增大而膨胀，检索效率待验证 |
| 动态环境适应 | 场景记忆 EMA 更新较慢（α=0.2），对快速变化的环境响应滞后 |
| 无深度传感器的场景 | 依赖 RGB-D 点云编码，纯 RGB 输入无法构建场景记忆 |

### 6.1 隐含假设 (Hidden Assumptions)

1. **环境结构相对稳定**：场景记忆通过 EMA 渐进构建，假设环境不会在 episode 间发生剧烈变化。如果家具频繁移动，记忆地图会退化。
2. **深度传感器可靠**：PointAttn 编码依赖准确的深度信息。在反光表面（水槽、玻璃）或暗光环境下，点云质量下降会直接影响场景记忆质量。
3. **FIFO 窗口足够覆盖任务历史**：情景记忆的窗口大小 k 未明确给出。如果任务跨度超过 k 步，早期关键状态会被遗忘。
4. **仿真到真机的迁移可行**：MoMani 仿真数据 + 1,200 条真机演示的组合能否覆盖真实世界的分布偏移？论文在 7m×7m 单一 arena 验证，泛化性存疑。
5. **分部扩散的独立性假设**：基座和机械臂独立扩散，假设两者动力学可解耦。但在紧密协作场景（如基座移动同时机械臂操作），独立性假设可能限制性能。
