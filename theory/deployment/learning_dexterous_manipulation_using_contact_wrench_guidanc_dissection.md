### 1.2 关键机制

- **不匹配接触位置，而是匹配接触的"效果"**。作者在 §2 直接点破位置奖励的缺陷：同一块物体区域，法向和施力方向不同，产生的物体运动完全不同。图 1 右侧的开盒任务给出了可视化对照——位置奖励选出的接触点空间上很近，但接触法向几乎与人手垂直。
- **支撑函数把"变长集合"变成"定长向量"**。人类接触点数量和机器人接触点数量天然不同，力旋量矩阵列数也不同。作者用 b 个预采样单位方向 B 去取每列投影的最大值，得到固定 b 维描述子，从而可以逐元素比较。
- **归一化力预算**。每条摩擦锥边力都是单位力，所以这个描述子刻画的是"方向能力"而非"动力学可实现的力旋量"。作者明确说明理由：示范里接触力不可观测，绝对幅值跨具身、跨 sim-to-real 迁移效果差。
- **双向容差 + 漏接触/多接触惩罚**。式 (3) 的指数核永远为正，所以要额外惩罚"人类没有而机器人有"（unintended）与"人类有而机器人没有"（missed）两种情况。
- **降级路径**。当接触估计有噪声（例如从 RGB 视频重建的示范），直接匹配力旋量不可靠，作者改用只要求"每个基方向上有正支撑"的力闭合目标 r_fc。

⚡ **Eureka Moment**：把"人手怎么放"翻译成"这组接触能对物体施加什么方向的力与力矩"，跨具身迁移就从一个几何匹配问题变成了一个**集合相似度**问题——而集合相似度可以用支撑函数便宜地算出来。

## 2. 数学核心

📌 **Napkin Formula**（一行抓住本质）：

```
r = r_task + r_imit + r_cws，其中 r_cws 比较的是「人类与机器人接触集合的支撑函数」
```

**目标**：让 rollout 的物体位姿轨迹跟随人类示范，同时让机器人产生的接触在"能诱发什么物体运动"这件事上像人手。

**奖励总和**：

```
r = r_task + r_imit + r_contact
```

**任务奖励**（绝对位姿跟踪 + 相对位姿项）：

```
r_task = exp( - Σ_k ‖x_object,k ⊖ s_object,k‖² / var_obj ) + r_relative

r_relative = m(t) · exp( - e_object / var_rel )
```

其中 ⊖ 表示 SE(3) 上的位姿差；m(t) 是二值掩码，**只由示范中的物体间距离决定**，与策略当前物体距离无关——附录 C 解释了这样做的原因：防止策略靠"把两个物体拉远"来白拿奖励。

**模仿奖励**：

```
r_imit = exp( - ‖x_robot,t - s_robot,t‖² / var_imit )
```

**力旋量构造**：接触点 i 上第 j 条可行的接触力 f 诱导的原语力旋量为

```
w^{i,j}_{h,k} = [ f^{j}_{h,k} ; p^{i}_{h,k} × f^{j}_{h,k} ]^T ∈ R^6
```

把所有接触点 × 所有摩擦锥边拼成矩阵：

```
W_{h,k} = [ w^{1,1} … w^{1,d} … w^{c,1} … w^{c,d} ] ∈ R^{6×(c_h,k · d)}
```

**支撑函数**：给定 b 个单位方向 B ∈ R^{6×b}，

```
σ_{h,k} = max_col( B^T W_{h,k} ) ∈ R^b
```

最大值按 B^T W 的列独立取。因为每条边力都是单位力，这个式子等价于 conv{w^{i,j}} 的支撑函数，也就是"跨全部接触共享一份单位力预算时可达的净力旋量集合"的方向描述子。

**接触力旋量奖励**（式 3）：

```
r_cws^k = exp( - ‖max(0, (1-β)σ_h,k - σ_r,k)‖² / v_cws
               - ‖max(0, σ_r,k - (1+β)σ_h,k)‖² / v_cws )
```

max 逐元素作用。第一项在机器人支撑低于下容差界时给惩罚，第二项在超过上容差界时给惩罚，β 是相对容差。

**降级目标（力闭合）**：

```
r_fc^k = (1/B) · Σ_b 1[ σ_r,k,b > ε ]
```

作者指出最大化该目标等价于最大化力闭合目标。

**真实部署的坐标标定**（附录 G）：

```
T^B_E = T^B_O · (T^E_O)^{-1}
T^E_V = T^E_O · (T^V_O)^{-1}
```

一次性标定后固定，前者把策略腕目标从环境系映射到机器人基座系，后者把 Vicon 实时位姿映射到策略环境系。

> **符号归属提醒**：σ_h 是"人类示范"的支撑函数，σ_r 是"机器人当前状态"的支撑函数；两者只在同一刚性部件 k 上比较，跨部件不混算。

**直觉**：这不是在说"力要多大"，而是在说"这组接触在哪些方向上'顶得住'"。人手和机器人手哪怕接触点完全不同，只要在 b 个方向上能提供的最大投影值落在同一个容差带里，就认为它们在功能上相似。

**时序说明（必须区分）**：论文的参考轨迹写作 τ_ref = {x_t}_{t=1..H}，H 是参考帧数，但正文**没有公布统一的采样间隔 Δt**。若按均匀间隔采样 K 帧，首末跨度是 (K-1)·Δt；若在时刻 t 预测 t+1 至 t+H，则终点距当前参考是 H·Δt。这两个量都不是"记忆窗口"。正文还给出其他时序数字（如 reset 后 20 步 warm-up、接触断开最多 15 帧桥接、300 步回放检查、Vicon 100 Hz、底层指令最高 500 Hz、0.25 s stale）；与本段时序讨论直接相关的数字包括：CHORD 全身策略的 observation command 里用 "N future reference frames" 描述未来参考帧数，全身补全模块用 T_ctx = 4 帧上下文做自回归分块，真实部署的策略循环跑 20 Hz。**不能把 20 Hz 或 T_ctx=4 写成所有实验共有的时序参数。**

## 3. 带数字走一遍：玩具例子

> ⚠️ 以下为**假设数值**的手算示例，用于演示 r_cws 的计算闭环，不是论文实验数据。已逐步验算。

假设一个二维平面任务，力旋量退化为 (fx, fy, τz)。物体上一个接触点 p = (0.10, 0) m，摩擦系数 μ = 0.5，摩擦锥半角 α = arctan(0.5) ≈ 26.57°，离散为 d = 4 条单位边力，角度取 {-26.57°, -8.86°, +8.86°, +26.57°}。

**人类侧**（法向沿 +x）：四条边力及其力矩 τz = p_x·f_y − p_y·f_x = 0.10·f_y：

```
w1 = ( 0.8944, -0.4472, -0.04472 )
w2 = ( 0.9881, -0.1540, -0.01540 )
w3 = ( 0.9881,  0.1540,  0.01540 )
w4 = ( 0.8944,  0.4472,  0.04472 )
```

取 b = 2 个基方向：b1 = (1,0,0)，b2 = (0,0,1)。按列取最大：

```
σ_h = [ max fx, max τz ] = [ 0.9881, 0.04472 ]
```

**机器人侧**：假设机器人接触点也在 p = (0.10, 0)，但抓握姿态使法向转了 90°（沿 +y），锥角变为 {63.43°, 81.14°, 98.86°, 116.57°}：

```
fx:  0.4472, 0.1540, -0.1540, -0.4472
τz:  0.08944, 0.09881, 0.09881, 0.08944
σ_r = [ 0.4472, 0.09881 ]
```

**关键观察**：位置完全相同，但力旋量支撑方向完全不同——σ_r 在 b1 上只有人类的一半左右，在 b2 上却是人类的两倍多。

取 β = 0.2，v_cws = 0.5，逐项算：

```
下界 (1-β)σ_h = [ 0.79048, 0.035776 ]
上界 (1+β)σ_h = [ 1.18572, 0.053664 ]

第一项残差 max(0, 下界 - σ_r) = [ 0.34328, 0 ]
   平方和 = 0.11784

第二项残差 max(0, σ_r - 上界) = [ 0, 0.045146 ]
   平方和 = 0.0020382

总和 = 0.11988
r_cws = exp( -0.11988 / 0.5 ) = exp(-0.23976) ≈ 0.7867
```

**验算取反**：如果机器人 σ_r 完全等于 σ_h，两项残差都是 0，r_cws = exp(0) = 1.0，这是上限。

**这个例子说明什么**：在这个假设场景里，"位置完全正确"的接触只拿到约 0.79 的接触奖励。位置奖励会给它满分，力旋量奖励不会。这正好复现了论文图 1 想表达的现象。另一个推论：如果机器人接触点换到 p = (0.05, 0) 但法向正确，σ_r,τz 约减半到 0.02236，低于下界 0.035776；第一项残差为 [0, 0.013416]，第二项不触发，惩罚发生在 τz 分量而非 fx——也就是说**位置不同但方向对，惩罚反而小于位置对但方向错**，这正是作者想要的"功能优先于几何"。

几个容易忽略的工程细节：

- **稳定训练的前提是接触奖励先收敛**。作者在 §4.1 明确写道："stable training requires the contact wrench reward to converge before VOC decay begins"——也就是说课程退火的时间表必须与奖励收敛耦合，这是一个不好写进论文但会卡住复现者的隐含调度约束。
- **域随机化用的是任务相关扰动**。作者不是高斯加噪，而是从人类力旋量矩阵 W_h,k 里采样力旋量去扰动物体部件（§3.2）。这样扰动的方向分布与示范的接触力学一致。
- **接触观测在全身训练里被移除**。附录 F.2 明确写 "We remove contact observation from the whole body training observation space"，源文未提及手臂侧保留。
- **阈值宽松度**：大规模评测的成功判据是位置误差 < 15 cm 且旋转误差 < 40°（§4.1）。作者说这个判据在大规模下与人类判断强相关，但读者要意识到这不是毫米级精度。

## 5. 数据与评测

### 5.1 数据组成

- **仿真基准规模**：4,739 个双臂灵巧操作任务，覆盖单/多刚性物体、铰接物体、多物体交互。
- **来源**：七个动作捕捉数据集（ARCTIC、TACO、HOT3D、OakInk2、DexYCB、GRAB、H2O）+ 内部视频重建的示范。
- **HOT3D 的分段**：约 294 条原始长记录被切成约 4,045 个原子交互片段（附录 E）。这是 4,739 总量里的主要贡献来源之一，原文措辞是 "expands roughly 294 raw recordings into approximately 4,045 atomic clips"。
- **视频重建流水线**（附录 D）：MoGe 单目深度做米制锚定，Grounding DINO 检测、SAM2 分割、SAM3D 重建网格、FoundationPose 追踪 6-DoF，ViPE + Dyn-HaMR 恢复 MANO 手，最后用 3D Gaussian splatting 联合精修，DROID-SLAM 初始化相机。整套流程在一个刷子操作任务上定量验证，得到 0.647 AUC。
- **质量门**：手-物或手-手穿透 > 2 cm 的序列被拒；凸包/网格体积比 > 3 的高度凹陷物体豁免手-物穿透检查；另有一条 300 步的回放检查。

### 5.3 真实机器人设置

- **平台**：Dexmate 机器人 + 两只 Sharpa 灵巧手；每臂 7 个驱动关节、躯干 3 个、每手 22 个，部署时共 61 维指令向量；头部与移动底盘不参与策略控制；躯干固定在 q_torso = [0.78, 1.57, 0.44] rad。
- **状态**：六相机 Vicon，100 Hz，超 0.25 s 判 stale；ONNX Runtime，20 Hz 策略循环。
- **结果**（§4.3）：碗递接 5/5；手内盘子重定向 3/5；碗-盘叠放 5/5；搅拌机开合 5/5；胶囊机交替取放 5/5；盒子取放开环 6/7、闭环 7/7。

**注意**：这些是 trial 级别计数，样本极小，不足以支撑统计显著性结论。论文也没做跨天重复或不同操作者的方差分析。

## 6. 能力与失败模式

**能做的**：
- 刚性、铰接、多物体三类任务的统一处理，作者强调"prior methods are limited to subsets... whereas CHORD succeeds across all three categories"。
- 长程序列的跟踪退化更慢（图 5 报告 AUC 约 0.85–0.98，基线随时程显著退化）。
- 跨手型迁移：人类五指 → G1 + Dex3 三指手，附录 F.3 给出 wrench 奖励 0.925±0.104 vs 位置奖励 0.217±0.333 的对比。
- 开环与闭环两种部署模式。

**不能做 / 会失败的**：
- **依赖状态观测**。真实部署不使用视觉，"state-based observations" 是作者列出的第一条局限。这意味着任何需要从图像里估计物体位姿的开放场景都不在覆盖范围内。
- **依赖较干净的示范**。第二条局限原文是"effective contact guidance requires relatively clean human demonstrations"。附录 B.1 的 Table 2 只列注入噪声上界；Figure 9 的趋势显示：只加手部噪声时性能平缓下降；手部 + 接触噪声则下降更明显；噪声极高时力闭合指导反而优于被污染的力旋量指导，但作者补充说力闭合会"降低灵巧性"。
- **精确放置敏感**。第三条局限明确指出有些任务小位姿误差就导致功能性失败。
- **per-sequence 训练**。每个序列一个策略、约 2 小时单卡，这不是一个可扩展到开放任务分布的训练范式。
- **基线复现存在适配不确定性**。附录 I 详细记录了把 DexMachina、ManipTrans、SPIDER、Human2Sim2Robot 移植到 Sharpa 手的过程，其中 ManipTrans 是在"没有原始预训练手部运动模仿器和独立残差模块"的情况下重实现的，SPIDER 的 IK 也用了 CHORD 自己的求解器。这些适配让对比结果带有实现选择的影响，读者引用时值得注明。

### 6.1 隐含假设

| 假设 | 作者的处置 | 批判性观察 |
|------|-----------|-----------|
| 人类与机器人的接触可用同一套力旋量语言比较 | 用单位力预算归一化，只比较方向能力 | 作者自己承认这是"方向描述子，不是动力学可实现的力旋量"；真实执行限制靠 RL 隐式满足，没有显式保证 |
| 接触效果相似 ≈ 任务功能相似 | 用附录 A 的相关性（r≈0.80）作为经验支持 | 相关性是**训练信号与成功率**的关系，不是"力旋量相似度与功能等价"的直接证明；且关系饱和，高奖励区拟合差 |
| 视频重建得到的接触足以支撑力旋量奖励 | 噪声大时降级到力闭合 | 降级路径丢失了"追随人手施力方式"的信息，只剩"抓稳"，这与论文的核心卖点是有张力的 |
| 演示中的物体位姿足够准 | 重定向 + 穿透检查 + 回放检查 | 检查针对的是几何可行性与仿真稳定性，不校验接触力本身的物理正确性 |
| 仿真扰动分布与真实分布匹配 | 从 W_h,k 采样力旋量扰动 | 这是有原则的做法，但没有真实接触力测量做对照验证 |

## 7. 与相关工作对比

| 方法 | 接触信号 | 迁移机制 | 训练方式 | 适用场景 |
|------|---------|---------|---------|---------|
| DexMachina (2026) | 接触位置 | 虚拟物体控制器 + 位置奖励 | RL，per-sequence | 双臂灵巧操作 |
| ManipTrans (2025) | 接触力（近示范接触处） | 残差学习 + 接触力奖励 | RL | 双臂操作迁移 |
| SPIDER (2025) | 接触位置 | 课程 + 虚拟物体控制 | RL | 灵巧重定向 |
| Human2Sim2Robot (2025) | 源文未给出明确接触信号 | 单次人类示范 + sim-to-real RL | RL | 跨具身鸿沟 |
| **CHORD（本文）** | **接触力旋量支撑函数** | **支撑函数容差带 + 多/漏接触惩罚** | **RL（FlashSAC，4096 envs）** | **刚性 / 铰接 / 多物体 + 全身** |

**同系列的关键差异**：前面几种方法并非都在同一层做监督：ManipTrans 奖励示范接触附近的接触力，DexMachina 与 SPIDER 使用接触位置；CHORD 则换到"接触能造成什么"。作者把这一层差异看作能同时覆盖推、撬、滑这类**瞬态非力闭合阶段**的原因，并指出接触位置本身并不决定接触效果。

**面试 Tip**：如果被问到"CHORD 和 DexMachina 的本质区别是什么"，一句话答——**DexMachina 奖励"手碰到人碰过的地方"，CHORD 奖励"手能对人手能产生的物体运动做出同样的贡献"；前者不显式约束接触法向，后者允许在接触位置不同的情况下比较诱发的力旋量效果，但力旋量本身显式依赖接触位置，并非对位置不敏感。**

## 8. 精读建议

**值得精读原文的人**：
1. 正在设计 human-to-robot 迁移奖励函数的研究者——§3.1 的式 (1)–(3) 和附录 B.2 的参数消融是可直接复用的工程细节。
2. 需要构建大规模仿真基准的工程师——附录 E 的重定向、接触检测、穿透检查、回放检查四道工序描述得相当具体，包括 2 cm 阈值、15 帧桥接、200 次 QP 迭代这些可照抄的数字。
3. 评估"接触表征能否作为跨具身中间语言"这一科学问题的读者——附录 A 与附录 F.3 提供了两组不同角度的经验证据。

**建议章节路径**：先读 §3.1 建立力旋量奖励的直觉 → 再看 §4.1 与表 1 确认量级 → 然后跳到附录 B.1/B.2 看它在哪里退化 → 最后读附录 E 判断基准构建成本。§2 Related Work 可以快速扫过，因为核心差异在 §3.1 已经讲清楚了。

**不值得精读的理由**：如果你的关注点是 VLA 架构（视觉编码器、动作 token 化、语言条件），这篇论文的策略是 MLP + 状态观测，与 VLA 主干无关，读摘要和 §5 的结论即可。如果你已经熟悉力旋量空间与抓取闭包理论，§2 与 §3.1 前半部分对你没有新增信息，直接从式 (3) 开始读。
