### 1.2 关键机制 (Key Mechanism)

**为什么用 Transformer 而不是 MLP/LSTM？**

- **MLP**：无时序建模能力，无法从关节历史中提取隐式物体状态。Y轴横向位移完全丢失（RMSE 17.87mm）。
- **LSTM**：有时序能力但梯度衰减限制长程依赖，Z轴重力耦合动态建模不足（RMSE 15.64mm）。
- **Transformer**：自注意力机制可选择性地关注接触相关的时间步，完整捕捉快速状态转换（如 t=1s 的 Y 轴骤降、t=5-10s 的 X 轴高频振荡），RMSE 降至 13.70mm。

**为什么辅助重建损失（Reconstruction Loss）至关重要？**

消融实验显示：去掉重建头后，无掉落成功率从 ~100% 暴跌至 35%，平均每轮掉落 5 次。重建损失迫使 Transformer 编码层学习物体动力学表征——不是直接预测动作，而是先理解"手里拿着什么、它在哪里"。

⚡ **Eureka Moment**：关节位置命令与实际位置的偏差（tracking error）本身就编码了物体存在和尺寸信息——体积效应（手指被物体阻挡）和重量效应（重力导致稳态误差）在关节数据中形成可区分的特征签名，无需任何外部传感器。

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：
```
L = L_BC + λ_p·||p̂_obj - p_obj||² + λ_q·||q̂ - q||² + λ_v·||q̂̇ - q̇||²
  = 行为克隆误差 + 隐式物体状态编码正则化
```

**先给目标**：让学生仅凭关节历史 imitate teacher 的动作，同时通过辅助重建任务迫使编码器提取隐式物体状态。

**公式拆解**：

```
L_total = L_BC + L_recon

L_BC = ||â_t - a_t^teacher||²₂          (行为克隆: 学生模仿教师动作)

L_recon = λ_p·||p̂_obj_t - p_obj_t||²₂   (物体位置重建, λ_p=0.5)
        + λ_q·||q̂_t - q_t||²₂           (关节位置去噪, λ_q=0.3)
        + λ_v·||q̂̇_t - q̇_t||²₂         (关节速度去噪, λ_v=0.2)
```

**变量说明**：

| 符号 | 含义 | 维度 |
|------|------|------|
| â_t | 学生预测动作 | ℝ¹⁷ |
| a_t^teacher | 教师动作（ground truth） | ℝ¹⁷ |
| p̂_obj_t | 预测物体位置 | ℝ³ |
| q̂_t, q̂̇_t | 预测无噪关节位置/速度 | ℝ¹⁷ |
| λ_p, λ_q, λ_v | 重建损失权重 | 0.5, 0.3, 0.2 |

**直觉**：重建损失不是"额外任务"——它是隐式状态估计的引擎。没有它，Transformer 只是一个动作映射器；有了它，Transformer 必须先"理解"手里的物体在哪里、多重、多大，才能做出正确的重建。这正是从 proprioception 中提取 exteroception 的关键机制。

> 符号与本文保持一致：q = 关节位置, q̇ = 关节速度, p_obj = 物体位置, r_obj = 物体四元数, ω = 角速度

## 3. 带数字走一遍：玩具例子 (Worked Example)

假设一个简化场景：55mm 立方体在 ORCA 手上，目标旋转速度 ω* = 1.0 rad/s（绕 z 轴）。

**Step 1: 传感器输入**
- 16 个 AS5600 磁角度传感器读取关节位置 q_t ∈ ℝ¹⁶（腕关节未直接测量，固定为零位）
- 速度通过差分计算：q̇_t = (q_t - q_{t-1}) / Δt，Δt = 0.05s（20Hz）
- 加入噪声：每 episode 采样偏置 b_j ~ N(0, σ_b²)，每步采样 n_t ~ N(0, σ_n²)

**Step 2: Transformer 编码**
- 10 步历史 → 10 个 token（每步 q + q̇ 拼接后投影到 256-dim）
- + 1 个 action context token + 1 个 goal command token = 12 tokens
- 3 层自注意力 → [CLS] token 聚合全局信息

**Step 3: 隐式物体状态提取（数值示例）**

假设拇指 MCP 关节：
- 命令位置 q_cmd = 0.5 rad
- 无物体时实际位置 ≈ 0.5 rad（y=x 线附近）
- 有 55mm 立方体时：体积效应阻挡 → 实际位置 ≈ 0.38 rad
- 位置误差 e = 0.12 rad → 编码了"有物体"信号
- 换成 65mm 立方体：误差更大 → e ≈ 0.18 rad → 编码了"物体更大"信号

**Step 4: 重建头验证**
- Transformer 从 [CLS] token 预测 p̂_obj = [0.02, -0.01, 0.05] m
- 与 ground truth p_obj = [0.015, -0.013, 0.048] m 比较
- RMSE ≈ 6mm（X 轴最佳情况，论文报告 6.82mm）

**Step 5: 动作输出**
- â_t = [0.12, -0.08, 0.23, ..., 0.05]（17 维关节位置目标）
- EMA 平滑：a_applied = α·â_t + (1-α)·a_{t-1}，α 控制平滑强度
- 发送到 PD 控制器 → 手指运动 → 物体旋转

**闭环验证**：60 秒试验内，PT-Joint 完成 11.83 圈旋转（RPM），方向准确率 100%，零掉落。

### 6.1 隐含假设 (Hidden Assumptions)

1. **物体始终在手掌内**：任务假设物体不脱离手的抓握范围。如果物体滑出可触及区域，关节编码器无法检测（无视觉确认）。
2. **摩擦特性在域随机化覆盖范围内**：真实手指-物体摩擦如果超出 0.8-2.0× 范围，策略可能失效。
3. **腱传动延迟可忽略**：AS5600 直接测量关节角度，但 tendon 的动态响应（弹性变形、延迟）未在模型中显式建模。
4. **单一物体假设**：隐式状态估计假设手中只有一个物体。多物体交互会产生混淆的关节误差信号。
5. **控制频率 20Hz 足够**：对于快速操作（如抛接、高速旋转），20Hz 可能不足，但论文未测试更高频率。
