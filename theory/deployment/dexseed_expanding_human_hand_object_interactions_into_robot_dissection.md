## 1. 核心架构/方法总览

### 1.1 系统组件概览

| 模块 | 输入 | 输出 | 频率 / 规模 | 性质 |
|------|------|------|------------|------|
| Grasp Bank 构建 | GRAB 序列中“物体位移首次超阈值”的那一帧 | 170 维抓取描述子 → 固定阈值聚类 → 人工选 8 个 mode | 19 条源序列 | 规则 + 人工，非学习 |
| InteractionMesh retargeting | 21 个 MANO landmark + 源物体表面 anchors | Wuji 手 20-DoF 指关节 + 腕位姿的逐帧轨迹 | 全序列 T 帧优化 | 优化问题；跨物体迁移使用 Diff3F 深度特征匹配 |
| 全臂轨迹增广 | retarget 后的 hand–object 轨迹 | approach→grasp→transport→place→retreat 序列 | 每条源序列多 variant，IK 无解则丢弃 | 采样 + IK（Mink） |
| 指控策略（RL） | 542 维观测 | 20 维 residual 指关节目标（叠加在参考上） | 控制 30 Hz / 仿真 120 Hz；4096 并行环境 × 1500 iterations | MLP 4×1024，lr 2e-5 |
| 机械臂 | 预计算关节参考 | 7 关节 PD 目标 | 同上 | 经典控制，**不被策略修改** |
| 渲染 | 成功 rollout | 头视 + 腕视 RGB | 每个 timestep 一帧 | 3DGS 重建 + 增广 |
| VLA | 双视角图像 + 本体状态 + 抓取模式指令 | 27 维动作（7 臂 + 20 指） | 推理约 5 Hz，预测 50 步 chunk | LingBot-VLA 微调 55,000 steps，8×H20，batch 256，lr 5e-5 |

### 1.2 关键机制

- **按抓取组织，而不是按物体组织。** 8 个 grasp mode 各自带一句 GPT 生成的描述，25,270 条示范是 8 个 mode 的合计；同一 grasp mode 下的轨迹共用该 mode 的这句话。语言因此只承担“怎么抓”，不承担“抓什么”。
- **局部结构优先于点对点对齐。** 只用 landmark 匹配会丢掉手与物体之间的相对关系；用 Delaunay 四面体化建立固定邻域，再用 Laplacian 坐标匹配，等价于“要求在每一帧保持手–物邻域形状”。
- **臂在环是核心工程点。** 腕部跟踪误差会让手到达错误位置，进而错过接触。把 wrist-tracking error 显式放进观测（542 维里含“whole-arm dynamic context including wrist-tracking errors”），并让 R_obj 的容差随腕误差放宽。
- **成功过滤即数据闸门。** 只有满足任务与物理成功判据的 rollout 才进入渲染与 VLA 训练。

⚡ **Eureka Moment**：把人类交互看成“需要被保持的局部几何关系”，然后在**带机械臂跟踪误差的物理仿真**里重新解一次——参考不再是必须被复现的轨迹，而是被闭环修正的目标。

## 2. 数学核心

📌 **Napkin Formula**：

```
保持手–物邻域形状（Laplacian 匹配）→ 在含臂误差的物理里重新执行 → 只留成功轨迹
```

**目标**：把人类手–物序列 s 变成机器人可执行、可渲染、带语言的示范集合 D。

**(a) 抓取描述子（论文 Eq. 1）**

```
f = concat(a, x, g, h, d, s, e, c) ∈ R^170
a∈R^13（每指弯曲角之和 + 5 个指尖–掌距 + 3 个张开度统计）
x∈R^63（21 个 MANO 关节相对掌心的位置）
g∈R^3（掌心局部系下的世界上方向）
h∈R^21（手 landmark 相对物体表面采样点质心的竖直偏移）
d∈R^1（掌心到最近物体表面点的竖直偏移）
s∈R^63（21 个手关节指向最近物体表面点的向量）
e∈R^5（每指两侧是否都有物体表面，如穿过把手）
c∈R^1（接触点拟合平面法向与"接触中心→物体中心"连线的 cos²）
```

维度自检：13+63+3+21+1+63+5+1 = 170 ✅（与论文一致）

**(b) InteractionMesh 的 Laplacian 坐标（Eq. 2）与匹配损失（Eq. 3）**

```
δ_{t,i} = v_{t,i} − (1/|N(i)|) · Σ_{j∈N(i)} v_{t,j}

L_InterMesh = Σ_{t=1..T} [ Σ_{i∈V_H} ||δ^tgt_{t,i} − δ^src_{t,i}||²
                        + Σ_{i∈V_O} ||δ^tgt_{t,i} − δ^src_{t,i}||² ]
```

| 符号 | 含义 | 备注 |
|------|------|------|
| `N(i)` | 顶点 i 的固定邻域 | 由某个代表帧的 3D Delaunay 四面体化一次性确定，全序列共用 |
| `V_H` / `V_O` | 手顶点集 / 物体 anchors 集 | 两者都在同一物体局部坐标系下表达 |
| `δ^src` | 人类–源物体交互的 Laplacian 坐标 | 目标值 |
| `δ^tgt` | 机器人–目标物体交互的 Laplacian 坐标 | 由正运动学 + 优化变量决定 |

直觉：δ 是“我相对邻居偏了多少”。邻居同时包含手与物体顶点，所以物体顶点那一项也依赖手的位置——**手和物体被绑在同一个局部结构里**，不能各自单独对齐。优化变量是腕位姿 + 20-DoF 指关节，逐目标几何独立求解；此外还叠加了指尖接触约束、手–物与自穿透软惩罚、形态约束、时序平滑项。

**(c) 物理模仿的奖励（Eq. 4）**

```
R = 0.40·R_obj + 0.30·R_contact + 0.20·R_tip + 0.10·R_joint
    − 0.025·P_smooth − 0.01·P_act − 0.05·P_cross
```

| 项 | 作用 | 备注 |
|----|------|------|
| `R_obj` | 物体位姿跟踪 | 容差随腕跟踪误差放宽，避免把臂的误差算到手指头上 |
| `R_contact` | 参考交互中参与接触的手指确实建立接触 | |
| `R_tip` | 指尖在物体坐标系中的位置保持 | |
| `R_joint` | 跟踪参考指关节角 | |
| `P_smooth` / `P_act` / `P_cross` | 目标突变 / 过大残差 / 指尖–指尖碰撞 | 权重分别 0.025 / 0.01 / 0.05 |

## 3. 带数字走一遍：玩具例子

以下均为**假设数值**，用于验算公式形状，不代表论文实验。

**例 1：Laplacian 匹配（Eq. 2–3 的手顶点项）**
设手顶点 v1 的固定邻域只含两个物体 anchor，源帧：v1=(0,0,0)、v2=(1,0,0)、v3=(0,1,0)（长度单位任意）。
目标物体被放大 1.2×：v2'=(1.2,0,0)、v3'=(0,1.2,0)。

```
δ^src_1 = (0,0,0) − mean{(1,0,0),(0,1,0)} = (−0.5, −0.5, 0)
δ^tgt_1 = v1' − mean{(1.2,0,0),(0,1.2,0)} = v1' − (0.6, 0.6, 0)
```

- 若优化把 v1' 放在 (0,0,0)：δ^tgt=(−0.6,−0.6,0)，残差 = (−0.1,−0.1,0)，平方误差 = 0.02。
- 若把 v1' 放到 (0.1,0,0)：δ^tgt=(−0.5,−0.6,0)，残差 = (0,−0.1,0)，平方误差 = 0.01；零误差位置是 v1'=(0.1,0.1,0)。

验算：这是“物体变大时，手应当相应外移”的最小例子；两种摆放的平方误差分别为 0.02 与 0.01，差 0.01，对应残差范数约 0.1414 与 0.1 长度单位。这说明该损失对**尺度变化**敏感，而不是只对上式做点对点匹配。

**例 2：奖励加权（Eq. 4）**
设 R_obj=0.90、R_contact=0.80、R_tip=0.70、R_joint=0.95，P_smooth=2.0、P_act=1.5、P_cross=4.0。

```
正项 = 0.40×0.90 + 0.30×0.80 + 0.20×0.70 + 0.10×0.95
     = 0.360 + 0.240 + 0.140 + 0.095 = 0.835
罚项 = 0.025×2.0 + 0.01×1.5 + 0.05×4.0
     = 0.050 + 0.015 + 0.200 = 0.265
R    = 0.835 − 0.265 = 0.570
```

读法：在这组假设值下，单是 P_cross（0.200）就超过了整个 R_tip 的贡献（0.140）。也就是说，指尖互撞惩罚在数值上压过了“指尖位置保持”这一项——这是本笔记对权重配置的条件性观察，不是论文结论。

**例 3：数据规模自检**
Table I：6,596+2,559+2,475+2,481+3,452+2,680+2,442+2,585 = 25,270 ✅，源序列 5+2×7 = 19 ✅。
25,270 ÷ 19 = 1,330，即平均每条源序列贡献 1,330 条轨迹（本笔记算术）。

## 4. 工程视角

| 量 | 数值 | 属于什么 | 工程含义 |
|----|------|---------|---------|
| 仿真步频 | 120 Hz | IsaacLab 物理 | 接触求解足够细 |
| 策略控制 | 30 Hz | 指控策略动作频率 | 一个控制步 = 4 个物理步 |
| RL 采样 | 4,096 envs × 1,500 iterations | 每条源序列一个策略 | 19 条序列 = 19 次训练 |
| VLA 训练 | 55,000 steps，batch 256，8×H20 | 监督微调 | 单次训练任务 |
| VLA 推理 | 约 5 Hz | 部署节奏 | 见下方时序澄清 |
| Action chunk | 50 步 | **未来动作**长度 | 不是历史窗口 |
| RTC 执行 | 每 chunk 执行 30 步后切换 | 执行策略 | 20 步被丢弃 |

**时序必须分清**（这是本笔记的澄清，不是论文原文结论）：

```
若从当前参考 t 预测 t+1 … t+H，终点距 t 为 H·Δt（不是 (H+1)·Δt）
若均匀采样 K 帧作为一段观测，首末跨度为 (K−1)·Δt
```

- 论文的 50-step action chunk 属于“未来动作预测”，对应 H=50；它与“(K−1)Δt 的历史上下文”是两回事。
- **论文未说明 VLA 的观测历史窗口长度**，也未给出“记忆机制”；DexSeed 不是记忆架构，50 步 chunk 不应被解释成记忆窗口。
- 条件性推算：若动作步与约 5 Hz 的推理节奏对齐，则 50 步 ≈ 10 s 的未来动作，执行 30 步 ≈ 6 s，重叠 20 步 ≈ 40% 的 chunk 被丢弃。此推算依赖“动作步率 = 推理率”这一假设，论文未明确。
- 指控策略观测中的 “short-horizon future references” 是**未来参考帧**，同样不是已观测历史帧。

**成本结构**：数据量随“源序列 × 每序列增广 variant 数 × 成功率”增长，而训练成本随源序列数线性增长（一序列一策略）。若要把这套管线推到上百条源序列，瓶颈会从数据量转到策略训练与成功过滤的算力。

**精度/穿透 trade-off**：Table II 中本文 penetration 为 3.371 mm，高于 Wuji official 的 2.959 mm。论文只在 contact error 与 angular error 上声称优于三个基线，穿深并未声称最优——工程上若穿透敏感（薄壳、软物体），需要额外调整软惩罚权重。

8 模式均值 55%（本笔记算术：440/8）。论文对 G5 最低的解释是：handle-threading 对指尖–物体精确对齐要求更高。注意：**没有采集真实机器人动作示范**，真机只做部署评测。

## 6. 能力与失败模式

**能做**：单一语言指令在 8 种抓取模式间切换（同一物体上验证过 G1/G4 两模式）；跨兼容物体几何的重定向（0.75×/1.5× 圆环、不同杯子，仅定性 Fig. 3(b)）；桌面 pick-and-place 的整臂 + 手指协同；同一数据可换架构微调（π0 达 88.75/88.75/86.25/90.00）。

**不能做 / 未验证**：
- **in-hand 操作**：物体在手中改变接触的重定向，作者在 `§IV-F` 明确列为未来工作。
- **双臂与交接**：同样列为未来工作；本文全部是单臂。
- **跨本体**：只用了 Wuji 手 + Franka；不同指结构未测。
- **触觉**：数据里没有触觉观测；VLA 输入含图像与本体感知，作者将加入触觉以帮助检测滑移列为未来工作。
- **真机差距**：仿真 Seen 97.50% vs 真机均值 55%，论文未给 gap 分解。
- **过滤率未知**：25,270 条是通过物理成功判据筛出的，论文未报告候选总数与通过率（TODO：论文未给）。

### 6.1 隐含假设

1. **“抓取模式”是充分的语言粒度**：同一模式共用一句话，隐含“怎么说抓”比“抓什么”更决定手指构型。Table V 只在一个苹果、两个模式上支持这一点。
2. **物体几何“compatible”**：跨物体靠 Diff3F 特征匹配 + 相似变换（R, t, scale），默认源与目标存在可匹配的对应点；拓扑差异大的物体不在验证范围。
3. **单工作区视觉足够**：渲染场景是**一个**真实工作区的 3DGS 重建，靠光照/颜色/纹理/阴影/相机内外参扰动扩视觉多样性——真实世界外观分布覆盖仍是假设。
4. **臂参考不被修改**：臂只做 PD 跟踪预计算 IK 轨迹，策略无法调整臂；若参考本身不可达或碰撞，手指无法补救。
5. **一序列一策略可扩展**：19 条序列训 19 个策略，隐含该成本可随源数据线性放大。
6. **对比公平性**：Table III 中基线用浮动手训练，本文用臂闭环训练；论文对此明确说明，但读者不应把差距全部归因于方法本身。
