### 1.2 关键机制 (Key Mechanism)

**为什么这样设计？**

1. **联合建模而非解耦**：手构型决定可达接触点 → 接触几何约束容许力方向 → 力分布决定物理稳定性。三者互相约束，联合建模让单次前向传播输出几何一致且物理 grounded 的抓取。

2. **架构级物理保证**：传统方法用损失惩罚（如 `ReLU(‖f_t‖ − μ·f_n)`）软约束摩擦锥，但网络仍可能输出违规力。EquiDexFlow 在力解码器末尾插入**锥投影层**——分解为法向/切向分量后强制缩放，使输出**构造上**位于摩擦锥内。

3. **法向独立解码**：不依赖质心启发式估计法向（会缩小力闭可行域），而是用独立等变解码器预测每个接触点的内指法向，增大 wrench 平衡的可行空间。

⚡ **Eureka Moment**：把接触力分解到由网络自己预测的局部接触坐标系中，在局部坐标中做锥投影——这样力既是物理可行的，又保持端到端 SE(3) 等变（Proposition 1 + Theorem 1）。

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：

```
p_θ(T_w, q_h, C, N, Λ | P) = p_θ(T_w|P) · p_θ^q(q_h | z_O, T_w) · δ(C − g_C) · δ(N − η) · δ(Λ − Π_μ(f̃, N))
```

**目标**：从物体点云 P 学习一个联合分布，输出手腕位姿、关节角、接触点、法向和力坐标，满足 SE(3) 等变性和物理可行性。

**公式拆解**：

| 符号 | 含义 | 随机性 |
|------|------|--------|
| $T_w \in SE(3)$ | 手腕位姿 (旋转+平移) | 流采样 |
| $q_h \in \mathbb{R}^{16}$ | Allegro Hand 16 个关节角 | 流采样 |
| C ∈ R^(4×3) | 4 个指尖接触点 | 确定性 |
| N ∈ R^(4×3) | 4 个内指法向 | 确定性 |
| $\Lambda = \{\alpha_i\}$ | 局部力坐标 (在接触系中) | 确定性 |
| $\Pi_\mu$ | 摩擦锥投影 ($\mu=0.5$) | 确定性 |

**生成过程**（公式 5a-5e）：

```
T_0 ~ p_0 (均匀源分布)
T_w = Φ_θ^(1←0)(T_0; z_O)          // SE(3) 流匹配 ODE 积分
q_h ~ p_θ^q(·| z_O, T_w)           // Real-NVP 条件流
C = g_θ^C(z_O, T_w)                // 接触解码 + 表面投影
N = η_θ(z_O, C)                    // 法向解码
Λ = Π_μ(f̃_θ(z_O, C), N)           // 力解码 + 锥投影
```

**锥投影**（公式 7）——力的架构级摩擦锥合规：

```
f_n,i = softplus(f̃_i · n̂_i)                    // 法向分量（保证 ≥ 0）
f_t,i = f̃_i − (f̃_i · n̂_i) · n̂_i              // 切向分量
f̂_i = f_n,i · n̂_i + min(1, μ·f_n,i / ‖f_t,i‖) · f_t,i  // 缩放切向到锥内
```

**残差 wrench**（公式 10）——衡量力平衡质量：

```
r_w^O = G(Ĉ) · F̂ + w_ext
      = Σ_i [f̂_i; (ĉ_i − p_com) × f̂_i] + w_ext
```

> 符号与本文保持一致：$G$ 为抓取映射矩阵（$6 \times 3M$），将接触 Cartesian 力映射为物体坐标系残差 wrench；$w_{\text{ext}}$ 为外部 wrench（重力）。

## 3. 带数字走一遍：玩具例子 (Worked Example)

假设一个简化场景：2D 平面上的方块物体（边长 0.1m），两个指尖接触（M=2），摩擦系数 $\mu=0.5$。

**Step 1 — 网络输出原始力**：

```
假设力解码器对指尖 1 输出原始力 f̃_1 = [3N, −2N]（在接触系中）
假设法向 n̂_1 = [1, 0]（指向物体内部）
```

**Step 2 — 锥投影**：

```
f_n,1 = softplus(f̃_1 · n̂_1) = softplus(3) ≈ 3.05 N  （法向压力）
f_t,1 = f̃_1 − (f̃_1 · n̂_1) · n̂_1 = [3,−2] − 3·[1,0] = [0, −2]  （切向）
‖f_t,1‖ = 2.0 N
μ · f_n,1 = 0.5 × 3.05 = 1.525 N
‖f_t,1‖ > μ·f_n,1 → 需要缩放
缩放因子 = min(1, 1.525/2.0) = 0.762
f̂_1 = 3.05·[1,0] + 0.762·[0,−2] = [3.05, −1.525] N
验证：‖f̂_t,1‖ = 1.525 = μ·f_n,1 ✓ 恰好在锥边界上
```

**Step 3 — Wrench 平衡检查**：

```
假设接触点位置：ĉ_1 = [0.05, 0] m, ĉ_2 = [−0.05, 0] m
质心 p_com = [0, 0]
假设 f̂_2 = [3.05, +1.525] N（对称接触）

合力：Σ f̂_i = [6.1, 0] N（向上抵消重力）
合力矩：Σ (ĉ_i × f̂_i) = (0.05×0 − 0×3.05) + (−0.05×0 − 0×3.05) = 0

残差 wrench r_w = [6.1, 0, 0] + w_ext
若重力 w_ext = [−6.1, 0, 0] → r_w ≈ 0 ✓ 力平衡
```

**Step 4 — TTO 细化**：

```
初始流解码位姿可能让指尖偏离物体表面 2-3 cm
TTO 最小化：Σ ‖g_i(T_w, q_h) − Ĉ_i‖^2 + 0.05·ρ(偏离) + 50·穿透惩罚
200 步梯度下降后，运动学指尖位置收敛到解码接触点附近 < 1mm
```

### 6.1 隐含假设 (Hidden Assumptions)

1. **FRoGGeR 生成的数据分布覆盖真实可行域**：训练数据来自仿真优化器，但优化器本身的偏差（如偏好特定接触构型）会被网络学习并放大
2. **法向预测足够准确**：锥投影依赖网络预测的法向；若法向误差大，即使投影到"正确"锥内，实际物理摩擦锥可能不同
3. **静态重力环境**：w_ext 仅建模重力，未考虑加速度/惯性力；动态操作中力平衡假设失效
4. **点云质量**：512 点降采样假设物体表面足够光滑；对高曲率/细小特征的物体可能丢失关键接触信息
5. **开环执行足够**：硬件实验为开环 pick-and-hold，无触觉反馈或闭环调整；实际部署中扰动可能导致失败
