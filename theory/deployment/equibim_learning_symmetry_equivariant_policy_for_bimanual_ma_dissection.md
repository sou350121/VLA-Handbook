## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：

```
L_sym = ‖π(S(O)) - S(π(O))‖₂
```

**目标**：策略在对称变换下的输出应等于输出的对称变换。

**变量说明**：

| 符号 | 含义 | 维度/类型 |
|------|------|-----------|
| $\pi$   | 策略网络（任意架构） | $O \to A$   |
| O | 观测历史 | $\{O_{t-m+1}, \dots, O_t\}$ |
| $S(\cdot)$ | 对称变换（左右镜像） | 作用于观测和动作空间 |
| $\pi(O)$ | 原始观测的动作预测 | 动作序列 |
| $\pi(S(O))$ | 对称观测的动作预测 | 动作序列 |
| $S(\pi(O))$ | 原始预测的对称变换 | 动作序列 |
| L_sym | 对称一致性损失 | 标量 |

**直觉**：如果任务本身是左右对称的（如双臂装配），那么把场景左右翻转后，策略应该产生翻转后的相同行为。这个约束强制策略学习对称不变的任务表示。

**对称变换 S 的具体实现**：

```
图像观测：S(image) = 水平翻转

点云观测：S(p) = T_cam⁻¹ · R_y · T_cam · p
  其中 R_y = diag(1, -1, 1) 表示矢状面反射

末端执行器动作：在图像坐标系中应用相同反射

关节空间动作：S(q) = D · q
  其中 D 是根据 URDF 确定的关节对称符号对角矩阵
```

> 符号与本文/相关文档保持一致：$S$ 表示对称变换群作用，$\pi$ 表示策略，$O$ 表示观测，$A$ 表示动作。

## 3. 带数字走一遍：玩具例子 (Worked Example)

**场景**：双臂机器人执行"拿起左侧物体并传递到右侧"任务。

**训练样本**：
- 原始观测 O：摄像头看到物体在左侧（x = -0.2m），左臂在 home 位置，右臂在 home 位置
- 专家动作 a_expert：左臂移动到物体（x = -0.2m），抓取，右臂移动到中间（x = 0m），交接

**对称变换应用**：
1. $S(O)$：水平翻转图像 → 物体看起来在右侧（$x = +0.2\,\text{m}$）
2. $S(a_\text{expert})$：交换左右臂角色 → 右臂移动到物体（$x = +0.2\,\text{m}$），左臂移动到中间

**训练过程**：
```
前向 pass 1: π(O) → 预测动作 a1
前向 pass 2: π(S(O)) → 预测动作 a2

计算对称损失:
  L_sym = ‖a2 - S(a1)‖²
  
总损失:
  L_total = L_BC(π(O), a_expert) + L_BC(π(S(O)), S(a_expert)) + λ·L_sym
```

**效果**：如果策略学到对称性，那么当它在测试时遇到镜像配置（物体在右侧而非左侧），它会自动产生镜像行为，而无需额外训练数据。

## 4. 工程视角 (Engineering View)

**计算开销**：
- 训练时：2 倍前向 pass（O 和 S(O)），但可批量化处理
- 推理时：0 额外开销（单路前向）
- 内存：需存储变换后的观测和动作，约增加 20% 临时 buffer

**部署约束**：
- 需要准确定义对称变换 S（依赖相机外参和机器人 URDF）
- 对称轴必须与任务对称轴对齐（论文假设图像水平轴对应机器人左右方向）
- 对于非对称任务（如异质双臂），需谨慎应用或关闭正则化

**超参数建议**（来自论文）：
- $\lambda_\text{sym}$（对称损失权重）：需要调参，过大可能压制任务特定学习
- 数据增强：可结合对称变换作为数据增强手段

**量化/抖动考虑**：
- 对称变换涉及浮点运算（旋转矩阵），需注意数值精度
- 关节空间符号映射 D 矩阵需从 URDF 精确推导

## 6. 能力与失败模式 (Capabilities & Failure Modes)

**能做什么**：
- ✅ 提升对称双臂任务的成功率和鲁棒性
- ✅ 在分布偏移（镜像配置、演示质量不均、随机初始化）下保持性能
- ✅ 与任意策略骨干网络配合（Diffusion Policy, DP3, ACT）
- ✅ 支持多种观测模态（图像/点云）和动作空间（关节/末端）

**不能做什么**：
- ❌ 对功能不对称任务可能产生负增益（如 Handover Block 在模拟中下降）
- ❌ 无法处理非对称机器人构型（如异质双臂、单臂 + 夹具）
- ❌ 对称变换定义错误会导致训练不稳定

### 6.1 隐含假设 (Hidden Assumptions)

**X-Ray 批判视角**：

1. **相机居中假设**：假设摄像头安装在机器人中心正前方，图像水平轴与机器人左右方向对齐。偏离此配置需重新定义 S。

2. **任务对称性假设**：假设任务本身是左右对称的。但许多实际双臂任务存在功能不对称（如一手持工具一手持工件）。

3. **动作绝对参数化**：假设动作是绝对位姿/关节角，而非相对增量。相对动作的对称变换定义更复杂。

4. **演示数据对称覆盖**：假设训练数据包含足够的左右对称样本。如果数据严重偏向一侧，对称正则化可能无法充分学习。
