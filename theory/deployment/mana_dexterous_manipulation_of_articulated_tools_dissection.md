💡 **X-Ray 开场**

铰接工具（剪刀、钳子、镊子）是人类日常中最常见的工具类型，但机器人要像人一样灵巧地操作它们却极其困难——不仅需要稳定抓取，还需要在手指与工具持续接触的同时精确控制力的大小和方向。Mana 的核心发现是：与其让 RL 从头探索，不如借鉴计算机动画的思路——先由人标注工具的功能区域（<1 分钟），自动生成关键帧，再用运动规划连接几何可达段、用 RL 只处理接触丰富的短片段。这种"粗到细"的数据生成管线让扩散策略在 4 类工具上实现了 ~70% 的零样本 sim-to-real 成功率，而遥操作基线仅 ~30%。

### 1.2 关键机制 (Key Mechanism)

**为什么这样设计？** 铰接工具操作的核心难点在于：

1. **双目标冲突**：稳定抓取需要沿表面法线施力，但功能操作需要沿切线方向施力——两者往往不一致
2. **紧耦合动力学**：手指 + 工具构成一个紧密耦合系统，一个关节的微小误差会改变接触位置、力臂，进而 destabilize 整个交互
3. **遥操作不足**：现有位置式遥操作无法生成足够精确/足够大的接触力（3-7N），尤其对 ~1cm 厚的细小工具

**Mana 的解决方案**：将长视距操作分解为"关键帧骨架 + 短片段过渡"。关键帧由程序化生成（覆盖功能区域的密集采样），短片段中几何可达的用运动规划（MP），接触丰富的用 RL。这样 RL 只需学习短视距、高接触密度的局部行为，避免了端到端 RL 的探索灾难。

⚡ **Eureka Moment**：铰接工具操作不是"从头学一个长任务"的问题——它是"动画关键帧 + inbetweening"的问题。把操作分解为关键帧（人标注功能区域 $\to$ 程序化生成）+ 短片段过渡（MP 处理几何、RL 处理接触），就同时解决了探索难和数据少的两个瓶颈。

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：

```
L = E_(o,a)~D, t~U[0,T] [ || a - π(a_tilde, o, t) ||^2 ]
    └── 标准扩散去噪目标 ───┘
    数据 D 来自 Mana 管线（非人类演示）
```

**目标**：训练一个从视觉观测到动作的扩散策略，使其在真机上能复现 Mana 生成的仿真轨迹。

**公式分解**：

| 符号 | 含义 |
|------|------|
| `o_i` | 第 i 步观测 = 腕系工具点云 + 机器人本体感知 |
| `a_i` | 第 $i$ 步动作 $= \Delta 6\text{D}$ 腕位姿 $+ \Delta 16\text{D}$ 手指关节 |
| `a_tilde` | 加噪后的动作样本 |
| `t` | 扩散时间步，均匀采样自 `[0, T]` |
| `π` | Perceiver + Transformer Diffusion 策略网络 |
| `D` | Mana 生成的成功轨迹数据集（纯仿真） |

**直觉**：策略学习的是"从 noisy action 到 clean action"的映射，条件是当前观测。训练数据完全来自仿真——点云随机化（噪声扰动 + 随机遮挡）提升 sim-to-real 鲁棒性。

**RL 奖励函数**（用于 in-hand actuation 阶段）：

```
r = r_tool + w1·r_hand + w2·r_contact
```

| 项 | 作用 |
|----|------|
| `r_tool` | 鼓励工具达到目标构型和位姿 |
| `r_hand` | 鼓励手姿态匹配 |
| `r_contact` | 鼓励接触点数量和接触稳定性 |

> 符号与本文保持一致。具体权重值和随机化细节见论文 Appendix A.2（正文未展开）。

## 3. 带数字走一遍：玩具例子 (Worked Example)

以**注射器（syringe）**推注操作为例，走一遍 Mana 管线：

**Step 1 — 人标注**：在注射器 3D 网格上点选两个区域——柱塞（plunger）和筒身（barrel）。耗时 <1 分钟。

**Step 2 — 关键帧生成**：Grasp Generator 在柱塞表面采样 $20$ 个接触域，每个域生成 $5$ 个 IK 解 $\to 100$ 个抓取关键帧。过滤掉 IsaacLab 中不稳定的 $\to$ 剩余 $\sim 60$ 个。

**Step 3 — 预抓取（MP）**：RRT-Connect 从 $100$ 个随机初始手姿规划到预抓取位姿（指尖沿表面法线外偏 $2\text{--}8\,\text{mm}$ 随机距离）$\to$ 成功 $\sim 45$ 条轨迹。

**Step 4 — 抓取（MP$\to$RL fallback）**：几何挤压策略对 $30/45$ 条有效；剩余 $15$ 条用短程 RL 训练（$2000$ 步环境交互）$\to$ 成功抓取 $12$ 条。

**Step 5 — 推注（RL）**：从 60 个抓取关键帧出发，目标为柱塞下压 15mm。RL 训练 50K 步，奖励权重 `w1=0.5, w2=1.0`。成功轨迹 ~35 条，包含 3-7N 的推力。

**Step 6 — 策略训练**：总计 $\sim 92$ 条成功轨迹 $\to$ 采样 $50\text{K}$ 个 $(o, a)$ 对 $\to$ 训练扩散策略 $100\text{K}$ 步。

**Step 7 — 真机部署**：零样本迁移。10 次试验中 7 次成功完成"抓取→推注"全流程（手腕对齐阶段由遥操作辅助）。

## 4. 工程视角 (Engineering View)

| 维度 | 数值/约束 | 工程含义 |
|------|-----------|----------|
| **推理频率** | ~10 Hz | 受限于 SAM3 + FFS 立体匹配的感知管线；控制回路可接受，但滑移检测不够快 |
| **计算资源** | 2× RTX 4090 | Perceiver 编码 + Diffusion 推理并行；GPU 预算高，不适合边缘部署 |
| **操作力范围** | 3-7 N | Allegro 手最大扭矩 0.7Nm；>10N 场景（如扳机机构）无法处理 |
| **物体厚度** | 0.8-1.5 cm | 定制硅胶扁平指尖是关键——标准半球形指尖会产生不稳定点接触 |
| **数据生成速度** | <1 min/tool 标注 + GPU 并行生成 | 标注成本极低，但 RL 训练仍需 50K-100K 步/阶段 |
| **指尖设计** | 扁平硅胶接触面 | 被动变形补偿位姿误差，分散法向力——硬件设计对成功率影响巨大 |
| **控制架构** | 腕部 DIK + 手指 PD ($\tau = K_p \cdot e + K_d \cdot \dot{e}$) | 分层控制解耦腕部运动学和手指力控，但 PD 增益需调参 |

**关键 trade-off**：扩散策略提供了多模态动作分布（适合接触丰富的不确定性场景），但 10Hz 的推理频率意味着高频滑移检测（>100Hz）不可行——这是纯视觉方案的固有局限。

## 6. 能力与失败模式 (Capabilities & Failure Modes)

**能做什么**：
- 从零采样抓取桌面细小铰接工具（~1cm 厚）
- 执行开/关/挤压等单阶段操作（3-7N 力范围）
- 零样本 sim-to-real 迁移（无真机微调）
- 跨 4 类不同尺度/关节类型的工具泛化

**不能做什么**：
- >10N 操作力场景（如扳机、强力弹簧）— 硬件扭矩不足
- 遮挡下的滑移检测 — 无触觉/力觉传感，10Hz 视觉不够快
- 全自动技能链 — 工具到目标的精对齐（如 0.5mm 细线）依赖手腕遥操作
- Power grasp 策略 — Allegro 手是成人手的 2 倍大，细小把手不适合力抓取
- 非桌面场景（悬挂/浮动工具）— 仅评估桌面初始化

### 6.1 隐含假设 (Hidden Assumptions)

1. **工具网格 + URDF 可用**：Mana 需要工具的 3D 网格和关节模型作为输入。对于未知工具，需要额外的扫描/建模步骤——这在实际部署中可能成为瓶颈。
2. **功能区域可程序化标注**：当前需要人点选功能区域（<1 min）。作者声称可用 affordance 模型自动化，但未验证——如果自动标注误差 >5mm，关键帧质量会显著下降。
3. **仿真接触物理足够准确**：论文承认"更好的力和接触物理建模可以解决部分问题"。当前仿真中的接触摩擦模型可能与真机存在差距，这是 sim-to-real 的固有风险。
4. **单阶段操作可组合**：多阶段技能链（抓取→操作→放置→二次操作）需要额外的策略和衔接逻辑，本文仅用遥操作 bridging 验证了可行性。
5. **视觉分割在遮挡下仍可靠**：SAM3 在手指遮挡工具时可能失效，但论文未分析遮挡场景下的感知退化。
