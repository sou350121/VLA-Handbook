## 1. 核心架构/方法总览 (Overview / Architecture)

### 1.1 系统对比概览 (System Component Comparison)

|------|------|------|-----------|---------------|

| TAMP 重规划 | 新停靠点 + 技能段端点 | 新运动段轨迹 | 每条增强轨迹 (离线) | 仅训练时用 |

| 策略头 (DP3) | 点云 + 本体状态 | 末端执行器位姿 + 夹爪命令 | 每控制步 (在线) | 训练/推理一致 |

### 1.2 关键机制 (Key Mechanism)

**轨迹分解逻辑**：
- 计算末端执行器与目标物体几何中心的距离
- 距离 < 阈值 (0.1m) → 技能段 (接触丰富，需保持相对几何)
- 距离 ≥ 阈值 → 运动段 (自由空间运动，可重规划)

**停靠点可行性约束**（采样后验证）：
1. **可见性**：目标物体点在新视角下仍可见
2. **可达性**：目标在新基座位置的工作空间内
3. **无碰撞**：运动段可重规划为无碰撞轨迹

**3D 点云编辑**：
- 用 Grounded SAM 分割机器人/物体点云
- 对机器人点云应用与轨迹相同的空间变换
- 对物体点云：运动段不变，技能段跟随机器人变换（保持相对几何）

⚡ **Eureka Moment**：**将"视角泛化问题"转化为"几何停靠点泛化问题"**——通过固定第三人称视角，视角变化被简化为机器人基座位姿变化，再用 TAMP 保证运动段的可执行性，技能段完全复用。

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：
```
π_{p'} 通过行为克隆学习：min_π BC(π; D̂_{p'})，其中 D̂_{p'} 由 DockAnywhere 从 D_p 生成
```

**问题形式化**：

目标：学习一个策略 π_{p'}，能在未见过的停靠点 p' 预测可行动作：
```
a'_t ∼ π_{p'}(· | o'_t, a'_{t-1})
```

行为克隆损失：
```
min_{π_{p'}} L_BC(π_{p'}; D̂_{p'}) = -1/|D̂_{p'}| Σ_{(o'_t, a'_t)∈D̂_{p'}} log π_{p'}(a'_t | o'_t, a'_{t-1})
```

**关键变换公式**：

夹爪命令（不变）：
```
â_t^{cmd} = a_t^{cmd},  t ∈ [0, L)
```

技能段手臂位姿（复用）：
```
â_t^{pose} = a_t^{pose},  t ∈ τ_k^s
```

运动段手臂位姿（重规划）：
```
â_t^{pose} = Replan(â_{t_{end,k-1}}^{pose}, â_{t_{start,k}}^{pose}),  t ∈ τ_k^m
```

点云空间变换：
```
ΔT_t = (a_t^{pose})^{-1} · â_t^{pose}
ô_t^{pc,arm} = o_t^{pc,arm} · ΔT_t
```

最终合成点云：
```
ô_t^{pc} = [ô_t^{pc,arm}, ô_t^{pc,obj}]
```

> 符号说明：上标 pc=点云，pose=位姿，cmd=夹爪命令；τ^m=运动段，τ^s=技能段；ΔT=相对刚体变换

**直觉**：核心思想是"不变性分离"——夹爪命令和接触丰富的技能段在不同停靠点下保持不变（相对物体几何），只有自由空间运动需要适应新位置。

## 3. 带数字走一遍：玩具例子 (Worked Example)

**任务**：Pick-up Banana（抓取香蕉）

**源演示** @ 停靠点 p（距离物体 0.6m，正对）：
- 轨迹长度：L = 150 帧
- 解析结果：
  - τ₁ᵐ（运动段）：帧 0-80，末端从初始位置移动到香蕉上方 10cm
  - $\tau_1^s$（技能段）：帧 81-150，下降→闭合夹爪→抬起  

**新停靠点 p'**（距离物体 0.5m，右移 15cm）：

**步骤 1：验证可行性**
- 可见性 ✓（香蕉在相机视野内）
- 可达性 ✓（香蕉在工作空间内）
- 碰撞检测 ✓（运动段可重规划）

**步骤 2：动作生成**
- 夹爪命令：直接复用 150 帧的开/闭信号
- 技能段（帧 81-150）：位姿命令整体复用（相对香蕉的几何不变）
- 运动段（帧 0-80）：从新起点（p' 的初始位姿）重规划到技能段起点（香蕉上方 10cm，但坐标变换到 p' 系）

**步骤 3：点云合成**
- 计算机器人点云的变换矩阵 $\Delta T$（从 $p$ 到 $p'$ 的相对位姿）  
- 机器人点云：每帧应用 $\Delta T$  
- 香蕉点云：
  - 帧 0-80（运动段）：不变（机器人未接触）
  - 帧 81-150（技能段）：应用相同 $\Delta T$（保持与机器人的相对位置）  

**结果**：生成一条在 $p'$ 处物理一致的演示，用于训练策略 $\pi_{p'}$。

- **必须第三人称相机**：方法依赖固定视角，若只有机载相机需重新投影（论文提到可行但未验证）
- **需要 RGBD 相机**：点云获取依赖深度信息
- **分割模型依赖**：Grounded SAM 的分割质量影响点云编辑精度

**Trade-off**：
- 增强停靠点数量：4 个最佳（61.9% SR），6 个仅提升 2% 但计算成本增加 50%
- 空间范围：1.0 倍源距离最佳（87.2% SR），2.0 倍时降至 46.3%（过大扰动）

## 6. 能力与失败模式 (Capabilities & Failure Modes)

### 能做什么
- **跨停靠点泛化**：在训练未见过的停靠点仍保持 60%+ 成功率（仿真）
- **处理 SE(3) 变换**：支持平移 + 旋转的停靠点变化（DemoGen 仅支持近似平行变换）
- **复杂交互任务**：开柜门/抽屉等需要精确位姿的任务（60% SR，显著优于 DemoGen 的 48-52%）
- **低成本增强**：单条轨迹 0.02 秒，适合大规模数据生成

### 不能做什么
- **完全 egocentric 视角**：方法依赖固定第三人称相机，纯机载相机场景需额外验证
- **柔性物体操作**：点云编辑假设刚体变换，柔性物体（如布料、线缆）的形变未建模
- **超远距离泛化**：2.0 倍源距离时性能降至 46.3%，不适合极端位置偏移
- **动态场景**：假设场景静态，移动物体/人的场景未验证

### 6.1 隐含假设 (Hidden Assumptions)

1. **第三人称视角可用**：假设机器人工作区域有固定相机（如厨房天花板相机），但很多移动场景（仓库、户外）只有机载传感器
2. **物体刚性**：点云编辑假设物体是刚体，柔性物体或可变形容器的操作未考虑
3. **单次接触**：轨迹解析基于"接近→接触"的单次模式，多阶段接触（如先推后抓）可能解析错误
4. **分割可靠性**：依赖 Grounded SAM 的分割质量，遮挡/反光/透明物体可能分割失败
5. **导航误差范围有限**：实验验证的停靠点偏移在 0.4-0.8m 范围，更大偏移（如>1m）未测试
