## 1. 核心架构/方法总览 (Overview / Architecture)

### 1.1 系统对比概览 (System Component Comparison)

| 组件 | 传统特征拼接 | 本文策略共识 |
|------|-------------|-------------|
| 融合层级 | 特征层（encoder 后） | 策略层（score 输出后） |

| 稀疏信号 | 易被主导模态淹没 | 独立保留，权重保障 |
| 参数量 | 基准 | +0.7M（+0.3%） |

### 1.2 关键机制 (Key Mechanism)

**两层分解架构**：

1. **模态内组合（Intra-Modality）**：每个模态 i 有 Ki=2 个子策略（如视觉的 geometry vs fine detail，触觉的 contact onset vs sustained force），取平均得模态专属 score
2. **模态间组合（Inter-Modality）**：路由器 Rψ 读取各模态 embedding，输出共识权重 {wi}（softmax 归一化），加权组合各模态 score

⚡ **Eureka Moment**：**策略级组合而非特征级拼接**——每个模态的专家独立训练、独立保留其 behavioral constraints，路由器只在最后一步做加权共识。这保证了即使触觉只在 10% 时间关键，它的专家网络也不会被视觉信号"训练废掉"。

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：

```
p(a|s_t) ∝ ∏_i [p_i(a|m_i,t)]^{w_i}  →  ε_comp = Σ_i w_i · ε_i,comp
```

**推导链路**：

1. **能量函数视角**：每个子策略定义能量 `p_i,j(a|m_i,t) ∝ exp(-E_θ_i,j(a, m_i,t))`
2. **分布乘积 = 能量求和**：组合策略对应 `exp(-Σ_i w_i Σ_j E_θ_i,j)`
3. **扩散模型等价**：扩散 score 是能量的梯度，组合对应 score 加权求和

**变量说明**：

| 符号 | 含义 | 维度/范围 |
|------|------|----------|
| m_i,t | 模态 i 在时刻 t 的原始输入 | 如 RGB: 96×128×3, Tactile: 12×32×2 |
| e_i,t | 模态 embedding（含机器人状态） | 任务相关 |
| ε_θ_i,j | 子策略的 diffusion score 预测 | 与动作空间同维 |
| w_i | 路由器输出的共识权重 | [0,1], Σw_i = 1 |
| K_i | 每模态子策略数量 | 实验中 K_i = 2 |

> 符号与本文/相关文档保持一致：ε 表示 diffusion score（噪声预测），w 表示路由器权重

**直觉解释**：传统拼接是"把所有模态扔进一个大网络，让它自己学怎么融合"——但统计上 dominant 的模态（如视觉）会主导梯度更新。本文是"每个模态先学好自己的专长，最后用可解释的权重投票决定听谁的"——稀疏但关键的触觉专家不会被视觉专家"训练废"。

## 3. 带数字走一遍：玩具例子 (Worked Example)

**场景**：遮挡标记物抓取任务（Occluded Marker Picking）

**任务阶段**：
- t=0~5 步：机械臂从初始位置移动到容器上方（视觉主导）
- t=6~15 步：机械臂进入容器内部，视觉被遮挡（触觉主导）

**假设数值**（简化 2D 动作空间：x, z 方向）：

| 时刻 | 模态 | 专家 score 预测 ε_i,comp | 路由器权重 w_i | 贡献 w_i·ε_i |
|------|------|-------------------------|---------------|-------------|
| t=2 | 视觉 | [-0.3, -0.8]（向下向前） | w_rgb = 0.85 | [-0.255, -0.68] |
| t=2 | 触觉 | [0.0, 0.0]（无接触） | w_tac = 0.15 | [0.0, 0.0] |
| **组合** | | **ε_comp = [-0.255, -0.68]** | | |
| t=8 | 视觉 | [-0.1, -0.2]（不确定） | w_rgb = 0.45 | [-0.045, -0.09] |
| t=8 | 触觉 | [-0.6, -0.3]（检测到接触） | w_tac = 0.55 | [-0.33, -0.165] |
| **组合** | | **ε_comp = [-0.375, -0.255]** | | |

**关键观察**：
- t=2 时视觉权重 85%，触觉几乎无贡献（符合"视觉主导接近阶段"）
- t=8 时触觉权重升至 55%，超过视觉（符合"接触后触觉关键"）
- 组合 score 是加权平均，保证两模态都有贡献

## 4. 工程视角 (Engineering View)

**部署约束与 trade-off**：

| 维度 | 本文方法 | 传统拼接 | 工程含义 |
|------|---------|---------|---------|
| 训练复杂度 | 需独立训练 N 个模态专家 | 单次训练 | 前期多 N 倍时间，但新增模态无需重训 |
| 推理延迟 | 并行跑 N 个专家 + 路由器 | 单次前向 | 延迟增加约 15-20%（论文未明确给出） |
| 内存占用 | N 个专家网络 | 单一大网络 | 总参数 +0.7M（+0.3%），几乎持平 |
| 传感器故障 | 权重自动调整，优雅降级 | 可能完全失效 | 遮挡单相机仍可运行 |
| 增量学习 | 训练新专家 + 固定权重组合 | 完整重训练 | 新增触觉传感器可节省数天 compute |

**关键工程决策点**：
- K_i = 2（每模态 2 个子专家）是经验值——更多子专家可能捕捉更细粒度行为模式，但训练成本线性增长
- 路由器权重在训练后固定——推理时无法动态调整，这是设计取舍（简化部署 vs 运行时适应性）
- 扩散步数未明确给出——参考 Diffusion Policy 通常为 100 步，实际延迟需实测

## 6. 能力与失败模式 (Capabilities & Failure Modes)

**能做什么**：
- ✅ 接触丰富操作（遮挡抓取、拼图插入）——触觉在关键阶段主导
- ✅ 传感器故障鲁棒性——遮挡单相机仍可运行（Figure 6）
- ✅ 物理扰动恢复——执行中标记物被抢走后可重新规划（Figure 6a）
- ✅ 增量组合——预训练 RGB 策略 + 触觉策略用固定权重 (0.5, 0.5) 组合即可成功抓取（Figure 7）

**不能做什么**：
- ❌ 极端传感器腐蚀——论文承认"Occasional failures under extreme sensor corruptions"
- ❌ 细粒度时序权重调整——路由器权重训练后固定，无法在推理时按 timestep 动态调整
- ❌ 跨模态缺失泛化——未测试三模态以上（如 + 音频 + 力觉）场景

### 6.1 隐含假设 (Hidden Assumptions)

- **假设 1**：各模态专家独立训练时能学到有意义的 behavioral constraints——如果某模态本身信息量不足（如低分辨率触觉），独立训练可能失败
- **假设 2**：路由器能从 embedding 预测合适的共识权重——如果训练数据中某模态组合未见，外推能力未知
- **假设 3**：K_i = 2 足够捕捉模态内行为多样性——对更复杂任务可能不足
- **假设 4**：扩散模型作为基础策略——对非扩散策略（如 ACT、Transformer）的兼容性未验证
