### 1.2 关键机制 (Key Mechanism)

ETac 的核心是一个**两阶段变形传播模型**：

1. **阶段一：基于指数衰减的线性传播** — 用解析公式建模接触位移随距离的指数衰减，提供物理先验的平滑预测
2. **阶段二：残差修正网络** — 用轻量 PointNet 编码器 + MLP 解码器学习线性模型无法捕捉的非线性效应（曲率、各向异性、主动节点间的相互影响）

两阶段互补：线性部分保证外推泛化性，神经网络部分吸收复杂非线性残差。

⚡ **Eureka Moment**：不试图用一个纯神经网络或纯解析模型去拟合 FEM——而是让解析模型负责"已知的物理规律"（距离衰减），让神经网络只学"解析模型学不会的部分"（曲率、各向异性、主动节点互扰），从而用极小的网络实现极高的精度。

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：
```
U_p = exp(-α·||p_j - p_i||) · U_a  +  Φ_p(P, U_hat, N)
    └── 线性衰减传播 ──┘     └── 非线性残差修正 ──┘
```

**目标**：用轻量模型逼近 FEM 仿真中被动节点（非直接接触物体）的位移场。

**核心方程**：

```
被动节点位移:  U_p = Ω · U_a + Φ_p(P, U_hat, N)

传播矩阵:     Ω[i,j] = exp(-α · ||p_j - p_i||_2)

训练损失:     Loss = min_{α, Φ_p} ||U_p - U_p*||_2
```

**变量说明**：

| 符号 | 含义 | 维度 |
|------|------|------|
| U_p | 被动节点位移（待预测） | $(n-m) \times 3$ |
| U_a | 主动节点位移（接触节点） | $m \times 3$ |
| P | 节点原始位置 | $n \times 3$ |
| N | 节点法向量 | $n \times 3$ |
| U_hat | 全节点位移（被动节点补零） | $n \times 3$ |
| $\alpha$ | 材料衰减参数（可学习） | scalar |
| $\Phi_p$ | 残差网络（仅输出被动节点） | $(n-m) \times 3$ |
| U_p* | FEM 仿真的被动节点位移（ground truth） | $(n-m) \times 3$ |

> 符号与本文保持一致。U_p* 来自 FEM 仿真 oracle，作为训练标签。

**直觉**：线性衰减部分建模"离接触点越远，变形越小"这一物理直觉；残差网络吸收曲率效应和各向异性等解析模型难以显式建模的因素。两者相加，既快又准。

## 3. 带数字走一遍：玩具例子 (Worked Example)

假设一个简化场景：

- 触觉传感器表面离散化为 n = 100 个节点
- 其中 m = 5 个节点与物体直接接触（主动节点）
- 剩余 n - m = 95 个被动节点需要预测位移

**步骤 1：主动节点位移**

假设主动节点 p_j 的位移 U_a[j] = [0.002, 0.001, -0.005]（单位：m，即 z 方向压入 5mm）

**步骤 2：线性衰减传播**

对某个被动节点 p_i，与最近主动节点距离 ||p_j - p_i|| = 0.02m，α = 50（学习得到）：

```
Ω[i,j] = exp(-50 × 0.02) = exp(-1.0) ≈ 0.368
传播位移 = 0.368 × [-0.005] = -0.00184 m (z 方向)
```

对更远的被动节点（距离 0.04m）：

```
Ω[i,j] = exp(-50 × 0.04) = exp(-2.0) ≈ 0.135
传播位移 = 0.135 × [-0.005] = -0.000675 m
```

**步骤 3：残差修正**

PointNet 编码器读取 P, U_hat, N 的全局特征（64D），MLP 解码器输出每个被动节点的残差修正。假设对 p_i 的残差为 +0.0003m（因为曲率效应使实际变形略大于线性预测）。

**步骤 4：最终位移**

```
U_p[i] = -0.00184 + 0.0003 = -0.00154 m
```

**与 FEM oracle 对比**：假设 FEM 给出 U_p*[i] = -0.00158m，则单点误差仅 0.00004m = 0.04mm，远低于 TacSL 的 0.194mm 平均 RMSE。

### 不能做什么 / 失败模式

| 失败模式 | 原因 | 影响 |
|----------|------|------|
| 未见材料属性的泛化 | 传播模型针对特定 Young's modulus / Poisson ratio 训练 | 换材料需重新训练 |
| 大变形/撕裂场景 | 训练数据覆盖 0-4mm 压入深度 | 超出范围可能失效 |
| 高频动态接触 | 粒子级模型可能无法捕捉高频波动 | 对快速敲击等场景精度待验证 |
| 自接触复杂拓扑 | SDF 自碰撞检测可能不稳定 | 多指交互时可能出问题 |

### 6.1 隐含假设 (Hidden Assumptions)

1. **FEM 仿真 = 真实物理** — 传播模型用 FEM 数据训练，隐含假设 FEM 本身是准确的。但 FEM 的参数（Young's modulus, Poisson ratio）是否匹配真实材料未充分讨论
2. **材料属性不变** — $\alpha$ 和 $\Phi$ 针对特定材料训练，假设同一批次传感器的材料属性一致
3. **接触是准静态的** — 训练数据来自缓慢压入实验，未验证动态冲击场景
4. **节点离散化密度足够** — 1000 节点/全手是否足以捕捉高频变形模式未验证
