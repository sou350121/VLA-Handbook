### 1.2 关键机制 (Key Mechanism)

**为什么用 violation-implicit loss？** 传统方法将物理约束作为硬约束（xt+1 = fθ(xt, rt, λt)），导致损失景观在接触边界处几乎不连续——梯度要么接近 0 要么接近无穷大。本文把约束"软化"为损失项，允许优化器在轻微违反物理的情况下找到更平滑的梯度路径。

**为什么用 EIG 而非 Mutual Information？** MI 需要维护完整的信念分布 p(ω\|𝒟)，对于动态物体这会导致多模态分布且参数数量指数增长。EIG 只需要点估计（MLE）和 Fisher 信息矩阵，计算代价低一个数量级。

⚡ **Eureka Moment**：**把物理约束从"硬边界"变成"软惩罚"**——violation-implicit loss 让优化器可以在"轻微穿透"的假设下计算梯度，避免了接触动力学的数值病态，同时通过内层 QP 保证最终解的物理合理性。

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：

```
EIG ∝ log det(ℱ(𝒟_acq) · ℐ(𝒟_obs)^{-1} + I)
```

**目标**：选择下一个动作 r_T...H 使得 Expected Information Gain 最大化，从而用最少的接触次数学会物体的形状和位置。

**公式拆解**：

```
核心方程：
  ℒ_v(θ, xt, 𝒟) = Σ_t min_{λ_t} [ ℒ_t + ||xt+1 - fθ(xt, λt, rt)||² + gθ(xt, λt, rt) ]
  
  其中：
  - ℒ_t = (ct/2)·||n̂_t,m - n̂_t||²_{Σ^{-1}} + [(ct-1)·α·φ_t + log(1 + e^{α·φ_t})]
  - gθ 包含：互补性、最大功耗散、非穿透、非弹性碰撞
  - λ_t ∈ FC (摩擦锥约束)
  
EIG 计算：
  ℐ(𝒟_obs) ≈ Σ_t [ α²·(∇φ_t · (e^{α·φ_t}/(1+e^{α·φ_t})²) · ∇φ_t^T) + ct·∇n̂_t·Σ_n^{-1}·∇n̂_t^T ]
  
  ℱ(𝒟_acq) = E_{ct,n̂}[ ∇²_{ω} Σ_{t=T}^{H} ℒ_t ]  (与 ℐ 形式相同，但是对未来数据的期望)
  
  EIG = H[ω|𝒟_obs] - H[ω|𝒟_obs ∪ 𝒟_acq] ∝ log det(ℱ·ℐ^{-1} + I)
```

**变量说明**：

| 符号 | 含义 | 维度 |
|------|------|------|
| θ | 物体几何参数（立方体边长或凸包顶点） | 3 或 3×nv |
| xT | 物体在当前时刻的 SE(3) 姿态 | 7 (四元数 + 位移) |
| rt | 机器人末端执行器位置 | 3 |
| ct | 接触布尔 (0/1) | 1 |
| n̂_t,m | 测量的接触法向 | 3 |
| φ_t | signed distance (机器人 - 物体) | 1 |
| λ_t | 接触 impulse (法向 + 摩擦) | 3 |
| ℐ | Observed Information (Hessian of NLL) | (dim ω)² |
| ℱ | Fisher Information (期望的 ℐ) | (dim ω)² |

**直觉解释**：
- ℐ(𝒟_obs) 衡量"当前已经知道了多少"——值越大表示参数估计越确定
- ℱ(𝒟_acq) 衡量"这个动作预计能知道多少"
- EIG 本质上是 ℱ 相对于 ℐ 的"边际增益"——优先探索那些当前不确定性高、且预计能获得大量信息的区域

> 符号与本文/相关文档保持一致：ω = {θ, xT} 是待估计的参数；𝒟_obs 是已观测数据；𝒟_acq 是预计采集的未来数据

## 3. 带数字走一遍：玩具例子 (Worked Example)

假设一个 2D 简化场景：机器人用手指触摸一个未知位置的线段（1D 几何）。

**设定**：
- 真实线段：中心在 (0, 0)，长度 2cm，水平放置
- 初始猜测：中心在 (1, 0)，长度 1cm（完全错误）
- 机器人从 (2, 0) 向左移动

**第一次接触**（t=0）：
- 机器人在 x=1.5 处接触到猜测线段的右端点
- 测量：c_0 = 1（接触）, n̂_0,m = (-1, 0)（法向向左）
- 计算 ℒ_0：由于猜测线段在 x=1.5 处确实有表面，法向匹配，损失很小

**更新后**：
- 优化器发现：如果线段中心在 (0.5, 0)、长度 2cm，能更好解释这次接触
- ℐ(𝒟_obs) 的某些元素增大（对右端点位置更确定）

**EIG 指导的下一步**：
- 候选动作 A：再次触摸右侧（已探索区域）→ ℱ 小，EIG 低
- 候选动作 B：触摸左侧（未探索区域）→ ℱ 大，EIG 高
- 选择动作 B

**第二次接触**（t=1）：
- 机器人移动到 (-1.5, 0)，接触到线段左端点
- 现在左右端点都已知 → 线段中心 = 0, 长度 = 2cm，完美恢复

**关键洞察**：如果只用随机探索，可能需要 4-5 次接触才能覆盖两端；EIG 在第一次接触后就"知道"应该去对面，2 次接触完成学习。论文中立方体参数化实验验证了这一点：EIG 在 5 次动作后达到 <4mm bCH，随机探索需要 8 次才能达到同等精度。

## 4. 工程视角 (Engineering View)

**计算复杂度**：
- 内层 QP 求解：~1ms（Cvxpylayers，GPU 加速）
- Loss Hessian 计算：~10ms（Jaxopt 自动微分）
- EIG 优化（Cross-Entropy，50 个样本，3 轮迭代）：~200ms
- 单次动作总规划时间：~250ms

**部署约束**：
- 需要可微分接触动力学模拟器（本文用 Drake 1kHz 仿真）
- 触觉传感器频率 ≥ 30Hz（Densetact 满足）
- 物体必须是凸的（保证接触点唯一性）
- 物体不能太轻（<0.5kg 时 Densetact 难以检测轻触）

**Trade-off 分析**：

| 设计选择 | 收益 | 代价 |
|----------|------|------|
| Violation-implicit loss | 梯度稳定，收敛快 | 可能陷入非物理局部最优（需多初始化） |
| EIG 而非 MI | 计算快 10 倍，无需信念分布 | 局部度量，MLE 错误时性能下降 |
| 假设 dx_t/dx_{t-1} = I | 避免数值不稳定 | 对翻滚等混沌运动不适用 |
| 凸物体假设 | 接触点唯一，优化简单 | 无法处理凹物体（需多凸块并集） |

**内存占用**：
- 轨迹长度 T=5-8 步
- 每步存储：rt, ct, n̂_t,m（~50 bytes）
- 总数据量：<1KB，完全在嵌入式设备上可行

**实时性**：
- 规划频率：~4Hz（250ms/动作）
- 机器人执行频率：1Hz（1 秒/动作）
- 瓶颈在 EIG 优化，可通过减少 CE 样本数或并行化加速

## 6. 能力与失败模式 (Capabilities & Failure Modes)

### 能做什么
- ✅ 5-8 秒内仅用触觉数据学会未知凸物体的 3D 姿态和几何
- ✅ 物体在探索过程中可以自由移动（1-2cm 位移）
- ✅ 主动探索比随机探索快 30-60%，且更稳定
- ✅ 支持两种参数化：立方体（3 参数）和凸多面体（20 顶点=60 参数）

### 不能做什么
- ❌ 非凸物体（需扩展为凸块并集，未实现）
- ❌ 极轻物体（<0.5kg 时触觉信号太弱）
- ❌ 混沌运动（如翻滚，因 dx_t/dx_{t-1}=I 假设失效）
- ❌ 多物体场景（当前仅单物体）
- ❌ 视觉 - 触觉融合（纯触觉，但作者提到可与 FoundationPose 等结合）

### 6.1 隐含假设 (Hidden Assumptions)

**X-Ray 批判视角**：

1. **接触点唯一性**：假设凸物体 + 凸末端执行器保证单一接触点。如果传感器曲率与物体曲率匹配，可能出现面接触，法向估计失效。

2. **已知地面**：假设工作空间有已知的刚性地面平面，用于约束物体姿态（至少 3 个顶点在地面）。在无地面场景（如空中抓取）需要扩展。

3. **准静态运动**：1 秒直线轨迹假设物体运动是准静态的。高速冲击会导致动力学主导，violation-implicit loss 的准静态假设失效。

4. **传感器校准**：假设触觉传感器的法向估计模型准确。实际中 Densetact 需要针对每个传感器单独校准表面变形 - 力模型。

5. **MLE 局部最优可接受**：EIG 是局部度量，如果 MLE 陷入错误局部最优，EIG 会"自信地错下去"。论文用多初始化缓解，但未根本解决。

### 面试 Tip

**问**：触觉 SLAM 和视觉 SLAM 的核心区别是什么？

**答**：视觉 SLAM 是"被动密集"——每帧都有大量像素但深度模糊；触觉 SLAM 是"主动稀疏"——每次接触只有单点但物理约束强。因此触觉 SLAM 必须做主动探索（EIG/MI），而视觉 SLAM 可以被动等待运动视差。本文的 violation-implicit loss 解决了触觉特有的问题：接触会导致物体移动，姿态和几何必须联合优化。
