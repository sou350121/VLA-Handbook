💡 **X-Ray 开场**
细粒度接触丰富操作（如穿鞋带、传递脆弱芯片）对机器人来说很难，核心原因是触觉反馈利用不足。现有方法要么在特征层拼接视觉和触觉（视觉主导问题），要么训练多个单模态策略再组合（跨模态关联弱）。TouchGuide 换了一个思路：**不在特征层融合，而在动作空间融合**——先用纯视觉策略生成一个"看起来合理"的粗糙动作，再用一个接触物理模型（CPM）根据触觉信号对这个动作施加梯度引导，让它"摸起来也合理"。对 VLA 研究者意味着：$\pi_{0.5}$ 等流匹配策略可以即插即用地获得触觉能力，无需重新训练整个模型。

### 1.2 关键机制 (Key Mechanism)

TouchGuide 的核心设计可以分解为三个层次：

1. **两阶段推理**：扩散/流匹配采样的早期阶段（$k > K_{\text{TouchGuide}}$）仅用视觉生成粗糙动作；后期阶段（$k \leq K_{\text{TouchGuide}}$）引入 CPM 触觉引导。
2. **接触物理模型（CPM）**：一个独立的轻量模型，用 DINOv2 编码视觉和触觉观测，用 1D CNN+MLP 编码动作，在潜在空间中计算余弦相似度作为"触觉可行性分数"。
3. **对比学习训练**：CPM 仅用有限专家演示训练——同时间步的观测-动作对为正样本，不同时间步的为负样本，双向对比损失。

⚡ **Eureka Moment**：把触觉引导建模为动作空间中的可行性分数梯度 ∇_A s(V, T, A)，而非在特征层拼接——这样触觉信号直接修正"动作应该往哪走"，而不是让模型自己去学会"什么时候该听触觉的"。

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：
```
s_φ(V_t, T_t, A_t) = O_t^T · a_t    (观测-动作潜在空间余弦相似度)
```

**目标**：让采样过程中的动作分布被触觉可行性分数引导，最大化满足物理接触约束的动作概率。

**核心方程**（扩散策略引导）：
```
ε̂_θ = ε_θ(A_t^k, V_t) - η·√(1-ᾱ_k)·∇_{A_t^k} s_φ(V_t, T_t, A_t^k)
```

**核心方程**（流匹配策略引导，如 $\pi_{0.5}$）：
```
û_θ = u_θ(A_t^k, V_t) - η·[k/(1-k)]·∇_{A_t^k} s_φ(V_t, T_t, A_t^k)
```

**变量说明**：

| 符号 | 含义 |
|------|------|
| $\varepsilon_\theta$ / $u_\theta$ | 基策略的噪声预测（扩散）/速度预测（流匹配） |
| $\eta$ | 引导尺度（guidance scale） |
| ᾱ_k | 扩散噪声调度参数 |
| k/(1-k) | 流匹配的时间依赖权重（论文 Proposition 1 推导） |
| $s_\varphi$ | CPM 输出的可行性分数 |
| O_t | 潜在观测向量（视觉+触觉融合后 L2 归一化） |
| a_t | 潜在动作向量（L2 归一化） |
| $\tau$ | 对比学习可学习温度参数 |

**直觉**：可行性分数 $s = O_t^T \cdot a_t$ 本质上是"当前动作与当前触觉观测在潜在空间中的对齐程度"。梯度 $\nabla_A s$ 告诉采样过程"往哪个方向调整动作能让它更符合触觉物理约束"。这类似于 classifier guidance 中用分类器梯度引导生成过程，但这里引导信号来自触觉物理可行性而非类别标签。

> 符号与本文保持一致：V_t=视觉观测, T_t=触觉观测, A_t=动作, O_t=潜在观测, a_t=潜在动作, s=可行性分数。

**CPM 训练损失**：
```
L_CPM = 0.5 · (L_{O→a} + L_{a→O})

L_{O→a} = -(1/M) · Σ_i log[ exp(O_i^T · a_i / τ) / Σ_j exp(O_i^T · a_j / τ) ]
L_{a→O} = -(1/M) · Σ_i log[ exp(a_i^T · O_i / τ) / Σ_j exp(a_j^T · O_i / τ) ]
```

正样本：同时间步 $(O_t, a_t)$；负样本：不同时间步 $(O_{t+\Delta t}, a_t)$ 和 $(O_t, a_{t+\Delta t})$。

## 3. 带数字走一遍：玩具例子 (Worked Example)

假设一个简化的 2D 动作空间（位置 x, y），我们走一遍 TouchGuide 的推理引导过程：

**设定**：
- 基策略 $\pi_\theta$（扩散策略）生成粗糙动作 $A = [0.5, 0.3]$（仅基于视觉）
- 触觉观测 T 显示指尖与物体表面有接触（力信号在 y 方向较大）
- CPM 经过训练，知道"在接触状态下，x 方向动作应该小，y 方向可以大"

**Step 1: CPM 编码**
```
O_t = DINOv2(concat(V_t, T_t)) → L2Norm → [0.8, 0.6]  (归一化后)
a_t = CNN+MLP(A) → L2Norm → [0.6, 0.8]  (归一化后)
```

**Step 2: 计算可行性分数**
```
s = O_t^T · a_t = 0.8×0.6 + 0.6×0.8 = 0.48 + 0.48 = 0.96
```
分数 0.96 很高，说明当前动作与触觉观测对齐良好。

**Step 3: 但如果视觉主导产生了不合理动作**
假设视觉-only 策略生成了 A_bad = [0.9, 0.1]（快速横向滑动，忽略触觉接触）：
```
a_bad = [0.99, 0.14]  (归一化)
s_bad = 0.8×0.99 + 0.6×0.14 = 0.792 + 0.084 = 0.876
```
分数降到 0.876。更重要的是梯度：
```
∇_A s ≈ [∂s/∂x, ∂s/∂y] = [0.8, 0.6]  (CPM 认为应该增加 y 方向)
```

**Step 4: 引导修正**（扩散，η=1.0, √(1-ᾱ_k)=0.3）：
```
ε̂ = ε_base - 1.0 × 0.3 × [0.8, 0.6] = ε_base - [0.24, 0.18]
```
修正后的动作会向 y 方向偏移——更符合触觉感知的接触物理。

**Step 5: 流匹配场景**（如 $\pi_{0.5}$，$k=0.7$）：
```
权重 = k/(1-k) = 0.7/0.3 = 2.33
û = u_base - η × 2.33 × [0.8, 0.6] = u_base - [1.87, 1.40]
```
流匹配的引导权重随时间增长，在采样后期（k 接近 1）引导更强——这符合直觉：后期需要更精细的触觉修正。

## 4. 工程视角 (Engineering View)

| 工程维度 | 分析 |
|----------|------|
| **额外推理开销** | CPM 前向传播：$2\times$ DINOv2 + TranEnc + CNN+MLP + 余弦计算。DINOv2 是主要瓶颈（$\sim 100\text{-}200\,\text{ms}/$张），但可与基策略并行。仅在后期采样步（$k \leq K_{\text{TG}}$）调用，总开销 $\approx (K_{\text{TG}}/K) \times \text{CPM\_latency}$ |
| **K_TG 选择** | 论文未给出具体数值，但直觉上：早期步（$k$ 大）噪声大，触觉引导效果弱；后期步（$k$ 小）动作已接近最终，引导空间有限。合理范围可能是 $K_{\text{TG}} \approx K/3$ 到 $K/2$ |
| **内存占用** | CPM 额外加载：$2\times$ DINOv2 ($\sim 1.1\,\text{GB}$) + TranEnc + 动作编码器。与基策略共享 DINOv2 可减半。总计约 $1\text{-}2\,\text{GB}$ 额外显存 |
| **量化兼容性** | DINOv2 可 INT8 量化；CPM 本身轻量。但梯度计算需要 FP16/BF16，量化引导可能损失精度 |
| **部署约束** | 每任务需独立训练 CPM（对比学习，数据量小），但基策略零修改。适合"一个基策略 + 多个任务 CPM"的场景 |
| **触觉传感器依赖** | 实验使用 Xense 光学触觉传感器，输出触觉图像 $(200\times350\times3)$ 和力场 $(20\times35\times3)$。不同传感器需重新采集数据训练 CPM |
| **引导尺度 $\eta$** | 关键超参。$\eta$ 过小 $\to$ 引导不足；$\eta$ 过大 $\to$ 偏离视觉可行区域。需按任务调优 |

**工程含义**：TouchGuide 的核心工程价值在于"基策略免修改"——如果你已经有一个部署好的 $\pi_{0.5}$ 或 DP 策略，想给它加触觉能力，只需额外训练一个 CPM（对比学习，数据量小），推理时插入引导逻辑。这比从头训练一个 visuo-tactile 策略成本低得多。

### 6.1 隐含假设 (Hidden Assumptions)

1. **触觉信号在任务中是信息丰富的**：如果触觉信号变化很小（如空中移动），CPM 的引导信号可能很弱甚至噪声。论文承认"tactile signals often exhibit limited variation in many cases"。
2. **专家演示中的接触物理是"正确"的**：CPM 学习的是专家演示中隐含的接触约束。如果专家本身的接触策略不是最优的，CPM 会继承这个偏差。
3. **Vive Tracker 定位精度足够**：TacUMI 依赖 Lighthouse 定位，但在遮挡或大范围操作中可能丢失跟踪。
4. **DINOv2 对触觉图像的表征足够**：DINOv2 是在自然图像上预训练的，触觉图像（接触斑纹）与自然景观差异很大。论文在 Appendix C 有编码器对比实验，但具体结果未在主文中呈现。
5. **余弦相似度足以表征触觉可行性**：s = O_t^T · a_t 是一个简洁的设计，但可行性可能涉及更复杂的非线性关系。
