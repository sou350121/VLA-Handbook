### 1.2 关键机制 (Key Mechanism)

**两阶段分解的动机**: 人类操作者在抓取和接近阶段使用视觉开环操作，接触发生后才激活触觉反馈进行实时修正。本文模仿这一策略：

1. **Reach 阶段**：扩散策略通过模仿学习获得位置泛化能力，将 peg 从随机初始位置（5×5cm 区域）抓取并带到孔口附近。每个孔几何形状需要单独训练一个 reach policy。

2. **Insert 阶段**：基于位置的切换机制检测到末端进入 AABB 包围盒 X_init 后，切换到 RL 策略。RL 在接触丰富的交互中学习插入和失败恢复行为。

**非对称 Actor-Critic 设计**（核心创新）:

触觉信号受到抓握姿态的强烈影响——不同的 in-hand peg 位姿会导致原始传感器信号（尤其是扭矩 M_x, M_y）出现显著偏移。如果直接将原始触觉信号输入 actor，会增加输入方差、 destabilize 策略学习。

解决方案：
- **Actor**：仅依赖视觉观测生成动作 → 保持策略稳定
- **Critic**：额外接收触觉变化量 Δf_t = f_t - f̄ → 提供接触感知的价值估计

> ⚡ **Eureka Moment**: 触觉信号不直接驱动动作，而是用来"更准确地评估动作的好坏"——把触觉从"控制信号"重新定位为"评估信号"，避免了抓握偏移对策略网络的污染。

**触觉基线估计**: 每次抓取后，在 gripper 闭合后的稳定窗口内对触觉读数取平均：

```
f̄ = (1/K) Σ f_tb+k    (k=0,...,K-1)
```

其中 f̄ = [Fx, Fy, Fz, Mx, My, Mz]ᵀ 是 6-DoF 力/扭矩均值向量。触觉变化量 Δf_t = f_t - f̄ 隔离了插入引起的接触变化。

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：

```
Q_φ(o_vis, Δf, a) 学习接触感知价值 → 引导 π_θ(o_vis) 生成稳定插入动作
```

核心思想：触觉不改变"做什么"，但改变"知道做得好不好"。

**目标函数**:

```
max_π E[Σ γ^t · r_t]    where r_t ∈ {0, 1} (sparse binary)
```

稀疏二元奖励：插入成功 = 1，否则 = 0。

**Critic 损失**（SAC 标准 + 触觉增强）:

```
L_Q(φ) = E[(Q_φ(o, a) - y)^2]

y = r + γ(1-d) · E_a'[Q_φ̄(o', a') - α·log π_θ(a'|o')]
```

关键：o 在 critic 中包含触觉变化量 Δf_t，在 actor 中不包含。

**Critic Warmup**（MC 回归初始化）:

```
L_MC(φ) = E_(s,a,G)~D_demo[(Q_φ(s, a) - G)^2]
```

用演示轨迹的蒙特卡洛回报 G 直接回归 critic，避免早期 TD 学习的 bootstrap 误差。

**触觉分组采样**:

```
g(f̄) = (b_x(M̄_x), b_y(M̄_y))    → N×M 个触觉组
```

沿 M_x 和 M_y 轴离散化为 N=2 和 M=4 个区间，均匀采样组内均匀采样样本。

**变量说明**:

| 符号 | 含义 |
|------|------|
| φ | Critic Q 网络参数 |
| θ | Actor 策略参数 |
| φ̄ | Target critic 参数（软更新） |
| α | SAC 温度系数（熵正则化） |
| γ | 折扣因子 |
| d | Terminal flag (0/1) |
| f̄ | 抓握后触觉基线（6-DoF） |
| Δf_t | 触觉变化量 = f_t - f̄ |
| X_init | AABB 包围盒，切换条件 |
| G | 演示轨迹的蒙特卡洛累积回报 |

> 符号与本文保持一致：所有粗体字母表示向量（如 f, p），非粗体表示标量。

## 3. 带数字走一遍：玩具例子 (Worked Example)

假设一个 0.05mm 间隙的圆形孔插入场景：

**Step 1 — 抓取后基线估计**:
```
抓取稳定后 K=10 帧触觉读数平均:
f̄ = [2.1, -0.3, 0.5, 0.08, -0.12, 0.01]ᵀ  (N 或 N·m)
```

**Step 2 — 接触发生**（peg 边缘碰到孔口）:
```
当前触觉: f_t = [3.8, 1.2, 0.4, 0.15, 0.35, 0.02]ᵀ
触觉变化: Δf_t = [1.7, 1.5, -0.1, 0.07, 0.47, 0.01]ᵀ
                      ↑ 明显的侧向力和扭矩变化
```

**Step 3 — Critic 评估**:
```
Q_φ(o_vis, Δf_t, a_insert_down) ≈ -2.3  (低价值：触觉显示偏置接触)
Q_φ(o_vis, Δf_t, a_correct_xy)  ≈ +0.8  (高价值：先修正 xy 位姿)
```

Critic 通过触觉变化量识别出当前的向下插入动作会导致偏心接触（高侧向力），因此给修正动作更高的价值估计。

**Step 4 — Actor 选择动作**:
```
Actor 只看到视觉裁剪图像（peg 偏右）→ 输出 a_correct_xy
执行后 peg 对准孔口 → 下一帧 Δf_t 减小 → Q 值上升
```

**Step 5 — 触觉分组的影响**:
```
假设抓握扭矩 M̄_x = 0.08 → bin 1 (共2 bins)
           M̄_y = -0.12 → bin 3 (共4 bins)
组索引 g = (1, 3)

如果 buffer 中 (1,3) 组样本少，分组采样会增加该组的更新频率
→ 类似抓握姿态的策略得到更多训练
```

## 4. 工程视角 (Engineering View)

| 工程维度 | 数值/设计 | 含义 |
|----------|----------|------|
| 控制频率 | 10 Hz | Insert 阶段每秒 10 次决策；足够应对接触 dynamics |
| Reach 动作视域 | H=16 步 | 扩散策略输出 16 步动作序列，滚动执行 |
| 图像分辨率 | 128×128 | ResNet-18 编码；低分辨率降低计算负担 |
| 视觉编码器 | ResNet-18 | Actor 和 Critic 共享；轻量级 |
| 计算平台 | RTX 5090 + i9-14900 | 训练和实时推理在同一工作站 |
| 训练时间 | ~30 分钟 (1,000-2,000 步) | 人工介入下快速收敛；RLPD 双 buffer 策略 |
| Replay Buffer | D_demo + D_on 各半采样 | 演示先验 + 在线探索的平衡 |
| 触觉传感器 | Paxini PX-6AX GEN3 | 六维力/扭矩；嵌入 gripper 指尖 |
| 相机 | D405 (腕部) + D435i (全局) | 局部精细 + 全局场景感知 |

**工程含义**:
- **非对称设计的计算优势**: Actor 不需要处理触觉信号，推理时只需视觉编码 + 策略前向传播，降低延迟
- **Critic Warmup 的工程价值**: MC 回归初始化避免了早期随机探索中的价值估计爆炸，使 RL 训练从第 1 步就有合理的价值引导
- **触觉基线减法**: 一个简单的 f_t - f̄ 操作，消除了抓握位置变化带来的系统性偏移，比学习一个复杂的触觉表征网络更轻量、更可靠
- **分组采样的开销**: 2×4=8 个组的维护成本极低，但显著改善了 replay buffer 的覆盖度

### 6.1 隐含假设 (Hidden Assumptions)

1. **触觉传感器可用且校准准确**: 假设 gripper 上的六维力/扭矩传感器能提供可靠的触觉读数。如果传感器噪声大或未校准，触觉基线估计和变化量计算都会失效。

2. **抓取姿态变化有限**: 触觉基线减法假设抓握后的初始触觉状态相对稳定。如果抓取策略本身不稳定（peg 在 gripper 中滑动），基线估计会引入额外方差。

3. **AABB 切换边界可靠**: 基于位置的阶段切换假设末端执行器位置可以被准确追踪。如果 proprioception 有显著误差，切换时机可能过早或过晚。

4. **人工介入可行**: RLPD 训练管线依赖人工介入来纠正高风险状态。在无操作员在场的场景中（如自动化产线），这一假设不成立。

5. **peg 和 hole 几何已知**: 每个几何形状需要单独的 reach policy。系统不处理"看到未知孔几何"的情况。

| 残差 RL | 安全探索 | 基线策略 + 残差 | 演示 + 在线 | 安全关键场景 |
| **本文** | **触觉-视觉非对称利用** | **IL reach + RL insert, 触觉仅 critic** | **RLPD + 人工介入** | **亚毫米级精密装配** |

> **面试 Tip**: 当被问到"多模态融合应该把所有信号都输入同一个网络吗？"时，可以用本文回答："不一定。本文的非对称设计表明，让不同模态在不同网络组件中发挥不同作用（视觉驱动动作、触觉辅助评估），比统一融合更稳定——因为触觉信号受抓握姿态影响大，直接输入 actor 会增加策略方差。"

## 8. 精讀建議 (Reading Guide)

**值得精讀原文的人**:
- 做接触丰富操作（contact-rich manipulation）的研究者——非对称 actor-critic 设计可直接迁移到其他触觉任务
- 精密装配领域的工程师——完整的从抓取到插入的真实机器人实现，含详细的超参和训练流程
- 探索多模态融合策略的 VLA 研究者——"触觉不驱动动作但驱动评估"的思路对多模态 VLA 设计有启发

**建議章節路徑**:
1. 先读 §IV-B（Insert Policy）——理解非对称 actor-critic 和触觉 critic 的核心设计
2. 再看 §IV-A（Reach Policy）和 Location-based Switching ——理解两阶段如何衔接
3. 可跳过 §II（Related Work）——除非你需要完整的文献综述

**不值得精讀的理由**:
- 如果你不做精密装配或接触丰富操作，这篇的方法论距离你的场景较远
- 如果你已熟悉 SAC + RLPD 训练管线，本文的训练框架没有本质创新
- 如果你关心 VLA 大模型的端到端策略，这篇是传统 RL 方法，不是 VLA 架构
