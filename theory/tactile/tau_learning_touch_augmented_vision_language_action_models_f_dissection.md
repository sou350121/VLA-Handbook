**关键设计决策**:
- 触觉编码器 E_tou 从 π₀.₅ 视觉编码器初始化（共享权重），确保触觉特征与视觉特征在同一个语义空间
- 线性适配器 A_tou 将触觉特征投影到 VLA 的嵌入空间
- 预测分支仅在训练时提供额外监督信号，推理时完全移除 → **零推理开销**

### 1.2 关键机制 (Key Mechanism)

τ 的核心创新在于**用未来视觉特征变化作为触觉表征的监督信号**，而非直接预测触觉信号本身或绝对视觉特征。具体机制：

1. **动作条件预测**: 给定当前触觉表征 + 后续动作序列 → 预测未来视觉特征变化 Δz
2. **相对变化而非绝对值**: 监督目标是 Δz = z[t+Δₖ] - z[t]（未来减当前），而非直接预测 z[t+Δₖ]。这使模型关注"交互引起的变化"而非静态场景
3. **触觉加权**: 根据触觉信号变化幅度为每个未来时间步分配权重 w[t+Δₖ]，强调接触转换显著的时刻
4. **停止梯度目标**: 目标特征变化使用 stop-gradient，防止梯度回传到视觉编码器

⚡ **Eureka Moment**: 不直接预测触觉会怎样变，而是让触觉表征学会预测"我的动作会让视觉世界发生什么变化"——触觉因此隐式编码了物理交互动力学。

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：
```
L_total = L_IL + λ·L_SSL
其中 L_SSL = Σₖ w[t+Δₖ]·(1 - cos(Δẑ[t+Δₖ], Δz[t+Δₖ])) / (Σₖ w[t+Δₖ] + δ)
直觉: 用触觉+动作预测未来视觉变化，加权余弦相似度对齐，权重来自触觉变化幅度
```

### 2.1 策略损失 — 条件流匹配 (Imitation Learning)

**目标**: 让 VLA 学会从多模态观测生成动作块。

```
L_IL = E[ || v_θ(a[t:t+H]^s, o~[t]) - u(a[t:t+H]^s | a[t:t+H]) ||₂² ]
```

其中:
- a[t:t+H]^s = s·a[t:t+H] + (1-s)·ε, s ∈ [0,1], ε ~ N(0,I)
- u = ∂a^s/∂s = a[t:t+H] - ε (目标去噪方向)
- v_θ 是动作专家学习的去噪向量场

**变量说明**:

| 符号 | 含义 |
|------|------|
| s | 流轨迹上的连续时间步 |
| ε | 高斯噪声 |
| a[t:t+H] | 专家动作块 (H步) |
| o~[t] | 扩展观测 {I[t], ℓ[t], q[t], τ[t]} |

### 2.2 自监督损失 — JEPA 风格预测 (Predictive SSL)

**目标**: 让触觉表征学会预测"如果我执行这个动作，视觉世界会怎么变"。

```
预测: {ẑ[t+Δₖ]ᵛⁱˢⁱᵒⁿ} = P(Z[t]ᵗᵒᵘᶜʰ, Z[t:t+H]ᵃᶜᵗ)
目标: Δz[t+Δₖ]ᵛⁱˢⁱᵒⁿ = sg(z[t+Δₖ]ᵛⁱˢⁱᵒⁿ - z[t]ᵛⁱˢⁱᵒⁿ)
```

**触觉加权**:
```
w[t+Δₖ] = mean_{i∈{L,R}} clip(||τ[t+Δₖ]⁽ⁱ⁾ - τ[t]⁽ⁱ⁾||₂ / (c̄ + δ), w_min, w_max)
```

| 符号 | 含义 | 值 |
|------|------|-----|
| c̄ | 训练集归一化尺度 | 数据集统计 |
| δ | 数值稳定性 | 1e-6 |
| w_min, w_max | 权重截断范围 | 0.2, 5.0 |

**加权余弦对齐损失**:
```
L_SSL = Σₖ w[t+Δₖ]·(1 - cos(Δẑ[t+Δₖ], Δz[t+Δₖ])) / (Σₖ w[t+Δₖ] + δ)
```

**直觉**: 当触觉变化大时（如开始插入、施加压力），w 变大，模型更努力预测视觉变化。这迫使触觉表征关注那些"真正改变世界状态"的接触事件。

### 2.3 总损失

```
L_total = L_IL + λ·L_SSL, λ = 0.3
```

> 符号与本文保持一致：上标 vision/touch/action 表示模态，上标 (i) 表示左右传感器索引，Δₖ 表示未来时间偏移。

## 3. 带数字走一遍：玩具例子 (Worked Example)

假设一个简化的 USB 插入任务场景：

**时间步 t**: 机械臂已抓取 USB，开始接近端口。

| 时间步 | 触觉状态 | 视觉变化 | 权重 w |
|--------|---------|---------|--------|
| t | 空闲状态，无接触 | — | — |
| t+1 (Δ=1) | 轻微接触，USB碰到端口边缘 | 小变化（USB位置移动） | w=0.5 |
| t+2 (Δ=2) | 中等压力，USB开始倾斜插入 | 中等变化（角度变化） | w=2.0 |
| t+3 (Δ=3) | 紧密配合，USB完全插入 | 大变化（插入完成） | w=4.0 |

**预测过程**:
1. 触觉编码器将 τ[t]（左右手指的形变图）编码为 z[t]ᵗᵒᵘᶜʰ
2. 动作编码器将 a[t:t+H] 编码为 Z[t:t+H]ᵃᶜᵗ
3. 预测器 P 输出 ẑ[t+1], ẑ[t+2], ẑ[t+3]
4. 目标 Δz[t+Δₖ] = sg(z[t+Δₖ] - z[t]) 由视觉编码器提取

**损失计算**:
```
L_SSL = [0.5·(1-cos(Δẑ₁, Δz₁)) + 2.0·(1-cos(Δẑ₂, Δz₂)) + 4.0·(1-cos(Δẑ₃, Δz₃))] / (0.5+2.0+4.0+δ)
```

由于 w[t+3] = 4.0 最大，模型在训练时会优先学好"完全插入时视觉会怎么变"这个预测。这迫使触觉表征编码"USB完全插入"所需的精细接触信息——而这正是基线模型（如 ForceVLA 85%对齐但0%插入）失败的地方。

**总损失**:
```
L_total = L_IL + 0.3·L_SSL
```

假设 L_IL = 0.5（流匹配误差），L_SSL = 0.3（预测对齐误差），则 L_total = 0.5 + 0.3×0.3 = 0.59。

### 6.3 隐含假设 (Hidden Assumptions)

1. **未来视觉变化可充分编码触觉动力学**: 假设"视觉变化"足以捕捉所有与接触相关的动力学信息。但某些触觉信息（如材料属性、微观滑移）可能不会引起明显的视觉变化
2. **触觉传感器位置固定且可靠**: 假设 DM-Tac 传感器始终正确安装且信号质量稳定。实际部署中传感器可能松动或污染
3. **100条演示足够**: 每任务100条演示即训练，但未与更多数据（如500条）做对比实验。在更大规模数据下 JEPA 监督的边际收益未知
4. **单臂桌面操作假设**: 所有实验在 Franka 单臂桌面上进行，未验证移动基座或双臂场景
5. **未来时间偏移 Δₖ 手动设定**: 论文未说明 Δₖ 的选择策略（是固定的还是可学习的），这可能影响 SSL 效果

| ForceFlow† | 6D力/力矩+流匹配 | 有时序但非高维触觉 | 100/task | 23.75% | +力传感器 |
| T-Rex† | 大规模触觉预训练 | 有（大规模数据） | 大规模 | 31.25% | +触觉编码 |
| **τ (本文)** | **高维触觉+JEPA未来视觉预测** | **有（动作条件预测）** | **100/task** | **71.25%** | **零额外** |

**面试 Tip**: 如果被问到"τ 和 T-Rex 都用了触觉，有什么区别"——回答：T-Rex 通过大规模多感官预训练学习触觉表征（数据驱动），τ 通过 JEPA 风格的未来视觉预测在有限数据上学习触觉动力学（监督驱动）。τ 的优势是数据效率高且推理零开销，局限是仅在小规模数据集上验证。
