### 1.2 关键机制 (Key Mechanism)

**双模式采集管道**:
- **精度模式**: MoCap 追踪，亚毫米精度，适合高精度演示
- **便携模式**: VR 追踪，误差<1cm，成本约$700（双臂系统），支持野外采集和恢复遥操作

**跨形态适配**: 通过机构参数化映射，将手持接口适配到不同夹爪形态（屈伸式/平行夹爪），只需调整 2-3 个几何参数而非重新设计

**在线可行性验证**: 采集时实时映射到机器人位姿并检查——逆解失败/软限位超限/超速/通信异常，即时反馈操作者修正

**tAmeR 恢复遥操作**: Pico 4 Ultra AR 头显实时流式传输触觉视频 + 腕部鱼眼视觉，操作者在真实失败状态下进行恢复操作

⚡ **Eureka Moment**: 触觉 VLA 的数据瓶颈不在于算法或模型容量，而在于**数据本身的质量闭环**——演示必须可执行、失败必须可恢复、触觉必须真实，三者缺一不可。

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）:
```
L_total = L_con(触觉 - 视觉对比) + L_act(动作 L1 损失) + DAgger(恢复数据更新)
```

**触觉对比预训练目标** (Eq 5):
```
L_con = -1/B Σ_i=1^B log [ Σ_{v∈P_i} exp(v^T t_i / τ) / (Σ_{v∈P_i} exp(v^T t_i / τ) + Σ_{v∈N_i} exp(v^T t_i / τ)) ]
```
- B: batch size
- t_i: 触觉嵌入
- P_i = {v_i, v_{i+1}}: 正样本视觉集（当前帧 + 下一帧）
- N_i: 负样本集
- τ: 温度参数

**直觉**: 触觉嵌入应该与对齐的视觉帧以及时间上相邻的视觉帧都接近——因为触觉和视觉在接触事件中是时间同步且语义相关的。

**下游动作策略损失** (Eq 6):
```
L_act = Σ_{i=1}^T || â_i - a_i ||_1
```
- â_i ∈ R^16: 预测动作（双臂 7+7 关节 + 2 夹爪）
- a_i ∈ R^16: 演示动作

**机构适配运动学** (屈伸式夹爪，Eq 2-3):
```
w(x2, x3) = x3 + l1 * sin[π/2 - arctan(x4/(d+x2)) - arccos((l2²+x4²+(d+x2)²-l3²)/(2*l2*sqrt(x4²+(d+x2)²)))]
x1(x2) = l1 * [1 - cos(π/2 - arctan(x4/(d+x2)) - arccos(...))]
```
- w: 夹爪开口宽度
- x1: 指尖前后位移
- x2: 滑块位移（控制变量）
- x3: 可调参数（决定最大开口）

> 符号与本文/相关文档保持一致：l1-l4 为连杆长度，d 为滑块最前位置到固定点 A 的距离，φ2/φ3 为中间角度

## 3. 带数字走一遍：玩具例子 (Worked Example)

**场景**: 电缆安装任务 (Cable Mounting)

**数据采集阶段**:
1. 操作者使用 TAMEn 手持接口抓取柔性电缆
2. MoCap 以 240Hz 追踪位姿，触觉相机以 30FPS 记录接触
3. 在线验证检测到"电缆抬升过高"→超出机器人工作空间→即时提示操作者降低高度
4. 最终采集 221 条有效演示（100% 可重放）

**训练阶段**:
1. **预训练**: 在 FreeTacMan 3M 触觉 - 视觉图像对上训练触觉编码器（对比学习）
2. **微调**: 在 221 条双臂演示上训练 ACT 策略（L1 动作损失）
3. **恢复**: 部署策略→检测到失败（电缆滑脱）→tAmeR 介入收集恢复轨迹（21 条）→DAgger 更新

**推理阶段**:
- 输入：双腕 640x480 鱼眼 RGB + 四指触觉图像
- 输出：16 维动作（7+7 关节角 + 2 夹爪开度）
- 块大小：根据任务时序复杂度选择

## 4. 工程视角 (Engineering View)

**硬件成本分解**:
- 便携版双臂系统：~$700（Pico 4 Ultra $630 + 3D 打印结构件 + 触觉传感器）
- 精度版：需额外 MoCap 系统（NOKOV，未标价）

**时序/频率**:
- MoCap 追踪：240Hz（亚毫米精度）
- VR 追踪：100Hz（误差<1cm）
- 视觉/触觉相机：30FPS，640x480
- 在线验证延迟：未明确，但需实时反馈

**部署约束**:
- 需要机器人逆解和运动学模型（用于可行性验证）
- 触觉传感器需模块化集成（支持 GelSight/Xense/DW-Tac/PaXini 等）
- AR 头显需低延迟视频流（tAmeR）

**Trade-off**:
- 精度 vs 便携：MoCap 精度高但依赖基站；VR 便携但误差~1cm
- 数据量 vs 质量：50% 额外演示仅提升 5% 成功率（70%），10% 在线恢复提升 10%（75%）

## 6. 能力与失败模式 (Capabilities & Failure Modes)

**能做什么**:
- 接触丰富的双臂操作（变形物体、精密对齐、多阶段协调、持续接触）
- 跨夹爪形态快速适配（屈伸式/平行夹爪，参数化配置）
- 在线检测并过滤不可执行演示
- 在真实失败状态下收集恢复数据

**不能做什么**:
- 灵巧手操作（仅验证了夹爪）
- 跨传感器泛化（论文明确列为未来工作）
- 视觉严重退化时的目标获取（光照全干扰下草药转移/电缆安装均为 0%）

### 6.1 隐含假设 (Hidden Assumptions)

1. **触觉 - 视觉时间同步**: 对比学习假设触觉和视觉帧在时间上严格对齐（±1 帧内）
2. **机器人运动学已知**: 可行性验证需要精确的机器人 URDF 和逆解器
3. **操作者能理解反馈**: 在线验证提示需要操作者能即时修正（新手/专家表现差异未详细分析）
4. **触觉传感器兼容性**: 假设不同触觉传感器的输出可以通过简单集成适配（实际可能需要重新校准）
5. **恢复数据分布**: 假设在线恢复数据覆盖策略失败模式——如果策略出现未见过的失败类型，恢复数据可能无效
