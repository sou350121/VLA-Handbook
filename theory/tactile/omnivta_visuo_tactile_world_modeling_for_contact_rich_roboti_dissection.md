## 1. 核心架构/方法总览 (Overview / Architecture)

### 1.1 系统对比概览 (System Component Comparison)

| 模块 | 输入 | 输出 | 频率 | 训练/推理 |
|------|------|------|------|----------|
| TactileVAE | 原始触觉图像 (240×320) | 低维触觉潜变量 z_t | 60Hz | 自监督重建 |
| Visuo-Tactile World Model | (v_t, z_t, a_t) | (v_{t+1:H}, z_{t+1:H}) | 30Hz 预测 | 条件生成 |
| Adaptive Fusion Policy | (v_t, z_t, z_{t+1:H}^pred) | 动作 a_t | 30Hz | 行为克隆 |
| Reflexive Controller | (z_t^obs, z_t^pred) | 校正动作 Δa_t | 60Hz | 规则/学习混合 |

**关键设计选择**：
- **双流世界模型**：视觉流和触觉流分别预测，再融合（而非单流联合预测）
- **Latent Tactile Differential (LTD)**：编码当前触觉与预测未来触觉的差异
- **接触感知门控**：根据预测接触状态动态调整视觉/触觉权重

### 1.2 关键机制 (Key Mechanism)

**为什么这样设计？**

1. **触觉 VAE 而非直接输入原始图像**：触觉图像高维 (76,800 像素) 但信息冗余，VAE 压缩到 64 维潜变量，保留接触几何 + 力信息，降低世界模型负担

2. **世界模型预测短期演化**：人类操作时大脑会预测"接下来 0.5 秒接触如何变化"，OmniVTA 用生成模型实现类似功能，提前规划而非被动响应

3. **60Hz 反射控制器**：接触状态可能在 10-20ms 内突变（如打滑），30Hz 策略层太慢，需要独立高频回路做微调

⚡ **Eureka Moment**：**触觉信号的核心价值不是"补充视觉盲区"，而是"预测接触动力学演化" + "高频闭环校正"** —— 这篇论文首次把触觉从被动观测提升为主动预测变量。

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：

```
min_θ E[(z_t - z̃_t)²] + E[(v_{t+1:H} - v̂_{t+1:H})² + (z_{t+1:H} - ẑ_{t+1:H})²] + E[L_task(π(v_t, z_t, ẑ_{t+1:H}), a_t*)]
```

**分解说明**：

| 项 | 含义 | 对应模块 |
|----|------|---------|
| `E[(z_t - z̃_t)²]` | 触觉 VAE 重建损失 | TactileVAE |
| `E[(v_{t+1:H} - v̂_{t+1:H})² + (z_{t+1:H} - ẑ_{t+1:H})²]` | 世界模型预测损失 | Visuo-Tactile WM |
| `E[L_task(π(...), a_t*)]` | 策略行为克隆损失 | Fusion Policy |

**触觉 VAE 编码**：
```
q_φ(z_t | x_t) = N(μ_φ(x_t), σ_φ(x_t)²)
x̃_t = D_ψ(z_t)  # 重建触觉图像
```

**世界模型预测**（条件扩散或 Transformer）：
```
p_θ(v_{t+1:H}, z_{t+1:H} | v_{≤t}, z_{≤t}, a_{≤t})
```

**接触感知门控**：
```
α_t = σ(MLP(z_t, ẑ_{t+1:H}))  # 触觉权重 ∈ [0,1]
h_t = α_t · f_touch(z_t) + (1-α_t) · f_vision(v_t)
a_t = π(h_t)
```

> 符号说明：z_t = 触觉潜变量，v_t = 视觉观测，a_t = 动作，H = 预测时域 (通常 10-30 步)

## 3. 带数字走一遍：玩具例子 (Worked Example)

**场景**：机器人用海绵擦拭花瓶表面，过程中花瓶被外力推动导致位置偏移。

**步骤拆解**（时间单位：16.7ms = 60Hz 单步）：

| 时刻 | 事件 | 触觉 z_t | 世界模型预测 | 融合权重 α_t | 控制器输出 |
|------|------|---------|-------------|-------------|-----------|
| t=0 | 正常擦拭 | z_0=[0.2, 0.1, ...] | ẑ_{1:10} 平稳 | α=0.3 (视觉主导) | a_0 正常 |
| t=5 | 花瓶开始滑动 | z_5 突变 (压力分布改变) | ẑ_{6:15} 预测接触丢失 | α 升至 0.7 | a_5 微调 |
| t=6 | 反射控制器检测 | z_5^obs vs ẑ_5^pred 差异大 | - | - | Δa_5 = -0.15x, +0.08y |
| t=7 | 校正后 | z_6 恢复预期范围 | 重新预测 ẑ_{7:16} | α 降至 0.4 | a_6 恢复 |

**关键数值**：
- 触觉潜变量维度：64
- 预测时域 H：10 步 (167ms @ 60Hz)
- 反射控制器增益：K_p=0.8, K_i=0.1 (PID 形式)
- 门控 α 范围：0.2~0.8（根据接触置信度动态调整）

**如果没有反射控制器**：策略层 30Hz 响应，从检测到滑移到输出校正需 33ms，期间接触已丢失；**有反射控制器**：16.7ms 内完成检测 + 校正，接触保持。

## 4. 工程视角 (Engineering View)

### 4.1 系统资源需求

| 组件 | 计算负载 | 内存 | 延迟要求 |
|------|---------|------|---------|
| TactileVAE 编码 | ~5ms (GPU) | 50MB | <10ms |
| 世界模型推理 | ~15ms (GPU) | 200MB | <30ms |
| 策略网络 | ~3ms (GPU/CPU) | 30MB | <10ms |
| 反射控制器 | ~1ms (CPU) | 5MB | <5ms |

**总延迟预算**：~24ms（满足 30Hz 策略 + 60Hz 反射控制）

### 4.2 部署约束

1. **触觉传感器频率**：必须 ≥60Hz（论文用 GelSight Mini/Tac3D/Xense/Daimon，均支持 60-120Hz）

2. **时间同步精度**：视觉 (30Hz) 与触觉 (60Hz) 需亚毫秒级同步，否则世界模型训练发散

3. **跨平台迁移**：
   - 数据集用 xArm 7-DoF + TacUMI 采集
   - 迁移到新机器人需重新校准触觉 - 动作映射
   - 世界模型可微调，VAE 和策略层需部分重训

### 4.3 关键 Trade-off

| 选择 | 优点 | 缺点 |
|------|------|------|
| 潜变量 vs 原始触觉 | 降维 1000x，训练稳定 | 丢失高频细节 |
| 双流世界模型 vs 单流 | 视觉/触觉独立建模更准确 | 参数量 +30% |
| 60Hz 反射 vs 30Hz 统一 | 接触突变响应快 2 倍 | 控制回路复杂度翻倍 |

### 6.2 不能做什么 / 局限

| 限制 | 具体表现 | 根因 |
|------|---------|------|
| 非接触任务 | 性能退化 | 触觉信号无信息，门控失效 |

| 多机器人协同 | 未验证 | 数据集仅单臂采集 |
| 极端材质 | 触觉饱和 | GelSight 对高反光/透明物体失效 |

### 6.1 隐含假设 (Hidden Assumptions)

**X-Ray 批判视角**：

1. **触觉 - 视觉时间同步完美**：假设传感器驱动层能保证亚毫秒同步，但实际部署中 USB 延迟抖动可能破坏这一假设

2. **接触动力学局部性**：假设接触演化仅依赖局部历史 (10 步)，但某些任务（如长距离滑动）可能需要更长依赖

3. **单一接触点**：数据集以单点接触为主，多点接触（如双手协作）未覆盖

4. **刚性物体假设**：100+ 物体多为刚性或半刚性，高柔性物体（布料、线缆）未测试
