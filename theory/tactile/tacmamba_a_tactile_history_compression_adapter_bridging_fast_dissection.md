## 1. 核心架构/方法总览 (Overview / Architecture)

### 1.1 系统对比概览 (System Component Comparison)

| 组件 | 输入 | 输出 | 频率 | 训练/推理 | 关键特性 |
|------|------|------|------|-----------|----------|
| **TacMamba 触觉编码器 (System 1)** | 1D 力信号流 x(t) | 压缩隐藏状态 h_t | 100Hz | 两阶段：自监督预训练 + VLA 微调 | Mamba SSM，O(1) 推理，0.45ms 延迟 |
| **VLA 规划器 (System 2)** | 图像 + 语言 + z_tac (触觉 soft prompt) | 动作指令 | ~1Hz | 标准 VLA 微调 | 接收异步触觉状态注入 |
| **判别器 (仅训练)** | 隐藏状态对 (h_i, h_j) | 时序关系分类 (早/同时/晚) | - | 阶段 1 自监督 | 强制编码因果结构 |
| **硬件接口** | 定制单轴力传感器 | 100Hz 力数据流 | 100Hz | - | 形态学触觉指尖，机械投影分布式接触 |

### 1.2 关键机制 (Key Mechanism)

**为什么这样设计？**

1. **异步架构解耦快慢系统**：触觉编码器持续以 100Hz 更新隐藏状态，VLA 按需查询。这避免了同步架构中触觉处理被 VLA 低频推理拖慢的问题。

2. **Mamba 选择性状态空间**：传统 LTI 系统参数固定，无法处理混合动力学（如静态抓握 vs 瞬时"click"）。Mamba 的输入依赖选择性机制允许模型在静态时抑制噪声、在瞬态事件时激进更新内部状态。

3. **相位均匀采样解决数据稀疏**：关键接触事件（如按钮 snap-through）只占轨迹的<5%。标准均匀采样会让模型过拟合长持续时间的静态帧。相位均匀采样确保每个子任务阶段对训练贡献相等。

⚡ **Eureka Moment**：**触觉历史可以像语言 token 一样被压缩为 O(1) 访问的 soft prompt**——不是把原始触觉序列喂给 VLA，而是用 Mamba 实时压缩为紧凑状态向量，异步注入为 VLA 的软提示。这实现了"无损频率对齐"：100Hz 触觉反射完全不依赖 1Hz 视觉规划的延迟。

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：

```
h_t = Ā(Δ_t, x_t) · h_{t-1} + B̄(Δ_t, x_t) · x_t   [Mamba 离散化状态更新]
```

**目标**：将连续触觉信号 x(t) 编码为紧凑隐藏状态 h_t，满足：(1) 保留长时依赖 (2) O(1) 推理延迟 (3) 适应混合动力学。

**公式详解**：

| 符号 | 含义 | 维度 | 说明 |
|------|------|------|------|
| x_t | t 时刻触觉输入 | ℝ | 1D 力信号 |
| h_t | t 时刻隐藏状态 | ℝ^N | 压缩触觉历史 |
| Ā, B̄ | 离散化系统参数 | ℝ^{N×N}, ℝ^N | 由 Mamba 选择性机制计算 |
| Δ_t | 输入依赖时间步长 | ℝ | 动态调整，非固定 |

**直觉**：传统 LTI 系统用固定参数 (A, B)，但 TacMamba 的 Mamba 核心根据输入 x_t 动态计算 (Δ_t, B_t, C_t)。这使得模型能像"自适应物理滤波器"：静态抓握时抑制噪声，检测到"click"瞬态时激进更新状态。

**训练目标（阶段 1 自监督）**：

```
L_pre = -E_{(h_i,h_j)~D_bal} Σ_{c=0}^2 I(y_ij=c) · log D(h_i, h_j)_c
```

其中 y_ij ∈ {0: t_i<t_j, 1: t_i≈t_j, 2: t_i>t_j}，判别器 D 预测时序关系。关键是关系平衡采样强制三类均匀分布，防止模型走捷径（如永远预测"未来"）。

> 符号与本文/相关文档保持一致：h_t 表示触觉隐藏状态，区别于 VLA 的语言/视觉 token。

## 3. 带数字走一遍：玩具例子 (Worked Example)

**场景**：机器人按按钮，需要检测"click"瞬态反馈。

**假设参数**：
- 触觉采样率：100Hz（Δt = 10ms）
- Mamba 隐藏维度：N = 64
- 按钮 press 持续时间：200ms（20 个时间步）

**推理过程**：

```
t=0ms:   x_0 = 0.1N (未接触)
         h_0 = Ā·h_{-1} + B̄·0.1  →  h_0 ≈ [0,0,...,0]（静态，状态变化小）

t=50ms:  x_5 = 2.3N (初始接触)
         (Δ_5, B_5, C_5) = Linear(x_5)  →  参数调整，准备捕捉瞬态
         h_5 = Ā_5·h_4 + B̄_5·2.3  →  状态开始累积力历史

t=100ms: x_10 = 5.8N (按钮 snap-through 瞬态)
         Mamba 选择性机制检测到突变 → Δ_10 增大，B_10 增益提高
         h_10 = Ā_10·h_9 + B̄_10·5.8  →  隐藏状态显著更新，编码"click"事件

t=150ms: VLA 规划器查询触觉状态
         z_tac = Project(h_10)  →  投影为 VLA 软 prompt
         VLA 接收 z_tac + 图像 + 语言 → 输出"停止按压"动作

t=200ms: x_20 = 0.2N (释放)
         h_20 = Ā·h_19 + B̄·0.2  →  状态衰减，准备下一次交互
```

**关键观察**：
- 整个过程 h_t 更新始终是 O(1)：只依赖 h_{t-1} 和 x_t，不随历史长度增长
- Transformer 需要重新处理全部 20 个 token，延迟随历史线性增长
- LSTM 虽也是 O(1) 更新，但在 100Hz×数秒=数千步后会遗忘早期细节

## 4. 工程视角 (Engineering View)

| 指标 | TacMamba | Bi-LSTM | Transformer | 1D-CNN | 工程含义 |
|------|----------|---------|-------------|--------|----------|
| **推理延迟** | 0.45ms | 9.20ms | 11.37ms | 0.23ms | TacMamba 满足 100Hz 闭环 (<10ms)，Transformer/LSTM 超标 |
| **准确率** | 88.89% | 82.50% | 81.25% | 56.25% | TacMamba 在保持低延迟同时达到 SOTA 精度 |
| **内存增长** | O(1) | O(L) | O(L²) | O(1) | 长历史 (L=5000) 下 Transformer 内存爆炸 |
| **速度提升** | - | 21× | 25× | 0.5× | 相对基线的加速比 |

**部署约束**：
- **控制频率**：必须≥100Hz 才能捕捉触觉瞬态（如 click 振动<5ms）
- **量化误差**：论文未明确讨论，但 Mamba 的递归更新可能累积量化误差，建议 FP16 推理
- **硬件依赖**：需要定制单轴力传感器（成本低于 GelSight 等视觉触觉传感器）
- **与 VLA 集成**：无需联合预训练，冻结 Mamba 编码器后投影为 soft prompt 即可

**Trade-off 分析**：
- 选择 1D 力传感器而非高分辨率触觉相机：牺牲空间拓扑信息，换取计算效率和时序分辨率
- 异步架构：增加系统复杂度（需管理两个频率的同步），但避免 VLA 延迟拖慢触觉回路

### 6.1 隐含假设 (Hidden Assumptions)

**X-Ray 批判视角**——作者默认成立但未明确验证的前提：

1. **视觉已提供粗略接触位置**：论文假设 VLA  backbone 能从视觉推断接触区域，触觉只需补充时序动态。但在完全黑暗或视觉失效场景下，这一假设不成立。

2. **1D 力信号足够表征接触**：作者引用文献 [7] 支持"聚合力历史包含丰富信息"，但未系统比较 1D vs 6-DoF 力/力矩 vs 高分辨率触觉相机的信息损失。

3. **相位分割基于力梯度阈值**：自动分割依赖 ‖∇x_t‖ 检测非接触→接触转换。在渐变接触（如软物体）场景下，阈值选择可能敏感。

4. **Mamba 容量足够**：隐藏维度 N=64（推测）对简单接触任务可能足够，但更复杂操作（如工具使用、多物体交互）可能需要更大容量，影响 O(1) 优势。
