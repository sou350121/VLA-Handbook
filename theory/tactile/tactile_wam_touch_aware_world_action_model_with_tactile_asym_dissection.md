### 1.2 关键机制 (Key Mechanism)

论文识别了触觉注入 WAM 的两大核心问题，并逐一解决：

**问题 1: 触觉污染（Tactile Pollution）**
- 触觉数据集远小于视频预训练语料（UniVTAC 仅 800 条轨迹）
- 触觉信号描述稀疏的局部接触事件，对全局视觉外观预测无益
- 无约束的视觉 Query → 触觉 Key 注意力会干扰预训练视觉表征
- 表现：训练损失更高、未来帧 MSE 增加 ~50%、预测画面模糊

**问题 2: 像素-接触错位（Pixel-Contact Misalignment）**
- 触觉图像的像素变化 ≠ 实际接触变化
- 大像素变化可能对应微小物理变化，小像素变化可能对应滑动/压缩等关键事件
- 仅靠像素重建损失无法确保预测的触觉表征保留对动作生成关键的接触动力学

⚡ **Eureka Moment**: "视觉 Query 不需要看到触觉，但动作 Query 需要——用非对称注意力单向保护视觉预测路径，同时让动作生成感知触觉。"

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：

```
L = L_video + L_action + λ_τ·L_FM^τ + L_F
  └── 视觉流匹配 ─┘  └── 动作流匹配 ─┘  └── 触觉流匹配 ─┘  └── 代理监督 ┘

约束: Attn(Q^v, K^τ) = -∞  (VideoClean 掩码阻断视觉→触觉)
增强: A' = A + M^vc + I^c·b_c  (触觉感知偏置强化动作→触觉)
```

### 2.1 流匹配目标（基础框架）

对每个目标 x₀ᵐ（m ∈ {视觉, 动作, 触觉}），从噪声到干净数据的插值和速度：

```
x_ρᵐ = (1 - ρ)·x₀ᵐ + ρ·εᵐ,    u_ρᵐ = εᵐ - x₀ᵐ
L_FMᵐ = E[||v_θᵐ(x_ρᵐ, ρ; C_t) - u_ρᵐ||₂²]
```

其中 ρ ∈ [0,1] 是时间步，εᵐ ~ N(0,I) 是噪声，C_t 是条件上下文。

### 2.2 VideoClean 非对称掩码

```
M_qk^vc = -∞,  当 G(q) = 视觉 ∧ G(k) = 触觉
          0,   否则
```

**变量说明**:
- G(q), G(k): Query/Key 所属的模态组（视觉 V / 触觉 T / 动作 A / 状态 S）
- 仅阻断视觉 Query 访问触觉 Key；动作 Query 保留对触觉 Key 的完整访问权

### 2.3 触觉感知注意力偏置

```
s_c = tanh(ReLU(||F_c^obs||₂ - θ) / T)
b_c,k = clip(α·s_c, 0, b_max)
A'_qk = A_qk + M_qk^vc + I_qk^c · b_c(k),k
```

**变量说明**:
- F_c^obs: 从当前和上一时刻触觉图像提取的接触强度向量（§2.4）
- s_c: 接触强度标量，范围 [0,1)，反映接触是否存在及其强度
- θ: 阈值（低于此值认为无接触），T: 温度参数
- α: 放大因子，b_max: 偏置上界
- I_qk^c: 指示函数，动作 Query 和触觉 Key 在同一因果块内为 1，否则 0

### 2.4 触觉代理信号（Touch-Aware Proxy）

```
u_x,t^s = ΔI_t^s · g_x^s / √((g_x^s)² + (g_y^s)² + ε)
u_y,t^s = ΔI_t^s · g_y^s / √((g_x^s)² + (g_y^s)² + ε)
f_t^s = [<u_x,t^s>, <u_y,t^s>, <∂_x u_x,t^s + ∂_y u_y,t^s>]
```

**变量说明**:
- ΔI_t^s: 传感器 s 的灰度触觉图像时间差分
- (g_x^s, g_y^s) = ∇I_t^s: 空间梯度
- ε = 10⁻⁶: 数值稳定常数
- <·>: 空间平均操作
- f_t^s ∈ ℝ³: 每个传感器 3 维代理信号（切向变形 x2 + 散度 x1）
- 左右传感器拼接: F ∈ ℝ^{C×8×6}（C 个动作块，每块 8 帧触觉过渡）

### 2.5 代理监督损失

```
L_F = 0.05 · SmoothL1(F_hat, F*)
L_total = L_video + L_action + λ_τ·L_FM^τ + L_F
```

**直觉**: 代理信号 F 从触觉图像的光流中提取可微分的变形特征，比原始像素更能反映接触动力学。在训练时，梯度通过冻结的 VAE 解码器和可微估计器 Φ 反向传播到预测的触觉潜变量，迫使模型学习保留接触变化信息。

> 符号与本文保持一致：上标 v=视觉, τ=触觉, a=动作, s=状态; 下标 t=时间步, ρ=流匹配时间步; Φ=可微变形估计器。

## 3. 带数字走一遍：玩具例子 (Worked Example)

假设一个简化的灯泡插入任务（论文 Figure 6 的场景），我们追踪触觉代理和注意力偏置的数值变化：

**设定**:
- 动作块大小 K = 8 帧
- 触觉图像分辨率 64×64
- θ = 0.5（接触阈值）, T = 0.1（温度）, α = 2.0, b_max = 3.0

**Step 1: 未接触阶段（t = 0~3）**
```
ΔI_t ≈ [0.01, 0.02, 0.01]  (触觉图像几乎无变化)
||F_obs||₂ ≈ 0.025
s_c = tanh(ReLU(0.025 - 0.5) / 0.1) = tanh(ReLU(-0.475)/0.1) = tanh(0) = 0
b_c,k = clip(2.0 × 0, 0, 3.0) = 0
```
→ 偏置为 0，动作 Query 正常关注视觉和触觉 Key，无特殊偏向。

**Step 2: 初始接触（t = 4）**
```
ΔI_t ≈ [0.3, 0.4, 0.2]  (灯泡接触灯座，触觉图像开始变形)
||F_obs||₂ ≈ 0.54
s_c = tanh(ReLU(0.54 - 0.5) / 0.1) = tanh(0.4) ≈ 0.38
b_c,k = clip(2.0 × 0.38, 0, 3.0) = 0.76
```
→ 偏置 +0.76 加到动作 Query → 触觉 Key 的注意力 logits 上。模型开始更关注触觉。

**Step 3: 接触调整（t = 5~6，可能出现滑动）**
```
ΔI_t ≈ [0.8, 0.6, 0.5]  (灯泡在灯座内滑动，触觉变形加剧)
||F_obs||₂ ≈ 1.08
s_c = tanh(ReLU(1.08 - 0.5) / 0.1) = tanh(5.8) ≈ 1.0
b_c,k = clip(2.0 × 1.0, 0, 3.0) = 2.0
```
→ 偏置 +2.0，动作 Query 强烈关注触觉 Key。注意力权重从视觉向触觉偏移，使模型能基于触觉信号生成修正动作。

**Step 4: 接触稳定（t = 7~8）**
```
ΔI_t ≈ [0.05, 0.03, 0.04]  (灯泡已就位，触觉变形稳定)
||F_obs||₂ ≈ 0.04
s_c = tanh(ReLU(0.04 - 0.5) / 0.1) = 0
b_c,k = 0
```
→ 偏置回归 0，注意力恢复均衡。

**对比无偏置情况**: 论文 Figure 6 显示，无偏置时残留接触发展为滑动，任务失败；有偏置时模型在接触变化时及时修正，任务成功。

| 真机控制频率 | 未明确披露 | TODO: 待补充真机控制频率和推理延迟数据 |

**部署约束**:
- 需要 Vision-based 触觉传感器（如 DIGIT 类型），每个机械手爪一个
- 触觉图像处理（光流计算、代理提取）可在 CPU 上实时完成
- 主要计算瓶颈在 DiT 去噪过程，与纯视觉 WAM 相同
- 显存需求：额外触觉 token 序列，增加约 10-20% 显存（取决于序列长度）

**工程含义**: VideoClean 掩码的实现成本极低——只是在注意力计算中加一个 -∞ mask，不增加任何推理开销。触觉偏置的计算（光流 + 范数 + tanh）每个动作块只需一次，摊到每个去噪步骤几乎可忽略。

| 失败场景 | 原因 | 论文证据 |
|----------|------|---------|
| HDMI 插入 | 任务依赖更精细的触觉反馈或不同的接触建模 | UniVTAC 17/20 vs 期望更高 |

### 6.1 隐含假设 (Hidden Assumptions)

1. **触觉传感器始终可用且校准** — 论文假设左右触觉传感器在每个时间步都有可靠读数。真实场景中触觉传感器可能脱落、脏污或漂移。
2. **光流代理足以表征接触动力学** — 6 维代理信号基于灰度触觉图像的光流，假设这能捕捉所有对动作生成关键的接触信息。但实际接触力（法向力、切向力）无法从光流直接推断。
3. **仿真到真机的触觉分布一致性** — ManiFeel 仿真环境中训练的触觉表征能直接迁移到真实传感器。但仿真触觉图像和真实 DIGIT 类传感器的图像域差异可能很大。
4. **因果块边界与动作块对齐** — 注意力偏置按动作块边界划分因果块，假设每个动作块内的接触状态是一致的。但快速操作可能在一个块内经历多次接触状态变化。
5. **Wan2.2 VAE 对触觉图像的编码能力** — 假设为视频预训练的 VAE 能 adequately 编码触觉图像（通过 mosaicking 左右传感器）。但触觉图像的统计特性与自然景观视频差异很大。

| **Sparsh** (Higuera et al. 2024) | 自监督触觉表征 | 独立触觉编码器 | 自监督预训练 | 触觉表征学习（非 WAM） |
| **Visuo-Tactile WM** (Higuera et al. 2026) | 初步视觉+触觉融合 | 未明确 | 未明确 | 早期探索 |
| **Tactile-WAM** (本文) | 非对称注意力 + 代理监督 | Wan2.2 DiT + TAAM | 从训练开始 | 接触丰富操作 |

**面试 Tip**: 当被问到"如何将触觉信息融入预训练世界模型"时，回答核心是：「不要对称融合——视觉预测不需要触觉（会污染），但动作生成需要触觉（关键信号）。用非对称注意力单向保护视觉路径，同时用接触感知的注意力偏置让动作查询在关键时刻关注触觉。」
