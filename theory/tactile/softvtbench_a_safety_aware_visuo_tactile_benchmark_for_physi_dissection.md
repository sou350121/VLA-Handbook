💡 **X-Ray 开场**

现有机器人操作基准（LIBERO、RoboTwin 等）只看「任务有没有完成」，但可变形物体（面包、软包装、食品等）的操作有一个隐藏约束：你不能捏碎它、不能让它掉落、不能过度变形。SoftVTBench 第一次用 FEM 物理仿真做「特权状态」评估——策略看不到形变数据，但评测器用 FEM-RMS 形变判断操作是否安全。结果发现：约 70% 的「成功」任务在物理层面是不安全的。触觉反馈能把安全成功率从 21.4% 提升到 35.6%。

### 1.2 关键机制 (Key Mechanism)

SoftVTBench 的核心设计围绕三个关键机制：

1. **特权 FEM 状态评估**：策略只能看到视觉、触觉、本体感知和语言指令，但评测器在后台记录 FEM 节点位置、物体位姿、接触状态和掉落事件。策略必须从可观测信号中推断接触条件、初始滑动和材料柔顺性。

2. **双指标分离**：Goal Success（任务是否完成）和 Safety Success（是否在物理安全约束下完成）分开报告。Safety Success = Goal Success ∧ 无掉落 ∧ 峰值形变 ≤ 物体特定阈值 τ_o。

3. **2×2 匹配任务设计**：物体类型（可变形 vs 刚性）× 变化轴（物体身份 vs 空间布局），四个任务套件配对设计，将「可变形物体安全操作」从「基本操作能力」中分离出来。

⚡ **Eureka Moment**：「成功完成任务」和「安全地完成任务」是两个不同的概念——约 70% 的 Goal Success 在物理层面是不安全的，现有基准系统地高估了策略性能。

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：

```
Safety Success = Goal Success ∧ NoDrop_episode ∧ (D_peak ≤ τ_o)
```

**目标**：在完成任务的同时，确保物理交互过程安全——不掉落、不过度变形。

**公式分解**：

```
D_peak = max_t D(t)                    // 全轨迹峰值形变
D(t)   = FEM-RMS 形变 (归一化为包围盒对角线百分比)
τ_o    = κ · D_ref_o, κ=0.5 (默认)     // 物体特定安全阈值
```

**变量说明**：

| 符号 | 含义 | 来源 |
|------|------|------|
| D(t) | t 时刻的 FEM-RMS 形变，去除全局刚体运动后 | 特权 FEM 状态 |
| D_peak | 全 episode 的最大形变 | 式 (3) |
| τ_o | 物体 o 的安全阈值 | 式 (6)，离线标定 |
| D_ref_o | 物体 o 的参考形变（压缩扫描中的最大稳定形变） | Appendix C.3 |
| κ | 安全系数，默认 0.5 | Appendix C.3 |
| NoDrop | 全程无掉落/滑脱/逃逸 | 特权状态检测 |

**直觉**：阈值 τ_o 设为参考形变的一半（κ=0.5），意味着策略必须在「能捏住」和「别捏碎」之间找到一个窄窗口。策略看不到 D(t) 和 τ_o——它必须从触觉 RGB 图像和标记运动场中推断出这个安全区间。

> 符号与本文保持一致。FEM-RMS 形变是有限元方法计算的均方根形变，归一化为物体包围盒对角线的百分比。

## 3. 带数字走一遍：玩具例子 (Worked Example)

假设一个面包类可变形物体（Object-Soft 套件中的第 0 号任务）：

**场景设定**：
- 物体包围盒对角线 = 80mm
- 离线标定：D_ref = 20% 对角线（即 16mm 的绝对形变）
- 安全阈值：τ_o = 0.5 × 20% = 10% 对角线（即 8mm）

**VO 策略的一次 rollout**：

| 时间步 | 动作 | D(t) | 判断 |
|--------|------|------|------|
| t=0 | 接近物体 | 0% | 正常 |
| t=5 | 闭合夹爪 | 8% | D ≤ τ_o ✓ |
| t=8 | 提升 | 12% | **D > τ_o ✗**（过捏） |
| t=15 | 移动 | 6% | D ≤ τ_o ✓ |
| t=22 | 放置 | 3% | D ≤ τ_o ✓ |
| t=30 | 松开 | 0% | 完成 |

- Goal Success = True（物体放入目标容器）
- NoDrop = True（全程无掉落）
- D_peak = max(0, 8, 12, 6, 3, 0) = 12% > τ_o = 10%
- **Safety Success = False**（峰值形变超标）

这正是论文 Table 3 中 VO 在 Object-Soft 上 70.4% Goal Success 但仅 21.4% Safety Success 的微观机制：大量 rollout 在某个时间步过度压缩了物体。

**VT 策略的同一场景**：

触觉标记运动场在 t=7 检测到夹爪-物体界面剪切力急剧上升 → 策略提前减小夹爪闭合度 → D(t) 峰值控制在 9% → Safety Success = True。

### 6.1 隐含假设 (Hidden Assumptions)

1. **FEM-RMS 形变是安全性的充分代理指标**：论文用单一的 RMS 形变标量判断安全性，但实际安全可能涉及局部应力集中、剪切力分布等多维因素。一个低 RMS 但局部高应力的操作可能比高 RMS 但均匀分布的操作更危险。

2. **κ=0.5 是普适的安全系数**：论文对所有物体使用 κ=0.5，但不同材料（海绵 vs 面包 vs 软糖）的安全裕度可能差异很大。Appendix C.3 报告了 κ∈{0.3, 0.7} 的敏感性分析，但未给出材料自适应的 κ 选择方法。

3. **仿真到真实的迁移可行性**：论文未讨论 Sim2Real 问题。GelSight Mini 的仿真渲染（Taxim optics + FOTS markers）与真实传感器在噪声、分辨率、延迟上有系统差异。

4. **固定 seed 评估的充分性**：每套件仅 50 个验证 episodes，对于统计显著性可能不够。论文未报告置信区间或方差。
