### 1.2 关键机制 (Key Mechanism)

**为什么这样设计？**

1. **过分割初始化**：传统方法用 DBSCAN 等聚类直接猜"正确"的部件数量，但复杂物体（如 11 个抽屉的储物柜）极易出错。ArtPro 反其道而行——先分成比真实数量更多的提议，然后在优化中合并。

2. **运动一致性合并**：两个相邻区域如果交换运动参数后渲染结果几乎不变（深度图 L1 误差变化 < 10⁻³），说明它们属于同一部件，应该合并。

3. **碰撞感知剪枝**：优化过程中如果两个部件在运动轨迹上发生碰撞（重叠体积增加 > 10⁻⁴），说明运动轴估计错误，需要剪枝校正。

⚡ **Eureka Moment**：这篇论文最核心的洞见是——**关节物体的部件分割不应该是一个固定的起点，而是一个在优化过程中持续 refine 的动态过程**。"猜一次分割"的范式注定脆弱，"提议 - 验证 - 合并"的自校正系统才能鲁棒。

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：

```
L = L_I + λ_cd·L_cd + λ_pc·L_pc + λ_ls·L_ls + λ_reg·L_reg
```

**目标**：最小化渲染损失 + 几何对齐 + 部分区分 + 空间平滑 + 紧凑性正则化

**变量说明**：

| 符号 | 含义 | 默认权重 |
|------|------|----------|
| L_I | RGBD 渲染损失（3DGS 光栅化） | 1.0 |
| L_cd | 单侧 Chamfer 距离（变换后高斯中心 → $P^1$） | 0.5 |
| L_pc | 部分对比损失（抑制非最大部分概率） | 0.1 |
| L_ls | 局部平滑损失（kNN 邻居静态概率差） | 0.02 |
| L_reg | 正则化（部分概率分布对齐高斯） | 1.0 |

**直觉**：这个损失函数的设计核心是**多任务协同**——L_I 保证视觉保真度，L_cd 保证几何对齐，L_pc 强制每个高斯只属于一个主导部分，L_ls 防止分割碎片化，L_reg 保持部分紧凑性。

### 2.1 部分归属概率计算

```
P̂ₘ(xᵢ) = (1 - Pₛ(xᵢ)) · Pₘ(xᵢ) / Σₖ₌₁ᴹ Pₖ(xᵢ)

Gₘ = {gᵢ ∈ G | P̂ₘ(xᵢ) > ε},  ε = 0.01
```

**直觉**：先排除静态部分概率，然后在可动部分中归一化。阈值 $\varepsilon = 0.01$ 确保只有高置信度的高斯才被分配给部件。

### 2.2 运动参数变换

```
对于棱柱关节：x̂ᵢ = xᵢ + tₘ
对于旋转关节：x̂ᵢ = Rₘ(xᵢ - cₘ) + cₘ + tₘ,  q̂ᵢ = Rₘ ⊗ qᵢ
```

其中 $R_m$ 是 6DoF 旋转表示，$c_m$ 是旋转中心，$t_m$ 是平移向量。

### 2.3 提议整合判据

```
S(T) = Σᵥ |Dᵥ(T(G)) - Dᵥ|  (渲染深度图与 GT 的 L1 误差)

合并条件：|S(Tᵢ⁽ⁱ⁾) - S(Tᵢ⁽ʲ⁾)| < τ_merge = 10⁻³
```

**直觉**：如果把部件 i 的运动参数换成部件 j 的，渲染结果几乎不变，说明两者运动一致，应该合并。

### 2.4 碰撞检测与剪枝

```
Δvᵢ,ⱼ = vᵢ,ⱼ¹ - vᵢ,ⱼ⁰ > τᵥ = 10⁻⁴  →  检测到碰撞

对于棱柱关节：tₘ ← tₘ - (tₘ · a_col) · a_col
```

**直觉**：如果运动后重叠体积增加，说明运动轴方向估计错了，把平移向量投影到垂直于碰撞轴的平面上。

> 符号与本文/相关文档保持一致：$P_s=$静态部分概率，$P_m=$可动部分 $m$ 概率，$G=$高斯集合，$T=$刚体变换

## 3. 带数字走一遍：玩具例子 (Worked Example)

假设我们重建一个**双抽屉储物柜**（1 个静态框架 + 2 个可动抽屉）：

**初始化阶段**：
- 输入：t=0（关闭）和 t=1（拉开 10cm）的双状态 RGBD 图像
- 过分割产生 5 个提议（真实只有 2 个抽屉，但算法不知道）
- 每个提议基于 OBB 主轴初始化：假设抽屉 1 沿 X 轴平移 5cm（真实值的一半，见公式 5）

**优化循环 1（0-5000 轮）**：
- 高斯原语优化收敛，渲染 PSNR 达到 35dB
- 运动剪枝检测到提议 1 和提议 2 在运动轨迹上有碰撞（Δv = 2×10⁻⁴ > τᵥ）
- 剪枝：将提议 1 的平移向量从 (0.05, 0, 0) 修正为 (0, 0.05, 0)

**优化循环 2（5000-10000 轮）**：
- 提议整合触发：计算相邻提议对的运动一致性分数
- 提议 1 vs 提议 2：$|S(T_1^{(1)}) - S(T_1^{(2)})| = 0.0008 < \tau_{\text{merge}} \to$ **合并**
- 提议 3 vs 提议 4：分数变化 $0.002 > \tau_{\text{merge}} \to$ 不合并
- 现在剩下 4 个提议

**优化循环 3（10000-15000 轮）**：
- 提议 3 vs 提议 4 也满足合并条件 $\to$ 合并
- 现在剩下 3 个提议（1 个静态 + 2 个可动，正确！）
- 无提议可合并，退出循环

**后处理精修**：
- 双状态联合优化，加入碰撞损失 L_col
- 最终输出：CD-w = 0.65mm, 运动误差 = 0.04mm（见表 1）

**工程含义**：

1. **吞吐/延迟权衡**：ArtPro 比 ArtGS 慢 62%（17min vs 10min），但对于复杂多部件物体（如 11 抽屉储物柜），ArtGS 会失败而 ArtPro 能成功。这是**用时间换鲁棒性**的典型 trade-off。

2. **部署约束**：
   - 需要**双状态捕获**：物体必须能拍到"关闭"和"打开"两个状态
   - 需要**深度图**：纯 RGB 无法运行（依赖 L_cd 和深度渲染损失）
   - 内存友好：2.7GB GPU 内存可在消费级显卡（如 RTX 3060）上运行

3. **量化误差敏感点**：
   - 深度图质量直接决定运动参数估计精度（论文 Figure 13 展示失败案例）
   - 建议使用 PriorDA 等先验提示深度预测器提升真实扫描数据质量

4. **步数/抖动**：
   - 运动剪枝每 100 轮执行一次，防止优化早期陷入局部最优
   - 提议整合每 5000 轮执行一次，避免频繁合并导致不稳定

### 6.3 隐含假设 (Hidden Assumptions)

**X-Ray 批判视角**：

1. **刚体假设**：每个可动部件只做单一刚体变换（棱柱或旋转）。现实中的软体部件（如布袋、电线）不适用。

2. **双状态充分性**：假设两个状态（t=0, t=1）足以捕捉运动学结构。对于多阶段运动（如三段式抽屉），可能信息不足。

3. **深度图准确性**：假设 Depth Anything V2 等预训练模型能提供足够准确的深度。在反光/透明表面可能失效。

4. **运动可见性**：假设可动部件在两个状态之间有可见位移。对于锁定的部件或微运动（<1mm），无法检测。

5. **语义无关性**：方法完全自监督，不利用任何语义先验（如"抽屉通常是长方体"）。这既是优点（泛化好）也是缺点（边界可能不准确）。
