## 0. 两篇论文各自在说什么

**VGA**（2026-04-14）说：机器人的大脑应该**用 3D 思考**。用 3D 几何 backbone 替代语言模型，36K 场景的 3D 预训练就超过了万亿 token 的 VLM。
→ [VGA 详解](vga_vision_geometry_action_over_language_video_2026.md)

**Spark 2.0**（2026-04-14）说：3D 内容应该**像视频一样流动**。1 亿泼溅的 3DGS 世界在手机浏览器上秒开。
→ [Spark 2.0 详解](spark_2_0_3dgs_web_renderer_world_labs_2026.md)

同一天发布。看起来一个做 AI，一个做渲染，毫无交集。

但把它们并排看，一个更深的主题浮现了。

---

## 1. First Principle：瓶颈不在智能，在 3D 表征

### 语言表征已经解决了

GPT-3 的历史意义不在于它"能写文章"——在于它证明了**通用语言表征是可能的**。有了好的 language embedding，下游任务（翻译、问答、代码、推理）只需要少量适配。

### 图像表征基本解决了

CLIP / DINOv2 / SigLIP 为 2D 图像做了同样的事。有了好的 visual embedding，物体识别、场景理解、图文匹配都变成了下游微调。

### 3D 表征还没解决

**这是当前具身智能的真正瓶颈。**

没有一个"3D 世界的 GPT-3"——一个在海量 3D 数据上预训练的基础模型，能让所有下游 3D 任务（操作、导航、建图、重建）只需要少量适配。

**VGA 和 Spark 2.0 从两端逼近这个缺口：**

```
VGA 从"智能端"说：
  如果 3D 表征够好（VGGT），36K 场景就能让机器人操作超过 VLM + 万亿 token

Spark 从"基础设施端"说：
  如果 3D 内容能像视频一样流动（.RAD + LoD + 虚拟分页），人人都能创建和消费 3D

两者的交叉点：
  当每个人都能轻松创建 3D 内容（Spark）→ 3D 数据爆炸 → 3D 基础模型成为可能 →
  机器人获得真正的 3D 理解（VGA 的路线被验证）→ 具身智能起飞
```

---

## 2. 类比：具身智能正在经历语言智能 2018 年的时刻

| 时间 | 语言智能 | 具身智能（现在） |
|------|---------|---------------|
| **表征缺失期** | Word2Vec 时代：每个任务训一个模型 | 现在：每个机器人任务训一个 policy |
| **表征突破期** | GPT / BERT：通用语言表征出现 | **正在发生**：VGGT / 3DGS 基础模型雏形 |
| **应用爆发期** | ChatGPT：一个模型做所有任务 | **尚未到来**：等待"3D 世界的 GPT" |

VGA 的消融实验给出了最强的信号：**random init → 6.4%，VGGT pretrained → 98.1%**。差距不是 10%、20%——是 **92 个百分点**。这意味着 3D 预训练不是"锦上添花"，它**就是全部**。

这和 BERT 时代的发现惊人相似——随机初始化的 Transformer 在下游任务上几乎无用，但预训练后的 BERT 在所有 NLP benchmark 上碾压。

## 3. Spark 2.0 是"3D 内容的 HTTP"

语言智能的爆发需要两个条件：
1. **表征**：GPT/BERT（能理解语言）
2. **基础设施**：互联网/HTTP（语言内容能自由流动）

类比：

| | 语言 | 3D |
|--|------|-----|
| 表征 | GPT / BERT | VGGT / 3D 基础模型 |
| 基础设施 | HTTP + 浏览器 | **Spark 2.0 + .RAD + WebGL2** |
| 内容格式 | HTML / Markdown | **.RAD（3DGS 的 MP4）** |
| 创作工具 | WordPress / 记事本 | **Marble（AI 生成 3D）** |

Spark 2.0 做的事情本质上和 HTTP 一样——让 3D 内容可以在网络上自由流动，任何设备都能消费。

**没有 HTTP 就没有互联网内容爆炸 → 没有互联网内容就没有 GPT 的训练数据。**

同理：**没有 Spark 这样的 3D 基础设施 → 3D 内容不会爆炸 → 3D 基础模型缺训练数据 → VGA 路线的上限被锁死。**

## 4. 两者合体后的未来想象

### 想象 1：机器人的"3D 原生思维"

```
当前机器人的思维链路：
  3D 世界 → 📷 2D 图像 → VLM（2D 思考） → Action Head（回到 3D）
                         ↑ 信息瓶颈

未来的思维链路（VGA + Spark 路线）：
  3D 世界 → 3DGS 重建（Spark） → 3D backbone（VGGT） → 3D 动作（VGA）
                               ↑ 全程 3D，无瓶颈
```

机器人不再"看照片然后想象 3D"——它直接在 3D 空间中感知、思考、行动。就像人类不会把世界压成照片再理解——我们天然在 3D 中认知。

### 想象 2：相机标定的消亡

当前每个机器人系统都要做相机标定（hand-eye calibration）。这是一个繁琐的工程步骤。

但 VGGT **自动预测相机参数**作为副产品。Spark 2.0 处理**任意视角**的渲染。

两者结合：机器人**不需要知道相机在哪**——它从多张图直接推断 3D 结构，顺便知道了相机的位置。"相机标定"这个概念可能像"拨号上网"一样成为历史。

### 想象 3：新的数据飞轮

```
Spark 降低 3D 创作门槛
     ↓
更多人创建 3DGS 内容（扫描房间、工厂、商店）
     ↓
海量 3D 数据产生
     ↓
训练更强的 3D 基础模型（VGGT 的下一代）
     ↓
VGA 路线变得更强（98% → 99.5%）
     ↓
更多机器人部署 → 机器人自己也在产生 3D 数据
     ↓
飞轮加速
```

这和 Sergey Levine [在 PI 访谈中](../vla-core/physical_intelligence_sergey_levine_foundation_model_vision_2026.md)说的"bootstrap 冷启动"是同一个问题——但解法不同。Levine 期待机器人自身"变得足够有用"来启动飞轮。Spark + VGA 路线暗示了另一条路：**让非机器人用户的 3D 内容创作来喂养机器人的 3D 理解**。

### 想象 4：Sim2Real gap 的根本解法

Sim2Real 之所以难，是因为仿真器的渲染和真实世界长得不一样——机器人在仿真里学到的视觉特征在真实世界中不 work。

但如果感知 backbone 不是在 RGB 像素上工作，而是在 **3D 几何**上工作呢？

- 仿真器的 3D 几何是精确的
- 真实世界的 3D 几何（通过 3DGS 重建）也是精确的
- 两者在几何空间中几乎一致——**gap 消失了**

VGA 的零样本跨视角泛化（58% vs π₀.₅ 的 52%）已经初步验证了这一点：3D 表征天然更鲁棒，因为它不依赖像素级外观。

### 想象 5：3D 作为人机共享的"思维空间"

李飞飞说："文本成为了软件的通用接口；3D 正在成为空间的通用接口。"

如果机器人用 3D 思考（VGA），人类也能看到机器人的 3D 思考（Spark），那么 3D 就成了**人机共享的思维空间**：

- 机器人在 3D 空间中规划轨迹 → Spark 实时可视化给操作员
- 操作员在 3D 场景中标注"这个区域危险" → 机器人直接在 3D 表征中接收
- 调试时不是看 2D 注意力热图，而是在 3D 空间中看"机器人关注哪些几何结构"

## 5. 最大的未解问题

### ❓ 3D 预训练数据从哪来？

VGA 用了 36K 3D 场景就超过了万亿 token 的 VLM。但 36K 对一个"基础模型"来说太小了。需要的是**百万到十亿级的 3D 场景**。

来源候选：
- Objaverse（~80 万 3D 物体）
- Habitat/AI2THOR/RoboGen 仿真生成
- **每一个 Spark 用户的 3DGS 扫描**——这是最大的潜力来源
- 自动驾驶的 LiDAR 数据（Waymo、nuScenes 等）

### ❓ 语言能力会不会被牺牲？

VGA 把语言降格为"条件输入"。但真实世界的指令很复杂——"把最贵的物品放到安全的地方"需要常识推理，这是 VLM 的强项。

最终答案可能不是 VGA 替代 VLA，而是**两者融合**——3D backbone 做空间推理，VLM 做语义推理，两者在中间层融合。这回到了 [研究主线](../vla-core/vla_research_mainline.md)中"双系统架构"的讨论。

### ❓ 3D 基础模型的 Scaling Law 是什么？

语言模型有明确的 Scaling Law：loss ∝ N^(-α)。3D 呢？

VGA 只测了一个数据点（36K 场景 → 98.1%）。我们需要：
- 3.6K 场景 → ?%
- 360K 场景 → ?%
- 3.6M 场景 → ?%

**如果 3D 也有 Scaling Law，那第一个发现它的团队将拥有巨大的先发优势**——因为他们知道该投多少算力和数据。
