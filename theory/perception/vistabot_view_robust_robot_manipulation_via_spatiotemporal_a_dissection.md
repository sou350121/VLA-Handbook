## 1. 核心架构/方法总览 (Overview / Architecture)

VistaBot 是一个三层流水线：4D 几何估计 → 时空隐特征提取 → 闭环策略执行。核心思想是"把任意测试视角翻译回训练视角的隐空间"，而不是让策略本身学习跨视角不变性。

### 1.1 系统对比概览 (System Component Comparison)

| 组件 | 输入 | 输出 | 训练/推理 | 频率/时序 |
|------|------|------|-----------|-----------|
| VGGT 几何估计 | 训练视角 I_t + 测试视角 I_n | 相对位姿 T_{n→t} + 深度图 D_n | VGGT 预训练 + 少量具身数据微调 | 每帧推理 |
| 点云变换+渲染 | I_n, D_n, T_{n→t}, K | 训练视角渲染图 I_r + 投影掩码 M_r | 确定性计算，无学习 | 每帧推理 |
| 时空插值渲染 | I_r, M_r, T_n, T_t | 多帧插值图像序列 | 确定性计算 | 每帧推理 |
| CogVideoX VDM | 插值图像序列 + 历史记忆帧 | 扩散隐特征 F_obs（从最终 DiT 块提取） | VDM 微调（条件生成） | 每帧推理 |
| ACT/π0 策略 | F_obs + F_state | 动作块（action chunk） | 模仿学习（50 演示/任务） | 每帧推理 |

### 1.2 关键机制 (Key Mechanism)

**为什么这样设计？**

1. **几何先验解决结构一致性**：纯生成模型（如 LangScene-X）缺乏物理约束，容易产出"融化"的帧。VGGT 提供的深度和位姿确保点云变换的几何正确性。
2. **扩散模型解决遮挡补全**：点云渲染有孔洞（遮挡 + 视角差异），VDM 在掩码条件下 inpaint 填补缺失区域，同时保持视觉一致性。
3. **隐空间而非像素空间**：直接在 VDM 的 DiT 隐特征上训练策略，省去了 VAE 解码 + 策略视觉编码的两步开销，推理效率更高。
4. **时空插值平滑过渡**：不在单一帧上做 inpaint，而是沿相机轨迹插值多帧（公式 3），让 VDM 看到"视角变化的过程"而非"突变"，生成质量显著提升。
5. **时序记忆保证闭环稳定**：缓存上一帧观察并通过 cross-attention 注入 DiT，确保连续帧之间的时序一致性。

⚡ **Eureka Moment**：策略不需要学习跨视角不变性——只需要在推理时把测试视角的感知表示"翻译"回训练视角的隐空间，原有策略就能直接工作。

## 2. 数学核心 (Math Core)

### 📌 Napkin Formula（一行抓住本质）

```
a_t = π(F_obs, F_state)
其中 F_obs = ExtractLatent(VDM(Inpaint(proj(T_{n→t} · proj^{-1}(I_n, D_n, K)), M_r)))
```

直觉：动作 = 策略(扩散隐特征, 机器人状态)。策略的视觉输入不是原始图像，而是经过"几何变换 + 扩散补全 + 隐空间编码"的翻译表示。

### 2.1 核心方程拆解

**步骤 1：几何估计（VGGT）**
```
D_n, T_{n→t} = VGGT(I_n, I_t)
```
- D_n ∈ R^{h×w}：测试帧深度图
- T_{n→t} ∈ SE(3)：测试视角到训练视角的相对位姿
- K ∈ R^{3×3}：相机内参（假设已知）

**步骤 2：点云变换**
```
P_t = T_{n→t} · proj^{-1}(I_n, D_n, K)
I_r = proj(P_t, K)
```
- proj^{-1}：逆透视投影，将 2D 像素 + 深度升维为 3D 点云
- proj：透视投影，将 3D 点云渲染为 2D 图像

**步骤 3：时空插值**
```
T(t) = t · T_n + (1 - t) · T_t,  t ∈ [0, 1]
```
- 沿相机位姿轨迹线性插值，生成多帧中间视角
- 每帧独立渲染点云，形成平滑过渡序列

**步骤 4：VGS 评估指标**
```
VGS = (1/N) · Σ_{i=1}^{N} S(θ_i) / S(θ_0)
```
- S(θ_i)：视角 θ_i 下的任务成功率
- S(θ_0)：训练视角（基准）下的成功率
- VGS 越接近 1，跨视角鲁棒性越强

### 2.2 符号说明

| 符号 | 含义 | 维度 |
|------|------|------|
| I_t, I_n | 训练视角/测试视角 RGB 图像 | R^{h×w×3} |
| D_n | 测试帧深度图 | R^{h×w} |
| T_{n→t} | 相对位姿（测试→训练） | SE(3) |

### 4.1 推理延迟与吞吐

| 组件 | 估计延迟 | 说明 |

| CogVideoX VDM | ~500-1500ms | 扩散模型去噪（20-50 步），主要瓶颈 |
| ACT/π0 策略 | ~10-50ms | Transformer 前向传播 |
| **总流水线** | **~3 Hz** | 论文明确给出（§IV-A Real Robot） |

**工程含义**：
- 3 Hz 的控制频率适合桌面操作（开门、抓取、放置），但不足以应对高速动态任务（如接住掉落物体、快速操作传送带物品）。
- VDM 是主要延迟瓶颈。如果 CogVideoX 可以用更少的去噪步数（如 10 步）或蒸馏版本，频率可提升至 5-10 Hz。
- 隐空间策略设计（跳过 VAE 解码 + 视觉编码）节省了约 50-100ms，这是关键优化。

### 4.2 内存与部署约束

- **VGGT**: 需要加载预训练几何模型（约 1-2 GB 显存）
- **CogVideoX**: 视频扩散模型，需要 3D VAE + DiT（约 8-20 GB 显存，取决于模型大小）
- **ACT/π0**: ACT 较小（~100 MB），π0 较大（~10 GB）
- **总显存需求**: ACT 组合约 10-22 GB，π0 组合约 20-32 GB

### 6.3 隐含假设 (Hidden Assumptions)

1. **相机内参 K 已知**：论文假设 K 在训练和测试时一致且已知。实际部署中，更换相机或重新安装会导致 K 变化。
   - *风险*：K 误差会直接传播到点云重建质量，影响后续所有步骤。
   
2. **场景在单次操作期间静态**：点云变换假设环境不变。如果有移动物体或人在场景中走动，几何估计会混乱。
   - *风险*：动态场景下 VGGT 的深度估计可能不稳定。

3. **VGGT 微调数据覆盖目标场景**：论文提到用"少量"模拟+真实数据微调 VGGT，但未公开数据量。
   - *风险*：如果微调数据不足，VGGT 在机器人手臂/夹爪等具身物体上的深度估计可能不准确。

4. **训练视角与测试视角的旋转轴固定**：实验仅围绕垂直轴旋转，不涉及俯仰/翻滚变化。
   - *风险*：实际部署中相机可能有任意 6-DOF 位姿变化，本文方法在俯仰/翻滚方向上的泛化能力未知。

5. **VDM 在未见过的场景泛化**：VDM 在训练数据分布外生成新视角时，可能产生合理的但几何错误的图像。
   - *风险*：隐特征中的几何错误会被策略放大，导致操作失败。

**面试 Tip**：当被问到"VistaBot 和传统数据增强（如随机裁剪/旋转）有什么区别"时，回答：「数据增强是在输入像素层面做变换，策略需要自己学习跨视角不变性——这在高维视觉空间中极难。VistaBot 是在几何+隐空间层面做变换，把测试视角'翻译'回训练视角的表示，策略不需要学习不变性，只需要处理'熟悉的'表示。这是'翻译'vs'学习'的本质区别。」
