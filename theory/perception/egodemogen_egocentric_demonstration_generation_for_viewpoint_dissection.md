### 1.2 关键机制 (Key Mechanism)

**为什么这样设计？**

1. **轨迹 - 视觉解耦**：EgoTrajTransfer 处理动作坐标系变换，EgoViewTransfer 处理视觉合成——两者独立但通过时间戳对齐
2. **运动 - 技能分段**：根据夹爪状态将轨迹分为自由空间运动段（用缩放 + 对齐）和接触操作段（用刚体变换）
3. **自监督训练**：双重重投影策略从单视角数据构造训练对，无需多视角采集
4. **IK 过滤**：自动剔除不可行视角，保证生成演示的运动学可行性

⚡ **Eureka Moment**：第一人称视角变化 ≠ 第三人称视角变化——前者同时改变相机和动作坐标系，因此必须联合迁移动作和合成观察，单独做视角合成会导致视觉 - 动作不匹配。

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：

```
目标：生成 (Ṽ, Q̃, v_nov) 使得 Ṽ 与 Q̃ 在视角 v_nov 下视觉 - 动作一致
```

**核心方程**：

```
Q̃ = T(Q; ΔT)          # 轨迹迁移算子
Ṽ = G(V, Q̃; ΔT)       # 条件视频生成器
```

**轨迹迁移（运动段）**：

```
p_new(t) = R_align · (p_old(t) - p_start_old) · s + p_start_new
其中 s = ||p_end_new - p_start_new|| / ||p_end_old - p_start_old||
R_new(t) = Slerp(R_start_new, R_end_new; α(t))
```

**轨迹迁移（技能段）**：

```
T_e_new(t) = ΔT · T_e_old(t)    # 刚体变换
```

**视频生成目标**：

```
L = E_{t,ε}[||ε - ε_θ(z_t, V_S^train, V_R^train, t)||²]
```

**变量说明**：

| 符号 | 含义 | 单位/维度 |
|------|------|-----------|
| Q | 源关节轨迹 | $T \times d$ ($d=$关节自由度) |
| Q̃ | 迁移后轨迹 | $T \times d$ |
| $\Delta T$ | 视角变换矩阵 | $\mathrm{SE}(3) \in \mathbb{R}^{4 \times 4}$ |
| V | 源观察视频 | $T \times H \times W \times 3$ |
| Ṽ | 合成观察视频 | $T \times H \times W \times 3$ |
| T_e | 末端执行器位姿 | SE(3) |
| s | 路径缩放因子 | 标量 |
| R_align | 路径方向对齐旋转 | SO(3) |
| z_t | 扩散过程噪声潜变量 | 潜空间维度 |
| $\varepsilon_\theta$ | 去噪网络 | 神经网络 |

> 符号与本文/相关文档保持一致：$\Delta T$ 表示由机器人基座运动 $(\Delta x, \Delta y, \Delta \theta)$ 诱导的坐标变换，$v_{\text{nov}}$ 表示新第一人称视角参数。

**直觉解释**：轨迹迁移的核心是"运动段缩放对齐，技能段刚体变换"——自由空间移动可以缩放路径，但接触操作必须保持相对物体的精确位姿。视频生成的核心是"解耦条件"——场景视频编码视角几何，机器人视频编码动作轨迹，两者独立但时间对齐。

## 3. 带数字走一遍：玩具例子 (Worked Example)

假设我们有一个"拿起碗"的演示，源视角 v_src = (0, 0, 0)，新视角 v_nov = (0.05m, 0, 5°)。

**步骤 1：轨迹分段**
- 源轨迹 Q 共 120 帧
- 夹爪状态：帧 1-40 张开（运动段），帧 41-80 闭合（技能段），帧 81-120 张开（运动段）

**步骤 2：运动段迁移**
- 运动段 1（帧 1-40）：
  - 源起点 p_start_old = (0.3, 0, 0.5)m，终点 p_end_old = (0.3, 0.2, 0.3)m
  - 新起点 $p_{\text{start\_new}} = \Delta T \cdot p_{\text{start\_old}} = (0.34, 0.02, 0.5)\,\text{m}$
  - 新终点 $p_{\text{end\_new}} = \Delta T \cdot p_{\text{end\_old}} = (0.34, 0.22, 0.28)\,\text{m}$
  - 缩放因子 s = ||p_end_new - p_start_new|| / ||p_end_old - p_start_old|| ≈ 1.02
  - 对中间 38 帧应用公式 $p_{\text{new}}(t) = R_{\text{align}} \cdot (p_{\text{old}}(t) - p_{\text{start\_old}}) \cdot 1.02 + p_{\text{start\_new}}$

**步骤 3：技能段迁移**
- 技能段（帧 41-80）：直接应用刚体变换 $T_{e\_new}(t) = \Delta T \cdot T_{e\_old}(t)$
- 保持碗 - 夹爪相对位姿不变

**步骤 4：IK 求解**
- 对每帧 T_e_new(t) 用 CuRobo 求解关节角 q̃_t
- 假设 IK 成功率 98%（2 帧失败，用相邻帧插值）
最大关节跳变 $0.05\,\text{rad} < \tau_{\text{jump}} = 0.1\,\text{rad}$，通过过滤

**步骤 5：视频合成**
- 场景视频：重投影源视频到 v_nov，遮罩机器人区域，INPAINT 修复
- 机器人视频：用 Q̃ + URDF + 相机参数渲染
- EgoViewTransfer 输入 48 通道（场景 24 + 机器人 24），输出合成视频 Ṽ

**最终输出**：新演示 (Ṽ, Q̃, v_nov)，120 帧，视觉 - 动作时间对齐。

- 需要准确 URDF 模型和相机内外参标定

- 视角范围 vs IK 可行性：大视角迁移提高泛化但 IK 失败率上升

## 6. 能力与失败模式 (Capabilities & Failure Modes)

**能做什么**：
- 在 Δx,Δy ∈ [-0.1, 0.1]m, Δθ ∈ [-10, 10]° 范围内生成视角 - 动作一致的新演示
- 同时提升标准视角和新视角下的策略性能（实机 +16.0%/+23.0%）
- 处理基座 - 相机解耦场景（Table 6：额外相机扰动下仍有 +15.5% 提升）

**不能做什么**：
- 大视角迁移（>0.2m 或>25°）：IK 失败率急剧上升，生成质量下降
- 跨物体/跨任务泛化：仅在同一任务内迁移视角
- 动态场景：假设场景静态，重投影假设几何不变
- 无 URDF/无标定场景：依赖准确的机器人和相机参数

### 6.1 隐含假设 (Hidden Assumptions)

1. **相机刚性安装在机器人头部**：视角变化完全由基座运动诱导——实际中手持相机或柔性安装不成立
2. **场景几何静态**：重投影假设场景不变——动态物体或可动物体会导致伪影
3. **IK 可解**：假设迁移后端位姿在机器人工作空间内——大视角迁移时可能不可达
4. **单任务内迁移**：假设源和目标视角执行同一任务——跨任务迁移未验证
5. **准确标定**：依赖相机内外参和 URDF 精度——标定误差会累积到生成质量
