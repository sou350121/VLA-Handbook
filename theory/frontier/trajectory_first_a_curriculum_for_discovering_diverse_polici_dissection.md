### 1.2 关键机制 (Key Mechanism)

本文的核心创新不是一个新的损失函数或网络架构，而是一个**课程学习框架**，解决了一个被忽视的问题：**多样性优化中的探索瓶颈**。

**问题诊断**：在接触密集型任务（如按钮按压、方块翻转）中，从动作到多样化物体状态的映射是非平滑的，由接触不连续性主导。这意味着：
- 策略空间的局部梯度无法在高质量行为模式之间"跳跃"
- 多样性目标仍然坍缩到单一局部最优（例如所有策略都用机器人同一部位按按钮）
- 噪声探索在碰撞惩罚任务中适得其反（频繁碰撞 → 负奖励 → 策略学会不操作）

**解决方案 — 两阶段课程**：

**Stage 1 — 约束新颖性搜索 (CNS)**：
- 用 B-spline 参数化开环轨迹 τ(ω)，控制点 ω ∈ R^{m×u}
- 用 CMA-ES 在轨迹空间做黑盒优化，最大化多样性熵，同时约束轨迹回报 ≥ α·v*
- 输出：n 条多样化的高回报轨迹锚点

**Stage 2 — 策略蒸馏**：
- 将 CNS 轨迹作为离线数据，用 Domino 框架蒸馏为 n 个反应式策略
- 三个关键稳定化技术：对称采样、v_max-trick、高策略 UTD

⚡ **Eureka Moment**：多样性优化的瓶颈不在"如何平衡奖励与多样性"，而在"如何发现不同的优质行为模式"——先在轨迹空间探索，再蒸馏为策略，比在策略空间直接优化有效得多。

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：

```
Stage 1:  max_Ω Diversity(Ω)  s.t.  v_ωᵢ ≥ α·v*,  ∀ωᵢ ∈ Ω    (CNS in trajectory space)
Stage 2:  max_Π Diversity(Π)  s.t.  J(π) ≥ α·v*,  ∀π ∈ Π      (Domino in policy space)
```

**目标**：学习 n 个策略集合 Πⁿ，在满足每个策略回报 ≥ α·v* 的前提下，最大化策略间的行为多样性。

**多样性度量**（最近邻距离）：

```
Diversity(Πⁿ) = (1/n) · Σᵢ min_{j≠i} || E_{s~ρ_πᵢ}[φ(s)] - E_{s~ρ_πⱼ}[φ(s)] ||²
```

其中 φ(s) 是状态特征映射（手动定义或学习），ρ_π 是策略 π 诱导的状态占用测度。

**Stage 1 目标函数**（CNS Lagrangian）：

```
L(τᵢ, λᵢ) = Σ_{(s,a)∈τᵢ} { [1-σ(λᵢ)] · log(min_{τⱼ} ||φ(sᵢ) - φ(sʲ)||₂) + σ(λᵢ) · r_ext(sᵢ, aᵢ) }
```

- σ(λᵢ) 是有界 Lagrange 乘子（通过 sigmoid 约束）
- 第一项是内在新颖性奖励（最大化与最近邻的距离）
- 第二项是外在任务奖励
- CMA-ES 优化 B-spline 控制点 ωᵢ

**Stage 2 内在奖励**（Domino diversity gradient）：

```
r_int(s, a | z) = φ(s)ᵀ · (φ̄_z - φ̄_j),  其中 φ̄_j = argmin_{j≠z} ||φ̄_z - φ̄_j||₂²
```

- φ̄_z 是技能 z 的期望状态特征
- 内在奖励推动当前技能的状态分布远离最近邻技能

**v_max-trick**（稳定化关键）：

```
v* ← max{v*, maxᵢ vᵢ}
```

- 单调递增地跟踪所有技能的历史最优回报
- 避免 v* 估计波动导致的策略非平稳性
- 早期 v* 较低 → 多样性目标优先；后期 v* 升高 → 任务性能压力增加 → 隐式课程

**符号说明**：

| 符号 | 含义 |
|------|------|
| Ωⁿ | n 条轨迹的参数集合 {ωᵢ} |
| Πⁿ | n 个策略的集合 {πᵢ} |
| φ(s) | 状态特征映射 S → R^f |
| v* | 最优策略回报的估计值 |
| α | 次优性约束系数 ∈ [0,1] |
| σ(λᵢ) | 有界 Lagrange 乘子 |
| UTD | Update-to-Data ratio |

> 符号与本文保持一致。φ 在文中既用于状态特征也用于特征期望 φ̄，上下文区分。

## 3. 带数字走一遍：玩具例子 (Worked Example)

以**按钮按压任务**为例，假设训练 5 个技能（n=5），B-spline 有 m=20 个控制点，控制维度 u=7（7-DOF 机械臂）。

**Stage 1 — CNS 探索**：

```
初始化: 5 条随机 B-spline 轨迹 {ω₁, ..., ω₅}
CMA-ES 迭代 500 代:

代 0:   所有轨迹都尝试用末端执行器按按钮 → 多样性 = 0.02
代 50:  ω₃ 发现用肘部碰按钮 → 多样性 = 0.35
代 150: ω₅ 发现用前臂侧面推按钮 → 多样性 = 0.72
代 300: ω₁ 发现从侧面滑入按按钮 → 多样性 = 1.15
代 500: 5 条轨迹覆盖 5 种不同接触模式 → 多样性 = 1.83

最终回报: [92, 88, 95, 91, 87] (归一化到 [0,100])
v* 估计 = 95 (最优轨迹回报)
α = 0.8 → 约束: 每条轨迹回报 ≥ 76 → 全部满足 ✓
```

**Stage 2 — 策略蒸馏**：

```
离线数据: 5 条 CNS 轨迹 × 200 步 = 1000 个 (s,a) 样本
在线数据: 每步环境交互产生新样本

对称采样: 每个 batch 50% CNS + 50% 在线
  → Batch = [τ₁[0:25], τ₂[0:25], ..., s_online[0:50]]

v_max-trick 演进:
  Step 0:    v* = 95 (CNS 最优)
  Step 5000: v* = max(95, 88) = 95  (π₁ 回报 88, 尚未超过 CNS)
  Step 15000: v* = max(95, 97) = 97 (π₃ 在线学习后超过 CNS)
  Step 30000: v* = max(97, 96) = 97 (稳定)

UTD 设置:
  Critic 更新: 每步 1 次
  Policy 更新: 每步 8 次  (高策略 UTD)
  → 策略能快速适应不断变化的内在奖励景观

最终结果 (5 seeds 平均):
  多样性: 1.5x 优于 Domino
  回报:   与 Domino 持平 (~92)
```

**关键洞察**：CNS 阶段找到的 5 种接触模式（末端执行器、肘部、前臂、侧面滑入、...）为策略蒸馏提供了"行为锚点"。没有这些锚点，Domino 在策略空间中只能找到 1-2 种模式（因为梯度无法跨越接触不连续性）。

## 4. 工程视角 (Engineering View)

| 维度 | 数值/设计 | 工程含义 |
|------|-----------|----------|
| B-spline 控制点数 | m=20 (论文未明确给出，典型值) | 参数空间 m×u ≪ 策略网络参数量，CMA-ES 高效 |
| CNS 迭代次数 | 500 代 (典型) | 每代 n 次轨迹评估 → 总样本 ≈ 500×n，可接受 |
| SAC 核心算法 | 双 Q 网络 + 目标网络 + 熵正则 | 标准 off-policy 算法，实现成熟 |
| 对称采样比例 | 50% CNS + 50% 在线 | 防止多样性坍缩；CNS 数据选 top 25% 回报 |
| v_max-trick | 历史最大值跟踪 | 消除 v* 估计方差，减少目标非平稳性 |
| 策略 UTD | 8 次/步 | 与标准 offline-to-online 相反（通常 critic UTD 高） |
| 技能编码 | one-hot z ∈ {0,1}ⁿ | 单网络多技能，参数量不随 n 线性增长 |
| 特征维度 f | 取决于任务（位置/接触力/姿态） | 手动定义，非学习 — 限制了泛化性 |

**部署约束**：
- 两阶段训练，Stage 1 (CNS) 和 Stage 2 (SAC) 顺序执行
- 推理阶段仅需反应式策略 π_z(a|s)，无需轨迹优化 — 推理延迟与标准 SAC 相同
- B-spline 设计需要任务先验（控制点数、 horizon），不 fully automatic

### 6.1 隐含假设 (Hidden Assumptions)

1. **状态可完全观测**：所有实验基于精确状态（非图像），VLA 场景下需要从图像提取 φ(s)
2. **仿真到真实的 gap 可忽略**：未做 real-world 验证，CNS 在仿真中找到的轨迹可能在真实物理中不可执行
3. **特征空间足够表达多样性**：φ(s) 的手动设计决定了"什么算多样性"——如果特征空间选择不当，多样性度量会失真
4. **CNS 样本效率足够**：CMA-ES 需要 500 代 × n 条轨迹评估，在真实机器人上可能不可行
5. **v* 可估计**：v_max-trick 假设至少有一个技能能达到接近最优的回报；如果所有技能都远次优，约束会过松
