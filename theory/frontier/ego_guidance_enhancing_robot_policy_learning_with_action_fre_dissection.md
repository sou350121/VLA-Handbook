## 1. 核心架构/方法总览 (Overview / Architecture)

先划清一个关键边界：本文的输入是**当前观测** o_t（primary camera + wrist camera 图像）与任务指令；生成专家预测的是**未来帧** o_{t+Δ} 的表征 Z_t = φ(o_{t+Δ})，它是监督目标而非输入。论文没有把未来帧回灌为历史上下文，也没有描述多帧历史堆叠。动作 chunk A_t = a_{t:t+H} 是未来动作序列，H=8 是预训练/LIBERO 的动作块设置；真实机器人实验中两个模型都预测 50-step action chunks，H=8 不是全文通用的“记忆窗口”。

### 1.2 关键机制 (Key Mechanism)

- **为什么不用 WAM**：World Action Model 在生成 latent 空间做扩散，链路更复杂；SPAR 从已优化好的 VLM 出发，扩展成 MoT，联合优化动作预测和视觉状态预测。
- **两个专家不互相 attend**：动作专家和生成专家各自参数独立，只 cross-attend 到共享的 ℋ。因此生成损失不能直接“告诉”动作专家怎么做，只能通过重塑共享 hidden states 间接影响策略。
- **人类视频只监督生成专家**：机器人数据同时监督 L_action 和 L_gen；egocentric 视频没有动作标签，只监督 L_gen。动作专家只由机器人数据更新。
- **推理删除生成专家**：按 Fast-WAM 的做法，部署时只保留 VLM + action expert，动作由 4 步 Euler 积分得到。作者主张部署架构和成本与标准 VLA 相同。
- **目标选择有讲究**：学习到的视觉表征比重建导向的 Wan-VAE latent 更有效；单帧预测与四帧预测几乎持平；回归目标也能工作。

⚡ **Eureka Moment**：把“未来视觉预测”从世界模型的一部分，降级成一个只正则化共享表征的辅助专家；它不与动作专家通信，推理时删掉，所以 human video 的收益被强制走“表征”这条窄路。

### 1.3 信息流/架构图 (Flow / Diagram)

```
机器人数据 ──> VLM backbone (Qwen3.5-2B) ──> ℋ ──┬──> action expert ──> A_t
                                                └──> generation expert ──> Z_t
egocentric 视频 ──> 同一 VLM backbone ──> ℋ ───────> generation expert ──> Z_t
                                      ↑
```

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**：

```
L = L_action(robot) + λ·L_gen(robot) + λ·L_gen(ego),  λ = 1
```

目标：联合训练动作预测与未来视觉表征预测；人类视频只进入 L_gen，动作通路只由机器人数据监督。

```
动作流匹配：
x^s = (1-s)·ε + s·x,  ε ~ N(0,I),  s ∈ [0,1]
L_action = E_{s,ε} [ (1/(H·d_a)) · || f_ψ(A_t^s, s; ℋ) - (A_t - ε) ||²_2 ]

生成流匹配：
L_gen^flow = E_{s,ε,t} [ (1/(N·d)) · || g_ω(Z_t^s, s; ℋ) - (Z_t - ε) ||²_2 ]

生成回归：
Z̄_t = (Z_t - μ_φ) / σ_φ
L_gen^reg = E_t [ (1/(N·d)) · || g_ω(ℋ) - Z̄_t ||²_2 ]

总损失：
L_robot = L_action + λ·L_gen
L_ego   = λ·L_gen
λ = 1

时间对齐：
τ = H / f_R
Δ_s = floor(τ·f_s + 1/2)
```

| 符号 | 含义 |
|------|------|
| ℋ | VLM 每层 hidden states，动作/生成专家通过 cross-attention 读取 |
| H | 动作 chunk 长度；本文预训练/LIBERO 为 8 |
| d_a | 动作维度；预训练为 7 |
| A_t | 未来动作 chunk a_{t:t+H} |
| Z_t | 未来帧 o_{t+Δ} 的表征，φ(o_{t+Δ}) ∈ ℝ^{N×d} |
| N, d | 目标 token 数与维度 |
| φ | 冻结的目标编码器 |
| λ | 生成损失权重，固定为 1 |
| f_R, f_s | 机器人数据/视频流的帧率 |
| τ | 物理时间跨度，τ = H/f_R |
| Δ_s | 视频流上的帧偏移 |

直觉：动作标签是低维、具身特定的监督；未来视觉表征是高维、通用的监督。两个专家互不通信，生成专家不能直接输出动作，只能通过改变 ℋ 让动作专家“看到”更好的表征。人类视频没有动作标签，所以只能走这条通路。

> 符号说明：ℋ 是 hidden states，H 是 action horizon；论文正文两者都用 H/ℋ 附近的记号，这里按语义拆开，避免混淆。

## 3. 带数字走一遍：玩具例子 (Worked Example)

以下数值均为**假设**，只用于验算公式，不代表论文实验。

**（1）时间对齐验算**

```
假设 DROID f_R = 15 Hz，H = 8：
τ = 8/15 ≈ 0.533 s
egocentric f_s = 30 fps：
Δ_s = floor(0.533×30 + 0.5) = floor(16.5) = 16 帧
LIBERO f_R = 20 Hz：
τ = 8/20 = 0.4 s → Δ_s = floor(0.4×20 + 0.5) = 8 帧
```

注意：这是从当前参考 t 预测未来到 t+H，终点距 t 是 H×Δt = 8/15 s，不是 (H-1)×Δt = 7/15 s。若误用 7 帧，30 fps 下会算成 floor(7/15×30+0.5)=14 帧，比论文的 16 帧少 2 帧。论文用 H×Δt，验算通过。

**（2）采样帧跨度验算**

```
假设 30 fps、5 秒 clip、每 10 帧采样：
K = 15 帧
首末跨度 = (K-1)×Δt = 14×(10/30) s = 4.67 s < 5 s
```

这是**已观测/上下文采样帧**的跨度，不是未来预测的 H×Δt。两者不能混：前者是 (K-1)×Δt，后者是 H×Δt。

**（3）损失归一化验算**

```
假设 N=2, d=2
Z_t   = [[1, 0], [0, 1]]
Z_hat = [[0.5, 0.5], [0, -0.5]]
误差  = [[0.5, -0.5], [0, 1.5]]
平方和 = 0.25 + 0.25 + 0 + 2.25 = 2.75
L_reg = 2.75 / (N·d) = 2.75 / 4 = 0.6875
```

验算正确：先逐元素平方，再求和，再除以 N·d。

**（4）流匹配单点验算**

```
x = 1, ε = 0, s = 0.5
x^s = (1-0.5)×0 + 0.5×1 = 0.5
速度目标 = x - ε = 1
若预测 0.8，平方误差 = (0.8-1)² = 0.04
```

验算正确。

## 5. 数据与评测 (Data & Eval)

### 5.1 预训练

- **机器人数据**：从 DROID 筛选成功 episode，去掉无运动、无有效指令或动作标注的片段，得到约 38,000 episodes、230 小时（66% 保留），用于与 egocentric 视频共训练；LIBERO 用于仿真下游微调。最终真实机器人场景会把机器人数据扩展到更多数据集，总计约 8,000 小时，并用内部遥操作演示做下游微调。

- **数据多样性固定预算下没有一致增益**：最高物体多样性甚至更差；作者倾向“扩大数据量”而非“最大化单一多样性”。
- **单阶段训练泛化差**：作者观察，未给数字；默认两阶段。
- **真实机器人统计噪声大**：5 个任务各 10 trials，合计 50 trials/方法，40% vs 44% 对应 20/50 vs 22/50，只差 2 个成功试验。若仅按总体比例做粗略二项近似，p=0.4 时标准误约 sqrt(0.4×0.6/50) ≈ 6.9 个百分点，95% 区间约 [26.4%, 53.6%]；4 个百分点的总体差异仍不大，且任务难度不同，更合适的比较应按 5 个任务分层或配对分析。这是本文的条件性分析，不是论文结论。
- **推理成本未实测**：作者只说生成专家删除后与标准 VLA 相同；没有吞吐/延迟数据。
- **未声明代码/数据开源范围**：复现风险高；本文不引用项目页或代码仓库。

### 6.1 隐含假设 (Hidden Assumptions)

- 未来视觉表征预测能迁移到动作策略；人类 egocentric 视频与机器人任务共享足够的视觉动态结构。
- SigLIP2 特征空间是合适的预测目标；单帧未来足够；回归与扩散的差异不影响任务结论。
- 生成专家删除后策略行为不变（依据 Fast-WAM，但本文未做删除前后的一致性消融）。
- DROID 筛选后的 230 小时足以支撑与 LIBERO 仿真评测配套的预训练；真实机器人场景另将机器人数据扩展到约 8,000 小时。Ego4D 的“可见手”门控能筛出可迁移片段。
- 真实机器人 10 trials 足以比较方法；π0.5 官方权重微调是公平基线。作者自己指出 SPAR 用了更小的机器人预训练语料、动作专家从头训练，因此“可比”本身带有条件。
- 预训练/LIBERO 的 H=8 与未来帧对齐是合理监督时域；真实机器人微调使用 50-step action chunk，动作时域设置需分开看。

## 7. 与相关工作对比 (Comparison)

| 维度 | 标准 VLA（π0/GR00T N1 类） | WAM（世界动作模型） | π0.5 基线 | SPAR（本文） |
|------|---------------------------|---------------------|-----------|--------------|
| 架构 | VLM + action expert | 在生成 latent 空间扩散 | 大规模 VLA | VLM + 两个独立专家（MoT） |
| 监督 | 机器人动作 | 未来生成 + 动作 | 大规模机器人数据 | 动作 + 未来视觉表征；人类视频只监督生成 |
| 人类视频 | 通常不用 | 可用于世界模型 | 本文未涉及 | 只用于 L_gen，无动作标签 |
| 推理 | action expert | 可能需要未来想象 | action expert | 删除生成专家；与标准 VLA 同架构/成本（作者主张） |
| 适用场景 | 通用操作 | 需要未来预测的任务 | 大规模预训练基线 | 想利用无动作 human video 改善 OOD 的 VLA |

注意：WAM 是论文讨论的类别，不是某一个具体模型；π0.5 是本文真实机器人基线；标准 VLA 是概念性对照。表中不写具体指标，避免把不同论文的数字混在一起。

**面试 Tip**：如果被问“SPAR 和世界模型有什么区别”，一句话答：SPAR 不要求模型在推理时想象未来，它只把未来视觉表征预测当作训练期的辅助正则；生成专家与动作专家不互相 attend，推理时删掉，所以收益只能通过共享 VLM 表征进入策略。
