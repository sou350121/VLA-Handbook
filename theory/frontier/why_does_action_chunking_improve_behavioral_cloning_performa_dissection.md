### 1.2 关键机制 (Key Mechanism)

论文系统性地检验了文献中关于动作分块成功的三个常见假设：

**假设 1：时间一致性（Temporal Consistency）**
- 观点：人类演示者产生平滑相关的动作序列，动作分块能更好地建模这种时间相关性
- 论文发现：人类确实表现出非马尔可夫行为（在"决策边界"处会暂停），但**简单的延迟策略**（π(a_t \| o_{t-d})）就能同样好地捕捉这种行为，不需要真正执行动作分块
- 关键实验：在 Libero-90 上，延迟策略的成功率匹配甚至超过动作分块（图 3）

**假设 2：视界缩减（Horizon Reduction）**
- 观点：动作分块将有效视界从 H 降到 H/k，从而降低复合误差
- 论文发现：复合误差的降低主要来自**基于过去观察做预测**（更早的状态分布偏移更小），而非视界缩减本身。延迟策略同样能实现相同的误差降低
- 理论结果：定理 2 证明 AC(k) 和 Delay(d) 在复合误差上界方面达到相同的 O((k+1)^{H/k} · ε) 缩放

**假设 3：表征学习（Representation Learning）**
- 观点：训练动作分块策略作为辅助损失，改善了表征学习和泛化
- 论文发现：仅在前几步有表征收益，更长的延迟下延迟策略提供相同的表征效果

⚡ **Eureka Moment**：动作分块策略 π(a_{t:t+k} \| o_t) 本质上是一个**隐式集成**——它同时学习了 k 个不同的时间关系 {a_t \| o_t, a_t \| o_{t-1}, ..., a_t \| o_{t-k+1}}，类似于随机森林通过聚合不同特征子集上的预测器来降低泛化误差。

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：

```
AC(k) ≈ Ensemble_{i=0}^{k-1} [ π(a_t | o_{t-i}) ]  +  复合误差降低 O((k+1)^{H/k} · ε)
```

**目标**：理解为什么动作分块策略 π(a_{t:t+k} \| o_t) 比单步策略 π(a_t \| o_t) 表现更好。

**核心方程**：

```
J(π_demo) - J(π) ≤ C(H) · ε    （标准 BC 次优性上界）
```

其中：
- J(π) 是策略的期望 episode 奖励（成功概率）
- C(H) 是误差复合速率，随视界 H 增长
- ε 是监督学习损失（验证集 MSE）

**动作分块/延迟策略的改进上界**（定理 2）：

```
J(π_demo) - J(AC(k))    ≤ O((k+1)^{H/k} · ε)
J(π_demo) - J(Delay(d)) ≤ O((k+1)^{H/k} · ε)    ← 相同的缩放！
```

**变量说明**：

| 符号 | 含义 |
|------|------|
| π_demo | 人类演示者策略 |
| π | 学习的策略 |
| H | episode 最大步数（视界） |
| k | 动作分块长度 |
| ε | 策略在演示者轨迹分布上的验证误差 |
| C(H) | 误差复合函数，取决于环境动力学性质 |
| o_t | 时刻 t 的观测 |
| a_t | 时刻 t 的动作 |

**直觉**：动作分块通过两个独立机制降低复合误差——(1) 基于更早的观察做预测（这些状态更接近训练分布），(2) 隐式集成多个时间关系（降低泛化误差）。延迟策略只利用机制 (1)，但在许多场景下已足够；显式集成同时利用 (1) 和 (2)。

> 符号与本文保持一致：π̂ 表示学习的策略，上标表示分块长度，下标 delay 表示延迟策略。

## 3. 带数字走一遍：玩具例子 (Worked Example)

考虑一个简化的 2D 机械臂控制场景：

**设定**：
- 视界 H = 100 步
- 动作维度 d_A = 2（x, y 方向）
- 演示者验证误差 ε = 0.01（归一化 MSE）
- 环境动力学是 1-Lipschitz 的

**单步 Markov 策略**：
```
复合误差上界 = 2^H · ε = 2^100 · 0.01 ≈ 无限大（指数爆炸）
实际表现：成功率低，误差快速累积导致 OOD 状态
```

**动作分块 AC(10)**：
```
有效视界 = H/k = 100/10 = 10
复合误差上界 = (10+1)^10 · 0.01 = 11^10 · 0.01 ≈ 2.6 × 10^9
虽然仍然很大，但相比 2^100 已经是指数级改善
实际表现（Libero-90）：89.2% 成功率
```

**延迟策略 Delay(10)**：
```
复合误差上界 = 相同 O((k+1)^{H/k} · ε)
实际表现（Libero-90）：94.0% 成功率（甚至超过 AC！）
原因：基于 o_{t-10} 做预测，该状态更接近训练分布
```

**随机延迟集成 AC(10)-RDE**：
```
集成效应：每步随机选择延迟 i ∈ {0, ..., 9}
相当于隐式集成 10 个不同的预测器
实际表现（Libero-90）：93.6% 成功率
实际表现（Robomimic Transport）：12.1%（AC: 12.6%，Delay: 7.9%）
```

**显式集成 Delay(n)-Ens**：
```
训练 m=5 个独立策略，集成预测
实际表现（Libero-90）：95.0% 成功率
实际表现（Robomimic Transport）：38.9%（远超 AC 的 12.6%！）
```

**关键洞察**：在 Robomimic Transport 上，显式集成比动作分块提升 3 倍多——这直接验证了"隐式集成是动作分块核心优势"的假设。

## 4. 工程视角 (Engineering View)

| 维度 | 动作分块 AC(k) | 延迟策略 Delay(d) | 随机延迟集成 RDE | 显式集成 Ens |
|------|---------------|------------------|-----------------|-------------|
| **推理延迟** | 每 k 步推理 1 次 | 每步推理 | 每步推理 | 每步推理 × m 模型 |
| **计算吞吐** | 最高（推理频率最低） | 中等 | 中等 | 最低（需运行 m 个模型） |
| **内存占用** | 1 个模型 | 1 个模型 | 1 个模型 | m 个模型 |
| **响应性** | 低（开环执行 stale 动作） | 高（每步新鲜推理） | 高 | 高 |
| **部署复杂度** | 低 | 低 | 低 | 中（需管理多模型） |
| **适用场景** | 推理计算受限 | 通用 | 通用 | 性能优先 |

**工程含义**：

1. **推理-执行交叠**：在真实机器人上，推理暂停会导致环境变化（机器人并非完全静止）。论文采用交叠策略——在当前动作执行完之前就开始计算下一步，但这引入了 1 步的额外延迟。

2. **控制频率的选择**：论文发现 15-20Hz 是最优范围。在 50-60Hz 高频下，延迟策略无法复现动作分块的成功——因为人类视觉引导行为的频率在 2-10Hz 范围，高频采集的动作之间存在强时间相关性，此时动作分块的时间一致性才真正发挥作用。

3. **部署建议**：如果推理计算充足，显式集成（Delay(n)-Ens）在几乎所有场景下都优于标准动作分块。Transport 任务上 +30% 的提升是显著的。如果计算受限，RDE 是零额外成本的改进方案。

### 6.1 隐含假设 (Hidden Assumptions)

1. **平滑确定性动力学**：定理 1-2 假设环境动力学是 1-Lipschitz 的。虽然有附录 B.3 的实验支持，但对于高度非线性或随机性的环境（如松散绳索操作、流体操控），结论可能不成立。

2. **单模态策略分布**：论文使用 MSE 作为验证误差度量，隐含假设策略对于给定观察产生单模态动作分布。对于真正多模态的任务（同一状态有多种正确动作），MSE 会低估策略质量。

3. **演示者质量一致**：所有基准使用"成功"演示，但未分析演示者次优性（suboptimality）对结论的影响。如果演示者本身有系统性偏差，延迟策略可能学到不同的偏差。

4. **观察延迟无代价**：延迟策略假设可以无代价地访问 o_{t-d}。在实际系统中，缓存历史观察可能需要额外内存，且传感器噪声可能随时间累积。
