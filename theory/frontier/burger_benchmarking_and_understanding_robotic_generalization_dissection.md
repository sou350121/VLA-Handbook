## 1. 核心架构/方法总览

### 1.1 系统对比概览

BURGER 本身不是新模型，而是“数据生成管线 + 数据集 + 评估器 + 一组后训练 VLA”。因此组件表要把**管线模块**和**被评测策略**分开归属。

| 组件 | 输入 | 输出 | 训练/推理差异 | 归属 |
|------|------|------|----------------|------|
| Sketch 生成 | 语言模板 prompt | 4×4 网格 PNG（每格一个极简线稿） | 仅离线数据生产 | 用 GPT-Image 2，一次性生成 |
| PNG→Skeleton | PNG | 二值骨架图 | 离线；圆形填充区先做质心抑制 | 算法 1 |
| Skeleton→SVG | 骨架图 + 采样间距 Δ | 有序笔画路径 SVG | 离线；按“先大轮廓后细节、自上而下最近邻”排序 | 算法 2 |
| SVG→轨迹回放 | SVG | 观测-动作对（LeRobot 格式） | 离线；末端位姿控制器，断笔处抬笔 | ManiSkill + SAPIEN 为主，MuJoCo / Isaac Sim 亦实现 |
| 评估器 | 最终画布图 | 目标类相似度分数 | 训练投影头+余弦分类器，DINOv3 主干冻结 | 论文自建，见 §2 |
| 被评测策略 | 指令 ℓ、当前画布 I_t、本体感知 q_t | 末端命令 a_t 或 action chunk | 各自原目标后训练，batch size 32 | π0 / π0.5 / π0-FAST / OpenVLA / OpenVLA-OFT |

**逐模型归属**（本文不把某一模型的属性合并给其他模型）：

| 模型 | 动作生成范式 | 后训练目标 | 论文中的动作 |
|------|--------------|------------|--------------|
| π0 | 独立 action expert + flow matching，连续动作 | 原始 flow-matching 目标 | 保留多模态 rollout |
| π0.5 | flow matching；官方描述为异构任务 co-training 以扩展泛化 | 原始 flow-matching 目标 | 真机微调与闭环交互均用此模型 |
| π0-FAST | autoregressive，FAST action tokenizer | 自回归 token 预测 | 方向坍缩、过度绘制 |
| OpenVLA | autoregressive，逐步离散动作 token | 逐步离散 token 预测 | 局部小圈停滞 |
| OpenVLA-OFT | OpenVLA 的优化微调变体，并行解码预测连续 action chunk | 连续 chunk 预测 | 受 chunk 长度强烈影响 |

### 1.2 关键机制

- **空白画布消除视觉捷径**：初始观测对所有指令完全相同，策略无法从 I_0 反推要画什么，语言必须真正被用上。
- **提示驱动可扩展**：语义复杂度可按“物体 + 属性 + 空间关系”组合式加码，无需重新采数据。
- **同一指令多解**：笔画顺序、起点、方向都合法，因此数据集天然多模态，逼模型学概念而不是背动作序列。
- **可检查性**：最终画布给语义/空间判断，全过程轨迹给动作执行判断（接触、进度、终止）。
- **终止必须学**：episode 在末端抬升超过预设高度阈值时结束，策略得自己决定“画完了”。

⚡ **Eureka Moment**：把“绘画”这个原本属于规划控制的课题，重构成一个**语言条件、天然多模态、结果可肉眼判读**的 VLA 诊断域——用它替代昂贵真机数据，先回答“架构吃得下大数据吗”。

## 2. 数学核心

📌 **Napkin Formula**：
```
数据多样性 ≈ 有效模态数 N_eff = exp(H(p))；策略好坏 ≈ 画布嵌入与目标类中心的余弦相似度
```

**目标一：量化“同一指令下有多少种合法走法”。** 把每条平面末端轨迹重采样为 32 个均匀时间点，拼接起点相对 xy 位置与相邻位移，得到 126 维描述子；标准化后用共享 k-means 码本聚类，再按簇内频率算有效模态数：

```
N_eff(ℓ; k) = exp( - Σ_{j=1..k} p_j · ln p_j )
```

| 符号 | 含义 |
|------|------|
| p_j | 指令 ℓ 下轨迹落入第 j 个簇的比例 |
| k | 码本大小，主结果 k=24，敏感性测 k∈{8,12,16,24,32,48} |
| N_eff | 有效模态数；全部轨迹同簇时为 1，均匀分布时为 k |

直觉：这就是簇分布的指数熵。它奖励“多条互不相同的走法”，惩罚“所有 rollout 挤成一条”。

**目标二：给画得像不像打分。** 冻结 DINOv3，取 CLS token 与平均 patch embedding 拼接，经两层 MLP 投到 256 维并做 L2 归一化，得 z(I)。余弦分类器 logit 为：

```
ℓ_{i,c} = γ · z_iᵀ ( w_c / ‖w_c‖₂ )
```

训练损失：

```
L = L_CE + λ · L_SupCon
```

推理时对每类算训练集嵌入均值再归一化得到类中心 q_c，评分即 `s(I, y) = z(I)ᵀ q_y`。组合任务先按前景像素密度最低的水平/竖直分界线切成两块，分别打分后取平均，并对空间关系错序额外惩罚。

> 符号与本文一致：τ 为对比温度，P(i) 为同类别正样本集，𝒜 为有效锚点集。论文未给出 γ、λ、τ 的具体取值。

## 3. 带数字走一遍：玩具例子

**以下数字为假设，仅用于验算公式，不是论文实测。**

假设（假设）某条指令下 10 条 π0 rollout 被聚成 3 簇，频率 p = (0.5, 0.3, 0.2)：

```
0.5·ln0.5 = -0.3466
0.3·ln0.3 = -0.3612
0.2·ln0.2 = -0.3219
Σ = 1.0297
N_eff = exp(1.0297) ≈ 2.80
```

极端情形校验：4 簇均匀分布时 N_eff = exp(-4×0.25×ln0.25) = exp(ln4) = 4，正好等于簇数，公式自洽。2.80 落在论文报告的 rollout 区间 2.1–6.7 内，量级合理。

**时序跨度验算（同样为假设数值）。** 设某段绘制持续 2.0 s，被均匀重采样到 K=32 个点：

```
Δt = 2.0 / (32-1) ≈ 0.0645 s
首末跨度 = (K-1)×Δt = 31 × 0.0645 ≈ 2.0 s  ✓
```

再设控制周期 Δt = 0.02 s（假设），从当前参考 t 预测未来 H=8 步：

```
预测终点 = t + H×Δt = t + 8×0.02 = t + 0.16 s
```

**关键区分**：这 0.16 s 是“未来预测区间”，它和附录 A.4 里“把轨迹重采样成 32 点”的历史描述**不是同一个东西**——后者是离线聚类用的轨迹表示。论文正文没有任何地方报告观测历史长度或记忆窗口。

## 4. 工程视角

- **chunk 长度是执行一致性的杠杆，不是记忆**。控制圆实验里 OpenVLA-OFT 在 H=1 时 20 次 rollout 只有 6 次建立稳定接触，H=8 时 20/20 建立接触，但 sweep 从 129.3° 涨到 586.1°（数据集参考 359.8°），即“接触好了，但画过头了”。这只是该消融的两个取值，**不能当成所有实验共有的记忆窗口或步长**。
- **终止判据下放到策略**。episode 以末端抬升过阈值为终点，阈值是环境侧超参；工程上这等价于把“停不停”从控制器挪进了策略，代价是过度绘制风险（π0、π0.5 均出现）。
- **真机推理要做多视角笔画重建**。每步需用深度图分割掉机械臂、从前/后两路 RealSense 各估可见笔画区、合并后再喂策略；人手进入画布区时推理暂停。这是每步的真实开销来源，论文未给延迟数字（**待补**）。
- **吞吐/量化误差未报告**。论文只给了 batch size 32 与每个任务 10 个评估 episode，训练时长、显存、推理频率均缺失。

## 5. 数据与评测

**数据（仿真）**：132 个单物体类 + 150 个组合类，每类 100 条，共 28,200 条仿真示范；其中组合 15,000 条，单物体 13,200 条。组合类由 100 个基础类两两配对：100 个左右关系 + 50 个上下关系。数据格式为 LeRobot，每条样本含指令、当前画布观测、本体感知、专家末端动作。

**评测（仿真）**：单物体评测用 10 类（闹钟、苹果、背包、香蕉、浴缸、长凳、自行车、生日蛋糕、蓝莓、书），每任务 10 个 episode，取指标均值；最终画布用于视觉评分，整条轨迹用于失效分析。组合评测在**未见过的物体配对**上做。

**真机设置**：Franka Panda + 绘图工具，前/后双 RealSense。真机数据为 10 个单物体类 × 每类 10 条 = 100 条示范，用开放环回放 SVG 采集（因此采集时不需要闭环视觉）。策略侧：π0.5 在 100 条真机数据上直接微调；另有策略用 13,200 条仿真示范做 co-train 后迁移。真机还验证了视角变化鲁棒性、补画缺失部件（给杯子加把手）、人画完后轮后跳过已完成部件、以及同任务多解。

**指标人评对齐**（表 4，10 类、66 名被试）：Spearman 0.834 vs CLIPScore 0.592；Kendall τ_b 0.655 vs 0.433；成对一致率 0.875 vs 0.803。

**多样性对比**：k=24 时 LIBERO 每条指令 1.09 个有效模态，BURGER 7.13，约 6.6×；附录用 40 条指令、每条约 42 条轨迹的等量设置，k 在 8–48 间扫，LIBERO 稳定在 1.05–1.10，BURGER 从 3.63 升到 9.22。

## 6. 能力与失败模式

| 现象 | 具体表现 | 涉及模型 |
|------|----------|----------|
| 初始位姿敏感 | 卡在局部小区域；或漂离目标绘制区 | OpenVLA；π0-FAST |
| 不终止 | 画完不抬笔，继续画 | π0；π0.5 |
| 过度绘制 | 继续超出预期笔画/单圈 | OpenVLA-OFT (H=8)；π0-FAST |
| 方向坍缩 | CW 占 95%，几何尚可但方向单一 | π0-FAST |
| 起点多样性下降 | 起点熵 0.35–0.63（数据集 0.97） | OpenVLA-OFT；π0-FAST |
| 未见物体失败 | 输出通用、无结构笔画 | π 系全体 |
| 组合退化 | 空间关系对了，物体质量下降；加竖直关系后更明显 | π 系全体 |

**能做的**：已见类别的语言条件绘制、已见关系向未见物体对迁移（如“杯子在苹果左边”）、保留多模态绘制行为（8 个代表任务上训练示范 4.0–7.7 modes，π0 rollout 2.1–6.7 modes）、真机闭环补画。

**不能做的**：未见物体类别、接触丰富介质（无笔刷动力学）、人类自然笔画顺序（顺序来自启发式）。

### 6.1 隐含假设

1. **“会画 = 会操作”的可迁移性**：论文明确承认绘画抽象掉了接触与物体动力学，但未验证绘画上的 scaling 曲线能否预测操作任务上的曲线。
2. **评估器即真值**：所有主结果都用自建 DINOv3 相似度打分，而人评对齐只在 10 个单物体类上做过；组合任务的两块切分 + 关系惩罚没有独立人评。
3. **数据多样性等价于人类多样性**：笔画顺序由启发式生成，作者自己在局限性里承认可能偏离人类示范。
4. **单帧观测足够**：策略只吃当前画布，隐含“画布本身编码了全部历史”这一前提——对绘画成立，对一般操作不成立。
5. **合成图像分布可控**：依赖闭源图像生成模型，prompt 里已硬编码“5–6 笔、正面视角、无纹理”等约束，但生成偏差未量化。

## 7. 与相关工作对比

| 工作 | 关注点 | 形态 | 训练方式 | 适用场景 |
|------|--------|------|----------|----------|
| BURGER（本文） | 语言条件绘画下的 VLA 泛化诊断 | benchmark + 数据管线 | 各模型原目标后训练 | 数据规模化、失效诊断 |

与 FRIDA、IMPASTO 的关键差别：那些工作要解决“怎么画好”，BURGER 要解决“用画来测 VLA”。

🎤 **面试 Tip**：被问“这篇和普通 benchmark 有什么不同”，答：它把评测信号从二值成功率换成了**画布 + 轨迹的双通道可读性**，所以能区分“画对了但停不下来”和“停得对但画歪了”——这两类失效在成功率里是同一个 0。
