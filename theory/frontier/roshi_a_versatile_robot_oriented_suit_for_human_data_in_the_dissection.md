| 时间同步模块 | UTC 时间戳 | 对齐的多模态流 | - | 最近邻时间匹配 |

### 1.2 关键机制 (Key Mechanism)

**为什么这样设计？**

1. **IMU 选 9 个而非满配**：每臂 2 个（上臂 + 前臂）、每腿 2 个（大腿 + 小腿）、骨盆 1 个——覆盖所有主要关节朝向，成本控制在$270
2. **用 Aria 而非普通摄像头**：Aria 自带 SLAM 输出，无需额外跑 VIO 算法，且时间戳与 IMU 同网同步
3. **扩散模型引导而非直接回归**：EgoAllo 在 AMASS 上预训练，有运动先验，IMU 只做"引导"而非完全约束，保持动作自然性
4. **AprilTag 视觉校准**：传统 IMU 校准需要 T 姿势 + 校准盒，RoSHI 用 iPhone 拍 20 秒自然运动视频，自动解算传感器 - 骨骼偏移

⚡ **Eureka Moment**：IMU 提供"局部准确但漂移"的骨骼朝向，Aria SLAM 提供"全局一致但缺身体"的轨迹——用扩散模型做"翻译器"，把两者融合成"全局一致的完整身体"。

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：
```
R^Wp_Bi(t) = R^Wp_Wi · R^Wi_Si(t) · (R^Bi_Si)^T
```
**直觉**：骨骼朝向 = IMU 世界对齐 × IMU 实时读数 × 传感器 - 骨骼偏移逆

### 2.1 符号说明

| 符号 | 含义 | 来源 |
|------|------|------|
| $R^{W_i}_{S_i}(t)$ | IMU 传感器在其局部世界中的朝向 | BNO085 直接输出 |
| $R^{B_i}_{S_i}$ | 传感器到 SMPL 骨骼的固定偏移 | 校准确定 |
| $R^{W_p}_{W_i}$ | IMU 局部世界到骨盆世界的对齐 | 校准确定 |
| $R^{W_p}_{B_i}(t)$ | 最终骨骼在骨盆世界中的朝向 | 公式 (1) 计算 |
| $T^{C}_{W_c}(t)$ | Aria 相机在全局世界中的位姿 | Aria SLAM 输出 |

### 2.2 校准优化（公式 3-4）

传感器 - 骨骼偏移通过多帧 AprilTag 观测的 Barycenter 优化：
```
R̄^Bi_Si = argmin_{R∈SO(3)} Σ_{j=1}^{N_i} d_g(R, R^Bi_Si(t_j))^2

d_g(R1, R2) = ||log(R1^T · R2)||
```
**直觉**：在旋转流形 SO(3) 上找"平均旋转"，用测地距离 d_g 衡量差异。

### 2.3 扩散模型引导

EgoAllo 原生用 HaMeR 手部姿态引导，RoSHI 改为用 IMU 骨骼朝向引导：
- **直接可观测关节**（肘、髋、膝）：IMU 朝向直接对比扩散预测
- **间接关节**（肩等）：用骨盆 - 关节相对旋转对比
- **时间一致性**：连续帧间的相对旋转一致性约束

## 3. 带数字走一遍：玩具例子 (Worked Example)

假设采集一个"走路取物"序列（Dataset 2 的 pickup-walkaround）：

**步骤 1：校准（20-40 秒）**
- 用户穿上 RoSHI 套装，手持 iPhone 自然摆动
- iPhone 检测到 9 个 AprilTag，每标签平均 150 帧有效观测
- 计算 $\overline{R}^{B_i}_{S_i}$：对 150 个 $R^{B_i}_{S_i}(t_j)$ 在 $\mathrm{SO}(3)$ 上取 Barycenter
- 计算 $R^{W_p}_{W_i}$：用骨盆 IMU 作为参考世界，对齐其他 8 个 IMU

**步骤 2：数据采集（60 秒序列）**
- IMU 输出：$R^{W_i}_{S_i}(t)$ 在 100 Hz，共 6000 帧
- Aria 输出：$T^{C}_{W_c}(t)$ 在 30 Hz，共 1800 帧
- 时间对齐：IMU 帧 t=0.010s 匹配 Aria 帧 t=0.033s（最近邻）

**步骤 3：姿态生成**
```
帧 t=5.0s 时：
- IMU 读数：R^Wi_Si(5.0) = [0.98, 0.01, 0.15, 0.02] (四元数)
- 校准参数：R^Wp_Wi = [0.99, 0.02, 0.10, 0.01], R^Bi_Si = [0.97, -0.05, 0.20, 0.03]
- 计算：R^Wp_Bi(5.0) = R^Wp_Wi · R^Wi_Si(5.0) · (R^Bi_Si)^T
- 输入 EgoAllo：条件 T^C_Wc(5.0) + 引导 R^Wp_Bi(5.0)
- 输出：SMPL 参数 (β, θ, γ)，24 关节 3D 位置
```

**步骤 4：精度评估**
- OptiTrack 真值：关节位置 [x, y, z]_gt
- RoSHI 预测：关节位置 [x, y, z]_pred
- MPJPE = mean(||[x,y,z]_pred - [x,y,z]_gt||) = 6.2 cm (Dataset 2 平均)

## 4. 工程视角 (Engineering View)

| 指标 | 数值 | 工程含义 |

| 硬件成本 | ~$350 (9×$30 IMU + $20 接收器 + Aria 眼镜) | 商业方案 (Xsens $4500+) 的 1/13 |

| 校准时间 | 20-40 秒 | 传统 IMU 校准需 5-10 分钟（T 姿势 + 校准盒） |
| 同步精度 | <100 ms (LAN 时钟偏移) | 人类感知尺度可忽略 |
| 数据输出 | SMPL + 全局轨迹 + RGB | 直接适配 PyRoki/GMR 等 retargeting 工具 |

**部署约束**：
- 需要 Project Aria 眼镜（目前仅 Meta 合作伙伴可获取，二手市场约$1500）
- IMU 需 3D 打印外壳固定，strap 滑动会导致校准失效
- 室外强光下 AprilTag 检测可能失败，需遮挡辅助

## 5. 数据与评测 (Data & Eval)

### 5.1 数据集构成

| Dataset | 运动类型 | 时长 | 主导失效模式 |
|---------|----------|------|--------------|
| Dataset 1 | 原地动作（最小遮挡） | 多序列 | SLAM 漂移影响小，评估姿态重建质量 |
| Dataset 2 | 全局移动 + 中等敏捷 | 多序列 | 视野丢失导致视觉基线 recall 下降 |
| Dataset 3 | 敏捷运动（类体育） | 多序列 | 高速动态 + 运动模糊，压力测试 IMU |

共 11 个序列，2 名数据采集者。

### 5.2 评测指标与基线

**指标**：
- MPJPE (Mean Per-Joint Position Error, cm)：全局坐标系下关节位置误差
- JAE (Joint Angle Error, degrees)：父子骨骼方向角误差（与全局位姿无关）

**基线**：
1. SAM 3D Body（第三方校准相机，不公平但强基线）
2. IMU-only（Aria SLAM + 头到骨盆固定变换）
3. IMU+EgoAllo (root)（仅替换根位姿为 EgoAllo）
4. EgoAllo full（纯第一人称全身估计）

### 5.3 定量结果（论文 Table III）

| 方法 | Dataset 1 MPJPE | Dataset 2 MPJPE | Dataset 3 MPJPE |
|------|-----------------|-----------------|-----------------|
| IMU-only | ~12 cm | ~15 cm | ~18 cm |
| EgoAllo full | ~9 cm | ~11 cm | ~13 cm |
| **RoSHI (Ours)** | **~5 cm** | **~6 cm** | **~8 cm** |
| SAM3D (第三方相机) | ~4 cm | ~7 cm* | ~9 cm* |

*SAM3D recall 在 Dataset 2 仅 50%（受试者走出视野）

**结论**：RoSHI 在所有数据集上 MPJPE 最优，JAE 在 Dataset 1/2 最优；SAM3D 虽在可见帧上精度略高，但覆盖率严重受限。

### 6.1 能做什么

| 场景 | 能力 | 证据 |

| 人形机器人遥操作 | 数据可 retarget 到 Unitree G1，训练策略成功部署 | Fig. 4 + §IV-C |

### 6.2 不能做什么

| 限制 | 原因 | 影响 |
|------|------|------|
| 手指精细动作 | 无手部 IMU，仅靠扩散模型先验 | 不适合抓取/操作任务的数据收集 |
| 多人交互场景 | 单用户系统，无多人体追踪 | 不适合社交/协作任务 |
| 极端高速运动 | IMU 100 Hz 上限，>10m/s 动作可能混叠 | 职业体育级动作需更高频 IMU |
| 水下/真空环境 | IMU 非防水，Aria 无法工作 | 特殊环境需定制封装 |

### 6.3 隐含假设 (Hidden Assumptions)

1. **IMU strap 不滑动**：校准后假设传感器 - 骨骼相对位置固定，实际运动中 strap 滑动会引入系统误差
2. **Aria SLAM 不失效**：在纹理缺失（白墙）或重复纹理（长廊）环境中 SLAM 可能漂移，影响全局轨迹
3. **扩散模型泛化**：EgoAllo 在 AMASS 上训练，对非人类运动（如舞蹈/杂技）可能失效
4. **时间同步足够**：假设<100ms 时钟偏移可忽略，但对高速冲击类动作（如击掌）可能有影响
