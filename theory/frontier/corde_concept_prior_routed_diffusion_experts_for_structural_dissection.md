### 1.2 关键机制 (Key Mechanism)

CoRDE 的架构由三个核心模块构成：

**模块 1 — 概念先验提取器**
- 使用冻结的概念编码器 p(c\|o) 从多模态观测中提取 C 个语义簇的分布
- 计算归一化置信度 γ(o) = 1 - H(p(c\|o)) / log C
- 概念置信度自适应调节结构引导强度 $\lambda(o) = \lambda_{\max} \cdot \gamma(o)$

**模块 2 — 结构引导责任推断（E-Step）**
- 通过可学习软映射矩阵 P_CE(z\|c) 将概念语义投影为结构先验 p_struct(z\|o)
- 结构先验与行为证据 r(z\|o, a₀) 几何融合，得到变分责任后验 q*(z\|o, a₀)
- 关键创新：几何平均而非硬分配，保持任务相变时的连续性

**模块 3 — LoRA 参数高效专家池（M-Step）**
- 共享冻结扩散 Transformer 骨干 $h_\eta(o)$
- 每个专家仅通过 Attention-LoRA 模块 B^((z)) A^((z)) 差异化（秩 r ≪ d）
- 随机扩散项 g(t)dw 保持不变，确保全秩行为多样性

⚡ **Eureka Moment**：用高层语义概念的软映射（而非硬绑定）来引导 MoE 路由——概念置信度高时路由更确定，概念模糊时自动回退到行为证据驱动，且 LoRA 专家只修改确定性漂移项而不触碰 SDE 随机项，从而在参数高效的同时不损失行为多样性。

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：

```
q*(z│o,a₀) = (1/Z) · r̄(z│o,a₀)^[1/(1+λ)] · p_struct(z│o)^[λ/(1+λ)]
```

这是行为证据与结构先验的**几何平均**——$\lambda$ 控制两者的权重平衡。

### 目标

将预训练的单体扩散教师策略蒸馏为 K 个专家的 MoE 学生策略，同时：
1. 消除路由崩溃（routing collapse）
2. 控制参数膨胀
3. 保持理论上的分数近似质量

### 核心方程

**结构先验（Eq.3）**：

```
p_struct(z│o) = Σ_{c=1}^{C} p_φ(c│o) · P_CE(z│c)
```

- p_φ(c│o): 冻结概念编码器输出的 C 个语义簇分布
- P_CE(z│c): 可学习软映射矩阵（C→K 的 many-to-many 投影）
- 约束: Σ_z P_CE(z│c) = 1

**变分责任后验（Eq.5，核心公式）**：

```
q*(z│o,a₀) = (1/Z) · r̄(z│o,a₀)^[1/(1+λ(o))] · p_struct(z│o)^[λ(o)/(1+λ(o))]
```

- r̄(z│o,a₀): 归一化行为证据 = q_ψ(z│o) · exp(-‖u_T - u_θ^((z))‖²₂)
- $\lambda(o) = \lambda_{\max} \cdot \gamma(o)$: 自适应结构引导强度
- γ(o) = 1 - H(p_φ(c│o)) / log C: 归一化概念置信度
- $Z(o,a_0)$: 配分函数（归一化常数）

**直觉**：当概念置信度高（$\gamma\to 1$, $\lambda\to \lambda_{\max}$）时，后验偏向结构先验（语义驱动路由）；当概念模糊（$\gamma\to 0$, $\lambda\to 0$）时，后验退化为行为证据驱动（数据驱动路由）。

**路由熵界（Theorem 1）**：

```
lim_{λ→∞} H(q*) = H(p_struct)
```

结构引导强度趋于无穷时，责任后验的熵收敛到结构先验的熵——路由确定性由概念先验保证。

**L2 分数近似界（Theorem 2）**：

```
‖u_T - ũ‖²₂ ≤ Σ_{z=1}^{K} q*(z) · ‖u_T - u_θ^((z))‖²₂
```

- u_T: 教师分数场
- ũ = Σ q*(z) · u_θ^((z)): 学生混合分数场
- 全局近似误差被局部专家误差的加权和上界——Jensen 不等式的直接应用

**SDE 随机项保留（Remark）**：

```
da_t = [f(a_t, t) - g²(t) · u_θ^((z))(a_t, o, t)] · dt + g(t) · dw̄
```

- LoRA 只修改确定性漂移项（括号内）
- Wiener 过程 g(t)dw̄ 持续注入全 rank 各向同性噪声
- 行为熵保持最大化，不受低秩约束影响

> 符号与本文保持一致：$o=观测$, $a_0=干净动作$, $a_t=t$ 时刻噪声动作, $u=分数场$, $\theta=专家参数$, $\psi=路由器参数$, $\varphi=概念编码器参数$, $\eta=冻结骨干参数$

## 3. 带数字走一遍：玩具例子 (Worked Example)

假设一个简化的 2 专家 (K=2)、2 概念 (C=2) 场景：

**场景设定**：
- 概念 c₁ = "抓取"，c₂ = "放置"
- 专家 z₁ = "抓取专家"，z₂ = "放置专家"
- 当前观测 o 来自一个"先抓取后放置"的长视界任务

**Step 1 — 概念置信度**：

```
p_φ(c₁│o) = 0.7,  p_φ(c₂│o) = 0.3
H(p) = -(0.7·log₂0.7 + 0.3·log₂0.3) ≈ 0.88 bit
γ(o) = 1 - 0.88/log₂(2) = 1 - 0.88 = 0.12
λ(o) = λ_max · 0.12 = 1.0 · 0.12 = 0.12  (设 λ_max=1.0)
```

概念置信度较低（$0.12$），说明当前观测的语义不够清晰——可能处于抓取$\to$放置的过渡阶段。

**Step 2 — 结构先验**（假设 P_CE 已学习为近似对角矩阵）：

```
P_CE = [[0.8, 0.2],    # c₁→z₁:0.8, c₁→z₂:0.2
        [0.3, 0.7]]    # c₂→z₁:0.3, c₂→z₂:0.7

p_struct(z₁│o) = 0.7·0.8 + 0.3·0.3 = 0.65
p_struct(z₂│o) = 0.7·0.2 + 0.3·0.7 = 0.35
```

**Step 3 — 行为证据**（假设专家分数误差）：

```
‖u_T - u_θ^((1))‖² = 0.5  →  exp(-0.5) ≈ 0.607
‖u_T - u_θ^((2))‖² = 1.2  →  exp(-1.2) ≈ 0.301

假设路由器先验 q_ψ(z₁│o) = q_ψ(z₂│o) = 0.5:

r(z₁│o,a₀) = 0.5 · 0.607 = 0.303
r(z₂│o,a₀) = 0.5 · 0.301 = 0.151

归一化: r̄(z₁) = 0.303/(0.303+0.151) ≈ 0.667
        r̄(z₂) = 0.151/(0.303+0.151) ≈ 0.333
```

**Step 4 — 几何融合（责任后验）**：

```
指数: 1/(1+λ) = 1/1.12 ≈ 0.893
      λ/(1+λ) = 0.12/1.12 ≈ 0.107

q*(z₁│o,a₀) ∝ 0.667^0.893 · 0.65^0.107 ≈ 0.685 · 0.957 ≈ 0.655
q*(z₂│o,a₀) ∝ 0.333^0.893 · 0.35^0.107 ≈ 0.357 · 0.880 ≈ 0.314

归一化: Z = 0.655 + 0.314 = 0.969
q*(z₁) = 0.655/0.969 ≈ 0.676
q*(z₂) = 0.314/0.969 ≈ 0.324
```

**解读**：尽管概念置信度低（$\lambda$ 小），行为证据仍然主导了路由决策（$z_1$ 抓取专家占优），但结构先验提供了轻微的正则化（$0.676$ vs 纯证据的 $0.667$）。在过渡阶段，这种软融合避免了硬分配的突变。

**Step 5 — 高置信度场景对比**：

如果观测明确是"抓取"阶段：
```
p_φ(c₁│o) = 0.95, γ(o) = 1 - H(0.95)/1 ≈ 0.70
λ(o) = 0.70

q*(z₁) ∝ 0.667^(1/1.7) · 0.65^(0.7/1.7) ≈ 0.761 · 0.809 ≈ 0.616
q*(z₂) ∝ 0.333^(1/1.7) · 0.35^(0.7/1.7) ≈ 0.533 · 0.564 ≈ 0.301

q*(z₁) ≈ 0.672, q*(z₂) ≈ 0.328
```

高置信度时结构先验权重增加，路由更稳定。

## 4. 工程视角 (Engineering View)

### 6.1 隐含假设 (Hidden Assumptions)

1. **概念编码器已足够好**: 论文假设存在一个能提取有意义语义分布的冻结概念编码器（如 HiMaCon）。如果概念质量差，$\lambda \to 0$ 时系统退化为纯证据驱动，失去结构引导优势
2. **概念-专家映射可学习**: P_CE 软映射矩阵通过 EM 自组织更新，假设概念空间和专家空间之间存在稳定的 many-to-many 对应关系
3. **LoRA 秩足够**: 假设 r≪d 的低秩更新足以捕捉专家间的差异化行为。对于高频精细操作（如触觉反馈控制），低秩可能不够
4. **教师策略质量**: 蒸馏质量上界受限于预训练教师 u_T。如果教师本身在多任务上有缺陷，CoRDE 无法超越
5. **仿真到现实的鸿沟可跨越**: 所有实验在仿真环境完成，未验证物理部署
