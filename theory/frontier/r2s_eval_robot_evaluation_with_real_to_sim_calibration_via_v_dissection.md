💡 **X-Ray 开场**
当前 VLA 策略评测依赖真机重复试验——每次都要人工摆场景、跑机器人、记录成功率。这不仅慢（每次试验数分钟），而且不稳定（微小扰动改变结果），更致命的是：成功率是二元的，两个都成功的策略可能在动作质量上天差地别。R2S-Eval 的思路是：先在仿真里校准真实环境，让策略在仿真里跑完所有试验，再用 VLM 像人一样"看视频打分"，最后用 Bradley-Terry 模型把两两比较汇总成带置信区间的策略排名。

| **可重复性** | 低（环境扰动敏感） | 高（仿真环境确定性） |

### 1.2 关键机制 (Key Mechanism)

**机制一：行为校准而非视觉校准**
- 目标不是 photorealistic digital twin，而是校准"影响策略行为"的因素：机器人几何/运动学/关节限位/控制接口、任务物体 3D 重建与位姿、相机视角
- 这比视觉重建更经济——不需要高保真渲染，只需要策略输出正确的动作

**机制二：两阶段 VLM 判断**
- Stage 1（描述）：VLM 对单个视频生成结构化行为描述 d = G_desc(v, x)，涵盖动作平滑度、时序连续性、任务进度、接触/力度控制
- Stage 2（比较）：两视频匿名排列（随机 A/B 位置），VLM 比较两个描述输出二元偏好 y = G_pref(d_i, d_j)
- 两阶段设计让判断基于显式证据而非直觉打分

**机制三：Bradley-Terry 偏好聚合**
- 将 N 个策略的两两比较汇总为偏好矩阵 M，用 BT 模型拟合每个策略的潜在质量分数 θ_i
- 输出带 bootstrap 置信区间的排名，而非单一排序

⚡ **Eureka Moment**：策略评测的核心不是"算成功率"，而是"估计策略间的相对偏好"——用 VLM 看视频做 pairwise 比较，再用统计模型聚合，比人工数成功次数信息量大得多。

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：
```
θ̂ = argmax_θ Σ_{i<j} [ M_ij · log σ(θ_i - θ_j) + M_ji · log σ(θ_j - θ_i) ]
```

**目标**：从 VLM 的 pairwise 偏好计数矩阵 M 中，估计每个策略的潜在质量分数 θ，使得观测到的偏好最可能。

**公式展开**：

```
输入：
  Π = {π_1, ..., π_N}          // N 个候选策略
  M ∈ N^{N×N}                  // 偏好计数矩阵, M_ij = i 胜过 j 的次数
  q_ij(θ) = σ(θ_i - θ_j)       // BT 模型: π_i 胜过 π_j 的概率

对数似然：
  ℓ(θ, M) = Σ_{i<j} [ M_ij · log q_ij(θ) + M_ji · log q_ji(θ) ]

求解：
  θ̂ = argmax_θ ℓ(θ, M)       // MM (Minorization-Maximization) 算法
  约束: Σ_i b_i = 1, θ_i = log(b_i), b_i > 0

输出：
  r_pref = Rank(θ̂_1, ..., θ̂_N)   // 策略排名
  BT CI: 95% bootstrap 置信区间     // 1000 次重采样
```

**变量说明**：

| 符号 | 含义 |
|------|------|
| θ_i | 策略 π_i 的潜在质量分数（BT strength 参数的对数） |
| M_ij | 在所有 pairwise 比较中，π_i 的视频被 VLM 偏好于 π_j 的次数 |
| q_ij(θ) | BT 模型预测 π_i 胜过 π_j 的概率 = sigmoid(θ_i - θ_j) |
| b_i | BT strength 参数（原始尺度，非对数） |
| σ(·) | sigmoid 函数 |

**直觉**：这跟 Elo 等级分 / Chess 排名的数学本质一样——不是算绝对分数，而是从两两对战记录中反推每个策略的"真实实力"。θ_i - θ_j 越大，π_i 被偏好于 π_j 的概率越高。

> 符号与本文保持一致：π_i 为策略，τ 为 rollout 轨迹，v 为视频，θ 为 BT 分数。

## 3. 带数字走一遍：玩具例子 (Worked Example)

假设 3 个 VLA 策略 {A, B, C} 在 7 个任务上各跑 200 个 rollout，VLM 对每对策略做 pairwise 比较：

```
步骤 1: 采集偏好计数
  比较 (A, B): A 胜出 68 次, B 胜出 32 次 → M_AB = 68, M_BA = 32
  比较 (A, C): A 胜出 75 次, C 胜出 25 次 → M_AC = 75, M_CA = 25
  比较 (B, C): B 胜出 55 次, C 胜出 45 次 → M_BC = 55, M_CB = 45

步骤 2: BT 最大似然估计
  ℓ(θ) = 68·log σ(θ_A-θ_B) + 32·log σ(θ_B-θ_A)
       + 75·log σ(θ_A-θ_C) + 25·log σ(θ_C-θ_A)
       + 55·log σ(θ_B-θ_C) + 45·log σ(θ_C-θ_B)

  求解（MM 算法迭代）:
  θ_A = 0.82, θ_B = 0.12, θ_C = -0.94
  （归一化: Σ b_i = 1, b_i = exp(θ_i)）

步骤 3: 排名 + 不确定性
  排名: A ≻ B ≻ C
  95% CI (bootstrap 1000 次):
    θ_A: [0.65, 0.98]   → 95% CI 宽度 = 0.33
    θ_B: [-0.05, 0.28]  → 95% CI 宽度 = 0.33
    θ_C: [-1.15, -0.72] → 95% CI 宽度 = 0.43

  解读: A 和 B 的 CI 有重叠 → 差距不显著；A 和 C 的 CI 无重叠 → A 显著优于 C
```

**与成功率的对比**：
```
假设成功率: A=72%, B=68%, C=45%
  排名: A ≻ B ≻ C（一致）

但如果: A=68%, B=66%, C=65%（全部接近）
  成功率排名仍为 A ≻ B ≻ C，但差距微小
  BT 偏好可能揭示: A 的动作质量明显优于 B（虽然成功率接近）
  → 这就是"行为信息量"的价值
```

## 4. 工程视角 (Engineering View)

| 维度 | 数值/约束 | 工程含义 |
|------|----------|----------|
| **仿真平台** | NVIDIA Isaac Sim | 需要 GPU 渲染 + 物理引擎；校准一次后可无限复用 |
| **策略训练数据** | 3,525 条 teleop 轨迹（真实）+ action replay（仿真） | teleop 采集成本高（exoskeleton + VR），但一次性投入 |
| **Rollout 数量** | 真实 20 次/任务，仿真 200 次/任务 | 仿真可跑 10× 更多试验，覆盖更广的初始化分布 |
| **VLM 推理** | 8 个 VLM 模型 × 100-2000 次 pairwise 比较 | 每个比较需两次 G_desc + 一次 G_pref；32B 模型单次约数秒 |
| **BT 拟合** | MM 算法（非梯度），收敛快 | 计算成本可忽略，bootstrap CI 需 1000 次重采样 |
| **A/B 位置偏差** | 91.5% 顺序一致 | 随机化 A/B 分配即可缓解，不需额外校准 |
| **部署约束** | 需要 Isaac Sim license + 足够 GPU | 对无仿真环境的小团队门槛较高 |

**关键 trade-off**：校准精度 vs 开发成本。论文明确不追求 photorealism，只校准行为相关因素。这意味着：
- 优点：校准周期短（几天而非几周）
- 风险：某些接触物理差异（如摩擦系数）可能残留，导致 π^S 和 π^R 行为不完全一致（最大成功率差距 7.0pp）

### 6.1 隐含假设 (Hidden Assumptions)

1. **π^S 排名 ≈ π^R 排名**：论文通过 closed-loop 成功率一致性验证了这个 proxy 假设（平均差距 2.13pp），但没有直接验证排名在多次独立校准中的稳定性
2. **VLM 偏好 ≈ 人类偏好**：82.9-91.9% 一致性不错，但 8-17% 的不一致可能系统性偏向某些行为模式（如更流畅但更慢的动作）
3. **校准环境足够覆盖策略差异**：假设校准后的仿真环境能保留策略间的相对性能差异，但如果校准过度"平滑"了环境难度，可能压缩策略间的可区分度
4. ** pairwise 比较的独立性**：BT 模型假设每对比较独立，但实际上同一策略的多个 rollout 视频可能存在相关性（相同初始化分布）
