## 1. 核心架构/方法总览 (Overview / Architecture)

### 1.1 系统对比概览 (System Component Comparison)

| 模块 | 输入 | 输出 | 训练时机 | 推理时行为 |
|------|------|------|----------|------------|
| **Base VLA** (冻结) | 图像+本体+语言 → token | 动作 chunk (H=16) | 预训练后冻结 | 始终参与，参数不变 |
| **Adapter Aᵢˡ** (旁路) | 层 ℓ 的输入特征 xˡ | 修正量 Δˡ ∈ Rᵈˡ | 新任务时仅训练新 Adapter | 路由选一个激活，加到基模块输出 |
| **Discriminator Dⱼˡ** (自编码器) | 层 ℓ 的输入特征 xˡ | 重构特征 x̂ˡ | 两阶段：先训 Adapter，再训 Discriminator | 计算重构误差 eˡⱼ(xˡ)，选最小误差者 |
| **路由机制** | 所有 Discriminator 的重构误差 | 选中的 Adapter 索引 | 无训练（基于误差 argmin） | 每层独立选一个 Adapter |

### 1.2 关键机制 (Key Mechanism)

**为什么这样设计？**

1. **旁路注入而非修改**：Adapter 以 `Mˡ(xˡ) = Mˡ_pre(xˡ) + Aˡ*(xˡ)` 的方式并联到预训练模块上，不改变原始模块的输入输出接口，保证旧知识不被覆盖。

2. **仅扩展感知编码层**：消融实验（Table II）表明，仅扩展编码器（observation encoding modules）的效果优于仅扩展解码器。因为感知编码层负责将多模态观测调制为任务特定表示，是存储新技能的最佳位置。

3. **两阶段训练**：先联合训练新 Adapter（flow matching loss），冻结其余参数后单独训练新 Discriminator（reconstruction loss）。这避免了浅层 Adapter 训练导致的特征分布变化干扰 Discriminator。

⚡ **Eureka Moment**：**用自编码器的重构误差作为"这个输入属于哪个任务"的代理信号**——在任务 A 数据上训练的判别器对任务 A 的特征重构误差最小，自然形成路由选择，无需任务标签。

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：
```
路由选择: Aˡ* = Bˡ(argminⱼ ‖xˡ - Dˡⱼ(xˡ)‖₂)
```

**目标**：在无需历史数据、无需任务标签的条件下，让 VLA 持续学习新任务而不遗忘旧任务。

**核心方程**：

Flow Matching 损失（训练 Adapter）：
```
L(θₙ) = E_{s,(A¹,o),A⁰} [ ‖v_θₙ(Aˢ, o, s) - (A¹ - A⁰)‖₂² ]
```
其中 s ~ U([0,1]), A⁰ ~ N(0,I), Aˢ = (1-s)A⁰ + sA¹。

自编码器重构损失（训练 Discriminator）：
```
L_recon(Dˡₙ) = E_{xˡ~Dₙ} [ ‖xˡ - Dˡₙ(xˡ)‖₂ ]
```

动态扩展 z-score：
```
zˡⱼ = (1/|Dₙ|) Σ_{xˡ∈Dₙ} (eˡⱼ(xˡ) - μˡⱼ) / σˡⱼ
```

**变量说明**：

| 符号 | 含义 |
|------|------|
| θ₀ | 预训练 VLA 参数（冻结） |
| θₙ | 阶段 n 的完整参数（θ₀ + 所有 Adapter + 所有 Discriminator） |
| Aˡᵢ | 层 ℓ 的第 i 个 Adapter: W_up · ReLU(W_down · xˡ) |
| Dˡⱼ | 层 ℓ 的第 j 个 Discriminator（自编码器） |
| γ | 动态扩展阈值（默认 0，越大扩展越少） |
| r | Adapter 瓶颈维度（r ≪ dˡ） |
| Bˡ | Discriminator → Adapter 的映射（满射） |

> 符号与本文保持一致。Adapter 结构为低秩 encoder-decoder，r 为瓶颈维度。

## 3. 带数字走一遍：玩具例子 (Worked Example)

假设一个简化场景：VLA 有 2 个可扩展层（ℓ₁=浅层编码器, ℓ₂=深层编码器），已学 2 个任务，现在来第 3 个任务 T₃。

**Step 1: 动态扩展决策**

对于层 ℓ₁，现有 Discriminator Dˡ¹₁ 和 Dˡ¹₂，阈值 γ=0：

```
新任务 T₃ 的特征通过 Dˡ¹₁:  eˡ¹₁ = 5.2,  μˡ¹₁=2.0,  σˡ¹₁=1.0  →  zˡ¹₁ = (5.2-2.0)/1.0 = 3.2
新任务 T₃ 的特征通过 Dˡ¹₂:  eˡ¹₂ = 4.8,  μˡ¹₂=2.5,  σˡ¹₂=1.2  →  zˡ¹₂ = (4.8-2.5)/1.2 = 1.9
```

zˡ¹₁=3.2 > 0, zˡ¹₂=1.9 > 0 → 两者都超过阈值 → **层 ℓ₁ 需要扩展**，新增 Adapter Aˡ¹₃ + Discriminator Dˡ¹₃。

对于层 ℓ₂：
```
新任务 T₃ 的特征通过 Dˡ²₁:  eˡ²₁ = 1.5,  μˡ²₁=1.2,  σˡ²₁=0.5  →  zˡ²₁ = (1.5-1.2)/0.5 = 0.6
新任务 T₃ 的特征通过 Dˡ²₂:  eˡ²₂ = 3.0,  μˡ²₂=2.0,  σˡ²₂=1.5  →  zˡ²₂ = (3.0-2.0)/1.5 = 0.67
```

zˡ²₁=0.6 > 0, zˡ²₂=0.67 > 0 → **层 ℓ₂ 也需要扩展**，新增 Adapter Aˡ²₃ + Discriminator Dˡ²₃。

**Step 2: 训练**

- 仅训练 Aˡ¹₃, Aˡ²₃, Dˡ¹₃, Dˡ²₃（共 4 个新模块），冻结其余所有参数
- Flow matching loss 训练 Adapter（~1 小时/仿真任务）
- Reconstruction loss 训练 Discriminator（两阶段）

**Step 3: 推理时路由**

```
新观测 oₜ 进入:
  层 ℓ₁: Dˡ¹₁→e=4.5, Dˡ¹₂→e=6.1, Dˡ¹₃→e=1.2  → j*=3  → 选 Aˡ¹₃
  层 ℓ₂: Dˡ²₁→e=2.0, Dˡ²₂→e=1.8, Dˡ²₃→e=3.5  → j*=2  → 选 Aˡ²₂
```

注意：不同层可以选择不同的 Adapter！这允许跨任务知识共享——浅层用新 Adapter（感知差异大），深层用旧 Adapter（动作先验相似）。

## 4. 工程视角 (Engineering View)

| 指标 | 数值 | 工程含义 |
|------|------|----------|
| 推理路由开销 | <3 ms/步 | 几乎可忽略，不影响 15-20 Hz 控制频率 |
| GPU 内存增长 | ~2%/任务 | 10 个任务后仅增长 ~20%，200M 基座 → ~240M |
| 训练时间（仿真） | ~1 小时/任务 | RTX 5090 上；可接受但非实时 |
| 训练时间（真实） | ~5 小时/任务 | 真实世界数据采集+训练成本高 |
| Adapter 结构 | encoder-decoder, r≪d | 参数量小，瓶颈结构保证轻量化 |
| 基座 VLA | DiT-Dec, 6 层, ~200M | 冻结 DINOv2 + CLIP 编码器 |

**部署约束**：
- 每多一个任务，推理时需多跑一组 Discriminator 前向（自编码器），但计算量远小于 Transformer 层
- 适配器数量线性增长（最坏情况 1 个/层/任务），需管理内存
- 两阶段训练意味着需要保存中间特征或重新前向传播一次

**Trade-off**：
- γ 越大 → 扩展越少 → 内存友好但 FWT 下降（图 5：γ=20 时适配器从 60 减到 16，AUC 略降但仍优于 ER）
- 扩展浅层 vs 深层：浅层扩展效果显著优于深层（Table II），因为感知调制比动作先验更需要任务特定化

- 覆盖不同重量（7g Lego → 0.5kg Moka 壶）、不同动力学（接触丰富的插入、非线性摩擦）
- 每任务 10 次 rollout 评估

**评测指标**：
- **AUC**（成功率曲线下面积）：综合新旧任务表现，越高越好
- **FWT**（前向迁移）：首次学习新任务的成功率，衡量学习能力
- **NBT**（负向后迁移）：学新任务后旧任务性能下降程度，越低越好（0 = 零遗忘）

### 6.1 隐含假设 (Hidden Assumptions)

1. **特征空间可分性**：假设不同任务的输入特征在 VLA 的中间层表示中是可区分的——如果两个任务在特征空间高度重叠，Discriminator 可能无法可靠路由。

2. **任务顺序的平稳性**：实验按固定顺序（Long → Goal → Spatial → Object）评估，但真实环境中任务到达顺序可能更随机或更极端。

3. **演示数据质量**：每任务仅 50 个演示（仿真）或未知数量（真实），假设这些演示足够覆盖任务的初始状态空间。

4. **适配器独立性**：假设每层只激活一个 Adapter 足够——但某些复杂任务可能需要多个 Adapter 的组合输出（类似 MoE 的加权混合）。
