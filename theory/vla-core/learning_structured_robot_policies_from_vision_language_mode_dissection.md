## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：

```
f_θ(I, U, S) → T  其中 T 是满足 JSON 语法和机器人约束的行为树
```

**目标**：学习映射函数 $f_\theta$，将高维视觉观测 $I$、自然语言指令 $U$、系统规范 $S$ 映射到有效行为树空间 $\Pi$。

**变量说明**：
- $I \in \mathcal{I}$：RGB 图像空间
- $U \in \mathcal{U}$：自然语言指令空间
- $S \in \mathcal{S}$：系统规范（原语库、安全约束、物体元数据）
- $T \in \Pi$：行为树空间
- $\theta$：Pixtral-12B + LoRA 参数

**符号算术（关键约束）**：

```
ξ_a = T_off · ξ_O = [R  t+Δz; 0^T  1]
其中 Δz = [0, 0, z_off]^T 且 z_off > 0
```

这表示接近位姿 $\xi_a$ 是通过对物体位姿 $\xi_O$ 施加 $z$ 轴偏移得到的，确保无碰撞轨迹。

**扁平层级约束**：

```
type(n_p) ≠ type(c_i)  ∀i
```

父节点类型不能与任何子节点类型相同，强制生成浅而宽的树。

> 符号与本文/相关文档保持一致：$\xi$ 表示位姿（pose），$T$ 表示变换矩阵，$R/t$ 分别表示旋转/平移。

## 3. 带数字走一遍：玩具例子 (Worked Example)

**场景**：桌面上有两个圆柱体——左侧黄色圆柱体（yellow_cylinder_0），右侧绿色圆柱体（green_cylinder_1）。

**指令**："Pick up the left cylinder"（拿起左边的圆柱体）

**推理过程**：
1. 模型接收 RGB 图像 + 指令 + 系统规范（含两个物体的位姿元数据）
2. 视觉推理：识别"left"对应 yellow_cylinder_0（基于图像中的相对位置）
3. 符号接地：将 yellow_cylinder_0 的位姿 $\xi_O$ 映射到行为树参数
4. 计算接近位姿：ξ_a = ξ_O + [0, 0, 0.1]^T（假设 z_off=0.1m）
5. 生成行为树：

```json
{
  "type": "Selector",
  "children": [
    { "type": "Condition", "name": "is_grasped" },
    {
      "type": "Sequence",
      "children": [
        { "type": "Action", "name": "MovePose", "args": ["yellow_cylinder_0"] },
        { "type": "Action", "name": "CloseGripper" }
      ]
    }
  ]
}
```

**执行**：机器人解析 BT，先检查 is_grasped 条件，若失败则执行 MovePose → CloseGripper 序列。

**关键**：模型没有见过真实图像，但从合成数据中学到了"left"的视觉 - 符号映射，零样本迁移成功。

- **零样本 Sim-to-Real**：合成训练→真实执行，无需微调

### 6.2 不能做什么

- **超长视野任务**：4400 token 上下文限制复杂多步任务

- **动态环境重规划**：BT 生成是一次性的，执行中物体位移需外部更新元数据

### 6.3 隐含假设 (Hidden Assumptions)

- **场景图存在**：假设外部感知系统提供物体位姿元数据 $\{\xi_{Oj}\}$
- **原子原语完备**：假设预定义的动作/条件库覆盖所有任务需求
- **静态场景**：假设执行期间物体位姿不变（或通过外部系统更新）
- **单机器人工作空间**：实验在桌面操作场景，未验证移动/双臂/人形机器人
