### 1.2 关键机制 (Key Mechanism)

**核心设计哲学**：将 VLM 知识基准转换为"动作选择"任务，而非"文本生成"任务。

具体步骤：
1. **从 VLM 基准筛选**：从 GQA、VL-Think、ScienceQA 等 5 个成熟基准中选择适合的知识类别
2. **指令长度过滤**：VLA 对长指令跟随能力有限，过滤掉过长的指令
3. **图像可读性过滤**：人工标注过滤掉目标过小或视觉模糊的样本
4. **二元化转换**：用 LLM 将开放回答或多选题转换为二元选择（两个选项）
5. **场景实例化**：在 SimplerEnv 中将两个选项图像放置在桌面上已知位置
6. **动作回答**：机器人将方块放置到它认为正确的选项图像上方

**为什么这样设计有效**：
- 短程、低复杂度动作 → 控制难度不再是瓶颈
- 二元选择 → 随机基线明确（$50\%$）
- 左右交换重复测试 → 消除位置偏好偏差
- 基于已有 VLM 基准 → 问题质量有社区验证

⚡ **Eureka Moment**：在认知科学中，非语言生物（如婴儿、动物）的知识评估是通过"知识条件化动作"而非"语言报告"进行的——Act2Answer 将这一范式首次引入 VLA 评估。

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：

```
SR = (1/N) · Σᵢ I(p⁽ⁱ⁾ ∈ Z⁺)    where    Z⁺ = {p : ‖p - p⁺‖ ≤ ε}
```

**目标**：量化 VLA 模型通过动作选择表达知识的准确率，解耦知识能力与控制能力。

**公式分解**：

| 符号 | 含义 |
|------|------|
| SR | Soft Success Rate，软成功率 |
| N | 总 episode 数（$3{,}440 = 1{,}720 \times 2$ 左右交换） |
| $p^{(i)}$ | 第 i 个 episode 中方块的最终 2D 位置 |
| $p^+$ | 正确选项图像的中心位置 |
| p⁻ | 错误选项图像的中心位置 |
| $\varepsilon$ | 容忍半径（定义目标区域 Z⁺ 和错误区域 Z⁻） |
| $Z^+$ | 目标区域（正确放置区域） |
| Z⁻ | 错误区域（错误放置区域） |
| $Z^\emptyset$ | 越界区域（两个区域之外） |
| $I(\cdot)$ | 指示函数，条件满足返回 1，否则 0 |

**三态解释框架**（基于概率质量分布）：

```
SR > 0.5 + Δ  →  Instruction-following / perceptual success
SR ∈ [0.5-Δ, 0.5+Δ]  →  Random guessing (chance-level)
SR < 0.5 - Δ  →  Systematic anti-selection (chooses wrong consistently)
```

$\Delta$ 是二项采样波动的半宽，每个类别不同（详见论文 Appendix E）。

**Chance-Normalized Retention**（层间知识保留度量）：

```
Retention = maxₙ(sₙᵉˣᵖ - c) / [maxₙ(sₙᵇᵇ - c) + ε]
```

| 符号 | 含义 |
|------|------|
| $s_{n}^{\text{exp}}$ | Action Expert 第 n 层的线性探测准确率 |
| $s_{n}^{\text{bb}}$ | VLM Backbone 第 n 层的线性探测准确率 |
| c | 随机基线准确率 |
| $\varepsilon$ | 小常数（数值稳定性） |

**直觉**：Retention 接近 1.0 表示 Action Expert 保留了与 Backbone 同等水平的知识信号；接近 0 表示知识在从语义表示到动作生成的转换过程中丢失了。

> 符号与本文保持一致：上标 exp = action expert, bb = backbone。

## 3. 带数字走一遍：玩具例子 (Worked Example)

假设我们评估 OpenVLA 在 Emotion（情感识别）类别上的表现：

**场景设定**：
- 问题："Do you see the sad person?"
- 左图：一个微笑的人（错误选项）
- 右图：一个流泪的人（正确选项）
- 正确位置 p⁺ = (0.4, 0.0)（右侧），错误位置 p⁻ = (-0.4, 0.0)（左侧）
- 容忍半径 $\varepsilon = 0.1\,\text{m}$

**一次 episode 的执行**：

```
Step 1: 相机拍摄桌面场景 → VLA 接收图像 + 指令
Step 2: VLM Backbone 处理视觉-语言特征
        → 中间层探测准确率: 62%（高于随机，说明知识存在）
        → 最后层探测准确率: 51%（接近随机，知识衰减）
Step 3: Action Expert 生成动作序列
        → 方块最终位置 p = (-0.35, 0.05) → 落在 Z⁻（错误区域）
Step 4: 评分: I(p ∈ Z⁺) = 0 → 本次失败
```

**100 次 episode 汇总**（Emotion 类别，OpenVLA 实际数据近似）：

```
正确放置到 Z⁺: 48 次
错误放置到 Z⁻: 42 次
越界 Z∅:      10 次
SR = 48/100 = 0.48

随机基线 = 0.50
假设 Δ = 0.05（二项波动）
0.48 ∈ [0.45, 0.55] → 判定为随机猜测
```

**对比 Magma 在相同类别**：

```
SR = 0.72 → 72% > 0.55 → 显著超越随机
Retention = 0.87 → Action Expert 保留了 87% 的 Backbone 知识信号
```

**关键洞察**：OpenVLA 的中间层探测可能达到 55-60%（知识部分存在），但最终动作选择只有 48%——知识存在但无法可靠地转化为正确动作。这就是论文所说的"语义表示与动作生成之间的瓶颈"。

## 4. 工程视角 (Engineering View)

| 维度 | 数值/特征 | 工程含义 |
|------|----------|---------|
| 每 episode 步数 | 短程放置（~5-10 步） | 推理成本低，大规模评估可行 |
| 环境 | SimplerEnv | 与主流 VLA 评估共享环境，集成成本低 |
| 总评估量 | 3,440 episodes | 单模型约需数小时（取决于推理速度） |
| 动作空间 | 2D 放置（选择左/右） | 极简动作空间，不测试精细操控 |
| 视觉分辨率 | 依赖模型原生分辨率 | 已过滤小目标样本，但低分辨率模型可能仍有感知局限 |
| 无抓取操作 | 仅放置方块 | 避免了抓取成功率的混淆因素 |
| 左右交换 | 每个问题 $\times 2$ | 消除位置偏好，评估量翻倍但更可靠 |
| 层间探测 | 逐层提取 hidden states | 需要模型内部访问权限（白盒），黑盒 API 模型无法使用 |

**部署约束**：
- Act2Answer 是评估协议，不是训练方法——它告诉你模型"知道什么"，但不直接帮助模型"记住更多"
- 层间 probing 需要访问模型中间层激活，对闭源 VLA（如 $\pi_0$ 的某些版本）可能受限
- 当前仅覆盖桌面双臂场景，未覆盖移动操作或人形机器人

**与训练流程的关系**：
- RQ6 发现：下游 SFT 微调（在非基准数据集上）反而导致 State 和 Color 类别性能下降
- 工程启示：在 VLA 上线前做领域适配微调时，应同时运行 Act2Answer 评估以监控知识保留

### 6.1 隐含假设 (Hidden Assumptions)

1. **二元选择足够代表知识**：论文假设二元选择任务能充分捕捉知识类别的核心能力。但实际上，某些知识（如因果推理、多步规划）可能需要更复杂的多选项或开放回答格式。

2. **SimperEnv 桌面场景足够代表"具身"**：评估仅在 SimplerEnv 的桌面双臂场景中进行。真实世界的光照变化、物体遮挡、动态背景可能进一步降低知识表现。

3. **线性探测足以测量知识保留**：层间 intent probing 使用线性分类器。如果知识以非线性方式编码，线性探测可能低估实际保留的知识量。

4. **VLM 文本解码是合理的上界**：RQ3 用 VLM 的文本解码准确率作为知识保留的理论上限。但文本解码和动作选择是不同的能力——高文本准确率不一定意味着高动作准确率，反之亦然。

5. **知识遗忘 = 灾难性遗忘**：论文将 VLM$\to$VLA 的知识下降归因为"遗忘"。但另一种可能是：机器人微调改变了表征空间，使得原有知识以不同方式编码，而非真正丢失。
