💡 **X-Ray 开场**
这篇论文解决的核心问题是：VLA 模型在闭圈控制中每秒都要处理大量视觉 token，如何安全地丢弃或复用其中一部分而不影响机器人动作？作者发现，现有的压缩方法（基于视觉相似度、注意力分数等）都是间接信号——真正应该问的是"这个 token 变多少才会让机器人动作出错？"。答案来自感知心理学中的"最小可觉差"（JND）概念：只要变化不引起下游动作偏差，就可以安全压缩。

### 1.2 关键机制 (Key Mechanism)

Action-JND 的核心机制分三步：

1. **训练 JND 估计器**: 给定冻结 VLA 的视觉 token 特征 F_t，轻量 CNN 估计器 G_φ 预测每个 token 的最大扰动 Δ̂_t，使得扰动后的特征 F̃_t = F_t + Δ̂_t 输入 VLA 后产生的动作偏差 D_act 不超过容忍阈值 ε_a。
2. **生成容忍度分数**: 训练完成后，扰动幅度 ‖Δ̂_t,i‖₂ 转换为 token 级 action-tolerance score——分数越高，该 token 越"安全"可压缩。
3. **指导压缩决策**: 在推理阶段，JND score 作为排序信号，对候选 token 按容忍度降序排列，优先复用/剪除高分数 token。

⚡ **Eureka Moment**: 压缩安全性的判断标准不应是"这个 token 看起来多冗余"，而应是"这个 token 变多少会让机器人动作出错"——前者是 proxy，后者是 ground truth。

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：

```
Δ_t* = argmax_Δ ||Δ||_2,  s.t.  D_act( a_t, ã_t ) ≤ ε_a
```

**目标**: 找到每个视觉 token 上最大的扰动幅度，使得 VLA 策略的动作输出偏差保持在可容忍范围内。

**公式拆解**:

```
L_JND = λ_act · D_act(r_t, r̃_t)  −  λ_mag · M(Δ̂_t)
        ↑ 动作一致性惩罚              ↑ 扰动幅度奖励
```

最小化 L_JND = 在保持动作不变的前提下，最大化扰动幅度。

**变量说明**:

| 符号 | 含义 |
|------|------|
| F_t ∈ R^{N×D} | N 个视觉 token 的特征，D 为特征维度 |
| Δ_t | 对 F_t 的扰动 |
| π_θ | 冻结的 VLA 策略 |
| a_t = π_θ(F_t, ℓ) | 干净动作 |
| ã_t = π_θ(F_t + Δ_t, ℓ) | 扰动后的动作 |
| D_act | 动作偏差度量 (见下方) |
| ε_a | 容忍的动作偏差阈值 |
| M(Δ̂_t) = (1/N) Σ_i ‖Δ̂_{t,i}‖₂ | 扰动幅度的 L2 范数均值 |
| λ_act, λ_mag | 平衡动作一致性与扰动幅度的超参 |

**动作偏差 D_act 的两种实例化**:

对于离散动作 token 策略（如 OpenVLA）：

```
D_act = D_KL( P_θ(a | F_t, ℓ) || P_θ(a | F_t + Δ_t, ℓ) )
```

对于连续动作回归策略（如 OpenVLA-OFT）：

```
D_act = λ_p · ‖Δp_t - Δp̃_t‖₁ + λ_r · ‖Δr_t - Δr̃_t‖₁ + λ_g · |g_t - g̃_t|
```

其中平移/旋转/夹爪的权重 λ_p, λ_r, λ_g 分别调节各分量重要性。

**直觉**: 想象每个视觉 token 有一个"安全变形空间"——在这个空间内扭曲它的特征表示不会让机器人做错动作。JND 估计器的任务就是为每个 token 找到这个空间的最大半径。半径大的 token 可以放心压缩，半径小的必须保留。

> 符号与本文保持一致：F_t 为视觉 token 特征，π_θ 为冻结 VLA，D_act 为动作偏差，ε_a 为容忍阈值。

## 3. 带数字走一遍：玩具例子 (Worked Example)

假设一个简化的 2D 视觉 token 场景：

**设置**:
- 1 个视觉 token，特征 f = [0.5, 0.3]（2 维）
- VLA 策略: a = π(f) = 2·f₁ + 3·f₂（线性近似）
- 干净动作: a_clean = 2·0.5 + 3·0.3 = 1.9
- 容忍偏差: ε_a = 0.2
- λ_act = 1.0, λ_mag = 0.5

**JND 优化过程**:

```
Step 1: 尝试扰动 δ = [0.05, 0.03]
  ã = 2·(0.5+0.05) + 3·(0.3+0.03) = 1.9 + 0.19 = 2.09
  D_act = |2.09 - 1.9| = 0.19 ≤ 0.2 ✓
  M(δ) = sqrt(0.05² + 0.03²) = 0.058

Step 2: 尝试更大扰动 δ = [0.08, 0.05]
  ã = 2·(0.5+0.08) + 3·(0.3+0.05) = 1.9 + 0.31 = 2.21
  D_act = 0.31 > 0.2 ✗ 超出容忍范围

Step 3: 二分搜索找到边界
  δ* ≈ [0.06, 0.037]
  ã ≈ 2.00, D_act ≈ 0.10 ≤ 0.2 ✓
  M(δ*) ≈ 0.07
```

**JND 分数**: s = ‖δ*‖₂ ≈ 0.07

**压缩决策**: 如果另一个 token 的 JND 分数为 0.03，则在剪枝时优先剪除分数 0.07 的 token（它的动作容忍度更高，压缩更安全）。

## 4. 工程视角 (Engineering View)

| 维度 | 数值/说明 | 来源 |
|------|----------|------|
| JND 估计器参数量 | 轻量 CNN（LayerNorm + 3×3 conv + n_s 空间残差块 + n_m 通道混合块 + 1×1 输出投影） | §IV-B1 |

| 推理时额外开销 | JND 估计器前向传播（单次 CNN 推理） | §IV-C |
| OpenVLA 87.5% 剪枝延迟 | 52.88ms → 30.16ms（CUDA），控制频率 18.91Hz → 33.15Hz | §V-B2 |
| OpenVLA 87.5% 剪枝 FLOPs | 降至 vanilla 的 33.06% | §V-B2 |
| 单视图 token 数 | 256（16×16 空间网格） | §IV-B1 |
| 双视图 token 数 | 512（主视图 256 + 腕部视图 256） | §IV-B1 |
| 双视图设计 | 两个独立 JND 估计器分别处理，避免混合不同视觉坐标系 | §IV-B1 |

**工程含义**:
- **即插即用**: JND 估计器不修改 VLA 架构，训练后作为独立模块插入现有压缩管线
- **训练成本可控**: 冻结 7B 参数的 OpenVLA，只训练一个小型 CNN 估计器
- **推理延迟 trade-off**: JND 估计器引入少量额外计算，但被 token 压缩带来的 FLOPs 大幅降低所抵消（净收益为正）
- **部署约束**: 需要每步推理时运行 JND 估计器 + 执行 token 排序，在边缘设备上需评估额外 CNN 推理是否值得

## 6. 能力与失败模式 (Capabilities & Failure Modes)

### 能做什么

- **激进 KV-cache 复用**: 在 60%-80% 复用比下，显著优于基于注意力的基线，因为直接优化动作保真度而非 proxy 信号
- **激进 Token 剪枝**: 在 87.5% 剪枝比下仍保持 42% 平均准确率（vs VLA-Cache 30.35%），因为移除的是动作容忍度最高的 token
- **双视图支持**: 独立处理主视图和腕部视图，不混合不同坐标系
- **兼容两种 VLA 范式**: 同时支持离散动作 token（OpenVLA）和连续动作回归（OpenVLA-OFT）

### 不能做什么

- **跨平台泛化未验证**: 实验仅在 LIBERO 桌面单臂操作场景测试，不能推断对移动机器人、双臂、人形机器人的效果
- **动态场景适应性未知**: JND 估计器在训练数据分布内有效，但面对分布外场景（新物体、新光照）的鲁棒性未评估
- **不替代架构级优化**: Action-JND 是 token 级压缩，不解决 VLA 模型本身的架构效率问题（如 parallel decoding、action chunking）

### 6.1 隐含假设 (Hidden Assumptions)

1. **JND 估计器的扰动空间足以覆盖实际压缩操作**: 估计器学习的是连续特征扰动，但实际压缩（剪枝/复用）是离散操作——两者之间的 gap 未量化
2. **训练时的动作偏差阈值 ε_a 在推理时同样适用**: 训练和推理使用相同的容忍标准，但推理时没有梯度信号来动态调整
3. **单步动作足以代表多步 chunk 的容忍度**: 论文承认单步公式可推广到多步 chunk，但未提供实验验证
4. **冻结 VLA 的梯度信号足够指导 JND 学习**: 训练时 VLA 冻结，仅通过动作偏差的梯度更新估计器——如果 VLA 的梯度信息不够丰富，估计器可能学到次优的 JND 边界
