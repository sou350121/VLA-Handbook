### 1.2 关键机制 (Key Mechanism)

论文的核心建模将 VLA 策略 $\pi$ 视为一个信息通道：

- **观察空间 X**：图像 + 语言指令的联合编码
- **动作空间 𝒜**：OpenVLA 中为 7 维（6-DoF 末端执行器 + 1-bit 夹爪），每维 256 个 bin
- **Oracle 动作 A\***：专家示范在同一观察下的动作
- **对抗扰动 $\delta$**：$\Vert\delta\Vert_\infty \leq \varepsilon$，可白盒自适应

**为什么用互信息而非准确率？** 准确率是一个标量阈值度量，无法捕捉策略输出分布的丰富性。互信息 $I(A^*; A_\pi)$ 衡量策略动作对 oracle 动作的"信息量"——它天然处理随机策略、多模态动作分布，并且满足数据处理不等式（DPI），这使得理论推导成为可能。

**泄漏扣减 −I(Aπ; δ) 的必要性**：一个退化策略可能直接把扰动 δ 嵌入到输出动作中，从而获得高 I(Aπ; Ãπ) 但没有真正的不变性。扣减项消除了这种病态情况。

⚡ **Eureka Moment**：能力与鲁棒性共享同一个"预算池"——这个预算只取决于任务本身（H(A\*)）和攻击者（I(X;X̃)），与策略架构、训练方法完全无关。任何鲁棒性提升如果不增加 A\* 信息，就必须从能力中扣除。

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：

```
Cap(π) + Rob(π) ≤ H(A*) + I(X; X̃)
```

**目标**：证明任何 VLA 策略的能力与鲁棒性之和存在一个与策略无关的上界。

**公式拆解**：

| 符号 | 定义 | 直觉 |
|------|------|------|
| $\mathrm{Cap}(\pi) = I(A^*; A_\pi)$ | 策略动作与 oracle 动作的互信息 | 策略"知道"多少正确答案 |
| Rob(π) = I(Aπ; Ãπ) − I(Aπ; δ) | 对抗下保留的互信息，扣减泄漏 | 策略在攻击下"不变"多少 |
| H(A\*) | oracle 动作的 Shannon 熵 | 任务本身的复杂度 |
| I(X; X̃) | 干净/扰动观察间的互信息 | 攻击信道容量（扰动保留了原始信息多少） |
| S = Budget − Cap − Rob | Slack（剩余容量） | $S \to 0$ 表示 Pareto 最优 |

**证明骨架**（三步）：

```
Step 1: Cap = I(A*; Aπ) = H(A*) − H(A*|Aπ) ≤ H(A*)
        等号成立 iff Aπ 是 A* 的充分统计量

Step 2: I(Aπ; Ãπ) ≤ I(X; X̃)
        两次 DPI: Aπ → X → X̃ 给出 I(Aπ; X̃) ≤ I(X; X̃)
                 Aπ → X̃ → Ãπ 给出 I(Aπ; Ãπ) ≤ I(Aπ; X̃)
        串联: I(Aπ; Ãπ) ≤ I(Aπ; X̃) ≤ I(X; X̃)

Step 3: −I(Aπ; δ) ≤ 0  (MI 非负)

合并: Cap + Rob ≤ H(A*) + I(X; X̃)
```

> 符号与本文保持一致：所有 MI 和熵以 nats 为单位。随机变量大写，具体实现小写。

**编码器级收紧（Corollary 4）**：

对于 $\pi = f \circ \phi$（$\phi$ 为冻结编码器，如 DINOv2+SigLIP）：

```
Cap(π) + Rob(π) ≤ H(A*) + I(ϕ(X); ϕ(X̃))
```

这通过将信道限制在编码器子空间，将边界收紧 $32\times$ 到 $50\times$（取决于 $\varepsilon$）。

## 3. 带数字走一遍：玩具例子 (Worked Example)

考虑一个简化的 2 维场景：

**设置**：
- 任务：2 个可能的 oracle 动作（左移 / 右移），$H(A^*) = \log(2) \approx 0.693$ nats
- 观察：$X \in \mathbb{R}^2$，动作 $A_\pi \in \{\text{左}, \text{右}\}$
- 攻击：$\varepsilon = 8/255$ 的 PGD 扰动

**干净策略**（Cap 高，Rob 低）：

```
Cap = I(A*; Aπ) = 0.55 nats    (策略正确捕捉了 ~80% 的 oracle 信息)
Rob = I(Aπ; Ãπ) − I(Aπ; δ) = 0.02 nats  (几乎无鲁棒性)
LHS = 0.55 + 0.02 = 0.57 nats
```

**对抗微调后**（Cap 降，Rob 升）：

```
Cap = 0.35 nats     (干净精度下降了)
Rob = 0.15 nats     (鲁棒性提升了)
LHS = 0.35 + 0.15 = 0.50 nats
```

**观察**：Cap + Rob 从 0.57 降到 0.50 —— 对抗微调同时缩小了 LHS。这是因为 AT 把策略推离了 A\* 的充分统计量流形，而 Rob 的增加不足以补偿 Cap 的损失。**这就是边界在经验层面的体现：鲁棒性不是免费的。**

**预算侧**（以 OpenVLA 真实数字为例，$\varepsilon = 8/255$）：

```
像素级预算:
  H(A*) ≈ 26 nats
  I(X; X̃) ≈ 5,000 nats (PCA tightened)
  Budget_pixel ≈ 5,026 nats
  Slack_pixel ≈ 5,026 − 7.5 ≈ 4,951 nats  (极度宽松)

编码器级预算:
  I(ϕ(X); ϕ(X̃)) ≈ 88 nats (ε=8/255, vanilla OpenVLA)
  Budget_enc ≈ 26 + 88 = 114 nats
  Slack_enc ≈ 114 − 7.5 ≈ 106 nats  (紧 47×)
```

| 工程维度 | 数值/事实 | 含义 |

| 松弛量 | ~10³ nats (像素级) / ~10² nats (编码器级) | 边界远未饱和 —— 现有策略离 Pareto 最优还很远 |
| 防御效果 | JPEG-50: +68 nats 编码器预算; LoRA: +0.7% | 输入端防御比 LLM 端防御对信息边界影响大 $100\times$ |

**工程含义**：

1. **部署约束**：如果你要在安全关键场景中部署 VLA，这个边界告诉你"最好的情况"是什么。即使理论上，$\varepsilon=16/255$ 的攻击也会收缩预算（$I(X; \tilde{X})$ 随 $\varepsilon$ 增大而减小）。
2. **模块边界**：编码器（DINOv2+SigLIP）是防御的关键插入点。输入端防御（JPEG 压缩、去噪）直接影响 I(ϕ(X); ϕ(X̃))，而 LLM 端防御（LoRA 微调）对信息边界影响极小。
3. **量化误差**：OpenVLA 的 256-bin 离散化使理论适用，但也意味着 tokenized VLA 的能力天花板比连续动作策略更低（Cor. 2）。

## 6. 能力与失败模式 (Capabilities & Failure Modes)

### 能做什么

| 能力 | 场景 | 原因 |
|------|------|------|
| 理论保证 | 任何离散化 VLA 策略 | 仅依赖 DPI + MI 非负，无需分布假设 |
| 防御诊断 | 判断防御干预信道的位置 | 编码器级边界对不同防御的预算偏移不同 |
| 跨论文对比 | 用 slack 替代绝对 Rob 数字 | Slack 归一化了不同任务/架构的不可比性 |
| 多步扩展 | 任意 horizon T | Cor. 3 逐步应用定理 1 |

### 不能做什么

| 失败模式 | 场景 | 原因 |
|----------|------|------|
| 构造最优策略 | 设计达到 Pareto 前沿的算法 | 边界是非构造性的（存在性，非算法性） |
| 紧预测 | 预测具体策略能达到的 Cap+Rob | Pixel-level slack ~10³ nats，过于宽松 |
| 连续动作直接适用 | $\pi_0$、扩散策略 | 需先量化（Cor. 2），量化会进一步收紧边界 |
| 自适应攻击下饱和 | PGD 攻击场景 | 自适应 $\delta(X)$ 破坏 Cor. 1(iii) 条件，等号永不成立 |

### 6.1 隐含假设 (Hidden Assumptions)

1. **离散化动作空间**：定理要求 H(A\*) 为有限 Shannon 熵。连续动作策略需先量化，但量化引入的误差方向是使边界更紧（对验证有利），而非更松。
2. **MINE 估计器的偏差方向**：论文声称 MINE 的低估偏差使 LHS 缩小而非 RHS，因此只增大 slack 不制造违反。这在 Gaussian proxy 中成立，但在真实 OpenVLA 上，Rob 的负值（符号伪影）可能掩盖真实的鲁棒性信号。
3. **编码器确定性**：Cor. 4 假设 $\phi$ 是确定性映射。如果编码器有 dropout 或随机增强，DPI 链需要修正。
4. **I(X; X̃) 的 PCA 上界**：像素级信道容量通过 PCA 收紧，但 PCA 本身是一个近似。真实的 ℓ∞-ball 约束集容量可能不同。
