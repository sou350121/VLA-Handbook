💡 **X-Ray 開場**
這篇問了三個問題：量化 VLA 的權重被少量位翻轉後會怎樣？需要多少次翻轉才能讓機器人閉環失敗？能不能只保護一小部分權重就扛住？

### 1.2 關鍵機制 (Key Mechanism)

- **為什麼 INT8 反而安全（謬誤）**：位寬低看似好攻擊，但實際上 INT8 的「有界值」消除了 NaN/∞ 爆炸。論文中 300 次隨機翻轉、100 次量級定向翻轉，動作偏移都 < 0.004（幾乎不變）。真正致命的是**損失對齊的梯度排序**，不是翻轉數量。
- **兩個設計選擇**：(1) 一個「穿得過迭代解碼」的**已執行動作目標**（Step 1）；(2) 一個**不受架構先驗限制**的量化感知排序（Step 2）。目標是 decoder-aware，定位搜索保持 architecture-agnostic。
- **為何用「固定方向流形逃逸」損失**：樸素的自偏差損失 −‖ã−ã_θ̂‖² 在 θ=θ̂ 處梯度為零，無法啟動一階搜索；各向同性「能量」損失在 flow head 上需要約 10 倍翻轉。固定方向損失把「有向位移」顯式化，經驗上把 π0 的預算從約 1000 降到約 100。
- **定位是「結果」而非「先驗」**：所有動作生成線性層都進入候選集（228–437 個矩陣），高增益位**自然集中**到少數層——直接頭集中於 LLM Layer 1，π0 集中於動作專家 Expert-L17（5-seed 均值）。

⚡ **Eureka Moment**：**同一個攻擊配方，跨架構的翻轉預算相差兩個數量級——因為傷害不是平均分佈，而是沿「動作生成通路」的少數高槓桿層集中；解碼器如何把權重擾動變成動作，決定了脆弱性。**

## 2. 數學核心 (Math Core)

📌 **Napkin Formula**（一行抓住本質）：

```
選 K 個位翻轉，使「已執行動作」沿固定方向 u 的最大投影被推離
→  min_{|F| ≤ K}  L_dir(θ̂ + δθ(F))
```

**目標**（Eq. 3，固定方向流形逃逸損失）：

```
d_θ^(m)(o) = ã_θ(o, x₁^(m)) − sg[ ã_θ̂(o, x₁^(m)) ]
L_dir(θ; θ̂) = − (1 / (|D_cal|·M)) Σ_{o∈D_cal} Σ_{m=1..M} ⟨ d_θ^(m)(o), u ⟩
```

**位增益**（Eq. 4–5，量化感知排序）：

```
g_ij^(ℓ) = ∂L_dir / ∂W_ij^(ℓ) |_{θ=θ̂}
s_ijb^(ℓ) = g_ij^(ℓ) · Δ_ijb^(ℓ)  ≈  ΔL_ijb^(ℓ)     （得分：預測損失變化）
G_ijb^(ℓ) = − s_ijb^(ℓ)                            （增益：正值代表翻轉有益）
G_ijb^(ℓ) = Δ_ijb^(ℓ) · E_{o,m}[ ⟨ ∂ã_θ/∂W_ij^(ℓ), u ⟩ ]
```

**INT8 有界性**（Def. 1–2）：

```
s_i = max( max_j |W_ij| / 127 , 1e−8 )
q_ij = clip_[−128,127]( round(W_ij / s_i) )
Δ_ijb = ( flip_b(q_ij) − q_ij ) · s_i
非符號位翻轉整數變化 ≤ 64；符號位翻轉變化 ≤ 128
⇒ |Δ_ijb| ≤ 128·s_i   （不會直接產生 ∞/NaN）
```

**收縮下界**（Appendix C，Proposition 1，僅為充分條件的直覺組織，未被端點診斷驗證）：

```
‖δa‖ ≤ C(μ) · Σ_ℓ L_ℓ·‖δθ_ℓ‖ ,   C(μ) = (1 − e^(−μ)) / μ
K ≥ D / ( L_max · b · C(μ) )
```

**變數說明**：

| 符號 | 含義 |
|------|------|
| ã_θ / ã_θ̂ | 攻擊時刻的可微動作（乾淨權重 θ̂ 用 stop-gradient 固定）|
| u | 固定方向，主實驗取全 1 向量；另測 −1 與三個高斯方向 |
| Δ_ijb | 翻轉第 b 位後去量化權重的精確變化 |
| G_ijb | 位增益，= 方向性動作敏感度 × 量化相關的翻轉幅度 |
| L_ℓ | 第 ℓ 塊權重對向量場 v 的敏感度上界（sup_s‖∂θℓ v‖）|
| μ | 雅可比對稱部分收縮係數（J_x + J_xᵀ ⪯ −2μI）|
| C(μ) | 收縮衰減因子，μ→0 時退化為 1（無衰減一階情形）|

**直覺**：G 是一個**投影**（動作沿 u 的敏感度），不是完整的敏感度範數。同一個方向 u 讓所有校準樣本擁有共同的動作空間朝向；排序因此不需要擬合幾何流形，也不需要強制每步梯度同號。搜索只需**一次反向傳播**，每權重評估 8 個位元，成本 O(8·N_w) = O(N_w)。

## 3. 帶數字走一遍：玩具例子 (Worked Example)

假設某動作生成線性層中一個權重 W_ij = 0.6，該輸出通道的最大絕對值為 1.27。

**Step A — 量化**：
```
s_i = 1.27 / 127 ≈ 0.01
q_ij = round(0.6 / 0.01) = 60   →  二進位 0011 1100
```

**Step B — 枚舉 8 個位元的 Δ**：

| 翻轉位元 | 位值 | 翻轉後整數 | 是否溢出 | Δ = (flip(q)−q)·s_i |
|---------|------|-----------|---------|---------------------|
| bit 2 | 4 | 56 | 否 | (56−60)·0.01 = −0.04 |
| bit 6 | 64 | 124 | 否 | (124−60)·0.01 = +0.64 |
| bit 7（符號）| 128 | 188→clip 127 | 是 | (127−60)·0.01 = +0.67 |

**Step C — 位增益**（設一次反向傳播得到 ∂L_dir/∂W_ij = −0.5）：
```
G_ijb = −g_ij · Δ_ijb
bit 2 : G = −(−0.5)·(−0.04) = −0.020   （負增益，丟棄）
bit 6 : G = −(−0.5)·(+0.64) = +0.320
bit 7 : G = −(−0.5)·(+0.67) = +0.335   ← 該權重的最佳位
```

**Step D — 全模型排序**：對每個權重取 b*_ij = argmax_b G_ijb，再把全部權重按增益排序，取 top-K 正增益者翻轉。

在這個玩具例中，符號位（bit 7）因為幅度上限 128s_i 最大，往往最容易成為「最佳位」——這與論文的真實機器人實驗一致：**100 個翻轉中 96 個是符號位翻轉，只有 4 個是 bit-6**。這個「符號位主導」的現象，也解釋了為何後續工作（Galil et al. 2026）專門研究符號位病變的選擇性保護。

**閉環放大直覺**：離散 OpenVLA 在 K=3 時，單步偏差僅 0.105（相對動作尺度 0.169，約 62%），但閉環成功率 0%。約 200 步的時域讓誤差逐步複合——最長時域的 LIBERO-Long 甚至**單一翻轉**就崩潰。

|---------|-----------|
| 攻擊成本 | 一次反向 + O(N_w) 排序；候選為所有動作生成線性層（228–437 個矩陣）|

**工程含義**：對直接回歸/離散頭，「保護 L1 一層」就是性價比最高的起點；對 flow head，局部保護會失效（攻擊會重新分佈，保護 14% 專家仍被打穿），但 flow head 本身已需要約 30 倍翻轉——這是一組**架構層面的權衡**：迭代解碼天然更貴，但也天然更韌。

## 6. 能力與失敗模式 (Capabilities & Failure Modes)

**能做**：
- 在 INT8 下用極少翻轉打垮閉環（直接頭 1–5，flow 頭約 100–300）
- 跨基準/跨具身泛化：LIBERO → SimplerEnv（不同 embodiment、OXE vs LIBERO 微調 checkpoint）
- 定向診斷：K=3 時在 99% 步數上反轉夾爪命令，而手臂偏差僅約 0.003
- 在真實機器人上驗證任務校準的邏輯權重損壞可造成失敗

**不能做 / 失敗模式**：
- **無隱蔽觸發後門（負面結果）**：T-BFA 式「乾淨行為 + 棋盤觸發」目標失敗——觸發條件下的乾淨/觸發梯度 cosine 僅約 0.24，30 次翻轉後乾淨閉環 SR 仍掉到 0%（K=10–30）。攻擊**不隱蔽**。
- **flow 頭局部保護無效**：保護 14% 專家仍被打穿，攻擊會重新分佈。
- **不構成物理可投遞性聲明**：評的是邏輯 INT8 損壞；~100–300 的 flow 預算超出已示範的物理投遞能力。
- **無跨任務遷移證據**：真實機器人只證明「任務校準」的損壞，未證明跨任務遷移；隨機對照也非層/位匹配。
- **視覺/輸入側攻擊不在範圍**：本文只碰權重，不碰輸入、訓練、激活、scale 或環境。

### 6.1 隱含假設 (Hidden Assumptions)

- **假設基線部署無有效 ECC/記憶體完整性**：若已有端到端 ECC，攻擊前提不成立（作者也承認這是防禦的 100% 覆蓋端點）。
- **假設攻擊者掌握完整知識**：架構、存儲權重、scale、解碼器、小型校準集。灰盒/黑盒場景未討論。
- **假設「閉環崩潰」由動作偏差單調驅動**：作者明確指出 endpoint 診斷不預測預算排序（π0.5 每日翻轉開環傷害更大，卻有更高的閉環預算），所以「偏差→失敗」的因果鏈並未建立。
- **假設量化 scale/激活不變**：只翻存儲整數，這在真實 Rowhammer 中取決於位址映射與故障剖面。
- **一階梯度忽略翻轉間交互**：one-shot 排序忽略選中位之間的相互作用；論文用 progressive PBS 做了部分驗證（每步重生梯度，選中位仍留在 LLM L1），但不覆蓋全部場景。

## 7. 與相關工作對比 (Comparison)

| 工作 | 攻擊面 | 目標 | 預算特徵 | 與本文差異 |
|------|--------|------|---------|-----------|
| BFA / PBS (Rakin 2019) | 量化分類器權重 | 分類輸出崩潰 | 約 11–17 次翻轉 | 分類器只讀出一次；本文是連續閉環動作 |

| FlipLLM / 符號位病變（2025-26）| LLM 多模態權重 | **類別式**輸出 | 稀疏符號位 | LLM 輸出離散且一次讀出；VLA 穿解碼器 + 閉環 |
| DP-Attacker (2024) | 擴散策略**輸入** | 視覺編碼器 | 輸入擾動 | 本文碰權重不碰輸入；定位不同層 |

🎯 **面試 Tip**: 被問到「VLA 的位翻轉攻擊和分類器有什麼本質不同」，一句話答——**分類器翻轉是單次讀出、有界的；VLA 翻轉穿過動作解碼器並在閉環裡反覆複合，所以解碼頭架構（尤其迭代 vs 單次讀出）直接決定了需要多少次翻轉才能讓機器人失敗。**

## 8. 精讀建議 (Reading Guide)

- **值得精讀原文的人**：
  1. 做 VLA 邊緣部署/量化落地的工程師——你需要知道「保護哪些層」的實證依據（§6.3、Fig. 5）
  2. 研究機器人/具身基礎模型安全的研究者——這是 VLA 權重攻擊的起點文獻（§4 威脅模型、§5 方法）
  3. 評估「解碼器架構 vs 魯棒性」權衡的架構設計者——flow head 的 10×–30× 預算差是很好的切入點（§6.5、Appendix B/C）

- **建議章節路徑**：先讀 §4 威脅模型（搞清攻擊邊界）→ 再看 §5.1 固定方向損失與 §6.2 攻擊結果（核心）→ 然後 §6.3 防禦 → 可跳 Appendix B（探索性 flow 衰減分析，作者自己說不構成因果結論）與 Appendix C（收縮下界僅為直覺組織，未被驗證）。

- **不值得精讀的理由**：如果你不做機器人/具身安全、也不涉及量化部署與記憶體完整性，讀摘要 + §7 對比表即可。另外注意：物理可投遞性、跨任務遷移、灰盒場景都是空白，若你的關注點正好在這些，本文給不了答案。
