### 1.2 关键机制 (Key Mechanism)

UniTexture 的核心流程分三阶段：

1. **校准-冻结**：用干净多视角图像拟合光照参数（每视角）和材质参数（每物体），Smooth-L1 损失对齐渲染与仿真器外观。校准后全部冻结。
2. **联合优化**：从任务分布中采样帧（任务、指令、姿态、视角），通过可微渲染器将共享纹理 θ 合成到观察图像中，送入冻结的 VLA 策略，计算动作空间目标损失，梯度回传到 θ。
3. **跨任务部署**：优化后的 θ 不变，直接用于所有任务——无需任何任务级微调。

⚡ **Eureka Moment**：不同任务的梯度可以"求共识"——一个纹理在所有任务的联合分布上优化后，能在每个单独任务上都产生有效的攻击信号，不需要为每个任务定制纹理。

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：

```
θ* = argmin_θ E_{τ~p(τ)} E_{ξ~D_τ} [ L_tgt( F(Ω(θ;I,C,P,M,ψ*)), L ); a* ]
```

**目标**：找到一个共享纹理 θ，使得在所有任务的联合分布上，VLA 预测的动作被推向攻击者指定的目标动作 a*。

**公式拆解**：

```
Ω(θ; I, C, P, M, ψ*) = M ⊙ R_ψ*(θ, C, P) + (1 - M) ⊙ I
```

| 符号 | 含义 |
|------|------|
| θ | H×W×3 的 UV 纹理贴图，值域 [0,1] |
| I | 原始观察图像 |
| C, P, M | 相机参数、物体 6-DoF 姿态、物体图像遮罩 |
| R_ψ* | 使用校准参数 ψ* 的可微渲染器 |
| Ω | 合成后的攻击观察（纹理物体替换原物体） |
| F | 冻结的 VLA 策略 |
| a* | 攻击者指定的目标动作 |
| L_tgt | 模型特定的目标损失（见下） |

**模型特定的目标损失**：

对于 **OpenVLA（自回归动作令牌）**：

```
L_tgt^tok(θ) = -1/|J| Σ_{j∈J} log p_F(z_j* | I~, L)
```

其中 z_j* = Q_act(a*) 是目标动作维度 j 的令牌，p_F 是冻结策略赋予该令牌的条件概率。

对于 **π0.5（流匹配动作块）**：

```
L_tgt^flow(θ) = 1/H_a Σ_{h=1}^{H_a} [ v_F(I~, L, x_t, t)_{h,j} - (u_t)_{h,j} ]²
```

其中 x_t = t·ε + (1-t)·A* 是流匹配时间 t 的噪声动作块，v_F 是策略预测的速度场，u_t = ε - A* 是目标速度。

> 符号与原文保持一致。所有公式来自论文 Equation (1)-(8)。

## 3. 带数字走一遍：玩具例子 (Worked Example)

假设一个简化场景：

- **目标物体**：一个盘子（plate），UV 纹理 224×224×3
- **目标动作**：将 z 轴平移推向 +1（向上）
- **两个任务**：τ₁ = "把盘子推到左边"，τ₂ = "把盘子推到右边"

**优化过程（单步示意）**：

```
步骤 1: 采样
  τ₁: I₁, L₁="push plate left", 盘子姿态 P₁, 遮罩 M₁
  τ₂: I₂, L₂="push plate right", 盘子姿态 P₂, 遮罩 M₂

步骤 2: 渲染+合成
  I~₁ = M₁⊙R_ψ*(θ, C₁, P₁) + (1-M₁)⊙I₁
  I~₂ = M₂⊙R_ψ*(θ, C₂, P₂) + (1-M₂)⊙I₂

步骤 3: VLA 前向
  a₁ = F(I~₁, L₁)  → 假设 z 分量 = -0.3 (原本向左推)
  a₂ = F(I~₂, L₂)  → 假设 z 分量 = -0.1 (原本向右推)

步骤 4: 计算损失 (π0.5 流匹配目标)
  目标 a* = +1.0 (向上)
  L₁ = (v_F(...) - u_t)²  → 鼓励 z 方向速度为正
  L₂ = 同上
  L = (L₁ + L₂) / 2

步骤 5: 梯度回传 + 更新
  ∇_θ L 通过可微渲染器反向传播
  θ ← θ - lr·∇_θ L, clip 到 [0,1]
```

经过 1001 轮迭代（每轮 50 次内部更新），纹理 θ 学会了：无论任务指令是"向左"还是"向右"，只要盘子出现在画面中，VLA 预测的 z 轴动作都会被推向 +1 方向。

**结果**：在 LIBERO-Spatial 上，π0.5 的成功率从 99% 降到 33%（盘子纹理）/ 40%（碗纹理），TDS（目标方向偏移）分别达到 10.6 和 17.9。

## 4. 工程视角 (Engineering View)

| 工程维度 | 数值/约束 | 含义 |
|----------|----------|------|
| 渲染分辨率 | 224×224 | 与 VLA 输入对齐，PyTorch3D 软 Phong 着色 |
| 优化迭代 | 1001 轮 × 50 次内部更新 = 50,050 次前向 | 每个纹理约需数小时 GPU 时间 |
| 优化器 | AdamW, lr=1e-3, cosine decay, batch=8 | 标准配置 |
| 攻击目标 | z 轴平移 +1（向上） | 最有效方向；-z（向下）效果最差（SR=91%） |
| 每任务评估 | 10 任务 × 10 次 rollout = 100 episodes | LIBERO 标准协议 |
| π0.5 执行 | 每 chunk 执行 5 步再重查询 | 比 OpenVLA（每步查询）更高效但攻击面更大 |
| 物理部署门槛 | 3D 打印目标物体 + UV 纹理印刷 | 中等，需匹配仿真器中的物体几何 |

**关键 trade-off**：攻击需要白盒梯度访问（优化阶段），但部署阶段完全黑盒——只需把优化好的纹理物体放在桌面上，无需与 VLA 交互。

## 5. 数据与评测 (Data & Eval)

**数据集**：LIBERO-Spatial 和 LIBERO-Goal，各 10 个语言条件操作任务。两个 suite 共享相同的盘子和碗物体。

**评估协议**：

| 设置 | 描述 |
|------|------|
| 干净基线 | LIBERO 原始观察，不经渲染管线 |
| 渲染原始纹理 | 原始物体纹理通过冻结渲染器（隔离渲染引入的误差） |
| 高斯噪声纹理 | N(0.5, 0.2²) 随机纹理，不经优化（隔离外观变化的影响） |
| UniTexture | 优化后的对抗纹理 |

**核心指标**：

| 指标 | 含义 | 计算方式 |
|------|------|----------|
| SR (Success Rate) | 任务成功率 | 成功 episode 占比 |
| TDS (Target Direction Shift) | 攻击引起的目标方向偏移 | E[σ·(a_adv - a_clean)] × 100 |
| pDHR (paired Direction Hit Rate) | 攻击导致目标方向命中的比例 | P[σ·(a_adv - a_clean) ≥ 0.01] × 100% |

**关键数据点**（来自论文 Table 1）：

- π0.5 + Spatial + 盘子: SR 99%→33%, TDS=10.6, pDHR=61.0%
- π0.5 + Spatial + 碗: SR 97%→40%, TDS=17.9, pDHR=65.5%
- OpenVLA + Spatial + 盘子: SR 84%→53%, TDS=-2.4（方向偏移为负！）
- 均值: 90.0%→48.4%（所有设置平均）

## 6. 能力与失败模式 (Capabilities & Failure Modes)

**能做什么**：

| 场景 | 效果 | 原因 |
|------|------|------|
| 同一 suite 内所有任务 | SR 降低 20-66 个百分点 | 纹理在任务联合分布上优化 |
| 跨 suite 迁移（同一策略） | SR 仍低于干净基线 | 任务间共享视觉-动作映射 |
| π0.5 → OpenVLA 跨模型 | SR 降至 26-61% | OpenVLA 对纹理变化更敏感 |
| 定向控制（π0.5） | TDS 持续为正，pDHR 42-90% | 流匹配目标直接优化连续动作 |

**不能做什么**：

| 场景 | 限制 | 原因 |
|------|------|------|
| OpenVLA 定向控制 | TDS 可能为负，pDHR 仅 31-35% | 离散令牌接口破坏方向信号 |
| 黑盒攻击 | 需要目标模型梯度 | 优化依赖 ∇_θ L_tgt |
| 跨模型反向（OpenVLA→π0.5） | π0.5 SR 保持 92-97% | π0.5 对物体外观变化更鲁棒 |
| -z 方向攻击 | SR 仅降到 91% | 向下偏移与正常接近动作一致 |

### 6.1 隐含假设 (Hidden Assumptions)

1. **攻击者可访问目标 VLA 的梯度**：白盒假设。实际部署中可能需要迁移攻击或查询攻击来绕过。
2. **目标物体在任务中频繁出现**：LIBERO 中盘子和碗是核心交互物体。如果目标物体在任务中出现频率低，攻击效果会衰减。
3. **渲染器校准可行**：需要干净多视角图像来拟合光照和材质参数。物理世界中这可能受限于传感器精度。
4. **单一目标动作 a***：论文固定 a* = +1（向上）。实际攻击可能需要根据任务动态选择目标。
5. **仿真到现实的 gap 可控**：纹理在仿真中优化，部署到物理世界时渲染差异可能降低攻击效果（论文未评估 sim2real）。
