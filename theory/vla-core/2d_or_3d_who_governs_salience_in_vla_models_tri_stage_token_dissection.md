### 1.2 关键机制 (Key Mechanism)

**为什么这样设计？**

1. **三阶段划分的必要性**：MVLA 的数据流不是端到端黑盒，而是明确的三阶段流水线（预处理→语义合成→动作迭代）。每个阶段 2D/3D 的贡献不同，必须分阶段处理。

2. **模态显著性差异**：2D 擅长纹理/颜色/语义，3D 擅长空间结构/深度关系。在不同任务阶段，两者的相对重要性会变化。

3. **动态自适应**：动作迭代过程中环境状态变化，显著性也会波动，需要时间维度上的预测和调整。

⚡ **Eureka Moment**：MVLA 的 token 剪枝不能简单套用 SVLA 方法——2D 和 3D 模态在三阶段中的显著性是动态变化的，必须分阶段、分模态、分语义地自适应剪枝。

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：

```
S_modal = α·||F_2D|| + β·||F_3D||,  其中 α, β 随阶段/语义/时间动态变化
```

**目标**：在最小化精度损失的前提下，最大化 token 剪枝率，从而降低 MVLA 推理延迟。

**公式**（三阶段显著性量化）：

```
Stage 1 (Preprocessing):  S_m = ||F_m||_2 / (||F_2D||_2 + ||F_3D||_2), m ∈ {2D, 3D}

Stage 2 (Semantic):       S_m^k = Σ_{i∈Patch_k} Attention(m_i, query) / |Patch_k|

Stage 3 (Iteration):      S_m(t) = S_m(t-1) + ΔS_m · Δt + ε(t)
```

**变量说明**：

| 符号 | 含义 | 来源 |
|------|------|------|
| S_m | 模态 m 的显著性分数 | 本文定义 |
| F_m | 模态 m 的编码器输出特征 | 2D/3D ViT |
| ||·||_2 | L2 范数 | 特征幅值度量 |
| Patch_k | 第 k 个语义 patch 集合 | 注意力聚类 |
| t | 动作迭代时间步 | 时序索引 |
| $\Delta S_m$ | 显著性变化率 | 经验估计 |
| $\varepsilon(t)$ | 环境扰动项 | 不可预测波动 |

**直觉**：用特征范数衡量"谁贡献更大"，用注意力分数衡量"在哪些语义区域谁更重要"，用时序预测捕捉"随任务进展如何变化"。

> 符号与本文/相关文档保持一致：F 表示特征 (Feature)，S 表示显著性 (Salience)，下标 m 表示模态 (modal)，上标 k 表示语义 patch 索引。

## 3. 带数字走一遍：玩具例子 (Worked Example)

假设一个 MVLA 模型处理"抓取桌上红色方块"任务：

**初始状态**（Stage 1 预处理）：
- 2D 输入：RGB 图像，256 tokens
- 3D 输入：点云，256 tokens
- 特征范数：||F_2D|| = 12.3, ||F_3D|| = 8.7
- 显著性计算：S_2D = 12.3/(12.3+8.7) = 0.586, S_3D = 0.414

→ **剪枝决策**：2D 保留 85% tokens（~217 个），3D 保留 70% tokens（~179 个）

**语义合成阶段**（Stage 2）：
- Patch 1（"红色"语义）：注意力分析显示 2D 主导（颜色信息）
  - $S_{2D}^{\text{color}} = 0.82$, $S_{3D}^{\text{color}} = 0.18$
  - 2D 保留 90%，3D 保留 40%
- Patch 2（"空间位置"语义）：3D 主导（深度/距离）
  - $S_{2D}^{\text{spatial}} = 0.35$, $S_{3D}^{\text{spatial}} = 0.65$
  - 2D 保留 50%，3D 保留 85%

**动作迭代阶段**（Stage 3，$t=0\to5$）：
- t=0（初始接近）：3D 显著性上升（需要精确距离）
- t=2（接触前）：2D 显著性回升（视觉伺服）
- t=5（抓取完成）：两者均衡

**最终结果**：
- 原始 tokens：512 个
- 剪枝后 tokens：~280 个（剪枝率 45%）
- 推理速度：从 4 Hz → 10.2 Hz（2.55x）
- 任务成功率：从 87% → 85%（仅下降 2%）

- 显著性阈值量化：建议 8-bit 量化（0-255 级）

- 额外缓存：需存储三阶段中间状态（特征范数、注意力图、时序预测参数）

**部署约束**：
- 需要访问 MVLA 内部特征（非黑盒 API）
- 需要双 ViT 编码器输出（2D+3D 分离）
- 适合自研/开源 MVLA，商用闭源模型需定制集成

### 6.1 隐含假设 (Hidden Assumptions)

1. **2D/3D 编码器分离**：假设 MVLA 使用独立的 2D ViT 和 3D ViT，若使用统一多模态编码器则方法需调整。

2. **注意力可解释性**：假设注意力分数能有效反映模态显著性，但注意力机制本身存在争议（是否真代表重要性）。

3. **时序可预测性**：假设显著性随时间变化有一定规律可预测，但复杂任务中环境扰动可能超出模型预测能力。

4. **任务类型覆盖**：实验可能集中在桌面操作任务，对移动操作/双臂协作/人形机器人的泛化性待验证。
