## 1. 核心架构/方法总览 (Overview / Architecture)

VLA-Trace 不是一个新的 VLA 模型，而是一个**诊断框架**——它像一台 CT 扫描仪，对已有的 VLA 模型进行三层递进式"切片"分析。

### 1.1 系统对比概览 (System Component Comparison)

| 维度 | $\pi_{0.5}$ | OpenVLA |
|------|------|---------|
| 基础 VLM | PaliGemma（双向注意力） | Llama（单向自回归注意力） |
| 动作生成 | 流匹配（flow matching） | 自回归 token 预测 |
| 输入格式 | 多视角图像 + BOS token + 任务指令 + 换行符 | 图像 patch + 模板 prompt（"In: What action...? Out:"） |
| 跨模态对齐 | 中间层广泛分布，波动大 | 平滑但较弱，集中在边界/末端层 |
| 主要漂移模态 | **文本**表征（重组织为任务条件控制特征） | **视觉**和联合表征 |
| 动作解码通路 | **视觉→动作**单通路主导 | 视觉 + 语言双通路 |
| 脆弱层数 | 窄瓶颈（少数关键层） | 广布脆弱区（多层分布） |
| 视觉注意力模式 | 分布式（高质量低峰值命中） | 稀疏集中（低质量高峰值命中） |

### 1.2 关键机制 (Key Mechanism)

VLA-Trace 的三阶段设计遵循"从几何到因果到行为"的证据链：

**阶段 1：表征偏移分析（Representation Shift）**
- 使用 CKA（Centered Kernel Alignment）量化三个检查点（C0: 预训练 VLM → C1: 预训练 VLA → C2: 任务微调 VLA）之间的表征几何变化
- 两个维度：跨模态 CKA（视觉 vs 文本对齐）+ 检查点漂移 CKA（各模态 pooled 表征的阶段间保留度）

**阶段 2：因果通路识别（Causal Pathways）**
- 注意力 knockout 干预：在预填充（prefill）阶段阻断 V-L 注意力，在生成（gen）阶段阻断动作 token 对视觉/文本的注意力
- 区分两个角色：(i) 表征编码阶段的多模态整合，(ii) 动作解码阶段的模态依赖

**阶段 3：行为探针（Behavioral Probes）**
- 注意力 IoU：量化动作查询对视觉 patch 的注意力与任务相关区域的重叠
- 视觉 patch 掩码：替换/遮挡目标物体、夹爪、机器人本体、背景
- 输入编辑：修改指令中的目标物体名称，观察行为是否跟随变化

⚡ **Eureka Moment**：VLA 模型的性能相似，但内部路由策略可能完全不同——π0.5 几乎只靠视觉做决策（语言形同虚设），而 OpenVLA 真正在使用双模态信息。这意味着"高成功率"掩盖了架构层面的根本差异。

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：
```
VLA-Trace(X) = CKA_跨模态(X) ⊕ CKA_漂移(X, C0:C1:C2)
             ⊕ Knockout_注意力(X, {V, L, A})
             ⊕ Probe_行为(X, {IoU, Mask, Edit})
```
VLA-Trace 将 VLA 模型 X 的诊断分解为四个正交探针的串联证据链。

### 2.1 跨模态 CKA

**目标**：量化视觉和文本表征之间的几何对齐程度。

```
CKA(X, Y) = ||X^T Y||_F^2 / (||X^T X||_F · ||Y^T Y||_F)
```

其中 X ∈ R^{N×dx}, Y ∈ R^{N×dy} 是样本×特征的表征矩阵，||·||_F 是 Frobenius 范数。

**变量说明**：
- N: 样本数
- dx, dy: 视觉/文本表征维度
- 值域 [0, 1]，越高表示两个模态的表征几何越相似

**直觉**：如果视觉和文本的 CKA 很高，说明模型把两种模态映射到了相似的几何空间——它们"看到"和"读到"的是同一个东西。

### 2.2 检查点漂移 CKA

**目标**：量化训练过程中各模态表征的保留/重组程度。

```
DriftCKA^v(c_t | c_a) = (1/|L|) · Σ_{l∈L} CKA(H^{v}_{c_a,l}, H^{v}_{c_t,l})
```

**变量说明**：
- $v \in \{\text{vision}, \text{text}, \text{joint}\}$: 表征视图（视觉池化/文本池化/联合池化）
- $c_a$, $c_t$: 锚点检查点和目标检查点（C0→C1→C2）
- $H^{v}_{c,l}$: 检查点 $c$ 第 $l$ 层的视图 $v$ 的表征矩阵  
- L: 评估的层集合

**直觉**：DriftCKA 越高 = 表征几何越稳定（保留预训练知识）；越低 = 重组越多（为机器人任务适配而改变）。$\pi_{0.5}$ 的文本 DriftCKA 低 → 语言被大量重组织；OpenVLA 的视觉 DriftCKA 低 → 视觉被大量重组织。  

### 2.3 注意力 IoU（行为空间的地标对齐）

```
IoU_90(M) = |H_90(A) ∩ M| / |H_90(A) ∪ M|
```

**变量说明**：
- A: 动作查询对视觉 patch 的平均注意力图
- $H_{90}(A)$: 注意力值 $\geq 90$ 分位数的 patch 集合  
- M: 模拟器提供的任务相关区域掩码（目标物体/机器人+物体）

**直觉**：动作注意力聚焦的区域，和真正该看的区域，重叠了多少？

> 符号与本文/相关文档保持一致：CKA 沿用 Kornblith et al. (2019) 原始定义；DriftCKA 为本文提出的阶段间几何保留度量。

## 3. 带数字走一遍：玩具例子 (Worked Example)

假设我们要诊断一个简化版的 VLA 模型（3 层 Transformer），执行 VLA-Trace 的完整流程：

**Step 1: 跨模态 CKA**
```
Layer 1: CKA(vision, text) = 0.72  → 预训练 VLM 阶段，视觉和文本已有较好对齐
Layer 2: CKA(vision, text) = 0.45  → VLA 微调后，中间层对齐下降
Layer 3: CKA(vision, text) = 0.68  → 末端层恢复对齐（为动作输出做准备）
```
直觉：中间层的对齐下降说明模型在"重新组织"多模态信息——不是简单传递，而是在融合。

**Step 2: 检查点漂移（文本视图）**
```
DriftCKA^text(C1|C0) = 0.61  → VLA 预训练保留了 61% 的文本几何
DriftCKA^text(C2|C1) = 0.38  → 任务微调只保留了 38%！
```
结论：任务微调阶段对文本表征的重组非常剧烈——$\pi_{0.5}$ 的文本表征被大量改写为任务条件控制特征。  

**Step 3: 注意力 Knockout**
```
Baseline (全模态):       LIBERO-10 成功率 = 93.5%
Gen: no image (去视觉):   LIBERO-10 成功率 = 0.0%   ← 致命！
Gen: no text  (去文本):   LIBERO-10 成功率 = 39.0%   ← 下降但不崩溃
```
结论：$\pi_{0.5}$ 的动作解码极度依赖视觉通路。语言在预填充阶段塑造了表征，但在生成阶段几乎不被使用。  

**Step 4: 行为探针 — 输入编辑**
```
原始指令: "put the white mug on the plate" → 成功率 80%
编辑指令: "put the red mug on the plate"   → 成功率 70%（仅降 10%）
```
结论：改了指令中的颜色词，模型大部分时候还是去拿原来的白色杯子。语义跟随能力有限。

## 4. 工程视角 (Engineering View)

| 维度 | 发现 | 工程含义 |
|------|------|---------|
| 模态依赖 | $\pi_{0.5}$ 视觉→动作单通路；OpenVLA 双通路   | 部署时若视觉质量下降（光照/遮挡），$\pi_{0.5}$ 会完全失效；OpenVLA 有语言兜底   |
| 脆弱层 | $\pi_{0.5}$ 窄瓶颈（1-2 层）；OpenVLA 广布（多层）   | $\pi_{0.5}$ 的量化/剪枝需极度小心关键层；OpenVLA 可承受更激进的压缩   |
| 语义跟随 | 两者均有限 | 需要额外的语义编辑训练目标（counterfactual instruction-image pairs） |
| 视觉捷径 | 两者都依赖场景布局线索（背景遮蔽降 25-30%） | 部署环境变化（新背景/新桌面）可能导致性能骤降 |
| 夹爪可见性 | $\pi_{0.5}$ 强依赖夹爪区域；OpenVLA 强依赖完整机器人可见性   | 不同型号的机械臂迁移需注意可见性差异 |

**部署约束**：
- $\pi_{0.5}$ 的视觉瓶颈意味着单目→多目的迁移收益可能集中在关键层，而非均匀分布  
- OpenVLA 的双通路设计在视觉退化场景下理论上更鲁棒，但实验显示其背景遮蔽敏感性更高（Robot BG 遮蔽降 $69\%$ vs $\pi_{0.5}$ 的 $56\%$）

**评估模型**：
- $\pi_{0.5}$：PaliGemma + 流匹配动作专家，双向注意力  
- OpenVLA：Llama-based 自回归，单向注意力

**基准数据集**：

- LIBERO-10/Goal/Object/Spatial：机器人域 benchmark（论文 Table 2-5 的核心数据源）
- LIBERO-10 作为主要 rollout 评估集（200 episodes $\times$ 10 tasks）  

**评测指标**：
- CKA 值：表征几何相似度（非绝对性能指标）
- 成功率 (%)：200 episodes 的闭环执行结果
- Attention IoU/Mass/Hit：视觉接地质量的三个互补维度
- 平均下降 (Avg. Drop)：遮蔽策略下的性能损失

## 6. 能力与失败模式 (Capabilities & Failure Modes)

### 能做什么
- **视觉接地轨迹生成**：两者都能将注意力正确聚焦到机器人-物体交互区域（Table 3: Robot+Object IoU_90 ≈ 0.13-0.15）
- **时序任务语义编码**：LIBERO-10 双子目标任务中，注意力在 Phase 1→Phase 2 间正确转移（图 5a）
- **诊断 $\pi_{0.5}$ vs OpenVLA 的架构差异**：框架有效区分了两种截然不同的模态路由策略

### 不能做什么
- **细粒度语义跟随**：修改指令中的目标物体名称，行为不一定跟随（Table 5: moka pot→frypan 从 75% 降到 30%，但 white mug→red mug 仅从 80% 降到 70%）
- **背景不变性**：背景遮蔽导致所有模型性能下降 7-30%（Table 4），说明依赖场景布局
- **跨架构泛化结论**：目前仅完整评估 2 个模型，结论不能直接推广到 X-VLA、GR00T 等

### 6.1 隐含假设 (Hidden Assumptions)

| 假设 | 说明 | 风险 |
|------|------|------|
| CKA 值反映"语义对齐" | CKA 测量几何相似性，但不直接等于语义理解 | CKA 高 ≠ 理解好，可能是过拟合的几何匹配 |
| Attention Knockout 失败 = 自然 OOD 失败 | knockout 是受控必要性探测，不是自然分布偏移 | 可能高估或低估真实鲁棒性 |
| LIBERO 任务 $\approx$ 真实机器人任务 | LIBERO 是模拟环境，物体/光照/物理模型简化 | 结论外推到真实世界需谨慎 |
| 注意力图 = 视觉接地 | Attention IoU 基于注意力权重，但注意力不等于"看" | 可能存在"有注意力但无理解"的情况 |
| C2 检查点跨 suite 共享 | $\pi_{0.5}$ 的 C2 在多个 LIBERO suite 上共享同一权重 | suite 间差异反映评估分布而非权重变化 |
