💡 **X-Ray 开场**
VF-VLA（Visual Foresight VLA）先预测未来图像再生成动作，这让它对分布外偏移特别脆弱——视觉预测和动作生成两个阶段同时受影响。本文发现：预测的未来图像和实际到达的图像天然构成一对自监督信号，可以在推理阶段直接用这对信号微调模型。配合一个自适应的方差过滤机制，T3VF 在 LIBERO-Plus 上把平均成功率提升了 5%，且不需要任何新模块或外部奖励。

### 1.2 关键机制 (Key Mechanism)

**核心洞察**：VF-VLA 在 step t 预测 ô_{t+n}，执行动作后 n 步到达真实观测 o_{t+n}。这对 (ô_{t+n}, o_{t+n}) 天然构成自监督对——不需要任何外部标注。

**两大挑战与对应方案**：

1. **噪声过滤**：预测误差可能来自视觉通路（需要更新）或动作通路（噪声）。用动作方差 σ²_t 作为代理指标——低方差说明动作确定，误差可归因于视觉；高方差说明动作本身不确定，跳过。

2. **自适应阈值**：固定方差阈值在不同难度 episode 间不通用。改用滑动窗口缓冲区 V_t（最近 |V|=10 步的方差），当 σ²_t ≤ Quantile_ρ(V_t) 时才更新。相对排序而非绝对截断，自然适应每个 episode 的难度尺度。

⚡ **Eureka Moment**：预测的未来图像和实际到达的图像天然构成自监督对——不需要外部奖励、不需要标注，环境本身就提供了"你猜对了没有"的答案。

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：
```
q ← q - α · ∇_q [ (1/B) Σ_{(ô, o)∈B} ℒ_img(ô, o) ]
条件：σ²_t ≤ Quantile_ρ(V_t)
```

**目标**：在测试时利用环境反馈的自监督信号，仅更新最小参数子集 q，使视觉预测通路逐步适应当前 OOD 环境。

**核心方程**：

```
ℒ_TTT = (1/B) Σ_{(ô_{t+n}, o_{t+n}) ∈ B} ℒ_img(ô_{t+n}, o_{t+n})
```

与训练阶段的目标 ℒ_train = ℒ_img + λ·ℒ_act 相比，测试时仅优化图像预测损失，且只更新 q。

**变量说明**：

| 符号 | 含义 | 本文取值 |
|------|------|----------|
| n | 预见步长（gap） | 4 |
| B | 测试时训练 batch size | 4 |
| K | 动作采样次数（用于方差） | 5 |
| \|V\| | 方差缓冲区大小 | 10 |
| ρ | 分位数阈值 | 0.3 |
| q | 可学习查询 token | 唯一被更新的参数 |
| σ²_t | 动作方差 | (1/K) Σ_k \|\|â_t^{(k)} - ā_t\|\|²_2 |

**直觉**：当模型对动作高度确定（低 σ²）时，预测误差更可能来自视觉通路而非动作通路——这时用 (ô, o) 对更新 q 是"对症下药"。缓冲区 V_t 确保阈值是相对的：在难的 episode 中放宽标准，在容易的 episode 中收紧标准，避免固定阈值导致的"简单段过更新、困难段不更新"问题。

> 符号与本文保持一致：ô 为预测图像，o 为实际到达图像，ℒ_img 为训练阶段使用的图像损失（具体形式依赖 VF-VLA 实现，如 MSE 或交叉熵）。

## 3. 带数字走一遍：玩具例子 (Worked Example)

假设一个简化的 2D 场景：

**初始状态**：
- 当前观测 o_t = [0, 0]，指令 l = "把方块放到红色区域"
- 模型预测 ô_{t+4} = [3, 2]（预见 4 步后的位置）
- 执行动作后实际到达 o_{t+4} = [5, 4]

**方差过滤**：
- K=5 次动作采样：{[1,0], [1.1,0.05], [0.9,0.1], [1.05,0.02], [0.95,0.08]}
- 平均动作 ā_t = [0.98, 0.05]
- 方差 σ²_t = (1/5) × Σ \|\|â^{(k)} - ā\|\|² ≈ 0.003（低方差 → 动作确定）

**缓冲区判断**：
- V_t = {0.005, 0.008, 0.002, 0.012, 0.003, 0.006, 0.001, 0.009, 0.004, 0.007}
- Quantile_0.3(V_t) ≈ 0.0035
- σ²_t = 0.003 ≤ 0.0035 → **通过过滤，纳入 B**

**测试时更新**：
- 假设 B 已积累 4 个样本，计算 ℒ_TTT
- 假设 ∇_q ℒ_TTT 在 q 方向上的梯度为 [0.1, -0.05, 0.02]
- α = 0.001（学习率）
- q_new = q_old - 0.001 × [0.1, -0.05, 0.02] = q_old - [0.0001, -0.00005, 0.00002]

**效果**：q 微调后，下一轮预见 ô_{t'+4} 会更接近真实 o_{t'+4}，进而通过 h_act 改善动作质量。循环往复，模型逐步适应 OOD 环境。

## 4. 工程视角 (Engineering View)

| 维度 | 数值/权衡 | 工程含义 |
|------|-----------|----------|
| 推理开销 | 1.3× 基线时间（vs 无过滤 1.7×） | 方差计算（K=5 次采样）是主要额外开销；自适应过滤减少了 60% 的无效更新 |
| 更新频率 | 约 30% 的 step 触发更新（ρ=0.3） | 不是每步都更新——过滤机制在"学得够多"和"不过载"间平衡 |
| 参数量 | 仅更新 q（查询 token） | q 是参与视觉预测通路的最小模块；但这也意味着 backbone 的特征提取能力不变，适应上限受限 |
| 内存开销 | 缓冲区 V_t 存储 10 个方差值 + 批量 B=4 的图像对 | 极低，无需额外模型或缓存 |
| 部署约束 | 无需修改模型架构 | 可直接叠加到任何 VF-VLA 上（Mantis、WorldVLA 等），即插即用 |
| 延迟影响 | 每步多一次 K 次采样 + 方差计算 | 方差计算可并行（单次 backbone forward + 并行 action head decode），实际延迟增加可控 |

**关键 trade-off**：只更新 q 而非 backbone 参数——这保证了轻量和安全（不破坏预训练知识），但也意味着模型无法从根本上改变视觉特征提取方式。在极端 OOD 场景下（如完全不同的机器人平台），这种轻量更新可能不够。

## 6. 能力与失败模式 (Capabilities & Failure Modes)

**能做什么**：
- 在中等 OOD 偏移下（LIBERO-Plus 的 lighting/background 扰动），通过测试时自监督逐步改善视觉预测
- 不需要任何训练管道改动——部署时即插即用
- 开销可控（1.3×），适合对延迟不极端敏感的场景

**不能做什么**：
- 极端 OOD（如完全不同的机器人平台、未见过的物体类别）—— q 的容量有限，无法改变 backbone 的特征提取
- 需要实时性的场景（1.3× 开销可能不可接受）
- 非 VF-VLA 架构（直接动作生成的 VLA 如 RT-1 没有预测-到达对，不适用）

### 6.1 隐含假设 (Hidden Assumptions)

1. **预测-到达对的质量**：假设 o_{t+n} 可以作为 ô_{t+n} 的可靠 oracle。但在长 horizon 任务中，n=4 步后环境可能因外部干扰（人碰了物体等）而改变，此时 o_{t+n} 不是预测质量的准确反映。

2. **方差作为代理指标的充分性**：低动作方差 ≠ 视觉预测误差可归因。模型可能对错误动作高度确定（自信地犯错），此时方差低但误差源仍是动作通路。

3. **q 的容量足够**：只更新查询向量 q 假设 q 有足够的表达能力来编码 OOD 适应信息。但 q 通常只有几十个到几百个 token，容量有限。

4. **episode 内难度变化可用滑动窗口捕捉**：假设最近 10 步的方差分布能代表当前难度。但在难度突变（如突然遇到障碍物）时，窗口可能滞后。
