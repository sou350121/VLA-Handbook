## 1. 核心架构/方法总览 (Overview / Architecture)

### 1.1 系统对比概览 (System Component Comparison)

| 组件 | RT-2 / OpenVLA 基线 | VLANeXt 最终配方 | 关键差异 |
|------|---------------------|-------------------|----------|
| VLM Backbone | LLaMA 3.2-3B + SigLIP2 | Qwen3-VL-2B | 更强的多模态理解能力 |
| 策略头 | 复用文本 token 做分类 | 12 层 Transformer + 16 个 Meta Query tokens | 解耦动作预测与语言空间 |
| 动作输出 | 单步分类（256 bins） | 8 步 chunk + Flow Matching 回归 | 连续动作建模 + 时间一致性 |
| VLM-策略连接 | 完全解耦（loose） | 软连接：可学习 Query Buffer + 逐层 Cross-Attention | 引入隐式表征缓冲 |
| 视觉输入 | 单视角（第三人称） | 双视角（第三人称 + 腕部相机） | 互补几何信息 |
| 本体感知 | 不使用 | 注入 VLM 层（线性 projector） | 更好的多模态融合 |
| 时间历史 | 仅当前帧 | 仅当前帧（实验证明视频输入无益） | 避免噪声干扰 |
| 辅助目标 | 无 | 频域正则化（DCT + 加权 MSE） | 轻量正则，抑制轨迹抖动 |

### 1.2 关键机制 (Key Mechanism)

**为什么这样设计？**

- **解耦策略头**：复用文本 token 做动作分类会把动作预测约束在语言空间里。引入独立的 12 层策略模块让动作预测在专属空间中进行，性能显著提升。
- **Action Chunking（8 步）**：单次预测 8 个连续动作，模型被迫学习动作序列的时间连贯性，而非孤立地预测每一步。
- **Flow Matching 替代分类**：当动作空间维度较高时，256-bin 分类的离散化误差成为瓶颈。Flow Matching 直接建模连续动作分布，精度更高。
- **软连接（Soft Connection）**：loose 连接（完全解耦）信息传递不足，tight 连接（逐层硬对接）干扰 VLM 表征。可学习 Query Buffer 作为"翻译层"，在 VLM 的文本空间和策略的动作空间之间建立可训练的映射。
- **VLM 侧注入本体感知**：将 proprioception 作为 VLM 的输入而非策略模块的输入，让视觉、语言和 proprioception 在早期融合，避免策略模块过度依赖 proprioception 而忽略视觉线索。

⚡ **Eureka Moment**：VLA 性能的提升不一定来自更大的模型——通过 12 条精心设计的选择（解耦策略头 + 软连接 + Flow Matching + 频域正则 + 多视角 + VLM 侧本体感知），一个 2.5B 的模型可以全面超越 7B 的 OpenVLA-OFT。

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：

```
L_total = E[||v_t(x_t) - v_θ(x_t, t)||²]     ← Flow Matching 主干
        + λ·||DCT(a_pred) ⊙ w - DCT(a_gt) ⊙ w||²  ← 频域正则
```

**目标**：最小化 Flow Matching 向量场预测误差 + 频域动作差异。

**变量说明**：

| 符号 | 含义 |
|------|------|
| v_θ(x_t, t) | 策略网络预测的向量场（flow） |
| x_t | 插值状态（时间步 t 的混合状态） |
| a_pred, a_gt | 预测动作 chunk 和真实动作 chunk（8 步） |
| DCT | 离散余弦变换（将时域动作转到频域） |
| w | 频域权重向量（低频高、高频低，抑制轨迹抖动） |
| λ | 频域正则权重（论文未给出具体值，TODO） |

**直觉**：Flow Matching 负责让动作在时域上准确；频域正则负责让动作序列在频域上"平滑"——高频分量对应轨迹中的高频抖动，降低其权重相当于一种隐式的动作平滑先验。

> 符号与本文/相关文档保持一致：Flow Matching 采用 Lipman et al. (2021) 的 conditional flow matching 框架。

## 3. 带数字走一遍：玩具例子 (Worked Example)

假设一个简化的 2 维动作空间（x, y 平移），chunk size = 4：

**真实动作序列**（归一化到 [-1, 1]）：

```
t=0: [0.10, 0.20]
t=1: [0.15, 0.25]
t=2: [0.20, 0.30]
t=3: [0.25, 0.35]
```

**Flow Matching 损失**（时域）：

```
假设预测为：[0.12, 0.22], [0.18, 0.28], [0.22, 0.32], [0.28, 0.38]

L_FM = (1/8) × Σ ||a_pred - a_gt||²
     = (1/8) × [(0.02)²+(0.02)² + (0.03)²+(0.03)² + (0.02)²+(0.02)² + (0.03)²+(0.03)²]
     = (1/8) × [0.0008 + 0.0018 + 0.0008 + 0.0018]
     = 0.0007
```

**频域正则**（DCT 变换后）：

```
对 x 坐标做 1D DCT：
  真实: DCT([0.10, 0.15, 0.20, 0.25]) ≈ [0.50, -0.22, 0.00, 0.00]
  预测: DCT([0.12, 0.18, 0.22, 0.28]) ≈ [0.52, -0.20, 0.01, -0.01]

  频域权重（低频高）: w ≈ [1.0, 0.7, 0.4, 0.1]

  L_freq_x = Σ w_i² · (DCT_pred_i - DCT_gt_i)²
           = 1.0²·(0.02)² + 0.7²·(0.02)² + 0.4²·(0.01)² + 0.1²·(-0.01)²
           = 0.0004 + 0.000196 + 0.000016 + 0.000001
           ≈ 0.000613
```

**总损失**（假设 λ = 0.1）：

```
L_total = 0.0007 + 0.1 × (L_freq_x + L_freq_y)
        ≈ 0.0007 + 0.1 × 0.0012
        ≈ 0.00082
```

**关键观察**：频域正则的梯度主要作用于低频分量——这意味着模型被鼓励学习动作的"总体趋势"（低频），而对高频抖动（可能是噪声）不那么敏感。这就是为什么论文说它"improves generalization ability"。

## 4. 工程视角 (Engineering View)

| 维度 | 数值/权衡 | 工程含义 |
|------|-----------|----------|
| 模型参数量 | 2.5B（Qwen3-VL-2B + 12 层策略头） | 比 OpenVLA-OFT（7B）少 64%，推理延迟和显存需求大幅降低 |
| 训练步数 | 10,000 steps | 相对较少的 fine-tuning 步数，batch size 256 |
| 学习率 | 1e-4（<3B 模型）/ 5e-5（≥3B 模型） | 标准 fine-tuning 学习率范围 |
| Action Chunk Size | 8 | 推理时一次输出 8 步，控制频率可降低 8 倍（如 10Hz → 1.25Hz 调用） |
| 世界模型辅助 | 性能提升但训练时间 ×3 | 论文选择排除——性价比不高；若算力充裕可考虑 |
| 视频输入 | 无增益甚至轻微下降 | 节省视频编码器的计算和显存开销 |
| 频域正则 | 可忽略的额外开销 | DCT 是 O(n log n) 的确定性变换，几乎不增加训练时间 |
| 多视角输入 | 双相机 vs 单相机 | 需要额外的相机硬件和图像预处理管道 |
| 部署平台 | 论文在单/多 GPU 上训练 | 推理可在单 GPU（如 RTX 4090）上运行 |

**部署约束**：2.5B 参数的模型在 FP16 下约需 5GB 显存，加上 KV Cache 和输入图像编码，实际推理约需 8-10GB 显存，可在消费级 GPU 上部署。

### 6.1 隐含假设 (Hidden Assumptions)

1. **统一评估框架的代表性**：论文假设在 LIBERO 上得出的设计选择可以泛化到其他机器人平台和数据集。但 LIBERO 的扰动类型（光照、背景、语言改写）可能无法覆盖真实世界的所有分布偏移。
2. **10,000 步 fine-tuning 足够**：所有实验使用相同的 10K 步训练，这可能不足以让某些设计选择（如世界模型辅助）达到最优性能。
3. **Qwen3-VL-2B 是最优性价比选择**：论文发现 Qwen3-VL-4B 更好但选择了 2B 版本。这个选择基于 LIBERO 基准，可能在更复杂的真实世界任务中 4B 的优势会更明显。
4. **频域正则的泛化增益可迁移**：DCT + 加权 MSE 的假设是"高频 = 噪声"，这在桌面操作任务中可能成立，但在需要精细高频调整的任务中（如灵巧操作）可能适得其反。
