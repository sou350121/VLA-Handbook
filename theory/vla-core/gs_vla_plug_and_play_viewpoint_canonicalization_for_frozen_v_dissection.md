### 1.2 关键机制 (Key Mechanism)

**核心思想**: 将视角偏移重构为"局部新视角合成"问题，而非全局 NVS。

在 Locality 假设下（部署相机偏移量 ε_t 通常在几到几十厘米），大部分像素可以通过几何 warp 直接映射到 canonical 视角，只有深度不连续处（物体边缘）会露出一条窄的 disocclusion band。这条带的面积与偏移量 ρ 成线性关系 O(ρ)。

因此，学习只需要处理这条窄带——不需要生成整张新图像。

⚡ **Eureka Moment**: 视角规范化不是"从零合成新视角"，而是"几何 warp + 局部 inpainting"——而 α-blending 天然就是 inpainting 引擎，不需要单独的修复头。

### 1.3 信息流/架构图 (Flow / Diagram)

```
部署相机输入                    Canonicalizer f_φ                   冻结 VLA π_θ
┌──────────────┐           ┌──────────────────────────┐          ┌─────────────┐
│ I_s (RGB)    │──┐        │                          │          │             │
│ D_s (Depth)  │──┤        │  [I_s ‖ D_s]             │          │             │
│ (C_s, C*, K) │──┤──concat──→  U-Net (4M)            │──I^*──→  │  a = π_θ    │
│              │  │        │    ├─ Δμ (pos residual)  │          │  (frozen)   │
└──────────────┘  │        │    ├─ log s (scale)      │          │             │
                  │        │    ├─ q (orientation)    │          └─────────────┘
                  └───────→│    ├─ α (opacity)        │
                           │    └─ Δc (color res)     │
                           │           ↓               │
                           │  3D GS Rasterizer         │
                           │  (gsplat α-blender)       │
                           └──────────────────────────┘
```

端到端路径：
1. RGB + Depth 在通道维度拼接 → U-Net 输入
2. 相机位姿对 (C_s, C*) 经 MLP → 128-d pose embedding → FiLM 调制 U-Net
3. U-Net 对每个源像素预测 14-d 高斯描述子
4. 高斯中心锚定在深度反投影世界坐标 X_w，允许 10% 深度残差偏移
5. gsplat 可微 α-blender 在 canonical 位姿渲染 → I^*
6. I^* 输入冻结 VLA → 动作输出

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：

```
f_φ: (I_s, D_s, C_s, C*, K) → I^*    其中 I^* 是 canonical 视角图像
μ = X_w + 0.1 · D_s(u,v) · tanh(Δμ)  高斯中心 = 几何基座 + 有界残差
```

**目标**: 让冻结策略 π_θ 在部署时看到的是"仿佛从训练视角拍摄"的图像。

**核心方程**:

```
输入: I_s ∈ [0,1]^(H×W×3), D_s ∈ R^(H×W), C_s=(R_s,t_s), C*=(R*,t*), K
输出: I^* ∈ [0,1]^(H×W×3)

步骤 1 — 反投影:
  X_w = R_s · K^(-1) · D_s(u,v) · [u,v,1]^⊤ + t_s

步骤 2 — 高斯参数预测 (U-Net):
  [Δμ, log s, q, α, Δc] = U-Net([I_s ‖ D_s], z_pose)
  z_pose = MLP(C_s, C*) ∈ R^128

步骤 3 — 高斯中心约束:
  μ = X_w + c_Δμ · D_s(u,v) · tanh(Δμ),  c_Δμ = 0.1

步骤 4 — α-blending 渲染:
  I^*(p) = Σ_{i∈N(p)} T_i · α_i · c_i
  T_i = Π_{j<i} (1 - α_j)

训练损失:
  L = 0.8 · ||I^* - I*||_1 + 0.2 · (1 - SSIM)
```

**变量说明**:

| 符号 | 含义 | 维度 |
|------|------|------|
| I_s | 源视角 RGB 图像 | H×W×3 |
| D_s | 源视角深度图 | H×W |
| C_s, C* | 源/规范相机位姿 | SE(3) |
| K | 相机内参矩阵 | 3×3 |
| X_w | 世界坐标反投影点 | R^3 |
| μ | 高斯中心位置 | R^3 |
| log s | 各向异性对数尺度 | R^3 |
| q | 方向四元数 | R^4 |
| α | 不透明度 | R |
| Δc | 颜色残差 | R^3 |
| z_pose | 位姿嵌入 | R^128 |

**直觉**: 每个源像素变成一个 3D 高斯球，U-Net 只负责"微调"这些球的位置/大小/颜色/透明度。大部分区域 tanh(Δμ) ≈ 0（因为 head 零初始化），高斯几乎不动——只有 disocclusion band 区域的高斯被拉伸/着色来填补空洞。α-blender 自动处理遮挡排序和混合。

> 符号与本文保持一致。SE(3) 表示 3D 刚体变换群，SO(3) 表示 3D 旋转矩阵群。

## 3. 带数字走一遍：玩具例子 (Worked Example)

假设一个简化场景：

```
场景: 桌面上一个立方体
训练视角 C*: 相机在正上方，俯角 45°
部署视角 C_s: 相机向右偏移 10cm（ε_t = 10cm）
```

**步骤分解**:

1. **反投影**: 立方体顶面中心像素 (u=256, v=256)，深度 D_s=0.5m
   ```
   X_w = R_s · K^(-1) · 0.5 · [256, 256, 1]^⊤ + t_s
   ```
   假设得到世界坐标 X_w ≈ (0.1, 0.5, 0.3)

2. **U-Net 预测**: 由于偏移仅 10cm，大部分像素的 Δμ ≈ 0（零初始化 + 小扰动）
   ```
   μ = X_w + 0.1 × 0.5 × tanh(0.01) ≈ X_w + 0.0005m
   ```
   高斯中心几乎不动——几何 warp 已经覆盖了 95%+ 的像素。

3. **Disocclusion 区域**: 立方体右边缘出现一条约 20 像素宽的 disocclusion band
   ```
   该区域像素: Δμ 较大（U-Net 学习到的残差）
   α ≈ 0.8（高不透明度，确保填充）
   Δc ≈ [0.12, 0.08, -0.05]（颜色残差，匹配桌面纹理）
   ```

4. **α-blending**: 深度排序后，立方体高斯在前，桌面高斯在后
   ```
   对于 disocclusion 区域像素 p:
   I^*(p) = T_cube · α_cube · c_cube + T_table · α_table · c_table
          ≈ 0 × ... + 1.0 × 0.8 × (c_table + Δc)
   ```
   自动填充了空洞。

5. **策略推理**: π_θ 收到 I^*，与训练时看到的图像几乎一致
   ```
   无 canonicalizer: 成功率 9.3%（图像 OOD）
   有 GS-VLA: 成功率 82.4%（恢复 87.5% 的性能损失）
   ```

**工程含义**:
- **深度依赖**: 需要实时单目深度估计——这是部署瓶颈。如果 depth 模型本身对视角偏移敏感，会引入额外误差。
- **控制频率**: canonicalizer 是 per-frame 操作，无时序聚合。与控制频率线性相关，10Hz 控制 = 10 次/秒渲染。
- **部署约束**: 适合仿真环境（LIBERO 有 ground truth depth）；真实部署需要可靠的单目深度估计。

### 6.1 隐含假设 (Hidden Assumptions)

1. **深度已知或可精确估计**: 论文在 LIBERO 仿真中使用 ground truth depth。真实部署依赖单目深度估计，而单目深度本身对视角变化敏感——这可能形成循环依赖。
2. **相机参数已知**: 需要准确的 (C_s, C*, K)。§4.5 测试了标定噪声，但真实场景的标定误差可能更大。
3. **Locality 假设成立**: 相机偏移在 ε-ball 内。如果机器人平台振动或相机支架松动超出预期范围，性能会骤降。
4. **场景静态**: 每帧独立处理，无时序一致性约束。快速运动可能导致帧间闪烁。
5. **单目输入**: 仅用单张 RGB 图像 + 深度。如果部署时有双目或 RGB-D 传感器，未利用额外信息。
