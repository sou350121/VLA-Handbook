### 1.2 关键机制 (Key Mechanism)

**核心思想**：扩散/流匹配策略的推理过程从初始噪声 z₁ 开始，通过去噪模型逐步生成动作。标准做法是每次从各向同性高斯分布 N(0,I) 采样 z₁。但论文发现，某些特定的常数噪声向量 w 能"引导"预训练策略产生更优的行为轨迹。

**搜索算法**（Algorithm 1）：
1. 采样 n 个候选噪声向量 {wᵢ}，wᵢ ~ N(0,I)
2. 对每个 wᵢ，在搜索环境集 E 中 rollout 策略，计算平均累积奖励 R̄ᵢ
3. 返回奖励最高的 w* 作为金票

⚡ **Eureka Moment**：初始噪声不是"无关紧要的随机种子"——它是潜空间中的一个控制旋钮，可以在不改变模型权重的情况下 steering 策略行为。

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：
```
w* = argmax_w  𝔼_{e∈E}[Σ_t γ^t R(s_t, a_t) | a_t = π_w(s_t)]
```

**变量说明**：
| 符号 | 含义 |
|------|------|
| w* | 最优金票噪声向量 |
| w | 候选噪声向量 |
| E | 搜索环境集 |
| γ | 折扣因子 |
| R | 任务奖励函数 |
| π_w | 使用固定噪声 w 的策略 rollout |

**直觉解释**：金票搜索本质是在噪声空间中找到一个点，使得从这个点出发的策略轨迹在下游任务上获得最高累积奖励。这类似于在潜空间中做"无梯度优化"——通过蒙特卡洛采样评估不同噪声向量的价值。

**流匹配前向过程**（公式来自论文）：
```
z_{τ+1} = (1-τ)x + τε  where ε ~ N(0,I)
```
其中 τ 是扩散时间步，x 是数据点，z_τ 是在时间 τ 的部分噪声数据。标准推理从 z₁ = ε 开始去噪，金票方法将 z₁ 替换为常数 w*。

## 3. 带数字走一遍：玩具例子 (Worked Example)

假设我们有一个 Franka 机械臂抓取任务，基线策略用高斯噪声的成功率是 80%。

**搜索过程**：
1. 采样 n=6 个候选噪声向量 {w₁...w₆}，每个是 512 维向量（假设潜空间维度）
2. 每个 wᵢ 在 25 个不同起始状态 rollout，共 150 episodes
3. 计算每个 wᵢ 的平均成功率：
   - w₁: 72%, w₂: 68%, w₃: 85%, w₄: 79%, w₅: 100%, w₆: 44%
4. 选择 w₅ 作为金票

**验证**：在 50 个 held-out 测试 episodes 上评估：
- 基线（高斯噪声）：40/50 = 80%
- 金票 w₅：49/50 = 98%
- **提升**：18% 相对提升，仅用 150 次搜索 episodes

**关键洞察**：w₅ 不是"更小的噪声"或"更接近零"——它是一个特定方向的向量，能引导策略避开某些失败模式（如抓取角度偏差）。

### 6.1 隐含假设 (Hidden Assumptions)

1. **策略是 steerable 的**：作者假设预训练策略的潜空间中存在"好"的方向，但这不是数学保证
2. **奖励函数可计算**：需要能计算（稀疏）任务奖励，但奖励不必可微
3. **搜索环境代表性**：假设搜索环境分布与测试环境分布相近，否则可能过拟合
4. **噪声空间连续性**：假设噪声空间中"好"的向量形成连续区域，使随机搜索有效
