### 1.2 关键机制 (Key Mechanism)

**为什么用速度场分歧而不是输出动作分歧？**

传统 ensemble 方法比较最终输出动作的差异，但流匹配模型在推理时沿 ODE 轨迹生成 N_s 步动作。速度场分歧在每一步都测量差异，然后加权求和：

- 早期步（s ≈ 0）：样本噪声大，速度场分歧天然大 → 权重 κ_s = s/(1-s) 小
- 晚期步（s ≈ 1）：样本接近最终动作，速度场分歧反映真实认知差异 → 权重 κ_s 大

这种时间加权设计让 VFD 聚焦于"模型在接近决策时是否仍然不一致"，这才是认知不确定性的核心信号。

**Ensemble 构建策略**：不从头训练多个 VLA（太贵），而是取一个预训练基座模型，用 M 种不同数据 shuffle 微调得到 M 个成员。M=2 即可达到良好校准效果（论文 Figure 3）。

⚡ **Eureka Moment**：流匹配模型的两个 ensemble 成员之间的 KL 散度，可以通过沿 ODE 轨迹的速度场 L2 分歧加权积分来精确计算（定理 4.1）——不需要求解高维散度场，不需要采样似然，只需要跑一遍标准推理并比较速度场。

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：
```
u_e(y) = 1/[M(M-1)N_s] · Σ_{i≠j} Σ_{ℓ=0}^{N_s-1} [s_ℓ/(1-s_ℓ)] · ||v_s_ℓ^{θi}(x) - v_s_ℓ^{θj}(x)||²
```

**目标**：估计认知不确定性 I(x, θ | y, D) = E_θ[DKL(p(x|y,θ) || p(x|y,D))]，即模型间预测分布的平均 KL 散度。

**推导链条**：

1. **从认知不确定性到 pairwise KL**（Eq 4a-4c）：
   ```
   I(x,θ|y,D) ≤ (1/M²) · Σ_{i,j} DKL(p^{θi}(x|y) || p^{θj}(x|y))
   ```
   Jensen 不等式 → pairwise KL 散度之和是上界。

2. **从 KL 散度到速度场分歧**（定理 4.1，核心贡献）：
   ```
   DKL(p^{θ1}(x|y) || p^{θ2}(x|y)) = ∫_0^1 κ_s · E_{x_s}[||v_s^{θ1}(x_s,y) - v_s^{θ2}(x_s,y)||²] ds
   ```
   其中 κ_s = s/(1-s) 是 OT 高斯条件路径的缩放因子。

3. **离散化 + 多 ensemble 平均**（Eq 7，VFD 最终公式）：
   ```
   u_e(y; V) = 1/[M(M-1)N_s] · E_{x0} [Σ_{i≠j} Σ_{ℓ=0}^{N_s-1} κ_{s_ℓ} · ||v_{s_ℓ}^{θi}(x_{s_ℓ}^{(i)},y) - v_{s_ℓ}^{θj}(x_{s_ℓ}^{(i)},y)||²]
   ```

**变量说明**：

| 符号 | 含义 |
|------|------|
| y | 条件输入（observation = 图像+语言+本体感知）|
| x | 动作序列（action chunk，维度 d）|
| v_s^θ(x, y) | 神经网络学习的速度场（R^d → R^d）|
| s | 流匹配时间，0（纯噪声）→ 1（数据分布）|
| κ_s | 时间权重 s/(1-s)，晚期步权重更大 |
| N_s | ODE 积分步数（推理步数）|
| M | ensemble 成员数（论文用 M=2）|
| x_{s_ℓ}^{(i)} | 第 i 个成员在步 s_ℓ 的隐状态 |

**直觉**：两个模型对同一输入的速度场越不一致，说明它们对"该怎么动"越没有共识 → 认知不确定性越高。晚期步（s→1）的权重趋于无穷，因为此时噪声几乎为零，速度场分歧完全反映模型认知差异而非随机性。

> 符号与论文保持一致。定理 4.1 的证明见论文 Appendix A.2，核心技巧是利用流连续性方程和 OT 高斯路径的解析形式。

## 3. 带数字走一遍：玩具例子 (Worked Example)

假设一个 2D 动作空间（如机械臂末端 x-y 坐标），两个 ensemble 成员 θ1 和 θ2，N_s = 5 步推理。

**场景 A：分布内输入**（训练数据中常见的目标位置）

| 步 ℓ | s_ℓ | κ_{s_ℓ} | ||v^{θ1} - v^{θ2}||² | 加权分歧 κ·||Δv||² |
|------|------|---------|---------------------|-------------------|
| 0 | 0.0 | 0.00 | 0.50 | 0.00 |
| 1 | 0.2 | 0.25 | 0.30 | 0.075 |
| 2 | 0.4 | 0.67 | 0.15 | 0.10 |
| 3 | 0.6 | 1.50 | 0.08 | 0.12 |
| 4 | 0.8 | 4.00 | 0.05 | 0.20 |

```
VFD = (1/5) × (0.00 + 0.075 + 0.10 + 0.12 + 0.20) = 0.10
```
→ 低不确定性。两个模型在分布内输入上速度场高度一致。

**场景 B：分布外输入**（训练数据中从未见过的目标位置）

| 步 ℓ | s_ℓ | κ_{s_ℓ} | ||v^{θ1} - v^{θ2}||² | 加权分歧 κ·||Δv||² |
|------|------|---------|---------------------|-------------------|
| 0 | 0.0 | 0.00 | 1.20 | 0.00 |
| 1 | 0.2 | 0.25 | 1.80 | 0.45 |
| 2 | 0.4 | 0.67 | 2.50 | 1.675 |
| 3 | 0.6 | 1.50 | 3.20 | 4.80 |
| 4 | 0.8 | 4.00 | 4.50 | 18.0 |

```
VFD = (1/5) × (0.00 + 0.45 + 1.675 + 4.80 + 18.0) = 4.99
```
→ 高不确定性（≈50× 场景 A）。关键观察：晚期步（s=0.8）贡献了 90% 的不确定性分数，因为 κ_s 放大 + 速度场分歧本身也大。

**工程含义**：VFD 天然聚焦于"模型在最终决策阶段的分歧"，这正是部署时最需要的信号——早期分歧可能是随机噪声，晚期分歧才是模型真的不知道该怎么办。

## 4. 工程视角 (Engineering View)

| 维度 | 数值/约束 | 说明 |
|------|-----------|------|
| Ensemble 大小 M | 2（推荐） | Figure 3 显示 M=2 与 M=4 校准效果接近 |
| 推理开销 | ≈2× 单模型 | M=2 时速度场计算翻倍，但可 GPU 并行 |
| ODE 步数 N_s | 与基线 VLA 相同 | 不增加生成步数，只是在每步多算一次速度场比较 |
| 训练成本 | M 次独立微调 | 同一预训练模型 + 不同数据 shuffle，可并行 |
| 内存开销 | M× 模型参数 | M=2 时推理需同时加载 2 个模型权重 |
| 失败检测延迟 | 每个 action chunk 一次 VFD 计算 | 可在动作执行前预判失败 |
| SAVE 循环轮数 R | 10-15 轮（LIBERO） | 每轮收集 n_e 条专家示范 |

**部署约束**：
- VFD 需要在推理时同时运行 M 个模型的前向传播。对于 Pi0 级别的 VLA（数 B 参数），M=2 意味着 GPU 内存需求翻倍。
- 如果硬件受限，可考虑：(1) 权重共享 + 仅 action head 独立；(2) 测试时 dropout 替代 ensemble（但论文未评估此方案）。
- κ_s = s/(1-s) 在 s→1 时趋于无穷，实际实现中需要在最后几步做数值截断（论文未明确说明截断策略）。

**评测任务**：

1. **校准性（Calibration）**：VFD 分数与 per-task 成功率的 Spearman/Pearson 相关性
   - VFD: −Spearman = 0.71±0.03, −Pearson = 0.71±0.02
   - 最佳基线（GU）: −Spearman = 0.62±0.00
   - 结论：VFD 相关性显著高于所有基线（Action-L2, ACE, DECU, GU, Entropy, Perplexity）

2. **主动微调效率（SAVE）**：达到目标成功率所需 active fine-tuning 轮数
   - 达到 ≥50% SR：VFD 引导需 6.0±0.8 轮，Random 需 8.7±2.1 轮
   - 最终 SR：VFD 67.1±3.2% vs Random 54.6±0.9%
   - 数据效率提升：≥22% 更少样本

3. **失败检测（Failure Detection）**：部署时预测动作失败
   - 准确率 67%，TPR（召回率）79%
   - 基线：ACE, STAC, RND-OE
   - 阈值设定：仅用 10 次成功 rollout  + conformal prediction

## 6. 能力与失败模式 (Capabilities & Failure Modes)

**能做什么**：
- 在未见过的初始状态下可靠估计模型认知不确定性（LIBERO 上 Spearman 0.71）
- 仅用 2 个 ensemble 成员即可达到良好校准（降低部署成本）
- 即使只改变语言指令（图像不变），VFD 仍然校准良好（Figure 4）
- 指导主动数据收集，减少 ≥22% 的专家示范需求
- 部署时检测 imminent failure，TPR 达 79%

**不能做什么 / 局限**：
- 仅在 LIBERO 仿真验证，未在实际机器人平台测试
- 需要训练 M 个 ensemble 成员——虽然比从头训练便宜，但仍需额外计算
- 推理时内存需求翻倍（M=2），对边缘部署设备不友好
- 未评估 aleatoric uncertainty（数据固有噪声），仅关注 epistemic
- Conformal prediction 阈值需要 10 次成功 rollout 校准——对新任务仍需少量先验数据

### 6.1 隐含假设 (Hidden Assumptions)

1. **Ensemble 多样性来自数据 shuffle 足够**：论文用同一预训练模型 + 不同 shuffle 生成 ensemble 成员。这假设 shuffle 引入的多样性足以近似参数后验分布。但不同的 shuffle 可能产生高度相似的模型，特别是当预训练模型已经很强时。

2. **OT 高斯条件路径假设**：定理 4.1 依赖于 OT Gaussian conditional paths 的解析形式。如果 VLA 使用不同的条件路径（如 curved interpolation），定理可能不直接适用。

3. **速度场分歧 = 认知不确定性**：这个等价关系在定理 4.1 中数学上成立，但前提是速度场在无穷远处衰减足够快（technical condition）。在高维动作空间（如 7-DOF 机械臂 + gripper），这个条件是否满足未经验证。

4. **LIBERO 代表性**：LIBERO 的 task distribution 可能与真实世界差异很大。VFD 在仿真中的校准性不一定迁移到真机。
