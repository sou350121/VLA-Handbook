### 1.2 关键机制 (Key Mechanism)

**为什么这样设计：**

- **噪声空间而非动作空间**：直接微调 VLA 的动作生成路径代价高、不稳定。冻结 VLA、只训练一个轻量噪声 actor，将优化约束在小模块内，同时保持输出锚定在预训练先验附近。
- **人类矫正需要翻译**：人类给出的矫正动作在动作空间，而噪声 actor 需要噪声空间的监督信号。直接反向传播通过整个解码链计算代价高且信号不稳定。UniSteer 利用流匹配解码器的逐步 Euler 结构，从动作端沿解码轨迹逐步反演回噪声端。
- **统一接口**：RL 分支从奖励中学习探索，人类指导分支从矫正中学习"正确"的噪声区域。两者通过同一个噪声 actor 统一，互不冲突。

⚡ **Eureka Moment**：人类矫正动作虽然天然在动作空间给出，但可以通过冻结流匹配解码器的固定点反演，精确映射回噪声空间——这使得人类指导和噪声 RL 可以共享同一个轻量 actor 的更新接口，而不是各自为战。

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：
```
L_total = L_RL + L_demo = -Q_ω(s, z) + ||ψ_φ(s) - z^h||²₂
```

**目标**：在冻结 VLA 解码器 G_θ 的前提下，训练轻量噪声 actor ψ_φ 和噪声 critic Q_ω，使得策略能在有限真实交互预算内快速适配新任务。

**核心方程**：

1. **流匹配策略前向过程**（冻结）：
```
dz_t/dt = v_θ(z_t, t, s),  z ∈ R^d, t ∈ [0,1]
a = G_θ(s, z_0) = z_0 + ∫₀¹ v_θ(z_t, t, s) dt
```
从初始噪声 z_0 ~ N(0,I) 出发，通过状态条件速度场积分到 t=1，得到动作块 a。

2. **噪声空间策略**：
```
z_t ~ ψ_φ(·|s_t),    a_t = G_θ(s_t, z_t)
```
Actor 输出噪声分布，解码器将其映射为动作。

3. **Critic TD 损失**：
```
L_Qω = ||Q_ω(s,z) - (r + γ·Q̄_ω(s',z'))||²
```

4. **RL 策略损失**：
```
L_RL = -Q_ω(s, z),    z ~ ψ_φ(s)
```

5. **人类矫正反演**（Proposition 2，固定点迭代）：
```
z_k^(m+1) = z^(k-1) - Δt · v_θ(z_k^(m), t_k, s)
z^ = z^K  (K步反演后的初始噪声目标)
```
从人类矫正动作 a^h 出发，沿解码轨迹逐步反演，每步做 M 次固定点迭代。

6. **Demo 监督损失**：
```
L_demo = ||ψ_φ(s) - z^h||²₂
```

**变量说明**：

| 符号 | 含义 |
|------|------|
| θ | 冻结 VLA 速度场网络参数 |
| φ | 噪声 Actor 参数 |
| ω | 噪声 Critic 参数 |
| z | 噪声变量（策略的"动作"） |
| a | 解码后的动作块（7 步执行） |
| a^h | 人类矫正动作块 |
| z^h | 反演得到的噪声目标 |
| v_θ | 流匹配速度场 |
| K | Euler 离散化步数 |
| M | 每步固定点迭代次数 |
| Δt | Euler 步长 |
| γ | 折扣因子 |

> 符号与论文保持一致。速度场 v_θ 在反演和推理中使用同一冻结权重。

## 3. 带数字走一遍：玩具例子 (Worked Example)

假设一个简化的 2D 场景：

**设置**：
- 动作维度 d=2（简化为 2D 末端执行器位置）
- K=3 步 Euler 离散化，Δt=1/3
- 初始噪声 z_0 = [0.5, -0.3]
- 速度场 v_θ 在三个时间步的输出分别为：v_0=[0.8, 0.5], v_1=[0.3, 0.2], v_2=[0.1, 0.1]

**前向解码**（冻结 VLA）：
```
z_0 = [0.5, -0.3]
z_1 = z_0 + Δt·v_0 = [0.5, -0.3] + [0.267, 0.167] = [0.767, -0.133]
z_2 = z_1 + Δt·v_1 = [0.767, -0.133] + [0.1, 0.067] = [0.867, -0.066]
z_3 = z_2 + Δt·v_2 = [0.867, -0.066] + [0.033, 0.033] = [0.9, -0.033] = a
```
得到动作 a = [0.9, -0.033]。

**人类矫正**：假设人类给出 a^h = [1.0, 0.1]，需要反演回噪声目标。

**反向反演**（从 z^₀ = a^h 开始）：

第 3 步反演（t=1→2/3）：
```
目标：找 x 使 x = z^₀ - Δt·v_θ(x, t_2, s) = [1.0, 0.1] - Δt·v_θ(x, ...)
固定点迭代（假设 v_θ 近似不变）：
x^(0) = [1.0, 0.1]
x^(1) = [1.0, 0.1] - [0.033, 0.033] = [0.967, 0.067]
x^(2) ≈ [0.967, 0.067]（收敛）
→ z^₁ = [0.967, 0.067]
```

第 2 步反演（t=2/3→1/3）：
```
x^(0) = [0.967, 0.067]
x^(1) = [0.967, 0.067] - [0.1, 0.067] = [0.867, 0.0]
→ z^₂ = [0.867, 0.0]
```

第 1 步反演（t=1/3→0）：
```
x^(0) = [0.867, 0.0]
x^(1) = [0.867, 0.0] - [0.267, 0.167] = [0.6, -0.167]
→ z^₃ = [0.6, -0.167]
```

**结果**：反演得到噪声目标 z^ = [0.6, -0.167]。Actor 的损失为：
```
L_demo = ||ψ_φ(s) - [0.6, -0.167]||²₂
```
如果当前 actor 输出 ψ_φ(s) = [0.5, -0.3]，则 L_demo = 0.01² + 0.133² ≈ 0.0178。梯度会推动 actor 向 [0.6, -0.167] 靠近。

**闭环验证**：用 z^ 作为新输入通过冻结解码器，应得到接近 a^h 的动作。论文 Table 2 显示固定点反演的动作重建 MSE 仅为 0.00122（Pick up Spoon），验证了反演精度。

## 4. 工程视角 (Engineering View)

| 维度 | 数值/约束 | 工程含义 |
|------|-----------|----------|
| 训练硬件 | 单 NVIDIA A100 | 低成本部署，适合单机器人实验室 |
| 控制频率 | 30 Hz | 高频控制，动作块 7 步覆盖 ~0.23s |
| 反演时间 | 10-23s/16轨迹（Table 2） | 反演在人类干预后离线计算，不增加推理延迟 |
| 训练时间 | 45-100 分钟/任务 | 真实机器人交互时间，含数据收集 |
| 平均适配时间 | 66 分钟 | 4 个任务平均，从 20%→90% 成功率 |
| 人类干预频率 | 0.98 纯人类轨迹/轮 | 极低人类负担，模型自主探索为主 |
| 观察维度 | 2×RGB + 6D 位姿 + 夹爪 | 标准双摄 + 本体感知配置 |
| 动作维度 | 6D 位姿 + 夹爪开合 | 7 维连续动作空间 |
| 初始策略 | π₀ 预训练 + 30 演示 warmup | 需要预训练 checkpoint 和少量 warmup 数据 |

**关键 trade-off**：
- **反演精度 vs 计算成本**：固定点迭代比优化基反演快 7-15 倍（Table 2），但依赖速度场的 Lipschitz 连续性。如果速度场不满足 Lipschitz 条件（如存在不连续跳跃），反演可能发散。
- **噪声空间 vs 动作空间更新**：噪声空间更新保持输出锚定在预训练先验附近，但限制了策略的表达能力。如果目标行为与预训练先验差异过大，噪声 actor 可能无法覆盖足够的行为空间。
- **人类干预频率**：每轮不到 1 条纯人类轨迹就能显著加速，但具体需要多少干预取决于任务复杂度。Fold Towel（100 分钟）比 Pick up Spoon（45 分钟）需要更多时间。

## 6. 能力与失败模式 (Capabilities & Failure Modes)

**能做什么**：
- 在 45-100 分钟内将预训练 VLA 适配到 4 类不同的真实机器人操作任务
- 显著提升 OOD 空间泛化（3 个位置任务 OOD 成功率从 0%→100%）
- 用极少人类干预（平均每轮 <1 条纯人类轨迹）加速噪声空间 RL
- 在接触丰富的精密操作（Insert Square）上达到 100% 成功率

**不能做什么 / 失败模式**：
- **Fold Towel 仍仅 75%**：可变性物体动力学仍是最大瓶颈，扩散策略对非刚性物体的建模能力有限
- **仅单臂验证**：所有实验在 AgileX Piper 单臂上进行，未验证双臂、移动操作或人形平台
- **依赖预训练 checkpoint**：需要 π₀ 架构的预训练模型 + 30 条 warmup 演示，冷启动场景不适用
- **反演质量依赖假设**：Proposition 1-2 要求速度场全局 Lipschitz 连续。如果实际速度场不满足（如网络存在饱和/不连续），反演可能不唯一或不收敛
- **未覆盖自回归 VLA**：方法专门针对流匹配 VLA 设计，不适用于 RT-1/RT-2 等自回归架构

### 6.1 隐含假设 (Hidden Assumptions)

1. **速度场全局 Lipschitz 连续**：Proposition 1 假设 v_θ 对噪声变量全局 Lipschitz。实际神经网络速度场（使用 ReLU/GELU 激活）理论上满足局部 Lipschitz，但全局 Lipschitz 需要谱归一化或其他约束。论文未验证实际模型是否满足此条件。

2. **反演步数 M 足够**：固定点迭代需要 M 步收敛。论文未公开 M 的具体取值和收敛判据，不同任务的收敛速度可能不同。

3. **人类矫正动作可执行**：反演假设人类给出的动作 a^h 在冻结解码器的像空间内（即存在对应的噪声 z 使得 G_θ(s,z) ≈ a^h）。如果人类动作超出预训练 VLA 的能力范围，反演可能产生低质量噪声目标。

4. **奖励信号可获取**：RL 分支需要真实世界奖励。论文使用终端成功率作为奖励，但未说明奖励函数如何设计（自动检测 or 人工标注）。
