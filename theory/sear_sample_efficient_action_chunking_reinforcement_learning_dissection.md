💡 **X-Ray 开场**

动作分块（一次预测 N 个连续动作）在模仿学习中非常成功，但在在线强化学习中直接套用效果很差。原因有两个：(1) 动作空间维度膨胀导致 Critic 难以拟合；(2) 每 N 步才决策一次，降低了策略的"反应频率"和状态覆盖。SEAR 的核心发现是：用一个因果 Transformer Critic 同时对分块的每个前缀做 Q 值预测（多视野目标），加上训练时随机执行分块前缀后重规划，就能同时解决这两个问题。对 VLA 研究者意味着：动作分块可能成为 VLA 策略 RL 微调的一种有效范式——用分块加速价值传播，同时保持足够的反应性。

## 1. 核心架构/方法总览 (Overview / Architecture)

### 1.1 系统对比概览 (System Component Comparison)

| 组件 | SimbaV2 (无分块) | CQN-AS (分块) | SEAR (分块) |
|------|------------------|---------------|-------------|
| **Actor 输出** | 单步动作 a_t | 动作分块 a_{t:t+N} | 动作分块 a_{t:t+N} |
| **Critic 架构** | MLP (双 Q) | MLP (多目标) | Causal Transformer (多目标) |
| **Critic 目标** | 单步 TD | 每步独立 Q 值 | 多视野 Q 值（因果前缀） |
| **决策频率** | 每步 | 每 N 步 | 每 N 步训练 / 随机重规划 |
| **评估模式** | 标准 | 固定 receding horizon | 随机重规划 + receding horizon |
| **熵正则化** | SAC 风格 | 无 MaxEnt | MaxEnt-RL 完整框架 |
| **样本效率** | 基线 | 中等 | 高（多视野梯度 × N） |
| **Metaworld-Hard IQM** | ~60% | ~60% | ~80%+ |

### 1.2 关键机制 (Key Mechanism)

**两个核心设计解决两个核心问题：**

1. **多视野 Critic 目标（Multi-Horizon Targets）** — 解决动作空间膨胀
   - 传统方法：一个分块 → 一个 Q 值目标 → 梯度信号稀疏
   - SEAR：一个分块 → N 个 Q 值目标（每个前缀一个）→ 有效梯度信号增加 N 倍
   - 关键洞察：k 步目标 G^{(k)} 只依赖前 k 个动作 → 天然适合因果 Transformer

2. **随机重规划（Random Replanning）** — 解决状态覆盖退化
   - 传统分块：每 N 步评估一次 Actor → 状态空间出现"盲区"
   - SEAR：训练时随机执行分块的前 1~N 步后重规划 → Actor 在全部状态上均匀覆盖
   - 这使得 receding horizon 控制在 RL 中首次真正有效

⚡ **Eureka Moment**：多视野目标 + 因果 Transformer 的组合让"训练用长分块加速价值传播"和"评估用短分块保持反应性"不再矛盾——你可以在训练时用 N=10 的分块，评估时只用 receding horizon=3~5。

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：

```
L = (1/2N) · Σ_{k=1}^{N} [Q_φ^{(k)}(s_t, a_{t:t+k-1}) - G^{(k)}(s_t, a_{t:t+k-1})]²
```

**目标**：让因果 Transformer Critic 同时拟合动作分块所有前缀的 Q 值，而非仅拟合整个分块的一个 Q 值。

**公式分解**：

- **多视野目标 G^{(k)}**（k 步 horizon 的 TD target）：

```
G^{(k)}(s_t, a_{t:t+k-1}) = Σ_{i=0}^{k-1} γ^i · r_{t+i}    ← k 步回报
                          + γ^k · Q̄^{(k)}(s̃, ã)             ← 自举
```

其中 s̃ = s_{t+k}，ã 是从当前策略采样的下一个分块。

- **整块 Q 值目标**（用于 Actor 更新）：

```
Q̄^{(N)}(s̃, ã) = min_j [Q_{φ̄_j}^{(N)}(s̃, ã) - α · Σ_{i=0}^{N-1} γ^i · log π_θ(ã_{t+i} | s̃)]
```

Double Q + 熵正则化，类似 SAC 但扩展到分块。

- **Actor 更新**（reverse KL divergence）：

```
J(π) = E_D [ KL( π_θ(·|s_t) || exp(Q_φ^{(N)}(s_t, a_{t:t+N}) / α) / Z(s_t) ) ]
```

**变量说明**：

| 符号 | 含义 |
|------|------|
| N | 动作分块大小（论文测试 1, 5, 10, 20） |
| k | 多视野目标的 horizon 索引（1 到 N） |
| γ | 折扣因子 |
| α | 熵正则化系数 |
| Q^{(k)} | k 步 horizon 的 Q 值预测（Critic 输出） |
| G^{(k)} | k 步 horizon 的 TD 目标 |
| φ | Critic 参数 |
| θ | Actor 参数 |
| π_θ | 动作分块策略 π(a_{t:t+N} \| s_t) |

> 符号与论文保持一致。关键区别：传统 Critic 输出单个 Q(s, a)，SEAR 的 Critic 输出 N 个 Q 值 Q^{(1)}...Q^{(N)}，每个对应分块的一个前缀。

**直觉**：想象你在教一个机器人抓杯子。传统方法：执行完整个分块后才给一个"好不好"的信号。SEAR：每走一步都给一个"这一步好不好"的信号——梯度信号多了 N 倍，学习自然更快更稳。

## 3. 带数字走一遍：玩具例子 (Worked Example)

假设一个简化的 2D 操作任务，分块大小 N=3，折扣 γ=0.99。

**场景**：机器人从状态 s_0 出发，预测一个 3 步动作分块 (a_0, a_1, a_2)。

**步骤 1：执行与收集**

```
s_0 ──a_0──→ s_1 (r=0.5) ──a_1──→ s_2 (r=0.8) ──a_2──→ s_3 (r=1.0)
```

**步骤 2：计算多视野目标**

```
G^{(1)} = r_0 + γ · Q̄^{(1)}(s_1, ã)
        = 0.5 + 0.99 · Q̄^{(1)}(s_1, ã)

G^{(2)} = r_0 + γ·r_1 + γ² · Q̄^{(2)}(s_2, ã)
        = 0.5 + 0.99·0.8 + 0.99² · Q̄^{(2)}(s_2, ã)
        = 0.5 + 0.792 + 0.9801 · Q̄^{(2)}(s_2, ã)

G^{(3)} = r_0 + γ·r_1 + γ²·r_2 + γ³ · Q̄^{(3)}(s_3, ã)
        = 0.5 + 0.792 + 0.9703 + 0.9703 · Q̄^{(3)}(s_3, ã)
        = 2.262 + 0.9703 · Q̄^{(3)}(s_3, ã)
```

假设目标 Critic 给出的自举值分别为 Q̄^{(1)}=2.0, Q̄^{(2)}=3.5, Q̄^{(3)}=5.0：

```
G^{(1)} ≈ 0.5 + 1.98 = 2.48
G^{(2)} ≈ 1.292 + 3.43 = 4.72
G^{(3)} ≈ 2.262 + 4.85 = 7.11
```

**步骤 3：Critic 损失**

假设 Critic 当前预测为 Q^{(1)}=2.0, Q^{(2)}=4.0, Q^{(3)}=6.5：

```
L = (1/6) · [(2.0-2.48)² + (4.0-4.72)² + (6.5-7.11)²]
  = (1/6) · [0.2304 + 0.5184 + 0.3721]
  = (1/6) · 1.1209
  ≈ 0.187
```

**关键对比**：传统方法只计算 G^{(3)} 一个目标，损失 = 0.5 · (6.5 - 7.11)² = 0.186。看似相近，但传统方法丢失了 G^{(1)} 和 G^{(2)} 提供的中间梯度信号——在早期训练时，这些中间信号是 Critic 学习因果依赖的关键。

**步骤 4：随机重规划的影响**

假设这次训练采样执行了前 k=2 步后重规划（而不是固定执行 3 步）：

```
s_0 ──a_0──→ s_1 ──a_1──→ s_2 ──(重规划)──→ 新分块
```

Actor 在 s_2 处被评估（而不是像传统方法那样只在 s_0, s_3, s_6... 处被评估）。这打破了"每 N 步评估一次"的规律模式，确保 Actor 在状态空间的各个位置都能获得训练信号。

## 4. 工程视角 (Engineering View)

| 维度 | 传统单步 (SimbaV2) | SEAR (N=10) | 工程含义 |
|------|-------------------|-------------|---------|
| **Critic 前向传播** | 1 次 MLP | 1 次 Transformer（输出 N 个 Q 值） | 训练时 Critic 计算量增加，但只需一次前向 |
| **Actor 前向传播** | 每步 1 次 | 每 N 步 1 次 | 推理时 Actor 调用频率降低 N 倍 |
| **Critic 更新复杂度** | O(1) 目标 | O(N) 目标 | 多视野损失计算量线性增长 |
| **推理延迟** | ~1ms/步 | ~0.1-0.3ms/步（分摊） | 部署时可能更低（Actor 调用少） |
| **内存占用** | 标准 replay buffer | 标准 replay buffer（存储每步 transition） | 无额外内存开销 |
| **量化误差敏感度** | 中等 | 较高（Transformer 对量化更敏感） | 边缘部署需关注量化策略 |
| **训练-评估分布偏移** | 无 | 存在（receding horizon 引入） | 随机重规划缓解此问题 |

**部署建议**：
- 训练阶段：用 N=10 的分块 + 随机重规划
- 评估阶段：receding horizon = 3~5 步（论文最优范围）
- 如果部署到资源受限的边缘设备：可用 MLP Critic 替代 Transformer（性能略降但仍优于基线）

### 6.2 不能做什么 / 局限

| 局限 | 详细说明 |
|------|---------|
| 高动态场景（如 locomotion） | ❌ 论文明确说明"当前动作分块方法不适用于高动态域"——分块会降解数据质量 |
| 短 horizon 任务 | ⚠️ 收益有限 | 分块的优势在长程任务中才显著 |
| 计算开销 | ⚠️ Transformer Critic 增加训练成本 | 但推理时 Actor 调用减少可部分补偿 |
| 泛化性未验证 | ⚠️ 仅在 Meta-World 和 OGBench 验证 | 未测试真实机器人或更复杂的模拟环境 |

### 6.3 隐含假设 (Hidden Assumptions)

1. **因果结构匹配**：假设动作分块中 k 步的回报确实只依赖前 k 个动作。在存在强外部干扰或环境动态变化快的场景中，这个假设可能不成立。

2. **随机重规划不引入分布偏移**：训练时随机执行前缀后重规划，假设这不会导致训练-评估分布差异过大。论文通过实验验证了这一点，但未在分布偏移更极端的场景（如多任务、领域自适应）中测试。

3. **MaxEnt 框架的熵系数 α 可固定**：论文使用固定 α，未探索自适应温度系数的效果。在复杂任务中，自适应 α 可能进一步提升性能。

4. **Transformer 的因果注意力足够表达动作依赖**：假设 causal self-attention 能有效建模动作间的时序依赖。但论文未与 RNN/SSM 等序列模型做对比（仅在 Outlook 中提到 SSM 是未来方向）。
