### 1.2 关键机制 (Key Mechanism)

**因子偏差的本质**：预训练策略在微调时倾向于过度依赖某些语言因子作为捷径，而不是真正理解所有因子。例如，在训练数据中"蓝色"总是和"抓取"同时出现，模型可能学会"看到蓝色就抓取"，而不是理解"抓取"这个动作的含义。

**FDR（因子主导率）**的核心思想：
- 构造一对因子 (f1, f2) 的故意相关训练集
- 在 OOD 测试场景中，两个因子解耦——模型必须选择依赖哪一个
- 统计模型依赖 f1 的次数 vs 依赖 f2 的次数
- FDR = (N_f1 - N_f2) / (N_f1 + N_f2 + ε)，正值表示 f1 主导，负值表示 f2 主导

**FDH（因子主导层级）**通过 Copeland 排名将所有成对比较聚合为全局排序。

⚡ **Eureka Moment**：捷径学习不是随机的——不同架构的 VLA 策略共享同一套因子偏差层级（颜色 ≥ 物体 ≥ 空间 ≥ 动词 ≥ 尺寸），这意味着可以用一个 model-agnostic 的数据采集策略来修复所有模型。

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：
```
FDR(f1, f2) = (N_f1 - N_f2) / (N_f1 + N_f2 + ε)  ∈ (-1, 1)
```

**目标**：量化两个指令因子之间的相对主导强度，识别策略在哪个因子上走了捷径。

**公式拆解**：
- `N_f1`：rollout 中策略过度拟合 f1 的次数（即依赖 f1 作为捷径）
- `N_f2`：rollout 中策略过度拟合 f2 的次数
- `ε → 0`：防止除零的小常数
- `FDR > 0`：f1 主导（策略更依赖 f1）
- `FDR < 0`：f2 主导（策略更依赖 f2）
- `FDR ≈ 0`：两个因子被均衡地 grounding

**Copeland 排名聚合**：
```
C(fi) = Σ_{j≠i} 1[FDR(fi, fj) > τ]    where τ = 5%
```
每个因子对每赢一次 +1 分，按总分降序排列得到 FDH。

**直觉**：FDR 本质上是一个归一化的"胜负差"指标。如果一个策略在 300 次 rollout 中有 200 次依赖颜色、100 次依赖物体，FDR(color, object) = (200-100)/(200+100) = 0.33，说明颜色明显主导。

> 符号与本文保持一致：f1, f2 为因子（Verb/Color/Object/Size/Spatial），N 为 Gemini-2.5-Flash 分类的 rollout 计数，τ 为 Copeland 排名的平局阈值。

## 3. 带数字走一遍：玩具例子 (Worked Example)

假设我们要评估 (Color, Verb) 这对因子：

**训练阶段**：构造相关训练集
- 红色 → 总是 paired with 抓取
- 蓝色 → 总是 paired with 推动
- 黄色 → 总是 paired with 拉动
- 其他因子（物体、尺寸、空间）随机化

**OOD 测试**：构造解耦场景
- 场景中有红色方块（训练中未见"红色+推动"组合）
- 指令："推动红色方块"
- 模型有两个选择：
  - 走颜色捷径 → 抓取（因为红色在训练中总配对抓取）
  - 走动词捷径 → 推动蓝色方块（因为推动在训练中总配对蓝色）

**收集 400 次 rollout**：
- 240 次：模型抓取了红色方块（overfit to Color）
- 160 次：模型推动了蓝色方块（overfit to Verb）

**计算 FDR**：
```
FDR(Color, Verb) = (240 - 160) / (240 + 160 + 0.001)
                 = 80 / 400.001
                 ≈ 0.20
```
正值 0.20 说明 Color 主导 Verb——这与论文 Table 1 中观察到的趋势一致。

**数据采集修复**：
- 根据 FDH，Color 排名高（强势），Verb 排名低（弱势）
- V 策略：固定 Verb（弱势因子），变化 Color 和其他因子
- 例如：收集"每种动词 × 多种颜色"的组合，而不是"每种颜色 × 多种动词"
- 论文结果：用 n=400 演示（完整空间的一半），V 策略达到了 n=800 的 Random 策略的性能

## 6. 能力与失败模式 (Capabilities & Failure Modes)

### 能做什么
- **诊断捷径行为**：首次系统性地量化 VLA 策略在每个语言因子上的偏差程度
- **跨架构一致性**：6 个不同架构的 VLA 策略共享同一因子层级，说明发现具有普遍性
- **数据效率提升**：真实机器人上用一半演示达到更强性能（n=100 vs n=200）
- **Model-agnostic**：不需要修改模型架构或训练目标

### 不能做什么
- **仅适用于桌面操作**：实验限制在 ManiSkill 仿真和 UR5 桌面操作，未验证移动机器人/双臂/人形
- **因子空间有限**：仅 5 个因子，真实场景中的指令因子远更丰富（如"把红色杯子拿到厨房"涉及更多语义维度）
- **不解决尺寸因子**：Verb-Size 设置中 V 策略在 π0.5 上落后 Random（51% vs 68%），因为尺寸从相对几何中 grounding 本质上困难
- **不优化采集策略本身**：V 策略是启发式的，不是全局最优的；未来可通过主动学习/课程设计改进

### 6.1 隐含假设 (Hidden Assumptions)

1. **Gemini-2.5-Flash 作为 judge 是可靠的**：论文附录显示与人工标注一致，但 judge 模型本身的偏差未被量化。如果 Gemini 对某些因子组合有系统性误判，FDR 分数会失真。
2. **因子层级是跨场景稳定的**：论文发现 color ≥ object ≥ spatial ≥ verb ≥ size 在 6 个模型上一致，但这仅在桌面操作 + 5 因子空间内验证。在更复杂场景中，这个层级可能改变。
3. **偏差感知采集的增益来自因子 grounding 改善**：论文假设性能提升是因为策略更好地 grounding 了弱势因子，但未做消融实验验证这一点（vs. 其他解释如"更多样化的空间配置"）。
4. **模板化指令分解适用于真实场景**：论文使用固定模板 "[Verb] the [Size] [Color] [Object] on the [Spatial Attribute]"，但真实用户指令不一定符合此模板。
