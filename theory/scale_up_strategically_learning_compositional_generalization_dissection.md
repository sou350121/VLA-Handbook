### 1.2 关键机制 (Key Mechanism)

**因子偏差（Factor Bias）的定义**：微调后的策略过度依赖某些主导因子作为捷径，同时 grounding 不足其他因子。

**FDR（Factor Dominance Rate）的核心思想**：
- 在训练时故意将两个因子 f1 和 f2 关联（例如：grasp ↔ sphere，push ↔ cube）
- 推理时呈现训练时未见过的非对角线组合
- 用 Gemini-2.5-Flash 分类每次 rollout 是成功、过度拟合 f1、还是过度拟合 f2
- 计算 `FDR(f1, f2) = (N_f1 - N_f2) / (N_f1 + N_f2 + ε)`

**FDH（Factor Dominance Hierarchy）的核心思想**：
- 对所有因子对的 FDR 做 Copeland ranking
- 每个因子 f_i 的 Copeland 分数：`C(f_i) = Σ_{j≠i} 1[FDR(f_i, f_j) > τ]`，其中 τ = 5%
- 按分数降序排列得到全局层级

⚡ **Eureka Moment**：不同架构的 VLA 基础策略共享几乎相同的因子偏差层级（color ≥ object ≥ spatial ≥ verb ≥ size），这意味着偏差是 VLA 策略的**系统性属性**而非特定模型的缺陷——因此可以用一个 model-agnostic 的通用数据采集策略来修复。

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：
```
FDR(f1, f2) = (N_f1 - N_f2) / (N_f1 + N_f2 + ε)   ∈ (-1, 1)
C(f_i) = Σ_{j≠i} 1[FDR(f_i, f_j) > τ]              （FDH Copeland 分数）
```

**目标**：量化预训练 VLA 策略在微调后对各个指令因子的依赖程度差异。

**变量说明**：
| 符号 | 含义 |
|------|------|
| f1, f2 | 两个被评估的指令因子（如 color 和 verb） |
| N_f1 | rollout 中被判定为过度拟合 f1 的次数 |
| N_f2 | rollout 中被判定为过度拟合 f2 的次数 |
| ε | 趋近于 0 的小常数，防止除零 |
| FDR ∈ (-1, 1) | 正值表示 f1 主导，负值表示 f2 主导，接近 0 表示平衡 |
| τ | 平局阈值（论文使用 5%） |
| C(f_i) | Copeland 分数，用于全局排序 |

**直觉**：FDR 本质上是一个归一化的"偏好差"——如果策略在 400 次 rollout 中有 280 次跟随 f1、120 次跟随 f2，则 FDR = (280-120)/(280+120) = 0.4，说明 f1 显著主导。FDH 则将所有成对比较聚合为一个全局排名，类似于体育比赛中的"积分排名"。

> 符号与本文保持一致。论文使用 Gemini-2.5-Flash 作为 judge 模型分类 rollout 行为，附录 B.2 显示其判断与人类标注高度一致。

## 3. 带数字走一遍：玩具例子 (Worked Example)

假设我们用 π0 模型做 (Color, Object) 因子对的 FDR 评估：

**训练阶段**：
- 故意关联：red ↔ cube，blue ↔ sphere，yellow ↔ cup（对角线训练）
- 300 次演示，随机化其他因子（verb, size, spatial）

**推理阶段**：
- 呈现非对角线组合（如 "grasp the red sphere"——red 在训练中只与 cube 配对）
- 场景中只有两个物体：红色 star（跟随颜色）和红色 cup（跟随物体）
- 发出指令 "grasp the red cup"（red 是训练配对色，cup 是训练配对物体）
- 策略选择红色 star → 跟随颜色；选择红色 cup → 跟随物体

**400 次 rollout 的结果**：
```
成功:     40 次
跟随 Color: 240 次（选择了与颜色匹配的物体，忽略了物体类型）
跟随 Object: 120 次（选择了与物体类型匹配的物体，忽略了颜色）

FDR(color, object) = (240 - 120) / (240 + 120 + ε) = 120 / 360 = 0.333
```

**解读**：FDR = +0.33 表示颜色因子显著主导物体因子。策略倾向于 "找红色的东西" 而非 "找杯子"。

**扩展到全局 FDH**：
假设 π0 的所有成对 FDR 如下（简化版）：

| 因子对 | FDR | 胜者 |
|--------|-----|------|
| color vs object | +0.33 | color |
| color vs spatial | +0.45 | color |
| color vs verb | +0.52 | color |
| color vs size | +0.61 | color |
| object vs spatial | +0.12 | object |
| object vs verb | +0.18 | object |
| object vs size | +0.25 | object |
| spatial vs verb | +0.08 | spatial |
| spatial vs size | +0.15 | spatial |
| verb vs size | +0.06 | verb |

Copeland 分数（τ=5%）：
```
color:   赢 4 场 → C = 4
object:  赢 3 场 → C = 3
spatial: 赢 2 场 → C = 2
verb:    赢 1 场 → C = 1
size:    赢 0 场 → C = 0
```

**FDH 排序**：color ≥ object ≥ spatial ≥ verb ≥ size

**指导数据采集**：
- 当需要 2 个因子变化时：选择 size（最弱因子），固定 color，变化 size
- 当需要 3 个因子变化时：选择 verb + size，固定 color + object，变化 verb + size
- 采样策略 V：固定主导因子，变化弱因子（列式采样），而非随机采样

## 4. 工程视角 (Engineering View)

| 维度 | 数值/约束 | 工程含义 |
|------|-----------|----------|
| 指令空间大小 | 6×6×6×6×5 = 6,480 种唯一指令 | 穷举覆盖在真实机器人上不可行（每个指令至少 1 次演示 = 6480 次） |
| 每次 FDR 评估 | 300 次训练演示 + 400 次 rollout | 单次因子对评估成本可控；5 因子需 C(5,2)=10 次评估 |
| Judge 模型 | Gemini-2.5-Flash | 自动化 rollout 分类，附录显示与人类标注一致；替代方案：人工标注或更小的分类器 |
| 真实机器人实验 | UR5 + RealSense D455 + FLIR 手内相机 + GELLO 遥操作 | 3 个任务（Bun/Pizza/Cup），每个 16 种指令变体 |
| 数据效率 | 策略 V 用 n=100 超过基线 n=200 | 真实场景中演示成本减半，直接节省遥操作人力 |
| 因子变化 f | 衡量环境配置切换成本 | 策略 V 在相同 f 下性能更优，意味着更少的环境切换次数 |

**部署约束**：
- FDR/FDH 评估是**离线**的，不影响推理延迟
- 偏差感知采样策略 V 是**数据采集阶段**的策略，不改变模型架构
- 全局 FDH 排序（color ≥ object ≥ spatial ≥ verb ≥ size）被证明跨模型一致，因此可以**预计算一次**，用于所有后续数据采集，无需为每个新任务重新估计偏差

## 5. 数据与评测 (Data & Eval)

### 仿真环境
- **平台**: ManiSkill（物理仿真）
- **指令模板**: "[Verb] the [Size] [Color] [Object] on the [Spatial Attribute] of the table"
- **因子词汇**: Verb(6) × Color(6) × Object(6) × Size(6) × Spatial(5) = 6,480 种指令
- **场景**: 每个场景最多 3 个 distractor 物体，随机空间配置
- **评估模型**: π0, π0.5, GR00T-N1.7（仿真）；GR00T-N1.7（真实机器人）

### 评测指标
| 指标 | 定义 | 用途 |
|------|------|------|
| **FDR** | 成对因子偏差率，∈(-1,1) | 诊断两个因子之间的相对依赖强度 |
| **FDH** | Copeland ranking 全局排序 | 聚合为全局因子层级，指导采样策略 |
| **成功率** | rollout 成功完成任务的比例 | 评估数据采集策略的最终效果 |
| **因子变化 f** | Hamming distance 衡量指令配置差异 | 控制环境切换成本，公平比较 |
| **演示预算 n** | 允许收集的演示总数 | 评估数据效率 |

### 基线策略
| 策略 | 描述 | 优势 | 劣势 |
|------|------|------|------|
| **Complete** | 穷举所有因子组合 | 上界性能 | 组合爆炸，真实场景不可行 |
| **Random** | 随机采样因子组合 | 简单 | 预算分散，每个指令采样不足 |
| **L** | 固定每个因子，均匀采样其他因子 | 结构化 | 未考虑因子偏差 |
| **V (Ours)** | 固定主导因子，变化弱因子 | 样本高效 | 依赖全局 FDH 排序的普适性 |

## 6. 能力与失败模式 (Capabilities & Failure Modes)

### 能力
- **诊断能力**: FDR/FDH 框架可以精确定位策略失败的具体因子层面原因，而非仅报告 "任务失败了"
- **跨模型一致性**: 6 个基础策略（RT 系列、OpenVLA、π0 系列、GR00T）共享相似的因子层级
- **数据效率**: 策略 V 在真实机器人上用一半演示（n=100 vs n=200）实现更强性能
- **Sim-to-Real 迁移**: 仿真中发现的偏差模式和策略有效性在真实 UR5 机器人上得到验证

### 失败模式
| 场景 | 失败原因 |

| 多步任务（未验证） | 论文仅评估单步操作；多步任务中的因子偏差模式可能不同 |

### 6.1 隐含假设 (Hidden Assumptions)

1. **因子独立性假设**: 论文将指令分解为 5 个独立因子（Verb, Color, Object, Size, Spatial），但真实指令中这些因子可能存在语义依赖（如 "pour" 动词更常与 "cup" 物体关联）。因子独立性假设简化了实验设计，但可能忽略了真实的语言共现模式。

2. **全局 FDH 普适性假设**: 策略 V 使用一个全局 FDH 排序（color ≥ object ≥ spatial ≥ verb ≥ size）指导所有任务的数据采集，而非为每个任务重新估计偏差。论文在 Finding 3 中验证了跨模型一致性，但未验证跨任务/跨场景一致性。如果不同任务的最弱因子不同，全局排序可能不是最优的。

3. **Judge 模型可靠性假设**: FDR 计算依赖 Gemini-2.5-Flash 对 rollout 视频的分类。附录 B.2 显示与人类标注一致，但未报告 judge 模型自身的置信度或不确定性。如果 judge 在某些边界情况下判断不稳定，FDR 估计会有噪声。

4. **桌面操作代表性假设**: 所有实验在受控桌面操作场景中进行。论文在 Limitations 中承认，开放世界中因子偏差模式是否保持一致是开放问题。
