### 1.2 关键机制 (Key Mechanism)

**核心思想：分层抽象，而非端到端。**

本文的方法可以理解为在"规划器"和"世界模型"之间插入一个可学习的抽象层：

1. **航路点空间（Waypoint Space）**：将高维目标（48 维关节姿态）投影为 4 个 2D 图像点——骨盆、头部、左手、右手在当前观测帧上的投影位置。这 8 个维度天然携带空间语义，且可通过 CEM 高效搜索。

2. **扩散策略 $\pi_\theta$**：将航路点映射为 $T=8$ 步低层关节动作序列。输入：上下文观测 + 上下文姿态 + 航路点标注图像；输出：8 步 48 维关节动作。策略在训练时通过从未来姿态反投影得到航路点标签。

3. **提升世界模型 $f^{\text{HL}}$**：组合策略与冻结的世界模型。输入单个航路点动作 → 策略生成 8 步关节动作 → 世界模型自回归生成 8 帧观测 → 输出最终观测 $o_{t+T}$。

⚡ **Eureka Moment**：在 egocentric 视角下，目标图像 o_g 几乎无法提供目标姿态信息（身体大部分在画面外），但 2D 航路点直接在当前帧上标注目标位置——同样的信息，表达方式决定了是否可搜索。

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：

```
LWM(o_t, p_t, a^HL) = WorldModel rollout( π(a^HL | o_t, p_t) )
```

即：提升世界模型 = 策略将高层动作翻译为低层动作序列 + 世界模型自回归展开。

**目标**：在保持世界模型冻结的前提下，通过训练一个轻量策略 $\pi_\theta$，使得 CEM 在低维航路点空间中搜索到的动作序列，能够产生比直接在 48 维关节空间中搜索更接近目标的最终姿态。

**核心方程**：

```
策略输出：a^LL_{t:t+T-1} = π_θ(o_t, p_t, a^HL_t)

世界模型自回归：o_{τ+1} = f_φ(o_τ, a^LL_τ), τ = t, ..., t+T-1

提升世界模型：o_{t+T} = f^HL(o_t, p_t, a^HL_t)
```

**CEM 规划目标对比**：

```
低层搜索：a^LL* = argmin_{a^LL} E_{o_g~f_φ(a^LL)} [C(o_g, o_target)]

高层搜索：a^HL* = argmin_{a^HL} E_{o_g~f_φ(π(a^HL))} [C(o_g, o_target)]
```

**变量说明**：

| 符号 | 含义 | 维度 |
|------|------|------|
| o_t | t 时刻观测（图像） | $H \times W \times 3$ |
| p_t | t 时刻姿态 | $\mathbb{R}^{48}$ |
| $a^{\text{HL}}$ | 高层航路点动作 | $\mathbb{R}^8$（4 个关节 × 2D） |
| $a^{\text{LL}}$ | 低层关节动作 | $\mathbb{R}^{48}$ |
| T | 策略动作序列长度 | 8 |
| $K_\pi$ | 策略上下文长度 | 3 |
| K | 世界模型上下文长度 | 8 |
| $C(\cdot)$ | 感知相似度代价函数 | 标量 |

> 符号与本文保持一致：粗体表示序列（如 o_t），非粗体表示单时刻量。

## 3. 带数字走一遍：玩具例子 (Worked Example)

假设一个简化场景：

- **初始状态**：agent 站在房间中央，目标是在 3 米外的门把手处
- **初始 MJE**：假设起始姿态与目标姿态的平均关节误差为 1.2 米
- **CEM 搜索**：64 个样本 × 6 次迭代

**PEVA CEM（低层搜索）**：
- 搜索空间：48 维 × 8 步 = 384 维
- 每次 CEM 迭代在高斯先验 N(0, 0.05²I) 中采样 384 维向量
- 64 个样本在 384 维空间中覆盖极其稀疏
- 结果：MJE 从 1.2m 降到 1.112m（降低 8.8 cm）
- 问题：搜索空间太大，样本无法有效覆盖

**Lifted CEM（高层搜索）**：
- 搜索空间：8 维 × 1 步 = 8 维
- 每次 CEM 迭代在 N(0, 0.3²I) 中采样 8 维向量（4 个航路点的 2D 坐标）
- 64 个样本在 8 维空间中覆盖充分得多
- 策略将每个航路点映射为 8 步合理的关节动作（策略已学习运动模式）
- 世界模型自回归展开为观测序列
- 结果：MJE 从 1.2m 降到 0.87m（降低 33 cm）
- 提升倍数：$33/8.8 \approx 3.8\times$

**关键直觉**：搜索维度从 384 降到 8，相同样本量下的空间覆盖率提升约 384/8 = 48 倍。这是维度灾难的基本数学——体积比随维度指数增长。

## 4. 工程视角 (Engineering View)

| 工程维度 | PEVA CEM | Lifted CEM | 含义 |
|----------|----------|------------|------|
| 搜索维度 | 384 维/次 | 8 维/次 | 维度降低 $48\times$ |
| CEM 样本效率 | 低（稀疏覆盖） | 高（充分覆盖） | 相同样本量下搜索质量更高 |
| 策略推理开销 | 无 | 1 次扩散去噪（64 步） | 新增但固定，可接受 |
| 世界模型推理 | $64\times6\times T$ 次 | $64\times6\times1$ 次策略 + 相同 WM 展开 | 世界模型调用次数相同 |
| 总计算量 | 高 | 中等 | 高层搜索收敛更快 |
| 部署约束 | 需在线搜索 | 需额外加载策略模型 | 策略轻量（扩散 UNet [256,384,512]） |
| 实时性 | 受限于搜索预算 | 搜索预算可降低 | 实际部署更友好 |

**工程含义**：
- 策略模型只需加载一次，推理是前向扩散过程，可批处理
- 世界模型冻结意味着不需要重新训练或微调——任何已有的世界模型都可以"即插即用"地被提升
- 航路点空间天然支持手动指定（在图像上点 4 个点），这为 human-in-the-loop 控制提供了自然接口

## 5. 数据与评测 (Data & Eval)

**数据集**：Nymeria（论文 [23]）
- 来源：Project Aria 眼镜 + XSens 动捕服
- 规模：50 个室内外环境，15 分钟连续第一人称视频
- 采样频率：4 Hz
- 身体模型：XSens 上半身 checkpoint，15 个关节，48 维动作

**训练配置**（论文 §4.0.3）：
- 策略训练：10 epochs，lr=5×10⁻⁴，AdamW，batch size=256
- 动作序列长度 $T=8$，上下文 $K_\pi=3$
- UNet 维度：[256, 384, 512]（从 NoMaD 的 [64,128,256] 增大）
- 航路点掩码：训练时 50% 全可见，50% 每个航路点独立以 0.5 概率掩码

**评测指标**：Mean Joint Error (MJE)，单位米
- 计算方式：从初始姿态积分预测动作得到最终姿态，与前向运动学计算所有关节的 3D 位置，平均欧氏距离

**规划任务**：128 个混合导航+交互任务
- 约束：目标姿态至少 1 个关节在当前观测中可见
- 约束：初始 MJE $\geq 0.1\,\text{m}$（排除静止任务）

### 6.1 隐含假设 (Hidden Assumptions)

1. **世界模型足够准确**：提升层的质量受限于底层世界模型的预测精度。如果 $f_\varphi$ 在自回归展开中累积误差大，LWM 的输出也会失真。论文未系统分析世界模型误差对提升层的影响。

2. **航路点到关节动作的映射是良态的**：假设 8 维航路点空间到 48 维关节空间的映射可以被扩散策略有效学习。对于某些 embodiment（如多指手、软体机器人），这个映射可能高度多模态或不连续。

3. **叶关节足以控制全身**：选择骨盆/头/手作为航路点基于"这些是交互和导航的关键"的假设。但对于某些任务（如用肘部开门），非叶关节可能更重要。

4. **CEM 在 8 维空间中有效**：假设航路点空间的代价函数地形足够平滑，使 CEM 能收敛到好的局部最优。未分析代价函数的凸性或存在多个局部最优的情况。

5. **2D 投影保留了足够的信息**：假设当前观测图像 o_t 和航路点间距足以推断 3D 目标姿态。在遮挡严重或深度变化大的场景中可能不成立。
