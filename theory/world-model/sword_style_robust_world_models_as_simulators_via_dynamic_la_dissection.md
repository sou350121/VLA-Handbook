## 1. 核心架构/方法总览 (Overview / Architecture)

Sword 是一个**解耦式**世界模型框架——与 RynnVLA/WorldVLA 的"统一架构"不同，Sword 将世界模型严格定位为 VLA 策略的仿真器（simulator），不共享策略网络。整个框架由两大核心模块组成：

### 1.1 系统对比概览 (System Component Comparison)

| 组件 | 输入 | 输出 | 训练/推理差异 | 关键设计 |
|------|------|------|--------------|---------|
| 风格增强 (SGSA) | 原始帧 o_t + style_t | 增强帧 o_t~ | 仅训练阶段 | 基于 Cosmos-Transfer 2.5，注入深度/分割/任务先验 |

### 1.2 关键机制 (Key Mechanism)

**模块一：结构引导风格增强 (Structure-Guided Style Augmentation, SGSA)**

问题：世界模型在训练时看到的视觉条件单一（固定光照、固定桌面颜色、固定机械臂颜色），导致模型"死记"了这些表面纹理而非学习物理动力学。遇到 OOD 条件时，从第 15 帧开始风格偏移，第 30 帧完全模糊/结构崩塌。

解法：用 Cosmos-Transfer 2.5 做风格迁移，但**不是无约束迁移**——通过三层先验约束保证几何结构和任务语义不变：
- **深度图** (DepthAnything)：保持空间几何
- **语义分割** (SAM2 + GroundingDINO)：保持物体级语义
- **任务先验** (T5 编码的 task+style 联合 prompt)：保持机器人-物体交互语义

增强函数从 `o_t~ = A(o_t, style_t; η)` 升级为 `o_t~ = A(o_t | d_t, s_t, e_t; η)`，其中 d_t 是深度图，s_t 是分割掩码，e_t 是 T5 编码的联合 prompt。

⚡ **Eureka Moment**：世界模型学不会物理动力学的根本原因不是容量不够，而是训练数据太"干净"——模型选择了更简单的策略：记住像素统计规律而非学习状态转移规律。风格增强 + 结构约束让模型"别无选择"，只能学动力学。

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：
```
L_DLB(θ) = E[ ||ε - ε_θ(z_{t,τ}, τ, a_t, C_t)||² ]
```

**目标**：训练一个动作条件化的扩散世界模型，使其在自回归推理时能稳定预测未来状态，即使初始条件有 OOD 风格偏移。

**核心方程**：

```
世界模型定义:
  o^_{t+1} ~ P_hat_φ(o_{t+1} | o_t, a_t)

风格增强:
  o_t~ = A(o_t | d_t, s_t, e_t; η)
  其中: d_t = Depth(o_t), s_t = Seg(o_t), e_t = Enc_T5([task_t; style_t])

DLB 训练目标:
  L_DLB(θ) = E_{z_t, ε, τ, a_t, C_t} [ ||ε - ε_θ(z_{t,τ}, τ, a_t, C_t)||² ]
  其中: ε ~ N(0, I), τ = diffusion timestep, C_t = 动态潜变量缓存
```

**变量说明**：

| 符号 | 含义 | 维度/备注 |
|------|------|----------|
| o_t | t 时刻观测帧 | 原始像素空间 |
| z_t | o_t 的 VAE 潜变量 | 压缩 ~60x |
| a_t | 动作序列 | 以文本形式注入 DiT |
| $\tau$ | 扩散时间步 | 标准扩散训练 |
| $\varepsilon$ | 高斯噪声 | N(0, I) |
| $\varepsilon_\theta$ | 网络预测的噪声 | DiT 输出 |
| C_t | 动态潜变量缓存 | 存储 $z^t$，在线更新 |
| $\eta$ | 风格变换强度 | 超参 |
| d_t, s_t, e_t | 结构先验 | 深度图/分割/任务编码 |

**直觉**：标准扩散模型用 `||ε - ε_θ||²` 训练，条件是用 ground-truth 历史帧（Teacher Forcing）。Sword 把条件换成缓存中的自身预测 `C_t`，并且是**渐进式**替换——早期以 GT 为主（稳定），后期逐渐增加预测条件比例（对齐推理分布）。损失函数形式不变，但条件分布变了，这才是关键。

> 符号与本文保持一致：P_hat_φ 参数化扩散 Transformer，L_DLB 是去噪目标，C_t 是动态缓存。

## 3. 带数字走一遍：玩具例子 (Worked Example)

假设一个简化的 2D 机械臂抓取场景，用具体数值走一遍 Sword 的训练和推理流程：

**训练阶段 — 第 1 步：风格增强**
```
原始帧 o_0: 桌面颜色 RGB(200,200,200), 机械臂 RGB(100,100,100), 光照 500 lux
风格变换后 o_0~: 桌面颜色 RGB(150,180,220), 机械臂 RGB(180,120,80), 光照 350 lux
结构先验保持不变: 深度图 d_0 = [0.5m, 0.5m, 0.6m, ...]（物体位置不变）
                  分割掩码 s_0 = [机械臂, 物体, 桌面, ...]（语义不变）
```

**训练阶段 — 第 2 步：DLB 渐进式自举**

假设训练总步数 T = 10000，当前步 t = 5000（中期）：
```
自举概率 p_bootstrap(t) = t / T = 5000/10000 = 0.5

对于每个训练样本:
  50% 概率: 用 ground-truth 潜变量作为历史条件（Teacher Forcing）
  50% 概率: 用缓存 C_t 中的预测潜变量 z^t 作为历史条件（Self-Conditioning）

早期 (t=1000): p = 0.1 → 90% GT, 10% 预测
中期 (t=5000): p = 0.5 → 50% GT, 50% 预测
后期 (t=9000): p = 0.9 → 10% GT, 90% 预测
```

**训练阶段 — 第 3 步：扩散去噪**
```
输入: z_{t,τ} = 加噪后的目标潜变量 (τ=500/1000)
条件: [历史上下文 (GT 或缓存), 动作文本 a_t]
网络输出: ε_θ (预测的噪声)
损失: L = ||ε - ε_θ||² = 均方误差
假设: ε = [0.1, -0.2, 0.05, ...], ε_θ = [0.08, -0.18, 0.07, ...]
     L = 0.0012 (训练收敛后)
```

**推理阶段 — 自回归 rollout**
```
Step 0: 输入 o_0 (OOD 风格: 新桌面颜色) + a_0..N
Step 1: 预测 o^_1..8 (8帧)
Step 2: 取 o^_8 作为新上下文，预测 o^_9..16
...
Step N: 连续预测 64 帧 (8 步 × 8 帧/步)

WoVR 在 Step 3 开始模糊 (Frame 25)，Step 4 结构崩塌 (Frame 30+)
Sword 在 Step 8 仍保持清晰，风格与 o_0 一致
```

**工程含义**：

## 6. 能力与失败模式 (Capabilities & Failure Modes)

### 能做什么

| 能力 | 场景 | 原因 |
|------|------|------|
| OOD 风格泛化 | 新光照/颜色/背景下的稳定预测 | 风格增强让模型见过足够多的视觉变化 |
| 长程自回归稳定 | 64+ 帧预测不模糊/不崩塌 | DLB 消除了训练-推理分布偏移 |
| 动作跟随 fidelity | 正确跟随抓取/放置等动作序列 | 结构先验保持了几何和语义约束 |
| RL 仿真器 | 在"想象"中完成 VLA 策略 GRPO 训练 | 世界模型提供可靠的奖励信号 |

### 不能做什么

| 失败模式 | 场景 | 原因 |
|---------|------|------|
| 真实机器人迁移 | 未见真实机器人实验 | 仅 LIBERO 仿真验证，sim2real gap 未知 |
| 多任务泛化 | 仅 LIBERO-Spatial 子集 | 未测试 LIBERO-Object/Goal/Long 等其他子集 |
| 极端 OOD 风格 | 超出风格增强覆盖范围的变化 | 风格增强有分布边界，超出部分未测试 |
| 超长程预测 | 512+ 帧连续自回归 | 实验未报告极端长程下的表现 |

### 6.1 隐含假设 (Hidden Assumptions)

1. **风格增强覆盖足够广**：假设 Cosmos-Transfer 2.5 生成的风格变化覆盖了推理时可能遇到的 OOD 条件。如果真实环境有训练时从未见过的风格（如完全不同的机器人平台），泛化可能失效。

2. **结构先验不会成为瓶颈**：DepthAnything、SAM2、GroundingDINO 都是预训练模型，在 LIBERO 上应该表现良好，但如果遇到训练数据中没有的物体类别，深度/分割质量下降会直接影响风格增强质量。

3. **Wan 2.2 TI2V 的 DiT 架构足够表达**：假设 DiT 架构有足够的容量同时建模视觉生成和动作条件。如果架构本身是瓶颈，SGSA + DLB 的改进上限有限。

4. **仿真器 fidelity 与 RL 成功率正相关**：论文假设更好的预测质量 $\to$ 更好的 RL 训练信号 $\to$ 更高的策略成功率。这个因果链在 LIBERO 上成立，但未必在所有任务上都成立。

## 7. 与相关工作对比 (Comparison)

| 方法 | 关注点 | 架构 | 训练方式 | 适用场景 |
|------|--------|------|---------|---------|
| **Sword** | 世界模型作为 RL 仿真器 | 解耦 (Wan DiT + 独立策略) | SGSA + DLB | VLA 后训练，需要 OOD 鲁棒仿真 |
| WoVR | 世界模型作为 RL 仿真器 | 解耦 (Wan DiT + 独立策略) | Teacher Forcing | 同左，但对 OOD 敏感 |
| RynnVLA | 统一架构 | 共享潜空间 (policy + generation) | 联合训练 | 需要 action 和 visual 互增强 |
| WorldVLA | 统一架构 | 共享潜空间 | 联合训练 | 同左 |
| Self-Forcing | 缓解 exposure bias | 通用视频生成 | 自回归 unrolling 训练 | 通用视频预测，非机器人专用 |
| DMD / Diffusion Forcing | 缓解 exposure bias | 通用视频生成 | 噪声注入 context | 通用视频生成 |

**面试 Tip**：当被问到"世界模型作为仿真器和统一架构（如 WorldVLA）有什么区别？"时，可以这样答：解耦式（如 Sword/WoVR）把世界模型和策略完全分开，世界模型只做一件事——提供可靠的仿真环境，策略可以在其上跑任何 RL 算法；统一式（如 RynnVLA/WorldVLA）让策略理解和视觉生成共享潜空间，两者互增强，但灵活性更低——策略和生成被绑在一起，不能独立更换 RL 算法或世界模型。

## 8. 精读建议 (Reading Guide)

**值得精读原文的人**：
- 做世界模型作为 RL 仿真器的研究者——DLB 机制对任何自回归生成模型都有参考价值
- 要评估将 VLA 策略迁移到 OOD 视觉条件的工程师——SGSA 提供了系统化的风格增强方案
- 关注 exposure bias 在具身智能中表现的研究者——本文是少有的将这一问题放在机器人仿真场景中系统解决的论文

**建议章节路径**：
先读 §3.1（SGSA 结构引导风格增强）$\to$ 再看 §3.2（DLB 动态潜在自举）$\to$ 可跳 §2（相关工作，除非你要写文献综述）$\to$ 重点看 §4.2 和 §4.4（OOD 泛化和 fidelity 的定性分析）$\to$ §5 消融实验验证了两个模块的独立贡献

**不值得精读的理由**：
如果你不做机器人仿真、已熟悉 Self-Forcing / DMD 等 exposure bias 缓解技术、或对 LIBERO 基准不感兴趣——读摘要和 §1 引言就足够了。本文的核心创新（SGSA + DLB）本质上是工程组合，方法论深度中等。
