### 1.2 关键机制 (Key Mechanism)

LaWAM 的核心设计决策有四个：

1. **复用潜动作模型的解码器作为世界模型**：前人（LAPA、UniVLA 等）把潜动作模型（LAM）的解码器当作辅助训练组件，训练完就丢弃。LaWAM 反其道而行——这个解码器天然就是一个潜动作条件化的世界模型，直接拿来用。

2. **在冻结视觉编码器（DINOv3）的潜空间中操作**：不生成像素，只预测特征。DINOv3 的特征空间已有丰富的语义和空间结构，子目标本身就携带了足够的几何信息。

3. **潜动作蒸馏（Latent-Action Distillation）**：部署时无法用后验编码器（需要未来观测），所以训练一个策略先验 p_θ(ẑ|o,l) 来预测潜动作，然后送入 LaWM 解码成子目标。

4. **Knowledge Insulation (KI)**：策略训练时保护 LaWM 参数不被梯度覆盖，确保世界模型的动力学知识不被策略学习破坏。

⚡ **Eureka Moment**：潜动作模型的解码器 ≠ 辅助训练组件，它本身就是最轻量、最高效的世界模型接口——把潜动作展开为具身化的潜视觉子目标，一步到位。

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：
```
p(a_{1:T}, û_T, ẑ | o, l) = p_θ(ẑ|o,l) · p_ω(û_T|u, ẑ) · p_η(a_{1:T}|o,l,u,û_T)
         └───┘         └───────────┘         └─────────────────────┘
       策略先验       世界模型解码          动作专家生成
     预测潜动作       → 潜视觉子目标        → 动作 chunk
```

**目标**：将动作生成分解为三个可独立优化的组件——策略预测"想做什么"（潜动作），世界模型预测"做了之后看到什么"（潜子目标），动作专家生成"具体怎么做"（动作序列）。

**公式分解**：

```
训练阶段 1 — 潜动作模型（LAM）:
L_LAM = L_wm + L_aux + β·DKL(q_φ(z|u, u_T) ‖ N(0,I))

其中:
  L_wm  = ‖ũ_T - u_T‖²          (前向预测：解码器匹配目标特征)
  L_aux = ‖g(s, z) - s_T‖²      (辅助：末端执行器状态预测)
  DKL   = 潜动作空间正则化（使其可被策略建模）
```

```
训练阶段 2 — LaWAM 策略:
L_LaWAM = λ_distill·L_distill + λ_wm·L_wm + L_act

其中:
  L_distill = E[‖ẑ - z‖²]       (潜动作蒸馏：策略预测 ≈ 后验推断)
  L_wm      = ‖û_T - u_T‖²      (子目标监督：策略驱动的子目标匹配真实)
  L_act     = 条件流匹配损失      (动作 chunk 生成)
```

**变量说明**：

| 符号 | 含义 | 维度/类型 |
|------|------|----------|
| o, l | 当前观测、任务指令 | 图像 + 文本 |
| u = f_ψ(o) | DINOv3 编码的潜特征 | 冻结编码器输出 |
| z, ẑ | 真实潜动作（后验）/ 策略预测潜动作 | 连续向量 |
| u_T, û_T | 真实未来特征 / 策略驱动预测子目标 | 与 u 同维 |
| a_{1:T} | 动作 chunk（物理时间跨度 τ） | 机器人关节空间 |
| τ | 物理时间间隔（非帧偏移） | 秒 |
| s, s_T | 当前/未来末端执行器状态 | 位姿 |

> 符号与论文保持一致：u 表示潜特征（非控制输入），z 表示潜动作（非离散代码），τ 表示物理时间跨度（非帧数）。

## 3. 带数字走一遍：玩具例子 (Worked Example)

假设一个简化的 2D 操纵场景：

**设定**：
- 当前观测 o：机械臂在 (0, 0)，目标物体在 (3, 2)
- 指令 l："把物体移到右边"
- 物理时间跨度 τ = 0.5s（对应一个 action chunk）

**Stage 1 训练时**：
1. DINOv3 编码：u = f_ψ(o)，u_T = f_ψ(o_T)，其中 o_T 是 0.5s 后的观测
2. 后验编码器推断潜动作：z = q_φ(z | u, u_T)
   - 假设 z ≈ [0.8, 0.3, -0.1, ...]（编码了"向右移动"的视觉变化）
3. 解码器预测：ũ_T = LaWM_ω(u, z)
4. 损失：L_wm = ‖ũ_T - u_T‖² = 0.05（训练收敛后）

**Stage 2 推理时**：
1. 策略先验预测：ẑ = p_θ(ẑ | o, l) ≈ [0.75, 0.28, -0.08, ...]（接近 z）
2. LaWM 解码子目标：û_T = LaWM_ω(u, ẑ)
   - û_T 对应的视觉特征显示"物体在 (5, 2)"位置
3. 动作专家生成：a_{1:T} = p_η(a_{1:T} | o, l, u, û_T)
   - 输出 8 个动作帧：机械臂从 (0,0) 移动到 (3,2)，抓取，再移到 (5,2)
4. 总延迟：187ms（单次 LaWM 前向 + 单次 DiT 去噪）

**关键直觉**：潜动作 z 不是一个具体的关节角度序列，而是一个"视觉变化意图"——LaWM 把这个意图翻译成了当前具身下的具体视觉子目标。同一个 z（"向右移动"）在不同机器人/不同初始位置下，LaWM 会生成不同的 û_T。

## 4. 工程视角 (Engineering View)

| 工程维度 | 数值/特征 | 含义 |
|----------|----------|------|
| 总参数量 | 2.3B | 比 π0.5 (3.5B) 更小，比 LingBot-VA (5.5B) 小 58% |
| LaWM 参数量 | 230M | 占世界建模部分的 5%（对比 WAN 5B） |
| 单 chunk 延迟 | 187ms (A100) | 比 π0.5 (220ms) 还快，比 LingBot-VA (4482ms) 快 24x |
| 推理迭代次数 | 1 次 LaWM + 10 步 DiT 去噪 | 非迭代世界模型预测 |
| 训练数据量 | 3000h 机器人 + 1500h 人类 | 人类视频仅用于 LaWM 预训练 |
| 控制频率 | 各数据集保持原生频率 | 物理时间编码处理多频率混合 |
| 部署约束 | 需 A100 级别 GPU（2.3B 模型） | 边缘部署需量化 |

**工程含义**：
- **非迭代世界模型是延迟杀手锏**：像素 WAM 需要多次去噪/自回归生成未来帧，LaWM 只需一次前向。这 24x 延迟优势直接决定了实时操纵的可行性。
- **Knowledge Insulation 是工程必需**：没有 KI 时，策略梯度会覆盖 LaWM 学到的动力学，消融实验显示 w/o KI 在 LIBERO-Long 上 drop 最明显。这不是学术装饰，是训练稳定性保障。
- **物理时间编码解决多频率问题**：不同数据集的控制频率不同（5Hz vs 20Hz），LaWAM 用物理时间间隔 τ 而非帧偏移来定义子目标，避免了频率对齐问题。

|------|------|------|
| 移动相机/人形机器人 | LaWM 无法学习连贯潜动作空间 | 相机自运动主导观测变化，掩盖了动作效果 |
| 精细可变形物体动力学 | 毛巾折叠等任务仍有挑战 | 训练数据中精细变形样本稀少 |
| 大视角变化的人眼视频 | 潜动作空间退化 | DINOv3 特征在剧烈视角变化下不穩定 |

### 6.1 隐含假设 (Hidden Assumptions)

1. **相机稳定性假设**：论文假设观测变化主要由机器人动作引起，而非相机运动。这在桌面操纵中成立，但在移动/人形场景中不成立——作者已在 Limitations 中承认，但未提供缓解方案。

2. **潜空间线性假设**：LaWM 在 DINOv3 特征空间中进行预测，隐含假设视觉变化在潜空间中近似线性/平滑。但 DINOv3 是为表征学习优化的，不是为动力学建模优化的——某些物理变化（如遮挡、反射）在潜空间中可能高度非线性。

3. **物理时间充分性**：用固定物理间隔 τ 定义子目标，假设 τ 内的动力学对所有任务足够"一致"。但不同任务的时间尺度差异很大（快速抓取 vs 慢速折叠），单一 τ 可能不是最优。

4. **知识绝缘可完美实现**：KI 假设可以完全隔离 LaWM 和 Action Expert 的梯度。实际实现中可能有残余梯度泄漏，论文未提供 KI 有效性的定量验证。
