## 1. 核心架构/方法总览

### 1.1 系统对比概览

| 模块 | 输入 | 输出 | 训练/推理差异 | 时序语义 |
|------|------|------|----------------|----------|
| 物理态滤波 q_f | 历史 H_t | P_t 后验 | 推理时不看未来（前瞻规划用），但训练时由 q_s 蒸馏 | 每个时间步 |
| 平滑器 q_s | H_t, a^F, S^F_{t+1} | ξ_t=(P_t,U_t) | 事后/反事实用，需要已观测的未来 | 每个时间步事后 |
| 图生成器 f_G | P_t, H_t, 候选动作 a | G^obj, W^obj, G^dim, Γ | 换动作即重生成 | 每个候选动作、每步 |
| 因子消息传递 | Z_t, Γ, P_t, a, U_t | Ẑ_{t+1} | 一次前进一步 | 时间步 |
| 锚定反事实 | S^F_{t+1}, 对比 Δ̂ | Ŝ^cf | 推理时用；训练时参与 L_rt 往返损失 | 每个候选动作 |
| CAP 规划 | M 个共享 ξ、候选序列 | a* | 在线采样 | 每次决策 |
| 事后更新 | 事实片段 τ^F | 重试起点、π_φ | 训练 | 每个片段 |

**关键区分**：H_t 是**历史**（已经观测到的帧和已经执行的动作）；S_{t+1} 到 S_{t+H} 是**未来预测帧**。这两者在同一篇里用的是同一套 t 下标，容易读混。

### 1.2 关键机制

- **动作 = 图生成器，不是图上的一个输入特征**。换动作时，边是否存在（G^obj）和边有多强（W^obj）都会重新算，所以接触的产生、断开、力重定向都能表达成拓扑变化，而不是藏在某个全局 context 向量里。
- **对象数可变**。类型模板 B^type 与成对共享网络 L_ψ、Ω_η 让加对象只改「求值次数」，不改「参数个数」。这是作者声称相对固定维度潜 DAG（如 CausalVAE 的 h(B)=tr(exp(B⊙B))−d=0 约束）的主要结构优势。
- **时间构造保证无环**。图连的是 t 时刻变量到 t+1 时刻变量，因此不需要 NOTEARS 类无环惩罚——除非引入同切片瞬时边。
- **共享类型条件函数 + 对称聚合** ⇒ 转移对对象置换等变，支持可变基数。作者明确承认：没见过的机制类型仍需要适配或不确定性检测。
- **一个情境，多个分支**。ξ_t 只抽一次，所有候选动作共用；只有 f_G 及其下游机制不同。这是整篇方法的枢纽。

⚡ **Eureka Moment**：把「比较动作」从「分别预测再相减」改写成「同一 ξ 下过两张图再相减」——共同情境项自动抵消，剩下的只是动作真正改动的部分。

## 2. 数学核心

📌 **Napkin Formula**（一行抓住本质）：

```
Ŝ^cf(a') = S^F + Φ(H, ξ^F, a') − Φ(H, ξ^F, a^F)     ξ^F 两支共用
```

先给目标：在同一物理情境下，算出「换动作会改变什么」，而不是「换动作平均会怎样」。

**（a）单步识别**

```
假设：一致性、正性、动作干预的模块性、无隐藏动作混淆
      S_{t+1}(a) ⊥ A_t | H_t

命题 1：  p(s' | h, a) = p(s' | h, do(a))    对每个有支撑的 (h,a)
证明要点：图蕴含 A_t ⊥ P_t | H_t ⇒ p(p|h,a)=p(p|h)，
          代入观测转移积分即得；等价于 H_t 阻断了 A←H←P→S 与 A←H→S 两条后门。
```

作者特别分开两件事：**部分可观测**只让 P_t 不确定，不产生混杂；只有当某个未记录的特权变量 C^π 在给定 H_t 后仍同时影响 A_t 和 S_{t+1}，式 6 才失效。

**（b）图结构（工程上最该看的部分）**

```
B̄_t   = (Υ_t B^type Υ_tᵀ) ⊙ K(V_t, A_t)                      候选邻接（类型模板×几何可行）
G^obj = B̄_t ⊙ HardConcrete( L_ψ(V_t, P_t, A_t) )             边是否存在
W^obj = G^obj ⊙ Ω_η(V_t, P_t, A_t)                           边强（带符号）
G^dim = (G^obj ⊗ B^dim) ⊙ HardConcrete( L_ψd(Z_t, P_t, A_t) ) 升到因子分辨率
Γ_t   = G^dim ⊙ (W^obj ⊗ 1_K 1_Kᵀ)                           有效加权邻接
Ẑ_{t+1} = F_θ( Z_t, Agg[ Γ_t ⊙ M_θ(Z_t, P_t, A_t) ], U_t )
```

变量说明：

| 符号 | 含义 | 常见误读 |
|------|------|----------|
| N_t | t 时刻对象/机器人部件数，可随场景变化 | 不是固定维度 |
| K | 每个对象拆成的**状态因子数** | 不是采样帧数 |
| H | 规划时域**步数**（a_{t:t+H−1}） | 与历史 H_t 同符号但含义完全不同 |
| M | 每次决策的**共享情境抽样次数** | 不是训练轮次，也不是回合数 |
| U_t | 单步转移噪声 | 不是动作 chunk 长度 |

**（c）事实数据究竟定住了什么**

```
E[ Δ_t(a', a^F) | H_t ] = μ(H_t, a') − μ(H_t, a^F)      ← 平均效应，可由事实数据识别

若用这个平均对比代替个体对比，误差为：
E[ ‖ S^F + μ(H,a') − μ(H,a^F) − S_{t+1}(a') ‖² | H_t ] = tr Var[ Δ_t(a', a^F) | H_t ]
```

命题 2（事实数据只定边缘、不定耦合）的构造：令 U~N(0,I)，模型 1 设 S(a)=S(a')=U，模型 2 设 S(a)=U、S(a')=−U。两者所有边缘都是 N(0,I)，平均效应相同，但个体效应一个是 0、一个是 −2U。因此「切换动作是否会伤害」这类量从事实拟合里读不出来。

**（d）配对优势的方差**

```
Var[ Â_M ] = ( σ²_a + σ²_ā − 2 ρ σ_a σ_ā ) / M
独立抽样    = ( σ²_a + σ²_ā ) / M
当 σ_a = σ_ā 时，配对方差 = 独立方差的 (1 − ρ) 倍
```

> 注意措辞：论文写的是「reduce estimator variance by the factor 1−ρ」，按上面的推导应读作**配对方差是独立方差的 (1−ρ) 倍**（也就是等精度时配对所需 rollout 数是独立的 (1−ρ) 倍，独立所需才是配对的 1/(1−ρ) 倍），而不是「方差减少了 1−ρ」。

**（e）CAP 目标**

```
A(a; ā, ξ) = J(ξ, a) − J(ξ, ā)
a* = argmax_a  E_ξ[A] − λ_u U(a)     s.t.  Pr_ξ[ A(a;ā,ξ) < −δ ] ≤ ε
事后：a^cf = argmax_a E_{ξ~q_s(·|τ^F)}[ A(a; a^F, ξ) ]，R(τ^F) ≥ 0
π 更新：L_π = −E[ exp( Ā(a;a^F)/η ) · log π_φ(a|H_t) ]   （无需 learned critic）
```

**（f）总损失**

```
L = L_dyn + β L_KL + λ_s L_sparse + λ_p L_persist + λ_d L_dist + λ_rt L_rt + λ_cf L_cf
L_sparse = ‖G^obj‖_1 + α ‖G^dim‖_1
L_dist   = KL[ sg{q_s(P_t|H_t,a^F,S^F)} ‖ q_f(P_t|H_t) ]      滤波器向平滑器蒸馏
L_rt     = 换动作→生成锚定反事实→再 abduction 回去→要求恢复事实后继
```

L_rt 是本文最巧的一块：**不用反事实标签**，只要求「情境不依赖你选了哪个动作」——如果平滑器把动作特有信息塞进 ξ_t，往返就恢复不出事实后继。

## 3. 带数字走一遍：玩具例子

> ⚠️ 以下数值全部是**假设**，只用于验算公式链路，不代表论文任何实验。

设场景有 3 个物体（红块、蓝块、远处绿块），为简化取 K=1。事实动作 a^F = 推红块，观测到后继 S^F = (红 0.10 m, 蓝 0.00 m, 绿 0.00 m)。

**第 1 步：abduction**。平滑器给出假设情境 ξ^F：红块 0.5 kg、蓝块 0.3 kg、摩擦 μ=0.2、转移噪声 U^F=(0,0,0)。

**第 2 步：换动作重生成图**。候选 a' = 侧抓红块。

| 边 | 事实图（推） | 反事实图（抓） |
|----|--------------|----------------|
| gripper→red | 激活 | 激活（接触类型不同） |
| red→blue | 激活（碰撞） | 未激活 |
| 任一边→green | 无 | 无 |

**第 3 步：锚定对比与掩码**。在 ξ^F 下展开：Φ(ξ,a')=(0.30, 0.00, 0.00)，Φ(ξ,a^F)=(0.10, 0.00, 0.00)。

```
Δ̂ = (0.20, 0.00, 0.00)
Ŝ^cf = S^F + Δ̂ = (0.30, 0.00, 0.00)
入度 n = (G^F + G^cf)ᵀ1 = (2, 1, 0)  ⇒ 绿块 n=0 ⇒ Δ̂_green 恒为 0（式 22 成立，验算通过）
```

**第 4 步：平均锚定的代价**。假设红块位移的个体效应在不同情境间波动，Var[Δ_red]=0.04 m²。若改用平均对比锚定，由式 24 得 MSE = 0.04 m²，即 RMS 误差 0.2 m —— 比红块名义位移 0.10 m 还大。这就是「平均效应用来排序会失真」的最小算例。

**第 5 步：配对方差**。设 M=8 次共享抽样，σ²_a=4，σ²_ā=4，ρ=0.9。

```
配对： Var = (4+4−2·0.9·4)/8 = 0.8/8 = 0.1
独立： Var = (4+4)/8 = 1.0
比值 = 0.1 = 1 − ρ                    （验算通过）
若要求 Var ≤ 0.1：配对需 M=8，独立需 M=80，差 10 倍
```

**第 6 步：伤害约束**。8 次共享抽样中有 1 次 A < −δ=−0.05，则 π_harm = 0.125 > ε=0.1，CAP 拒绝切换，保留 incumbent（A≡0 恒可行）。

**第 7 步：事后后悔**。若事实回报 J^F=0.2，而在同一 ξ^F 下最优候选序列回报 0.9，则 R=0.7>0，说明失败由动作选择造成；若事实动作在该情境下已不劣于任何候选（即所有候选相对事实动作的优势都不为正），则 R=0，说明没有候选能比事实动作更好；若所有候选都失败但事实动作仍是最差，则 R>0，说明动作选择仍有改进空间，不能据此断言「没有动作能救」并只更新物理后验。

## 4. 工程视角

| 项 | 情况 | 工程含义 |
|----|------|----------|
| 单次决策成本量级 | M 个共享情境 × H 步展开 × 候选序列数 | CAP 是 MPC 风格：执行首动作后重规划，预算按决策频率而非按帧分配 |
| 图计算 | 对象层 O(N_t²) 成对求值；因子层 O((N_t·K)²) | 稀疏门 + 掩码让「候选打分成本随动作触及的场景局部缩放」，但这是设计目标，论文未给实测延迟 |
| 上下文长度 | 由 H_t 决定，论文未规定具体窗口 | 不能把 H 步规划时域当记忆窗口；也不能把 K 当采样帧数 |
| 状态保持 | episode-persistent prior 保物理量（质量/摩擦/柔顺），U_t 每步重采样 | 重试时物理量继承、扰动不继承（式 34），这是「同一物体换一次扰动再试」的语义 |
| 数据通路 | 需克隆仿真器状态 + 匹配随机种子执行替代动作 | 真机上无对应能力，是落地最大阻塞 |
| 无 critic | 优势由耦合反事实 rollout 直接算，π_φ 用优势加权回归更新 | 省掉价值网络的训练稳定性问题，但每次更新要多跑 M×H 的展开 |

一个容易忽略的工程量：式 30 的传播掩码 d_h 是逐层递推的，只有被 flag 的行才重算消息；实现上这等价于一张随 horizon 增长的稀疏 mask，缓存参考轨迹的行就能省掉大半计算——但这依赖奖励是 object-additive 的，非加性奖励下 e_0 抵消不成立。

## 6. 能力与失败模式

**作者主张能做的：**

- 在同一物理情境下比较任意数量候选动作，并给出个体级伤害概率（式 31）。
- 精确区分「动作改变了哪些对象」与「动作碰不到的对象」：式 22 保证无入边对象的后继严格保持观测值，式 30 把它扩到 horizon。
- 无标签约束 abduction 的动作无关性（round-trip loss）。
- 无 learned critic 的优势加权策略学习，且每个执行过的转移为多个未执行动作提供监督信号。

**明确不能做 / 未验证的：**

- **不是 VLA**：无语言指令、无视觉-语言主干、无真实机器人实验。论文自己的定位也是「world model + planner」。
- **无任何数值结果**，因此无法判断相对 TD-MPC2 / CF-GPS / Counterfactual Quotient Models 的实际位置。
- **多步反事实的误差累积没有分析**：每步都重算门、权、对象集，长 horizon 下误差如何传播，论文只给了单步识别结论。
- **正性依赖**：确定性行为策略下，未被执行的替代动作没有数据支撑，式 6 即使成立也用不上。
- **未见机制类型**：作者自认需要额外适配或不确定性检测，即组合泛化只覆盖已知交互角色。

### 6.1 隐含假设

1. **动作只通过图生成器影响未来**（模块性）。真实接触里摩擦、形变、夹持力会与动作耦合，若这种耦合跨越了「图」这一层，反事实就不再是「只换动作方程」。
2. **物理量在 episode 内持续**。非平稳对象（液体、软体、磨损）会破坏 episode-persistent prior。
3. **行为策略的全部输入都在 H_t 里**。任何特权信息（力传感器、真值位姿）进入策略就破坏识别，论文用一组实验条件专门测这个边界，但没有给结果。
4. **仿真器可克隆 + 可配对随机种子**。这是数据协议的隐含前提，也是真机迁移的硬约束。
5. **图结构可由干预验证替代标签**。无图标签时只能做 held-out 干预、物体移除、非父节点干扰不变性这类行为级检验，不等于结构可识别。

## 7. 与相关工作对比

| 方法类别 | 代表 | 核心手段 | 与 WhatIf 的差异（作者主张） |
|----------|------|----------|------------------------------|
| 常规世界模型 | DreamerV3, TD-MPC2 | 序列模型 + critic 打分 | 各候选独立采样，无共享情境耦合；只给边缘律 |
| 因果/物体中心 WM | Causal World Models, FOCUS, FIOC-WM, Dyn-O, SPARTAN | 物体分解、稀疏局部图、上下文向量 | 图多为事实预测而学，不保证换动作后在同一情境下重生成 |
| 潜 DAG | CausalVAE plug-in | 固定维度稀疏 DAG + 无环约束 | 固定对象集，邻接参数不随对象进出迁移 |
| 反事实 RL | CF-GPS | abduction 外生噪声后替换策略 | 依赖正确的因果模拟器，无物体级机制 |
| 反事实表示 | Counterfactual Quotient Models | 分离动作相关分量、抵消共同模态 | 无物体级结构，不解释接触的产生与消失 |
| 混杂 MBRL | Gasse et al. | 处理行为策略带来的混杂 | 关注策略学习偏差，不是动作级反事实图 |

**面试 Tip**：被问「WhatIf 和 CF-GPS 差在哪」，一句话答——CF-GPS 在已知因果模拟器上替换策略，WhatIf 把动作变成一张随情境重生成的稀疏物体–因子图，让不同动作的未来在同一个被 abduction 的 ξ 下耦合；代价是要额外学 abduction 与稀疏结构，而且这篇目前还没有实验数字。

## 8. 精读建议

- **值得精读原文的人**：① 做 model-based 操作规划、想给现有策略加显式物理结构的同学；② 研究反事实/因果表示、关心识别条件的人（§3.2 与 Prop.2 是全文最硬的部分）；③ 准备把世界模型接进 CEM/MPPI 的工程同学（§3.4 与 §3.7）。
- **建议章节路径**：先读 §3.1–3.2 建立因果模型与识别条件 → 再看 §3.4 的图结构（最工程化、最容易复现）→ 然后 §3.5 锚定反事实与 Prop.2 → §3.7 CAP → §4 只看协议设计，不要期待数字 → §2 相关工作可跳读。
- **不值得精读的理由**：如果你只关心端到端 VLA 策略、需要已被验证的 benchmark 成绩、或不做带接触的操作任务，读摘要与 §1 即可；本文的贡献目前停留在形式化与设计层面。
