### 1.2 关键机制 (Key Mechanism)

PhyLatent 的核心设计哲学是：**全局非崩溃是起点，局部结构才是关键**。五条训练组件围绕三个崩溃模式展开：

- **物理不变性路径（SVIC）**：对输入做亮度/颜色扰动，强制增强后的表示与原始表示对齐。直觉：同一个物理状态，不管光照怎么变，潜表示应该不变。
- **物理可辨识性路径（PSG + FRA）**：用仿真器提供的物理状态（关节角度、物体位置等）做监督信号，同时通过投影头和动作查询模块对齐预测未来与观测未来。直觉：物理上不同的状态必须在潜空间可区分。
- **反事实动力学路径（CASC + LD）**：构造反事实动作序列（打乱 batch 内动作 + 噪声），强制不同动作产生的预测分支充分分离；同时对未来潜加噪声做去噪，正则化局部几何。直觉：不同动作应该产生不同的可预测结果。

⚡ **Eureka Moment**：全局分布正则化（SIGReg）防止的是"所有输入映射到同一个点"这种平凡解，但世界模型需要的是更精细的局部几何结构——相同物理状态要近、不同物理状态要远、不同动作的预测分支要可区分。这三条局部约束与全局正则化是互补而非替代关系。

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：

```
L_PhyLatent = L_pred + 0.09·L_SIGReg
            + λ_inv·L_inv       (物理不变性)
            + λ_state·L_state   (物理可辨识)
            + λ_align·(L_proj + L_act)  (未来对齐)
            + λ_sep·L_sep + λ_denoise·L_denoise  (反事实)
```

**目标**：在 JEPA 基线（预测损失 + 全局正则）之上，增加三条局部结构约束，使潜空间同时满足：(1) 外观不变性、(2) 物理可辨识性、(3) 反事实可区分性。

**核心方程分解**：

```
// 基线预测损失（与 LeWorldModel 共享）
L_pred = MSE(Z_hat, sg(Z_plus))

// 物理不变性：增强序列对齐
L_inv = d_N(Z_aug, sg(Z))
// d_N = 沿特征维度 L2 归一化后的均方距离

// 物理可辨识：状态 grounding（编码 + 预测共享状态头）
L_state = MSE(H_s(Z), S_bar) + MSE(H_s(Z_hat), S_bar[K+1:T])

// 未来对齐：投影头 + 动作查询
L_proj = d_N(phi(Z_hat), sg(phi(Z_plus)))
L_act  = d_N(Psi(Z_hat, C_ctx^a), sg(Psi(Z_plus, C_ctx^a)))
L_align = L_proj + L_act

// 反事实分离：动作差异驱动的 margin loss
L_sep = (1/|Ω|) Σ [m_{b,τ} - δ_{b,τ}^z]_+
// m = min(γ·δ^a, m_max)，仅保留动作差异 > median 的位置

// 潜去噪：正则化局部几何
L_denoise = MSE(epsilon_hat, epsilon)
// 输入：加噪目标未来 + 预测未来 + 动作上下文 + 噪声尺度
```

**变量说明**：

| 符号 | 含义 |
|------|------|
| Z, Z_hat | 编码序列 / 预测未来序列 |
| Z_aug | 外观增强后的编码序列 |
| S_bar | 标准化物理状态向量（仿真器提供） |
| H_s | 共享状态头（MLP） |
| phi | 共享投影头 |
| Psi | 动作查询模块（MHA，动作表示做 query） |
| d_N | L2 归一化后的均方距离 |
| sg(·) | stop-gradient（目标分支不反向传播） |
| γ, m_max | 分离 margin 的缩放系数和上限 |
| D_ω | 去噪头（接收噪声尺度 σ 作为条件） |

> 符号与本文保持一致。所有损失均为训练时优化目标，推理时仅保留编码器 E、投影头 P 和预测器 F_θ。

## 3. 带数字走一遍：玩具例子 (Worked Example)

假设一个简化的 2D 物理状态空间（物体位置 x ∈ [-1, 1]，速度 v ∈ [-1, 1]），JEPA 编码器输出 8 维潜表示。

**场景 1：物理不变性崩溃修复**

```
原始帧 o_t：物体在 x=0.3, v=0.1 → 编码 z_t = [0.12, -0.05, ..., 0.08]
增强帧 o_t^aug：同一帧 + 亮度偏移 → 编码 z_t^aug = [0.15, -0.03, ..., 0.10]

基线 LeWorldModel：
  d_nuis = ||z_t - z_t^aug||_2 = 0.05
  d_state = ||z_t - z_{t+Δ}||_2 = 0.03  (真实状态转移)
  r_inv = log10(0.05/0.03) = 0.22 > 0 → 崩溃！外观变化 > 状态转移

PhyLatent 修复后（SVIC 约束）：
  d_nuis = 0.012
  d_state = 0.03
  r_inv = log10(0.012/0.03) = -0.40 < 0 → 通过
```

**场景 2：反事实动力学崩溃修复**

```
同一状态 z_t，两个候选动作：
  动作 i（向左推）：真实未来 z_{t+k}^(i) = [-0.5, 0.2, ...]
  动作 j（向右推）：真实未来 z_{t+k}^(j) = [0.5, -0.1, ...]
  d_true = ||z_{t+k}^(i) - z_{t+k}^(j)||_2 = 1.2

基线 LeWorldModel 预测：
  z_hat^(i) = [-0.1, 0.05, ...]
  z_hat^(j) = [0.1, -0.03, ...]
  d_pred = 0.35 → r_cf = 0.35/1.2 = 0.29 < 0.5 → 崩溃！

PhyLatent 修复后（CASC 约束）：
  z_hat^(i) = [-0.45, 0.18, ...]
  z_hat^(j) = [0.48, -0.09, ...]
  d_pred = 1.05 → r_cf = 1.05/1.2 = 0.88 > 0.5 → 通过
```

**场景 3：MPC 规划中的连锁效应**

```
规划 horizon H=5，每步采样 20 个候选动作。

基线：由于反事实崩溃，20 个候选动作的预测未来过于接近，
     MPC 无法区分"推左"和"推右"，选到次优动作的概率高。
     → OGBench-Cube 成功率 70.0%

PhyLatent：CASC 强制不同动作的预测分支分离，
           MPC 能可靠比较候选动作的优劣。
           → OGBench-Cube 成功率 78.1%（+8.1%）
```

## 4. 工程视角 (Engineering View)

| 工程维度 | 分析 |
|----------|------|
| 训练开销 | 5 个额外损失项，但均为潜空间操作（非像素级），计算开销可控。去噪头 D_ω 是最重的额外模块（需要接收噪声尺度作为条件输入） |
| 推理开销 | **零**。所有附加头（H_s、ϕ、Ψ、D_ω）在推理时完全移除，编码器 E + 预测器 F_θ 与基线相同 |
| 内存占用 | 训练时需要存储增强序列、反事实动作序列、噪声样本，batch 内额外内存约 20-30% |
| 物理状态标注 | 依赖仿真器 API 提供结构化物理状态（关节角度、物体位姿等）。真实机器人部署需要额外的状态估计模块（如视觉里程计、力觉融合） |
| 超参敏感度 | 5 个 λ 权重（λ_inv, λ_state, λ_align, λ_sep, λ_denoise）+ γ 和 m_max。SIGReg 权重固定为 0.09（与基线一致） |
| 与 VLA 的集成点 | PhyLatent 训练的是世界模型的编码器+预测器，VLA 的策略网络可以直接接在训练好的编码器之上，无需修改 |

**工程含义**：PhyLatent 的核心价值在于"训练时多花 20-30% 的算力，推理时零代价换取更可靠的世界模型"。对于需要潜空间 MPC 的 VLA 系统（如基于 JEPA 的闭环控制），这是一个高性价比的改进。但对于纯前馈策略网络（如 ACT），PhyLatent 的改进可能只间接体现在更好的状态表征上。

## 6. 能力与失败模式 (Capabilities & Failure Modes)

**能做什么**：
- 显著提升 JEPA 世界模型的局部几何质量（三种崩溃率全面下降）
- 在需要潜空间 MPC 规划的任务上大幅提高成功率（Cube +8.1%，TwoRooms +17%）
- 推理时零开销——所有额外约束仅在训练时生效
- 与现有 LeWorldModel 架构完全兼容，无需修改网络结构

**不能做什么 / 局限**：
- **依赖物理状态标注**：PSG 需要仿真器提供精确的物理状态向量。真实机器人上没有"上帝视角"的物理状态，需要额外的状态估计模块
- **仅解决表示层**：PhyLatent 改进的是世界模型的潜表示，不直接改进策略网络。对于纯前馈 VLA（如 ACT），收益是间接的
- **仿真到真实的 gap**：所有实验在仿真器上完成，真实世界的传感器噪声、延迟、非结构化环境可能削弱效果
- **TwoRooms 大幅提升但 Reacher/PushT 持平**：可能暗示 PhyLatent 对"需要精细动作区分的导航类任务"收益更大，而对"精细操作类任务"收益有限

### 6.1 隐含假设 (Hidden Assumptions)

| 假设 | 说明 | 风险 |
|------|------|------|
| 物理状态可获取 | PSG 依赖仿真器 API 提供标准化物理状态 | 真实世界需要状态估计，可能引入额外误差 |
| 外观增强覆盖充分 | SVIC 仅使用亮度和颜色扰动 | 可能未覆盖纹理变化、遮挡、运动模糊等真实干扰 |
| 反事实动作构造合理 | CASC 通过 batch 内排列 + 噪声构造反事实 | 排列后的动作组合在物理上可能不合理（如速度突变） |
| 潜空间维度足够 | FRA 和 LD 假设潜空间有足够容量承载物理结构 | 低维潜空间可能无法同时满足全局正则和局部约束 |
