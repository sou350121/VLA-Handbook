## 1. 核心架构/方法总览 (Overview / Architecture)

### 1.1 系统对比概览 (System Component Comparison)

| 模块 | 传统视频 3DGS 管线 | Wanderland 方案 | 关键差异 |
|------|------------------|----------------|---------|
| 数据采集 | 单目/RGB 视频（YouTube、网络爬取） | MetaCam 手持多传感器（LiDAR+IMU+RGB） | 多模态 vs 单模态 |
| 位姿估计 | SfM (COLMAP) 或深度模型 (VGGT) | LIV-SLAM (LiDAR-Inertial-Visual) | metric-scale vs 非度量 |
| 几何重建 | 3DGS opacity 场提取 | 全局一致点云 → mesh 提取 | 碎片化 vs 水密 |
| 3DGS 初始化 | 随机或 SfM 稀疏点云 | 密度点云 + 深度图 | 收敛速度/质量 |
| 物理交互 | 不可靠/无 | 可靠 collision mesh | 可 benchmark vs 仅训练 |
| 适用场景 | 训练为主 | 训练 + benchmark | 核心差异 |

### 1.2 关键机制 (Key Mechanism)

**为什么这样设计？**

1. **多传感器采集**: RGB-D 传感器户外失效（阳光干扰、距离有限），三脚架方法效率低。MetaCam 类手持设备平衡了效率与精度。

2. **LIV-SLAM 重建**: 纯视觉 SLAM 缺乏绝对尺度、长轨迹漂移；纯 LiDAR SLAM 缺乏纹理。融合方案兼顾 metric 精度与全局一致性。

3. **点云初始化 3DGS**: 直接用优化后的密度点云初始化高斯，避免随机初始化收敛慢、易陷入局部最优的问题。

4. **并行 mesh 提取**: 从同一全局点云提取 collision mesh，确保几何表示与视觉表示一致（避免 vid2sim 中 opacity 提取 mesh 的碎片化）。

⚡ **Eureka Moment**: 视觉逼真 ≠ 几何可信——具身 AI benchmark 需要的是 metric-scale 几何 grounding，而不仅是神经渲染质量。

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）:

```
几何误差 = |重建点云 - 真实几何| → 导航评估误差 ∝ 几何误差
```

**目标**: 最小化 sim-to-real 几何差距，使仿真中训练的导航策略能可靠迁移到真实世界。

**变量说明**:
- 重建点云：LIV-SLAM 输出的全局一致 metric 点云
- 真实几何：物理世界的实际几何结构（未知，用高精度扫描近似）
- 导航评估误差：策略在仿真中成功率 vs 真实世界成功率的差距

**直觉**: 如果仿真环境的几何（墙壁位置、障碍物高度、通道宽度）与真实世界偏差超过机器人尺寸的量级，任何导航策略的评估结果都不可信。

> 符号说明：本文未给出显式损失函数，核心贡献是 pipeline 设计而非算法创新。

## 3. 带数字走一遍：玩具例子 (Worked Example)

假设一个简单场景：机器人在室内走廊导航，需要从 A 点走到 B 点，走廊宽 1.5 米，中间有一个 0.3 米宽的柱子。

**视频 3DGS 管线的问题**:
- SfM 位姿估计误差：~5-10 cm（非 metric，尺度漂移）
- 深度估计误差：~10-20 cm（纯视觉推断）
- 结果：柱子位置可能偏移 15 cm，宽度估计为 0.2-0.4 米
- 导航策略在仿真中学会"贴右墙走"，但真实世界中柱子位置不同 → 碰撞

**Wanderland 方案**:
- LIV-SLAM 位姿误差：~1-2 cm（LiDAR metric 尺度）
- 点云密度：>1000 点/m²（手持近距离扫描）
- 结果：柱子位置误差 <3 cm，宽度估计 0.29-0.31 米
- 导航策略评估可靠，sim-to-real 迁移成功率高

**关键阈值**: 对于典型桌面/移动机器人（尺寸 0.3-0.5 米），几何误差需 <5 cm 才能可靠评估避障能力。Wanderland 声称达到此阈值，视频 3DGS 方法无法达到。

## 6. 能力与失败模式 (Capabilities & Failure Modes)

### 6.1 能做什么

| 能力 | 场景 | 原因 |
|------|------|------|
| 可靠导航 benchmark | 室内 + 室外混合环境 | metric-scale 几何 + 物理交互 |
| 3D 重建方法对比 | 多传感器 vs 纯视觉 | 提供原始传感器数据 |
| 新视角合成评估 | 有限外推视角 | 高质量 3DGS 模型 |
| 策略迁移研究 | sim-to-real 迁移 | 低 sim-to-real 几何差距 |

### 6.2 不能做什么

| 限制 | 原因 | 影响 |
|------|------|------|
| 大规模场景生成 | 依赖人工采集 | 无法像视频挖掘那样扩展到 1000+ 场景 |
| 动态场景处理 | LIV-SLAM 假设静态 | 行人/车辆移动会导致重建伪影 |
| 极端光照条件 | LiDAR/RGB 都有局限 | 夜间/强光下质量下降 |
| 全自动化 pipeline | 需要人工采集 + 后处理 | 不适合众包/社区贡献模式 |

### 6.3 隐含假设 (Hidden Assumptions)

1. **静态场景假设**: LIV-SLAM 假设环境静态，动态物体（行人、车辆）会导致重建错误。

2. **手持采集可行性**: 假设研究者可以合法/安全地在目标场景中手持设备行走——某些场景（私人建筑、危险区域）不可行。

3. **设备可及性**: 假设研究团队能获取 MetaCam 或类似设备（~$5000-10000）——对小团队/发展中国家是门槛。

4. **几何精度 = 评估可靠性**: 假设几何精度是导航评估可靠性的主要瓶颈——但策略架构、奖励设计等也可能影响迁移。
