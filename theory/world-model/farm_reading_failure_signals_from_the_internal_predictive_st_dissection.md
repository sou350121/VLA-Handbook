## 1. 核心架構/方法總覽 (Overview / Architecture)

FARM 的整體思路是「**表徵學習與下游監督分離**」：骨幹（V-JEPA2 編碼器 + VLA-JEPA 預測器）全程凍結，只訓練一個讀出頭。這使實驗結果直接檢驗「失敗信息是否**已經**存在於預訓練預測表徵中」，而不是檢驗一個新訓練的動力學模型有多大容量。

### 1.1 系統對比概覽 (System Component Comparison)

| 模組 | 輸入 | 輸出 | 是否訓練 | 角色 / 關鍵點 |
|------|------|------|----------|----------------|
| V-JEPA2 編碼器 | 觀測歷史 x_{i,≤t} | world-state tokens | 凍結 | 把歷史映射為世界狀態 token |
| VLA-JEPA 預測器（第 12 層塊，正規化前） | world-state tokens + 任務條件 latent-action tokens | H_t^WM ∈ R^{768×1024} | 凍結 | 因果、動作條件的預測計算 |
| 動作條件 token 剔除 | — | 只保留 768 個世界狀態 token | 凍結 | 抽出純預測狀態 |
| 共享投影 + LayerNorm + GELU | h_j^WM ∈ R^{1024} | u_j ∈ R^{32} | **訓練** | 保參數量不隨 token 數膨脹 |
| 注意力池化 | {u_j} | r ∈ R^{32} | **訓練** | 依內容選擇哪些 token 重要 |
| 兩層 MLP + sigmoid | r | s_t ∈ [0,1] | **訓練** | 逐步失敗分數 |
| 因果風險聚合 | {s_τ}, τ≤t | q_t = max s_τ | 無參 | 只依賴已觀測分數 |

### 1.2 關鍵機制 (Key Mechanism)

- **為什麼凍結？** 若同時訓練骨幹，就無法區分「失敗信息是預訓練表徵自帶的」還是「被失敗標籤訓練出來的」。凍結把骨幹變成一個**固定特徵提取器**，讓讀出頭只做「選擇與組合」。
- **為什麼要 32 維瓶頸？** 瓶頸刻意做小（z^F ∈ R^{32}），強迫讀出頭**只能選取既有信息**，不能重建一個新的預測模型。
- **為什麼是注意力池化而非平均池化？** 768 個 token 對不同執行狀態的重要性不同；注意力允許讀出頭對不同狀態強調不同預測 token。
- **為什麼是 max 而非 mean 聚合？** 短暫但強烈的失敗證據應被保留；max 只需存一個標量。

⚡ **Eureka Moment**：**失敗信息不需要被「學」出來——它已經被預訓練的預測目標編碼進了世界模型的內部狀態，一個小讀出頭只要把它「讀」出來即可。**

### 1.3 信息流/架構圖 (Flow / Diagram)

```
觀測歷史 x_{i,≤t}

   ▼
[V-JEPA2 編碼器]  (凍結)

   ▼
[VLA-JEPA 預測器 第12層塊]  (凍結)  ← 任務條件 + latent-action tokens

   ├── 剔除 action-conditioning tokens
```

## 2. 數學核心 (Math Core)

📌 **Napkin Formula**（一行抓住本質）：

```
s_t = σ( w_o^T · MLP( Σ_j softmax_j(a^T u_j)·u_j ) ),   u_j = GELU(LN(Wp·h_j^WM))
q_t = max_{τ≤t} s_τ
```

**目標**：在凍結的 WM state 上訓練一個讀出頭，輸出逐步失敗分數 s_t，並以因果方式聚合成軌跡風險 q_t。

**骨幹與讀出頭的分離**（梯度只進讀出頭）：

```
H_{i,t}^WM = sg[ F_φ(x_{i,≤t}) ]      # φ 凍結，sg = stop-gradient
s_{i,t}    = G_θ(H_{i,t}^WM) ∈ [0,1]  # θ 唯一可訓練參數
```

**讀出頭三連**（抑制下標）：

```
u_j = GELU( LN( Wp·h_j^WM + bp ) )     # 共享投影: 1024 → 32
α_j = softmax_j( a^T u_j ),  r = Σ_j α_j·u_j
z^F = GELU( Wf·r + bf ),  s = σ( w_o^T·z^F + bo )
```

**訓練損失**（任務均衡的二元交叉熵）：

```
L_FARM(θ) = E_{k,i,t}[ ℓ_BCE(s_{i,t}, y_i) ]
ℓ_BCE(s,y) = -y·log s - (1-y)·log(1-s)
採樣: k~Unif(K_tr) → i~Unif(D_k) → t~Unif(T_i)   # 分層均勻採樣，任務等權
```

**因果風險**：

```
q_{i,t} = max_{τ≤t} s_{i,τ} = max(q_{i,t-1}, s_{i,t})
```

| 符號 | 含義 |
|------|------|
| H_{i,t}^WM | 凍結 WM state，R^{768×1024}（768 個保留的世界狀態 token，1024 為預測器內部隱藏寬度）|
| F_φ | 預訓練 WM-state 提取器；φ 全程凍結 |
| G_θ | FARM 讀出頭；θ 為唯一可優化參數 |
| Wp ∈ R^{32×1024}, a ∈ R^{32} | 共享投影矩陣、注意力向量 |
| s_{i,t} | 第 i 條軌跡第 t 步的逐步失敗分數 |
| q_{i,t} | 因果軌跡風險（僅聚合 τ≤t 的分數）|
| y_i ∈ {0,1} | 軌跡結局標籤，1 = Failure |

> 符號與原文保持一致：原文用 H_t^WM 記號，本文統一為 H_{i,t}^WM。

**直覺**：分層採樣讓每個任務等權，避免長 rollout 因為「步數多」而主導損失；32 維瓶頸 + 凍結骨幹共同保證讀出頭「只能讀、不能造」。

## 3. 帶數字走一遍：玩具例子 (Worked Example)

假設一條 5 步軌跡，每一步的 WM state 被壓成 3 個「代表 token」的投影向量（真實是 768 個，這裡只為走通流程）。注意力權重 α 由 a^T u_j 過 softmax 得到（數值假設）。

| 步 t | 投影 u_1,u_2,u_3（示意） | 注意力 α | 池化 r | MLP→sigmoid：s_t | q_t = max |
|------|--------------------------|----------|--------|------------------|-----------|
| 1 | 近零向量 | (0.33,0.34,0.33) | ≈0 | 0.12 | 0.12 |
| 2 | 略偏 | (0.5,0.3,0.2) | 小 | 0.18 | 0.18 |
| 3 | 出現異常模式 | (0.7,0.2,0.1) | 增大 | 0.31 | 0.31 |
| 4 | 抓取偏移 | (0.85,0.1,0.05) | 大 | 0.64 | 0.64 |
| 5 | 物體滑落 | (0.9,0.08,0.02) | 最大 | 0.88 | **0.88** |

- 早期 s_t 低 → 風險 q_t 維持低位，系統繼續執行。
- 第 4 步起 s_t 抬升，q_t 因 **max** 而不會「回落」——即便第 5 步前後有局部抖動，已捕捉的失敗證據仍被保留。
- 若部署閾值設在 q_t > 0.5，則此軌跡在第 4 步即觸發接管/恢復/重置信號。

這個閉環的關鍵：**q_t 只依賴 ≤t 的分數**，因此可在每個 replanning step 在線更新，不需看到未來 rollout。真實實驗中，僅用 25% 因果歷史時 Pooled AUROC/AUPRC 已達 75.07±0.73 / 80.75±0.16；到 75% 歷史時達 81.63±0.40 / 85.53±0.65，僅比全歷史低 1.78/1.27 個點（論文 Fig. 5）。

## 5. 數據與評測 (Data & Eval)

**仿真基準**：500 條軌跡（246 成功 / 254 失敗），來自 10 個 LIBERO 操作任務，每任務 50 條。作者把一個執行策略幾乎從不失敗的 LIBERO-10 任務，替換為一個 LIBERO-Goal 抽屜放置任務 → 9 個 LIBERO-10 + 1 個 LIBERO-Goal。

- **角色劃分**：7 個源/Seen 任務（S1–S7）+ 3 個 strict-Unseen（U1–U3），在訓練讀出頭前即固定。
- **固定切分**：每個源任務切成 30 TRAIN / 20 SEEN_EVAL → 210 訓練 + 140 Seen 評估軌跡。U1–U3 完全排除在源訓練外，貢獻 150 條 strict-Unseen 軌跡。
- **共同視野**：每個任務只取所有軌跡共有的前 T_k 個 replanning step，防止「軌跡長度 / 終止時間」成為分類捷徑。
- **表示與因果分析**：使用全部 350 條源任務軌跡，採 trajectory-grouped 5-fold OOF（每 fold 留出每任務 10 條共 70 條，重複 seeds 0/1/2）。

**主要結果**：
- 凍結 WM state 在全 7 個任務上一致可判失敗，**Pooled AUROC/AUPRC = 85.68 / 88.59**（Table IIa）。
- 訓練任務覆蓋度（FARM-Expanded，446 軌跡）：Macro AUROC/AUPRC 從 1 任務的 62.55/56.78 升到 7 任務的 85.43/85.67；Pooled 從 61.71/52.42 升到 89.73/88.06。
- 15 個 matched baseline 中，FARM 在 4 個 Seen 指標全面領先；相對 SAFE-MLP 提升 **5.42/4.88** Macro AUROC/AUPRC 點（Table III）。
- 真實機器人 4 個族群：PIPER X/π*₀.₆（497 軌跡）、PIPER X/VLA-JEPA（100）、SO-101/Eval-RL（70）、Franka/π₀-FAST-DROID（SAFE 公開 13 任務、778 rollouts）。
- strict-Unseen（zero-shot）由 **STAC-Single** 排名第一，FARM 仍高於 SAFE-MLP/LSTM；在 Adapt-35 監督下，FARM 反超 STAC-Single。

## 6. 能力與失敗模式 (Capabilities & Failure Modes)

**能做**：
- 對新策略/新平台/新視覺域，用**固定讀出頭**做 zero-shot 監控（FARM-Expanded 在全部 4 個 zero-shot 設定優於 FARM-Core）。
- 有少量目標標註時，**只調讀出頭**（33,985 參數）吸收殘餘域偏移：Franka 全族群 5-fold OOF Adaptation 達 75.78±1.08 AUROC / 74.31±0.96 AUPRC。
- 從**部分因果歷史**判失敗（25% 歷史即有 75.07 AUROC）。
- 以近零成本在線更新 q_t，用閾值觸發 continue / intervene / recover / reset。

**不能做 / 受限**：
- **不生成也不改進動作**——FARM 是監控器，不是策略；干預/恢復策略需另行設計（作者列為未來工作）。
- **需要內部狀態訪問權**：若世界模型不暴露 predictor 內部張量（本文取第 12 層塊、正規化前），此方法不可用。
- **需要標註結局**：訓練與適配都要求成功/失敗標籤。
- **零-shot 遷移不均勻**：strict-Unseen 任務明顯比 matched Seen 難；zero-shot 表現還取決於**源讀出頭如何訓練**（Core vs Expanded 的差距證明）。
- **只在桌面操作驗證**：LIBERO + PIPER X / SO-101 / Franka 桌面抓取與放置，未驗證移動/雙臂/人形。

### 6.1 隱含假設 (Hidden Assumptions)

1. **「失敗信息可判別」假設**：默認同一軌跡內所有 WM state 都繼承同一個軌跡級標籤（失敗是全軌一致的屬性）——但真實中有些軌跡「部分成功、末段失敗」，步級標籤與軌跡級標籤不一致的影響未被檢驗。
2. **「內部狀態取樣位置最優」假設**：只系統比較了若干預定義的提取位置，未窮舉所有層；失敗信息在層間如何分布被列為 future work。
3. **「結局標籤可靠」假設**：依賴終止幀分數與人工/自動成敗判定的一致性。
4. **「延遲可忽略」假設**：0.2256 ms 只測讀出頭；端到端延遲取決於骨幹世界模型推理，作者明確排除在外。

## 7. 與相關工作對比 (Comparison)

- **建議章節路徑**：先讀 §III-C（讀出頭設計，理解 32 維瓶頸與注意力池化的用意）→ 再看 §IV-B 與 §IV-E（表示證據 + 因果/延遲）→ 可跳 §IV-A3（15 個 baseline 的細節枚舉，除非你要復現對比）。
- **不值得精讀的理由**：如果你不做機器人學習、或已熟悉 SAFE 式「凍結特徵 + 輕量讀出」範式，讀摘要 + §III 足夠——本文的貢獻在於**換了表徵來源（世界模型內部預測狀態）**並做了充分的跨平台驗證，而非提出新的學習算法。
