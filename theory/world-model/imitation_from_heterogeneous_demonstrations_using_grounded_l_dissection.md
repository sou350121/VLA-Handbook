## 1. 核心架构/方法总览 (Overview / Architecture)

### 1.1 系统对比概览 (System Component Comparison)

GLAM 是一个两阶段管线，核心创新在第一阶段的世界模型设计。

| 组件 | 输入 | 输出 | 训练数据 | 关键特性 |
|------|------|------|----------|----------|
| **异构 IDM** ($q_\varphi$) | 帧过渡 $(o_t, o_{t+1})$ | 潜在动作 z_t | $D_{\text{tar}} \cup D_{\text{aux}}$ | 源不变——同一网络处理所有来源 |
| **目标动作编码器** $(q_\eta)$ | (s_t, a_t) 目标状态-动作对 | 潜在动作 z_t | D_tar 仅 | 注入可执行动作语义 |
| **共享前向动力学** $(p_\theta)$ | (x_t, z_t) 或 (s_t, z_t) | 下一状态预测 | $D_{\text{tar}} \cup D_{\text{aux}}$ | 两个生成模型共享，物理锚定 |
| **观测编码器** $(q_\psi)$ | 观测 o_t (RGB 或掩码) | 潜在状态 x_t | $D_{\text{tar}} \cup D_{\text{aux}}$ | Dreamer 风格图像编码 |
| **动作解码器** $(p_\theta)$ | 潜在动作 z_t | 可执行动作 a_t | D_tar 仅 | 将潜在动作映射回目标空间 |
| **下游 BC 策略** $(\pi_\omega)$ | 观测 + 本体状态 c_t | 潜在动作块 $z_{t:t+H}$ | $D_{\text{tar}} \cup D_{\text{aux}}$ | 基于 MIP 回归策略 |

### 1.2 关键机制 (Key Mechanism)

**为什么用两个生成模型？**

单一世界模型（如 Dreamer）从观测过渡推断潜在动作，但这些动作缺乏"可执行性"——它们只是帧间变化的统计摘要，不保证能映射回目标机器人的实际控制空间。GLAM 引入第二个生成模型，利用目标域中可用的动作标签 $a_t$，通过动作编码器 $q_\eta(s_t, a_t)$ 将可执行动作语义注入潜在空间。

**非对称 KL 对齐是核心设计**

两个推断通路（IDM vs 动作编码器）通过以下约束桥接：

```
C_KL = E[ D_KL( q_φ(z_t | x_t, x_{t+1}) || sg[q_η(z_t | s_t, a_t)] ) ]
```

关键在 `sg[·]`（stop-gradient）：KL 散度的梯度只流向 IDM 侧，动作编码器侧冻结。这意味着 IDM 学习模仿动作编码器的分布（吸收可执行语义），但动作编码器不被 IDM 的模糊信号污染。作者称之为" deliberate asymmetry"——动作编码器携带特权信息（目标动作标签），是更可靠的锚点。

⚡ **Eureka Moment**: 动作表示应该基于"它对环境的实际影响"来定义，而不是基于它来自哪个机器人——世界模型的物理预测（前向动力学）就是那个跨源的公共监督信号。

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：
```
L = -J_H(D) - J_T(D_tar) + λ·C_KL(IDM ||_sg ActionEncoder)
```
两个 ELBO（异构 + 目标）最大化生成似然，一个非对称 KL 约束将两个推断通路绑在一起。

### 2.1 异构生成模型 ELBO (J_H)

目标：从纯观测数据中推断潜在动作，同时能预测未来观测。

```
J_H = E[ Σ_t log p_ψ(o_t | x_t)           // 观测重建
         - D_KL(q_ψ(x_{t+1}|o_{t+1}) || p_θ(x_{t+1}|x_t, z_t))  // 动力学一致性
         - D_KL(q_φ(z_t | x_t, x_{t+1}) || p(z_t))              // 动作先验
         - D_KL(q_ψ(x_1 | o_1) || p(x_1)) ]                     // 状态先验
```

- **p(z_t) = N(0, I)**：标准正态先验
- **$q_\phi$ 是 IDM**：从连续两帧的潜在状态过渡推断动作——不依赖动作标签，因此源不变
- **共享 $p_\theta$**：前向动力学在异构模型和目标模型之间共享，是物理锚定的关键

### 2.2 目标生成模型 ELBO (J_T)

目标：利用目标域的动作标签，将潜在空间锚定到可执行动作。

```
J_T = E[ Σ_t log p_θ(s_{t+1} | s_t, z_t)  // 状态转移预测
         + log p_θ(a_t | z_t)              // 动作重建（可解码性保证）
         - D_KL(q_η(z_t | s_t, a_t) || p(z_t)) ]  // 动作编码先验
```

- **log p_θ(a_t | z_t)** 是关键：强制潜在动作包含足够的信息来重建原始动作
- 仅作用于目标域——辅助数据没有动作标签

### 2.3 非对称 KL 对齐 (C_KL)

```
C_KL = E[ D_KL( q_φ(z_t | x_t, x_{t+1}) || sg[q_η(z_t | s_t, a_t)] ) ]
```

- IDM 分布向动作编码器分布靠拢
- `sg[·]` 阻止梯度回传动作编码器
- 只在目标数据 D_tar 上计算（动作编码器需要动作标签）

### 2.4 下游 BC 损失 $(L_\pi)$

```
L_π = E_{τ~D} [ ‖z_hat_{t:t+H} - z_t‖² ]     // 潜在动作回归（全数据）
      + E_{τ~D_tar} [ ‖a_hat_{t:t+H} - a_t‖² ]  // 真实动作回归（目标数据）
```

第一项让策略从所有数据（包括无标签辅助数据）学习；第二项确保在目标域上的动作精度。

> 符号说明：
> - o_t: 观测（RGB 图像 + 末端执行器位姿）
> - s_t: 本体状态（关节角度等）
> - a_t: 机器人动作
> - z_t: 潜在动作（d 维连续向量）
> - x_t: 潜在状态（从观测编码）
> - D_tar: 目标机器人带标签数据
> - D_aux: 辅助数据（无动作标签）

## 3. 带数字走一遍：玩具例子 (Worked Example)

假设一个简化的 2D 推块任务：

**场景设定**：
- 目标机器人 Kinova：7-DoF 臂，动作空间 7 维（关节速度）
- 辅助数据 UMI：浮动手持夹爪，无关节动作标签，只有 RGB 帧

**Step 1 — IDM 推断**：
给定辅助数据中一帧过渡 $o_t \to o_{t+1}$（块从位置 $(0,0)$ 移到 $(0.1, 0)$）：
- 观测编码：$q_\psi(o_t) \to x_t$, $q_\psi(o_{t+1}) \to x_{t+1}$
- IDM 推断：q_φ(z_t | x_t, x_{t+1}) → N(μ=[0.3, 0.0, ...], σ=[0.05, ...])
- 潜在动作 $z_t \approx [0.3, 0.0, \dots]$ 编码了"向右推"这个语义

**Step 2 — 动作编码器对齐**：
同一过渡在目标数据中（Kinova 执行了 a_t = [0.1, -0.05, 0.2, ...]）：
- 动作编码：q_η(z_t | s_t, a_t) → N(μ'=[0.35, 0.02, ...], σ')
- C_KL 计算：D_KL(N(μ,σ) || sg[N(μ',σ')]) → 梯度推动 IDM 的 μ 向 μ' 靠拢
- 结果：IDM 学会了"向右推"在潜在空间中的位置，即使它从未见过 Kinova 的动作

**Step 3 — 跨源解码**：
辅助数据的新 episode 中，IDM 推断出 $z_t \approx [0.3, 0.0, \dots]$：
- 动作解码器 p_θ(a_t | z_t)（只在 Kinova 数据上训练）输出 a_t ≈ [0.12, -0.04, 0.18, ...]
- 这个动作可以在 Kinova 上直接执行——尽管 z_t 是从 UMI 视频推断的

**Step 4 — BC 策略训练**：
- 用 z_t 重标注所有 500 条轨迹（100 Kinova + 400 UMI）
- BC 策略学习 $\pi_\omega(o_t) \to z_{t:t+H}$，在混合数据上回归
- 推理时：看到新场景 $\to$ 预测潜在动作块 $\to$ 解码为可执行动作

## 6. 能力与失败模式 (Capabilities & Failure Modes)

### 6.1 能做什么

| 能力 | 证据 | 条件 |
|------|------|------|
| 跨 embodiment 迁移 | UMI $\to$ Kinova 解码成功（Figure 2） | 两种 embodiment 产生相似环境过渡 |
| Sim2Real 迁移 | Kinova-sim → Kinova-real 解码成功 | 仿真与真实的视觉域差距不太大 |
| 利用无标签数据 | 400 条 UMI 无标签轨迹提升性能 | 辅助数据覆盖目标任务的物理动态 |
| 难任务突破 | Stack-Three 从 $\leq 4\%$ → $72.7\%$ | 需要辅助数据包含双臂协调动态 |

### 6.2 不能做什么（失败模式）

| 失败模式 | 原因 | 论文证据 |
|----------|------|----------|
| 辅助数据与目标任务物理动态不匹配 | IDM 学到的是"错误"的动作表示 | 未测试（假设） |
| 辅助数据视觉域差距过大 | 观测编码器 $q_\psi$ 无法对齐不同视觉域 | 仅测试 sim UMI → real Kinova，差距有限 |
| 纯视觉系统（无本体状态） | BC 策略需要 s_t 拼接；目标模型需要 s_t | 论文所有实验都有本体状态 |
| 大规模泛化 | 仅 5 个桌面操作任务 | 未测试移动机器人、人形、长序列任务 |

### 6.3 隐含假设 (Hidden Assumptions)

1. **辅助数据覆盖目标任务的物理动态**：IDM 只能从辅助数据中学到"已见过的"环境过渡模式。如果辅助数据中没有双臂协调的样本，IDM 无法泛化到双臂任务。论文在 Stack-Three 上成功可能是因为模拟 UMI 数据中包含了双臂协调的过渡。

2. **观测编码器的域不变性**：$q_\psi$ 将不同来源的观测编码到同一个潜在状态空间。这假设不同 embodiment 的视觉输入在 DINOv2 特征空间中足够相似——对于真实人类视频可能不成立。

3. **动作空间连续性**：潜在动作 z_t 是连续变量，假设不同 embodiment 的动作空间可以通过连续映射对齐。对于离散动作空间（如 gripper open/close），可能需要额外处理。

4. **KL 对齐的充分性**：非对称 KL 假设动作编码器的分布是 IDM 的"上界"。如果动作编码器本身因目标数据少而估计不准，IDM 可能学到错误的对齐。

5. **冻结 GLAM 不影响策略性能**：Stage 2 中 GLAM 冻结，重标注的 z_t 是固定的。如果 GLAM 的某些 z_t 推断有偏差，这些偏差会作为"脏标签"传递给 BC 策略，且无法通过策略训练纠正。

## 7. 与相关工作对比 (Comparison)

| 方法 | 关注点 | 架构 | 训练方式 | 跨源 | 需大规模预训练 |
|------|--------|------|----------|------|----------------|
| **MIP** | 单域 BC | 回归策略 | 仅 D_tar | ❌ | ❌ |
| **CLAM** | 单 embodiment 潜在动作 | IDM + FDM + 动作解码器 | 仅 D_tar | ❌ | ❌ |
| **LAPA** | 离散潜在动作码本 | VQ-VAE + IDM + FDM | $D_{\text{tar}} \cup D_{\text{aux}}$ | ✅ | ✅ (VLM finetune) |
| **Sim-Real Co-training** | sim/real 特征对齐 | OT loss + DTW 采样 | 混合数据 | ✅ (sim/real) | ❌ |
| **GLAM** | 异构数据统一潜在空间 | 双生成模型 + 非对称 KL | $D_{\text{tar}} \cup D_{\text{aux}}$ | ✅ (任意源) | ❌ |

**GLAM 的三处差异化**（论文 §2）：
1. 单一 IDM 跨所有数据源训练 → 源不变潜在空间（vs CLAM 单 embodiment）
2. 目标侧动作编码器 + 非对称 KL → 注入可执行语义（vs LAPA 后验 grounding）
3. 冻结世界模型作为潜在动作锚点 → 无需大规模预训练（vs LAPA 需 VLM finetune）

💡 **面试 Tip**: 当被问到"GLAM 和 CLAM 的核心区别是什么？"——回答："CLAM 是单 embodiment 的潜在动作模型，它的 IDM 只在目标数据上训练，无法处理无标签的异构数据。GLAM 把 IDM 扩展到跨所有数据源共享，然后用目标域的动作编码器通过非对称 KL 把可执行语义注入 IDM 空间——核心是把跨源对齐从手工工程变成了表示学习。"
