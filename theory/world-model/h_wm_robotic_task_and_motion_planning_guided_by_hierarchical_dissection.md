## 1. 核心架构/方法总览 (Overview / Architecture)

### 1.1 系统对比概览 (System Component Comparison)

| 模块 | 输入 | 输出 | 频率 | 训练/推理 |
|------|------|------|------|-----------|
| 逻辑世界模型 (M_L) | 当前逻辑状态 X_m, 观测 obs_m | 候选动作 $a_{m+1}$, 下一逻辑状态 $X_{m+1}$ | 每子任务 1 次 (低频) | LoRA 微调 Qwen3-4B-Instruct |
| 视觉世界模型 | $obs_m$, $a_{m+1}$, $X_{m+1}$, 关节配置 $q_m$ | 潜视觉子目标特征 $f_{\text{pred}}^{m+1}$ | 每子任务 1 次 (低频) | PaliGemma 初始化 + 2 层 FC |
| 子任务完成预测器 | $obs_t$, $a_{m+1}$ | 完成信号 (binary) | 每控制步 1 次 (高频) | 基于 understanding expert + CLS token |
| Guided VLA | $obs_t$, $a_{m+1}$, $f_{\text{pred}}^{m+1}$, $q_t$ | 动作块 $\alpha^{t:t+k}$ | 每控制步 1 次 (高频) | PaliGemma 初始化 + cross-attention |

### 1.2 关键机制 (Key Mechanism)

**为什么这样设计？**

1. **分层时序解耦**：世界模型在子任务级别运行（低频），VLA 在控制步级别运行（高频）。这样避免了每帧都跑世界模型的开销，同时保证子任务内部有稳定的视觉目标指导。

2. **逻辑 - 视觉对齐**：视觉世界模型的预测不是无约束的图像生成，而是被逻辑状态转移严格约束。给定 $(\text{obs}_m, a_{m+1}, X_{m+1})$，视觉模型只预测该子任务结束时的视觉特征，避免了迭代生成中的误差累积。

3. **双向信息流限制**：VLA 的 action expert 可以 attend 到 understanding 和 goal expert，但反向信息流被显式禁止。这保持了层次结构的稳定性，防止低层噪声污染高层预测。

⚡ **Eureka Moment**：H-WM 的核心洞见是——**长视野鲁棒性来自符号，可执行性来自视觉；两者必须联合预测而非串联**。现有方法要么先规划再执行（符号→视觉，误差无法反馈），要么纯视觉预测（无符号约束，长视野崩溃）。H-WM 让逻辑层和视觉层在同一框架内互相约束：逻辑层告诉视觉层"要到什么状态"，视觉层告诉逻辑层"这个状态看起来什么样"。

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：

```
H-WM 联合优化：L = L_logic(ML) + L_visual(MV) + L_policy(π)
其中 L_visual 使用 Sliced Wasserstein Loss 对齐预测特征与目标特征分布
```

**目标**：学习一个分层世界模型，能够同时预测逻辑状态转移和对应的视觉结果，并用这些预测指导 VLA 策略。

**公式分解**：

```
1. 逻辑状态转移（PDDL 风格）:
   X^{m+1} = (X^m \ Del(a)) ∪ Add(a)
   
   其中 a = ⟨Pre(a), Add(a), Del(a)⟩ 是动作 schema
   Pre(a) ⊆ X^m 是前置条件

2. 视觉特征预测:
   f_pred^{m+1} = MV(obs_m, a_{m+1}, X_{m+1}, q_m)
   
   训练目标：min E[d_SW(f_pred^{m+1}, f_goal^{m+1})]
   d_SW = Sliced Wasserstein Distance

3. VLA 策略:
   α^{t:t+k} = π(obs_t, a_{m+1}, f_pred^{m+1}, q_t)
   
   使用 flow-matching objective 训练
```

**变量说明**：

| 符号 | 含义 | 来源 |
|------|------|------|
| $X^m$ | 子任务 m 的逻辑状态（ground atoms 集合） | PDDL 符号化 |
| $a_{m+1}$ | 子任务 m+1 的逻辑动作 | 逻辑 WM 预测 |
| obs_m | 子任务 m 开始时的 RGB 观测 | 机器人摄像头 |
| q_m | 子任务 m 开始时的关节配置 | 机器人本体感知 |
| $f_{\text{pred}}^{m+1}$ | 预测的子任务结束视觉特征 | 视觉 WM 输出 |
| $f_{\text{goal}}^{m+1}$ | 真实子任务结束视觉特征（编码后） | 关键帧标注 |
| $\alpha^{t:t+k}$ | 动作块（k 步） | VLA 输出 |

**直觉**：逻辑层用符号保证"做什么"的一致性，视觉层用特征保证"做成什么样"的可执行性。两者通过共享的子任务索引 m 对齐，在推理时同步调用。

> 符号与本文/相关文档保持一致：逻辑状态用 $\mathcal{X}$（花体 X），视觉特征用 $f$，动作用 $a$ 或 $\alpha$（$\alpha$ 表示低层连续动作）。

## 3. 带数字走一遍：玩具例子 (Worked Example)

假设一个 LIBERO-LoHo 任务："把黄油和巧克力布丁放进抽屉，然后关上抽屉"（5 步任务）。

**步骤分解**：

```
子任务 0: 初始状态
  X^0 = {OnTable(butter), OnTable(pudding), Closed(drawer)}
  obs_0 = 摄像头看到桌子上的物体
  q_0 = 机械臂初始关节角度

子任务 1: 拿起黄油
  逻辑 WM 预测：a_1 = Pick(butter), X^1 = {Holding(butter), OnTable(pudding), Closed(drawer)}
  视觉 WM 预测：f_pred^1 = 编码"手抓住黄油"的视觉特征
  VLA 执行：用 (obs_t, a_1, f_pred^1, q_t) 生成抓取动作，直到完成预测器触发

子任务 2: 把黄油放进抽屉
  逻辑 WM 预测：a_2 = PlaceIn(butter, drawer), X^2 = {In(butter, drawer), OnTable(pudding), Open(drawer)}
  视觉 WM 预测：f_pred^2 = 编码"黄油在抽屉里"的视觉特征
  VLA 执行：...

（继续到子任务 5：抽屉关闭，任务完成）
```

**关键数字**：
- 每个子任务，世界模型只调用 1 次（低频）
- VLA 在每个控制步（约 10-20Hz）调用，使用同一个 $f_{\text{pred}}^{m+1}$ 直到子任务完成
- LIBERO-LoHo 任务长度：5-7 步（相比原始 LIBERO 的 1-3 步翻倍）

**误差累积对比**：
- 纯 VLA：每步都有小误差，5 步后累积成功率从 85% 降到 40%
- H-WM：每子任务有视觉目标约束，误差被限制在子任务内部，5 步后成功率保持 70%+

## 4. 工程视角 (Engineering View)

**吞吐/延迟**：
- 逻辑 WM 推理：Qwen3-4B + LoRA，单次约 100-200ms（可接受，因为每子任务只调用 1 次）
- 视觉 WM 推理：PaliGemma + 2 层 FC，单次约 50-100ms
- VLA 推理：需要满足 10-20Hz 控制频率，使用 action chunking（一次预测 k=10 步）

**内存**：
- 逻辑 WM：4B 模型 LoRA 微调，约 8-10GB GPU 内存
- 视觉 WM：PaliGemma 3B + 小 head，约 6-8GB
- VLA：PaliGemma 3B，约 6-8GB
- 总需求：可分时加载，峰值约 10-12GB

**部署约束**：
- 需要 off-the-shelf VLM（Qwen3-VL-2B）做逻辑状态估计，这是额外的推理开销
- 逻辑状态标注需要 predicate 分类器，新任务需要重新标注
- 子任务完成预测器需要针对每个任务域微调（泛化性待验证）

**Trade-off**：
- 优点：长视野任务成功率显著提升，架构模块化便于调试
- 缺点：需要逻辑标注 pipeline，推理延迟高于纯 VLA，新任务迁移成本高

## 6. 能力与失败模式 (Capabilities & Failure Modes)

**能做什么**：
- 5-7 步的中长视野桌面操作任务（LIBERO-LoHo）
- 最多 20 步的超长视野任务（RoboCerebra，用 Q-Score 评估部分完成）
- 跨任务泛化（在 LIBERO 训练，评估 LIBERO-10/LoHo）

**不能做什么**：
- 移动机器人任务（实验只在桌面机械臂上验证）
- 双臂协作（单臂设置）
- 动态环境（假设环境静态，物体位置已知）
- 零样本新任务（需要逻辑动作和 predicate 标注）

### 6.1 隐含假设 (Hidden Assumptions)

1. **逻辑状态可估计**：假设 off-the-shelf VLM 能从观测中准确识别 predicate（如 OnTable, Holding, In）。真实场景中遮挡、光照变化会导致估计错误。

2. **子任务边界清晰**：假设任务可以干净地分解为离散子任务，每个子任务有明确的完成条件。连续/模糊边界的任务（如"搅拌直到均匀"）难以处理。

3. **逻辑 - 视觉对齐存在**：假设每个逻辑状态 X 对应一个可学习的视觉特征分布。但同一逻辑状态可能有多种视觉实现（如"黄油在抽屉里"可以有不同位置/朝向）。

4. **环境静态**：假设在执行子任务期间，环境不会发生未预料的变化。动态干扰（如人移动物体）会导致视觉目标失效。

## 7. 与相关工作对比 (Comparison)

| 方法 | 规划方式 | 视觉 grounding | 长视野能力 | 主要局限 |
|------|----------|----------------|------------|----------|
| 端到端 VLA（OpenVLA, π0） | 无显式规划 | 直接观测→动作 | 弱（1-3 步） | 误差累积，无中间监督 |
| LLM 分层规划 | 语言子目标 | 弱（语言→视觉 gap） | 中 | 缺乏物理约束，语义 - 执行错位 |
| 视觉世界模型 | 无符号规划 | 视频/图像预测 | 中 | 迭代生成误差累积 |
| 经典 TAMP | PDDL 符号规划 | 弱（独立感知 pipeline） | 强 | 感知噪声敏感，手动设计 domain |
| **H-WM（本文）** | **逻辑 WM 符号规划** | **视觉 WM 特征预测** | **强** | **需要逻辑标注，VLM 估计误差** |

**面试 Tip**：被问到"如何解决 VLA 长视野任务误差累积"时，可以回答："H-WM 的思路是用分层世界模型同时预测逻辑和视觉状态转移——逻辑层保证长视野一致性，视觉层提供可执行的具体目标。关键是两层联合预测而非串联，这样视觉预测被逻辑约束，逻辑规划有视觉反馈。"
