## 1. 核心架构/方法总览 (Overview / Architecture)

### 1.1 系统对比概览 (System Component Comparison)

| 组件 | 输入 | 输出 | 训练方式 | 推理频率 |
|------|------|------|----------|----------|
| **JAST-DiT（Stage I）** | 噪声轨迹块 [a_t+1:t+H; s_t+1:t+H] + 历史状态 H_t + CLIP 文本编码 | 流速度场 v_θ | Flow Matching 行为克隆 | 每控制步推理一次，输出 H 步 chunk，仅执行第一步 |
| **RLHR（Stage II）** | 同上 + 环境交互反馈 | 优化后的动作分布 | PPO + 混合奖励（物理+文本） | 同 Stage I（推理架构不变） |
| **历史采样器** | 完整历史缓冲区 B_t（L_max 帧） | 采样历史 H_t（N_s 近 + N_l 远） | 确定性非线性下采样 | 每控制步更新 |
| **CLIP 文本编码器** | 自然语言指令 c | c_pool（池化）+ c_txt（token 级特征） | 冻结 | 每 episode 一次 |

**关键设计差异**：
- 动作和状态 token 在联合注意力中**双向交互**（无因果掩码），因为扩散策略对整个轨迹块联合去噪
- 文本使用 penultimate-layer 特征而非最终投影，避免 token 级语义丢失
- 历史注入采用**分层交叉注意力**：先查远距离稀疏历史，再查近距离密集历史

### 1.2 关键机制 (Key Mechanism)

**JAST-DiT 三流联合注意力**：动作、状态、文本各自独立投影到共享隐空间，各自加位置编码后拼接为统一的 Q/K/V，做标准多头注意力后再拆分回三个流。每个 Transformer 块内通过 AdaLN-Zero 注入全局条件（flow time τ + 池化文本向量 c_pool）。QK-Norm 增强数值稳定性。

**非线性历史采样**：受认知科学中"工作记忆"和"遗忘曲线"启发。保留最近 N_s 帧作为密集近期历史，从 L_distant = L_max - N_s 的远距离历史中按对数衰减概率稀疏采样 N_l 帧。采样公式：

```
I_i = floor(L_distant · (1 + ln(1 - u_i · (1 - e^(-α))) / α))
```

其中 u_i ~ Uniform[0,1]，α 控制衰减率（越大越偏向近期帧）。

**RLHR（Reinforcement Learning with Hybrid Rewards）**：在 Flow Matching 预训练基础上，注入可学习噪声到 flow-sampling 过程中，用 PPO 优化混合奖励：物理反馈奖励（稳定性、运动质量）+ 文本对齐奖励（CLIP 相似度）。

⚡ **Eureka Moment**：将动作、状态、文本作为**三个平等的 token 流**放入同一个 Transformer 做联合注意力——而不是把文本当作粗糙的全局条件——是同时提升文本对齐和物理稳定性的关键架构决策。

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：

```
L_total = L_FM(θ) + L_RLHR(θ)
L_FM = E[||v_θ(x_τ, τ, y) - (x_1 - x_0)||²₂]    ← Stage I: 流匹配行为克隆
L_RLHR = E[R_phys + R_text - β·log(π_θ/π_ref)]  ← Stage II: PPO 混合奖励
```

**目标**：训练一个语言驱动的扩散策略 π_θ，在物理仿真环境中从自然语言指令 c 和状态历史 H_t 生成可执行的动作序列。

**变量说明**：

| 符号 | 含义 | 维度 |
|------|------|------|
| s_t | 本体感知状态（根高度 + 各关节位置/旋转/线速度/角速度） | R^358 |
| a_t | PD 控制器目标关节角度 | R^69 |
| H | 预测视界（trajectory chunk 长度） | 标量 |
| c | 自然语言指令 | 文本 |
| c_pool | CLIP 池化文本嵌入 | R^d |
| c_txt | CLIP penultimate-layer token 特征 | R^{L_txt × d} |
| x_0 | 高斯噪声 | R^{H × (d_a + d_s)} |
| x_1 | 干净数据（未来状态-动作轨迹块） | R^{H × (d_a + d_s)} |
| τ | flow time | [0, 1] |
| α | 历史采样衰减率 | 标量 |

**直觉**：Stage I 用 Flow Matching 学习从噪声到干净轨迹块的确定性映射（等价于行为克隆拟合专家轨迹）；Stage II 在闭环仿真中用 PPO 直接优化任务级奖励，其中可学习噪声注入提供探索能力，混合奖励同时推动物理稳定性和文本对齐。

> 符号与本文保持一致：动作 a ∈ R^69，状态 s ∈ R^358，文本由 CLIP 编码为 c_pool + c_txt。

## 3. 带数字走一遍：玩具例子 (Worked Example)

假设一个简化场景：H = 4 步预测视界，d_a = 2（简化关节角度），d_s = 3（简化状态），L_max = 20（历史窗口），N_s = 5（近期密集），N_l = 3（远期稀疏），α = 2.0。

**Step 1 — 历史采样**：
- 近期：保留 s_{t-1}, s_{t-2}, s_{t-3}, s_{t-4}, s_{t-5}（5 帧密集）
- 远期：L_distant = 15，采样 3 帧。设 u = [0.2, 0.6, 0.9]：

```
I_1 = floor(15 × (1 + ln(1 - 0.2×(1-e^(-2)))/2)) = floor(15 × 0.91) = 13 → s_{t-14}
I_2 = floor(15 × (1 + ln(1 - 0.6×(1-e^(-2)))/2)) = floor(15 × 0.70) = 10 → s_{t-11}
I_3 = floor(15 × (1 + ln(1 - 0.9×(1-e^(-2)))/2)) = floor(15 × 0.44) = 6  → s_{t-7}
```

对数衰减使得采样偏向较近帧（t-7, t-11, t-14），而非均匀分布（t-6, t-10, t-15）。

**Step 2 — Flow Matching 去噪**：
- 采样 τ = 0.5，构造 x_0.5 = 0.5·x_0 + 0.5·x_1
- 目标速度 u_0.5 = x_1 - x_0
- 网络预测 v_θ(x_0.5, 0.5, y)，其中 y = {H_t, c_txt, c_pool}
- 损失：||v_θ - (x_1 - x_0)||²₂

**Step 3 — 推理执行**：
- 从 τ=0 到 τ=1 数值积分得到 x_1_hat = [a_{t+1:t+4}; s_{t+1:t+4}]
- 仅执行 a_{t+1}（PD 控制器目标角度）
- 仿真器返回 s_{t+1}，更新历史缓冲区
- 下一控制步重复

**Step 4 — RL 后训练（Stage II）**：
- 在 flow-sampling 中注入可学习噪声 ε，扩大探索范围
- 每步计算混合奖励 R = R_phys + R_text
- PPO 更新策略：最大化 E[R] 同时约束 KL(π_θ || π_ref)

## 4. 工程视角 (Engineering View)

| 工程维度 | 数值/约束 | 含义 |
|----------|-----------|------|
| 状态维度 | 358 | 包含根高度 + 各关节位置/6D旋转/线速度/角速度 |
| 动作维度 | 69 | PD 控制器目标关节角度（Humanoid 通常 69 DOF） |
| 模型规模 | 206M / 578M / 1231M | Base / Large / Huge 三档 |
| 每头维度 | 128 | 固定，通过层数和头数缩放 |
| 数据规模 | 550K 轨迹 / ~1200 小时 | MotionMillion 清洗后 |
| 推理模式 | Receding-horizon | 每次推理 H 步，仅执行第 1 步 |
| 文本编码 | CLIP（冻结） | penultimate-layer token 特征 + 池化向量 |
| Stage I 训练 | Flow Matching BC | 确定性回归，无采样不确定性 |
| Stage II 训练 | PPO + 噪声注入 | 在线 RL，计算成本显著增加 |

**工程含义**：
- Receding-horizon 控制意味着推理延迟 = 单次 DiT forward pass + PD 控制步。扩散步数（flow-sampling steps）直接影响控制频率。
- 三流联合注意力的计算复杂度随 token 数线性增长（动作 H·d_a + 状态 H·d_s + 文本 L_txt），对实时控制友好。
- RLHR 阶段需要闭环仿真交互，训练成本远高于 Stage I 的离线 BC。
- 无真机实验意味着从仿真到现实的 sim2real gap 未解决——这是最大的部署障碍。

## 6. 能力与失败模式 (Capabilities & Failure Modes)

### 能做什么

- **多样化语言驱动动作**： locomotion、体育运动、舞蹈、日常动作（项目页展示）
- **长期稳定控制**：Duration 达 98.08%（接近 Phys-GT 的 100%），说明长时间运行不易摔倒
- **文本精确对齐**：R-Precision 全面领先，能理解复杂语言描述
- **模型规模可扩展**：从 0.2B 到 1.2B 参数性能单调提升

### 不能做什么

- **真机部署**：所有实验在 PHC 仿真中进行，无真实机器人验证（论文未提及 sim2real）
- **分布外泛化**：未见对训练集中未见过的动作类型的泛化评估
- **多机器人/双臂/移动操作**：仅针对单个人形机器人
- **视觉条件控制**：纯文本+本体感知，无视觉输入（与 VLA 的"V"有差距）

### 6.1 隐含假设 (Hidden Assumptions)

- **文本指令在训练分布内**：CLIP 编码的文本特征假设指令与训练数据语义空间一致，未见 OOD 文本鲁棒性测试
- **仿真器足够真实**：PHC 仿真器的物理特性（接触模型、摩擦、执行器延迟）假设能代表真实世界——但 sim2real gap 未量化
- **状态完全可观测**：假设所有 358 维本体感知状态精确可用，无传感器噪声建模
- **PD 控制器足够表达**：动作空间为 PD 目标角度，未探索更高级的力矩/阻抗控制
- **单一人形骨架**：假设人形骨架参数固定，未见跨平台迁移实验

## 7. 与相关工作对比 (Comparison)

| 方法 | 关注点 | 架构 | 训练方式 | 语言条件 | 数据规模 |
|------|--------|------|----------|----------|----------|
| **PDP (2024)** | 语言驱动人形控制 | 分层规划-跟踪 | RL | 是 | 小规模 |
| **UniPhys (2025)** | 统一物理控制器 | 潜技能蒸馏 | RL | 是 | 中等 |
| **CLoSD (2025)** | 语言条件扩散控制 | 扩散策略 | BC | 是（粗糙条件） | 中等 |
| **SCRIPT Stage I** | 端到端扩散策略 | JAST-DiT 三流联合 | Flow Matching BC | 是（token 级） | 大规模 (1200h) |
| **SCRIPT Stage II** | 同上 + RL 优化 | JAST-DiT + PPO | BC + RLHR | 是（token 级） | 大规模 (1200h) |

**关键差异**：
- SCRIPT 是首个将扩散策略扩展到 1200 小时数据 + 1.2B 参数的语言驱动人形控制工作
- 三流联合注意力 vs. 文本粗糙条件：token 级交互带来显著 R-Precision 提升
- RLHR 在闭环仿真中直接优化任务奖励，而非离线轨迹级奖励

**面试 Tip**：当被问到"扩散策略相比 RL 策略的优势"时，可以回答：扩散策略的多模态表达能力天然适合人类动作的多样性（一个语言指令对应多种合理动作），而传统 RL 策略（如 PPO 高斯输出）倾向于平均化多种模式。SCRIPT 的创新在于用 Flow Matching + RL 后训练兼顾了两者——FM 保证多样性，RL 保证任务性能。
