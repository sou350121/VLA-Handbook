| Action Expert (SnapFlow) | 噪声 x_1, 目标时间 s=0, 上下文 c | 单步动作 x_0 | 1 次前向传播 | 训练：FM/一致性混合；推理：单步 |
| Target-Time Embedding | 目标时间 s | 嵌入 $\varphi_s$ | 每次前向 | 零初始化训练，推理时 s=0 |

### 1.2 关键机制 (Key Mechanism)

**问题根源**：流匹配 VLA 学习的是瞬时速度场 u_t(x_t)，需要 10 步 Euler 积分才能从噪声 x_1 走到动作 x_0。 naive 地减少步数会导致速度场未校准，成功率下降。

**SnapFlow 的解决方案**：
1. **修正一致性目标**：用模型自身的边际速度预测 u_θ 替代条件速度 v_t，避免轨迹漂移（理论见 Theorem 1-2）
2. **两步 Euler 捷径目标**：用梯形法则近似平均速度，比单点条件速度更准确
3. **渐进 FM/一致性混合**：α=0.5 平衡速度估计质量与单步校准
4. **目标时间嵌入**：零初始化 MLP 区分 FM（s=t）与一致性（s=0）样本，无需改架构

⚡ **Eureka Moment**：流匹配 VLA 的速度场是为 10 步积分学习的，不是为单步跳跃校准的——SnapFlow 通过自蒸馏"拉直"速度场，让单步跳跃直接到达终点，同时保留多步能力。

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：

```
L = α·L_FM + (1-α)·λ·L_shortcut
其中 L_shortcut = ‖F_θ(x_1, 0, 1|c) - 0.5·[v_1 + v_0.5]‖²
```

**目标**：训练一个网络 F_θ，使其能从噪声 x_1 单步生成高质量动作 x_0，同时保持速度估计 u_θ 的准确性。

**公式拆解**：

| 符号 | 含义 | 来源 |
|------|------|------|
| x_t | 时间 t 的插值状态 | $x_t = (1-t)\cdot x_0 + t\cdot \varepsilon$ |
| v_t | 条件速度 | $v_t = \varepsilon - x_0$ |
| u_t | 边际速度场 | u_t(x_t) = E[v_t | x_t] |
| $F_\theta(x_t, s, t$|c) | 预测从 t 到 s 的平均速度 | 网络输出 |
| $\alpha$ | FM/一致性混合比 | 默认 0.5 |
| $\lambda$ | 一致性损失权重 | 默认 0.1 |

**直觉**：标准流匹配学习瞬时速度（s=t），SnapFlow 额外学习从 t=1 到 s=0 的平均速度。两步捷径目标用梯形法则近似积分，比单点估计更准确。

> **关键理论结果**（证明见 Appendix A）：
> - Theorem 1：条件速度 v_t 与边际速度 u_t 永远存在差异（Σ_t ≠ 0）
> - Theorem 2：用 v_t 替代 u_t 训练一致性目标会引入系统性漂移
> - Theorem 3：一致性映射的总误差随时间跨度 |t-s| 累积

## 3. 带数字走一遍：玩具例子 (Worked Example)

假设我们有一个简化的 1D 动作空间，真实动作 $x_0 = 5.0$，噪声 $\varepsilon = 2.0$。

**标准流匹配（10 步 Euler）**：
```
x_t = (1-t)·5.0 + t·2.0
t=1.0: x_1 = 2.0
t=0.9: x_0.9 = x_1 - 0.1·F_θ(x_1, 0.9, 1.0) = 2.0 - 0.1·(-3.0) = 2.3
t=0.8: x_0.8 = 2.3 - 0.1·(-3.1) = 2.61
...
t=0.0: x_0 ≈ 5.0  [10 步后接近真实值]
```

**SnapFlow 单步**：
```
训练时计算捷径目标：
v_1 = F_θ(x_1, 1, 1) = -3.0  [瞬时速度估计]
x_0.5 = x_1 - 0.5·v_1 = 2.0 - 0.5·(-3.0) = 3.5
v_0.5 = F_θ(x_0.5, 0.5, 0.5) = -2.8  [中间点速度]
v_target = 0.5·(v_1 + v_0.5) = 0.5·(-3.0 + -2.8) = -2.9

单步预测目标：F_θ(x_1, 0, 1) → -2.9
推理：x_0 = x_1 - 1.0·(-2.9) = 2.0 + 2.9 = 4.9  [单步接近真实值]
```

**关键差异**：标准流匹配的速度场是为小步长积分校准的，大步长会累积离散化误差。SnapFlow 直接优化大步长（单步）预测，避免误差累积。
