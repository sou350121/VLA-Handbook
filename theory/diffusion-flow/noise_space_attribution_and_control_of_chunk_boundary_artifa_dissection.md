## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：
```
a_t:t+H = π_θ(x_t, z)    →    J_contrast = (1/|B|)·Σ_{p∈B} j̄_p − (1/|I|)·Σ_{p∈I} j̄_p
```

**目标**：量化分块边界处的动作不连续程度，并将其归因于潜噪声 z 的变化。

**核心方程**：

```
动作 jerk（二阶差分）：
j_t = ||a_t − 2·a_{t−1} + a_{t−2}||_2

Episode-level 边界-内部 jerk 对比：
J_contrast = (1/|B|) · Σ_{p∈B} j̄_p  −  (1/|I|) · Σ_{p∈I} j̄_p

噪声定向扰动：
z' = z + α·d    （d 为搜索到的局部最优方向，α 为操控强度）
```

**变量说明**：

| 符号 | 含义 |
|------|------|
| a_t | t 时刻的动作向量 |
| j_t | t 时刻的动作 jerk（二阶时间差分） |
| B = {0, 1} | 边界相位（分块起始两步） |
| I = {2, 3, 4} | 内部相位（分块中间三步） |
| j̄_p | 相位 p 上的平均 jerk |
| z | 潜噪声向量 |
| d | 噪声空间中的定向扰动方向 |
| α | 定向操控强度（signed steering strength） |
| H | 动作块长度 |
| K | 实际执行步数（K ≤ H，重规划间隔） |

> 符号与本文保持一致。jerk 越大表示边界处动作变化越剧烈，即伪影越强。

**直觉**：jerk 捕捉的是动作的"突变"程度。如果分块边界处的平均 jerk 显著高于分块内部，说明存在系统性边界伪影。论文证明这个差值可以通过仅改变 z 来定向调制。

## 3. 带数字走一遍：玩具例子 (Worked Example)

假设一个简化的 2D 动作空间场景：

**设定**：
- 重规划间隔 K = 5（每 5 步重规划一次）
- 动作块长度 H = 10
- 当前 chunk 的最后两个动作：a_{t-2} = [0.1, 0.2], a_{t-1} = [0.15, 0.25]
- 下一个 chunk 的第一个动作（边界处）：a_t = [0.8, 0.9]（大跳变）

**计算 jerk**：
```
j_t = ||a_t − 2·a_{t−1} + a_{t−2}||_2
    = ||[0.8, 0.9] − 2·[0.15, 0.25] + [0.1, 0.2]||_2
    = ||[0.8−0.3+0.1, 0.9−0.5+0.2]||_2
    = ||[0.6, 0.6]||_2
    = sqrt(0.36 + 0.36)
    = sqrt(0.72)
    ≈ 0.849
```

**对比内部相位**（假设内部 jerk 平均为 0.15）：
```
J_contrast = j̄_boundary − j̄_interior
           = 0.849 − 0.15
           = 0.699
```

**噪声操控后**（假设 α = −0.5 沿低伪影方向）：
```
a'_t = [0.3, 0.35]  （更平滑的过渡）
j'_t = ||[0.3, 0.35] − [0.3, 0.5] + [0.1, 0.2]||_2
     = ||[0.1, 0.05]||_2
     ≈ 0.112

J'_contrast = 0.112 − 0.15 = −0.038  （伪影几乎消除）
```

**关键数字**（来自论文 §4.2）：
- 固定上下文中，24 个噪声样本的边界 gap 标准差 σ = 0.040
- 最大上下文级标准差达 0.097
- 成功/失败组的 gap 差异量级约 0.1-0.2，噪声操控可达到的变化量级与之相当

## 4. 工程视角 (Engineering View)

| 维度 | 数值/约束 | 工程含义 |
|------|-----------|----------|
| 重规划频率 | K=5 步 | 高频重规划降低单次计算负担，但增加边界伪影出现频率 |
| 噪声方向搜索 | 12 个随机方向 × 2 个 α 符号 = 24 次前向传播 | 在线成本高，不适合实时模块 |
| α 扫描范围 | |α| ≤ 0.5（局部线性区） | 超出后响应弯曲，偏离模型训练分布 |
| Real-robot 验证 | Aubo i5, r=0.968, R²=0.938 | 仿真到真机局部可控性可迁移，但 broader replication 留待未来 |
| 在线干预成本 | 显著高于轻量级实时模块 | 需要 budget-aware 的上下文自适应控制器 |
| 信息路径完整性 | DDPM 不可控 vs DDIM 可控 | 向 flow matching / consistency model 迁移时此问题更突出 |

**部署约束**：
- 当前方法依赖局部方向搜索，在线成本远超轻量级实时模块
- 更现实的路径：分阶段关键上下文筛选 → 局部分支验证
- 自适应控制器的瓶颈不在回归目标本身，而在第二级调度：何时干预、选高还是选低、如何分配有限干预预算

**评测任务设置**：
- 使用 frozen checkpoint（不微调），确保所有变化来自噪声操控而非策略更新

- 配对未来延续（pairwise matched continuation）排除下游随机性

## 6. 能力与失败模式 (Capabilities & Failure Modes)

### 能做什么

| 能力 | 条件 | 效果 |
|------|------|------|
| 分离成功/失败 episode | 任意上下文 | 失败组 J_contrast 显著更高（p < 0.05） |
| 固定上下文噪声操控 | OpenPI/flow matching | r=0.904 (BTJ), r=0.968 (gap) |
| DDIM 下的方向操控 | 相同 DP 权重 | r=0.961 (gap), r=0.927 (BTJ) |
| 任务结果提升 | task 8, target-low | 0.674 → 0.791 (+11.7pp) |
| 关键上下文方向反转 | 配对验证 | 0.033 → 0.717（高伪影有利场景） |
| 真机局部可控性 | Aubo i5 | r=0.968, R²=0.938 |

### 不能做什么

| 失败模式 | 原因 |
|----------|------|
| DDPM 下方向不可控 | Markov 逆向步骤破坏信息路径（零方差也不行） |
| ACT 下方向不可控 | 确定性策略，噪声路径不存在 |
| 全局统一最优方向 | 方向偏好上下文依赖（96.9% 上下文不匹配全局最优） |
| 自适应控制器稳定在线增益 | 上下文筛选 + 调度 + 预算分配的多级问题尚未解决 |
| 饱和任务上的正增益 | 成功率已近 1.0，正增益被天花板压缩 |

### 6.1 隐含假设 (Hidden Assumptions)

1. **局部线性假设**：噪声方向操控在 |α| ≤ 0.5 范围内近似线性，但论文 Figure 3b 显示超出此范围后响应弯曲——这意味着操控强度有硬上限
2. **关键上下文可识别**：论文假设存在可识别的"关键上下文"，但自适应控制器中"哪些上下文值得干预"是一级问题，尚未解决
3. **信息路径完整性可检测**：论文通过 DDPM/DDIM 对比间接证明了信息路径的重要性，但没有给出一个可计算的"路径完整性"度量
4. **仿真到真机可迁移**：Aubo i5 验证仅在一个固定上下文上完成，更广泛的硬件级复现留待未来工作
5. **jerk 作为伪影代理**：使用动作 jerk 作为边界伪影的代理指标，但 jerk 高不一定等价于"任务有害"——方向反转现象本身就说明了这一点
