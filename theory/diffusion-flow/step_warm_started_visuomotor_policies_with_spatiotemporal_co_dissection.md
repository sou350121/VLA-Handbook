## 1. 核心架构/方法总览 (Overview / Architecture)

STEP 是一个**两阶段推理框架**：先用轻量级预测器生成热启动动作序列，再将其注入扩散过程进行少量步数的精炼。

### 1.2 关键机制 (Key Mechanism)

STEP 的核心创新是将扩散加速问题分解为**三个正交维度**：

**机制 1：时空一致性预测器 (Spatiotemporal Consistency Prediction)**

预测器 $f_\theta$ 接收两个输入：
- 当前观测 o_t（视觉/本体感知）
- 历史动作序列 $A_{t-H}$（过去 $H$ 步的完整动作序列）

输出：预测动作序列 Â_t，作为扩散过程的热启动初始值。

架构：2 层 Cross-Attention Transformer（hidden_dim=128），动作序列作为 Query，观测作为 Key/Value。选择 2 层是因为在 RoboMimic 基准上 2 层与更多层的成功率相当但延迟更低（论文 Figure 3）。

训练目标：MSE 损失 L_pred = E[||Â_t - A_t||²]，监督学习。

**机制 2：速度感知扰动注入 (Velocity-aware Perturbation Injection)**

在真实物理世界中，当连续动作变化极小时（||ΔA_t|| < ε_a，ε_a=0.01），机器人可能因静摩擦力进入"执行死锁"状态。STEP 检测到这种情况时：
- 降低预测动作缩放系数 $\sigma = \sigma_{\text{scale}}$（而非 $1$）
- 注入可控噪声 σ_t = σ_stall（仿真 0.1，真实世界 1.0-1.4）

这相当于给机器人一个"抖动"来克服静摩擦，而在正常执行时不干扰原始策略。

**机制 3：局部收缩性理论保证 (Local Contractivity Analysis)**

论文证明：在标准噪声调度下，扩散反向过程的均值映射 $\mu_k$ 在数据流形附近是局部收缩的（Lipschitz 常数 $c_k < 1$）。因此从时空一致性热启动出发的误差会指数衰减：

```
||Ã_0 - A_0|| ≤ Π_{k=1}^{K'} c_k · ||Ã_{K'} - A_{K'}||
```

这意味着即使热启动不是完美的，后续的去噪步骤也能快速修正误差。

⚡ **Eureka Moment**：不要从纯噪声开始 — 用历史动作 + 当前观测预测一个"足够好"的初始动作，让扩散过程只做"精细修正"而非"从零生成"。

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：

```
Ã_{K'} = σ · f_θ(o_t, A_{t-H}) + σ_t · ε    (热启动)
A_0 ≈ μ_1(μ_2(...μ_{K'}(Ã_{K'})))            (2 步精炼)
```

**目标**：在最少去噪步数 K' 下，使最终动作 A_0 逼近目标分布 p(a|o_t) 的高概率流形。

**关键方程与变量**：

| 符号 | 含义 | 典型值 |
|------|------|--------|
| K | 总扩散步数 | 100 |
| K' | 热启动步（从中开始精炼） | 2 或 4 |
| $f_\theta$ | 时空一致性预测器 | 2-layer Transformer, 0.98M 参数 |
| $\sigma$ | 预测动作缩放系数 | $1$（正常）/ $\sigma_{\text{scale}}$（死锁） |
| $\sigma_t$ | 注入噪声幅度 | $0$（正常）/ $\sigma_{\text{stall}}$（死锁） |
| $\varepsilon_a$ | 死锁检测阈值 | 0.01 |
| $\sigma_{\text{stall}}$ | 死锁扰动幅度 | 0.1（仿真）/ 1.0-1.4（真实） |
| c_k | 反向映射 Lipschitz 常数 | < 1（保证收缩） |

**扩散反向过程**（标准 DP 公式，STEP 复用）：

```
a_{k-1} = (1/√α_k) · [a_k - ((1-α_k)/√(1-ᾱ_k)) · ε_θ(a_k, k, o)] + σ_k·ε
```

**预测器训练损失**：

```
L_pred(θ) = E[||f_θ(o_t, A_{t-H}) - A_t||²_2]
```

**局部收缩性**（理论保证）：

```
||Ã_0 - A_0|| ≤ Π_{k=1}^{K'} c_k · ||Ã_{K'} - A_{K'}||
```

> 符号与本文保持一致：$o_t$ 为观测，$A_t$ 为动作序列（horizon $H$），$\varepsilon_\theta$ 为去噪网络。

## 3. 带数字走一遍：玩具例子 (Worked Example)

假设一个简化的 2D 操纵场景：

**场景设定**：
- 动作维度 d=2（x, y 平面移动），horizon H=8
- 扩散总步数 K=100，STEP 从 K'=2 开始精炼
- 真实目标动作 A_t = [0.5, 0.3, 0.4, 0.2, ...]（8 步序列）

**Step 1 — 预测器输出**：
```
Â_t = f_θ(o_t, A_{t-H}) = [0.48, 0.31, 0.38, 0.22, ...]
预测误差 ||Â_t - A_t|| ≈ 0.05（L2 距离）
```

**Step 2 — 热启动初始化**（$K'=2$，$\sigma=1$，$\sigma_t=0.1$）：
```
Ã_2 = 1.0 · Â_t + 0.1 · ε,  ε ~ N(0, I)
    ≈ [0.48, 0.31, ...] + [0.02, -0.01, ...]
    = [0.50, 0.30, ...]
```
此时 Ã_2 已经非常接近目标 A_t 的流形（距离 < 0.05）。

**Step 3 — 扩散精炼**（2 步反向过程）：

第 2 步反向（k=2）：
```
μ_2(Ã_2) = (1/√α_2) · [Ã_2 - β_2/√(1-ᾱ_2) · ε_θ(Ã_2, 2, o_t)]
```
假设 c_2 = 0.7（收缩因子），误差从 0.05 压缩到 0.035。

第 1 步反向（k=1）：
```
μ_1(Ã_1) = (1/√α_1) · [Ã_1 - β_1/√(1-ᾱ_1) · ε_θ(Ã_1, 1, o_t)]
```
假设 c_1 = 0.6，误差从 0.035 压缩到 0.021。

**最终结果**：
```
||A_0 - A_t|| ≈ 0.021
```

对比：如果从纯噪声 A_100 ~ N(0, I) 开始，初始误差 ≈ 1.0（随机距离），需要 ~50-100 步才能收缩到同等精度。STEP 用预测器把初始误差从 1.0 降到 0.05，因此只需 2 步。

- STEP 不修改扩散策略的训练过程 — 它是一个**推理时加速层**，可以 drop-in 应用到任何预训练的 Diffusion Policy 模型

- 速度感知扰动注入几乎零成本：只是一个阈值检测和噪声注入，不增加网络推理

## 6. 能力与失败模式 (Capabilities & Failure Modes)

**能做什么**：
- ✅ 将 Diffusion Policy 推理延迟从秒级降到毫秒级（20ms）
- ✅ 在 2 步推理下保持甚至超越 100 步 DDPM 的成功率
- ✅ 兼容现有 DP 权重，无需重新训练扩散策略
- ✅ 在边缘设备（RTX 2050, 4GB VRAM）上部署
- ✅ 克服真实物理世界的执行死锁（静摩擦问题）

**不能做什么 / 局限**：
- ❌ 预测器需要额外训练（100K steps）— 不是完全零成本的加速
- ❌ 分布外泛化能力未充分验证 — 预测器在训练分布外的观测上可能输出低质量初始动作
- ❌ 仅在桌面操作任务上评估（RoboMimic, Push-T, ManiSkill2, SO-ARM101）— 对移动机器人、双臂、人形机器人的有效性未知
- ❌ 预测器训练依赖历史动作缓存 — 在任务切换或初始阶段（t < H）退化为标准扩散，失去加速优势
- ❌ 速度感知扰动是启发式的 — 阈值 $\varepsilon_a$ 和 $\sigma_{\text{stall}}$ 需要手动调参

### 6.1 隐含假设 (Hidden Assumptions)

| 假设 | 说明 | 风险 |
|------|------|------|
| 任务连续性 | 相邻时间步的目标动作分布变化不大 | 在快速状态变化或任务切换时，预测器可能输出错误初始值 |
| 历史动作信息充分 | $A_{t-H}$ 足以推断当前动作 | 如果环境动态高度非线性或存在隐藏状态，历史动作可能不够 |
| 预测器训练数据覆盖 | 预测器在训练时见过足够多的 $(o_t, A_{t-H})$ 组合 | 分布偏移时预测质量下降，且论文未报告 OOD 鲁棒性实验 |
| 局部收缩性成立 | 去噪网络 $\varepsilon_\theta$ 在数据流形附近 $L$-Lipschitz | 实际网络的 Lipschitz 常数可能 > 1，理论保证在实践中可能不严格成立 |
