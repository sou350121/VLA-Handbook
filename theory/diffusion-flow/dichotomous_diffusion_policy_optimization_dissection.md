💡 **X-Ray 开场**
扩散策略在模仿学习中表现出色，但用 RL 微调时面临两难：直接用指数加权回归会因权重爆炸导致训练不稳定，用高斯似然近似则计算量巨大且误差累积。DIPOLE 的核心发现是——最优策略可以分解为一对正/负二分策略，分别用有界 sigmoid 加权训练，推理时再线性组合。这相当于给扩散策略的 RL 训练装上了"油门踏板"：一个参数 $\omega$ 控制从保守到贪婪的连续调节。

## 1. 核心架构/方法总览 (Overview / Architecture)

### 1.1 系统对比概览 (System Component Comparison)

| 组件 | 传统 Exp-Weighted 回归 | DIPOLE |
|------|----------------------|--------|
| 权重函数 | $\exp(\beta \cdot G(s,a))$ — 无界、快速增长 | $\sigma(\beta \cdot G(s,a))$ 和 $1-\sigma(\beta \cdot G(s,a))$ — 有界 $[0,1]$ |
| 策略数量 | 1 个扩散模型 | 2 个扩散模型（π⁺ 和 π⁻） |
| 训练稳定性 | 高 $\beta$ 时 loss 爆炸 | 始终有界，不会爆炸 |
| 数据利用 | 高回报样本主导 loss | 高低回报样本分别被 π⁺/π⁻ 利用 |
| 推理方式 | 单个噪声预测器 $\varepsilon_\theta$ | ε̃ = (1+ω)·ε⁺ − ω·ε⁻（CFG 风格） |
| 贪心控制 | 通过 $\beta$（耦合在训练中） | 通过 $\omega$（推理时独立调节） |
| 理论保证 | 有闭式解但训练不稳定 | 有闭式解且训练稳定 |

### 1.2 关键机制 (Key Mechanism)

**为什么这样设计？**

传统 exp-weighted 回归的核心问题是：$\exp(\cdot)$ 函数增长太快，当 $\beta$ 较大时，高质量动作的权重会爆炸式增长，导致 loss 不稳定。实践中人们要么用小 $\beta$（牺牲最优性），要么 clip 权重（也牺牲最优性）。

DIPOLE 的洞察是：利用 sigmoid 函数的恒等式 $\sigma(x) = 1/(1+\exp(-x))$，可以将最优策略的 exp 权重分解为两个有界项的比值：

```
π*(a|s) ∝ [μ(a|s) · σ(βG)]^(1+ω) / [μ(a|s) · (1-σ(βG))]^ω
```

这意味着：
- **正策略 $\pi^+$**：用 $\sigma(\beta G)$ 加权，专注于从高回报样本学习
- **负策略 π⁻**：用 (1-σ(βG)) 加权，专注于从低回报样本学习
- 两个权重都在 [0,1] 范围内，训练永远不会爆炸

⚡ **Eureka Moment**：最优策略的 exp 加权可以精确分解为一对有界 sigmoid 加权的正/负策略之比——这既解决了稳定性问题，又天然导出了 CFG 风格的推理组合公式。

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：
```
π*(a|s) ∝ [π⁺(a|s)]^(1+ω) / [π⁻(a|s)]^ω
→ score: ∇_a log π* = (1+ω)·∇_a log π⁺ − ω·∇_a log π⁻
→ 噪声预测: ε̃ = (1+ω)·ε⁺ − ω·ε⁻
```

**目标**：在 KL-正则化 RL 框架下，找到最优扩散策略 $\pi^*$，使其在保持与参考策略 $\mu$ 接近的同时最大化期望回报。

**基础 KL-正则化目标**（原始形式）：
```
max_π E_s~d^π [ E_a~π [G(s,a)] − (1/β)·DKL(π(·|s) || μ(·|s)) ]
```

**原始闭式解**（不稳定的根源）：
```
π*(a|s) ∝ μ(a|s) · exp(β·G(s,a))
```

**DIPOLE 的 Greedified 目标**：
```
max_π E_s~d^π [ E_a~π [G(s,a)] − (1/(ωβ))·DKL(π(·|s) || μ(·|s)·σ(βG)/Z(s)) ]
```

**DIPOLE 闭式解**（稳定分解）：
```
π*(a|s) ∝ μ(a|s) · σ(βG) · exp(ω·βG)
        ∝ [μ·σ(βG)]^(1+ω) / [μ·(1-σ(βG))]^ω
        ∝ [π⁺]^(1+ω) / [π⁻]^ω
```

**训练损失**：
```
L(ε⁺) = E[σ(β·G(s,a)) · ‖ε − ε⁺_θ1(at, s, t)‖²]
L(ε⁻) = E[(1−σ(β·G(s,a))) · ‖ε − ε⁻_θ2(at, s, t)‖²]
```

**推理组合**：
```
ε̃(at, s, t) = (1+ω)·ε⁺_θ1(at, s, t) − ω·ε⁻_θ2(at, s, t)
```

> 符号说明：
> - G(s,a)：单步设为 r(s,a)，多步设为优势函数 A(s,a)
> - $\beta$：温度参数，控制权重分布的锐度
> - ω：贪心因子，推理时控制策略的贪婪程度（ω=0 保守，ω↑ 贪婪）
> - $\sigma(x) = 1/(1+\exp(-x))$：sigmoid 函数
> - $\mu$：参考策略（离线 RL 中为行为策略 $\pi_\beta$，离线到在线中为上一轮策略 $\pi_{k-1}$）

## 3. 带数字走一遍：玩具例子 (Worked Example)

假设一个简单场景：状态 s 下有 3 个候选动作，其优势值分别为：

| 动作 | A(s,a) | $\sigma(\beta \cdot A)$ (设 $\beta=1$) | 1−σ(β·A) |
|------|--------|------------------|-----------|
| $a_1$   | +2.0   | $\sigma(2.0) \approx 0.88$    | 0.12      |
| $a_2$   | 0.0    | $\sigma(0.0) = 0.50$    | 0.50      |
| $a_3$   | −2.0   | σ(−2.0) ≈ 0.12   | 0.88      |

**正策略 $\pi^+$ 训练**：$a_1$ 获得权重 $0.88$（重点学习），$a_2$ 权重 $0.50$，$a_3$ 权重 $0.12$（几乎不学）
**负策略 π⁻ 训练**：a₃ 获得权重 0.88（重点学习什么是"坏的"），a₂ 权重 0.50，a₁ 权重 0.12

**推理时组合**（设 $\omega=2.0$）：
```
ε̃ = (1+2)·ε⁺ − 2·ε⁻ = 3·ε⁺ − 2·ε⁻
```

这意味着：
- 正策略的贡献被放大 3 倍（推动向高回报方向）
- 负策略的贡献被减去 2 倍（推开低回报方向）
- 净效果：$a_1$ 的概率密度被强烈推高，$a_3$ 被强烈压低  

**对比原始 exp-weighted**（同样 $\beta=1$）：  
```
exp(1·2.0) ≈ 7.39, exp(0) = 1, exp(−2) ≈ 0.135
```
最高和最低权重比 = $7.39/0.135 \approx 54.8$ 倍——这会导致 loss 极度不稳定。  

而 DIPOLE 的最大/最小权重比 = $0.88/0.12 \approx 7.3$ 倍——训练稳定得多。  

## 4. 工程视角 (Engineering View)

| 维度 | 考量 | 具体数值/分析 |
|------|------|--------------|
| 模型参数量 | 2 个扩散头 vs 1 个 | 论文中 DP-VLA 用两个 LoRA 模块实现，额外参数约 $1\text{B} \times \text{rank\_ratio} \times 2$   |
| 训练 FLOPs | 2 倍扩散头训练 | 正/负策略可并行训练，实际 wall-clock 约 1.5-1.8x |
| 推理延迟 | 2 次前向 + 1 次线性组合 | ε⁺ 和 ε⁻ 可 batch 在一起算，组合是 O(d) 向量操作，可忽略 |
| 步数/采样效率 | 标准扩散步数 | 论文未明确步数，但 CFG 风格组合不增加采样步数 |
| 内存占用 | $2\times$ 模型权重 + 优势函数缓存   | 推理时两个头可共享 encoder，仅 action head 翻倍 |
| 部署约束 | 需要在线计算优势函数 A(s,a) | 需要训练一个 Q/V 网络，与标准 offline RL 一致 |
| 量化误差 | 两个头的量化误差会线性叠加 | ω 较大时 ε⁻ 的量化误差被放大，需注意 |

**工程含义**：DIPOLE 的核心 trade-off 是"训练时 2x 模型 vs 推理时几乎零额外开销"。对于 VLA 系统，这意味着在边缘部署时，扩散策略头的推理延迟不会显著增加——额外的 π⁻ 头可以和 π⁺ 共享视觉 encoder，仅 action decoder 部分需要两份。

## 6. 能力与失败模式 (Capabilities & Failure Modes)

### 能做什么
- **稳定的扩散策略 RL 微调**：sigmoid 有界权重确保训练不会因 exp 爆炸而崩溃
- **灵活的贪心度控制**：推理时通过 $\omega$ 连续调节策略的贪婪程度，无需重新训练  
- **高效利用高低质量数据**：π⁺ 学好的，π⁻ 学坏的，比只用高回报样本更高效
- **扩展到 1B 参数 VLA**：在 NAVSIM 自动驾驶任务上验证了可扩展性

### 不能做什么 / 局限
- **具身机器人场景未验证**：实验在 OGBench/ExORL 仿真环境和 NAVSIM 自动驾驶上，尚未在真实机器人操作/抓取任务上测试
- **需要优势函数估计**：需要训练 Q/V 网络来计算 G(s,a)，增加了 pipeline 复杂度
- **双头推理假设**：π⁺ 和 π⁻ 共享相同的架构和输入，如果两个策略需要不同的表征能力，可能受限
- **$\omega$ 的选择仍需调参**：虽然 $\omega$ 是连续控制旋钮，但最优值因任务而异  

### 6.1 隐含假设 (Hidden Assumptions)

1. **优势函数 A(s,a) 足够准确**：DIPOLE 的权重完全依赖 A(s,a) 的质量。如果 Q/V 估计偏差大，sigmoid 权重会误导训练方向。论文未系统分析 Q 误差对最终性能的影响。

2. **π⁺ 和 π⁻ 共享相同架构是足够的**：分解后的正/负策略用相同结构的扩散模型学习，但最优情况下两者可能需要不同的容量或归纳偏置。

3. **sigmoid 加权足以捕捉回报分布**：exp 权重可以放大极端差异，sigmoid 是有界的——在回报分布极度偏斜的任务中，可能"压平"了重要的区分信号。

4. **NAVSIM 伪闭环仿真 $\approx$ 真实闭环**：论文使用"非反应式伪闭环仿真"，这意味着其他 agent 不响应自车行为。真实驾驶中其他车辆会反应，性能可能下降。
