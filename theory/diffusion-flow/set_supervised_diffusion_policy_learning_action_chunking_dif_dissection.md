💡 **X-Ray 开场**
扩散策略（DP）在模仿学习中表现出色，但和所有 BC 方法一样存在分布偏移问题——部署时机器人犯错后人类介入修正，但现有方法只用人类的修正动作做 BC 训练，完全忽略了"机器人原本打算做什么"这个负信号。SDP 的核心发现是：正负动作对可以定义一个"可接受动作集合"，训练策略生成集合内任意动作而非精确模仿人类，反而能提升鲁棒性和数据聚合质量。对 VLA 研究者意味着：VLA 后训练中的微调阶段，可以用类似思路减少对少量高质量干预数据的过拟合依赖。

### 1.2 关键机制 (Key Mechanism)

**为什么这样设计？**

- **从单步到动作分块**：CLIC 只处理单步动作 $a \in A$，但 Diffusion Policy 的核心优势之一是动作分块（$T$ 步连续动作），能缓解协变量偏移、捕捉多模态行为。SDP 将 CLIC 的集合构造扩展到 $T$ 步分块空间，每个时间步独立构造单步集合，组合成 $T$ 维序列集合。
- **从 EBM 到扩散模型**：EBM 训练不稳定且难以整合动作分块（需要高维联合能量函数），而扩散模型天然支持高维连续动作分块建模，训练稳定。
- **从精确模仿到集合对齐**：BC 假设人类动作是完美标签，但人类干预本身有噪声——SDP 的集合允许策略在"足够好"的区域内探索，而非精确拟合一个可能不完美的点。

⚡ **Eureka Moment**：人类修正数据天然包含正负信号——机器人想做的（错）和人类让它做的（对），这对分块定义了一个"可接受区域"，训练策略生成该区域内任意动作比精确模仿人类更鲁棒。

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：

```
L_SDP = -1/N · Σ_{n=1}^{N} log π_θ(A⁰_n | O_t)
其中 A⁰_n ∈ A_hat_t  且  A_hat_t = {A | ∀i, a_{t+i} ∈ A_ss_{t+i}}
```

**目标**：最大化扩散策略生成"期望动作集合内"动作分块的似然，而非精确模仿单一人类动作。

**核心方程分解**：

```
// 步骤 1: 单步期望集合（CLIC 延续）
A_ss(a⁻, a⁺) = {a ∈ A | r · ‖a⁺ - a⁻‖ ≥ ‖a - a⁺‖}

// 步骤 2: 动作分块期望集合（SDP 扩展）
A_hat_t = [A_ss_t, A_ss_{t+1}, ..., A_ss_{t+T-1}]

// 步骤 3: 目标策略（重加权当前策略）
π_target(A|O_t) ∝ 1{A ∈ A_hat_t} · π_θ(A|O_t)

// 步骤 4: KL 损失 → 采样近似
L = E_{A~π_target}[-log π_θ(A|O_t)] ≈ -1/N · Σ_{n=1}^{N} log π_θ(A⁰_n|O_t)

// 步骤 5: 扩散实现（标准 noise prediction，目标替换为 A⁰_n）
∇_θ ‖ε_k - ε_θ(O_t, √ᾱ_k·A⁰_n + √(1-ᾱ_k)·ε_k, k)‖²
```

**变量说明**：

| 符号 | 含义 | 备注 |
|------|------|------|
| A⁻, A⁺ | 负/正动作分块 | T 维序列，来自机器人/人类 |
| r | 半径比超参 | 控制集合体积，$r \in [0,1]$ |
| A_hat_t | 期望动作分块集合 | T 个单步集合的笛卡尔积 |
| N | 采样数量 | 论文中 N=10（算法伪代码） |
| K_A | 集合采样起始去噪步 | 从 K_A 步开始去噪+反射 |
| L_A_hat | 逐维反射投影算子 | 确保去噪过程中样本留在集合内 |

> 符号与本文保持一致。扩散系数 $\alpha_k$, $\gamma_k$, $\sigma_k$ 遵循标准 DDPM 调度。

## 3. 带数字走一遍：玩具例子 (Worked Example)

假设一个简化的 2D 单步场景（T=1 以简化），观察 O 下：

- 机器人动作 a⁻ = (0, 0)
- 人类修正 $a^{+} = (1, 0)$
- 半径比 r = 0.5

**步骤 1：构造期望集合**

```
‖a⁺ - a⁻‖ = ‖(1,0) - (0,0)‖ = 1
r · ‖a⁺ - a⁻‖ = 0.5

A_ss = {a | ‖a - (1,0)‖ ≤ 0.5}
```

即以 (1, 0) 为圆心、半径 0.5 的圆盘。任何落在此圆盘内的动作都被视为"可接受"。

**步骤 2：从集合采样**

假设通过去噪+反射，采样到 N=3 个样本：
```
A⁰_1 = (1.0, 0.1)   ‖A⁰_1 - a⁺‖ = 0.1 ≤ 0.5 ✓
A⁰_2 = (0.7, 0.3)   ‖A⁰_2 - a⁺‖ = 0.36 ≤ 0.5 ✓
A⁰_3 = (1.2, -0.2)  ‖A⁰_3 - a⁺‖ = 0.28 ≤ 0.5 ✓
```

**步骤 3：训练**

标准扩散训练，但目标从 $a^{+} = (1,0)$ 替换为采样到的 $A^{0}_n$。

**对比 BC**：BC 会精确拟合 $a^{+} = (1,0)$，策略分布坍缩到一个点。SDP 的分布覆盖整个半径 $0.5$ 的圆盘，在部署时遇到分布偏移时，策略有更大的"容错空间"——即使推理有微小偏差，只要落在圆盘内就是可接受动作。

**扩展到 T=16 动作分块**：每个时间步独立构造圆盘，T 个圆盘的笛卡尔积构成 2T 维超柱体。策略被训练生成该超柱体内的任意序列，而非精确拟合人类分块。

## 4. 工程视角 (Engineering View)

| 维度 | BC-DP | SDP | 工程含义 |
|------|-------|-----|----------|
| 训练计算 | $1\times$ forward | $N\times$ 采样 $+ 1\times$ forward | 训练开销增加 $\sim N$ 倍（$N=10$ 时约 $2\text{--}3\times$ 实际开销，因采样可重用网络） |
| 推理计算 | K 步去噪 | K 步去噪（相同） | **推理零额外开销**，部署友好 |
| 数据需求 | 仅正动作 | 正负分块对 | 在线场景天然满足；离线需人工构造负样本 |
| 超参敏感 | 低 | 中（r 值） | $r$ 控制集合体积：$r$ 太小 $\to$ 退化为 BC；$r$ 太大 $\to$ 监督信号太弱 |
| 内存占用 | 标准 replay buffer | 需存储 A⁻ | 每条数据额外存储 $T \times \text{dim}$ 维负动作 |
| 训练稳定性 | 高（标准 DDPM） | 高（标准 DDPM） | 反射投影是确定性操作，不引入额外不稳定性 |
| 与 VLA 微调兼容性 | 直接可用 | 需改造数据管道 | VLA 后训练阶段可注入对比数据，但需设计负样本生成策略 |

**部署约束**：SDP 的推理与标准 DP 完全一致（K 步去噪），不增加推理延迟。主要工程成本在训练端——需要 N 次去噪采样来生成训练目标。

## 6. 能力与失败模式 (Capabilities & Failure Modes)

**能做什么**：
- 在线人类干预场景：天然利用正负分块对，无需额外数据构造
- 噪声修正鲁棒性：集合监督天然容忍人类修正中的不一致
- 长程任务：动作分块 + 集合对齐减少协变量偏移累积
- 离线微调：通过人工构造负样本（单位球扰动），可在现有演示数据集上应用

**不能做什么**：
- 无负信号场景：如果只有纯演示数据（无机器人自身动作记录），需要人工构造负样本，质量取决于扰动策略
- 高维 $r$ 选择：在 $T \times \text{dim}$ 高维空间中，单一标量 $r$ 可能不足以描述各维度的不同容差
- 跨任务泛化：实验仅在单一机器人平台上验证，未测试跨平台迁移

### 6.1 隐含假设 (Hidden Assumptions)

1. **分块内各时间步独立构造集合**：SDP 假设 a⁺_{t+i} 优于 a⁻_{t+i} 仅取决于 O_t，忽略了分块内时间依赖性。实际上，一个时间步的"好"动作可能依赖于前序动作的选择。
2. **球形集合假设**：使用 L2 球定义期望集合假设动作空间各方向容差一致。对于某些任务（如插入操作），某些方向（沿插入轴）的容差可能远大于其他方向。
3. **人类修正总是"更好"的**：SDP 假设 a⁺ 是比 a⁻ 更好的动作，但人类干预本身可能也有次优情况。CLIC 通过集合精炼缓解此问题，但初始集合可能仍包含次优动作。
4. **反射投影不破坏策略分布**：去噪过程中的逐维反射确保样本在集合内，但可能扭曲策略原本的概率分布形状。
