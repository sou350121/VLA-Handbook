**训练/推理关键差异**：
- 训练阶段：教师强制（teacher-forced），用真实潜隐序列做滑动窗口预测
- 推理阶段：自回归（autoregressive），用预测器自己的输出作为下一步输入，滚动 K=30 步

### 1.2 关键机制 (Key Mechanism)

**为什么用潜在空间而不是像素空间？**

像素级视频预测有两个致命问题：(1) 计算开销大，需要生成每个像素；(2) 像素空间中的"模糊"不代表预测不准——多种合理的未来画面在像素空间差异很大，但对判断成功/失败没有额外信息。潜在空间预测只保留与结果相关的信息（物体是否被抓住、是否滑落），丢弃无关细节（背景纹理、光照变化）。这遵循 JEPA（Joint-Embedding Predictive Architecture）原则。

**为什么策略可以完全解耦？**

传统方法（如 SIRIUS）联合训练策略和动力学模型，监控模块与策略深度耦合。ContactGuard 把策略当作"黑盒提议者"——只消费策略已经发出的动作 chunk，不访问策略内部参数，不需要联合训练。这意味着：
- 可以附加到任意已有的 chunked 策略（ACT、Diffusion Policy 等）
- 世界模型训练不需要策略参与，用无标签的机器人轨迹即可
- 部署时策略和监控模块独立运行

⚡ **Eureka Moment**：不预测"下一步长什么样"，而是预测"下一步会不会失败"——潜在世界模型的价值不在于生成逼真的未来画面，而在于压缩出足以判断成败的抽象表示。

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：

```
P(fail) = σ(w^T · standardize(P_θ(E_φ(o_t), a_{t:t+K-1})) + b)
         ↑           ↑                                    ↑
      分类器       世界模型K步预测                      编码+动作
```

**目标**：在夹爪闭合前 k_pre 帧，预测接触后 K 步的潜在状态，并用线性探针判断是否失败。

**核心方程**：

```
损失函数（世界模型训练）：
L = (1/L) Σ_{i=0}^{L-1} ||z_{i+C}^ - z_{i+C}||_2^2 + λ·L_reg
  └─ next-latent 回归   └─ SIGReg 抗坍缩正则

失败探针：
P(fail | z_{t+K}^) = σ(w^T · z~_{t+K} + b)
  其中 z~_{t+K} = (z_{t+K}^ - μ) / σ  （标准化）

探针训练（L2 正则 + 类别平衡）：
min_{w,b} (1/2)||w||_2^2 + ρ · Σ_{i=1}^{N} s_{y_i} · log(1 + exp(-(2y_i-1)(w^T z~_i + b)))
  其中 s_c = N / (2·N_c)  （类别权重，补偿正负样本不平衡）
```

**变量说明**：

| 符号 | 含义 | 典型值 |
|------|------|--------|
| V | 相机路数 | 3 |
| D | 潜在维度 | 未明确（ViT-Tiny 通常 192-384） |
| C | 上下文窗口 | 未明确 |
| K | Rollout 步数 | 30 |
| k_pre | 接触前锚定位移 | 15 帧 |
| 控制频率 | — | 30 Hz |
| 预接触窗口 | 0.5s × 30Hz | 15 帧 |
| 预测后视窗口 | 0.5s × 30Hz | 覆盖接触后 0.5s |
| τ | 中止阈值 | 每任务独立选取（验证集） |

> 符号与本文保持一致：E_φ 为编码器，P_θ 为预测器，σ 为 sigmoid 函数，L_reg 为 SIGReg 正则项。

## 3. 带数字走一遍：玩具例子 (Worked Example)

假设一个简化的抓取场景，用合理假设数值演示完整流程：

**场景设定**：
- 3 路相机（左腕、右腕、中视），每路 224×224 RGB
- 控制频率 30 Hz，动作维度 d = 7（6 关节 + 1 夹爪）
- 潜在维度 D = 192（ViT-Tiny）

**Step 1 — 编码**：
```
o_t (3路图像) → E_φ → z_t ∈ R^192
假设 z_t = [0.12, -0.05, 0.33, ..., 0.08]（192维）
```

**Step 2 — 触发检测**：
```
扫描动作 chunk a_{t:t+29}，发现第 15 步夹爪命令从 open→close
k_pre = 15，满足触发条件（closure 在 15 帧内）
→ 激活监控
```

**Step 3 — 自回归 Rollout**：
```
z_{t+1} = P_θ(z_t, a_t)         = [0.10, -0.03, 0.35, ...]
z_{t+2} = P_θ(z_{t+1}, a_{t+1}) = [0.08, -0.01, 0.38, ...]
...
z_{t+15} = ...（夹爪即将闭合）
...
z_{t+30} = P_θ(z_{t+29}, a_{t+29}) = [0.05, 0.12, -0.22, ...]  ← 预测接触后状态
```

**Step 4 — 探针评分**：
```
标准化：z~_{t+30} = (z_{t+30} - μ) / σ
假设训练集统计量 μ = [0.1, 0.0, 0.1, ...], σ = [0.2, 0.15, 0.25, ...]

探针计算：
score = w^T · z~_{t+30} + b
假设 w = [0.3, -0.5, 0.8, ...]（训练得到）
score = -1.2

P(fail) = sigmoid(-1.2) = 0.23

阈值 τ = 0.30（该任务验证集选取）
0.23 < 0.30 → 不中止，继续执行 ✓
```

**对比失败案例**（假设同一场景但夹爪偏移）：
```
z_{t+30} = [0.30, -0.45, 0.60, ...]（物体滑落的潜在特征）
score = w^T · z~ + b = 1.8
P(fail) = sigmoid(1.8) = 0.86
0.86 > 0.30 → 中止！机械臂暂停 5s，避免失败接触 ✓
```

## 4. 工程视角 (Engineering View)

| 维度 | 数值/约束 | 工程含义 |
|------|----------|---------|
| 控制频率 | 30 Hz | 每 33ms 一个控制周期，监控必须在 chunk 窗口内完成 |
| 预接触窗口 | 0.5s (15 帧) | 从触发到夹爪闭合有 15 帧决策时间 |
| Rollout 步数 | K=30 | 自回归 30 步预测，覆盖接触前 0.5s + 接触后 0.5s |
| 预测器 | 4 层 Transformer + 2 层 MLP | 轻量架构，推理延迟可控 |
| 探针 | 线性逻辑回归 | O(D) 计算，几乎零开销 |
| 策略耦合 | 完全解耦 | 策略和监控并行运行，监控不阻塞策略除非 abort |
| 数据需求 | 世界模型：无标签轨迹；探针：~250 标注抓取 | 探针标注成本可控，世界模型可复用任意轨迹 |
| 部署开销 | 编码器 + 预测器 + 探针 | 约等于一个小型 Transformer 推理，可在边缘 GPU 运行 |

**关键 trade-off**：
- **潜在维度 vs 信息保留**：D 太小会丢失失败判别信息，太大会增加推理延迟。论文未明确 D 的具体值（ViT-Tiny 通常在 192-384 之间）。
- **K 步 rollout vs 误差累积**：自回归 K=30 步，早期预测误差会累积到后期。教师强制训练 vs 自回归推理的 gap 是潜在风险。
- **单阈值 vs 动态阈值**：τ 每任务选一次后冻结，意味着不随场景复杂度自适应。

**评测协议**：
- 离线评测：N=50 次监控 rollout，记录 P(fail) 分数，计算 AUC / balanced accuracy / false abort rate
- 在线评测：当 P(fail) > τ 时暂停 5s 后继续执行剩余 chunk（counterfactual proxy），记录 would-be outcome
- 测试集与训练集严格分离：世界模型训练、探针拟合、阈值选取、消融调优均不使用测试数据

**基线方法**：
- LeWM：单相机世界模型（容量匹配）
- Direct-linear：跳过 rollout，直接用当前潜隐 z_t + 动作预测失败
- Current latent：用当前潜隐 z_t 而非预测未来潜隐
- FAIL-Detect / RND / SAFE：外部运行时失败检测器

## 6. 能力与失败模式 (Capabilities & Failure Modes)

**能做什么**：
- 在夹爪闭合前 0.5s 预测抓取失败（论文 Table 1：多视图 ContactGuard 在 4 个任务上 AUC 优于所有基线）
- 利用多视角补偿遮挡：某一相机被遮挡时，其他相机可补充信息
- 即插即用：不修改 ACT 策略，作为独立模块附加
- 用少量标注数据（~250 次/场景）训练探针

**不能做什么**：
- **触发器硬编码**：仅支持"夹爪开→关"这一种接触事件。推、插、拧、折叠等其他接触类型需要重新设计触发逻辑
- **不处理中止后的恢复**：论文中 abort 后暂停 5s 再继续执行原 chunk 以记录 counterfactual，实际部署中需要恢复策略
- **不搜索候选动作**：只判断当前提议的 chunk 是否安全，不生成替代动作
- **单一阈值**：τ 每任务固定，不随场景动态调整

### 6.1 隐含假设 (Hidden Assumptions)
