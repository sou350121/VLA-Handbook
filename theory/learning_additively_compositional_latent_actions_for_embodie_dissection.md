### 1.2 关键机制 (Key Mechanism)

**加法组合约束 (Additive Composition, AC)**:
对于同一场景中的三个观测 o_i, o_j, o_k，潜在动作满足：
```
z_ik = z_ij + z_jk
```
其中 z_ij = f(o_i, o_j) 是逆动力学模型 (IDM) 输出的潜在动作。

**为什么这样设计？**
1. **物理直觉**：短时程刚体运动在欧氏空间可近似为加法（Baker-Campbell-Hausdorff 近似）
2. **代数结构**：加法约束自动导出恒等元 (z_ii=0)、逆元 (z_ji=-z_ij)、循环一致性
3. **信息过滤**：非组合性成分（如静态场景标识、未来泄漏）会被约束抑制

⚡ **Eureka Moment**：潜在动作的范数 ||z|| 应该与物理位移幅度成正比——但现有 LAM 学到的潜在动作范数系统性地低估真实位移；AC 约束通过强制组合一致性，使潜在空间范数自然校准到运动幅度。

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：
```
L = L_rec + L_VQ + λ_AC · E_{i,j,k}[||o_k - F(o_i, f(o_i,o_j) + f(o_j,o_k))||²]
```

**目标**：在保持标准重建质量的同时，强制潜在动作空间满足加法组合结构。

**公式分解**：

| 符号 | 含义 | 来源 |
|------|------|------|
| o_i, o_j, o_k | 同一轨迹/场景中的三个观测 | 论文 §3.1 |
| z_ij = f(o_i, o_j) | IDM 输出的潜在动作 (R^d) | 论文 Eq.1 |
| F(z, o) | FDM，从初始观测和潜在动作重建目标观测 | 论文 §3.1 |
| L_rec = E_{i,j}[||o_j - F_{z_ij}(o_i)||²] | 标准重建损失 | 论文 Eq.1 |
| L_AC-FDM = E_{i,j,k}[||o_k - F(o_i, z_ij + z_jk)||²] | AC 组合损失 (FDM 形式) | 论文 Eq.5 |
| λ_AC | AC 损失权重 (超参) | 论文 §3.4 |

**直觉**：如果潜在动作真正编码了运动语义，那么从 o_i 到 o_k 的潜在动作应该等于从 o_i 到 o_j 再到 o_k 的潜在动作之和。FDM 从"加和的潜在动作"解码出的重建应该接近真实 o_k。

> 符号与本文/相关文档保持一致：z 表示潜在动作向量，F 表示前向动力学模型，f 表示逆动力学模型，下标 ij 表示从时刻 i 到 j 的转移。

## 3. 带数字走一遍：玩具例子 (Worked Example)

假设一个 2D 平面上的机器人末端执行器，从位置 p_0 = (0, 0) 移动到 p_2 = (3, 4)。

**场景 1：无 AC 约束的标准 LAM**
- IDM 学到：z_02 = f(p_0, p_2) = [2.1, 2.8]（低估位移）
- 潜在范数：||z_02|| = 3.5，但真实位移 ||p_2 - p_0|| = 5.0
- 位移校准误差：30%

**场景 2：AC-LAM**
采样中间点 p_1 = (1.5, 2.0)：
- z_01 = f(p_0, p_1) = [1.5, 2.0]，||z_01|| = 2.5
- z_12 = f(p_1, p_2) = [1.5, 2.0]，||z_12|| = 2.5
- AC 约束：z_02 ≈ z_01 + z_12 = [3.0, 4.0]
- 潜在范数：||z_02|| = 5.0，与真实位移完全匹配

**AC-FDM 损失计算**：
```
z_sum = z_01 + z_12 = [3.0, 4.0]
ô_2 = F(p_0, z_sum)  # FDM 从 p_0 和 z_sum 重建 p_2
L_AC-FDM = ||p_2 - ô_2||²
```
如果 FDM 学得好，ô_2 ≈ p_2，损失接近 0。

**关键洞察**：AC 约束迫使潜在动作的向量加法对应于物理位移的向量加法，从而校准潜在范数与运动幅度。

## 4. 工程视角 (Engineering View)

| 工程维度 | 设计选择 | 含义 |
|----------|----------|------|
| **损失形式** | FDM 形式 (Eq.5) vs IDM 形式 (Eq.4) | FDM 形式更稳定；IDM 形式易导致潜在动作坍缩到零 |
| **AC 施加位置** | post-VQ 连续嵌入 | 与 Villa-X 兼容，保留 VQ 瓶颈的离散化优势 |
| **时间跨度约束** | 机器人数据 τ≤3s，人类视频 τ≤2s | 确保 BCH 近似有效（小旋转假设） |
| **旋转过滤** | 过滤大旋转三元组 | 避免加法假设失效（旋转是乘法组合） |
| **训练稳定性** | 无需 EMA 或冻结目标 | FDM 形式天然稳定，简化实现 |
| **推理开销** | 零额外开销 | AC 约束仅在训练时生效，推理用标准 IDM |

**部署约束**：
- AC-LAM 需要三元组采样逻辑，训练数据加载器需支持 (i,j,k) 同轨迹采样
- 对于长时程动作规划，需分段应用 AC 约束（每段 ≤3s）
- 本体感知 FDM 需要机器人状态输入（位置/速度），纯视觉设置需调整

### 6.2 不能做什么 / 局限性

| 局限 | 原因 | 影响 |
|------|------|------|
| 长时程动作 | 加法假设仅适用于短时程 | 需分段处理或引入层次结构 |
| 大旋转运动 | 旋转是乘法组合 (SO(3)) | 论文过滤大旋转三元组 |
| 跨场景组合 | AC 约束是场景内的 | 跨场景动作组合未验证 |
| 离散动作 | 本文用连续潜在空间 | 离散动作组合性需另行研究 |

### 6.3 隐含假设 (Hidden Assumptions)

1. **短时程运动可近似为欧氏加法**：依赖 BCH 近似，对大旋转/长时程失效
2. **轨迹=场景**：论文将每条轨迹视为独立场景，但真实场景中跨轨迹可达性未利用
3. **潜在空间维度足够**：假设 R^d 能容纳加法结构，但未分析最小维度需求
4. **VQ 不破坏组合性**：假设量化后连续嵌入仍保持加法性质（经验验证但未证明）
