## 1. 核心架构/方法总览 (Overview / Architecture)

LaPla 将自动驾驶建模为一个**隐式对齐序列建模任务**，分为两个阶段：

### 1.1 系统对比概览 (System Component Comparison)

| 组件 | 输入 | 输出 | 训练/推理 | 作用 |
|------|------|------|-----------|------|
| **残差 VQ-VAE** (预训练, 冻结) | 轨迹位移+航向角 x ∈ R^3 | 量化隐向量 z_q / 重建轨迹 x̂ | 仅预训练阶段 | 捕获运动学先验，编码-解码对 |
| **VQ-VAE Encoder** f_enc (冻结) | 历史动作 x_t | 量化隐向量 z_{q,t} | 冻结 | 将历史动作编码为语义对齐 token |
| **Emu3-8B Backbone** (LoRA 微调) | 多模态序列 X | 隐藏状态 h_t | LoRA 微调 | 多模态语义理解 + 推理 |
| **未来隐向量投影头** ϕ_fut | h_t (action query 的隐藏态) | 连续隐向量 ẑ_t | 可训练 | 将语义隐态映射到 VQ-VAE 隐空间 |
| **扰动参数** {b^(n), σ^(n)} | — | 扰动后的隐向量 ẑ_t^(n) | 可训练 | 生成 N=20 个多样化轨迹候选 |
| **VQ-VAE Decoder** f_dec (冻结) | 连续隐向量 ẑ_t^(n) | 位移 d̂_t + 航向 θ̂_t | 冻结 | 将隐向量解码为物理轨迹 |
| **VQA 头** (可选) | 缓存隐态 H | 自然语言答案 | 联合训练 | 提供可解释输出 |

### 1.2 关键机制 (Key Mechanism)

**为什么这样设计？** 现有 VLA 方法在动作生成上面临三难困境：

1. **动作 Token 化**（AutoVLA）：将连续轨迹硬编码为离散 token，引入量化误差，开环表现尚可但闭环中误差累积导致轨迹锯齿化
2. **双系统解耦**（DriveVLM/Senna）：VLM 做高层决策，下游 VA 做低层规划，存在时空错位——语义推理和控制频率不同步
3. **扩散动作头**（DrivePI）：通过迭代去噪生成平滑轨迹，但训练不稳定且推理延迟高（多次去噪步骤），不适合车载实时部署

LaPla 的洞察：**VQ-VAE 的离散量化瓶颈在预训练阶段是必要的**（用于聚类出物理合理的运动基元），但在推理阶段反而是负担。解决方案是——**预训练时用离散量化结构化隐空间，推理时直接输出连续隐向量绕过量化**。

⚡ **Eureka Moment**：VQ-VAE 的离散量化只在预训练时用于构建结构化隐空间；推理时让 VLM 直接输出连续隐向量，绕过 codebook 查找，由冻结解码器"翻译"为物理轨迹——**量化是手段而非目的**。

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：

```
L_vla = min_n (1/T) Σ_t SmoothL1(p̂_t^(n), p_t) + λ·L_vqa
      │            │
      │            └─ 冻结解码器将连续隐向量"翻译"为物理轨迹
      └─ Best-of-N 选择最优候选，梯度回传到隐向量投影
```

**目标**：让 VLM 输出的连续隐向量 ẑ_t 经过冻结解码器 f_dec 后，解码出的轨迹尽可能接近 ground truth。

**核心方程**：

```
ẑ_t = ϕ_fut(h_t)                          # 投影头: VLM 隐态 → 连续隐向量
ẑ_t^(n) = ẑ_t + σ^(n)·b^(n) + 0.1·(ẑ_t ⊙ b^(n))   # 扰动生成多样性
[d̂_t^(n); θ̂_t^(n)] = f_dec(ẑ_t^(n))       # 冻结解码器 → 位移+航向
p̂_t^(n) = p_0 + Σ_{τ=0}^{t-1} d̂_τ^(n)      # 累积求和 → 绝对坐标
L_plan = min_n (1/T) Σ_t ||p̂_t^(n) - p_t||_{SmoothL1}  # BoN 损失
```

**变量说明**：

| 符号 | 含义 | 维度 |
|------|------|------|
| h_t | action query <act_t> 的最后一层隐藏态 | R^{d_vlm} |
| ẑ_t | 预测的连续隐向量 | R^{d_z} |
| b^(n), σ^(n) | 可学习扰动基向量和尺度 | R^{d_z}, R |
| f_dec | 冻结的 VQ-VAE 解码器 | — |
| d̂_t, θ̂_t | 解码出的位移和航向角 | R^2, R |
| p̂_t | 累积重建的绝对航点 | R^2 |
| T | 规划时间步数 | — |
| N | 轨迹候选数 | 20 (推理时) |

> 符号与本文保持一致。所有向量均为列向量。⊙ 表示逐元素乘法。

**直觉**：冻结解码器 f_dec 充当**运动学梯度预条件器**——原始欧氏空间中的轨迹误差通过 f_dec 的反向传播被"过滤"成物理一致的隐空间梯度，主动引导 VLM 的优化方向朝向运动学合理的流形。

## 3. 带数字走一遍：玩具例子 (Worked Example)

假设一个简化场景：车辆在直道上需要左转。

**Step 1: VLM 输出隐向量**
- h_0（t=0 时刻的 action query 隐藏态）经 ϕ_fut 投影得到 ẑ_0 ∈ R^{d_z}
- 假设 ẑ_0 在隐空间中对应"直行"方向

**Step 2: 扰动生成多样性**
- N=20 个扰动变体：ẑ_0^(n) = ẑ_0 + σ^(n)·b^(n) + 0.1·(ẑ_0 ⊙ b^(n))
- 假设其中 n=7 的 b^(7) 在隐空间中对应"左转"方向
- 则 ẑ_0^(7) 会偏向"左转"的隐向量区域

**Step 3: 冻结解码器翻译**
- f_dec(ẑ_0^(7)) → [d̂_0^(7); θ̂_0^(7)] = [0.5m, 15°]
- 即解码出：前进 0.5 米，航向偏转 15°（左转）
- 注意：如果直接用 VQ-VAE 的离散量化，ẑ_0 会被硬编码到最近的 codebook entry，可能丢失这 15° 的精细角度

**Step 4: 多步累积**
- t=0: p̂_0 = p_0 = [0, 0]（当前位置）
- t=1: p̂_1 = [0, 0] + [0.5, 0] = [0.5, 0]（假设 d̂_0^(7) 的 x 分量）
- t=2: p̂_2 = [0.5, 0] + [0.48, 0.13] = [0.98, 0.13]（航向偏转开始体现）
- ...
- t=6（3秒规划）: p̂_6 ≈ [2.8, 0.9]（完成左转轨迹）

**Step 5: BoN 选择**
- 20 个候选中，n=7 的轨迹与 ground truth 的 SmoothL1 损失最小
- 损失回传：∂L/∂p̂ → ∂p̂/∂d̂ → ∂d̂/∂ẑ（通过冻结解码器的梯度）→ ∂ẑ/∂h → 更新 ϕ_fut 和 LoRA 参数

**关键**：冻结解码器虽然参数不变，但梯度仍可通过它回传到 ẑ_t，引导隐向量向正确方向移动——这就是"隐式对齐"的含义。

### 6.1 隐含假设 (Hidden Assumptions)

1. **VQ-VAE 预训练数据覆盖足够广**：如果预训练数据中没有某种驾驶行为（如紧急避让），冻结解码器无法生成该行为的轨迹，即使 VLM 理解了这个意图
2. **隐空间连续性假设**：连续隐向量经过冻结解码器后能产生平滑轨迹——这要求 VQ-VAE 的隐空间本身是语义平滑的（论文声称"nearby latents correspond to similar trajectories"但未给出定量验证）
3. **BoN oracle selector 可用性**：开环评测使用 oracle selector 选择最优候选，实际部署时需要可靠的候选评分器
4. **Emu3-8B 作为 backbone 的通用性**：更换 backbone 后性能可能显著不同，论文未做 ablation
