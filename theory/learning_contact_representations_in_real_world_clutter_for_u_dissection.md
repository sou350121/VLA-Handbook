**训练 vs 推理差异**：
- 训练阶段：仅接触推断网络需要训练（64 epochs, batch=4），优化器不参与
- 推理阶段：接触推断 + 优化器联合运行，无硬件特定参数

### 1.2 关键机制 (Key Mechanism)

**为什么这样设计？** 传统方法要么端到端学习（绑定硬件），要么纯解析优化（需要精确接触标注）。SpaHybGen 的关键创新在于**中间层解耦**：

1. **接触表示作为通用接口**：神经网络不直接输出抓取位姿，而是输出"哪里可以接触"的空间特征场。这个表示不绑定任何特定机械手——它是一个关于"场景中的哪些表面区域适合接触"的通用知识。
2. **优化器负责硬件适配**：给定接触特征和机械手 URDF，可微优化器通过迭代搜索找到最优抓取位姿。不同机械手共享同一套接触特征，只需替换 URDF。
3. **数据效率**：接触特征从 GraspNet-1Billion 学习（10 亿抓取样本），泛化能力来自大规模数据而非网络容量。

⚡ **Eureka Moment**：**将"接触"抽象为硬件无关的空间特征场，让神经网络学感知、优化器做适配——解耦后，训练一次即可部署到任意机械手。**

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：

```
g* = argmax_g  Σ_{p ∈ contacts(g)}  f_θ(p | D)  −  λ·C(g; H)
```

其中 `f_θ` 是接触推断网络（3D U-Net），`D` 是深度观测，`contacts(g)` 是抓取 `g` 下的接触点集，`C(g; H)` 是机械手 `H` 的约束代价（碰撞、力闭合等），`λ` 是平衡系数。

**目标**：找到使接触质量最大化且满足机械手物理约束的抓取位姿 `g*`。

**公式分解**：

| 符号 | 含义 | 来源 |
|------|------|------|
| `f_θ(p \| D)` | 网络推断的位置 `p` 处的接触质量分数 | 3D U-Net 输出 |
| `D` | 场景深度观测（体素化或 TSDF） | 深度相机 |
| `contacts(g)` | 抓取 `g` 下机械手与物体的接触点集 | 运动学正解 |
| `C(g; H)` | 机械手约束代价（碰撞惩罚 + 力闭合偏离） | 解析模型 |
| `λ` | 接触质量 vs 约束的平衡权重 | 自动目标缩放策略 |
| `g` | SE(3) 抓取位姿 + 关节角度 | 优化变量 |

**直觉**：接触推断网络告诉优化器"场景中哪里好抓"，优化器在"好抓的位置"中搜索满足机械手约束的位姿。网络负责感知泛化，优化器负责硬件适配。

## 3. 带数字走一遍：玩具例子 (Worked Example)

假设一个简化场景：桌面上有 3 个物体（立方体、圆柱体、球体），使用 2 指夹爪（Robotiq 2F）。

**Step 1 — 场景观测**：
- 深度相机捕获场景，体素化网格为 128×128×128
- 每个体素值为 0/1（占据/空闲）

**Step 2 — 接触推断**：
- 3D U-Net 处理体素网格
- 输出每个体素的接触特征向量 `f ∈ R^d`（含接触质量和方向）
- 假设物体表面体素获得高接触分数（如 0.85-0.95），空隙区域低分（<0.2）

**Step 3 — 优化器搜索**（以立方体为例）：
- 初始化 64 个候选抓取位姿（随机 SE(3) + 关节角度）
- 对每个候选 `g_i`：
  - 计算接触点 `contacts(g_i)`（通过运动学正解）
  - 查询接触特征：`score_i = Σ f_θ(p | D)`
  - 计算约束代价：`C_i = collision_penalty + force_closure_deviation`
  - 总评分：`S_i = score_i − λ·C_i`
- 迭代 120 次，逐步优化位姿
- 最终选择 `g* = argmax S_i`

**假设数值**（基于论文报告的 94.3%–98.0% 成功率推断）：
- 立方体：接触分数 0.92，约束代价 0.05 → 总分 0.87 → ✅ 成功抓取
- 圆柱体：接触分数 0.88，约束代价 0.08 → 总分 0.80 → ✅ 成功抓取
- 球体：接触分数 0.75，约束代价 0.15 → 总分 0.60 → ⚠️ 边缘情况（球面接触不稳定）

### 6.1 隐含假设 (Hidden Assumptions)

1. **深度观测足够**：假设深度相机能提供可靠的场景几何——但透明物体、强光、遮挡会导致深度缺失
2. **刚体假设**：优化器基于刚体运动学——不适用于软体操作
3. **静态场景**：虽然有 20 Hz 动态更新，但接触特征推断是静态的（非时序模型）
4. **接触质量可学习**：假设从 GraspNet-1Billion 学到的接触表示能泛化到新物体——但 GraspNet 主要覆盖日常物体
5. **力闭合充分**：优化器使用力闭合作为约束——但某些操作（如推、拨）不需要力闭合
