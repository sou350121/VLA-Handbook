💡 **X-Ray 开场**
VLA 模型从预训练迁移到具体任务时，通常用 SFT 或 RL。SFT 有分布偏移问题，而现有 RL 方法把所有模块用同一频率更新——但这忽略了语义层和动作层的学习节奏本质不同。TEMPO 发现：让语义投影层「慢更新」保持表征稳定，让动作专家「快更新」快速吸收交互反馈，两者用独立的 TD3 回路分别优化，就能在长程任务上获得更大的性能提升。对研究者意味着：VLA 的后训练不再是「调哪些参数」的问题，而是「以什么节奏调」的问题。

## 1. 核心架构/方法总览 (Overview / Architecture)

### 1.1 系统对比概览 (System Component Comparison)

| 组件 | 输入 | 输出 | 训练状态 | RL 回路 | 更新频率 |
|------|------|------|----------|---------|----------|
| VLM Backbone (VL) | (o_t, l_t) 视觉+语言 | h_t 多模态表征 | 冻结 | 无 | 0 |
| Semantic Projection (π_θ^s) | h_t | z_t 潜在动作 | 可训练 | Semantic TD3 | 低频 (f_s) |
| Action Expert (π_φ^a) | z_t | a_t 动作块 | 可训练 | Action TD3 | 高频 (f_a) |

| 对比维度 | FLOWER-RL (基线) | TEMPO (本文) |
|----------|------------------|--------------|
| RL 回路数 | 1 (联合更新 π^s + π^a) | 2 (独立更新) |
| 更新频率 | 相同 | 非对称 (f_a > f_s) |
| 梯度隔离 | 无（联合梯度） | 有（stop-gradient） |
| Replay Buffer | 1 个 | 2 个 (D_S, D_A) |
| Critic | 1 对 twin critics | 2 对 twin critics |

### 1.2 关键机制 (Key Mechanism)

- **冻结 VLM 保留通用语义**：不更新庞大的预训练视觉-语言骨干，避免破坏已有的互联网级语义知识，同时大幅降低计算开销。
- **双独立 TD3 回路**：语义投影层和动作专家各自拥有独立的 replay buffer、twin critics、target networks 和优化器。两者共享同一组环境交互数据，但通过不同的状态-动作空间进行优化。
- **频率解耦**：核心创新。语义投影层低频更新（防止潜在动作空间漂移），动作专家高频更新（快速吸收控制反馈）。两者的有效更新频率比 ρ = f_a / f_s 是可调超参。
- **Stop-Gradient 隔离**：动作专家更新时，从 h_t 重新计算 z_t^sg = sg(π_θ^s(h_t))，阻止梯度回传到语义投影层，确保两个回路的梯度路径完全独立。

⚡ **Eureka Moment**：VLA 后训练的关键不是「更新哪些模块」，而是「以什么节奏更新」——语义和动作的学习时间尺度不同，解耦它们的更新频率比联合更新更有效。

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：

```
ρ = f_a / f_s > 1  →  动作专家更新频率 > 语义投影层更新频率
```

**目标**：在 MDP 框架下最大化长程累积奖励，同时避免语义漂移导致动作专家学习目标持续变化。

**核心方程**：

```
RL 目标:  max_ω E[Σ_{t=0}^{H-1} γ^t · r_t]

语义回路 Bellman Target:
  y_t^S = r_t + γ·(1-d_t) · min_{i=1,2} Q̄_i^s(h_{t+1}, z̃_{t+1})
  其中 z̃_{t+1} = π̄_θ^s(h_{t+1})

语义 Critic Loss:
  L_Qs = Σ_{i=1}^{2} E[(Q_i^s(h_t, z_t) - y_t^S)^2]

语义 Actor Loss:
  L_s = -E[Q_1^s(h_t, π_θ^s(h_t))]

动作回路 Bellman Target:
  y_t^A = r_t + γ·(1-d_t) · min_{i=1,2} Q̄_i^a(z̃_{t+1}, ã_{t+1})
  其中 z̃_{t+1} = π̄_θ^s(h_{t+1}), ã_{t+1} = π̄_φ^a(z̃_{t+1})

动作 Critic Loss:
  L_Qa = Σ_{i=1}^{2} E[(Q_i^a(z_t, a_t) - y_t^A)^2]

动作 Actor Loss (stop-gradient):
  L_a = -E[Q_1^a(z_t^sg, π_φ^a(z_t^sg))]
  其中 z_t^sg = sg(π_θ^s(h_t))

频率比:
  ρ = f_a / f_s = (N_a · d_s) / (N_s · d_a)
```

> 符号说明：
> - h_t: VLM 编码的多模态语义表征（冻结）
> - z_t: 语义投影层输出的潜在动作
> - a_t: 动作专家输出的可执行动作块
> - r_t: 稀疏奖励（任务完成 = 1，否则 = 0）
> - d_t: 当前指令是否终止
> - γ: 折扣因子
> - N_a, N_s: 每轮中动作/语义 critic 的更新次数
> - d_a, d_s: 动作/语义 actor 的延迟更新间隔
> - ρ: 动作-语义更新频率比，ρ > 1 表示动作更新更快

## 3. 带数字走一遍：玩具例子 (Worked Example)

假设一个 5 步指令链的长程操作任务，每步产生一个潜在动作 z_t 和动作块 a_t：

**设置**：
- ρ = 3（动作专家每轮更新 3 次，语义投影层更新 1 次）
- γ = 0.99
- N_a = 4, d_a = 2 → f_a = 2（每轮 2 次 actor 更新）
- N_s = 2, d_s = 3 → f_s = 0.67（每轮 0.67 次 actor 更新）
- ρ = 2 / 0.67 ≈ 3

**第 1 轮交互**（4 步）：

```
Step 1: h_1 → z_1 = [0.3, -0.1, 0.5] → a_1 → r_1=0, h_2
Step 2: h_2 → z_2 = [0.2, 0.0, 0.4] → a_2 → r_2=0, h_3
Step 3: h_3 → z_3 = [0.4, 0.1, 0.3] → a_3 → r_3=0, h_4
Step 4: h_4 → z_4 = [0.5, 0.2, 0.2] → a_4 → r_4=1, h_5, d_4=1
```

**数据写入两个 Buffer**：

```
D_S = {(h_1,z_1,r_0,h_2,d_0), (h_2,z_2,r_0,h_3,d_0), (h_3,z_3,r_0,h_4,d_0), (h_4,z_4,r_1,h_5,d_1)}
D_A = {(h_1,z_1,a_1,r_0,h_2,d_0), ..., (h_4,z_4,a_4,r_1,h_5,d_1)}
```

**更新过程**（1 轮中）：

```
Critic 更新:
  Q^s 更新 4 次 (N_a=4) → 用 D_S 中的样本计算 TD error
  Q^a 更新 4 次 (N_a=4) → 用 D_A 中的样本计算 TD error

Actor 更新:
  π_φ^a 更新 2 次 (f_a=2, 每 2 次 critic 更新后更新一次 actor)
  π_θ^s 更新 0 次 (f_s=0.67 < 1, 本轮不更新，累积到下一轮)
```

**直觉**：动作专家从 4 个样本中快速学到了「第四步需要完成动作」的反馈模式（r_4=1），更新了 2 次参数。语义投影层保持不变，z_1~z_4 的潜在动作空间保持稳定，动作专家的学习目标没有漂移。如果 ρ=1，两者同步更新，z 空间可能在这 4 步内已经变化，导致动作专家刚学到的映射关系失效。

## 4. 工程视角 (Engineering View)

| 工程维度 | 考量 |
|----------|------|
| 计算开销 | VLM 冻结 → 前向传播成本不变；但需要维护两套 TD3 回路（critics + targets + buffers），额外参数量约为原单回路的 ~1.5-2x |
| 内存占用 | 两个独立 replay buffer 存储不同格式的数据（D_S 无 a_t，D_A 有 a_t），内存约为单回路的 ~1.8x |
| 训练吞吐 | 每轮需要执行两次 critic 更新 + 两次 actor 更新（非对称频率），实际训练速度约为单回路的 0.6-0.7x |
| 超参敏感 | ρ 是关键超参——论文指出 ρ > 1 普遍优于 ρ = 1，但最优 ρ 值因任务而异，需要网格搜索 |
| 部署影响 | 推理时架构不变（VL + π^s + π^a 串行），推理延迟与 FLOWER 完全相同，仅训练阶段有额外开销 |
| 模块化优势 | 可独立替换动作专家（换机器人平台时只重训 π^a），语义投影层可跨任务复用 |

**工程含义**：TEMPO 的设计使得训练和推理解耦——训练时维护两套回路增加开销，但推理时与基线完全一致。对于需要频繁适配新任务的场景，这种模块化设计降低了每次适配的成本。

## 6. 能力与失败模式 (Capabilities & Failure Modes)

### 能做什么

| 场景 | 能力 | 证据 |
|------|------|------|
| 长程多指令任务 | 随着指令链增长，性能优势扩大 | SR5 提升 3.9pp > SR1 提升 0.6pp |
| 跨场景泛化 | 在未见过的环境 D 上表现最优 | CALVIN ABC→D 协议 |
| 真实机器人操作 | 学会正确的多步操作序列 | Block Sliding + Car Retrieval |
| 模块化适配 | 可独立更新动作专家或语义投影层 | 消融实验证实两者互补 |

### 不能做什么 / 局限

| 局限 | 原因 | 影响 |
|------|------|------|
| 仅在桌面操作验证 | 实验限于 CALVIN + 2 个真实任务 | 无法推断对移动/双臂/人形机器人的效果 |
| ρ 超参需调优 | 不同任务可能有不同的最优频率比 | 实际部署时需要额外的调参成本 |
| VLM 冻结 | 如果任务需要新的视觉概念理解，冻结 VLM 可能成为瓶颈 | 对于与预训练数据分布差异大的任务可能表现不佳 |
| 稀疏奖励设定 | 仅用任务完成奖励，未利用过程奖励 | 在需要密集反馈的精细操作任务上可能不如专用方法 |

### 6.1 隐含假设 (Hidden Assumptions)

1. **语义表征已足够**：假设预训练 VLM 的 h_t 已经包含了任务所需的所有语义信息，只需通过投影层调整即可。如果任务涉及 VLM 未见过的概念，这个假设可能不成立。
2. **潜在动作空间是线性可分的**：假设 z_t 空间中的优化可以用 TD3 这类基于连续控制的算法有效完成。如果 z_t 空间高度非线性或存在多模态分布，TD3 可能不够。
3. **频率比 ρ 的通用性**：论文在 CALVIN 上找到了 ρ > 1 的优势，但未验证不同任务复杂度下最优 ρ 是否一致。
4. **两个回路共享同一组交互数据是充分的**：论文假设相同的 rollout 数据可以同时服务于语义和动作两个回路的优化。实际上，语义回路可能需要更多样化的语义状态覆盖，而动作回路可能需要更多边界情况的操作数据。
