## 1. 核心架构/方法总览 (Overview / Architecture)

### 1.1 系统对比概览 (System Component Comparison)

| 范式 | 采样方式 | 监督信号 | 少样本能力 | 收敛速度 | 抗遗忘 | 鲁棒性 |
|------|----------|----------|------------|----------|--------|--------|
| VLA-Offline SFT | Off-policy | 稠密 (token 级) | ✗ | 快 | ✗ | ✗ |
| VLA-Online RL (GRPO) | On-policy | 稀疏 (任务成功/失败) | ✓ | 慢 | ✓ | ✓ |
| **VLA-OPD (本文)** | **On-policy** | **稠密 (教师 logits)** | **✓** | **快** | **✓** | **✓** |

**训练/推理差异**：
- **训练期**：学生策略 on-policy 采样 $\to$ 教师冻结提供 labels $\to$ 反向 KL 优化  
- **推理期**：仅用学生策略，教师不参与（蒸馏完成）

### 1.2 关键机制 (Key Mechanism)

**Phase 1 - 学生采样**：学生策略 $\pi_\theta$ 在环境中执行，收集轨迹 $T_{\text{student}}$。由于学生初始能力有限（如 1-traj SFT 初始化），会频繁进入分布外 (OOD) 状态。

**Phase 2 - 教师标注**：对学生访问的每个状态 s_t，查询冻结教师 π_tea 获取动作 logits q_t(a) = π_tea(a|s_t)。不执行教师动作，仅作为监督信号。

**Phase 3 - 模式寻求优化**：用反向 KL 散度更新学生，使学生分布向教师对齐，但过滤教师的不确定性尾部。

⚡ **Eureka Moment**：**反向 KL 的"模式寻求"特性是关键**——它让学生只关注教师最自信的动作模式，既避免 Forward-KL 的熵爆炸（模仿教师犹豫），又避免 Hard-CE 的熵坍缩（丢失探索多样性）。

│                    VLA-OPD Training Loop                    │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│ Phase 1: On-Policy Sampling (Student Exploration)           │
│   π_θ(·|o) → 生成 G 条轨迹 {τ_1, ..., τ_G}                  │
│   每条轨迹：s_0 → a_0 → s_1 → a_1 → ... → s_T              │

│   θ ← θ + α · ∇J                                            │

                              │

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：

```
r_t^OPD = -(log π_θ(a_t|s_t) - log π_tea(a_t|s_t)) = -log[π_θ(a_t|s_t) / π_tea(a_t|s_t)]
```

**目标函数**：最大化负反向 KL 散度的期望

```
max_θ J(θ) = E_{s~π_θ}[-D_KL(π_θ(·|s) || π_tea(·|s))]
```

**变量说明**：

| 符号 | 含义 | 来源 |
|------|------|------|
| $\pi_\theta$ | 学生策略（待优化） | 本文方法 |
| $\pi_{\text{tea}}$ | 教师策略（冻结） | 预训练专家（如 SimpleVLA-RL） |
| s_t | 学生轨迹上的状态 | Phase 1 采样 |
| a_t | 学生执行的动作 | Phase 1 采样 |
| $r_t^{\text{OPD}}$ | token 级内在奖励 | Phase 2 计算 |
| G | 每组轨迹数量 | 超参（论文用 G=8） |

**直觉解释**：
- 当学生动作概率与教师一致时，$r_t \approx 0$（高奖励）
- 当学生显著偏离教师时，r_t 为大幅负值（惩罚）
- 关键技巧：计算 $r_t$ 时对 $\log \pi_\theta$ 项用 $\text{stop\_gradient}$，避免奖励计算影响梯度

**三种目标对比**（§3.4 核心分析）：

| 目标 | 优化方向 | OOD 状态行为 | 熵动态 |
|------|----------|--------------|--------|
| Forward-KL | $D_{\text{KL}}(\pi_{\text{tea}}$ || $\pi_\theta)$ | 模仿教师不确定性 | 熵爆炸 |
| Hard-CE | $\text{CE}(\pi_{\text{tea}}, \text{argmax})$ | 刚性跟踪 argmax | 熵坍缩 |
| **Reverse-KL** | **$D_{\text{KL}}(\pi_\theta$ || $\pi_{\text{tea}})$** | **只关注教师高置信模式** | **有界健康熵** |

> 符号与本文/相关文档保持一致：$\pi$ 表示策略分布，$\theta$ 为学生参数，$\text{tea}$ 为教师下标

## 3. 带数字走一遍：玩具例子 (Worked Example)

假设一个简化的 2D 抓取任务，动作空间为离散 4 方向 {上，下，左，右}。

**场景**：学生在 OOD 状态 s_err（因执行误差偏离专家轨迹）

**教师分布**（在 s_err 处有一定不确定性）：
```
π_tea(·|s_err) = {上: 0.6, 下: 0.3, 左: 0.05, 右: 0.05}
```

**学生当前分布**（初始偏离较大）：
```
π_θ(·|s_err) = {上: 0.2, 下: 0.2, 左: 0.4, 右: 0.2}
```

**学生采样动作**：假设采样到 a_t = "左"

**Forward-KL 问题**：
- 强制学生覆盖教师整个支撑集
- 学生会学到：$\pi_\theta \approx \{\text{上}: 0.6, \text{下}: 0.3, \text{左}: 0.05, \text{右}: 0.05\}$
- 结果：熵从 1.91 bits 爆炸到 1.68 bits（仍高），但模仿了教师的"犹豫"

**Hard-CE 问题**：
- 只匹配 argmax：教师选"上"，学生必须选"上"
- 学生学到：$\pi_\theta \approx \{\text{上}: 1.0, \text{下}: 0, \text{左}: 0, \text{右}: 0\}$
- 结果：熵坍缩到 0，失去探索能力

**Reverse-KL（本文）**：
- 学生只需确保高概率动作落在教师高概率区域内
- 优化后：$\pi_\theta \approx \{\text{上}: 0.7, \text{下}: 0.25, \text{左}: 0.03, \text{右}: 0.02\}$
- 结果：熵维持在 ~1.4 bits（健康水平），既果断又有多样性

**奖励计算示例**（学生采样到"上"）：
```
r_t = -(log(0.7) - log(0.6)) = -(-0.357 - (-0.511)) = -0.154
```
负值较小（接近 0），表示学生与教师对齐良好。

## 4. 工程视角 (Engineering View)

**吞吐/延迟 trade-off**：
- **教师推理开销**：每个状态需查询教师 logits（额外 forward pass）
- **优化**：教师可批量推理；G=2 时性能已接近 G=8（§4.4），可降成本
- **环境交互**：仍需 on-policy 采样，但样本效率比 GRPO 高 3x（LIBERO-Long 上 50 步 vs 150 步达 80% 成功率）

**部署约束**：
- **教师可用性**：需预训练专家模型（论文用 SimpleVLA-RL）；若无可用的教师，需先训练单任务策略
- **内存**：无需 value network（critic），比标准 Actor-Critic 节省显存
- **收敛步数**：LIBERO 上 ~50-100 步可达 90%+ 成功率；RoboTwin2.0 双臂任务需更多步

**量化/抖动考虑**：
- 论文未明确讨论量化；但蒸馏框架理论上支持量化教师→学生
- 动作空间为连续时（如 7-DoF 机械臂），logits 替换为高斯分布参数

**工程含义**：
- **适用场景**：有教师模型 + 需快速适配新任务 + 担心 SFT 遗忘
- **不适用场景**：无教师可用 + 纯离线数据充足 + 任务极简单

## 6. 能力与失败模式 (Capabilities & Failure Modes)

**能做什么**：
- ✅ 用极少演示（1-traj）快速适配新任务
- ✅ 在 OOD 状态主动纠错（on-policy 暴露分布偏移）
- ✅ 保留预训练通用能力（抗灾难性遗忘）
- ✅ 扩展到复杂形态（双臂协调 RoboTwin2.0 验证）

**不能做什么**：
- ❌ 无教师模型时无法使用（需预训练专家或单任务策略）
- ❌ 仍需环境交互（虽比纯 RL 少 3x，但非纯离线）
- ❌ 未验证跨机器人形态迁移（如从单臂到人形）
- ❌ 未测试长 horizon 任务（LIBERO-Long 最长 ~100 步）

### 6.1 隐含假设 (Hidden Assumptions)

**X-Ray 批判视角**：
1. **教师可访问性**：假设存在高质量教师模型（开源 checkpoint / API / 单任务策略）。若教师本身有偏，学生会继承偏差。
2. **状态可重复查询**：假设教师可在学生访问的任意状态 s_t 提供 logits。若教师训练数据分布与学生 OOD 状态差距过大，教师预测可能不可靠。
3. **环境可重置**：on-policy 采样需能重置环境到初始状态。真实机器人场景中重置成本高。
4. **动作空间离散化**：论文实验用离散动作（或连续动作离散化表示）。纯连续动作空间下的反向 KL 实现细节未详述。
5. **单教师假设**：未探索多教师蒸馏（如集成不同专家）。
