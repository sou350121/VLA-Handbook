### 1.2 关键机制 (Key Mechanism)

**为什么用 SDE 而非 ODE？**
- ODE 确定性轨迹 collapse 到窄流形，无法发现多样化解
- SDE 注入结构化噪声，强制模型探索专家轨迹相邻状态
- 关键洞察：更宽探索空间需要更细粒度监督来 anchor

**为什么用步级监督而非终端监督？**
- 终端 x0 监督在 SDE 下导致高方差梯度（噪声沿去噪路径累积）
- 步级 xt- 监督提供局部低方差梯度，匹配具身控制的短去噪路径约束
- 实践可行性：具身控制通常用 K=10-20 步短路径，步级监督计算开销可接受

**为什么用对比排序而非加权 MSE？**
- 加权 MSE 包含隐式分离惩罚项 ||dt||²，抑制分支分离从而抑制策略更新
- 对比排序只保留方向对齐信号，实现双向推拉动态（成功时拉正分支推负分支，失败时相反）

⚡ **Eureka Moment**：**更宽探索空间必须匹配更细粒度监督**——SDE 扩展了行为流形，但粗粒度终端监督无法纠正累积偏差；步级监督用方差归一化的局部梯度实现鲁棒对齐。

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：

```
L_total = softplus(½·y·(E⁺ - E⁻)) + λ_TR·||Δv||²
```

**目标**：最大化成功轨迹的似然比，最小化失败轨迹的似然比

**公式拆解**：

| 符号 | 含义 | 来源 |
|------|------|------|
| y = 2r-1 | 奖励标签转换 (r∈{0,1} → y∈{-1,1}) | §4.2 |
| E⁺, E⁻ | 正负镜像分支的方差归一化步级误差 | Eq.6 |
| ΔE = E⁺ - E⁻ | 误差差，正比于 log 似然比 | Lemma 4.2 |
| softplus(z) = log(1+e^z) | 平滑 hinge 损失 | §4.2 |
| λ_TR·||Δv||² | Trust region 正则，防止过大更新 | Algorithm 1 |

**误差计算** (代码块形式):
```
E⁺ = ||xt- - μ⁺_θ,t||²_Σt⁻¹   (马氏距离，Σt⁻¹ 归一化)
E⁻ = ||xt- - μ⁻_θ,t||²_Σt⁻¹
```

**镜像分支构造** (代码块形式):
```
v⁺_θ = (1-β)·vold + β·vθ   (正分支，沿更新方向偏移)
v⁻_θ = (1+β)·vold - β·vθ   (负分支，对称偏移)
```

**直觉**：
- y=+1（成功）时，最小化损失要求 E⁺ < E⁻，即正分支比负分支更好地拟合观测转移
- y=-1（失败）时，要求 E⁺ > E⁻，即负分支更好地拟合
- 这等价于调整构造的转移似然比 log(q⁺/q⁻) 以匹配 episode 标签

> 符号与本文/相关文档保持一致：v 表示 velocity field（流匹配的速度场预测），xt 表示去噪时间 t 的状态，xt- 表示下一步状态（t- = t - δt）

## 3. 带数字走一遍：玩具例子 (Worked Example)

假设一个简化的 2D 动作空间场景：

**设定**：
- 机器人需要抓取物体，动作 a = (x, y) ∈ R²
- 当前去噪步 t=0.5，状态 xt = (0.5, 0.5)
- 去噪步长 δt = 0.1，下一步 t- = 0.4
- 噪声调度 σt = 0.3，协方差 Σt = σt²·I = 0.09·I

**Rollout 阶段**：
```
vold = πθ_old(c, s, xt, t) = (0.1, -0.05)  # 旧策略预测的速度场
```

用 Flow-SDE 采样下一步：
```
xt- = xt + [vold + σt²/(2t)·(xt + (1-t)·vold)]·(-δt) + σt·√δt·ε
    = (0.5, 0.5) + [ (0.1, -0.05) + 0.09/(2·0.5)·((0.5, 0.5) + 0.5·(0.1, -0.05)) ]·(-0.1) 
      + 0.3·√0.1·ε
    ≈ (0.49, 0.51) + 噪声项  (假设 ε=(0.1, -0.2)，则 xt- ≈ (0.499, 0.491))
```

执行动作后获得终端奖励 r=1（成功抓取），则 y = 2·1 - 1 = +1

**优化阶段**：
```
vθ = πθ(c, s, xt, t) = (0.12, -0.03)  # 当前策略预测
Δv = vθ - vold = (0.02, 0.02)
β = 1.5  # trust region 超参

v⁺_θ = (1-1.5)·vold + 1.5·vθ = (-0.5)·(0.1, -0.05) + 1.5·(0.12, -0.03)
     = (-0.05, 0.025) + (0.18, -0.045) = (0.13, -0.02)

v⁻_θ = (1+1.5)·vold - 1.5·vθ = 2.5·(0.1, -0.05) - 1.5·(0.12, -0.03)
     = (0.25, -0.125) - (0.18, -0.045) = (0.07, -0.08)
```

计算转移均值（简化，忽略漂移项）：
```
μ⁺ ≈ xt + vold·(-δt) + v⁺_θ·δt 的线性组合 ≈ (0.495, 0.505)
μ⁻ ≈ 类似计算 ≈ (0.485, 0.515)
```

计算方差归一化误差：
```
E⁺ = ||xt- - μ⁺||²_Σt⁻¹ = ||(0.499, 0.491) - (0.495, 0.505)||² / 0.09
   = ||(0.004, -0.014)||² / 0.09 = (0.000016 + 0.000196) / 0.09 ≈ 0.0024

E⁻ = ||xt- - μ⁻||²_Σt⁻¹ = ||(0.499, 0.491) - (0.485, 0.515)||² / 0.09
   = ||(0.014, -0.024)||² / 0.09 = (0.000196 + 0.000576) / 0.09 ≈ 0.0086

ΔE = E⁺ - E⁻ = 0.0024 - 0.0086 = -0.0062
```

计算损失：
```
L = softplus(½ · y · ΔE) = softplus(½ · 1 · (-0.0062)) 
  = softplus(-0.0031) = log(1 + e^(-0.0031)) ≈ 0.049
```

梯度更新（简化）：
```
∂L/∂θ ∝ σ(zt) · y · (∂vθ/∂θ)ᵀ · Bt · Σt⁻¹ · et
其中 et = xt- - μ_old ≈ (0.009, -0.019) 是 rollout 残差
```

**关键观察**：
- E⁺ < E⁻ 说明正分支更好地拟合了观测转移
- y=+1 时损失鼓励这种差异（ΔE 为负时 softplus 值小）
- 梯度方向会推动 vθ 更接近 v⁺_θ，即沿 Δv 方向更新

## 4. 工程视角 (Engineering View)

| 工程维度 | π-StepNFT | PPO | GRPO | 含义 |
|----------|-----------|-----|------|------|
| 前向次数/优化步 | 1 | 多（critic + policy） | 多（多采样） | π-StepNFT 计算开销最低 |
| 内存占用 | 低（无 critic） | 高（critic 网络） | 中 | 适合单 GPU 部署 |
| 采样吞吐 | 高（RLinf 共置） | 中 | 中 | 环境 + rollout + actor 同 GPU |
| 去噪步数 K | 10-20（短路径） | N/A | N/A | 具身控制延迟约束 |
| 更新频率 | 每 episode 后 | 每 batch | 每 batch | 在线学习 |
| 超参敏感度 | 中（β, σ, α） | 高（clip, λ） | 中 | 需动态 decay 调度 |

**部署约束**：
- **短去噪路径**：K=10-20 步是实践 sweet spot，更长路径收益递减（论文引用 Chen et al., 2025）
- **单 GPU 共置**：RLinf 框架要求环境、rollout 策略、actor 在同一 GPU，适合 8×H100 或 8×4090 配置
- **VLM 骨干冻结**：只微调 action expert（~300M 参数），骨干（PaliGemma-3B）冻结以节省显存

**Trade-off**：
- **探索宽度 vs 监督粒度**：σ 太大导致收敛困难，太小限制探索；β 在 [1.0, 2.0] 最优
- **更新激进 vs 稳定**：动态 decay α（0.9 → 0.995）平衡初期加速和后期稳定
- **稀疏奖励 vs 稠密价值**：稀疏二元信号训练更稳定，但长 horizon 任务 credit assignment 弱于 PPO

3. **对 critic-free RL 感兴趣的方法研究者**：§4.4 对比 Diffusion-NFT 的 weighted-MSE，Theorem 4.5 证明隐式惩罚项存在，理论扎实
