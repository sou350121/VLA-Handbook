### 1.2 关键机制 (Key Mechanism)

**机制一：Outcome-Balanced PPO（OB-PPO），两段式**

1. **难点感知的 advantage 分配（DAA）**：用每个任务成功率的 EMA 构造有界权重 w_k，只乘到该任务的**正 advantage**上；负 advantage 此阶段不动。目的是把正学习信号从「已经会做的任务」挪一部分给「还不会做的任务」。
2. **保号的配对 advantage 归一化**：把一批里正、负 advantage 两组分别缩放到相同的平均绝对幅值 m，符号逐一保留。这一步在 DAA 之后做，因此正样本跨任务的相对权重不变。

**机制二：策略诱导的 flow rectification（周期性阶段）**

当测得的 SDE-ODE 边缘差异超过阈值 γ 时：冻结当前策略快照 θ_ref → 用确定性 ODE 从 t=1 采样到 t=0，收集端点对 (o_i, X_0^i, X_1^i) → 在这些固定对上以线性桥为目标做条件 flow matching → 得到 θ_rec → 恢复 PPO。要点是：**不是让策略迁就旧几何，而是让几何跟上策略**。

⚡ **Eureka Moment**：Flow-SDE 的 score 近似建立在「线性插值路径」这一几何假设上；RL 更新可能改变速度场，使该假设不再严格成立、降低原 score 近似的准确性。与其加正则把策略按在原地（可能压制任务适应），不如周期性用策略自己的 ODE 端点对重建线性桥，以提高 score 近似与当前策略的兼容性；实际效果需实证检验。

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**：

```
advantage：先按任务成功率重加权正样本，再按符号分组等幅缩放
速度场：按当前策略的 ODE 端点对，周期性重拟合 linear-bridge flow
```

**目标一：flow matching 预训练。** 线性插值路径与目标速度：

```
x_t = t·x_1 + (1-t)·x_0,   v_target = x_1 - x_0
L(θ) = E_{t, x_0, x_1} [ || v_θ(x_t, t, c) - v_target ||² ]
```

**目标二：SDE 构建与 score。** 与概率流 ODE 同边缘的 SDE：

```
dx_t = ( v_θ(x_t,t,c) - (σ_t²/2) ∇log p_t(x_t) ) dt + σ_t dω
```

在线性路径假设下，score 有闭式：

```
∇log p_t(x_t) = - x_t / t - ((1-t)/t) · v_θ(x_t, t, c)
```

**目标三：离散化后的高斯转移与 PPO。** Euler–Maruyama 给出：

```
x_{t_{k-1}} ~ N( μ_θ(x_{t_k}, t_k),  σ_{t_k}² Δt_k I )
μ_θ = x_{t_k} + [ v_θ + (σ_{t_k}²/(2 t_k)) (x_{t_k} + (1-t) v_θ) ] Δt_k
```

轨迹似然可分解为转移似然之积；把转移级重要性比代入 clipped PPO：

```
L_PPO = - E[ min( r_k(θ)·Â_k,  clip(r_k(θ), 1-ε, 1+ε)·Â_k ) ]
r_k(θ) = π_θ(x_{t_{k-1}}|x_{t_k},c) / π_{θ_old}(x_{t_{k-1}}|x_{t_k},c)
```

**目标四：OB-PPO 的两段变换。**

```
# DAA（只作用于正 advantage）
s_k^{(n)} = β·s_k^{(n-1)} + (1-β)·ŝ_k^{(n)},   s_k^{(0)} = 0
w̃_k = max(1 - s_k^{(n-1)}, ε)
w_k = clip( w̃_k / ( (1/K)·Σ_j w̃_j ),  w_min,  w_max )
A_{k,i}^{+} ← w_k · A_{k,i}^{+},   A_{k,i}^{-} ← A_{k,i}^{-}

# 配对 advantage 归一化
m_+ = (1/|B^+|)·Σ_{i∈B^+}|A_i|,   m_- = (1/|B^-|)·Σ_{i∈B^-}|A_i|
m   = (1/|B|)·Σ_{i∈B}|A_i|
Ã_i = A_i·(m/m_+)  (A_i>0)
Ã_i = A_i·(m/m_-)  (A_i<0)
Ã_i = 0           (A_i=0)
```

**目标五：rectification 损失。**

```
C_{θ_ref} = { (o_i, X_0^i, X_1^i) }_{i=1}^N,   X_0 = F_{θ_ref}(o, X_1), X_1 ~ N(0,I)
X̃_t^i = (1-t)·X_0^i + t·X_1^i,   u_i* = dX̃_t^i/dt = X_1^i - X_0^i
L_rect(θ) = E[ || M ⊙ ( v_θ(X̃_t, t, o) - (X_1 - X_0) ) ||₂² / ||M||₁ ]
```

> 符号与本文保持一致：`c` 为观察–语言上下文；`x_1` 为噪声端点，`x_0` 为动作端点；`σ_t` 为噪声幅度；`ε`（PPO 里）为 clip 系数，`ε`（DAA 里）为 `1e-6` 的下限，两者数值不同、请勿混用；`M` 为动作子空间选择掩码，`||M||₁` 用于归一化。

**直觉**：score 近似是对「线性路径」这一个几何事实求导得到的；RL 改动 v_θ 后，该线性路径假设可能不再严格成立，原 score 近似对当前策略诱导分布的准确性可能下降；若仍用旧 score 计算 PPO 似然，训练分布（SDE）与部署分布（ODE）的差异可能扩大。rectification 定期从当前策略采样确定性 ODE 端点对，用这些对重定义线性桥，目标是提高下一次 score 近似与当前策略的兼容性；实际效果需由实验检验。

## 3. 带数字走一遍：玩具例子 (Worked Example)

> 以下为**假设数值**，仅用于演示两个变换的算术，不代表论文实验；每一步都已重新验算。

**场景**：一批 4 个样本，advantage 经 DAA 之前为 `A = [+2.0, +1.0, +0.5, -3.0]`。假设 DAA 已经把它们乘成 `A' = [+2.0, +1.0, +0.5, -3.0]`（即本玩具例中 DAA 暂视为恒等映射，以单独考察配对归一化）。

计算分组均值：

```
B^+ = {1,2,3},  m_+ = (2.0+1.0+0.5)/3 = 1.1667
B^- = {4},      m_- = 3.0
m = (2.0+1.0+0.5+3.0)/4 = 1.625
```

缩放：

```
Ã_1 = 2.0 × (1.625/1.1667) ≈ 2.786
Ã_2 = 1.0 × 1.3929        ≈ 1.393
Ã_3 = 0.5 × 1.3929        ≈ 0.696
Ã_4 = -3.0 × (1.625/3.0)  = -1.625
```

校验：正组平均绝对值 `(2.786+1.393+0.696)/3 = 1.625 = m` ✅；负组绝对值 `1.625 = m` ✅；符号逐一保持 ✅。

**对照标准批归一化**：`μ_B = 0.125`，`σ_B ≈ 1.883`，得到 `[+0.995, +0.465, +0.199, -1.660]`。正组平均绝对值约 `0.553`，负组约 `1.660`——负组幅值仍是正组的约 3 倍，符号条件不均衡没有被修正。若把样本换成 `[+0.5, +0.1, +0.05, -0.3]`，则 `μ ≈ 0.0875`，`+0.05` 会被归一化成约 `-0.13`，**正 advantage 变号**——这正是论文 §4.2.2 指出的「一个低于批均值的正 advantage 可能被改号」的问题。

**DAA 数值走一遍**：两任务，`β=0.9`，`w_min=0.75`，`w_max=1.25`。若 `s_A=0.9`、`s_B=0.1`，则 `w̃_A = 0.1`、`w̃_B = 0.9`，归一化后 `w_A = 0.2`、`w_B = 1.8`，clip 后 `w_A = 0.75`、`w_B = 1.25`。于是难任务 B 的正 advantage 被放大 1.25 倍、易任务 A 的被压缩到 0.75 倍，负 advantage 不动。

### 5.3 真实机器人设置

- 任务：FR3 机械臂 + 两指夹爪，把胡萝卜（约 145 mm，50 g）放进浅红盘（外径约 156 mm，内径约 152 mm）。
- 相机：固定前置 Orbbec，640×480 RGB。
- Real2Sim2Real 管线：从工作区照片/视频、录制的策略相机帧与实测尺寸构造 ManiSkill/SAPIEN 场景；FR3 关节配置；胡萝卜与盘子的尺寸匹配碰撞体；胡萝卜叶只影响外观。
- 重置分布：盘子固定，胡萝卜沿桌面两轴各 ±40 mm 随机、yaw 随机。
- 稀疏奖励：双边抓取 + 抬升 ≥ 30 mm + 释放并接触盘子 + 手臂近乎静止；放置判据允许胡萝卜本体最多超出盘子内半径 40 mm。
- 训练：1,000 次 SFT → 两分支 RL。标准分支用 RLinf 的 Flow-SDE PPO + GAE，训练 100 epochs；VLM 冻结，优化 action expert 与 critic。修改分支 = 配对 advantage 归一化 + 失败状态回放。
- 评测：每个 RL checkpoint 评 100 次物理试验，同一胡萝卜/盘子位置范围、同一成功判据、同一部署模式。

> 注意：真实机器人实验评估的是**配对 advantage 归一化 + 失败状态回放**的组合，不是完整的 OB-PPO（缺 DAA），也没有启用 rectification。因此 32%→43% 不能归因于完整框架；论文作者在 §5.3 末尾也明确写了这是「combination」的评估。

## 6. 能力与失败模式 (Capabilities & Failure Modes)

**能做**：在 π0.5 骨干上，将 SDE 在线 RL 的训练信号更均匀地分配给难任务和正/负 advantage 两组；周期性刷新 velocity field，使 SDE 训练分布更贴近 ODE 部署分布；这些组件可以插入既有 Flow-SDE PPO 管线，不改 PPO clipping。

**不能做**：
- 不改变轨迹采样方式、clipping 规则、reward 设计；奖励函数仍是稀疏任务成功判据，作者没有给出 reward shaping 方案。
- rectification 的收益只建立在仿真（表 3：LIBERO 98.1 vs 96.5 等），真实机器人上未启用。
- 没有显式记忆机制；不能据此推断跨 episode 或跨任务的知识保留与迁移。
- 没有开放代码/数据，复现成本高。

### 6.1 隐含假设 (Hidden Assumptions)

1. **线性路径假设成立**：公式 (4) 的 score 近似假设 x_t 落在连接 x_0 与 x_1 的直线上。rectification 只是周期性把这条直线「重新对准」当前策略，并没有证明两次 rectification 之间该假设仍近似成立。
2. **成功率 EMA 是任务难度的一个好代理**：DAA 的权重只依赖成功率，不区分任务类型、动力学难度或稀疏程度；若某任务成功率长期为 0，`1-s` 趋近 1，可能过度加权一个本就不可学的任务。
3. **配对归一化的分组足够大**：`m_+` 与 `m_-` 在批内样本很少（例如负 advantage 只有一两个）时是高方差估计；论文未给出批大小敏感性。
4. **固定 γ 阈值跨基准可迁移**：γ=0.003 在 LIBERO 与 ManiSkill 上最优，但两个基准的最优值恰好一致，作者未在 CALVIN/MetaWorld 上扫描；跨基准迁移性未验证。
5. **冻结 VLM 不损失适应能力**：所有任务共享同一个冻结多模态表示；若新任务的视觉或语言分布显著偏移，action expert 端无法通过更新 VLM 来补救。

## 7. 与相关工作对比 (Comparison)

| 方法 | 关注点 | 架构/训练方式 | 与本文关系 |
|------|--------|----------------|------------|
| π_RL (Chen et al., 2026) | 把 ODE-SDE 公式扩到 flow VLA 的在线 RL | Flow-SDE PPO 基线 | 本文直接基线；表 1 中本文平均高 +2.3 p.p. |
| Flow-GRPO (Liu et al., 2025a) | 可处理的 flow 在线 RL | SDE 同边缘构造 + 线性路径 score | 本文的数学起点；本文指出 RL 更新会改变速度场，可能降低原 score 近似对当前策略诱导分布的准确性，rectification 旨在提高兼容性，实际效果需实证检验 |
| ReFPO (Wang et al., 2026) | 用 reflow 正则约束 flow | 在 FPO 目标中加 λ·L_reflow，联合更新 | 本文在 π_RL 基线上实现 ReFPO-inspired joint reflow 作对照（表 3）：联合目标平均 84.7%，分离阶段平均 87.6%；表 1 的实际 ReFPO 为 83.5% |
| FPO (McAllister et al., 2026) | 从条件 flow matching 直接推策略梯度 | 不显式评估 flow 密度 | 本文未直接对比 FPO，只在 ReFPO 语境中引用 |
| BAPO (Xi et al., 2026) | 正负样本贡献不平衡 | 自适应 clipping 边界 | 本文对照（表 4）：共享 DAA 时配对归一化平均 88.3% vs BAPO 式 85.9% |
| ReinFlow (Zhang et al., 2025b) | 可学习噪声注入 | 离散时间随机过程 | 相关工作，本文未直接对比 |
| AWR/AWAC/ARFM | 正 advantage 加权回归 | 正权重回归/最大似然更新 | 论文 §2 区分：这些方法只调正权重，不做带符号的 PPO 梯度 |

**面试 Tip**：如果被问「这篇和 ReFPO 有什么区别」，一句话答——ReFPO 把 reflow 损失塞进策略梯度里联合训练（λ 控制权衡）；本文把重建单独做成一个暂停 PPO 的阶段，用当前策略的 ODE 端点对重拟合，理由是「联合更新时重建目标和策略目标互相牵制」，论文表 3 的数字支持这一说法（同一基线上 84.7% vs 87.6%）。

## 8. 精读建议 (Reading Guide)

- **值得精读原文的人**：
  1. 正在把在线 RL 用到 flow-matching VLA、且已经跑通 Flow-SDE PPO 的研究者——重点看 §4.1 与 §4.2 的公式和表 2 的消融顺序。
  2. 要做「训练/部署采样器一致性」监控的工程团队——重点看 §4.1 的触发条件与表 5 的 γ 间隔数据。
  3. 做稀疏多任务 advantage shaping 的研究者——重点看 §4.2.2 的配对归一化与表 4 的 BAPO 对比。
- **建议章节路径**：先读 §3 Preliminaries（公式 1–5 是全文基础）→ §4.1 + §4.2（两个机制）→ §5.2 表 2 + 表 3（为什么分离比联合好）→ §5.3（真实机器人边界条件）。§2 相关工作可按需跳读，它主要用于定位与其他方法的差异。
- **不值得精读的理由**：若你不做 flow-matching 策略、不做 VLA、或只做离线模仿学习，摘要加表 1 足够；若你已经熟悉 Flow-GRPO 的 SDE 构造，§3 可跳读；若你只关心真实机器人泛化，本文的真实实验只覆盖桌面单任务、单一 FR3 平台、单一相机位姿，不作为泛化性证据。
