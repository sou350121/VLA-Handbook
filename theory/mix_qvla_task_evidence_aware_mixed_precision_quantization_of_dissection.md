### 1.2 关键机制 (Key Mechanism)

Mix-QVLA 的核心创新在于**重新定义"什么是量化敏感度"**：

- **传统方法（QVLA 等）**：量化层 m 到 b bit → 比较输出动作 a_quantized vs a_full_precision → 动作偏差大的层 = 敏感层
- **Mix-QVLA**：量化层 m 到 b bit → 比较四个功能边界上的**任务证据图**（gradient-weighted evidence maps）→ 证据质量偏移 + 证据分布偏移 = 敏感度

关键洞察：动作偏差小 ≠ 内部决策路径完好。量化可能让模型"走到正确的终点但走了错误的路"——这在闭环策略中尤其危险，因为错误的内部证据会导致后续观察的 grounding 偏差累积。

**四个功能边界**：
1. **ν (nu)** — 视觉编码器输出（视觉 grounding）
2. **β (beta)** — 投影层输出（视觉-语言对齐）
3. **ψ (psi)** — 语言策略表示（多模态推理）
4. **α (alpha)** — 动作头表示（决策形成）

⚡ **Eureka Moment**：量化敏感度不应只看"终点偏差"（动作），而应度量"路径完整性"（任务证据在四个功能边界上的保留程度）——因为 VLA 是闭环策略，内部证据的扭曲会在时间上累积放大。

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：
```
Ω(m,b) = avg_i [ κ·log( avg_γ exp(ℓ_ev(m,b)/κ) ) ]
其中 ℓ_ev = |log(M_quant/M_fp)| + λ·JS(P_fp || P_quant)
```

**目标**：度量量化层 m 到 b bit 时对全精度决策证据路径的破坏程度。破坏越大 → 该层越需要保留高精度。

**公式分解**：

**步骤 1：参考决策固定**
```
y_i* = (y_{i,1}*, ..., y_{i,K}*)   ← θ_FP 生成的动作 token 序列（固定不变）
J_i(θ; y_i*) = (1/K) Σ_k log p_θ(y_{i,k}* | y_{i,<k}*; z_i)   ← teacher-forced log-prob
```

**步骤 2：边界任务证据图**
```
E_{i,γ}^θ = | Z_{i,γ}^θ ⊙ ∇_{Z} J_i(θ; y_i*) |
其中 Z = (H - μ_FP) / (σ_FP + ε)   ← 用 FP 统计量归一化
```
- 激活项 |Z| 标识边界表示中活跃的特征
- 梯度项 ∇J 标识这些特征对支持 FP 决策的影响力
- 两者逐元素相乘 → 同时"活跃且重要"的特征 = 任务证据

**步骤 3：证据扭曲度量**
```
Δ_mass = | log( (M_quant + ε) / (M_fp + ε) ) |    ← 证据总量变化
Δ_attr = JS( a_fp || a_quant )                      ← 证据分布重分配
ℓ_ev(m,b) = Δ_mass + λ·Δ_attr                        ← 边界级损失（λ=1）
```
- M = (1/d) Σ_j E_j — 证据质量（平均证据强度）
- a_j = (E_j + ε) / Σ(E + ε) — 归一化证据分布
- JS divergence 度量分布偏移，即使总证据量不变也能检测到

**步骤 4：Soft-bottleneck 聚合（跨边界）**
```
L_i^SB(m,b; κ) = κ·log( (1/|Γ|) Σ_γ exp(ℓ_{i,γ}^ev(m,b) / κ) )
```
- κ→0 时趋近 max（瓶颈边界主导）
- κ=0.1 时接近瓶颈但数值平滑
- 比简单平均更好：一个边界严重退化不会被其他边界"稀释"

**步骤 5：全局 + 时间敏感度**
```
Ω(m,b) = (1/N) Σ_i L_i^SB(m,b; κ)                    ← 全局敏感度
Ω_τ(m,b) = max_q Ω_q(m,b)                            ← 时间敏感度（最差阶段）
```

**步骤 6：ILP 比特分配**
```
min Σ_{m,b} x_{m,b} [α·Ω(m,b) + β·Ω_τ(m,b)]
s.t. Σ_b x_{m,b} = 1 ∀m                              ← 每层恰好一个 bit-width
     Σ_{m,b} x_{m,b}·N_m·b ≤ C_size_target           ← 模型大小预算
     Σ_{m,b} x_{m,b}·MACs(m)·b² ≤ C_bitops_target    ← BitOps 预算
```

> 符号与本文保持一致：θ_FP=全精度模型, θ_{m,b}=量化层m至b bit的变体, Γ={ν,β,ψ,α}=四个功能边界, κ=soft-bottleneck温度, λ=证据分布权重, α/β=全局/时间敏感度权重, x_{m,b}=二元分配变量

## 3. 带数字走一遍：玩具例子 (Worked Example)

假设一个简化场景：单层量化评估，层 m 被量化到 4-bit，在 3 个校准样本上运行。

**样本 1**（τ=28，轨迹早期）：
```
FP 边界证据质量: M_ν=0.50, M_β=0.45, M_ψ=0.40, M_α=0.35
W4 边界证据质量: M_ν=0.48, M_β=0.44, M_ψ=0.30, M_α=0.34

Δ_mass: ν=|log(0.48/0.50)|=0.041, β=0.022, ψ=0.288, α=0.029
Δ_attr: ν=0.015, β=0.012, ψ=0.180, α=0.010
ℓ_ev:   ν=0.056, β=0.034, ψ=0.468, α=0.039

Soft-bottleneck (κ=0.1):
L^SB = 0.1·log( (exp(0.56) + exp(0.34) + exp(4.68) + exp(0.39))/4 )
     = 0.1·log( (1.75 + 1.40 + 107.8 + 1.48)/4 )
     = 0.1·log(28.1) = 0.1·3.34 = 0.334
```
→ ψ 边界（语言策略表示）的退化主导了总分，因为 exp(4.68) 远大于其他。

**样本 2**（τ=85，轨迹晚期）：
```
ℓ_ev: ν=0.030, β=0.025, ψ=0.150, α=0.080
L^SB = 0.1·log( (exp(0.30)+exp(0.25)+exp(1.50)+exp(0.80))/4 )
     = 0.1·log( (1.35+1.28+4.48+2.23)/4 )
     = 0.1·log(2.34) = 0.1·0.85 = 0.085
```
→ 晚期阶段 ψ 退化减轻，但 α（动作头）敏感度上升。

**样本 3**：L^SB = 0.120

```
Ω(m, 4) = (0.334 + 0.085 + 0.120) / 3 = 0.180
```

**时间分箱**（假设 Q=4 个阶段）：
```
Bin 1 (ρ∈[0,0.25]): 样本1 → Ω_1 = 0.334
Bin 2 (ρ∈[0.25,0.5]): 样本2 → Ω_2 = 0.085
Bin 3 (ρ∈[0.5,0.75]): 样本3 → Ω_3 = 0.120
Bin 4 (ρ∈[0.75,1]): 空

Ω_τ(m, 4) = max(0.334, 0.085, 0.120) = 0.334
```

**比特分配**（α=0.75, β=0.25）：
```
综合分数 = 0.75·0.180 + 0.25·0.334 = 0.135 + 0.084 = 0.219
```
如果另一层 m' 的综合分数只有 0.050，则 m 会被分配更高 bit-width。

## 4. 工程视角 (Engineering View)

| 维度 | 数值 | 工程含义 |
|------|------|----------|
| FP 模型大小 | 15.2-15.4 GB | OpenVLA 7B 在 BF16 下的基线 |
| W4A4 Mix-QVLA | 4.0-4.1 GB | **73% 压缩**，可在 8GB Jetson Orin 上运行 |
| W8A8 Mix-QVLA | 6.6-6.7 GB | 适合 16GB GPU 部署 |
| 推理加速 | 1.39-1.52x | W4A4 下最高 1.52x，来自低 bit 计算和内存带宽节省 |
| 校准开销 | 需前向+反向传播 | 比 QVLA（仅前向动作偏差）成本高；但一次性离线完成 |
| 部署开销 | 零额外开销 | 分配固定后推理无时间步切换 |
| 优化求解 | CVXPY + ECOS_BB | ILP 求解器，层数多时可能慢（但量化层数通常可控） |

**关键 trade-off**：
- **证据敏感度 vs 动作敏感度**：证据方法需要反向传播（计算 ∇J），动作方法只需前向。但证据方法能发现动作方法遗漏的内部退化（论文图 2a 显示语言模块证据损失最大但动作误差较小）。
- **固定分配 vs 动态切换**：Mix-QVLA 校准后分配固定，不运行时切换。这简化了部署但放弃了根据任务阶段动态调整精度的可能性（DyQ-VLA 的方向）。
- **软瓶颈 vs 硬瓶颈**：κ=0.1 接近 max 但不完全等于 max。这避免了极端值主导同时保留了对瓶颈边界的敏感性。

## 6. 能力与失败模式 (Capabilities & Failure Modes)

### 能做什么
- **在 OpenVLA 系列上实现最优精度-效率权衡**：W4A4 下比 QVLA 内存更低、成功率相当或更高
- **诊断量化对内部决策路径的影响**：证据图可视化可定位哪些功能边界受量化影响最大
- **时间维度敏感度分析**：区分"始终脆弱"的层和"仅在特定阶段敏感"的层
- **部署友好**：分配固定，推理无额外开销

### 不能做什么
- **跨架构泛化未验证**：仅在 OpenVLA 上测试，对 π0、GR00T、RDT 等架构未知
- **真实机器人部署未验证**：LIBERO 仿真 ≠ 真实世界（仿真-现实差距可能放大量化误差）
- **运行时动态精度切换**：分配在校准后固定，不能根据任务阶段动态调整
- **因果保证**：证据图是诊断信号，不是任务成功的因果保证（论文 §5 明确承认）

### 6.1 隐含假设 (Hidden Assumptions)

1. **校准数据代表性**：假设 LIBERO 训练集的 demonstration 能覆盖部署时的分布。如果部署任务超出校准分布，证据敏感度估计可能不准确。
2. **FP 决策是"正确"参考**：Mix-QVLA 以 FP 模型的动作 token 序列为参考基准。但如果 FP 模型本身在某些样本上决策错误，保留其证据路径未必是最优目标。
3. **证据保留 ≈ 任务成功**：核心假设是"保留 FP 证据路径 → 保持任务成功率"。但消融实验显示证据-only 设置（75.9%）略低于组合设置（76.3%），说明证据保留与任务成功并非完全等价。
4. **软瓶颈温度 κ=0.1 普适**：论文在所有实验中固定 κ=0.1，未探索不同模型/任务下的最优值。
5. **ILP 求解器可扩展**：ECOS_BB 在层数多时可能求解缓慢，论文未讨论大规模层的求解时间。
