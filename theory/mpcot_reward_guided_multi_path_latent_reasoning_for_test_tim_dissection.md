### 1.2 关键机制 (Key Mechanism)

MPCoT 的核心设计围绕三个组件：

1. **潜在假设初始化**：从同一个融合上下文 c_t 出发，通过可学习的假设编码 e_m 和训练时扰动 ε_t,m，初始化 M 个并行的潜在假设 z_t,m^(0)。所有路径从相同的感知-语言证据出发，差异来自潜在控制假设的专门化。

2. **权重共享多步精炼**：对每个路径，用同一个精炼算子 F_θ 迭代 K 步。每一步对当前潜在状态做 LayerNorm 后与上下文 c_t 拼接，预测一个修正方向 r_t,m^(k)，然后以残差方式更新。权重共享意味着增加 K 只增加计算量，不增加参数量。

3. **置信度软聚合**：K 步精炼后，轻量评分器 h_ω 对每个分支打分，softmax 得到选择概率，用这些概率作为权重对所有分支做加权平均，得到聚合后的潜在表示 z̄_t，送入原有策略头解码动作。

⚡ **Eureka Moment**：VLA 的推理深度不应通过生成文本 token 来实现，而应在连续潜在空间中维护多个假设，用共享权重反复精炼，训练时用奖励信号教会评分器"哪个假设更可能成功"，推理时评分器就是执行质量的代理——完全不需要奖励或外部评估器。

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：
```
z̄_t = R_θ(o_t, l; K, M)    →    a_t ~ π_0(a | z̄_t)
     ↑ 多路径潜在推理          ↑ 原有策略头（不变）
```

### 目标 → 公式 → 变量 → 直觉

**目标**：在不改变 VLA 策略接口的前提下，通过测试时可控的潜在计算量提升长视界决策质量。

**核心方程组**：

```
(1) 上下文融合:
    c_t = f_mm(f_v(o_t), f_l(l))

(2) 假设初始化:
    z_t,m^(0) = c_t + e_m + ε_t,m

(3) K 步精炼 (k=1..K):
    r_t,m^(k) = F_θ([LN(z_t,m^(k-1)); c_t])
    z_t,m^(k) = z_t,m^(k-1) + r_t,m^(k)

(4) 评分 + 聚合:
    s_t,m = h_ω(z_t,m^(K))
    p(m|o_t,l) = exp(s_t,m/τ) / Σ_j exp(s_t,j/τ)
    z̄_t = Σ_m p(m|o_t,l) · z_t,m^(K)

(5) 动作解码:
    a_t ~ π_0(a | z̄_t)

(6) 训练损失:
    L = L_BC + λ_RL · L_RL + λ_div · L_div

(7) 复合奖励 (仅训练):
    r_t,m = β_a·r_t,m^act + β_p·r_t,m^prog + β_s·r_t,m^succ
```

**变量说明**：

| 符号 | 含义 |
|------|------|
| o_t | t 时刻的视觉观察 |
| l | 任务指令 |
| c_t | 融合后的潜在上下文，维度 d（跟随 OpenVLA-OFT 的潜在宽度） |
| e_m | 可学习的假设编码，从固定最大路径池中选择 |
| ε_t,m | 训练时小扰动（推理时为 0，确定性推理） |
| K | 精炼步数（深度控制） |
| M | 假设数量（宽度控制） |
| F_θ | 共享权重精炼算子（轻量残差 MLP） |
| h_ω | 两层层路径评分器 |
| τ | softmax 温度 |
| π_0 | 原有策略头（OpenVLA-OFT，不变） |

> 符号与本文保持一致。K=0, M=1 时退化为直接解码（无推理）。M=1 时退化为单路径迭代推理。

**直觉**：把 VLA 的推理看作一个"测试时计算分配"问题——与其一次过就决定动作（浅），或者生成大量文本 token（深但慢），不如在潜在空间里同时维护多个假设，反复精炼，然后让评分器选最靠谱的那个。训练时教评分器怎么选，推理时它自己就能判断。

## 3. 带数字走一遍：玩具例子 (Worked Example)

假设一个简化的 2D 潜在空间（d=2），M=3 个假设，K=2 步精炼。

**Step 0 — 初始化**：
```
c_t = [0.5, 0.3]          # 融合上下文
e_1 = [0.1, 0.0], e_2 = [0.0, 0.1], e_3 = [-0.1, -0.1]  # 假设编码

z_1^(0) = [0.6, 0.3]      # 偏向 x 方向的假设
z_2^(0) = [0.5, 0.4]      # 偏向 y 方向的假设
z_3^(0) = [0.4, 0.2]      # 保守假设
```

**Step 1 — 第 1 步精炼**（假设 F_θ 预测修正方向）：
```
r_1^(1) = F_θ([LN(z_1^(0)); c_t]) = [-0.05,  0.12]
r_2^(1) = F_θ([LN(z_2^(0)); c_t]) = [ 0.08,  0.05]
r_3^(1) = F_θ([LN(z_3^(0)); c_t]) = [ 0.02, -0.03]

z_1^(1) = [0.55, 0.42]    # 修正后
z_2^(1) = [0.58, 0.45]
z_3^(1) = [0.42, 0.17]
```

**Step 2 — 第 2 步精炼**：
```
r_1^(2) = [-0.02,  0.03]
r_2^(2) = [ 0.01,  0.02]
r_3^(2) = [-0.01, -0.01]

z_1^(2) = [0.53, 0.45]
z_2^(2) = [0.59, 0.47]
z_3^(2) = [0.41, 0.16]
```

**Step 3 — 评分 + 聚合**（假设 h_ω 打分）：
```
s_1 = 0.8, s_2 = 1.2, s_3 = -0.3    (τ=1.0)

p(1) = exp(0.8) / (exp(0.8)+exp(1.2)+exp(-0.3)) = 2.23/6.66 ≈ 0.33
p(2) = exp(1.2) / 6.66 ≈ 0.55
p(3) = exp(-0.3) / 6.66 ≈ 0.12

z̄_t = 0.33·[0.53,0.45] + 0.55·[0.59,0.47] + 0.12·[0.41,0.16]
    = [0.556, 0.453]
```

**直觉**：假设 2（z_2）获得了最高评分和权重（0.55），因为它的精炼轨迹最终指向了最合理的动作方向。假设 3 被降级（0.12），因为它偏离了有效区域。聚合后的 z̄_t 是一个"加权共识"，比任何单一假设都更稳健。

## 6. 能力与失败模式 (Capabilities & Failure Modes)

### 能做什么
- **长视界序列决策**：CALVIN 5-step SR 提升 16.5 个百分点，误差累积显著降低
- **测试时精度-延迟 trade-off**：通过调整 (K, M) 在不重新训练的情况下改变推理深度
- **与现有 VLA backbone 正交**：插入在融合层和动作头之间，不替换 backbone
- **零推理 token**：相比显式 CoT 快 3-5 倍，同时效果更好

### 不能做什么 / 失败模式
- **真实机器人部署未验证**：实验仅在 LIBERO/CALVIN 仿真环境（论文 §6 Limitations 明确承认）
- **未见过的机器人平台**：未测试 embodiment 变化、传感器噪声、硬件延迟
- **接触丰富场景**：未覆盖需要精细触觉反馈的任务
- **训练依赖 Qwen3-VL**：虽然推理时不需要，但训练时的评估器偏差可能传播到评分器

### 6.1 隐含假设 (Hidden Assumptions)

1. **潜在空间中的多假设能覆盖真实的不确定性**：论文假设 M 个潜在假设足以覆盖决策空间中的关键分歧点，但未验证 M 不够大时的覆盖盲区
2. **共享权重精炼足够表达不同路径的差异化更新**：所有路径用同一个 F_θ，假设不同假设的修正方向可以由同一个算子生成——这可能在高度异构的任务中成为瓶颈
3. **训练时的奖励信号能充分教导评分器**：Path Consistency 从 68.5% 提升到 84.3%——仍有 15.7% 的情况评分器选择了非最优路径
4. **Qwen3-VL 作为进度评分器没有系统性偏差**：冻结的 Qwen3-VL 可能对某些类型的任务或观察有偏好，这种偏差会直接注入评分器
