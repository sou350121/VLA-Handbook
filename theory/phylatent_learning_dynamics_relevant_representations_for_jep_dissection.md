**总参数量**: ~19.6M（含所有训练期辅助头）

### 1.2 关键机制 (Key Mechanism)

PhyLatent的核心设计哲学是：**训练期加约束，推理期零开销**。所有五个辅助组件仅在训练时使用，推理时编码器、预测器和MPC规划器与基线LeWorldModel完全相同。

三个训练通道各自针对一种崩溃模式：

- **物理不变性通道**（SVIC）：对同一物理状态施加亮度/颜色扰动，强制增强视图的表示与原视图接近。使用stop-gradient防止原表示被更新。
- **物理可辨识性通道**（PSG + FRA）：PSG用物理状态标签监督编码和预测分支；FRA通过投影头对齐和动作查询模块进一步约束未来表示的结构。
- **反事实动力学通道**（CASC + LD）：CASC通过batch内动作置换构造反事实动作序列，强制不同动作产生分离的未来分支；LD通过在目标未来上加噪声并训练去噪头来正则化局部几何。

⚡ **Eureka Moment**：全局分布非退化（SIGReg）≠ 局部几何可用——世界模型的潜空间需要显式的局部结构约束才能支持可靠的动作比较和规划。

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：

```
L_PhyLatent = L_pred + 0.09·L_SIGReg
            + λ_inv·L_inv           (物理不变性)
            + λ_state·L_state       (状态锚定)
            + λ_align·(L_proj + L_act)  (未来对齐)
            + λ_sep·L_sep + λ_denoise·L_denoise  (反事实)
```

**目标**: 在JEPA基线预测损失和全局正則化之上，增加五个辅助损失项，分别约束潜空间的三个动力学相关几何属性。

**关键公式拆解**:

```
// 基线预测损失（LeWorldModel已有）
L_pred = MSE(Z_hat, sg(Z^+))

// SVIC: 静态视觉不变性约束
L_inv = d_N(Z_aug, sg(Z))
  // d_N = 归一化MSE（沿特征维度l2归一化后计算）

// PSG: 物理状态锚定
L_state = MSE(H_s(Z), S_bar) + MSE(H_s(Z_hat), S_bar[K+1:T])
  // H_s = 共享状态头，S_bar = z-score标准化的物理状态向量

// FRA: 未来表示对齐（双分支）
L_proj = d_N(phi(Z_hat), sg(phi(Z^+)))
L_act = d_N(Psi(Z_hat, C_ctx^a), sg(Psi(Z^+, C_ctx^a)))
  // Psi = 动作查询模块: LN[MHA(W_q·c_bar^a, W_k·X, W_v·X)]

// CASC: 反事实动作分离
L_sep = (1/|Ω|) · Σ[ m_b,τ - δ_b,τ^z ]_+
  // m_b,τ = min(γ·δ_b,τ^a, m_max)  // 期望分离边界正比于动作差异
  // Ω = 动作差异超过batch中位数的位置集合

// LD: 潜去噪
L_denoise = MSE(epsilon_hat, epsilon)
  // epsilon_hat = D_w(Z_tilde^+, Z_hat, C_den^a, sigma)
```

**变量说明**:

| 符号 | 含义 |
|------|------|
| Z, Z_hat, Z^+ | 编码潜序列、预测潜序列、目标潜序列 |
| d_N | 归一化均方距离（沿特征维度l2归一化后计算MSE） |
| sg | stop-gradient（目标分支不反向传播） |
| H_s | 共享物理状态头（MLP） |
| S_bar | 任务特定的标准化物理状态向量 |
| phi | 共享投影头 |
| Psi | 动作查询模块（MHA，动作作为query，潜序列作为key/value） |
| γ, m_max | CASC的分离比例系数和最大间隙 |
| D_w | 去噪头（接收加噪目标、预测未来、动作嵌入、噪声尺度） |

> 符号与论文保持一致。所有辅助损失仅在训练期生效，推理时仅保留 F_θ 预测器和 MPC 规划器。

## 3. 带数字走一遍：玩具例子 (Worked Example)

假设一个简化的2D潜空间场景，来理解CASC如何工作：

**设置**:
- 当前状态 z_t，两个候选动作 a_1 = [0.1, 0.0]（左移），a_2 = [0.0, 0.1]（右移）
- 真实未来：z_{t+1}^{(1)} = [0.5, 0.0]，z_{t+1}^{(2)} = [0.0, 0.5]
- 真实分支距离：d_true = ||[0.5, -0.5]|| = 0.707

**LeWorldModel（无CASC）的问题**:
- 预测器分别拟合每个分支，但两个预测可能都靠近 [0.25, 0.25]（平均化倾向）
- 预测分支距离：d_pred = 0.2（远小于0.707）
- r_cf = 0.2/0.707 = 0.28 < 0.5 → 触发反事实崩溃

**PhyLatent（有CASC）的修复**:
- 动作差异：δ^a = ||a_1 - a_2|| / sqrt(2) = 0.141/1.414 ≈ 0.1
- 期望分离边界：m = min(γ·0.1, m_max) = min(10·0.1, 2.0) = 1.0
- 当前预测分离：δ^z = ||z_hat^{(1)} - z_hat^{(2)}|| / sqrt(192)
- 如果 δ^z < m，则 L_sep = m - δ^z > 0，推动预测器拉开两个分支
- 经过训练后，预测分支距离接近真实距离，MPC可以可靠地区分"左移好"还是"右移好"

**PSG的玩具例子**:
- 物理状态 s = [cube_x=0.3, cube_y=0.1, gripper_open=1.0]（3维）
- 潜表示 z = [0.12, -0.45, 0.78, ..., 0.03]（192维）
- H_s(z) 输出 3 维预测：[0.31, 0.09, 0.98]
- L_state = MSE([0.31,0.09,0.98], [0.3,0.1,1.0]) = 0.00017
- 这个损失迫使192维潜空间的某些方向编码物理状态信息

## 4. 工程视角 (Engineering View)

| 维度 | 数值/trade-off | 工程含义 |
|------|---------------|----------|
| 模型大小 | 19.6M参数 | ViT-Tiny/14 + 6层Transformer，适合边缘部署 |
| 输入分辨率 | 224×224 | 标准ViT输入，无需特殊预处理 |
| 观察历史 | 3帧 | 短上下文窗口，低延迟但可能丢失长期依赖 |
| 潜维度 | 192 | 相对紧凑，MPC搜索效率高 |
| 训练开销 | 5个辅助头额外计算 | 推理时零开销——所有辅助头可丢弃 |
| 推理延迟 | 与LeWorldModel相同 | 无额外计算，因为辅助头仅在训练期存在 |
| 物理标签需求 | 训练期需要 | 仿真器中易获取；真实世界需状态估计器 |
| MPC规划 | 在潜空间直接进行 | 无需图像生成，规划速度快一个数量级 |

**部署约束**:
- 训练时需要仿真器提供物理状态（如物体位置、关节角度），这限制了在无仿真器真实场景中的直接应用
- 但推理时完全不需要物理状态，只需图像+动作即可
- 潜在方案：先用仿真器训练PhyLatent表示，然后在真实世界用相同的编码器+预测器做MPC

## 6. 能力与失败模式 (Capabilities & Failure Modes)

### 能做什么

- **显著降低三种动力学崩溃率**（Cube上）：
  - 物理不变性崩溃：15.60% → 7.53%（降低52%）
  - 物理可辨识性崩溃：6.71% → 0.95%（降低86%）
  - 反事实动力学崩溃：8.41% → 4.62%（降低45%）
- **跨任务迁移**：在Cube上训练的表示原理（不变性/可辨识性/反事实分离）对TwoRooms（导航任务）同样有效，提升17pp
- **推理零开销**：所有辅助头训练后可丢弃，不增加推理延迟

### 不能做什么 / 失败模式

- **PushT任务未见提升**（77.67% → 75.33%）：论文指出接触丰富的推动任务除了表示质量外，还依赖精确的局部接触过渡和规划目标的几何——PhyLatent的诊断指标改善了但不足以克服接触动力学的复杂性（论文 Appendix C.3）
- **Reacher提升微弱**（+1pp）：可能因为Reacher本身的基线已经较高（78%），提升空间有限
- **依赖物理状态标签**：PSG需要任务特定的物理状态向量作为监督信号，在无仿真器真实场景中难以获取
- **仅评估了4个仿真任务**：没有真实机器人实验，泛化性待验证

### 6.1 隐含假设 (Hidden Assumptions)

- **物理状态标签可获取**：论文假设训练期有仿真器提供精确的物理状态。在真实世界中，这需要额外的状态估计器（如视觉追踪、力传感器），增加了系统复杂度
- **外观扰动足以模拟不变性挑战**：SVIC仅使用亮度和颜色扰动，未测试纹理变化、遮挡、光照方向变化等更复杂的不变性挑战
- **batch内动作置换构造反事实是充分的**：CASC通过batch内排列组合构造反事实动作，但这可能无法覆盖真实场景中所有有意义的反事实情况
- **MPC在潜空间中足够有效**：论文假设在192维潜空间中做MPC规划是可行的，但未探索更高/更低维度的影响
