## 1. 核心架构/方法总览 (Overview / Architecture)

### 1.1 系统对比概览 (System Component Comparison)

| 组件 | LeWorldModel (基线) | PhyLatent (本文) | 推理阶段变化 |
|------|---------------------|------------------|-------------|
| 视觉编码器 E + 投影头 P | ✓ | ✓（共享） | 无变化 |
| 动作编码器 G_a | ✓ | ✓（共享） | 无变化 |
| 预测器 F_θ | ✓ | ✓（共享） | 无变化 |
| SIGReg 全局正则 | ✓ | ✓ | 无变化 |
| 静态视觉不变性约束 SVIC | ✗ | ✓ (训练) | 移除 |
| 物理状态 grounding PSG | ✗ | ✓ (训练) | 移除 |
| 未来表示对齐 FRA | ✗ | ✓ (训练) | 移除 |
| 反事实动作分离 CASC | ✗ | ✓ (训练) | 移除 |
| 潜去噪 LD | ✗ | ✓ (训练) | 移除 |
| 训练损失总数 | 2 (L_pred + SIGReg) | 7 (全部) | 无变化 |

**关键设计哲学**：所有新增模块仅在训练时使用，推理时编码器-预测器-MPC 规划器完全不变。这使 PhyLatent 可作为"训练时插件"无缝集成到任何基于 JEPA 的世界模型管线。

### 1.2 关键机制 (Key Mechanism)

PhyLatent 将训练约束组织为三条互补路径：

1. **物理不变性路径**：SVIC — 对同一物理状态施加外观扰动（亮度、颜色、纹理、噪声），强制编码后的潜表示保持接近。核心思想：外观变化不应主导潜位移。

2. **物理可辨识性路径**：PSG + FRA — 用仿真器提供的物理状态（关节角、物体位姿等）对编码和预测潜序列做 grounding；同时通过投影头和对齐头确保预测未来与观测未来在结构和动作上下文上一致。

3. **反事实动力学路径**：CASC + LD — 通过 batch 内 action 置换构造反事实动作序列，强制不同动作产生的预测未来分支保持足够分离；同时用潜去噪正则化局部未来几何。

⚡ **Eureka Moment**：全局非崩溃只是起点——一个可靠的世界模型潜空间必须在局部保持物理不变性、物理可辨识性和反事实动力学结构，三者缺一不可。

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：
```
L_PhyLatent = L_pred + 0.09·L_SIGReg
            + λ_inv·L_inv                    ← 物理不变性
            + λ_state·L_state                ← 物理 grounding
            + λ_align·(L_proj + L_act)       ← 未来对齐
            + λ_sep·L_sep + λ_denoise·L_denoise  ← 反事实动力学
```

**目标**：在 LeWorldModel 的基线损失（预测损失 + SIGReg）之上，增加五项约束，分别修复三种动力学相关崩溃。

**关键变量说明**：

| 符号 | 含义 |
|------|------|
| z_t | 当前观测的潜表示 P(E(o_t)) |
| ẑ_{t+1} | 预测的未来潜 F_θ(z_t, a_t) |
| sg(·) | stop-gradient 操作 |
| d_N(X, Y) | 归一化均方距离（沿末维 L2 归一化后 MSE） |
| L_inv | 外观扰动前后的潜表示距离 |
| L_state | 潜表示经状态头 H_s 预测物理状态的 MSE |
| L_proj | 预测未来与观测未来经共享投影头 φ 的对齐损失 |
| L_act | 动作查询模块 Ψ 的条件对齐损失 |
| L_sep | 反事实动作分支分离损失（hinge 形式） |
| L_denoise | 潜去噪损失（预测添加的噪声） |

> 符号与本文/相关文档保持一致。所有对齐损失使用归一化均方距离 d_N，而非原始 MSE，以确保尺度不变性。

**直觉**：L_pred 保证单步预测准确，SIGReg 保证全局分布不崩溃，但两者都不约束"哪些样本应该靠近、哪些应该分开"。PhyLatent 的五项损失分别从五个角度补上这个缺口——本质上是在潜空间里注入"物理等价关系"的归纳偏置。

## 3. 带数字走一遍：玩具例子 (Worked Example)

假设一个 2D 机械臂在平面内操作，物理状态 s = (θ_1, θ_2) 为两个关节角，观测 o 为 64×64 图像，潜维度 d_z = 128。

**场景 1：物理不变性崩溃修复**

- 初始状态 s = (30°, 45°)，观测 o（正常光照）
- 增强观测 o_aug（亮度 +30%，色偏 +15%）
- 真实状态转移 Δs = (5°, -3°) → o_{t+Δ}

LeWorldModel 下（崩溃案例）：
```
d_nuis = ||z(o) - z(o_aug)||_2 = 0.85    ← 外观变化导致的潜位移
d_state = ||z(o) - z(o_{t+Δ})||_2 = 0.62  ← 真实状态变化的潜位移
r_inv = log10((0.85+ε)/(0.62+ε)) = 0.14 > 0 → 崩溃！
```
外观变化比真实物理变化产生了更大的潜位移。

PhyLatent 修复后（假设训练收敛）：
```
d_nuis = 0.28    ← SVIC 强制外观扰动后的潜表示接近
d_state = 0.62   ← 不变（物理转移的潜位移）
r_inv = log10((0.28+ε)/(0.62+ε)) = -0.34 < 0 → 不崩溃 ✓
```

**场景 2：反事实动力学分离**

- 从同一状态 z_t 出发，两个动作 a_1 = (0.5, 0.3) 和 a_2 = (-0.5, -0.3)
- 真实未来分离：d_true = ||z_{t+1}(a_1) - z_{t+1}(a_2)||_2 = 1.2
- LeWorldModel 预测分离：d_pred = ||ẑ_{t+1}(a_1) - ẑ_{t+1}(a_2)||_2 = 0.45
- r_cf = 0.45 / (1.2 + ε) = 0.37 < 0.5 → 崩溃！丢失了 63% 的分支分离度

PhyLatent 的 CASC 损失：
```
动作差 δ^a = ||a_cf - a||_2 / sqrt(d_a) = 0.7
目标分离裕度 m = min(γ·δ^a, m_max) = min(2.0·0.7, 1.5) = 1.4
L_sep = [1.4 - δ^z]_+ = [1.4 - 0.45]_+ = 0.95 → 梯度推动预测分支分离
```
训练后假设 d_pred 提升到 0.85：
```
r_cf = 0.85 / 1.2 = 0.71 > 0.5 → 不崩溃 ✓
```

## 4. 工程视角 (Engineering View)

| 维度 | 分析 |
|------|------|
| 训练开销 | 增加 5 个损失项，但新增模块（状态头 H_s、投影头 φ、动作查询 Ψ、去噪头 D_ω）均为小型 MLP，参数量相对编码器/预测器可忽略 |
| 推理开销 | 零——所有辅助头在推理时移除，编码器-预测器-MPC 管线完全不变 |
| 内存需求 | 训练时需同时维护原始序列、增强序列、反事实序列，batch 内存约增加 30-50% |
| 数据依赖 | 需要仿真器输出的物理状态向量（关节角、物体位姿等）；真实世界部署需额外状态估计模块 |
| 超参敏感性 | 5 个 λ 权重需调优（论文附录提供了具体值）；SVIC 的增强范围（亮度/颜色扰动幅度）影响物理不变性强度 |
| 可扩展性 | 方法本身不依赖特定架构，可迁移到任何 JEPA 变体；但物理状态 grounding 需要任务特定的状态定义 |

**工程含义**：PhyLatent 的核心价值在于"训练时注入、推理时免费"。对于需要部署 MPC 的具身智能系统，这意味着可以用几乎零推理代价换取更高的规划成功率。主要工程挑战在于物理状态信号的获取——仿真环境中这是免费的，但真实机器人需要额外的状态估计器。

## 6. 能力与失败模式 (Capabilities & Failure Modes)

### 能做什么

- **显著降低三种崩溃率**：物理可辨识性崩溃从 6.71% 降至 0.95%（降低 86%），效果最显著
- **提升 MPC 成功率**：Cube 上 +8.1%，TwoRooms 上 +17.0%
- **推理零开销**：所有约束仅在训练时使用
- **架构无关**：可集成到任何 JEPA 变体

### 不能做什么

- **需要物理状态标注**：PSG 依赖仿真器提供的物理状态向量，真实世界部署需要额外的状态估计
- **仅验证于模拟环境**：4 个任务均为模拟基准，未在任何真实机器人上测试
- **不解决全局崩溃**：SIGReg 仍负责全局分布约束，PhyLatent 是补充而非替代
- **对简单任务收益有限**：Reacher 和 PushT 上"保持竞争力"说明在简单任务上收益不明显

### 6.1 隐含假设 (Hidden Assumptions)

1. **仿真器物理状态可靠**：PSG 假设仿真器输出的物理状态向量是准确且充分的——如果状态定义不完整（如忽略摩擦、形变），grounding 可能引入偏差
2. **外观增强覆盖充分**：SVIC 假设亮度/颜色/纹理/噪声增强足以覆盖推理时的外观变化——但真实世界的光照变化、遮挡、传感器噪声可能远超增强范围
3. **batch 内动作置换有意义**：CASC 假设 batch 内不同样本的动作置换能产生有区分度的反事实分支——在动作空间高度集中或动作维度较低时可能效果有限
4. **潜空间维度足够**：所有方法假设潜维度 d_z 足够容纳物理不变性和反事实分离的约束——如果潜空间过小，可能产生新的折叠
