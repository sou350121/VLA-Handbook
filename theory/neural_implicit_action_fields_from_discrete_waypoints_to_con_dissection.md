| **时间绑定** | 绑定训练采样频率 | 分辨率无关，任意频率查询 |
| **可微性** | 数值微分 (噪声放大) | 解析可微 (C∞ 连续) |
| **MLLM 角色** | 直接预测动作 token | 谱调制器 (预测 SIREN 的γ, β) |
| **监督信号** | 位置 loss | 位置 + 速度 + 加速度 + 加加速度 loss |
| **推理速度** | 自回归慢 / 并行快 | 单步并行解码 |
| **控制模式** | 位置控制 (stiff) | 阻抗控制 (compliant) |

### 1.2 关键机制 (Key Mechanism)

**为什么这样设计？**

1. **离散范式的三个根本问题**：
   - 刚性时间离散化：绑定固定采样率，无法亚步查询
   - 缺乏高阶动力学监督：无法约束速度/加速度连续性
   - 动态不一致性：数值微分放大量化噪声，阻抗控制不可行

2. **SIREN 的选择**：正弦激活保证 C∞ 光滑性和良好解析导数（ReLU 分段线性无法捕捉平滑运动）

3. **谱调制架构**：MLLM 不直接预测轨迹，而是预测轻量调制系数 (γ, β) 来变形共享 meta 参数 (W, b)——类似运动原语先验的结构化适应

⚡ **Eureka Moment**：**动作不是要预测的序列，而是要预测的函数**——把 MLLM 从"轨迹生成器"重新定位为"流形雕塑家"，用超网络范式预测隐式表示的参数而非值本身。

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：

```
A(τ) = SIREN(τ; θ),  θ = HyperNetwork(MLLM_context)
```

**目标**：从预测离散航点序列转向预测连续动作流形的参数

**核心方程**：

```
离散范式：A_seq = {a₀, a₁, ..., aₕ₋₁}  (H 固定，分辨率绑定)

连续范式：A(τ) = Φ(τ; θ),  τ∈[-1,1],  θ∈Θ  (无限分辨率)

SIREN 前向：
  h⁽⁰⁾ = τ
  h⁽ˡ⁾ = sin(ω₀ · (Ŵ⁽ˡ⁾h⁽ˡ⁻¹⁾ + b̂⁽ˡ⁾)),  l=1,...,L
  A(τ) = W_out·h⁽ᴸ⁾ + b_out

调制机制：
  Ŵ⁽ˡ⁾ = W⁽ˡ⁾ ⊙ (1 + γ⁽ˡ⁾)  (频率缩放)
  b̂⁽ˡ⁾ = b⁽ˡ⁾ + β⁽ˡ⁾        (相位偏移)

解析速度（链式法则递归）：
  v(τ) = W_out · ḣ⁽ᴸ⁾
  ḣ⁽ˡ⁾ = cos(u⁽ˡ⁾) ⊙ (Ŵ⁽ˡ⁻¹⁾ · ḣ⁽ˡ⁻¹⁾),  ḣ⁽⁰⁾ = 1
```

**变量说明**：

| 符号 | 含义 |
|------|------|
| τ | 归一化时间域 [-1, 1]，对应 chunk 时长 T |
| θ | SIREN 参数向量（由 MLLM 预测） |
| γ, β | 调制系数（频率/相位） |
| W, b | SIREN 共享 meta 参数（运动原语先验） |
| ω₀ | 频率缩放因子（SIREN 超参） |
| K | 查询点数（推理时任意，训练时固定） |

**直觉**：把动作轨迹想象成一条光滑曲线——离散范式是用有限点逼近它，NIAF 是直接给出曲线的数学公式。MLLM 的工作不是画点，而是调整公式里的参数。

## 3. 带数字走一遍：玩具例子 (Worked Example)

假设我们有一个简化的 1D 动作（单关节角度），chunk 时长 T=1s，SIREN 有 L=2 层。

**训练时**（K=10 个查询点）：

```
1. MLLM 编码视觉 + 语言上下文，输出 Z ∈ R^(Q×d)
2. 投影得到调制系数：
   γ⁽¹⁾, γ⁽²⁾ ∈ R^64  (64 个权重组)
   β⁽¹⁾, β⁽²⁾ ∈ R^1   (偏置)
3. 调制 SIREN 参数：
   Ŵ⁽ˡ⁾ = W⁽ˡ⁾ ⊙ (1 + γ⁽ˡ⁾)
   b̂⁽ˡ⁾ = b⁽ˡ⁾ + β⁽ˡ⁾
4. 对每个 τₖ ∈ {-1, -0.78, ..., 0.78, 1} 查询：
   A(τₖ) = Φ(τₖ; θ)
5. 计算 loss：
   L_pos = (1/K) Σₖ ||A(τₖ) - a_gt,ₖ||²
   L_vel = (1/K) Σₖ ||(2/T)·∇A(τₖ) - v_gt,ₖ||²  (如有速度标签)
```

**推理时**（K=50 或 200，任意）：

```
1. 同样步骤 1-3 得到调制后的 SIREN
2. 用更高频率查询（如 K=200，50Hz→200Hz）：
   τₖ = -1 + 2k/199,  k=0,...,199
3. 得到平滑轨迹 A(τₖ)，无需插值
4. 同时得到解析速度 v(τₖ) = ∇A(τₖ) 用于阻抗控制
```

**关键优势**：训练用 K=10，推理可以用 K=200——因为学的是函数不是点。

## 4. 工程视角 (Engineering View)

| 考量 | 细节 |
|------|------|
| **推理延迟** | 单步并行解码（优于自回归），MLLM 主导延迟；SIREN 前向可忽略 |
| **控制频率** | 训练 50Hz，推理可上采样到 200Hz+（图 7 验证速度波动减少） |
| **内存** | SIREN meta 参数固定大小；调制系数 Q×d 与 chunk length 无关 |
| **量化误差** | 无（连续表示）；离散范式有 B-spline 控制点量化或 DCT 截断 |
| **部署约束** | 真机需要 FOC 驱动高频速度反馈（用于 L_vel 监督和阻抗控制） |
| **训练稳定性** | SIREN 需小心初始化（论文用标准 SIREN 初始化策略） |
| **Chunk Length** | 消融显示 H=10 最优；太长增加优化难度，太短无法捕捉长期趋势 |

**工程含义**：NIAF 把"动作头"从分类器/回归器变成了"函数生成器"。部署时需要：
1. 修改推理代码支持任意 K 查询
2. 真机控制循环解析速度信号（而非数值微分）
3. 阻抗控制器使用解析速度作为 feedforward 项

## 6. 能力与失败模式 (Capabilities & Failure Modes)

**能做什么**：
- ✅ 无限分辨率轨迹查询（训练 50Hz→推理 200Hz+）
- ✅ 解析速度/加速度/加加速度输出（用于阻抗控制）
- ✅ 长视野任务（LIBERO-Long 95.5%，CALVIN 4.47 连续任务）
- ✅ 跨主干扩展（Florence-2→Qwen3-VL 性能提升）
- ✅ 接触丰富任务（Cup Stacking 80%，Shape Insertion 85%）

**不能做什么**：
- ❌ 无高频速度反馈的真机部署（L_vel 无法监督，阻抗控制失效）
- ❌ 极端长 chunk（H>20 性能下降，优化困难）
- ❌ 非周期性动作（SIREN 对高频细节捕捉好，但极低频趋势需足够层数）

### 6.1 隐含假设 (Hidden Assumptions)

1. **chunk 内运动光滑**：SIREN 的 C∞ 连续性假设动作 chunk 内是光滑的——对快速启停/碰撞场景可能不适用
2. **速度标签可用**：真机实验假设 FOC 驱动能提供可靠速度估计（并非所有机器人都有）
3. **归一化时间域**：τ∈[-1,1] 假设 chunk 时长固定——可变时长任务需额外处理
4. **共享 meta 先验**：假设所有任务共享同一套运动原语——极端多样化任务集可能需任务特定先验
