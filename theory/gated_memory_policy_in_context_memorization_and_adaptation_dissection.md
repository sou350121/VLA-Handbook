## 1. 核心架构/方法总览 (Overview / Architecture)

### 1.1 系统对比概览 (System Component Comparison)

| 维度 | Diffusion Policy (基线) | 长历史 DP / PTP | GMP (本文) |
|------|------------------------|-----------------|-------------|
| 历史处理方式 | 无 / 短窗口拼接 | 直接拼接所有历史 token 到序列 | 交叉注意力模块 + 缓存历史 token |
| 记忆调用策略 | 不适用 | 始终使用全部历史 | 二进制门控 μ_t ∈ {0,1}，按需激活 |
| 计算复杂度 | O(1)（无历史） | O(H²)（自注意力二次方） | O(H)（交叉注意力线性）+ 门控关闭时 O(1) |
| 鲁棒性（噪声历史） | 不适用 | 差（过拟合干净历史） | 扩散噪声注入历史动作，训练/推理一致 |
| 马尔可夫任务表现 | 强 | 下降（长历史引入噪声） | 保持竞争力（门控自动关闭） |
| 非马尔可夫任务表现 | 弱 | 中等（简单任务可用） | 强（MemMimic 平均提升 30.1%） |
| 训练范式 | 标准扩散去噪 | 扩散 + 辅助目标（PTP） | 扩散 + 门控自校准（两阶段） |

### 1.2 关键机制 (Key Mechanism)

GMP 围绕两个核心问题设计：

**问题 1：When — 何时调用记忆？**
- 答案：二进制门控 μ_t = 1{σ(φ(I_t, P_t)) > 0.5}
- 门控由 MLP 实现，输入当前图像 I_t 和机器人本体感知 P_t，输出 0 或 1
- μ_t = 0 时跳过交叉注意力（推理时间降为常数）；μ_t = 1 时激活历史交叉注意力
- **自校准流程**：训练两个策略（门控始终开 vs 始终关），在验证集上比较动作预测误差，误差显著降低的 timestep 标记为 μ_t = 1，否则 μ_t = 0。冻结门控权重后在全数据集上重训策略

**问题 2：What — 回忆什么信息？**
- 答案：轻量交叉注意力模块，从缓存的历史 token 中提取相关信息
- 每条历史轨迹包含：1 个聚合图像特征（ViT + MAP pooling）+ h 个动作 token
- 滑动窗口缓存 n 条历史轨迹，推理时无需重新计算历史 token（KV cache 思想）

⚡ **Eureka Moment**：门控不需要端到端训练——通过比较"有记忆 vs 无记忆"策略在验证集上的预测误差来自动生成标签，避免了直通过估计器(STE)导致门控趋向全开的问题。

### 1.3 信息流/架构图 (Flow / Diagram)

```
┌─────────────────────────────────────────────────────────────┐
│                    当前 timestep t                          │
│  I_t (图像) ──→ ViT ──→ MAP Pooling ──→ 视觉特征            │
│  P_t (本体感知) ────────────────────────────────────→       │
└────────────────────────────┬────────────────────────────────┘
                             │
                    ┌────────▼────────┐
                    │   Memory Gate   │  μ_t ∈ {0, 1}
                    │   φ(I_t, P_t)   │  MLP + Sigmoid
                    └────────┬────────┘
                             │
              ┌──────────────┼──────────────┐
              │ μ_t = 0      │              │ μ_t = 1
              ▼              │              ▼
         跳过交叉注意力       │    ┌──────────────────┐
         z_bar = z            │    │ Cross-Attention  │
                              │    │ Q: 当前 DiT token│
                              │    │ K,V: 缓存历史    │
                              │    │ (n 条轨迹)       │
                              │    └────────┬─────────┘
              ┌───────────────┼─────────────┼────────┐
              │               │             │        │
              ▼               ▼             ▼        ▼
         ┌──────────────────────────────────────────────┐
         │        Residual: z_bar = μ_t·h + z          │
         │        → Feed-Forward → Action Output       │
         └──────────────────────────────────────────────┘

         历史缓存 (推理时 O(1) 读取):
         [Traj_{t-nh}] [Traj_{t-(n-1)h}] ... [Traj_{t-h}]
```

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：
```
z_bar_{t:t+h} = μ_t · CrossAttn(Q=z_{t:t+h}, K/V=H_cached) + z_{t:t+h}
其中 μ_t = 1{σ(φ(I_t, P_t)) > 0.5}
```

**目标**：在扩散策略的去噪网络中，让策略学会按需引入历史上下文，而非始终使用或始终不使用。

**核心方程分解**：

```
L_action = E_{A^0_{t:t+h}, ε, k} [ ||A^0_{t:t+h} - φ_θ(A^k_{t:t+h}, I_t, P_t, k)||^2_2 ]
```

| 符号 | 含义 |
|------|------|
| A^0_{t:t+h} | 真实动作轨迹（预测视界 h） |
| A^k_{t:t+h} | 第 k 步扩散去噪时的噪声动作 |
| I_t, P_t | 当前图像观察和机器人本体感知 |
| φ_θ | 去噪网络（DiT backbone + GMP 模块） |
| μ_t | 二进制门控值 |
| H_cached | 缓存的历史 token 集合 |
| z_{t:t+h} | DiT 残差连接（无记忆时的中间表示） |
| h_{t:t+h} | 交叉注意力输出 |

**直觉**：门控 μ_t 是一个"开关"——当策略判断当前时刻不需要历史信息时（μ_t = 0），残差连接直接传递，计算量等同于无记忆策略；当需要时（μ_t = 1），交叉注意力从缓存中提取相关信息并注入残差流。

> 符号与原文保持一致。扩散噪声注入：在扩散步 k 时，历史动作使用 A^{k-1}_{t-nh:t}（比当前预测干净一步），而非干净历史。

## 3. 带数字走一遍：玩具例子 (Worked Example)

假设一个简化场景：

**任务**：Match Color — 机器人看到 4 个彩色箱子，抓取立方体后箱色被随机化，需将立方体放回原始匹配颜色的箱子。

**设置**：
- 预测视界 h = 8 步
- 历史窗口 n = 3 条轨迹（每次轨迹采样 1 张图像 + 8 个动作）
- 总 timestep = 96 步

**逐步推演**：

```
t = 0~47:  机器人观察箱子颜色、抓取立方体
           μ_t = 0（门控关闭）— 当前操作不需要回忆
           计算量 = 标准 DiT 前向传播

t = 48:    箱色被随机化（关键时刻！）
           μ_48 = 1（门控打开）— 策略需要记住原始颜色
           交叉注意力激活，查询缓存中 t≈48 的图像特征
           注意力权重最高指向 t=48（颜色首次被观察的时刻）

t = 49~79:  机器人移动中
           μ_t = 0（大部分时刻门控关闭）
           计算量恢复为常数

t = 80:    放置立方体（另一关键时刻）
           μ_80 = 1（门控打开）
           交叉注意力将最高权重分配给 t=48（颜色观察时刻）
           策略根据回忆的颜色信息选择正确的箱子

总门控开启率: 约 27%（73% 的时刻 μ_t = 0）
```

**推理时间对比**（论文 Fig 13 数据）：
- 无历史 DP: ~12ms
- 长历史 DP (120步): ~85ms（O(H²) 自注意力）
- GMP (门控开): ~28ms（O(H) 交叉注意力）
- GMP (门控关): ~14ms（几乎无异步开销）

## 4. 工程视角 (Engineering View)

| 工程维度 | 分析 |
|----------|------|
| 吞吐/延迟 | 门控关闭时推理延迟仅增加 ~2ms（对比无历史基线），实际部署中可忽略；门控开启时延迟 ~28ms，仍远低于长历史方案 |
| 步数/控制频率 | 假设 10Hz 控制频率，28ms 推理时间占用 28% 周期预算，剩余 72% 可用于通信和规划 |
| 内存占用 | 缓存 n 条轨迹：n × (1 图像特征 + h 动作 token) × d 维。假设 n=3, h=8, d=384 → 约 12KB 缓存，极低 |
| 量化误差 | 门控是二进制决策，对量化不敏感；交叉注意力和 DiT backbone 可按标准方式量化 |
| 部署约束 | 需要预缓存历史轨迹；首次 n 条轨迹无历史可用（等效于无记忆策略），warm-up 阶段性能略低 |
| 训练成本 | 两阶段训练：(1) 校准门控需训练 2 个策略；(2) 冻结门控重训最终策略。总训练量 ≈ 3 倍标准 DP |

**工程含义**：GMP 的门控设计本质上是在控制频率和模块边界之间做了一个精妙的 trade-off——高频控制循环中，大部分时刻不需要记忆，门控关闭保证了低延迟；关键时刻打开门控，交叉注意力提供必要的历史信息。这比始终携带长历史的方案在工程上更可行。

## 6. 能力与失败模式 (Capabilities & Failure Modes)

### 能做什么

| 能力 | 场景 | 原因 |
|------|------|------|
| trial内记忆 | Match Color, Discrete Place Back | 交叉注意力自动定位关键帧 |
| 跨trial适应 | Iterative Pushing/Flinging/Casting | 缓存多轮历史，注意力聚焦成败关键结果 |
| 马尔可夫任务兼容 | RoboMimic 全部任务 | 门控自动关闭，不引入噪声 |
| 真实世界部署 | Flip and Place Back, Iterative Casting | 扩散噪声增强提高鲁棒性 |

### 不能做什么

| 局限 | 场景 | 原因 |
|------|------|------|
| 超长序列 | 需要记住数十次之前的事件 | 有限滑动窗口，超出缓存的历史丢失 |
| 零样本新任务 | 从未见过的任务类型 | 门控在校准集上训练，分布外任务门控可能失效 |
| 语义级推理 | 需要理解"为什么"而非"怎么做" | 纯视觉-动作空间，无语义表征层 |

### 6.1 隐含假设 (Hidden Assumptions)

1. **验证集代表性假设**：门控校准依赖验证集，假设验证集覆盖了部署时所有"需要记忆"的关键时刻。如果部署环境出现验证集中未见的场景，门控可能给出错误的开/关决策。

2. **有限窗口充分性假设**：假设 n 条历史轨迹足以覆盖任务所需的全部记忆。对于需要"无限记忆"的超长序列任务（如数百次迭代学习），该假设不成立。

3. **单模态历史充分性假设**：历史仅包含图像特征+动作，不含语言/语义信息。对于需要高层语义推理的任务（如"根据用户指令调整策略"），可能不够。

4. **门控稳定性假设**：假设门控在训练后冻结不会因分布偏移而退化。但实际部署中，视觉输入的域偏移可能导致门控决策质量下降。

## 7. 与相关工作对比 (Comparison)

| 方法 | 关注点 | 架构 | 训练方式 | 适用场景 |
|------|--------|------|----------|----------|
| Diffusion Policy | 马尔可夫任务 | DiT，无历史 | 标准扩散去噪 | 简单操作任务 |
| BC-RNN | 通用序列建模 | RNN 编码器 | 行为克隆 | 中等记忆需求 |
| 长历史 DP | 扩展上下文 | DiT + 拼接历史 | 标准扩散 | 简单非马尔可夫 |
| PTP | 辅助目标增强 | DiT + 历史token预测 | 扩散 + 辅助预测 | 需要时间理解 |
| MemoryVLA | VLA + 外部记忆 | VLM + 记忆库检索 | VLA 训练 + 检索 | 高层规划 |
| **GMP (本文)** | **按需记忆** | **DiT + 门控 + 交叉注意力** | **扩散 + 门控自校准** | **混合记忆需求** |

**面试 Tip**：如果被问到"门控记忆和 RNN 记忆的区别"，可以回答——RNN 隐式地压缩所有历史信息到一个固定维度的隐藏状态，而 GMP 显式地缓存原始历史 token 并通过交叉注意力按需检索，门控机制进一步避免了不必要的记忆调用，在马尔可夫任务上不会因历史噪声而降级。
