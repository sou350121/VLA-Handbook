### 1.2 关键机制 (Key Mechanism)

**为什么这样设计？**

VLA 遗忘比单模态遗忘更复杂，因为：
1. **多模态纠缠**： unwanted behavior 可能编码在视觉特征、跨模态绑定、或动作先验中
2. **闭环控制评估**：失败必须通过具身执行判断，而非输出准确率
3. **部署约束**：必须保持原生 VLA 接口，支持量化后鲁棒性

VLA-Forget 的核心设计原则：
- **分层定位**：用 ratio-aware score 选择视觉/投影器层，用 significance ratio 选择语言层
- **三目标优化**：同时优化遗忘效力、感知保留、推理保留
- **适配器优先**：用 LoRA 实现参数高效更新，支持滚动回滚

⚡ **Eureka Moment**：VLA 的 undesirable behavior 是跨三模块分布的——只编辑视觉栈会留下动作先验，只编辑语言骨干会保留感知捷径；必须三阶段联合编辑才能实现干净遗忘。

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：

```
min_θ L_retain + λ_feat·L_feat - λ_f·L_forget - λ_m·L_mismatch
```

**目标解释**：在保留非目标行为的前提下最大化遗忘效力，同时防止浅层遗忘导致的恢复。

### 2.1 核心方程详解

**保留损失 (Retain Loss)**:
```
L_retain = E_(x,y)~Dr[CE(p_θ(·|x), y)] + β·E_x~Dr[KL(p_θ0(·|x) || p_θ(·|x))]
```
- 第一项：在保留集上保持动作 token 预测准确率
- 第二项：KL 散度约束，防止更新后策略偏离原始模型太远

**遗忘损失 (Forget Loss)**:
```
L_forget = E_(x,y)~Df[CE(p_θ(·|x), y)]
```
- 实现方式：对 L_forget 做梯度上升 (gradient ascent)
- 目标：让模型在遗忘集上的预测误差最大化

**不匹配损失 (Mismatch Loss)**:
```
L_mismatch = E_x~Df[KL(p_θ(·|x) || p_θ0(·|x))]
```
- 防止浅层遗忘：推动更新后策略远离原始遗忘响应
- 减少量化后行为恢复

**感知保留损失 (Perceptual Preservation Loss)**:
```
L_feat = E_x~Dr∪Dm[||h^V_θ(x) - h^V_θ0(x)||^2 + γ·||h^P_θ(x) - h^P_θ0(x)||^2]
```
- 在保留集和边界集上蒸馏内部特征
- 保持非目标视觉 grounding

**层选择分数 (Layer Selection Scores)**:

视觉/投影器 ratio-aware score:
```
φ(l) = (||g^f_l||_2 / (||θ_l||_2 + ε)) · (1 - cos(g^f_l, g^r_l))^α
```
- 分子：遗忘梯度范数（影响越大越好）
- 分母：参数范数归一化
- 余弦项：与保留梯度的冲突程度（冲突越小越好）

语言层 significance ratio:
```
Sig(l) = ||∇_θl L_forget||_2 / (||∇_θl L_retain||_2 + ε)
```
- 选择遗忘梯度远大于保留梯度的层

> 符号与本文/相关文档保持一致：θV = 视觉编码器，θP = 投影器，θL = 语言/动作骨干，Df = 遗忘集，Dr = 保留集，Dm = 边界集

### 2.2 直觉解释

想象 VLA 模型是一个三层过滤系统：
1. **视觉层**：看到"蓝色杯子"→ 提取视觉特征
2. **投影层**：把视觉特征翻译成语言模型能理解的形式
3. **语言层**：根据指令"拿蓝色杯子"→ 预测动作 token

如果模型学会了错误行为（比如看到"蓝色"却抓"红色杯子"），这个错误可能存在于：
- 视觉层：把蓝色识别错了
- 投影层：把蓝色特征绑定到了错误的语言 token
- 语言层：即使正确识别蓝色，动作先验还是错的

VLA-Forget 的做法：三层都检查，但只编辑最关键的那几层（用上述分数选择），同时确保其他功能不受影响。

## 3. 带数字走一遍：玩具例子 (Worked Example)

假设我们有一个简化的 VLA 场景：

**任务**：机器人根据指令抓取指定颜色的杯子
**错误行为**：当指令是"拿蓝色杯子"时，模型错误地抓取红色杯子
**遗忘目标**：移除这个错误映射，但保留其他颜色抓取能力

### 3.1 数据构造

```
遗忘集 Df (100 条):
  - 图像：场景中有蓝色杯子和红色杯子
  - 指令："拿蓝色杯子"
  - 错误标签：模型原本预测的动作 token 对应"抓红色"

保留集 Dr (500 条):
  - 图像：各种颜色杯子场景
  - 指令："拿 X 色杯子" (X ≠ 蓝色)
  - 正确标签：对应颜色的抓取动作

边界集 Dm (50 条):
  - 图像：蓝色物体但不是杯子（蓝色球、蓝色方块）
  - 指令："拿蓝色 X"
  - 正确标签：保留对蓝色物体的正常响应
```

### 3.2 三阶段更新过程

**Stage 1: 视觉遗忘 (KV = 2 层)**

假设视觉编码器有 12 层，计算每层的 φ(l) 分数：
```
层 10: φ = 0.85  ← top-1
层 11: φ = 0.72  ← top-2
层 9:  φ = 0.45
...
```
选择层 10 和 11 进行 LoRA 编辑。

更新后效果：
- 对"蓝色杯子"图像的视觉特征响应减弱 40%
- 对其他颜色杯子的特征响应变化 < 5%

**Stage 2: 跨模态遗忘 (KP = 1 层)**

投影器有 3 层，选择分数最高的 1 层：
```
层 2: φ = 0.91  ← 选择
层 1: φ = 0.33
层 0: φ = 0.28
```

更新后效果：
- "蓝色视觉特征 → 蓝色语言 token"的绑定保持
- "蓝色视觉特征 → 红色动作 token"的错误绑定被打破

**Stage 3: 推理/动作遗忘 (KL = 3 层)**

语言骨干有 32 层，计算 Sig(l)：
```
层 28: Sig = 4.2  ← top-1
层 29: Sig = 3.8  ← top-2
层 30: Sig = 3.5  ← top-3
层 27: Sig = 2.1
...
```

更新后效果：
- 指令"拿蓝色杯子"→ 错误动作 token 的预测概率从 0.85 降至 0.12
- 其他指令的动作预测准确率保持 > 90%

### 3.3 最终评估

```
遗忘效力指标:
  - FC (Forget Cross-Entropy): 93 (越高越好，基线 GA=93, SSD=78)
  - FAD (Forget Accuracy Drop): 0.88 (越高越好，表示遗忘集准确率下降 88%)

保留效用指标:
  - RC (Retain Utility Score): 91 (越高越好，基线 GA=60, NPO=88)
  - RAD (Retain Accuracy Drop): 0.21 (越低越好，表示保留集准确率仅下降 21%)

具身执行指标:
  - TSR (Task Success Rate): 78% (越高越好，基线 GA=40%, NPO=74%)
  - SVR (Safety Violation Rate): 5% (越低越好，基线 SSD=17%, GA=5%)
```

### 4.2 部署约束与量化鲁棒性

**关键发现**（Table 3）：
```
量化后遗忘效力保持率 (8-bit / 4-bit):

方法      8-bit 保持率    4-bit 保持率
GA        62%           31%
NPO       71%           45%
VLA-Forget 89%           67%
```

**工程解释**：
- 激进的全模型更新 (GA) 在量化后容易"恢复"遗忘行为
- VLA-Forget 的选择性编辑更稳定，因为：
  1. 只编辑关键层，参数变化集中
  2. 有 L_mismatch 项防止浅层遗忘
  3. LoRA 适配器可以独立于主模型量化

**部署建议**：
- 遗忘完成后先做 8-bit 量化测试，确认 SVR < 10% 再部署
- 保留原始模型 checkpoint，支持紧急回滚
- 在生产环境部署前用边界集 Dm 做对抗测试

### 4.3 延迟与吞吐影响

由于使用 LoRA 适配器：
- **推理延迟**：增加 < 3%（适配器矩阵乘法开销）
- **吞吐**：无明显影响（适配器可融合到主模型）
- **热更新**：支持运行时切换适配器（无需重启服务）

| 维度 | LLM 遗忘 (Yao et al. 2024) | VLM 遗忘 (Fan et al. 2023) | VLA-Forget (本文) |
|------|---------------------------|---------------------------|-------------------|
| 目标模型 | 纯语言模型 | 视觉 - 语言模型 | 视觉 - 语言 - 动作模型 |
| 评估方式 | 文本输出准确率 | 图像/文本输出质量 | 具身执行成功率 |
| 编辑范围 | 语言层 | 视觉 + 语言层 | 视觉 + 投影 + 语言 + 动作层 |
| 部署约束 | 无特殊要求 | 无特殊要求 | 需保持动作 token 接口 |
| 量化鲁棒性 | 未测试 | 未测试 | 8-bit/4-bit 测试通过 |

### 7.2 与 VLA 微调方法对比

| 方法 | 目标 | 参数效率 | 与遗忘的兼容性 |
|------|------|---------|---------------|
| OpenVLA 全模型微调 (Kim et al. 2024) | 新任务适应 | 低 (7B 全参数) | 不兼容（会覆盖遗忘） |
| LoRA 微调 (Hu et al. 2022) | 参数高效适应 | 高 (~0.1%) | 兼容（可叠加适配器） |
| VLA-Forget | 行为删除 | 高 (~0.15%) | 原生支持 |

### 7.3 面试 Tip

**问**："VLA 遗忘和普通 LLM 遗忘有什么区别？"

**答**："三个核心差异：第一，VLA 的错误行为分布在视觉、跨模态、动作三个模块，单模块编辑不够；第二，评估必须通过具身执行而非输出准确率；第三，部署时必须考虑量化鲁棒性，因为机器人常在边缘设备运行。VLA-Forget 的三阶段混合设计就是为了解决这三个问题。"
