### 1.2 关键机制 (Key Mechanism)

ReGen 的核心流程分为三个阶段：

1. **初始化阶段** ($0 \leq t < H$)：从当前任务的真实演示中取一个完整的 action chunk（$H=16$ 步），用真实观测初始化 rollout
2. **递归生成阶段** ($H \leq t \leq T_{\max}$)：不再使用真实观测，而是将 WAM 自己生成的未来观测作为下一步输入，递归生成完整轨迹
3. **终止判断**：达到最大步数 T_max，或 goal-reward head 连续 3 步预测 >0.99 且至少一次达到 1.0

生成的伪轨迹集合 $R_k = \cup\, \tilde{\tau}_i$ 与当前任务演示 $D_k$ 合并为 $D_k^+$，用行为克隆损失更新策略。

⚡ **Eureka Moment**：WAM 的"预测未来观测"能力天然适合"生成过去任务的伪演示"——同一个生成式接口，同一个模型，既是策略又是记忆，无需额外训练生成模型。

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：
```
D_k⁺ = D_k ∪ [∪_{i=1}^{M} rollout(π_θ | ℓ_i, o_0 ∼ D_k)]
θ ← argmin_θ E_{(o,a,ℓ)∼D_k⁺} [L_BC(π_θ(o,ℓ), a)]
```

**目标**：在仅能访问当前任务演示 $D_k$ 的前提下，利用 WAM 的生成能力合成之前 $M$ 个任务的伪轨迹，使策略在 $D_k^+$ 上训练时同时获得新技能并保留旧技能。

**核心方程分解**：

WAM 基础预测（论文 Eq.1）：
```
(ã_{t:t+H}, õ_{t+H}, r̃_t) ~ π_θ(· | o_t, ℓ)
```
- $\tilde{a}_{t:t+H}$: 预测的 $H=16$ 步动作序列
- $\tilde{o}_{t+H}$: 预测的未来观测
- $\tilde{r}_t \in [0,1]$: 任务进度/奖励估计（dense proxy for task completion）

递归生成（论文 Eq.2）：
```
o_t^{in} = o_t           (0 ≤ t < H, 真实观测)
o_t^{in} = õ_t           (H ≤ t ≤ T_max, 生成观测自举)
```

伪轨迹构建（论文 Eq.3）：
```
τ̃^i = {(o_t^{in}, ã_t)}_{t=0}^{T_i}
```

训练目标（论文 Eq.4）：
```
min_θ E_{(o_t,a_t,ℓ)∼D_k⁺} [L_BC(π_θ(o_t, ℓ), a_t)]
```
- ℓ = ℓ_k 对于 D_k 中的样本
- $\ell = \ell_i$ 对于 $\tilde{\tau}^i$ 中的样本

> 符号说明：$\theta$ 为 WAM 参数；$\ell$ 为语言指令；$o$ 为多视图 RGB + 本体感知状态；$a$ 为动作；$H=16$ 为动作预测 horizon；$T_{\max}$ 为最大生成步数。

## 3. 带数字走一遍：玩具例子 (Worked Example)

假设一个简化场景：
- 已学任务：T1="把苹果放进碗"，T2="把香蕉放到盘子上"
- 当前任务：T3="把橙子放进碗"
- WAM 基础策略 $\pi_\theta$ 已在 $T_1$, $T_2$ 上训练

**ReGen 回放生成过程**：

1. 从 T3 演示采样一个真实观测 o_0（机械臂在 T3 场景的初始状态）
2. 初始化：用 $T_3$ 的真实动作 chunk 填充前 16 步，$o_0^{in}\dots o_{15}^{in} = $ 真实观测
3. 递归阶段 t=16：
   - 输入：$o_0^{in} + T_1$ 指令 "把苹果放进碗"
   - WAM 输出：ã_0...ã_15, õ_16, r̃_0
   - 取 $\tilde{a}_0$ 与 $o_0^{in}$ 组成伪轨迹第 0 步
4. t=32：
   - 输入：õ_16 + T1 指令
   - WAM 输出：ã_16...ã_31, õ_32, r̃_16
   - 取 ã_16 与 õ_16 组成伪轨迹第 16 步
5. 继续递归直到 r̃_t > 0.99 连续 3 步（模型认为任务完成）
6. 对 T2 重复相同过程
7. 最终 $D_3^+ = D_3$ (50条真实) $\cup\, \tilde{\tau}^1$ (约200步) $\cup\, \tilde{\tau}^2$ (约200步)
8. 在 $D_3^+$ 上训练 2K iterations

**关键数值**：每个前序任务生成 10 条伪轨迹（论文设定），假设每条平均 200 步，则 2 个前序任务贡献约 4000 步伪数据，与当前任务 $50\times 200=10000$ 步真实数据混合训练。

## 4. 工程视角 (Engineering View)

| 工程维度 | 数值/设定 | 含义 |
|---------|----------|------|
| 基础模型 | Cosmos-Predict2-2B | 2B 参数，需多 GPU 或大显存单卡 |
| 动作 horizon H | 16 步 | 初始化阶段需要 16 步真实数据 |
| 控制频率 | 15 Hz (真实世界) | 实时性要求中等 |
| 基础训练 | 10K iterations | 一次性预训练成本 |
| 每阶段微调 | 2K iterations | 持续学习阶段增量成本 |
| 伪轨迹数/任务 | 10 条 | 回放数据量 vs 计算成本 trade-off |
| 生成延迟 | 每步一次前向 | 无额外生成模型，延迟即 WAM 推理延迟 |
| 内存占用 | 无需存储历史数据 | 相比 ER 显著节省 buffer 内存 |

**工程含义**：
- ReGen 不引入额外模型——回放生成就是 WAM 前向推理，无额外推理开销
- 伪轨迹生成是离线批处理，不影响在线推理延迟
- 主要瓶颈在于 WAM 生成质量（长程退化），而非计算效率
- 适合部署场景：演示数据不可获取（私有基础模型），但 WAM 本身可用的情况

## 6. 能力与失败模式 (Capabilities & Failure Modes)

### 能做什么
- **无数据持续学习**：在完全不存储历史演示的前提下，显著降低遗忘（NBT 降低 40-50%）
- **跨套件泛化**：在 LIBERO 三个不同分布偏移套件（空间/物体/目标）上均有效
- **真实世界部署**：在 xArm7 上验证，NBT 从 96.3 降至 60.5，FWT 从 50 提升至 80
- **保持动作表征**：动作表示漂移（ℓ2 距离）仅 0.12，远优于 Seq-FT 的 0.3

### 不能做什么 / 失败模式
- **长程视觉退化**：递归生成时，未来观测的视觉保真度随时间退化，是伪回放质量的根本瓶颈（论文 §1, §5.4）
- **动作-观测不一致**：生成的观测与对应动作之间存在不一致，影响伪轨迹质量
- **LIBERO-Spatial 需要特殊处理**：ReGen† 需要从历史任务采样物体配置来初始化回放——这意味着对于空间泛化场景，仅靠语言指令不够，还需要场景结构信息
- **不替代真实回放**：仍显著低于 ER（真实回放）的性能，AUC gap 约 20-30%
- **仅验证单一 WAM**：全部实验基于 Cosmos-Policy，未验证其他 WAM 架构（如 OpenVLA 变体）

### 6.1 隐含假设 (Hidden Assumptions)

1. **WAM 的生成质量足够支撑回放**：假设 WAM 生成的伪轨迹在语义/动作层面足够准确。但论文自己承认长程退化是瓶颈——这意味着对于长任务，伪回放质量可能不够
2. **语言指令足以区分任务**：假设仅凭 ℓ_i 就能让 WAM 生成正确的历史任务轨迹。但在空间泛化场景（LIBERO-Spatial）中这个假设不成立，需要额外场景信息
3. **当前任务观测可作为历史任务回放的种子**：用 T_k 的真实观测初始化 T_i 的回放——这在物体/目标不同的场景下可能产生语义不一致（T_i 需要的物体在 T_k 场景中不存在）
4. **伪轨迹与真实轨迹在 BC 损失下等价**：假设 L_BC 对伪轨迹和真实轨迹一视同仁。但伪轨迹可能存在系统性偏差，BC 可能学到错误的映射
