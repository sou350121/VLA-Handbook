💡 **X-Ray 开场**
单张照片里的杂乱桌面，机器人想操作它——但现有方法从单图重建的 3D 物体一放到物理仿真器里就穿模、悬浮或沉穿桌面。SimuScene 的核心发现是：物理仿真不应该只在最后"验收"，而应该作为诊断工具嵌入重建循环本身——物体沉了多少、穿了多少，这些物理违规量本身就是修正几何形状的信号。对 VLA 研究者的意义：它提供了一条从单图自动生成物理一致仿真场景的路径，可用于 RL 训练数据合成和仿真到真实的迁移。

## 1. 核心架构/方法总览 (Overview / Architecture)

SimuScene 管线由五个阶段组成：分解初始化 → 位姿精化 → 诊断仿真 → 形状修正 → 最终组合。

### 1.1 系统对比概览 (System Component Comparison)

| 模块 | 输入 | 输出 | 关键依赖 | 训练/推理 |
|------|------|------|----------|-----------|
| 分解初始化 | 单张 RGB 图 | 基础结构 mesh + 每对象初始 mesh (M, s, t, R) | MLLM 编辑器, SAM3D, RAM++, MoGe | 推理（SAM3D 预训练） |
| 位姿精化 | 初始 mesh + 点云 | 精化位姿 (t_pre, R_pre) | FoundationPose, MoGe depth | 推理 |
| 诊断仿真 | 精化场景 S_pre | 穿透位移 Δt_pen + 重力位移 Δt_grv | MuJoCo, V-HACD | 纯物理仿真 |
| 形状修正 | 位移信号 $\rho$ | 拉伸 mesh 或重采样 mesh | SAM3D (FM-DPO 微调版) | 推理（微调后权重） |
| 最终组合 | 修正对象状态 | 仿真就绪场景 S | MuJoCo (完整 6-DoF) | 纯物理仿真 |

### 1.2 关键机制 (Key Mechanism)

**为什么这样设计**：传统方法把物理仿真放在最后做"布局清理"——物体位置不对就推一推。但 SimuScene 发现，当几何形状本身错误时（由于遮挡导致 amodal 补全失败），位置调整无法根本解决问题。所以把物理仿真提前到生成循环内部，用物理违规的量化程度来判断是"小误差"（拉伸修正）还是"大失败"（重采样）。

⚡ **Eureka Moment**：物理仿真不应该只是事后清理工具——它产生的穿透距离和下沉位移本身就是几何误差的量化测量，可以直接驱动形状修正。

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：
```
ρ_i = |ĝ^T · (Δt_pen + Δt_grv)| / ℓ_pre   ← 归一化重力轴位移
     └─ 物理违规量 ─┘           └─ 物体尺寸 ┘
     ρ_i < 0.15 → 拉伸修正
     ρ_i ≥ 0.15 → amodal 重采样
```

**目标**：用物理仿真产生的位移信号量化几何误差程度，据此选择轻量修正（拉伸）还是重度修正（重采样）。

**变量说明**：

| 符号 | 含义 | 计算方式 |
|------|------|----------|
| $\rho_i$ | 归一化重力轴位移 | 穿透+重力位移在重力方向投影 / OBB 重力轴边长 |
| $\Delta t_{\text{pen}}$ | 穿透解析位移 | MuJoCo 碰撞解析产生的位移 |
| $\Delta t_{\text{grv}}$ | 重力诱导位移 | 释放后第一接触帧的位移 |
| ℓ_pre | OBB 重力轴边长 | 从 S_pre 中对象的 Oriented Bounding Box 计算 |
| ĝ | 单位重力方向 | 通常为 [0, -1, 0] |

**直觉**：如果物体在仿真中只下沉了自身高度的 5%，说明形状大致正确只是略有偏差（拉伸即可）；如果下沉了 30%，说明 SAM3D 的形状采样严重错误（需要重新生成）。

**FM-DPO 损失函数**（用于 SAM3D 微调）：
```
L_FM-DPO(θ) = E_i [ w_i · (-log σ(-β/2 · (d_θ,i - d_ref,i))) ]
```
其中 $d_{\theta,i}$ 是当前模型的 win-lose flow-matching 损失差，$d_{\text{ref},i}$ 是冻结参考 SAM3D 的对应差值，$\beta=500$ 控制偏好强度，$w_i$ 为样本权重（遮挡-补全对 $1.0$，干净保持对 $0.1$）。

> 符号与本文保持一致：M_i = 第 i 个对象的 3D canonical mesh，s_i = 各向同性缩放，t_i = 平移，R_i = 旋转，N = 场景中对象数。

## 3. 带数字走一遍：玩具例子 (Worked Example)

假设一个杯子从单图重建后放入仿真：

**初始状态**：
- SAM3D 输出的杯子 canonical mesh 高度 ℓ_pre = 0.12m（OBB 重力轴边长）
- 位姿精化后放置在桌面上

**诊断仿真**：
- 穿透解析：无穿透，$\Delta t_{\text{pen}} = 0$
- 重力释放：杯子底部比实际矮了 $0.015\,\text{m}$，下沉 $\Delta t_{\text{grv}} = -0.015\,\text{m}$（沿重力方向）
- 计算 $\rho = |0.015| / 0.12 = 0.125$

**决策**：$\rho = 0.125 < 0.15$ → 选择**重力轴拉伸**
- 沿 OBB 重力轴拉伸 canonical mesh，拉伸量 = 0.015m
- 重新归一化，scale 吸收变化，平移更新使底部固定

**重仿真验证**：杯子现在稳定立在桌面上，无下沉。

---

另一个例子：被严重遮挡的花瓶
- $\rho = 0.045 / 0.20 = 0.225$
- $\rho \geq 0.15$ → 触发 **amodal 重采样**
- 用 OBB 扩展掩码 → 新 crop 图像覆盖预期隐藏区域 → SAM3D 重新生成完整形状
- 重采样后的花瓶形状在仿真中稳定

## 4. 工程视角 (Engineering View)

| 维度 | 细节 |
|------|------|
| 仿真引擎 | MuJoCo + V-HACD 碰撞几何提取 |
| 顺序协议开销 | N 个对象需要 N 次独立仿真（无法并行），但每次仿真只需运行到首次接触 |
| GPU 需求 | SAM3D 微调需 $4 \times$RTX PRO 6000 Blackwell，推理阶段单卡可运行   |
| 延迟瓶颈 | FoundationPose 旋转精化 + SAM3D 形状生成是主要耗时环节 |
| 内存 | 每对象独立处理，内存占用可控；最终场景包含 N 个独立 mesh |
| 部署约束 | 需要 MoGe（深度）、SAM3（分割）、FoundationPose（位姿）、SAM3D（形状）四个基础模型 |
| 可并行性 | 顺序协议本质不可并行——每个对象冻结后才处理下一个 |

**工程含义**：SimuScene 不是实时系统——它是一个离线场景重建管线，目标是在部署到仿真器之前生成物理一致的 3D 资产。适合数据生成和仿真环境搭建，不适合在线感知-规划循环。

## 6. 能力与失败模式 (Capabilities & Failure Modes)

**能做什么**：
- 从单张 RGB 图生成物理稳定的组合 3D 场景，可直接放入 MuJoCo 等仿真器
- 处理严重遮挡（amodal resampling 在 VLM 评估中 win rate 显著优于原始 SAM3D）
- 支持墙挂/线挂物体的约束仿真（point-anchored / line-anchored DoF 标签）
- 下游应用：人形机器人控制策略学习、机械臂杂乱操作

**不能做什么**：
- 不支持实时重建——管线是离线的、多阶段的
- 顺序协议不可逆——早期对象的错误估计无法被后续信息修正
- 极度遮挡场景（如物体完全被挡住）仍可能产生不合理形状
- 仅处理刚性物体——柔性物体、流体不在范围内

### 6.1 隐含假设 (Hidden Assumptions)

1. **基础模型足够可靠**：假设 SAM3D、MoGe、FoundationPose 在大多数情况下给出"大致正确"的初始估计。如果基础模型完全失败（如漏检），SimuScene 无法补救。
2. **重力方向已知**：假设可以从图像或先验确定重力方向——这在大多数室内场景成立，但并非总是如此。
3. **刚性物体假设**：所有物体被视为刚体，忽略了真实世界中部分物体的柔性和可变形性。
4. **顺序处理顺序合理**：假设按最低角排序的顺序协议能产生合理的重建结果——但不同顺序可能导致不同最终场景。
5. **仿真器参数合理**：评估依赖 MuJoCo 参数的一致性，如果仿真器摩擦/弹性参数与真实世界差异大，"物理稳定"不等于"真实可信"。
