💡 **X-Ray 开场**
当前 VLA 策略评估几乎全部依赖二元成功率——两个策略成功率相同，一个执行流畅稳健，另一个脆弱 erratic，但传统评估无法区分它们。RoboEval 提出用 13 个行为指标（效率、安全/稳定性、双臂协调）+ 阶段进度指标来量化"执行质量"，并在 5 种主流策略（ACT、Diffusion Policy、GR00T N1.6、X-VLA、π0.5）上验证：这些指标确实能在成功率相近时区分策略，且 >50% 的指标与成功率相关。对 VLA 研究者意味着：评估不再只是"跑 100 次看成功几次"，而是可以定位"策略在协调维度上差、但效率维度上不错"这类细粒度诊断。

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：
```
评估质量 = f(效率, 安全/稳定性, 协调性, 阶段进度)  ≠  二元成功率
```

RoboEval 将策略评估分解为四个正交维度，每个维度由可计算的指标构成：

### 2.1 效率指标 (Efficiency)

**目标**: 量化策略完成任务的时间和空间成本

```
L_joint = Σ(t=1→T-1) ‖q(t+1) - q(t)‖₂     (关节路径长度)
L_cart  = Σ(t=1→T-1) ‖x(t+1) - x(t)‖₂     (笛卡尔路径长度)
```

- `q(t)`: t 时刻关节配置
- `x(t)`: t 时刻末端执行器笛卡尔位置
- `T`: 轨迹总步数

**直觉**: 路径越短 = 越高效。人类演示提供效率参考下界。

### 2.2 安全/稳定性指标 (Safety/Stability)

**目标**: 量化执行过程中的物理交互质量和运动稳定性

```
Jerk_joint = (1/(T-3)) · Σ ‖(q(t+3) - 3q(t+2) + 3q(t+1) - q(t)) / (Δt)³‖₂
Jerk_cart  = (1/(T-3)) · Σ ‖(x(t+3) - 3x(t+2) + 3x(t+1) - x(t)) / (Δt)³‖₂
```

加上三个接触指标：
- 自碰撞次数 (Self-collision Count)
- 环境碰撞次数 (Environment Collision Count)
- 物体滑脱次数 (Slip Count)

**直觉**: 加加速度（jerk）衡量运动平滑度；碰撞/滑脱次数衡量接触稳定性。

### 2.3 协调指标 (Coordination)

**目标**: 量化双臂之间的空间对齐和时间同步

```
Δz = (1/T) · Σ |z_left(t) - z_right(t)|     (高度差异)
Δv = (1/(T-1)) · Σ ‖v_left(t) - v_right(t)‖₂ (速度发散)
```

**直觉**: Δz 和 Δv 越小 = 双臂协调越好。

### 2.4 阶段进度指标 (Task Progression)

每个任务被分解为离散阶段，记录每阶段的二元成功标志，最终成功率 = 完成所有阶段的 episode 比例。

> 符号与论文保持一致：q = 关节配置, x = 笛卡尔位置, T = 轨迹长度, Δt = 控制时间步长

## 3. 带数字走一遍：玩具例子 (Worked Example)

以 **Lift Pot** 任务为例，假设两个策略 A 和 B 都达到 40% 成功率：

| 指标 | 策略 A | 策略 B | 人类参考 |
|------|--------|--------|----------|
| 成功率 | 0.40 | 0.40 | 1.00 |
| 阶段进度 (TP) | 0.65 | 0.41 | 1.00 |
| 双臂高度差 ($\Delta z$) | 0.34 | 0.61 | 0.49 |
| 双臂速度差 ($\Delta v$) | 0.05 | 0.20 | 0.03 |
| 关节路径长度 | 11.22 | 47.03 | 3.33 |
| 完成时间 (s) | 3.66 | 6.17 | 0.45 |
| 环境碰撞 | 1.32 | 0.58 | 0.00 |
| 自碰撞 | 2.30 | 5.56 | 0.17 |

**诊断**：虽然 A 和 B 成功率相同（40%），但：
- 策略 A 的阶段进度更高（0.65 vs 0.41）→ 更接近完成
- 策略 A 的协调性更好（$\Delta v = 0.05$ vs $0.20$）→ 双臂更同步
- 策略 A 更高效（关节路径 11.22 vs 47.03，时间 3.66s vs 6.17s）
- 策略 B 碰撞更少（环境碰撞 $0.58$ vs $1.32$）→ 更保守

**结论**：策略 A 虽然碰撞略多，但整体执行质量显著优于策略 B。二元成功率完全掩盖了这一差异。

- 人类演示作为上界参考

### 6.3 隐含假设 (Hidden Assumptions)

1. **行为指标的低值 = 高质量**: 论文假设更短的路径、更低的 jerk、更小的协调差异意味着更好的策略。但在某些场景下（如精密操作），更长的路径和更高的 jerk 可能是有意为之的谨慎策略。
2. **仿真到真实的迁移**: 所有评估在仿真中进行，假设仿真中的行为指标排名能迁移到真实世界。
3. **人类演示作为黄金标准**: 论文将人类演示作为效率参考，但人类演示本身也有变异性（Table III 中人类指标的置信区间并非零）。
4. **指标独立性**: 13 项指标之间可能存在相关性（如路径长度和完成时间），但论文未做降维或主成分分析。
