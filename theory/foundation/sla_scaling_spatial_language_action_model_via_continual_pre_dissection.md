### 1.2 关键机制 (Key Mechanism)

- **为什么对齐视觉 token 而不是动作头**：论文 Eq. 1 把动作生成写成以视觉 token、语言 token、历史动作 token 为条件；作者据此论证“视觉 token 是动作生成的中间场景表征，应被正确监督”（作者主张，§3.1）。
- **为什么用冻结 3D 教师而不是加深度输入**：深度/点云输入会改变推理架构，且真实数据里深度与标定并不齐备；用训练时对齐可以复用 π0.5 权重，推理时零额外开销（论文 §3.2.1）。
- **为什么要自适应层选择**：不同数据域适合的对齐层不同；固定单层需要逐域做实验，且层 18 反而比层 12 差（Table 7：层 12 Clean2Random 67.3%，层 18 64.6%）。门控让多层特征按 token/通道加权融合（论文 §3.2.3）。
- **为什么要状态 dropout**：机器人状态可能成为“状态→示范轨迹”的捷径，削弱对视觉的依赖；按样本独立整段丢弃状态 token，鼓励使用视觉线索（论文 §3.2.4，引用 Lu et al. 2026；Zhao et al. 2025）。
- **为什么旋转用 SO(3) 复合而不是欧拉角相减**：欧拉角在 ±π 附近直接相减会产生数值跳变离群点，压缩归一化后的有效动作范围（论文 Figure 3）；改用 ΔR_t = R_t R_0^T 再取 Log 的旋转向量（Eq. 8–10）。

⚡ **Eureka Moment**：这篇论文最核心的一个想法是——**空间监督不必是推理时的输入模态，而可以是训练时的表征正则；而且“对齐哪一层”不该由人手工选，应该由可学习门控在多层特征上自适应分配。**

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：

```
L = L_action + α · mean_i [1 - cos(z_i, y_i)]
```

先给目标：让 VLA 的中间视觉 token 在余弦相似度意义下逼近冻结 3D 教师的逐像素空间表征，同时不破坏动作生成。再给公式与变量。

```
动作生成（Eq. 1）:
x_t^A ~ p_θ( x_t^A | {x_i^V}_{i=1..N}, {x_j^L}_{j=1..M}, x_<t^A )

动作损失（Eq. 2）:
L_action = L[ G({x_t^A}_{t=1..K}), A_gt ]

空间目标（Eq. 3）:
y = R[ f^3D(I) + E ]

跨层聚合（Eq. 4）:
z = F[{^(ℓ)x^V}_{ℓ=1..L}] = Σ_{ℓ=1..L} ^(ℓ)g ⊙ MLP[ LN( ^(ℓ)x^V ) ]

对齐损失（Eq. 5）:
L_align = (1/N) Σ_{i=1..N} [ 1 - S(z_i, y_i) ]

总损失（Eq. 6）:
L = L_action + α · L_align

门控（Eq. 7）:
^(ℓ)g_i = σ( W_g · ^(ℓ)x_i^V + b_g )

动作表示（Eq. 8–10）:
Δp_t = p_t - p_0
ΔR_t = R_t · R_0^T
Δr_t = Log(ΔR_t)^∨
```

| 符号 | 含义 | 备注 |
|------|------|------|
| x^V, x^L, x^A | 视觉、语言、动作 token | 视觉 token 数 N，语言 token 数 M，动作 token 数 K |
| ^(ℓ)x^V | 第 ℓ 层注意力后的视觉 token | ℓ = 1..L，论文中 L = 18（PaliGemma 语言主干层数） |
| f^3D | 冻结 3D 感知教师 | OmniVGGT；训练时冻结，推理丢弃 |
| E | 位置嵌入 | 加在教师特征上，保持空间位置顺序 |
| R[·] | 双线性重采样 | 把教师特征网格重采样到 VLA token 分辨率 |
| y_i | 第 i 个视觉 token 位置的空间目标 | 与 z_i 同视图、同图像位置 |
| g^(ℓ) | 逐 token、逐通道门控 | 参数跨层共享 |
| α | 对齐损失权重 | 论文未在正文给出具体取值（TODO：待补） |
| H | 动作 chunk 长度 | 论文正文未给出具体数值；Eq. 8–10 说明 chunk 内每个动作都以当前位姿 p_0, R_0 为参考 |
| Δt | 相邻动作的时间步长 | 由控制频率决定，论文未在正文给出 H 与 Δt 的具体组合 |

**直觉**：Eq. 5 不是回归特征值，而是最大化方向一致性；这使得对齐对教师特征的尺度不敏感，只要求“方向对”。Eq. 4 的门控是逐元素 sigmoid，相当于让每个 token 自己在不同层之间“选深度”；由于参数跨层共享，额外参数量很小。Eq. 8–10 的关键点是 **chunk 内所有动作共享同一个当前参考位姿**，而不是以前一个动作为参考，这避免了误差累积式的相对表示。

## 3. 带数字走一遍：玩具例子 (Worked Example)

> 以下数值为**假设**，用于验算公式闭环；不是论文实验数据。

**例 1：对齐损失**

假设 N = 4 个视觉 token，余弦相似度分别为 0.95、0.85、0.75、1.00。

```
L_align = (1/4)[(1-0.95) + (1-0.85) + (1-0.75) + (1-1.00)]
        = (1/4)[0.05 + 0.15 + 0.25 + 0]
        = 0.1125
```

若 L_action = 0.40，α = 0.5，则：

```
L = 0.40 + 0.5 × 0.1125 = 0.45625
```

这说明对齐项在 α 不太大时是“温和正则”，不会压过动作损失；论文没有在正文给出 α，因此这里只验算量级关系。

**例 2：旋转表示**

假设当前 R_0 = I，目标 R_t 是绕 z 轴 90° 旋转：

```
ΔR = R_t · R_0^T = R_t
Δr = Log(ΔR)^∨ = (0, 0, π/2) ≈ (0, 0, 1.5708)
```

若用欧拉角直接相减，当角度接近 +π 或 −π 时会出现 ±2π 跳变，归一化后会把典型值压缩到很窄的区间（论文 Figure 3 的定性描述）。这就是论文选择旋转向量 + SO(3) 复合的数值动机。

**例 3：动作 chunk 的时间跨度（假设 H = 4，Δt = 0.1 s）**

```
预测区间：t+1, t+2, t+3, t+4
终点距当前参考：4 × 0.1 = 0.4 s
若均匀采样 K = 5 个关键点，首末跨度：(5-1) × 0.1 = 0.4 s
```

注意：这 0.4 s 是**未来预测区间**，不能当作历史上下文或记忆窗口。论文正文未给出 H 的具体值，因此这里只做公式验算，不把 0.4 s 写成 SLA 的通用设置。

**例 4：记忆机制的时间跨度（假设 f = 30 Hz，t = 300 帧 = 10 s）**

按 Eq. 11：

```
M_t = [I_0, I_max(300-240,0), I_max(300-210,0), ..., I_max(300-30,0)]
    = [I_0, I_60, I_90, I_120, I_150, I_180, I_210, I_240, I_270]
```

- 近端 8 帧均匀间隔 30 帧 = 1 s，首末跨度 7 s；
- 加上 episode 初始帧 I_0 后，整体 9 帧**不是均匀间隔**，I_0 到 I_270 的跨度是 9 s；
- 若 t < 8f，缺失的近端帧用 I_0 填充（论文 Appendix B.1）。

因此不能简单套 `(K-1)×Δt`：记忆窗口是“初始帧 + 过去 8 秒每秒一帧”，且在 RoboDojo-Real 与 RoboDojo-Sim 的 post-training 使用。**动作 chunk 的未来区间与记忆的历史区间是两件事，不能互相替代。**

### 5.3 主要结果（论文实测，按来源标注）

- **LIBERO-Plus**：SLA 加权 SR 87.4%，比 π0.5 的 84.4% 高 3.0 个百分点，比 Spatial Forcing 的 85.1% 高 2.3 个百分点（Table 2）。七个维度中照明 98.8%、背景 98.0%、噪声 95.4% 为表中最高或并列最高；但 Robot 维度 73.8% 低于 Qwen-RobotManip 的 78.2%（Table 2）。
- **RoboTwin 2.0**：Clean2Clean 86.0%、Clean2Random 72.3%、平均 79.2%（Table 3）。Clean2Random 比 π0.5 的 46.0% 高 26.3 个百分点；平均比 Spatial Forcing 的 68.7% 高 10.5 个百分点。但 Clean2Clean 低于 ME-Dex-1.0 的 89.6%，Clean2Random 高于其 68.1%（Table 3）。
- **RoboCasa-Panda**：50 条/任务示范下 68.4%，比 Cosmos Policy 的 67.1% 高 1.3 个百分点、比 Spatial Forcing 的 67.6% 高 0.8 个百分点（Table 4）。注意表中 UVA、Cosmos Policy、Spatial Forcing 也使用 50 条/任务，其他若干高预算方法为 300–3,000 条/任务，论文明确在表中列出。
- **RoboDojo-Real**：平均 Score 42.3、SR 33.9%；π0.5 为 22.9 / 12.8（Table 5）。但 ARX X5 的 Score 50.3 低于 InternW0-Δ 的 59.7；Piper X 的 SR 仅 10.0%（Table 5）。Table 14 给出逐任务均值（ARX 50.7 / 38.3；Piper 60.3 / 53.3；Piper X 16.0 / 10.0），与 Table 5 的逐具身数值有轻微出入，整体平均 42.3 / 33.9 在两表中一致；论文正文未解释该差异。
- **真实部署 A–H**：SLA 平均 83.8%，π0.5 平均 59.8%，差 24.0 个百分点（Table 11）。逐条件：A 94%、B 82%、C 76%、D 78%、E 98%、F 84%、G 78%、H 80%。E 条件比 Spatial Forcing 的 94% 只高 4 个百分点，论文自己指出这相当于 50 个实例里多 2 个成功。
- **数据缩放消融**：两阶段都对齐时，5% 数据 49.2% → 100% 数据 72.3%，增益 23.1 个百分点；两阶段都不对齐时 43.8% → 48.2%，增益 4.4 个百分点（Table 6）。全数据下，仅预训练对齐 63.2%、仅后训练对齐 57.1%（Table 6）。
- **自适应层选择**：固定层 1/6/12/18 的 Clean2Random 分别为 43.4/45.0/67.3/64.6%，自适应 72.3%；平均 51.7/54.0/75.7/71.3% vs 79.2%（Table 7）。
- **状态 dropout**：0/25/50/75/100% 的平均 SR 为 38.1/79.2/53.9/61.9/56.7%（Table 8）；25% 最优。
- **旋转表示**：Euler 65.5%、Rot6D 62.9%、Quaternion 74.3%、Rotation Vector 79.2%（Table 9，均为平均 SR）。
- **相机标定**：无对齐 31.8%、VGGT 42.5%、OmniVGGT 无标定 42.8%、OmniVGGT 有标定 46.0%（Table 10，平均 SR）。

## 6. 能力与失败模式 (Capabilities & Failure Modes)

**能做好的**：

- **视觉扰动下的鲁棒性**：LIBERO-Plus 的 noise 95.4%、background 98.0%、light 98.8% 相对 π0.5 有提升（Table 2）。作者把原因归为“空间信息化的视觉表征帮助策略在观测扰动下保留任务相关场景结构”（作者主张，§4.3.1）。
- **仿真到随机的泛化**：RoboTwin Clean2Random 72.3%，比 π0.5 高 26.3 个百分点（Table 3）；作者认为这支持“超越 clean 训练条件的泛化”。
- **少样本下游适配**：RoboCasa-Panda 每任务 50 条示范下 68.4%，与使用 300–3,000 条示范的方法可比（Table 4）。
- **动态目标响应**：真实条件 C（人移动水果）SLA 76%，Spatial Forcing 58%，π0.5 42%（Table 11）。

**做不好或未验证的**：

- **逐任务方差大**：RoboTwin 的 Place Cans Plasticbox 从 Clean2Clean 96% 掉到 Clean2Random 40%，Handover Block 从 91% 掉到 38%（Table 12）；说明 clean 条件强不等于随机条件强。
- **跨具身仍有明显弱项**：RoboDojo-Real 的 Piper X 只有 10.0% SR（Table 5/Table 14）；ARX X5 的 Score 低于 InternW0-Δ。
- **长程与记忆**：RoboDojo-Sim 的 Long-Horizon 为 22.3 / 11.9%，低于多数基线（Table 15）；Memory 维度 26.2 / 25.8% 虽高，但那是**只启用预训练对齐 + 记忆机制**的设置，不能直接归因于 SLA 全配方。
- **真实部署接近天花板的条件**：E 条件 98% vs 94%，论文自己说 50 个实例里只多 2 个成功（§4.5.2）。
- **记忆机制缺少消融**：论文没有给出“有/无记忆”的对照表，只在 Appendix B 描述构造与编码；因此无法从论文判断记忆对 RoboDojo-Real 的贡献大小（TODO：待补）。

### 6.1 隐含假设 (Hidden Assumptions)

1. **冻结 3D 教师的空间特征可跨具身迁移**：OmniVGGT 在 RGB-only 时也能提供有用目标（Table 10：VGGT 42.5% vs OmniVGGT 无标定 42.8%，差异很小），但论文没有验证教师特征在不同相机内参/视角分布下的稳定性。
2. **对齐不会破坏 π0.5 的语义能力**：论文用 LIBERO-Plus 的语言扰动 83.5%（vs π0.5 80.8%）间接支持，但没有做纯语义任务（如 VQA）的保留性测试。
3. **状态 dropout 25% 是通用最优**：只在 RoboTwin 上扫了 0–100%，没有在 LIBERO-Plus、RoboCasa-Panda、真实部署上验证。
4. **EEF 统一动作空间足以吸收具身差异**：论文排除了灵巧手与移动底座，只保留两指夹爪；对更复杂具身的可扩展性未验证。
5. **数据筛选规则不引入分布偏置**：下采样比例（3%/10%、0.5%/15%）是工程选择，论文没有给出这些比例对最终性能的敏感性分析。

## 7. 与相关工作对比 (Comparison)

| 方法 | 3D 引入方式 | 训练阶段 | 推理是否需额外 3D 输入 | 与 SLA 的关键差异 |
|------|-------------|----------|------------------------|-------------------|
| PointVLA / GeoVLA | 点云特征融合 | post-training | 是 | 显式 3D 输入，改变推理架构 |
| BridgeVLA | 3D 观测投影到多视图 | post-training | 是 | 输入输出对齐，仍需几何预处理 |
| FALCON | 空间基础模型几何 token 融合进动作头 | post-training | 是 | 动作头层面融合 |
| Spatial Forcing | 隐式视觉嵌入对齐 | **仅 post-training** | 否 | SLA 的直接前身；SLA 把它扩展到持续预训练 |
| ROCKET | 多层空间对齐 | post-training | 否 | 多层对齐但未做持续预训练与自适应门控 |
| VEGA | 监督视觉编码器输出 | post-training | 否 | 监督位置不同 |
| Mind-VLA | 指令感知的目标物体表示对齐 | post-training | 否 | 对齐目标更语义化 |
| **SLA** | 隐式视觉嵌入对齐 + 自适应跨层门控 | **持续预训练 + post-training** | 否 | 两阶段都对齐；门控参数跨层共享；教师丢弃 |

**面试 Tip**：一句话——“SLA 的卖点不是又加了一个 3D 编码器，而是把 Spatial Forcing 的隐式对齐从 post-training 搬到 continual pre-training，并用可学习的跨层门控把‘选哪层对齐’变成可训练参数；推理时教师、投影器、门控全部丢掉；未启用记忆机制的条件部署成本与 π0.5 相同，但 RoboDojo-Real / RoboDojo-Sim 因保留历史图像输入与在线帧缓冲而增加推理开销。”

## 8. 精读建议 (Reading Guide)

- **值得精读原文的人**：
  - 正在做 VLA 空间增强、且不想改推理架构的研究者：重点看 §3.2.1–§3.2.3 与 Table 7/Table 10。
  - 需要评估“持续预训练是否值得”的工程团队：重点看 §4.2 的训练成本、§4.4.1 的数据缩放曲线、Table 6。
  - 做跨具身数据统一的研究者：重点看 §3.3.2 的 EEF 坐标约定、旋转表示与下采样策略。
- **建议章节路径**：先读 §3.2（对齐 + 门控）→ 再看 §4.4（消融，理解每个设计的边际贡献）→ 最后看 §4.3 与 Appendix B（评测与记忆机制）。若只关心结论，读摘要 + Table 2–6 + Table 11 即可。
- **不值得精读的理由**：如果你不做机器人学习、或已经熟悉 Spatial Forcing / ROCKET 这类隐式对齐路线，这篇的方法增量主要是“训练阶段前移 + 门控 + 数据统一”，读摘要与 Table 6 就能抓住要点；如果你只关心显式 3D 输入架构，这篇不是同一条路线。
