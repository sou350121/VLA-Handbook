## 1. 核心架构/方法总览 (Overview / Architecture)

### 1.1 系统对比概览 (System Component Comparison)

| 组件 | 输入 | 输出 | 训练阶段 | 推理位置 |
|------|------|------|----------|----------|
| **策略 πθ (Actor)** | 多模态状态 (图像+语言指令) | 动作块 a_t:t+H (H 步关节位置) | 离线全量微调 → 在线仅 action expert 更新 | 边缘端（每台机器人） |
| **Critic Qφ** | 状态表征 z_t + 动作块 a_t | 标量 Q 值 (双 Q clipped min) | 离线+在线持续全量微调 | 集中式 learner |
| **分布价值 Vψ** | 状态表征 z_t | 分类分布 (201 atoms) | 离线+在线持续全量微调 | 集中式 learner |
| **参考策略 πβ** | 同上 | 动作块 (用于 QAM 参考轨迹) | 离线 BC 初始化后冻结 | 仅 learner 端使用 |

**关键设计差异**：
- 策略与价值/critic 模块完全分离——只有策略 checkpoint 异步分发到 fleet
- 在线阶段 VLM backbone 冻结，仅更新 300M 的 action expert，保持高效
- 离线阶段用 n-step TD target (n=10 长程任务) 冷启动；在线阶段用 1-step

### 1.2 关键机制 (Key Mechanism)

**为什么这样设计？**

1. **DIVL（分布隐式价值学习）**：车队异步采集的数据是多模态、重尾的——同一状态-动作对在不同场景下可能对应成功、失败或人工干预。标量 critic 会把稀有但可复现的成功模式"平均掉"，而分类分布保留了高回报模式。

2. **QAM（伴随匹配策略提取）**：对 Flow-based VLA 直接反向传播 critic 梯度到多步去噪过程既昂贵又不稳定。QAM 将轨迹级策略优化转化为沿参考流的局部回归目标——critic 梯度只在终点计算一次，然后通过伴随方程传播到整个流。

3. **自适应 τ**：混合任务 replay 中，不同状态的置信度差异很大。DIVL 用价值分布的归一化熵作为不确定性信号，高熵状态降低 τ（保守），低熵状态保持高 τ（乐观）。

⚡ **Eureka Moment**：把"部署"从训练的终点重新定义为持续改进的数据源——车队本身就是一个不断生成目标分布样本的探索引擎。

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：
```
LWD = DIVL_value_learning + QAM_policy_extraction + offline_to_online_flywheel
```

**目标**：从车队部署经验中持续改进预训练 VLA 策略，同时保持通用性不坍缩到单一任务。

**核心方程**：

```
TD target (DIVL):
  y_Q = r_t + γ^H · Quant_τ(V_ψ(s_{t+H}))

  其中 Quant_τ 是分布价值模型 V_ψ 的 τ 分位数
  τ 根据分布熵自适应: τ(s) = clip(τ_base - α·H(s), τ_min, τ_max)

 critic loss:
  L_Q(φ) = E[(Q_φ(s_t, a_t) - y_Q)^2]

 分布价值 loss:
  L_V(ψ) = E[-log p_ψ(Q_φ_bar(s_t, a_t) | s_t)]

 QAM policy loss:
  L_QAM(θ) = E[∫_0^1 || 2·f_δ(s, a^w, w)/σ_w + σ_w·g̃_w ||^2 dw]

  其中 f_δ = f_θ - f_β (策略场与参考场的差)
  g̃_1 = -∇_a[Q_φ(s, a^1)/λ] (critic梯度初始化的伴随终端条件)
```

**变量说明**：

| 符号 | 含义 |
|------|------|
| s_t = (o_t, ℓ_k) | 状态：观测 + 语言指令 |
| a_t | 动作块 [a_t, ..., a_{t+H-1}]，H 步关节位置 |
| r_t | 稀疏二元奖励（成功=1，否则=0） |
| γ | 折扣因子 |
| H | 动作块长度 |
| τ | 分位数（控制bootstrap乐观程度） |
| λ | QAM 温度参数 |
| f_θ, f_β | 可训练/参考 flow 向量场 |
| g̃_w | 伴随状态 |

> 符号与论文保持一致。DIVL 的分布价值模型 V_ψ 用 201 个原子的分类离散化实现，支撑范围 [-0.1, 1.1]。

**直觉**：DIVL 先学"每个状态下各种动作值的全貌"（分布而非单点），然后取高分位数作为 optimistic bootstrap；QAM 则用 critic 的梯度信息指导 flow 策略朝高价值方向微调——两者通过同一 RL 目标在 offline 和 online 阶段保持一致，避免了常见的 offline-to-online 失配。

## 3. 带数字走一遍：玩具例子 (Worked Example)

假设一个简化的长程任务场景：泡茶任务，分为 3 个子步骤（放茶叶→倒水→出汤），每步执行一个 action chunk。

**场景设置**：
- 动作块长度 H = 10 步
- 折扣 γ = 0.99
- 只有最终成功时 r = 1，否则 r = 0

**Step 1 — 分布价值学习**：
在状态 s_t（"已放茶叶，等待倒水"），replay buffer 中有 100 个动作：
- 60 个来自成功轨迹 → critic Q 值集中在 [0.7, 0.9]
- 30 个来自失败轨迹 → critic Q 值集中在 [0.1, 0.3]
- 10 个来自人工干预 → critic Q 值在 [0.4, 0.6]

DIVL 学到一个三峰分布 p_ψ(v|s_t)：
```
[0.1-0.3]: 30%  ████████████████████
[0.4-0.6]: 10%  ███████
[0.7-0.9]: 60%  ████████████████████████████████████████
```

标量 IQL 会把这三个模式压缩成一个期望值 ~0.55，丢失了"存在高价值模式"的信号。
DIVL 的 τ = 0.7 分位数 → Quant_0.7 ≈ 0.72，保留了高回报模式的信息。

**Step 2 — TD Backup**：
假设下一步 s_{t+H} 的分布价值 0.7 分位数为 0.80：
```
y_Q = 0 + 0.99^10 × 0.80 = 0.904 × 0.80 = 0.723
```
critic 被引导向 0.723 更新。

**Step 3 — QAM 策略更新**：
critic 在终点 a^1 的梯度 ∇_a Q_φ(s, a^1) 指示"哪个方向的修改能提高 Q 值"。
伴随方程从 g̃_1 = -∇_a Q_φ/λ 开始反向传播，生成 g̃_w 轨迹。
QAM loss 将 f_θ 向 f_β + 修正量 回归，修正量的大小由 critic 梯度和伴随状态共同决定。

**结果**：策略在"倒水"子步骤的动作分布向高 Q 值区域偏移，但不脱离原始 flow 的表达能力范围。

## 4. 工程视角 (Engineering View)

| 工程维度 | 设计选择 | 含义 |
|----------|----------|------|
| **推理延迟** | 策略 backbone 在线冻结，仅 300M action expert 更新 | 边缘端推理不受在线训练影响；30 Hz 关节控制实时性保持 |
| **通信开销** | 仅分发策略 checkpoint（非 critic/value），每 50 步同步 | 减少 fleet→learner 上行带宽需求；异步架构容忍网络延迟 |
| **内存占用** | Actor (PaliGemma 2B + 300M expert) + Critic/Value (Gemma3-270M + SigLIP-400M) | 策略 ~2.3B 参数在边缘部署；critic/value ~670M 仅在 learner |
| **数据效率** | 4 小时 wall-clock ≈ 60 总机器人小时；混合 offline+online replay | 每任务约 3.75 机器人小时；离线 buffer 提供冷启动减少在线探索需求 |
| **训练稳定性** | 双 Q clipped min + EMA target network + 分布价值 | 缓解 off-policy 高估；分布模型对重尾回报鲁棒 |
| **部署约束** | 16 台 Agibot G1 双机械臂；3 RGB 相机/台 | 硬件门槛高；算法组件可降级到单机验证 |

**关键 trade-off**：在线阶段只用 1-step TD target（放弃离线阶段的 n-step 加速），因为在线轨迹混合了自主执行和人工干预，长 backup 可能跨越策略边界导致 TD 路径不一致。这是数据异质性 vs. 信号传播速度的经典权衡。

### 6.1 隐含假设 (Hidden Assumptions)

1. **价值分布的分类离散化足以捕捉多模态回报**：201 个原子在 [-0.1, 1.1] 范围内——对于极端重尾分布可能不够精细。

2. **QAM 的 KL 正则化强度（温度 λ）在所有任务上通用**：不同任务的探索-利用权衡可能不同，但论文未做任务级调参分析。

3. **参考策略 πβ 冻结不变是安全的**：QAM 始终相对于初始 BC 策略做改进——如果 BC 策略在某些状态-动作空间完全空白，QAM 无法覆盖这些区域。

4. **稀疏二元奖励足够引导长程任务**：3-5 分钟任务仅靠终端 r=1/0 信号，中间子步骤无密度奖励——依赖 TD backup 的传播能力。

5. **16 台机器人 fleet 的数据多样性代表目标部署分布**：如果实际部署环境超出 fleet 覆盖范围，策略可能无法泛化。
