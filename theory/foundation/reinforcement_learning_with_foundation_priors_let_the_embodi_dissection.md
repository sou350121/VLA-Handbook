## 1. 核心架构/方法总览 (Overview / Architecture)

### 1.1 系统对比概览 (System Component Comparison)

| 维度 | Vanilla RL (DrQ-v2) | RLFP + FAC (本文) |
|------|---------------------|-------------------|
| **奖励来源** | 人工设计密集奖励 | 基础模型自动奖励：λ·M_R + F(价值塑形) |
| **策略初始化** | 随机 | 基础策略先验 M_π warm start（前10条轨迹全用先验） |
| **探索引导** | 纯随机噪声 | 策略正则化 KL(π_φ, N(M_π, σ²)) + 价值引导选择 a* = argmax_k Q(s, a_i) |
| **成功反馈利用** | 无 | Success Buffer 存储成功轨迹，策略更新时做 Imitation |
| **样本效率** | 1M frames 仍多数任务失败 | 100k frames（~1h）7/8 任务 100% 成功 |
| **人工工程** | 每个任务需设计奖励函数 | 零人工奖励，仅需基础模型接口 |
| **基础模型依赖** | 无 | 3 个：M_π（代码/扩散）、M_V（VIP）、M_R（GPT-4V/成功分类器） |

### 1.2 关键机制 (Key Mechanism)

RLFP 框架将三个基础模型先验注入 RL 的三个核心环节：

1. **策略先验 M_π(s, T) → 行为 Warm Start + 正则化**
   - 真实机器人：GPT-4V 生成代码策略（给定原始技能接口 move_to、grasp、release）
   - 仿真：视频扩散模型（Seer 微调 10 条视频/任务）+ 逆动力学推断动作
   - 正则化项：L_reg(φ) = KL(π_φ, N(M_π(s_t, T), σ²))，约束策略不偏离先验太远

2. **价值先验 M_V(s, T) → 奖励塑形 (Reward Shaping)**
   - 使用 VIP 模型（输入当前图 + 目标图 → 价值估计）
   - 塑形函数：F(s, s', T) = γ·M_V(s', T) - M_V(s, T)
   - 关键性质：潜在函数塑形不改变最优策略（Therorem A.1 证明）

3. **成功奖励先验 M_R(s, T) → 0-1 稀疏奖励 + Success Buffer**
   - 真实机器人：GPT-4V 判断最终帧是否成功（准确率极高，Watering Plants 有 25% 假阳性）
   - 仿真：Ground Truth 0-1 奖励（GPT-4V 在仿真图上表现差）
   - 成功轨迹存入 D_succ，策略更新时做 KL 模仿

⚡ **Eureka Moment**：把人类学习的三种直觉（做什么/离目标近了吗/成功了吗）精确映射到 RL 的三个组件（策略函数/价值函数/奖励函数），并用现有基础模型分别填充——不是训练一个新模型，而是组装已有模型。

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：
```
L_actor = -E[min_k Q_k(s, a)] + α·KL(π_φ, D_succ) + β·KL(π_φ, N(M_π, σ²))
L_critic = E[(Q_θ(s, a) - y)²]
奖励: r = λ·M_R(s, T) + γ·M_V(s', T) - M_V(s, T)
```

**目标**：在 GCMDP 中最大化累积奖励，其中奖励由基础模型自动构建，策略由基础模型先验引导。

**公式拆解**：

| 符号 | 含义 | 来源 |
|------|------|------|
| M_π(s, T) | 策略先验函数 S×T→A | GPT-4V 代码生成 或 Seer 视频扩散 |
| M_V(s, T) | 价值先验函数 S×T→R | VIP 模型（当前图+目标图→价值） |
| M_R(s, T) | 成功奖励函数 S×T→{0,1} | GPT-4V（真实）或 GT（仿真） |
| F(s, s', T) | 价值塑形奖励 = γ·M_V(s') - M_V(s) | 潜在函数 reward shaping |
| λ | 成功奖励权重 = 100 | 超参 |
| α, β | 成功模仿/策略正则权重 = 1 | 超参 |
| γ | 折扣因子 = 0.99 | 标准 RL |

> 符号与本文保持一致。FAC 基于 DrQ-v2（SAC 变体），使用 clipped double Q-learning 减少高估。

**直觉**：奖励 = 成功信号（λ 放大）+ 价值增量（稠密引导）。策略更新 = Q 最大化 + 成功轨迹模仿 + 先验正则化。三者协同：先验给方向，价值给梯度，成功给锚点。

## 3. 带数字走一遍：玩具例子 (Worked Example)

假设一个简化的 2D 机械臂任务：将手移动到目标按钮位置。

**初始状态** s_0：手在 (0, 0)，目标在 (2, 1)。

**Step 1 — 策略先验给出初始动作**：
- M_π(s_0) = (0.5, 0.3)（代码策略建议向右上方移动）
- Actor π_φ 初始化接近 M_π，输出 a_φ = (0.4, 0.2)
- 安全探索选择：Q(s_0, a_prior) = -5.2，Q(s_0, a_φ) = -6.1 → 选择先验动作

**Step 2 — 执行并观察**：
- s_1 = (0.5, 0.3)，M_V(s_0) = -3.0（离目标远），M_V(s_1) = -1.5（更近了）
- 塑形奖励 F = γ·(-1.5) - (-3.0) = 0.99·(-1.5) + 3.0 = 1.515（正值 = 方向正确）
- M_R(s_1) = 0（未成功）
- 总奖励 r = 100·0 + 1.515 = 1.515

**Step 3 — 再走一步**：
- s_2 = (1.0, 0.6)，M_V(s_2) = -0.5
- F = 0.99·(-0.5) - (-1.5) = 1.005
- M_R(s_2) = 0，r = 1.005

**Step 4 — 到达目标**：
- s_3 = (2.0, 1.0)，M_R(s_3) = 1
- F = 0.99·0 - (-0.5) = 0.5（价值已饱和）
- r = 100·1 + 0.5 = 100.5 ← 成功信号爆发

**Critic 更新**（n=3 step TD target）：
```
y = r_0 + γ·r_1 + γ²·r_2 + γ³·min_k Q_k(s_3, a_3)
  = 1.515 + 0.99·1.005 + 0.9801·100.5 + 0.9703·(-0.2)
  ≈ 1.515 + 0.995 + 98.500 + (-0.194)
  ≈ 100.816
```

**Actor 更新**：
- Q 梯度：推动 a 使 Q(s, a) 接近 y ≈ 100.8
- L_reg：KL(π_φ, N(M_π, 0.01)) 防止偏离先验太远
- L_succ：此时 D_succ 为空（首次成功），无模仿损失

**关键观察**：塑形奖励 F 在初期提供稠密梯度（1.515, 1.005），让 agent 知道"方向对了"；成功奖励 λ·M_R = 100 在终点提供强信号。两者叠加，避免了 sparse reward 的探索困境。

## 4. 工程视角 (Engineering View)

| 工程维度 | 数值/设置 | 含义 |
|----------|-----------|------|
| 真实机器人学习速率 | ~1 trajectory/min | 5 任务共 340 条轨迹，平均 1 小时/任务 |
| 仿真训练帧数 | 100k frames（7/8 任务） | 约 1 小时训练（25fps ≈ 4000 steps/min） |

| 策略标准差 | 固定 σ = 0.1 | 不学习方差，简化优化 |
| 基础模型推理开销 | GPT-4V: ~1-2s/次（成功判定） | 仅终态调用，不影响控制频率 |
| VIP 推理开销 | ~50ms/次（价值估计） | 每步调用，需 GPU |
| 策略先验推理 | 代码策略: ~10ms；扩散: ~200ms | 代码策略快但灵活性差 |
| 内存占用 | DrQ-v2 + 2×Q + Actor + VIP | 约 500MB-1GB（取决于视觉编码器） |
| 控制频率 | 真实: ~10Hz；仿真: 25fps | VIP 是瓶颈（真实环境） |

**工程含义**：
- VIP 价值模型每步调用是实时部署的主要瓶颈。可考虑：(1) 蒸馏为轻量网络；(2) 降频调用（每 N 步更新一次价值）；(3) 缓存相似状态的价值估计
- GPT-4V 仅终态调用，API 延迟可接受，但成本和稳定性是隐患
- 固定 σ = 0.1 简化了实现但限制了探索自适应能力

## 6. 能力与失败模式 (Capabilities & Failure Modes)

### 能做什么
- **桌面操控任务**：5 种真实机械臂任务 + 8 种 Meta-World 仿真任务全部验证
- **免人工奖励**：无需为每个任务设计密集奖励函数
- **快速适应**：1 小时内从先验策略精调到可靠执行
- **噪声容忍**：对策略先验的量化误差和随机噪声有较强鲁棒性

### 不能做什么
- **非桌面/移动操作**：实验仅限于固定基座机械臂的桌面操作，未验证移动机器人、双臂协作或人形平台
- **长程多步骤任务**：任务序列最长约 10-15 步，未测试需要数十步以上规划的任务
- **强依赖先验质量**：当策略先验错误率 ≥50% 时性能崩溃
- **仿真到真实的价值迁移**：VIP 在仿真和真实中都使用同一模型，但未做系统的 Sim2Real 价值对齐实验

### 6.1 隐含假设 (Hidden Assumptions)

1. **成功判定可自动化**：假设 M_R 可以高精度判断成功。GPT-4V 在真实场景准确率很高，但 Watering Plants 有 25% 假阳性——这类错误会向 agent 传递错误信号。仿真中直接用 GT 回避了这个问题。

2. **价值先验已预训练**：VIP 是在大规模数据集上预训练的通用价值模型。如果目标域与 VIP 训练域差异大（如非常规物体、非常规视角），价值估计可能完全误导。

3. **策略先验至少"大致正确"**：代码策略依赖 GPT-4V 对任务的理解；扩散策略依赖少量示例视频微调。如果先验策略完全错误（如理解了错误的任务），正则化项反而会成为阻碍。

4. **单任务设定**：每个任务独立训练，未测试多任务/持续学习场景。先验是否需要为每个任务重新获取？
