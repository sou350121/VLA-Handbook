## 1. 核心架构/方法总览

### 1.1 系统对比概览

| 组件 | 传统随机测试 | 本文主动测试框架 |
|------|-------------|-----------------|
| 配置选择 | 均匀随机采样 | 基于代理模型不确定性 + 采集函数优化 |
| 性能度量 | 二元成功率 | 连续评分（0-6 级渐进式评分） |
| 统计严谨性 | 通常 <15 次/任务 | 预算 100 次，多次重复取均值 |
| 泛化估计 | 无法预测未测试配置 | 代理模型提供全空间性能预测 + 不确定性 |
| 失败模式识别 | 依赖人工观察 | 自动定位高不确定性/低性能区域 |
| 可重复性 | 随机性导致高方差 | 低方差（主动选择确定性高） |

### 1.2 关键机制

框架的核心是一个闭环迭代：

1. **设计空间定义**：将部署相关变量结构化为因子（物体位置 11×11 网格、桌高 3 档、相机视角 3 个），共 ~800 个有效配置
2. **代理模型拟合**：用已评估数据训练概率模型（GP / MDN / Deep Ensemble），输出每个未测试配置的性能预测 + 不确定性
3. **采集函数优化**：选择不确定性最高或信息增益最大的配置
4. **真实执行**：在物理机器人上执行该配置，记录评分
5. **更新迭代**：将新数据加入训练集，回到步骤 2

⚡ **Eureka Moment**：评估策略本身可以是一个主动学习问题——不是"随机撒网然后算成功率"，而是"用代理模型智能选择下一个测哪里最能缩小性能分布的不确定性"。

## 2. 数学核心

📌 **Napkin Formula**（一行抓住本质）：
```
x_t* = argmax_x α(x; SM(D_{t-1}))   s.t.   Σ 1{trials} ≤ T_budget
```

核心目标：在有限评估预算 T 内，选择序列 {x_1, ..., x_T} 使得代理模型对整个设计空间 X 上未知性能函数 f(x) 的估计误差最小。

**目标函数**：
```
min_{x_1,...,x_T}  E[ RMSE(μ_T, f) ] + E[ -LL(p_T, f) ]
```

其中 μ_T 是代理模型在 T 步后的预测均值，p_T 是预测分布。

**代理模型核心方程（GP 为例）**：
```
μ_t(x) = k_t(x)^T · (K_t + σ_n²·I)^{-1} · y_t
σ_t²(x) = k(x,x) - k_t(x)^T · (K_t + σ_n²·I)^{-1} · k_t(x)
```

**采集函数核心方程（BALD 为例）**：
```
α_BALD(x) = H[y | x, D_t] - E_{p(ω|D_t)}[H[y | x, ω]]
          = I(y; ω | x, D_t)    ← 模型参数与预测的互信息
```

**变量说明**：

| 符号 | 含义 |
|------|------|
| f(x) | 未知性能函数，配置 x → 连续评分 |
| 𝒟_t | t 步后已评估数据集 {(x_i, y_i)} |
| μ_t(x), σ_t²(x) | 代理模型预测均值和方差 |
| k(x, x') | RBF-ARD 核函数，编码因子间相似度 |
| ℓ_i | 每因子的自动相关确定长度尺度 |
| α(x) | 采集函数，衡量候选配置的信息量 |
| ω | 代理模型参数（MDN/Deep Ensemble 场景） |

> 直觉：GP 的 σ_t²(x) 告诉你"哪里不确定"，BALD 的互信息告诉你"哪里测了最能更新模型"。两者结合，主动测试总是选"最值得一测"的配置。

## 3. 带数字走一遍：玩具例子

假设一个简化场景：设计空间只有 3×3 = 9 个配置（2 个因子各 3 个取值），预算 T = 10 次评估。

**第 0 步：初始化**
- 随机选 N₀ = 3 个配置执行：x₁=(0,0)→y=2.0, x₂=(1,1)→y=1.5, x₃=(2,2)→y=0.5
- 拟合 GP：学到 ℓ_1 ≈ 0.5（因子 1 影响大），ℓ_2 ≈ 1.0（因子 2 影响小）

**第 1 步：主动选择**
- 对剩余 6 个配置计算采集函数值（以 PSD 为例，取最大标准差）：
  - σ(0,1) = 0.8, σ(1,0) = 0.9, σ(1,2) = 0.7, σ(2,0) = 0.6, σ(2,1) = 0.5, σ(0,2) = 0.4
- 选择 x₄ = (1,0)，σ 最大 = 0.9

**第 2 步：执行 + 更新**
- 真实执行 x₄=(1,0) → y₄ = 1.8
- 更新数据集 D₁ = D₀ ∪ {(1,0), 1.8}
- 重新拟合 GP，此时 (1,0) 附近的不确定性大幅下降

**第 3 步：重新计算**
- 现在最大不确定性可能转移到角落 (0,2) 或 (2,0)
- 继续选择 → 执行 → 更新

**10 步后**：代理模型对全 9 个配置的 RMSE 可能已降至 0.3 以下。对比随机测试，同等 RMSE 可能需要 13-14 步。

## 4. 工程视角

| 维度 | 数值/约束 | 工程含义 |
|------|----------|---------|
| 每次评估耗时 | ~1 分钟（含场景重置） | 100 次 = ~1.7 小时，vs 全量 2331 次 = ~39 小时 |
| 代理模型训练 | GP: 秒级；MDN/DeepEns: 分钟级 | 每轮迭代需重新拟合，GP 在小数据下更轻量 |
| 采集函数计算 | 遍历全候选空间 ≈ 800 次评估 | 计算成本可忽略，远小于一次真实硬件执行 |
| 初始样本 N₀ | 30（论文设定） | 太少 → 代理模型初始偏差大；太多 → 浪费预算 |
| 预算 T | 100（论文设定） | 典型部署场景下可接受的评估量 |
| 设计空间维度 | 3 因子（论文） | 维度灾难：4 因子 × 各 5 取值 = 625，已接近上限 |
| 代理模型选择 | Deep Ensemble + BALD 最佳 | 需权衡：GP 小样本强但 O(n³)；DeepEns 可扩展但需更多数据 |

**部署约束**：该框架假设每次评估需要人工或半自动重置场景。如果场景重置可自动化（如机械臂自动摆放物体），则评估速度可大幅提升，此时框架的价值从"省次数"转向"更准确估计"。

## 5. 数据与评测

**数据规模**：
- 3 个真实桌面操作任务，使用 UR5e 机械臂
- 全量评估：2331 次真实硬件执行（804 + 804 + 723）
- 每个任务约 39 小时人工评估时间
- 主动/随机测试离线模拟：从全量结果中无放回采样

**任务设计**：

| 任务 | 难度 | 评分范围 | 子步骤数 |
|------|------|---------|---------|
| Pick up blue block | 低 | 0.0-2.0（5 级） | 定位→接近→抓取→举起 |
| Set cup upright | 中 | 0.0-3.0（7 级） | 定位→接近→抓取→翻转→放置 |
| Put green block in pot | 高 | 0.0-6.0（13 级） | 开盖→定位→抓取→搬运→放入 |

**评测指标**：
- **RMSE**：代理模型预测均值 vs 真实评分的均方根误差
- **预测对数似然**：评估代理模型预测分布的质量（均值准确性 + 不确定性校准）

**因子设计**：
- 物体位置：11×11 网格（训练数据来自左下+右上象限）
- 桌高：{1, 2, 3} 英寸（训练数据来自 1 和 3 英寸，2 英寸为 OOD）
- 相机视角：{back, right, back-right}（训练数据来自 back 和 right，back-right 为 OOD）

## 6. 能力与失败模式

### 能做什么
- **预算内最大化信息获取**：在 100 次评估预算下，RMSE 比随机测试低 20-40%
- **泛化性能预测**：代理模型可准确预测 ID 和 OOD 因子值上的策略性能
- **失败模式定位**：自动识别高不确定性区域（可能是策略的盲区）
- **因子重要性分析**：通过 GP 的 ARD 长度尺度，自动学习哪些因子对性能影响最大
- **低方差**：主动测试在不同运行间方差更低，结果更稳定可重复

### 不能做什么
- **不适用于多策略比较**：框架设计为单策略性能估计，不是策略间对比
- **不处理策略随机性**：假设策略在固定配置下行为一致（论文基于 UR5e 的确定性观察）
- **因子空间有限**：仅 3 因子，未覆盖光照、物体纹理、语言指令变化等
- **离线模拟非在线**：实验通过离线采样模拟主动测试，未在线闭环执行

### 6.1 隐含假设 (Hidden Assumptions)

1. **策略确定性**：假设同一配置下策略输出一致。真实场景中策略可能有随机性（如采样温度 > 0），这会引入不可约的 aleatoric 噪声
2. **因子可重置**：假设每次评估后场景可精确重置到目标配置。实际中机械定位误差会累积
3. **评分一致性**：渐进式评分依赖人工判断，不同评估者可能有不同标准
4. **因子独立性**：设计空间假设因子间正交，但实际中物体位置和相机视角可能耦合
5. **代理模型充分性**：假设 GP/MDN/DeepEns 能充分捕捉性能函数的结构。对于高度非平滑的性能地形，代理模型可能欠拟合
