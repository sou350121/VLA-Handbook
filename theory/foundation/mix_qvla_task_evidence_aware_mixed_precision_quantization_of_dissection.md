### 1.2 关键机制 (Key Mechanism)

Mix-QVLA 的核心流程分三步：

1. **任务证据敏感度估计**：对每个候选层-位宽对 (m, b)，在 4 个 VLA 功能边界上计算梯度加权任务证据图，比较 FP 与量化版本的证据质量与分配差异，聚合为层敏感度分数 Ω(m,b)。

2. **时间感知敏感度**：将校准样本按轨迹进度 ρ ∈ [0,1] 分 bin，计算每个时间窗的敏感度，取最大退化作为时间敏感度 Ω_τ(m,b)。

3. **约束优化分配**：将敏感度分数输入二进制线性规划，在模型大小和 BitOps 预算约束下最小化总证据退化。

⚡ **Eureka Moment**：量化后的模型可以输出几乎相同的动作命令，但内部支撑该决策的证据链可能已经完全断裂——这是仅看动作偏差无法发现的盲区，而 Mix-QVLA 通过锚定 FP 决策证据来直接度量这一断裂。

## 2. 数学核心 (Math Core)

### 📌 Napkin Formula（一行抓住本质）

```
Ω(m,b) = avg_i [ κ·log( avg_γ exp(ℓ_ev_i,γ(m,b) / κ) ) ]
```

层敏感度 = 所有校准样本上、软瓶颈聚合的边界级任务证据退化。

### 目标

最小化量化对全精度策略内部决策证据链的破坏，在模型大小和 BitOps 预算约束下为每层分配最优位宽。

### 核心公式链

**公式 1：参考动作序列锚定**

```
y_i* = y_FP = (y_i,1*, ..., y_i,K*)    ← FP 模型生成的动作 token 序列，固定不变
```

**公式 2：参考动作支撑目标（教师强制对数概率）**

```
J_i(θ; y_i*) = (1/K) · Σ_k log p_θ(y_i,k* | y_i,<k*; z_i)
```

衡量模型 θ 对 FP 决策的支持强度。

**公式 3：边界归一化表示**

```
Z_i,γ^θ = (H_i,γ^θ - μ_γ^FP) / (σ_γ^FP + ε)
```

用 FP 校准统计量归一化，消除不同边界间的尺度差异。

**公式 4：梯度加权任务证据图**

```
E_i,γ^θ = | Z_i,γ^θ ⊙ ∇_Z J_i(θ; y_i*) |
```

激活 × 梯度 → 识别"既活跃又对决策有影响力"的特征。

**公式 5-6：证据质量失真**

```
M_i,γ^θ = (1/d_γ) · Σ_j E_i,γ,j^θ
Δ_mass(m,b) = | log( (M^θ_m,b + ε) / (M^θ_FP + ε) ) |
```

惩罚证据总量的变化。

**公式 7：证据分配失真（Jensen-Shannon 散度）**

```
a_i,γ,j^θ = (E_i,γ,j^θ + ε) / Σ_j'(E_i,γ,j'^θ + ε)
Δ_attr(m,b) = D_JS(a^θ_FP, a^θ_m,b)
```

即使总证据量不变，量化可能把证据重新分配到错误的特征上——JSD 捕捉这种分配偏移。

**公式 8：边界级任务证据损失**

```
ℓ_ev(m,b) = Δ_mass(m,b) + λ · Δ_attr(m,b)     ← λ=1（等权重）
```

**公式 9：软瓶颈聚合（跨边界）**

```
L_i^SB(m,b; κ) = κ · log( (1/|Γ|) · Σ_γ exp(ℓ_ev_i,γ(m,b) / κ) )
```

κ=0.1 时接近 max 操作但保持数值平滑——让最退化的边界主导分数，同时不忽略其他边界的中等退化。

**公式 10：全局层敏感度**

```
Ω(m,b; κ) = (1/N) · Σ_i L_i^SB(m,b; κ)
```

**公式 12-13：时间感知敏感度**

```
Ω_q(m,b; κ) = avg_{i ∈ C_q} L_i^SB(m,b; κ)     ← 按轨迹进度分 bin
Ω_τ(m,b; κ) = max_q Ω_q(m,b; κ)                 ← 取最大退化相位
```

**公式 14：混合精度位宽分配（二进制线性规划）**

```
min Σ_m Σ_b x_m,b · [α·Ω(m,b; κ) + β·Ω_τ(m,b; κ)]

s.t.
  Σ_b x_m,b = 1, ∀m                          ← 每层恰好一个位宽
  Σ_m Σ_b x_m,b · C_size(m,b) ≤ C_size^target  ← 模型大小预算
  Σ_m Σ_b x_m,b · C_bitops(m,b) ≤ C_bitops^target ← BitOps 预算
  x_m,b ∈ {0,1}

其中:
  C_size(m,b) = N_m · b
  C_bitops(m,b) = MACs(m) · b^2
```

> 符号与本文保持一致：θ_FP = 全精度模型；θ_m,b = 量化层 m 到位宽 b 的变体；Γ = {ν,β,ψ,α} 四个功能边界；κ = 软瓶颈温度（0.1）；α,β = 全局/时间敏感度权重（默认 0.75/0.25）。

### 直觉

Mix-QVLA 的核心直觉是：量化不只是"让输出接近"，而是"让内部推理路径接近"。就像两个人给出相同的答案——一个人用正确的推理，另一个人用错误的推理但碰巧蒙对了。Mix-QVLA 确保量化模型保留的是前者的推理路径。

## 3. 带数字走一遍：玩具例子 (Worked Example)

假设一个简化的 VLA 有 3 个可量化层（视觉编码器 FC、投影层、动作头），候选位宽 {4, 8, 16}，校准集 N=100 条轨迹样本。

**Step 1：FP 参考动作**

```
对样本 i=1: z_1 = (RGB, 关节角度, "pick up the cup")
FP 输出: y_1* = [token_7, token_3, token_12]  ← 固定参考
```

**Step 2：逐层量化 + 证据计算**

假设量化"投影层"到 4-bit：

```
边界 ν（视觉编码器输出）:
  FP 证据质量 M_FP = 0.85, 量化 M_q = 0.82
  Δ_mass = |log(0.82/0.85)| = 0.036
  Δ_attr = D_JS(a_FP, a_q) = 0.012
  ℓ_ev(ν) = 0.036 + 1·0.012 = 0.048

边界 β（投影层输出）:
  FP 证据质量 M_FP = 0.72, 量化 M_q = 0.51  ← 投影层被量化，退化明显
  Δ_mass = |log(0.51/0.72)| = 0.344
  Δ_attr = D_JS(a_FP, a_q) = 0.089
  ℓ_ev(β) = 0.344 + 1·0.089 = 0.433  ← 最退化边界

边界 ψ（语言策略表示）:
  ℓ_ev(ψ) = 0.067

边界 α（动作头）:
  ℓ_ev(α) = 0.055
```

**Step 3：软瓶颈聚合**

```
L^SB = 0.1 · log( (exp(0.048/0.1) + exp(0.433/0.1) + exp(0.067/0.1) + exp(0.055/0.1)) / 4 )
     = 0.1 · log( (1.61 + 72.9 + 1.92 + 1.72) / 4 )
     = 0.1 · log(19.3)
     = 0.1 · 2.96
     = 0.296
```

软瓶颈 κ=0.1 让 β 边界（0.433）主导了聚合结果——这正是设计意图：最脆弱的边界决定层的敏感度。

**Step 4：全局敏感度 + 分配**

```
对 100 个样本取平均: Ω(投影层, 4-bit) = 0.312
时间敏感度: Ω_τ(投影层, 4-bit) = 0.445  ← 末期抓取阶段退化更严重

综合分数 = 0.75 × 0.312 + 0.25 × 0.445 = 0.342
```

对比其他层-位宽对：

```
Ω(视觉FC, 4-bit) = 0.128 → 综合 0.141  ← 不敏感，可安全量化到 4-bit
Ω(动作头, 4-bit) = 0.287 → 综合 0.312  ← 中等敏感
Ω(投影层, 8-bit) = 0.089 → 综合 0.098  ← 8-bit 退化很小
```

优化器最终分配（假设预算允许）：

```
视觉编码器 FC → 4-bit  （证据退化低，安全）
投影层       → 8-bit  （证据退化高，需要保留精度）
动作头       → 4-bit  （中等退化，预算允许）
```

## 4. 工程视角 (Engineering View)

| 工程维度 | 数值/特征 | 含义 |
|----------|----------|------|
| 内存压缩（OpenVLA-OFT W4A4） | 15.4GB → 4.1GB | 可在单卡 A100（80GB）上跑 19 个实例，或部署到 RTX 4090（24GB） |
| 推理加速（W4A4） | 1.52× | 主要来自 W4A4 INT4 计算的吞吐量提升 |
| 校准开销 | N 个样本 × 每层一次前向+后向 | 假设 200 层 × 100 样本 = 20,000 次前向+后向，A100 上约 1-2 小时 |
| 优化器求解 | CVXPY + ECOS_BB | 二进制线性规划，变量数 = 层数 × 4（位宽候选），求解 < 1 分钟 |
| 部署时开销 | 零 | 位宽配置在校准后固定，推理无额外开销 |
| 量化粒度 | 层级别（非 token 级别） | 不支持运行时动态切换精度 |
| 精度候选 | {2, 4, 8, 16} | 覆盖 W2A2 到 BF16 全范围 |

**工程含义**：
- Mix-QVLA 的校准成本显著高于 QVLA（需要后向传播计算梯度证据图），但这是一次性离线成本。
- 1.52× 加速在 W4A4 设置下主要来自 INT4 矩阵乘法的硬件加速，而非算法创新。
- 4.1GB 内存使 7B 参数 VLA 可在消费级 GPU 上运行，对边缘部署是重大利好。
- 固定位宽分配意味着无法根据任务复杂度动态调整——简单任务可能过度保护，复杂任务可能量化过度。

### 6.1 隐含假设 (Hidden Assumptions)

1. **FP 决策是"正确"的**：Mix-QVLA 锚定 FP 动作序列作为参考，但如果 FP 本身在某些样本上决策错误，量化模型被强制模仿错误决策可能无意义。
2. **校准数据覆盖部署分布**：校准样本来自 LIBERO 训练演示，假设部署时任务分布相似。分布外任务下证据保留度的预测能力未知。
3. **证据质量与任务成功单调相关**：假设证据退化越大 → 任务成功率越低。但消融实验显示仅用证据信号（75.9%）不如组合信号（76.3%），说明证据保留度并非完美代理。
4. **软瓶颈 κ=0.1 是普适最优**：κ 值固定为 0.1，未做超参搜索。不同模型架构可能需要不同的 κ。
5. **BitOps 成本模型 b^2 适用于混合精度**：假设 WbAb 量化的 BitOps 与 b^2 成正比，但实际硬件加速可能因内存带宽瓶颈而非线性。

## 7. 与相关工作对比 (Comparison)

| 方法 | 敏感度信号 | 功能边界感知 | 时间感知 | 优化方式 | 适用场景 |
|------|-----------|-------------|---------|---------|---------|
| SmoothQuant | 激活异常值平滑 | ❌ | ❌ | 启发式尺度变换 | LLM/VLM 通用 |
| OmniQuant | 权重重建误差 | ❌ | ❌ | 逐层校准 | LLM/VLM 通用 |
| AWQ | 通道重要性 | ❌ | ❌ | 贪心选择 | LLM 通用 |
| QVLA | 最终动作偏差 | ❌ | ❌ | 敏感度排序 | VLA 专用 |
| DyQ-VLA | 运动学代理时序 | ❌ | ✅ | 时序代理驱动 | VLA 专用 |
| QuantVLA | 尺度校准 + 温度匹配 | ❌ | ❌ | 逐层校准 | VLA 专用 |
| **Mix-QVLA** | **任务证据保留度** | **✅ 4 边界** | **✅ 轨迹分 bin** | **CVXPY 约束优化** | **VLA 专用** |

**面试 Tip**：当被问到"Mix-QVLA 和 QVLA 的核心区别是什么？"——回答："QVLA 用最终动作偏差估计层敏感度，相当于只看'答案对不对'；Mix-QVLA 用任务证据保留度，相当于检查'推理过程对不对'。前者可能漏掉'答案对但推理错'的量化配置，后者通过锚定 FP 决策证据链来避免这个问题。"
