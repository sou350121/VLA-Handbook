### 1.2 关键机制 (Key Mechanism)

ConSFT 的核心洞察：**RL trust-region 中真正起作用的是 clipping 约束，而非 advantage weighting 或 on-policy sampling。**

作者通过 ablation 实验证明：
- PPO-NoClip（有 advantage 但无 clipping）：基础能力保留仅 3%，与 SFT 的 9% 相当
- PPO with clipping（ε=0.2）：基础能力保留 39%

因此 ConSFT 的设计目标是：**在 SFT 框架内模拟 clipping 的约束效果，但避免 RL 的计算开销。**

具体实现：
1. **流匹配策略比近似**：利用 flow-matching loss 作为负对数似然的代理，用指数 loss 差近似 importance sampling ratio
2. **理想专家替换**：将 behavior policy 概念化为理想专家（L_behavior = 0），从而得到权重 ω = exp(-L_SFT / τ)
3. **Stop-gradient**：权重通过 sg[] 算子作为非可微调制因子，避免优化目标本身被改变
4. **温度退火**：τ 在训练过程中指数衰减，从保守更新渐进过渡到无约束回归

⚡ **Eureka Moment**：用模型自身的 loss 作为置信度信号——模型对某个样本越没信心（loss 越高），对该样本的梯度更新就越保守；随着模型学会该样本，loss 下降，更新权重自然放大。这是一个自我调节的渐进学习动态。

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：

```
J_ConsFT(θ) = sg[exp(-L_SFT(θ) / τ)] · L_SFT(θ)
```

**目标**：在 SFT 框架内，让梯度更新幅度与模型置信度成正比——对已学会的样本全力拟合，对未学会的样本保守更新。

**公式拆解**：

| 符号 | 含义 |
|------|------|
| L_SFT(θ) | 流匹配回归损失，||v_θ(s) - v_target||² |
| τ | 温度参数，控制信任区域边界（训练初期大→保守，衰减后小→自由） |
| sg[] | stop-gradient 算子，权重不参与反向传播 |
| ω = exp(-L_SFT/τ) | 置信度权重，loss 越大权重越小 |

**直觉**：想象一个学生复习——对已经掌握的知识点（低 loss）多做练习巩固，对完全不会的知识点（高 loss）先不硬啃，等基础打好了再回头学。ConSFT 把这个直觉变成了优化算法。

**遗忘风险的理论界**：

利用 Fisher Information Matrix (FIM) 量化参数扰动对基础能力的影响：

```
R(g) = g^T · F · g          (遗忘风险 = 梯度在 FIM 度量下的二次型)

g_SFT = ∇_θ L_SFT(θ)        (SFT 无约束梯度)
g_ConsFT = ω · g_SFT        (ConSFT 调制梯度)

R(g_ConsFT) = ω² · R(g_SFT) = exp(-2·L_SFT(θ)/τ) · R(g_SFT)
```

关键结论：遗忘风险以指数速度衰减。当 L_SFT 很大时（不熟悉的样本），exp(-2L/τ) → 0，风险被严格压制。

> 符号与本文保持一致：F 为预训练目标的 FIM；g 为目标任务的梯度；R(·) 为遗忘风险。

## 3. 带数字走一遍：玩具例子 (Worked Example)

假设一个简化场景：微调 π0 模型学习一个新抓取任务，batch 中有 4 个样本：

| 样本 | L_SFT | τ (初期) | ω = exp(-L/τ) | 调制后梯度幅度 |
|------|-------|----------|---------------|---------------|
| A（类似预训练数据） | 0.1 | 1.0 | exp(-0.1) ≈ 0.90 | 0.90 · ∇L |
| B（中等难度） | 0.5 | 1.0 | exp(-0.5) ≈ 0.61 | 0.61 · ∇L |
| C（较难） | 1.0 | 1.0 | exp(-1.0) ≈ 0.37 | 0.37 · ∇L |
| D（全新模式） | 3.0 | 1.0 | exp(-3.0) ≈ 0.05 | 0.05 · ∇L |

**训练初期的效果**：
- 样本 A 和 B 获得大部分更新信号（权重 0.90 + 0.61），模型先学会"熟悉的"模式
- 样本 D 的更新被压制到 5%，不会导致参数空间的大范围扰动
- 遗忘风险：R(g_ConsFT) 相对于 R(g_SFT) 在样本 D 上衰减了 exp(-6) ≈ 0.0025 倍

**训练后期的效果**（τ 衰减到 0.1）：

| 样本 | L_SFT (已降低) | τ | ω |
|------|---------------|---|---|
| D（之前的高 loss 样本） | 0.3 | 0.1 | exp(-3.0) ≈ 0.05 |
| D（进一步学会后） | 0.05 | 0.1 | exp(-0.5) ≈ 0.61 |

随着模型学会样本 D，L_SFT 从 3.0 降到 0.05，权重从 0.05 自动增长到 0.61——模型开始全力拟合这个曾经"不会"的样本。这是一个自我调节的 curriculum learning。

## 4. 工程视角 (Engineering View)

| 维度 | 分析 |
|------|------|
| **额外计算** | 每个 sample 多一次 exp 运算和一次乘法，GPU 上可忽略（<0.5% overhead） |
| **额外显存** | 零——不需要参考网络、不需要 replay buffer |
| **训练步数** | 对全新控制基元可能增加 10-20% 步数（保守更新减慢收敛），但目标任务最终性能不降 |
| **超参敏感度** | τ 的初始值和衰减率 β 是主要超参；论文使用指数退火，具体值见 Appendix C.1 |
| **部署约束** | 推理阶段完全无影响——ConSFT 仅作用于训练；推理与 vanilla SFT 模型完全一致 |
| **兼容性** | 与 LoRA 正交，可叠加使用（但论文未探索此组合） |
| **分布式训练** | per-sample 权重计算可完全并行，无跨 GPU 通信开销 |

**工程含义**：ConSFT 的本质是在 SFT loss 前乘一个动态标量。这意味着：
- 控制频率不变（推理路径零改动）
- 模块边界不变（不引入新网络组件）
- 部署约束不变（模型权重文件与 SFT 完全兼容）

### 不能做什么

| 失败模式 | 原因 |
|----------|------|
| 加速全新控制基元学习 | 保守加权天然压制高 loss 样本的梯度，新技能学习更慢（论文 §6 明确承认） |
| 提供 ODE 轨迹误差保证 | 无理论界保证多步推理中流匹配 ODE 的有界误差（论文 §6） |
| 在极度分布偏移下完全保留 | 即使 ConSFT，LIBERO-Object 仍有 26% 下降（vs 基线 58%），并非零遗忘 |
| 替代 LoRA 的显存节省 | ConSFT 不减少参数量，全量微调场景下显存占用与 SFT 相同 |

### 6.1 隐含假设 (Hidden Assumptions)

| 假设 | 分析 |
|------|------|
| **L_SFT 可以作为置信度的代理** | 论文假设 flow-matching loss 与策略似然负相关，但这是一个近似——loss 低不一定意味着策略正确，可能是模式坍塌 |
| **理想专家的 L_behavior = 0** | 这是一个概念化假设。现实中 expert 在目标分布上的 loss 不一定为零，但作为相对基准是可接受的 |
| **FIM 在微调过程中近似不变** | 遗忘风险公式 R(g) = g^T F g 假设 FIM 反映预训练目标的曲率，但微调过程中 FIM 本身在变化 |
| **τ 退火 schedule 通用** | 论文使用固定指数退火，但不同任务的"学习曲线"可能不同——某些任务可能需要更长的保守期 |
