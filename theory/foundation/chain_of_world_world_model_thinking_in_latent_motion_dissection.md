### 1.2 关键机制 (Key Mechanism)

**为什么这样设计？**

1. **结构 - 运动解耦**：人类理解世界时不是记住每个像素，而是记住"什么东西在哪里"（结构）和"它怎么动"（运动）。视频 VAE 显式分离这两者，让 VLA 只关注运动动态。

2. **单 Q 令牌设计**：学习运动查询 Q 只出现一次（在首帧后），强制模型用单一潜向量聚合整个时间窗口的动态信息，避免逐帧冗余推理。

3. **两阶段训练**：预训练建立"从指令 + 首帧推断连续动态"的世界先验，协同微调将此先验与离散动作对齐——分离表示学习和策略学习。

4. **终端帧预测**：预训练时预测视频段的终端帧而非中间帧，避免重建冗余背景，同时保留世界演化的锚点。

⚡ **Eureka Moment**：世界模型不必在像素空间做——把视频压缩到结构 - 运动解耦的潜空间后，在这个紧凑空间里做时序推理，既保留世界模型的动态建模能力，又避免像素重建的计算浪费。

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：

```
L_co-finetune = Σ_j CE(A^j_q, A^j_q) + λ1·‖ẑm - zm(V1:f)‖² + λ2·Σ_j CE(ṽ^j_q, ṽ^j_q)
```

**目标**：在协同微调阶段，联合优化动作预测准确性、潜运动一致性、稀疏关键帧视觉一致性。

**公式拆解**：

| 符号 | 含义 | 维度/类型 |
|------|------|-----------|
| A^j_q | 预测的第 j 个动作块（离散令牌） | 序列 |
| A^j_q | 真实第 j 个动作块 | 序列 |
| ẑm | VLA 在 Q 位置预测的潜运动向量 | 1792 维连续向量 |
| zm(V1:f) | 视频 VAE 从完整视频段提取的潜运动（监督信号） | 1792 维连续向量 |
| ṽ^j_q | 预测的第 j 个关键帧视觉令牌 | 离散令牌序列 |
| ṽ^j_q | 真实第 j 个关键帧视觉令牌 | 离散令牌序列 |
| λ1 | 潜运动损失权重 | 标量（最优 0.1） |
| λ2 | 视觉令牌损失权重 | 标量（最优 0.01） |
| CE | 交叉熵损失 | 标量 |
| ‖·‖² | L2 距离 | 标量 |

**直觉**：第一项保证动作能做对，第二项保证潜空间动态推理与真实视频动态一致，第三项用稀疏视觉锚点约束状态演化不漂移。关键是 λ2 要小（0.01）——视觉只是辅助锚点，核心是潜运动指导动作。

**预训练损失**（公式 2）：

```
L_pretrain = ‖ẑm - zm‖² + Σ_{x∈{1,f}} CE(v^x_q, v^x_q)
```

第一项强制 Q 的表示准确总结从 v1 到 vf 的连续运动，第二项保证对未来状态的连贯预测。

**视频 VAE 损失**（公式 1）：

```
L_vae = L_rec + λp·Lp + λGAN·LGAN + λKL·LKL
```

重建损失 + 感知损失 + 对抗损失 + KL 散度正则，保证潜空间既能重建视频又平滑可插值。

> 符号与本文/相关文档保持一致：zm 表示运动潜变量（motion latent），zs 表示结构潜变量（structure latent），Q 表示运动查询令牌（motion query token）。

## 3. 带数字走一遍：玩具例子 (Worked Example)

假设我们有一个"拿起黑色碗放到盘子里"的任务：

**输入准备**：
- 指令 T: "pick up the black bowl and place it on the plate"
- 视频段长度 f = 16 帧（约 2 秒）
- 动作块大小 la = 10，所以 N = 16/10 ≈ 2 个动作块
- 关键帧：第 1 帧和第 11 帧（每 la 帧取首帧）

**预训练阶段**：
1. 视频 VAE 编码 16 帧 → zs (4×16×7×7) + zm (1792 维)
2. VQGAN 量化第 1 帧 → vq1，第 16 帧 → vqf
3. VLA 输入：[T, vq1, Q, vqf]，因果掩码让 Q 只能看到 T 和 vq1
4. VLA 输出：Q 位置的隐藏态 → MLP → 预测 ẑm（1792 维）
5. 计算损失：L2(ẑm, zm) + CE(vq1 预测，vq1) + CE(vqf 预测，vqf)

**协同微调阶段**：
1. 输入序列：[T, ṽq1, Q, Aq1, ṽq2, Aq2]
   - ṽq1: 第 1 帧的视觉令牌
   - ṽq2: 第 11 帧的视觉令牌
   - Aq1: 第 1-10 步的离散动作令牌
   - Aq2: 第 11-20 步的离散动作令牌
2. Q 只出现一次（在 ṽq1 后），自回归生成时 Q 的隐藏态聚合了整个序列的上下文
3. 输出：预测 A^1_q, A^2_q（动作） + ẑm（潜运动） + ṽ^2_q（第 2 关键帧）
4. 损失：CE(A^1_q, A^1_q) + CE(A^2_q, A^2_q) + 0.1×L2(ẑm, zm) + 0.01×CE(ṽ^2_q, ṽq2)

**关键数值**：
- 潜运动维度 Dm = 1792 = 16(帧) × 8(通道) × (7+7)(高 + 宽方向)
- 结构潜维度：4×16×7×7 = 1568 维
- 预训练步数：10k steps，batch size 256，约 24 小时（32×A800）
- 微调步数：LIBERO 8k steps，batch size 128，约 25 小时（16×A800）

## 4. 工程视角 (Engineering View)

**吞吐/延迟**：
- 预训练速度：约 417 samples/s（10k steps × 256 batch / 24h）
- 微调速度：约 142 samples/s（8k steps × 128 batch / 25h）
- 推理延迟：未明确报告，但单 Q 设计应比逐帧世界模型快 3-5 倍

**内存占用**（Figure 6）：
- UniVLA：最高（预测 6 帧的像素/令牌）
- CoWVLA "motion"：中等（只预测潜运动 + 终端帧）
- CoWVLA "motion & cot"：中等偏高（加终端帧监督）
- LAPA：最低（只预测潜动作）

**步数/时序**：
- 关键帧数量 N 的最优值 = 2（对应约 2 秒时间窗口）
- N=1 时性能显著下降（长程任务尤甚）——潜运动欠约束
- N≥3 时性能反而下降——模型依赖短期视觉匹配而非动态推理

**量化误差**：
- 视觉用 VQGAN 量化（离散令牌）
- 动作用 FAST 算法量化（频域离散化）
- 潜运动保持连续表示（1792 维向量）——避免量化损失动态信息

**部署约束**：
- 需要预训练视频 VAE（237k 视频，1 epoch + 20k iters）
- VLA 骨干 8.5B 参数（Emu3）——需要多卡推理或量化
- 推理时需缓存 Q 的隐藏态作为动态先验

**Trade-off 总结**：
- 用潜空间换计算效率：比像素世界模型快，但比直接动作映射慢
- 用两阶段训练换性能：预训练建立世界先验，微调对齐动作
- 用稀疏关键帧换长程推理：N=2 是甜区，太多削弱动态推理

## 6. 能力与失败模式 (Capabilities & Failure Modes)

**能做什么**：
- 长程任务规划（LIBERO-Long 92.8%，比 UniVLA 高 1.4%）
- 跨域泛化（LIBERO 0.956 → SimplerEnv 0.760，下降幅度小于基线）
- 稀疏视觉输入下的稳定控制（仅需 2 个关键帧）
- 物理合理的未来帧预测（Figure 5 显示比世界模型基线更准确）

**不能做什么**：
- 未见过的机器人形态（训练数据主要是 WidowX/UR5 类机械臂）
- 极端域偏移（新环境的光照/纹理/物体分布变化大时，视频 VAE 可能失效）
- 实时高频控制（动作块大小 la=10，控制频率约 5Hz）
- 多机器人协作（单臂操作数据集训练）

### 6.1 隐含假设 (Hidden Assumptions)

1. **视频 VAE 的潜空间足够表达机器人动态**：假设预训练视频 VAE（在通用视频上训练）的潜空间能捕捉机器人操作的运动模式。论文用 237k 机器人视频微调 VAE，但新环境仍可能分布外。

2. **结构 - 运动解耦是充分的**：假设场景动态可以完全分解为静态结构 + 运动向量。但对于可变形物体（液体、布料）或接触丰富的交互，这种分解可能不充分。

3. **单 Q 令牌能聚合长窗口动态**：假设单一 1792 维向量能编码 2 秒窗口的全部相关信息。对于更长的任务序列，可能需要多个 Q 令牌或层次化结构。

4. **终端帧是足够的世界锚点**：假设预测终端帧足以约束世界演化。但对于多阶段任务（如"先拿碗再倒水"），单终端帧可能丢失中间约束。
