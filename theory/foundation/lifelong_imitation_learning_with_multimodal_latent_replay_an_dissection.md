## 1. 核心架构/方法总览 (Overview / Architecture)

### 1.1 系统对比概览 (System Component Comparison)

| 模块 | 输入 | 输出 | 训练阶段 | 终身学习阶段 |
|------|------|------|----------|--------------|
| 视觉编码器 (CLIP ViT) | 代理视角 + 眼在手图像 | h(v) ∈ R^E | 可训练 | **冻结** |
| 语言编码器 (CLIP Text) | 任务指令文本 | h(l) ∈ R^E | 可训练 | **冻结** |
| 状态编码器 (2 层 MLP) | 本体感知 (关节位置/速度/夹爪) | h(s) ∈ R^E | 可训练 | **冻结** |
| FiLM 调制层 | h(v), h(s), h(l) | 任务条件化特征 | 可训练 | **冻结** |
| 时序解码器 (GPT-2) | 多模态序列 H ∈ R^{M×L×E} | 全局潜在 g_t ∈ R^E | 可训练 | **可训练** |
| 策略头 | g_t | 动作 â_t | 可训练 | **可训练** |
| 回放缓冲 B | - | {(H_n, a_n)} | - | 存储潜在特征 |

**关键差异**：与 TAIL/ISCIL 等 PEFT 方法不同，本文在终身学习阶段**完全冻结骨干编码器**，仅更新时序解码器和策略头。与 ER/LOTUS 等不同，本文存储**潜在特征**而非原始轨迹。

### 1.2 关键机制 (Key Mechanism)

**MLR (Multimodal Latent Replay)**:
- 不存储原始 (o≤t, a_t) 轨迹，而是存储冻结编码器输出的 H_n（多模态潜在拼接）
- 缓冲大小：每任务等价 5 条演示（与 SOTA 一致）
- 优势：内存效率高，无需访问原始感官输入

**IFA (Incremental Feature Adjustment)**:
- 为每个任务维护一个参考嵌入 h(r)(T_i)（本文使用语言嵌入 h(l)）
- 对新任务 T_k，惩罚其全局潜在 g_t(T_k) 比自身参考更靠近旧任务参考的配置
- 间隔 δ 自适应：δ = α·d(h(r)(T_k), h(r)(T_j))，其中 d 是角度距离
- 任务对选择：仅在语言 + 代理视角双模态相似度均在前 50% 的旧 - 新任务对之间应用

⚡ **Eureka Moment**：**用角度距离而非余弦距离定义间隔**——角度公式 d(a,b) = arccos(aᵀb / ||a||·||b||) 能放大相近任务参考之间的微小差异，而余弦相似度会压缩这些区别。

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：

```
L = L_BC + λ_IFA · (1/|P|) Σ_{(j,k)∈P, j<k} max(0, d(g_t(T_k), h(r)(T_k)) - d(g_t(T_k), h(r)(T_j)) + δ)
```

**目标**：最小化行为克隆损失的同时，确保新任务表征更靠近自身参考而非旧任务参考。

**变量说明**：

| 符号 | 含义 | 来源 |
|------|------|------|
| L_BC | 行为克隆损失 (负对数似然或 MSE) | 公式 (1) |
| λ_IFA | IFA 损失权重 | 固定为 0.1 |
| P | 任务对集合 | 语言 + 代理视角相似度均在前 50% 的旧 - 新任务对 |
| g_t(T_k) | 任务 T_k 的全局潜在表示 | 时序解码器输出 |
| h(r)(T_i) | 任务 T_i 的参考嵌入 | 语言嵌入 h(l) |
| d(·,·) | 角度距离 | arccos(aᵀb / ||a||₂·||b||₂) |
| δ | 自适应间隔 | α·d(h(r)(T_k), h(r)(T_j)) |
| α | 间隔缩放因子 | LIBERO-OBJECT:0.3, GOAL:0.7, 50:0.1 |

**直觉**：IFA 损失在 g_t(T_k) 距离自身参考 h(r)(T_k) 加上间隔 δ 后，仍比距离旧任务参考 h(r)(T_j) 更近时，才产生梯度。这形成一个"排斥力"，推开新旧任务表征，同时保持"吸引力"将任务表征拉向自身参考。

**角度距离 vs 余弦距离**：

```
余弦距离：d_cos(a,b) = 1 - (aᵀb / ||a||·||b||)    范围 [0,2]
角度距离：d_ang(a,b) = arccos(aᵀb / ||a||·||b||)  范围 [0,π]
```

角度距离在相近向量间（余弦值接近 1）有更大梯度，能更好区分语义相似任务。

> 符号与本文/相关文档保持一致：g 表示全局潜在，h 表示模态特定嵌入，上标 (r) 表示参考，(l)/(v)/(s) 表示语言/视觉/状态。

## 3. 带数字走一遍：玩具例子 (Worked Example)

假设 LIBERO-GOAL 基准，已学习任务 T_1 到 T_7，现在学习新任务 T_8（"把碗放进抽屉"）。

**步骤 1：提取参考嵌入**
- h(r)(T_8) = h(l)(T_8) = CLIP_Text("把碗放进抽屉") ∈ R^512
- 从回放缓冲 B 中读取旧任务参考 h(r)(T_1)...h(r)(T_7)

**步骤 2：计算任务相似度**
- 对每个旧任务 T_j，计算 Sim_l(T_8, T_j) 和 Sim_a(T_8, T_j)（语言 + 代理视角余弦相似度）
- 假设 T_6 与 T_8 最相似（都是"放入"类任务）：Sim_l = 0.82, Sim_a = 0.79
- T_6 在双模态均排前 50%，入选 IFA 任务对 P

**步骤 3：计算自适应间隔**
- d(h(r)(T_8), h(r)(T_6)) = arccos(0.82) ≈ 0.61 弧度
- α = 0.7（LIBERO-GOAL 最优值）
- δ = 0.7 × 0.61 ≈ 0.43

**步骤 4：计算 IFA 损失**
- 假设某 timestep t，g_t(T_8) 与 h(r)(T_8) 角度距离 = 0.35
- g_t(T_8) 与 h(r)(T_6) 角度距离 = 0.55
- L_IFA = max(0, 0.35 - 0.55 + 0.43) = max(0, 0.23) = 0.23

**步骤 5：梯度更新**
- 总损失 L = L_BC + 0.1 × 0.23
- 反向传播仅更新时序解码器和策略头参数
- g_t(T_8) 被推离 h(r)(T_6)，拉近 h(r)(T_8)

**效果**：训练结束后，T_8 的表征形成独立簇，不会与 T_6 混淆（见图 4 UMAP 可视化）。

## 4. 工程视角 (Engineering View)

| 工程指标 | 数值/约束 | 含义 |
|----------|-----------|------|
| GPU 内存 | 单张 A100 | 预训练 + 终身学习均可在单卡完成 |
| 批次大小 | 10 | 较小批次，适合回放混合 |
| 训练轮数 | 100 epochs | 预训练和终身学习阶段相同 |
| 学习率 | 1e-4 (AdamW + 线性调度) | 标准 Transformer 配置 |
| 缓冲大小 | 每任务 5 条演示等价 | 潜在特征存储，内存占用远小于原始轨迹 |
| 推理延迟 | 未报告 | 冻结 CLIP 编码器，仅需运行 GPT-2 解码器 + 策略头 |
| 任务 ID 需求 | **无需** | 测试时完全任务 ID 无关，适合实际部署 |
| 量化敏感性 | 未评估 | 潜在特征存储可能对量化误差敏感，待验证 |

**部署约束**：
- 需要两阶段流程：先多任务预训练（6 或 25 任务），再顺序终身学习
- 预训练编码器必须冻结，否则 IFA 假设失效
- 语言参考嵌入需预先计算并存储（每任务一个 512 维向量）

**吞吐/延迟 trade-off**：
- 回放缓冲采样增加每批次计算量（需混合新旧任务潜在）
- 但冻结骨干编码器大幅减少前向传播开销
- 预期推理速度优于 PEFT 方法（无需加载多组适配器）

### 6.3 隐含假设 (Hidden Assumptions)

**X-Ray 批判视角**：

1. **语言指令足够区分任务**：IFA 使用语言嵌入作为参考，假设任务文本描述能捕获任务本质差异。对于视觉主导差异的任务（如"用左手/右手抓取"），语言参考可能不足。

2. **任务相似度可静态计算**：任务对选择基于预计算的模态相似度，假设任务关系在训练过程中不变。但实际学习中，表征演化可能改变任务相似性。

3. **角度间隔对所有任务对公平**：自适应间隔 δ 基于参考距离，但不同任务对的"语义距离"与"特征空间距离"可能非线性相关。

4. **冻结 CLIP 足够通用**：假设预训练 CLIP 特征对所有 LIBERO 任务足够表达。对于域外任务（如非厨房场景），可能需要微调编码器。
