## 1. 核心架构/方法总览 (Overview / Architecture)

### 1.1 系统对比概览 (System Component Comparison)

Agentic Real2Sim 将整个 Real2Sim 流程拆分为四个代理阶段，每阶段由 **确定性工具**（工具函数）和 **VLM 决策**（技能调用）组成：

| 阶段 | 输入 | 输出 | 确定性工具 | VLM 决策（技能） |
|------|------|------|-----------|----------------|
| **Visual Processing** | 真实视频片段 + 标定数据 | 分割掩码、深度图、物体网格、位姿轨迹 | SAM 3（分割）、SAM 3D（几何）、FoundationStereo（深度）、FoundationPose（6D 位姿跟踪） | 物体发现、关键帧选择、掩码质量评判、位姿质量评判 |
| **Physical Prior Inference** | 视觉证据 + 任务语义 | 物体身份、材质类别、质量提示、接触属性 | — | 物体身份识别、地面参考物判定、材质/质量推断 |
| **Scene Preparation** | 事件文件夹（网格+位姿+轨迹） | MuJoCo 初始化场景 | 确定性标定、机器人基座位姿优化、地面平面估计 | 场景路由（刚体/可变形/人形适配器选择） |
| **Grasp Optimization** | MuJoCo 场景 + 初始物体位姿 | 优化后的物体放置位姿 | 物体位移扫描（deterministic sweep）或 LLM 辅助闭环优化 | 是否接受当前放置、是否需要进一步 refinement |

**关键设计哲学**：确定性工具与 VLM 代理决策分离。VLM 不做几何或物理计算——它只做边界清晰的 schema 约束决策（如"这个分割质量是否可用"、"哪个物体是被操作目标"）。这使系统可拆卸、可消融：换一个 VLM 后端不需要重写视觉管线。

### 1.2 关键机制 (Key Mechanism)

**事件孪生（Episodic Twin）统一表示**：论文定义了一个跨领域共享的数据契约

```
T = (O, A, G, S_{1:T}, Θ, B, M)
```

其中 O=真实观测、A=执行器/末端执行器、G=几何与外观资产、S=仿真器时序状态、Θ=物理与对齐参数、B=仿真后端、M=评估指标与追踪。这个契约是系统的核心抽象——刚体、可变形、人形三个适配器共享同一套文件夹结构和反馈接口，只是暴露不同的领域特定状态。

** Simulator-in-the-loop 抓取优化**：场景初始化后，系统不是直接接受初始物体放置，而是通过 MuJoCo 仿真反馈来优化物体位置。有两种路径：
- **确定性扫描**：批量评估候选位移，选择接触/抓取结果最好的
- **LLM 辅助闭环**：将渲染的关键帧和结构化回放摘要发给 VLM，由 VLM 提议改进

⚡ **Eureka Moment**：VLM 不直接做几何或物理——它只做"有界 schema 约束决策"，编排确定性专家工具。正因为 VLM 角色被严格限定，开源 31B 模型才能达到与 GPT-5.4 相当的效果。

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：
```
min_Θ  L_replay(T(Θ))  subject to  T = (O, A, G, S_{1:T}, Θ, B, M)
其中 L_replay = Σ_j penalty_j(identity, location, action, gripper)
```

**目标**：找到最优物理/对齐参数 Θ，使得仿真回放与真实观测的差异最小。

**变量说明**：

| 符号 | 含义 | 来源 |
|------|------|------|
| O | 真实观测（RGB 帧序列） | 输入视频 |
| A | 执行器（机器人末端执行器） | DROID 标定 |
| G | 几何资产（网格、外观） | SAM 3D + FoundationPose |
| S_{1:T} | 仿真器时序状态 | MuJoCo 仿真 |
| Θ | 物理与对齐参数（物体位姿、质量、摩擦系数等） | 优化目标 |
| B | 仿真后端 | MuJoCo |
| M | 评估指标与追踪 | VLM 评判打分 |

**直觉**：这不是一个可微优化问题——L_replay 由 VLM 评判给出（离散分数 0-10），因此 Θ 的优化通过确定性扫描（离散候选集）或 LLM 辅助闭环（提议-评估迭代）完成，而非梯度下降。

> 符号与本文保持一致。论文中未明确给出损失函数的解析形式，上述公式是对"回放成功率最大化"目标的抽象建模。

## 3. 带数字走一遍：玩具例子 (Worked Example)

假设一个 DROID 片段：机器人抓取桌面上一个红色杯子放到蓝色碗中。

**Step 1 — 视觉处理**：
- 输入：300 帧 RGB + 深度，相机标定已知
- VLM 发现 5 个候选物体：杯子、碗、桌子、抹布、水瓶
- 关键帧选择器选第 45 帧（杯子清晰可见，无遮挡）
- SAM 3 分割杯子 → 掩码 IoU 估计 0.82（通过 critic 阈值 0.7）
- FoundationPose 跟踪 300 帧，输出杯子 6D 位姿轨迹

**Step 2 — 物理先验推断**：
- VLM 识别：物体=陶瓷杯（刚性），材质=ceramic，质量≈0.3kg（基于视觉大小推断）
- 地面参考物=桌面

**Step 3 — 场景准备**：
- 机器人基座位姿优化：对齐机器人掩码，误差 < 2cm
- 地面平面估计：法向量 (0, 1, 0.02)，偏移 0.85m
- MuJoCo 加载场景：机器人 URDF + 杯子网格 + 碗网格

**Step 4 — 抓取优化**：
- 确定性扫描：20 个候选位移（±5cm 在 XY 平面）
- 候选 #7：位移 (+1.2cm, -0.8cm)，MuJoCo 仿真显示成功抓取，物体提升 15cm
- 回放评判：3 个 VLM judge 分别打分 8.5, 9.0, 8.2 → 最高 9.0 ≥ 8 → replay success

**失败案例**：假设分割失败（IoU=0.55 < 0.7），mask critic 拒绝 → 退回关键帧选择器 → 重试第 62 帧 → 仍失败 → 达到重试预算上限 → 标记为 failure。

## 4. 工程视角 (Engineering View)

| 维度 | 数值/估计 | 说明 |
|------|----------|------|
| 单次转换成本（Gemma 4 31B） | $0.026/episode | DROID-100 总计 $2.62 |
| 单次转换成本（GPT-5.4） | $0.823/episode | 31.4× 差距 |
| 回放成功率上限 | 48% | 所有 VLM 后端均 < 50% |
| 视觉前端瓶颈 | 分割/位姿跟踪 | 论文明确承认剩余改进空间在视觉/仿真组件 |
| 部署约束 | 需要 DROID 格式输入 | 同步 RGB+深度+标定+轨迹，非通用视频 |
| 仿真后端 | MuJoCo | 刚体场景；可变形需 EMPM；人形需额外运动控制器 |
| 并行度 | 高 | 片段间独立，可大规模 batch 处理 |

**工程含义**：
- VLM 角色被严格限定为"调度器"而非"计算引擎"，这意味着可以用较小的开源模型替代昂贵的闭源模型——成本差异巨大（31.4×），效果差异微小（48% vs 43% 成功率）
- 真正的性能瓶颈在视觉前端（SAM 3 分割质量、FoundationPose 跟踪稳定性），而非 VLM 推理能力
- 对于需要大规模生成仿真数据的 VLA 训练管线，这套系统提供了可批量运行的基础设施

## 5. 数据与评测 (Data & Eval)

**主要数据集**：DROID-100——从 DROID 数据集中随机采样的 100 个操作片段，覆盖不同物体、相机视角、遮挡模式和操作动词（pick/place/push/insert）。

**评测指标**：回放成功率（Replay Success），定义如下：
- 3 个 VLM judge（各用不同后端）独立比较真实关键帧与仿真关键帧
- 评分维度：目标物体身份（-4）、最终位置（-3）、动作类型（-2）、末端夹爪位置（-1），满分 10
- ≥8 = pass，7 = partial，≤6 = fail
- 至少一个 judge 给出 ≥8 分 → 该片段 replay success

**多领域定性测试**：
- 可变形：PhysTwin 风格（绳子、布料、毛绒物体），用 EMPM 仿真器验证变形参数恢复
- 人形：BFM-Zero 风格运动上下文检索 + 闭环回放

> 注意：可变形和人形场景仅展示定性结果，无聚合量化指标（论文 §4.4）。

## 6. 能力与失败模式 (Capabilities & Failure Modes)

**能做什么**：
- 将 DROID 格式的真实交互片段自动转化为 MuJoCo 可仿真场景
- 跨 4 种 VLM 后端无缝切换（Gemma 4 31B / Qwen 3.6 35B / GPT-5.4 / Claude Haiku 4.5）
- 生成可用于下游策略学习和评估的仿真数据
- 扩展到可变形物体和人形机器人（定性验证）

**不能做什么**：
- 不支持非 DROID 格式输入（需要同步 RGB+深度+标定+轨迹）
- 48% 成功率意味着超过一半的片段转换失败——不能直接用于生产级数据生成
- 可变形和人形场景尚无量化指标，成熟度远低于刚体操作
- 不处理动态场景（运动中的物体、多机器人协作）

**已知失败模式**（论文 §4.2 定性展示）：
- 分割失败：物体被遮挡或 SAM 3 无法识别 → mask critic 拒绝 → 达到重试预算 → 标记 failure
- 位姿跟踪漂移：FoundationPose 跟踪过程中逐渐偏离真实位姿 → 仿真回放与真实观测不一致
- 地面平面估计错误：错误识别地面参考物 → 整个场景放置错误

### 6.1 隐含假设 (Hidden Assumptions)

- **假设 1**：DROID 格式的标定数据始终准确——但真实世界中相机标定可能漂移或不完整
- **假设 2**：单物体操作场景——多物体交互、双手协作等复杂场景未评估
- **假设 3**：VLM 的 schema 约束决策足以覆盖所有边界情况——但长尾场景（罕见物体、极端视角）可能超出 VLM 判断能力
- **假设 4**：MuJoCo 刚体仿真足以捕捉真实物理——但摩擦系数、接触刚度的细微误差可能导致策略迁移失败（Sim2Real gap）
