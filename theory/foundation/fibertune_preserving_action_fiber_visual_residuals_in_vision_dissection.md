問題：微調後的 VLA 常常「忘掉」預訓練視覺能力（顏色、類別、干擾物辨識變差），但動作模仿精度卻在提升——為什麼？

## 1. 核心架構/方法總覽 (Overview / Architecture)

FiberTune 不是新模型，而是掛在既有 VLA（π0.5 / OpenVLA-OFT）微調流程上的**訓練期正則項**。它對中間層的視覺 token 表徵下手，加兩個輔助損失。

### 1.1 系統對比概覽 (System Component Comparison)

| 模組 | 輸入 | 輸出 | 訓練/推理 | 備註 |
|------|------|------|-----------|------|
| 策略主幹 R_θ | 圖像 V + 語言 L | 中間視覺 token R_θ ∈ R^(T_v×d) | 訓練+推理 | π0.5 取 prefix tower **layer 8**；OpenVLA-OFT 取 **layer 16** |
| Task loss L_task | R_θ, 動作標籤 A | 動作預測誤差 | 訓練+推理都受其訓練 | 唯一在部署時保留的項 |
| 在線動作 probe W* | stop-grad 後的 pooled 視覺特徵 R̄_θ | 動作預測（線性回歸） | **僅訓練** | 用其行空間估計「動作預測方向」，只由自身回歸目標更新 |
| 特徵濾波器 P_probe | W* | 動作預測子空間投影 | **僅訓練** | 岭穩定化，η=1e-4；更新前先投影 |
| 殘差 R_pf | R_θ, P_probe | 動作正交殘差 | **僅訓練** | R_pf = R_θ (I − P_probe)，是理想 U_θ 的可計算代理 |
| 凍結視覺教師 τ | 圖像 V | 教師視覺 token Z | **僅訓練** | RADIO `c-radio_v3-l`；固定隨機初始化 MLP adapter g（隱層 2048，初始化後凍結）|
| Align loss L_align | R_pf, Z | 方向對齊損失 | **僅訓練** | token 去均值 + 歸一化後的 cosine 對齊 |
| Rank prior L_rank | R_pf 協方差譜 | 譜熵懲罰 | **僅訓練** | 鼓勵殘差能量鋪開在多個方向 |

> 關鍵工程事實：**教師、probe、adapter、兩個輔助損失在部署時全部移除**，推理計算圖與純 task-loss 微調完全一致——這是它相對於「改模型結構」類方法的核心優勢。

### 1.2 關鍵機制 (Key Mechanism)

- **動作纖維（action fiber）**：對固定的動作目標 a，所有能被策略頭映射成同一動作的表徵構成一個水平集（level set）F_{a,θ} = { R : h_θ(R) = a }。動作損失只懲罰「跨纖維」方向，**沿纖維切向（fiber-tangent）**的方向一階不改變動作輸出，因此一階不受任務損失約束。
- **為什麼會坍縮**：預測映射在 pooled 特徵處線性化後，Jacobian J_θ 的**行空間** = 動作預測方向（被約束）；**零空間 Null(J_θ)** = 纖維切向（無約束）。顏色、類別、干擾物、未來相關狀態都可能落在零空間，於微調中被自由壓縮。
- **兩股互補壓力**：作者用條件互信息 I(U_θ; Z_c | A, L) 作為設計原理，鏈式分解得到 (i) 最大化 H(U_θ|A,L) → 殘差要**高秩、鋪開**（對應 L_rank）；(ii) 最小化 H(U_θ|Z_c,A,L) → 殘差要**能被教師視覺結構解釋**（對應 L_align）。
- **用 probe 近似 Jacobian**：精確算大 VLA 的局部 Jacobian 不可行，改用**輕量線性動作 probe** 在 stop-grad 的 pooled 特徵上做動作回歸，用其行空間作為動作預測方向的估計（維持不變的固定濾波器，梯度可透過它回流到 R_θ，但 probe 自身不被 L_align 優化）。
- **為什麼要秩正則**：只做對齊可能「把所有教師相關信息擠進少數幾個方向」也能滿足對齊目標；秩正則強迫殘差協方差譜鋪開，避免另一種形式的坍縮。

⚡ **Eureka Moment**：動作監督只給「跨纖維」方向梯度，動作等價的視覺結構落在零空間被放任坍縮——**先在特徵空間把動作預測方向濾掉，再對殘差做教師對齊 + 秩正則**，就能只守「該守的那部分視覺結構」，且推理零開銷。

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本質）：

```
L = L_task + λ_align·L_align + λ_rank·L_rank      # 殘差先濾後對齊 + 秩正則
```

**目標**：在不放鬆動作精度的前提下（s.t. L_task ≤ ε），最大化「動作正交殘差 U_θ」與凍結教師視覺表徵 Z_c 的條件互信息（條件於動作 A 與語言 L）：

```
max_θ  I(U_θ ; Z_c | A, L)      s.t.  L_task(θ) ≤ ε
```

**鏈式分解**（把「保留」拆成兩股壓力）：

```
I(U_θ ; Z_c | A, L) = H(U_θ | A, L) − H(U_θ | Z_c, A, L)
                       └─ 殘差要高秩/鋪開 ─┘   └─ 殘差要能被教師解釋 ─┘
```

**理想殘差投影**（依賴 Jacobian J_θ，實務不可算）：

```
Q_θ = I − J_θᵀ (J_θ J_θᵀ)† J_θ        # 一階保留纖維切向的正交投影
U_θ = R_θ Q_θ
```

**可計算代理：probe 濾波殘差**：

```
W*        = argmin_W  E || A − W · R̄_θ ||²          # 線性動作 probe（stop-grad pooled 特徵）
P_probe   = W*ᵀ (W* W*ᵀ + η I)⁻¹ W*                # 岭穩定化特徵濾波器, η = 1e-4
R_pf      = R_θ (I − P_probe)                       # ≈ U_θ；R_θ P_probe 是被移除的動作預測分量
```

**對齊損失**（作用在 R_pf，非完整 hidden state）：

```
Y_θ   = norm( C_T · g(R_pf) )        # g = 固定隨機初始化 MLP adapter（每 token 獨立）
Z̃     = norm( C_T · Z )              # Z = 凍結教師視覺 token；C_T 去 token 均值
L_align = − E_t [ cos( Y_θ,t , Z̃_t ) ]
        （等價於 vMF 方向似然；只在配對的圖像 token span 上算，語言/動作 token 排除）
```

其中 C_T = I_{T_v} − T_v⁻¹ · 1·1ᵀ 是去均值矩陣（先減去 token 方向上的共享均值，讓 cosine 作用在**token 相對結構**而非共享均值方向上）。

**有效秩先驗**（殘差協方差譜熵）：

```
p_i       = λ_i / Σ_j λ_j
H_shape   = − ( Σ_i p_i · log p_i ) / log K          # K = 非零特徵值個數
L_rank    = − H_shape(R_pf)                          # 越鋪開 → H_shape 越大 → L_rank 越小
```

**總目標**：

```
L = L_task + λ_align · L_align + λ_rank · L_rank
（π0.5 上 λ 取 0.0125 / 0.00625，1k 步 warmup，3k–6k 步衰減到 0.5×）
```

**方程要點**：公式皆以代碼塊/純文本表達，符號與原文一致——R_θ（中間視覺 token）、R̄_θ（pooled 特徵）、J_θ（動作映射對 pooled 特徵的 Jacobian）、U_θ（理想動作正交殘差）、R_pf（probe 濾波殘差）、Z（教師 token）、Z_c（去均值後教師 token）、K（協方差非零譜數）。

**直覺**：task loss 是「只朝改變動作的方向拉」；FiberTune 補上「別讓動作管不到的方向亂塌」——一個用教師視覺結構錨定它（L_align），一個用譜形狀逼它保持多方向（L_rank）。

> 原文另附命題與證明：在局部線性模型 Ã = J₀·R̃ + ε 且 E[ε|R̃]=0、協方差滿秩時，**總體最小二乘 probe 的解恰好恢復 J₀**，故 probe 行空間 = 局部動作映射行空間；有限樣本下加岭穩定化即得 P_probe。

## 3. 带数字走一遍：玩具例子 (Worked Example)

用二維 pooled 特徵走一遍「殘差為什麼會坍」與「秩正則怎麼救」。

**設定**：設 pooled 特徵 R̄ = (r_a, r_b)。假設 Jacobian 的行空間只落在 e_a 軸上，則零空間 = e_b 軸。於是理想濾波器近似

```
P_probe ≈ [[1, 0],
           [0, 0]]
R_pf = R̄ (I − P_probe) = (0, r_b)     # 只有第二維 r_b 是「動作正交殘差」
```

**純 task-loss 基線**：r_a 被動作損失約束；r_b 完全沒有梯度壓力，收斂中容易塌向單一方向甚至趨零。

**秩正則的數值效果**（K=4，協方差特徵值）：

```
坍縮情形     λ = {9, 1, 0, 0}   →  p = {0.9, 0.1}
             H_shape = −(0.9·ln0.9 + 0.1·ln0.1)/ln4
                     = −(−0.0948 − 0.2303)/1.3863 ≈ 0.2345
             L_rank = −0.2345          # 罰得重 → 模型被推離此狀態

鋪開情形     λ = {4, 3, 2, 1}   →  p = {0.4, 0.3, 0.2, 0.1}
             H_shape = −(0.4·ln0.4 + 0.3·ln0.3 + 0.2·ln0.2 + 0.1·ln0.1)/ln4
                     = 1.2799 / 1.3863 ≈ 0.9232
             L_rank = −0.9232          # 明顯更優
```

**有效秩診斷**（participation ratio，d_eff = (Σλ)² / Σλ²）：

```
坍縮 {9,1,0,0}:  d_eff = 100 / 82  ≈ 1.22
鋪開 {4,3,2,1}:  d_eff = 100 / 30  ≈ 3.33
```

**閉環**：最小化 L_rank 對應把殘差協方差譜從 {9,1,0,0} 推向 {4,3,2,1} 這類高秩分佈 → 診斷端觀察到的正是有效的 rank 大幅抬升（見 §4/§5 的 Table 3 實測：CALVIN/π0.5/general 的殘差有效秩從 4.24 升到 76.61）。**注意診斷用的 d_eff 與訓練用的 H_shape 是同一協方差譜的兩個不同摘要**，所以這是「表徵層證據」而非直接優化目標的複述。

## 4. 工程视角 (Engineering View)

| 面向 | 事實 | 工程含義 |
|------|------|----------|
| 推理開銷 | **零新增**：teacher / probe / adapter / 輔助損失部署時全拆 | 可直接套用到既有推理服務，不需重導出模型、不改 decode 路徑 |
| 訓練開銷 | 需凍結教師前向 + 在線 probe + 協方差/譜計算 | 訓練記憶體與步時上升；表 B.4 記載 π0.5 設定用到 **≥48GB 顯存的 GPU** |
| 訓練預算 | π0.5/CALVIN：batch 8 × accum 4 × 1 GPU，**6,000 步**；OpenVLA-OFT：batch 8 × accum 1，**15k–20k 步** | 相對主流 SFT 屬中等預算；殘差 probe/協方差在每個 forward micro-batch 上算（非累積梯度上）|
| 損失配比 | 輔助係數由短標定跑選出，令 ρ_aux = (λ_align|L_align| + λ_rank|L_rank|)/L_task 落在約 **6%–33%** | **係數不跨基準自動遷移**，換 benchmark 需重標定（工程落地的主要摩擦點）|
| 消融主導項 | CALVIN 上「**只用秩正則**」就恢復大部分增益（SR(5) 61.4→70.5），殘差對齊再補（→72.1） | 若只想低成本吃大部分收益，可先上 rank prior |
| 濾波一致性 | P_probe 由 pooled 特徵擬合，作用為**跨所有 token 位置的共享特徵通道方向** | 契合 transformer hidden state 的 channel-wise 結構；不需 per-token 濾波 |
| 模組邊界 | 只碰「中間層視覺 token」（π0.5 layer 8 / OpenVLA-OFT layer 16） | 層選擇是超參；改層需重新標定係數 |

**部署約束總結**：FiberTune 是「訓練期插件」——訓練側要能插入凍結教師前向與輔助損失，推論側完全不動。對已有 LeRobot / OpenVLA-OFT 微調管線的團隊，接入成本主要在訓練側的工程與超參標定。

| **OOD 綠色** | 15/32 (46.9%) | 20/32 (62.5%) | **+15.6** |

**表徵診斷（Table 3）**：六個設定中，FiberTune 一致抬升「殘差教師 CKA」（對齊度）與「殘差有效秩」（協方差鋪開度），例如 LIBERO/π0.5/general：CKA 0.154→0.680、有效秩 6.94→78.30。

**消融（Table 4，CALVIN adapted）**：

| 變體 | 教師信號 | 秩先驗 | Avg seq | SR(5)% |
|------|----------|--------|---------|--------|
| Baseline | 無 | 無 | 3.837 | 61.4 |
| Full-token align | 全 token | 無 | 3.685 | 58.3 |
| Full-token + rank | 全 token | 有 | 3.956 | 65.6 |
| Residual align | pf-殘差 | 無 | 3.980 | 66.2 |
| Residual rank only | 無 | 有 | 4.064 | 70.5 |
| **FiberTune** | pf-殘差 | 有 | **4.116** | **72.1** |

消融結論要點：**全 token（BlindVLA 式）對齊反而低於 baseline**（58.3 < 61.4），說明「先濾掉動作預測方向」是必要的；**秩正則是最主導的單一組件**。另附低學習率標定點（4k 步、6.25e-6）：3.992→4.206（SR(5) 63.9→71.5）。

## 6. 能力与失败模式 (Capabilities & Failure Modes)

**能做**：
- 在既有 VLA 微調管線上「加掛即用」，**推理零改動**地提升 OOD 視覺泛化（SO-101 留出綠色 +15.6 pp 是亮點）。
- 跨架構遷移（π0.5 與 OpenVLA-OFT 都見效）、跨初始化（general 與 adapted 皆正增益）。
- 提供可解釋的表徵診斷（殘差 CKA / 有效秩）來對齊「動機—增益」鏈路。

**不能/需謹慎**：
- 不改模型結構、不改推理，因此**不解決動作精度上限**問題；增益是泛化側。
- 實機證據**限單一任務（pick-place）+ 單一機械臂（SO-101）**，多樣真實工況的失效模式未刻畫。
- 直接照搬全 token 教師對齊（BlindVLA 式）在長程 CALVIN 連續訓練上可能**負遷移**（Table 4）。
- 輔助係數逐基準標定，未自動跨基準平衡——換域可能需重調。

### 6.1 隐含假设 (Hidden Assumptions)

- **channel-wise 共享方向**：假設動作預測特徵方向在所有視覺 token 位置共享（故 filtered on pooled 特徵即可）。若不同 token 位置對動作貢獻**異質**，此假設可能失效（作者在 Limitations 明示）。
- **一階線性局部模型**：整個推導建立在 h_θ 在 pooled 特徵處的一階線性化 + Jacobian 行/零空間分解上；動作映射高度非線性時近似可能崩壞。
- **凍結教師即「正確目標」**：隱含假設 RADIO 教師編碼的視覺結構就是「值得保留」的；若教師本身有偏差或與下游任務錯配，殘差對齊會一併把偏差鎖進去。
- **相關性非因果**：CKA/有效秩的抬升與行為增益**同時出現**，但作者是以「一致的相關性」作為動機的表示層證據，並未做因果消融（如「把秩壓回去是否增益消失」）。
- **單 seed 主結果**：Table 1 為默認種子的單次運行，多 seed 均值與 Wilson 95% CI 放附錄（CALVIN adapted 3-seed 平均 SR(5) 62.1→70.9，增益穩健但略小於單 seed 的 +10.7）。

## 7. 与相关工作对比 (Comparison)

| 方法 | 對齊/保留對象 | 核心機制 | 與 FiberTune 的差異 |
|------|----------------|----------|----------------------|
| **FiberTune**（本文） | **動作正交殘差 R_pf** | 過濾動作預測方向 → 教師對齊 + 有效秩正則 | 唯一同時「先濾後對齊 + 秩正則」；推理零開銷 |
| BlindVLA | 全 visual token | 凍結教師 + 固定 adapter + cosine 對齊 | FiberTune 借用其協定，但改對齊「濾波後殘差」；本文消融顯示 full-token 版在此設定下負遷移 |
| MAPS | 全 VL 表徵 | 模組化鄰近度排程保留 | 不加排程，改用動作正交濾波定位「該保留什麼」 |
| Spatial Forcing | 空間基礎表徵 | 對齊空間基礎模型 | 教師不同（RADIO 視覺 vs 空間基礎）且 FiberTune 只對殘差 |
| RS-CL | 機器人狀態相關表徵 | 對比正則 | RS-CL 用狀態度量，FiberTune 用動作預測方向的零空間幾何 |
| VICReg / Barlow Twins | 通用影像表徵 | 方差/協方差/冗餘正則 | FiberTune 的秩先驗同屬反坍縮傳統，但施加在**動作濾波後**的殘差方向 |

**面試 Tip**：被問「VLA 微調為什麼會掉視覺泛化、怎麼防」時，一句話答：**動作監督只約束跨動作纖維的方向，零空間裡的視覺結構沒有梯度壓力會坍縮；FiberTune 的關鍵是先濾掉動作預測方向、再對殘差做教師對齊 + 有效秩正則，且推理零開銷。** 若被追問細節，補「秩正則是最主要組件，消融裡單獨用秩正則就拿到大部分增益」。

## 8. 精讀建議 (Reading Guide)

- **值得精讀原文的人**：
  1. 做 VLA 後訓練 / 表徵保留微調的研究者——想理解「動作正交子空間」這個分析框架；
  2. 評估把該目標遷到自家 VLA 與機器人平台的工程師——重點看附錄 B（實現協定/超參）與 §4 工程視角；
  3. 關心 OOD 視覺泛化（顏色/干擾物）而又不能動推理路徑的落地團隊。
- **建議章節路徑**：先讀 §3.1（action fiber 與殘差坍縮，建立直覺）→ §3.2–3.4（probe 濾波 + 對齊 + 秩正則）→ §4.2/4.5（主結果與消融）→ 附錄 A.1/A.4（Jacobian projector 與 probe 行空間命題）→ 可跳 §2 Related Work（若非做文獻綜述）。
- **不值得精讀的理由**：若你不做機器人學習、或只關心全新模型架構/新能力（本文不改結構與推理）、或已熟悉 BlindVLA/MAPS 一類表徵保留方法，讀摘要 + 本文 §1.2 的 Eureka 即可掌握要點。
