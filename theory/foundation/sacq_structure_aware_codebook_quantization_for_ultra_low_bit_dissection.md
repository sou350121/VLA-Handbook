## 1. 核心架构/方法总览 (Overview / Architecture)

### 1.1 系统对比概览 (System Component Comparison)

SACQ 是离线量化流水线，推理时只保留压缩后的 weight-only 码本表示。各模块职责如下。

| 模块 | 输入 | 输出 | 频率/时序 | 训练/推理差异 |
|------|------|------|-----------|----------------|
| 结构感知码本拟合 | 校准输入统计、BF16 权重、各投影下游消费关系 | 每层码本 C 与分配 a | 离线，每层独立拟合 | 只在校准阶段；推理不跑 |
| 动作感知混合比特分配 | 每层当前/下一精度状态、最终动作相对误差 | 每层比特状态 | 离线贪心搜索，周期性刷新 Δ | 只在校准阶段 |
| 索引重分配 | 量化策略的层输入二阶矩、BF16 权重 | 新的码字索引 a* | 离线，按向量顺序扫描 | 只改索引，不改码本/scale |
| 动作级校准 | 固定索引后的码本、row-group scale、BF16 动作 | 校准后的码本与 scale | 离线，12 epochs | 只优化码本与 scale |
| 推理 | 压缩权重、当前观测与语言指令 | 未来 action chunk | 在线，按策略调用 | weight-only；A8 时激活走 INT8/FP8 路径 |

### 1.2 关键机制 (Key Mechanism)

- **结构感知度量**：不只用 `X^T X` 做层局部重构，而是按投影角色构造 `G(v)`。query/key 看 attention logits 的扰动；value 看 attention 概率加权后的输出；gate/up 看 SwiGLU 与 down projection 的传播；action head 还区分 cross-attention 的 query/key-value 输入、GELU FFN 和 AdaLN。
- **可分离近似**：完整二次型跨通道、跨向量耦合，无法逐向量独立优化；论文保留 `B` 的对角、把 `A` 限制到 4×4 输入块，得到 `G(v)=B_rr A_II`，使码本可以按向量独立拟合。
- **动作感知分配**：每层有从 GPTQ(4bit) 到 VC(1bit) 的离散状态；每次选“每节省 1 bit 带来的最终动作误差增量最小”的层，同时按语言骨干/动作头的实际计算 bpw 做组件平衡。
- **两阶段精调**：先固定码本和 scale，用二阶补偿重排离散索引；再固定索引，只优化码本和 row-group scale，使量化策略输出动作逼近 BF16 动作。

⚡ **Eureka Moment**：这篇论文最核心的想法是——**量化误差的“代价”不该在投影输出处定义，而应在该投影被下游消费后、最终动作被解码时定义**；因此码本拟合、比特分配和精调都围绕动作误差闭环。

### 1.3 信息流/架构图 (Flow / Diagram)

```
BF16 VLA + 校准数据
   │
   ├─ 收集各投影输入统计 / attention 概率 / 下游权重
   │
   ▼
[1] 结构感知码本拟合
   │   q/k/v/o、gate/up/down、DiT q/k/v/o、FFN、AdaLN 各自 G(v)
   ▼
[2] 动作感知混合比特分配
   │   逐层降精度，测最终动作相对误差增量 Δ_l
   │   选 Δ_l / 节省的存储成本 最小者
   ▼
[3] 索引重分配（二阶补偿）
   │   固定码本/scale，只更新 a*
   ▼
[4] 动作级校准
   │   固定 a*，只优化码本 C 与 row-group scale s
   ▼
量化策略 → 当前观测 + 语言指令 → 未来 action chunk → 机器人执行
```

> 【条件性分析】本文输入是当前观测与语言指令，输出是未来动作 chunk；论文没有视频历史帧采样或未来帧预测实验。LIBERO 每次执行 chunk 的前 8 个动作，SimplER 每次只执行第 1 个动作；这是执行频率，不是记忆窗口。若一般化地均匀采样 K 个历史帧，首末跨度是 `(K-1)×Δt`；若从当前参考 t 预测 t+1 至 t+H，终点距当前参考是 `H×Δt`。本文不涉及这些设置，不能把 action chunk 长度写成记忆窗口。

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**：

```
min_{C,a} Σ_v α(v)(v - c_a(v))^T G(v)(v - c_a(v))
分配时选 Δ_l / Δcost_l 最小的层；精调时最小化动作 MSE
```

### 2.1 向量码本表示

权重矩阵 `W ∈ R^{O×I}` 被分成连续 `g` 个元素的 block，每个 block 用自身 scale `s` 归一化；归一化后的元素再组成 `d` 维向量 `v`，每个向量用码本 `C={c_1,...,c_M}` 的一个索引表示。

```
b(M) = log2(M) / d
```

论文主设置：`g=64`、`d=4`、每层一个码本；索引率为 `log2(M)/4` bpw。解码时每个重构向量再乘回对应 block 的 scale。因此每层存储码本、每向量一个索引、每 block 一个 scale。

### 2.2 码本拟合目标

```
min_{C,a} Σ_{v∈V} α(v) (v - c_a(v))^T G(v) (v - c_a(v))
```

| 符号 | 含义 |
|------|------|
| `v` | 归一化后的 d 维权重向量 |
| `c_a(v)` | 分配给 v 的码字 |
| `G(v)` | 正半定矩阵，编码各坐标误差的代价与耦合 |
| `α(v)` | 每向量权重；SACQ 拟合时设 `α(v)=1`，直接在 scale 归一化空间拟合 |
| `C,a` | 码本与离散分配 |

若 `G(v)=I`、`α(v)=1`，退化为欧氏 k-means。SACQ 的关键是让 `G(v)` 反映该投影输出被下游消费时的敏感度。

### 2.3 投影角色度量

论文使用可分离近似：

```
G(v) = B_{r(v), r(v)} · A_{I(v), I(v)}
```

其中 `r(v)` 是向量所属输出行，`I(v)` 是其 4 个输入坐标；`B_rr` 是输出侧标量权重，`A_II` 是 4×4 输入块。

**Query / Key**：  
query 扰动对 attention logits 的影响为：

```
||ΔL||_F^2 = tr(E_Q A E_Q^T B),  A = X^T X, B = K^T K
```

key 投影对称地交换 query/key，`B=Q^T Q`。可分离近似保留 `B` 的对角与 `A` 的 4×4 块。

**Value / Output**：

```
A = E[Σ_s ω_s x_s x_s^T],  ω_s = Σ_{h,t} P_{h,t,s}^2
B_rr = ||W_O[:,r]||_2^2
```

`ω_s` 表示 token s 被 attention 关注的程度；output projection 的输入侧 Gram 是 `E[C^T C]`，输出侧 `B=I`。

**Feed-forward**：  
down projection 用 `A=E[z z^T]`、`B=I`。gate/up 通过 SwiGLU 非线性传播，论文给出一阶近似后的对角度量：

```
G_gate(v) = ||W_d[:,r]||_2^2 · Diag(E[(SiLU'(g_r) u_r)^2 (h_v ⊙ h_v)])
G_up(v)   = ||W_d[:,r]||_2^2 · Diag(E[SiLU(g_r)^2 (h_v ⊙ h_v)])
```

**Action head**：  
DiT 动作头区分 cross-attention 的 query 侧与 key/value 侧输入，使用 GELU FFN 的敏感度，并对 AdaLN 的 scale/shift 分支使用输出侧权重 `[ν;1]`，其中 `ν_j=E[LayerNorm(x)_j^2]`。

### 2.4 动作感知混合比特分配

每层状态按精度排序：

```
GPTQ(4bit) → GPTQ(3bit) → VC(2.75bit) → VC(2.5bit) → ... → VC(1bit)
```

1-bit 操作点还允许 `VC(0.75bit)`；只允许相邻状态转移。对每层测量“只把该层降一档”造成的最终动作相对误差增量 `Δ_l`，然后：

```
l* = argmin_l  Δ_l / (cost_l(ρ_l) - cost_l(ρ'_l))
```

`cost_l` 是该层实际存储成本，包含码本与 row-group scale 等 metadata；分配时先选计算 bpw 更高的组件（语言骨干或动作头），再在该组件内选上述比率最小的层。这样避免语言骨干或动作头被不成比例压缩。

### 2.5 两阶段后量化精调

**索引重分配**：收集层输入二阶矩：

```
H_l = (1/N_l) Σ_t x_t x_t^T
H~_l = 0.5(H_l + H_l^T) + 0.1 · tr(H_l)/n_l · I
H~_l^{-1} = U_l^T U_l
```

对当前 d 维向量的坐标 J 与剩余坐标 R：

```
a_J* = argmin_k || (w̄_J - q_k) U_JJ^{-1} ||_2^2
w̄_R ← w̄_R - (w̄_J - q_{a_J*}) U_JJ^{-1} U_JR
```

先重分配当前向量，再把残差传播到剩余坐标，使后续向量吸收前面的量化误差。此阶段码本、scale、混合比特分配固定，只更新索引。

**动作级校准**：固定索引 `a*`，只优化码本 `C` 与 scale `s`：

```
min_{C,s} E_x [ (1/N_x) || a_Q(x; C, s, a*) - a_BF16(x) ||_F^2 ]
```

`N_x` 是动作张量元素数。该目标直接让量化策略的最终动作匹配 BF16 动作，同时保持存储率不变。

## 3. 带数字走一遍：玩具例子 (Worked Example)

> 以下为**假设数值**，只用于验算 SACQ 的两个关键直觉：角色度量会改变码字选择；比特分配看“每 bit 的动作误差增量”。

### 3.1 角色度量改变最近码字

假设 `d=4`、`M=16`，则名义索引率：

```
b = log2(16)/4 = 4/4 = 1 bpw
```

假设归一化向量 `v=(0.9, 0.1, 0.05, 0)`，两个候选码字：

```
c1=(1.0, 0.0, 0.0, 0)
c2=(0.8, 0.1, 0.2, 0)
```

**欧氏度量 `G=I`**：

```
dist(v,c1) = (-0.1)^2 + 0.1^2 + 0.05^2 = 0.01+0.01+0.0025 = 0.0225
dist(v,c2) = 0.1^2 + 0^2 + (-0.15)^2 = 0.01+0+0.0225 = 0.0325
```

欧氏下选 `c1`。

**角色感知度量 `G=diag(1,100,1,1)`**（假设第 2 个坐标对下游极敏感）：

```
dist_G(v,c1) = 0.01×1 + 0.01×100 + 0.0025×1 = 0.01+1.0+0.0025 = 1.0125
dist_G(v,c2) = 0.01×1 + 0×100 + 0.0225×1 = 0.0325
```

此时选 `c2`。验算成立：同一个向量、同一组码字，仅因 `G` 强调第 2 坐标，分配从 `c1` 翻到 `c2`。这对应论文的论点：相似层局部误差在不同投影角色下代价不同。

### 3.2 比特分配比率

假设两层各降一档：

```
层1：Δ_1=0.01，节省 0.25 bit → 比率 0.01/0.25 = 0.04
层2：Δ_2=0.03，节省 0.50 bit → 比率 0.03/0.50 = 0.06
```

按 `Δ_l/Δcost_l` 最小，先降层 1。直觉：层 2 虽然绝对误差更大，但节省的存储更多；论文用“每 bit 换来的动作误差”而不是单看 Δ 或单看层局部重构。

**推理效率（表 3）**：W1.5A8 平均 93.55%，14.07 ms，相对 BF16 1.51×；W1.5A16 平均 93.85%，20.20 ms，1.05×。A8 使用 INT8 激活、INT8 GEMM，部分 attention 走 INT8-QK/FP8-PV；action cross-attention 与 language attention 的核心仍是 BF16。

**SimplER（表 2）**：2 L/A bpw 下，SACQ VM 63.76%、VA 52.27%；BF16 为 58.90%、53.45%。1.5 bpw 下降到 VM 57.20%、VA 44.67%。【作者主张】SACQ 在 VM 上超过 BF16、VA 上保持可比；但不能说所有 SimplER 协议都超过 BF16。

**OpenVLA-OFT（表 7）**：BF16 95.80%、15.203 GB；SACQ 3.00 V/L bpw 95.55%、5.128 GB；2.00 V/L bpw 94.05%、2.926 GB；1.50 V/L bpw 85.70%、2.463 GB。注意 V/L bpw 覆盖 420 个 vision/language 层，动作头排除。

**LIBERO-Pro（表 8）**：BF16 43.67%；SACQ 3.00/2.00/1.50 L/A bpw 分别为 43.76%、43.62%、42.62%。2 bpw 与 BF16 几乎持平，1.5 bpw 低约 1.05 个百分点。

**消融（表 4）**：1.5 bpw 下，Uniform Euclidean VQ 为 0.00%；加 mixed-bit allocation 仍 0.00%；加 structure-aware fitting 到 47.50%；完整 SACQ 93.85%。去掉 structure-aware 为 92.60%，去掉 allocation 为 93.25%。1.25 bpw 下，无 structure-aware 87.65%，完整 92.70%；LIBERO-Long 从 73.2% 到 87.6%，+14.4 个百分点。

**有限精调预算（表 9）**：90 个校准观测/套件时，structure-aware 84.15%，layer-local 74.55%，Euclidean 39.75%；720 时 layer-local 91.45% 反超 structure-aware 91.25%（+0.20）；1,440 时 92.95% vs 92.55%（+0.40）；2,880 时 structure-aware 93.85%，layer-local 92.60%。【作者主张】structure-aware 的主要价值是“精调受限时的更强低比特初始化”，而不是每个校准预算都绝对最高；这个细节必须保留。

## 6. 能力与失败模式 (Capabilities & Failure Modes)

**能做什么**

- 在 GR00T N1.7 的 LIBERO 仿真上，把语言/动作候选层压到 1.5 L/A bpw 仍保持 93.85% 平均成功率，接近 BF16 的 94.10%。
- 显著降低 resident memory：5.677 GB → 1.175 GB；A8 配置还能给 1.51× 推理加速。
- 在 SimplER 的 VM 上 2 bpw 超过 BF16 参考；在 LIBERO-Pro 扰动集上 2 bpw 与 BF16 几乎持平。
- 方法可迁移到 OpenVLA-OFT 的 vision/language 层量化，但动作头未量化，bpw 定义不同。

**不能做什么 / 失败模式**

- 不能保证真实机器人有效：论文没有真实平台实验。
- 1 bpw 明显退化：LIBERO 平均 83.05%，Long 仅 65.6%；超低比特仍有边界。
- SimplER VA 在 1.5 bpw 降到 44.67%，低于 BF16 53.45%；低比特并非所有协议都稳。
- 校准数据少时，结构感知优势更明显，但 layer-local 在 720/1,440 观测时略高；说明方法收益与校准数据量及由此带来的优化更新/输入统计量相关；附录 G 中精调固定为 12 epochs，不能据此推断对精调轮次的依赖。
- 基线存在移植/自定义：TWLA 的 PyTorch VLA port 未完全复现原实现，GPTQ-Ternary 是作者扩展；比较时要看条件。
- 量化范围不是全模型：GR00T 的 vision encoder 保持 4-bit，128 层与 token embedding 固定 4-bit；不能把 1.5 bpw 理解为所有参数都是 1.5 bit。

### 6.1 隐含假设 (Hidden Assumptions)

- 校准集能代表部署分布；否则动作级校准可能过拟合校准请求。
- 最终动作 MSE 与任务成功率足够相关；论文用动作相对误差做分配与验证，但这不是所有机器人任务的充分统计量。
- 可分离近似 `G(v)=B_rr A_II` 足够保留关键敏感度；该近似丢弃 B 的跨通道项和 A 的跨向量相关性；二阶索引重分配补偿的是跨向量量化误差，而非被丢弃的跨通道项。
- 每层一个码本、`d=4`、`g=64` 的设置在两个模型上可复用；换动作头或换模态可能需要重推度量。
- 仿真成功率可部分反映真实部署；作者明确把真实机器人留给未来工作。
- metadata 开销在低比特下不可忽略；论文用计算 bpw 做分配，但表里的 L/A bpw 不含 metadata，读表时需区分。

## 7. 与相关工作对比 (Comparison)

| 方法 | 量化表示 | 是否显式建模下游结构 | 是否用最终动作误差分配 | 论文中的定位/条件 |
|------|----------|----------------------|--------------------------|-------------------|
| HQQ | 均匀低比特 | 否 | 否 | 基线；3/2 bpw 下明显退化 |
| GPTQ | 标量/组量化 + 二阶补偿 | 层局部重构 | 否 | 基线；2 bpw 64.35%，1.5 bpw 附近有三值扩展 |
| AQLM | 加性码本 | 层局部重构 | 否 | 强码本基线；1.5 bpw 87.50% |
| ActQuant | 动作引导的混合精度 + scale 优化 | 部分动作敏感 | 动作敏感跨张量分配，未说明按最终动作误差 | 基线；在 GR00T DiT 上是作者移植 |
| TWLA | 三值权重 | 未强调投影角色 | 否 | 基线；PyTorch port 有存储/运行时限制 |
| SACQ（本文） | 结构感知向量码本 + 混合比特 + 两阶段精调 | 是，按 q/k/v/o、FFN、AdaLN 角色 | 是，按最终动作误差/bit | 在 GR00T N1.7/LIBERO 主结果中，1.5 L/A bpw 为 93.85%，BF16 为 94.10% |

**面试 Tip**：被问到 SACQ 时，先答“它不是把 LLM PTQ 直接搬到 VLA，而是把量化误差的度量从投影输出搬到下游动作；三组件是结构感知码本、动作误差/bit 分配、索引重排+动作级校准”，再补条件“GR00T N1.7/LIBERO 1.5 bpw 93.85% vs BF16 94.10%，但真实机器人未验”。

## 8. 精读建议 (Reading Guide)

- **值得精读原文的人**：
  1. 做 VLA 边缘部署、weight-only PTQ、码本量化的人；
  2. 需要复现“动作误差驱动比特分配”管线的工程师；
  3. 研究 VLA 专用量化、想把结构先验注入 PTQ 的研究者。
- **建议章节路径**：先读 §3.1 的 q/k/v/o 与 FFN 度量推导 → 再看 §3.2 的分配公式与 §3.3 的索引重排/动作校准 → 然后看 §5 消融与附录 G 的校准预算分析 → 最后看附录 A.3 的 DiT 动作头细节。可跳过 §2 的基础码本定义（若已熟悉 GPTVQ/AQLM）。
- **不值得精读的理由**：如果你不做机器人学习、只关心 LLM 量化，或只关心真实机器人闭环而不是仿真基准，读摘要和 §4 表格即可；本文的记忆机制与真实平台验证不是重点。
