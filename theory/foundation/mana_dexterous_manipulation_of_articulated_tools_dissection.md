## 1. 核心架构/方法总览 (Overview / Architecture)

### 1.1 系统对比概览 (System Component Comparison)

Mana 系统由两大模块组成：**Mana 数据系统**（离线生成仿真轨迹）和**机器人系统**（在线执行策略）。

| 组件 | 输入 | 输出 | 训练/推理 | 频率/时序 |
|------|------|------|-----------|-----------|
| **抓握生成器** (Grasp Generator) | 工具 mesh + 功能区域标注 (<1 min/工具) | 密集抓握关键帧集 | 离线一次性 | 每工具 ~数分钟 |
| **轨迹生成器** (Trajectory Generator) | 关键帧图 + 初始手配置 | 完整操作轨迹（腕部+手指关节） | 离线批量生成 | 数千轨迹/工具 |
| — 预抓取阶段 | 初始手配置 → 预抓取姿态   | RRT-Connect 路径 | 运动规划 (GPU) | 无 RL |
| — 抓取阶段 | 预抓取姿态 → 稳定抓握   | 几何挤压 或 短视野 RL | MP 或 RL | 接触丰富 |
| — 操作阶段 | 稳定抓握 → 工具构型变化   | RL 生成的操作轨迹 | RL (goal-reaching) | 高接触力 |
| **感知模块** | RGB-D 图像 (RealSense D435) | 工具点云（腕部坐标系） | 推理 (SAM 3 + Fast Foundation Stereo) | ~10 Hz |
| **视觉运动策略** | 点云 + 本体感知 | 腕部 delta 6D 姿态 + 手指 delta 关节角 | 推理 (Transformer Diffusion) | ~10 Hz |
| **底层控制器** | 关节角目标 | 电机扭矩 | PD 控制 | 高频 (~1 kHz) |

### 1.2 关键机制 (Key Mechanism)

Mana 的核心设计哲学是**"分解复杂度"**：

- **关键帧骨架化**：不要求 RL 从头探索长视野操作，而是用程序化关键帧定义操作的"骨架"——预抓取、稳定抓握、在手中操作等阶段的关键状态
- **分层求解器**：不同物理需求的阶段使用不同求解器
  - 预抓取（无接触力需求）→ RRT-Connect 运动规划  
  - 抓取（中等接触）→ 几何挤压 或 短视野 RL  
  - 操作（高接触力）→ 短视野 goal-reaching RL  
- **功能区域标注**：用户只需在工具 mesh 上标记功能区域（如钳子的把手、注射器的活塞和筒身），<1 分钟/工具。标注驱动接触域构建和 IK 优化

⚡ **Eureka Moment**：把"学习铰接工具操作"这个长视野探索难题，重新定义为"动画师画关键帧 + 间插"的问题——关键帧用程序化生成，间插用运动规划和 RL 分工完成，从而绕开了端到端 RL 的探索困境。

## 2. 数学核心 (Math Core)

### 2.1 RL 奖励函数 (In-hand Actuation)

 Mana 将操作阶段建模为目标到达问题，奖励函数由三项组成：

```
r = r_tool + w1 · r_hand + w2 · r_contact
```

| 符号 | 含义 | 直觉 |
|------|------|------|
| `r_tool` | 工具姿态匹配度 | 工具到达目标构型（如闭合/打开） |
| `r_hand` | 手部姿态匹配度 | 手指接近目标关节位置 |
| `r_contact` | 接触数量 + 接触点稳定性 | 维持稳定接触，防止滑动/弹出 |
| `w1, w2` | 权重系数 | 平衡各项目标重要性 |

### 2.2 扩散策略训练目标

```
L = E_(o_i, a_i)~D, t~U[0,T] [ || a_i - π(a~_i, o_i, t) ||^2 ]
```

| 符号 | 含义 |
|------|------|
| `o_i` | 第 i 步观测（点云 + 本体感知） |
| `a_i` | 第 i 步真实动作 |
| `a~_i` | 加噪后的动作样本 |
| `t` | 扩散时间步 |
| `π` | Transformer Diffusion 策略网络 |

### 2.3 底层 PD 控制

```
τ = Kp · e + Kd · ė
```

| 符号 | 含义 |
|------|------|
| `τ` | 电机扭矩输出 |
| `e` | 关节跟踪误差（目标 - 实际） |
| `Kp, Kd` | 比例/微分增益 |

📌 **Napkin Formula**（一行抓住本质）：

```
长视野操作 = 关键帧骨架 (程序化) + 段间运动 (MP/RL 分工) → 扩散策略学习 → 零样本 sim-to-real
```

> 符号与本文保持一致：$r$ 为奖励，$L$ 为损失，$\tau$ 为扭矩，$o/a$ 为观测/动作。  

## 3. 带数字走一遍：玩具例子 (Worked Example)

以**注射器操作**为例，走一遍 Mana 的完整流程：

**阶段 1：关键帧生成**
- 用户在注射器 mesh 上标注：活塞把手区域 + 筒身区域（<1 分钟）
- 抓握生成器构建接触域 → IK 优化手指接触点  
- 采样出 200 个关键帧：覆盖不同活塞位置（完全推入 → 完全拉出）和不同抓握角度  

**阶段 2：轨迹生成（假设 50 条成功轨迹）**
- 预抓取：RRT-Connect 从随机初始配置规划到预抓取姿态（手指偏离最终接触点 5-15mm）
- 抓取：几何挤压策略将手指沿接触法线向内移动 3mm，闭合抓握，抬升 5cm
- 操作：RL goal-reaching 从"抓握闭合"关键帧到"活塞拉出 2cm"关键帧
  - 奖励示例：r_tool=0.8（活塞到位），r_hand=0.6（手指位置匹配），r_contact=0.9（3/4 指保持接触）
  - 总奖励 $r = 0.8 + 0.3 \times 0.6 + 0.5 \times 0.9 = 1.13$  
  - 成功阈值：工具构型误差 <2mm 且姿态误差 <5°，持续 0.5s

**阶段 3：策略训练**
- 50 条轨迹 → 约 5000 步 $(o_i, a_i)$ 样本  
- 扩散策略训练：加噪级别 $t \in [0, 20]$，MSE 损失收敛到 $\sim 0.01$  
- 点云随机化：高斯噪声 $\sigma = 0.5\,\text{mm}$ + 随机遮挡 $20\%$ 点

**阶段 4：推理**
- RealSense 捕获 RGB-D → SAM 3 分割 → 立体匹配 → 腕部坐标系点云（~2000 点）
- 策略输出：腕部 delta 姿态 $[dx, dy, dz, drx, dry, drz]$ + 手指 delta 关节角 $[4\times4\ \text{DOF}]$
- 执行频率 $10\ \text{Hz}$，单次推理 $\sim100\ \text{ms}$（$2\times\text{RTX}\ 4090$）
- 预期成功率：~70%（基于论文 Table 1 注射器数据）

## 4. 工程视角 (Engineering View)

| 维度 | 数值/约束 | 工程含义 |
|------|-----------|----------|
| 推理频率 | ~10 Hz | 足够准静态操作；动态抓取可能需要 30+ Hz |
| 单次推理延迟 | ~100 ms | $2\times\text{RTX}\ 4090$；单卡可能 bottleneck |
| 数据生成时间 | <1 min 标注 + 数分钟生成/工具 | 可扩展到新工具；但需要 URDF |
| 力控范围 | 3-7 N（操作力） | Allegro 手最大扭矩 0.7 Nm 限制；>10 N 工具不可用 |
| 工具厚度 | 0.8-1.5 cm | 相对 Allegro 手（$\sim2\times$人手大小）偏小 |
| 自定义指尖 | 扁平硅胶接触面 | 关键硬件改动——半球形刚性指尖在薄工具上会滑动 |
| 感知输入 | RGB-D 点云（腕部坐标系） | 依赖 SAM 3 分割质量；遮挡下性能下降 |
| Sim-to-Real | 零样本迁移 | 训练时点云随机化（噪声 + 遮挡）是关键 |

**部署约束**：
- 需要 IsaacLab 仿真环境生成数据（GPU 加速）
- 需要工具 mesh + URDF（相机扫描可获取）
- 当前实现中，工具到目标的精细对齐（如 0.5mm 细线）仍需遥操作辅助

### 6.3 隐含假设 (Hidden Assumptions)

1. **工具 URDF 模型可用**：论文假设每个新工具都有或可获取准确的 mesh + URDF。现实中，非结构化环境中的工具可能没有现成模型
2. **功能区域可标注**：虽然标注 <1 分钟，但仍需人类在 3D 界面中标记。完全自动化需要依赖 affordance 模型（论文提及但未验证）
3. **准静态操作假设**：10 Hz 控制频率 + 低阻抗工具（<10 N）——动态操作（如快速切割、甩动）不在能力范围内
4. **单工具单任务假设**：每次只操作一个工具完成一个任务；多工具协作或工具切换未探索
5. **桌面初始化假设**：所有实验从桌面随机姿态开始；悬挂/浮动/手持工具未覆盖
