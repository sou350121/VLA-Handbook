💡 **X-Ray 开场**
RL 微调扩散策略时，模型会为了最大化奖励而把所有行为坍缩到一个"最优"模式上——就像一个人为了最快到达目的地只走一条路，失去了应对突发情况的灵活性。本文的核心发现是：预训练策略的潜在噪声空间中已经隐式编码了多种行为模式，通过无监督发现这些模式并用互信息作为内在奖励，可以在微调过程中同时提升任务成功率和保留行为多样性。对 VLA 研究者的意义：随着 VLA 策略越来越依赖 diffusion/flow 架构，RL 微调时的多样性保留将成为关键问题。

## 1. 核心架构/方法总览 (Overview / Architecture)

### 1.1 系统对比概览 (System Component Comparison)

| 组件 | 输入 | 输出 | 训练方式 | 是否可微 |
|------|------|------|----------|----------|
| 预训练策略 π_θ(a\|s,w) | 状态 s + 噪声 w | 动作 a | IL（模仿学习） | 冻结 |
| Steering Policy π_ψ^W(w\|s,z) | 状态 s + 模式 z | 噪声 w | RL + 内在奖励 | 可训练 |
| Inference Model q_φ(z\|s) | 下一状态 $s_{t+1}$ | 模式分布 | 交叉熵损失 | 可训练 |
| 环境 MDP | 动作 a | 下一状态 s' + 奖励 r | 固定 | N/A |

**训练流程**：
1. 阶段 1（模式发现）：联合训练 steering policy 和 inference model，最大化 I(Z;S)
2. 阶段 2（RLFT）：在内在奖励 + 任务奖励下微调 steering policy，正则化微调过程

### 1.2 关键机制 (Key Mechanism)

**核心问题**：经典多模态定义依赖动作密度的局部极大值，但扩散/流模型的动作密度没有闭式表达，无法直接计算。

**关键洞察**：预训练策略的潜在噪声 w 与动作 a 在给定状态 s 下是统计依赖的——即 I(W;A\|S) > 0。这意味着不同的噪声值确实会诱导不同的动作分布。然而，动作层面的多样性不等于轨迹层面的多样性（运动学冗余会导致多个关节动作产生相同的末端执行器运动）。

**解决方案**：
- 引入离散潜在变量 $z \in Z$ 作为行为模式的索引
- 将 steering policy 重参数化为 π_ψ^W(w\|s,z)，即用 z 控制噪声采样
- 训练 inference model q_φ(z\|s_{t+1}) 从访问的状态反推模式
- I(Z;S) 的估计作为内在奖励，鼓励不同 z 诱导不同的状态访问分布

⚡ **Eureka Moment**：预训练扩散/流策略的潜在噪声空间中已经"免费"编码了多种行为模式——不需要重新训练或额外数据，只需要一个 steering policy 和一个 inference model 就能把它们"解锁"出来，并用互信息作为内在奖励来防止 RL 微调时的模式坍塌。


## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：
```
max_θ J(π_θ) + λ·M(π_θ)
其中 M(π_θ) ≈ I(Z;S) = H(Z) - H(Z\|S)
```

**目标**：在最大化期望回报的同时，最大化行为模式与状态之间的互信息（即不同模式访问不同的状态空间区域）。

**核心方程**：

```
I(W;A|S) = E_{s,w}[ D_KL( π_θ(·|s,w) || p(·|s) ) ] > 0
```

这证明了潜在噪声与动作之间的条件互信息严格为正——不同的噪声确实产生不同的动作分布。

```
I(Z;S) = H(Z) - H(Z|S)
       = E_z[log p(z)] - E_s[E_{z|s}[log q_φ(z|s)]]
       ≈ E_z[log p(z)] - E_s[sum_z p(z|s) · log q_φ(z|s)]
```

互信息估计通过 inference model q_φ(z\|s) 实现，其中 H(Z) 由先验分布 p(z)（通常均匀）确定，H(Z\|S) 由 inference model 的交叉熵损失近似。

```
总奖励 = r_task(s,a) + β · I(Z;S)
```

$\beta$ 控制内在奖励与任务奖励的权衡。

**变量说明**：

| 符号 | 含义 |
|------|------|
| $\theta$ | 预训练策略参数（冻结） |
| $\psi$ | steering policy 参数 |
| $\phi$ | inference model 参数 |
| $z \in Z$ | 离散行为模式变量 |
| $w \in W$ | 潜在噪声变量 |
| $s \in S$ | 状态 |
| $a \in A$ | 动作 |
| I(Z;S) | 模式-状态互信息（内在奖励） |
| $\beta$ | 内在奖励权重系数 |
| $\lambda$ | 多模态性正则化系数 |

> 符号与本文保持一致。论文使用 MDP 标准记号。

## 3. 带数字走一遍：玩具例子 (Worked Example)

假设一个简化的 2D 机械臂任务，有 3 个潜在行为模式（$z \in \{0, 1, 2\}$）：

**模式 0**：从左侧抓取目标
**模式 1**：从右侧抓取目标
**模式 2**：从上方抓取目标

**预训练阶段**：扩散策略从演示数据中学到了这三种模式，但噪声空间是未结构化的——随机采样 w 可能以 33%/33%/34% 的概率产生三种模式。

**模式发现阶段**：
- steering policy 学会：给定 $z=0$ → 采样 $w$ 使策略从左侧抓取
- inference model 学会：看到末端执行器在目标左侧 → 预测 $z=0$
- I(Z;S) 估计：假设 H(Z) = log₂(3) ≈ 1.58 bits，H(Z\|S) ≈ 0.3 bits
- 内在奖励 $\approx 1.58 - 0.3 = 1.28$ bits

**RLFT 阶段对比**：

| 方法 | 任务奖励 | I(Z;S) | 有效模式数 |
|------|----------|---------|-----------|
| 标准 RLFT（无正则化） | 0.95 | 0.1 | ~1.1（几乎坍塌为单一模式） |
| BMD（本文） | 0.93 | 1.15 | ~2.8（保留三种模式） |

**直觉**：BMD 的任务奖励略低（0.93 vs 0.95），因为它不把所有概率质量集中在"最优"模式上，但保留了 2.8 个有效模式（vs 1.1），意味着策略在面对扰动或未见场景时有更强的适应性。

## 4. 工程视角 (Engineering View)

| 维度 | 考量 |
|------|------|
| 额外参数 | steering policy + inference model（相对预训练策略通常较小） |
| 训练阶段 | 两阶段：模式发现 → RLFT（可交替训练） |
| 推理延迟 | 推理时需额外运行 steering policy 采样 w（增加一次前向传播） |
| 内存开销 | 需维护三个模型（预训练策略冻结、steering policy、inference model） |
| 超参敏感 | $\beta$（内在奖励权重）、$z$ 的基数（模式数量）、训练轮次比例 |
| 部署约束 | 预训练策略冻结 → 适合边缘部署（只需加载小模型） |

**工程含义**：
- steering policy 通常远小于预训练扩散策略（例如 MLP vs U-Net），额外推理开销可控
- 预训练策略冻结意味着部署时不需要存储大模型的梯度，内存友好
- $\beta$ 的选择是关键 trade-off：过高 → 任务性能下降；过低 → 模式坍塌

## 6. 能力与失败模式 (Capabilities & Failure Modes)

### 能做什么
- **防止模式坍塌**：在 RL 微调过程中保留预训练学到的多种行为策略
- **无需先验知识**：不需要预先知道模式数量或类型
- **无需标注**：完全无监督，从预训练策略中自动发现
- **与多种架构兼容**：适用于扩散策略和流策略

### 不能做什么
- **不提升预训练策略本身**：只解决微调时的多样性问题，不改善 IL 阶段的学习
- **不处理连续模式空间**：论文聚焦离散 $z$，连续模式（$z \in \mathbb{R}^d$）仅提及未实验
- **不适用于非噪声条件策略**：方法依赖噪声条件生成策略（扩散/流），不适用于确定性策略或 VLA 策略
- **未验证真实机器人**：所有实验在仿真环境进行

### 6.1 隐含假设 (Hidden Assumptions)

1. **Steerability Assumption**：预训练策略的噪声输入可以被有效控制以诱导不同行为。如果预训练策略的噪声-动作映射是高度非线性的或存在"死区"，steering policy 可能无法有效探索所有模式。

2. **预训练策略已包含足够多样性**：BMD 只能"发现"预训练策略中已有的模式，不能创造新行为。如果 IL 阶段的演示数据本身缺乏多样性，BMD 也无能为力。

3. **模式数量固定**：论文使用离散 z，需要预设模式数量 |Z|。实际策略中的模式数量可能未知或动态变化。

4. **Inference Model 的可辨识性**：q_φ(z\|s) 需要能够从状态可靠地反推模式。如果不同模式导致相似的状态轨迹（运动学冗余），inference model 可能无法区分。

5. **仿真到真实的 gap**：所有实验在仿真中进行，真实机器人的传感器噪声、执行器延迟、动力学不确定性可能影响 steering policy 的有效性。
