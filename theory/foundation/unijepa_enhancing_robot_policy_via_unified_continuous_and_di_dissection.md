💡 **X-Ray 开场**

现有 VLA 方法分裂为两条路线：一条基于 VLM 理解（如 OpenVLA），语义强但缺动态建模；一条基于生成预测（如 π₀），能预测未来但丢失语言对齐。UniJEPA 的核心发现是：**让同一个 2.9B 模型同时做两件事——用离散 token 预测学语言理解，用连续高维特征预测学世界模型——然后第二阶段把这两股表征融合进 Flow Matching 动作头，就能在未见物体和场景上获得显著的泛化提升。** 对 VLA 研究者的含义是：未来表征预测不必走 VQ-VAE 量化路线，连续特征预测同样有效且更简单。

### 1.2 关键机制 (Key Mechanism)

UniJEPA 的设计围绕三个核心洞察：

1. **双路预测优于单路**：纯理解型 VLA（如 OpenVLA）语义强但无法建模物理动态；纯生成型 VLA（如 π₀）能预测未来但丢失语言对齐。两者统一优于任一单路。

2. **连续特征预测优于 VQ 量化**：UP-VLA 等先验工作用 VQ-VAE 将未来帧量化为离散 token 进行预测，但量化过程损失高频细节。UniJEPA 直接用冻结视觉编码器（SigLIP/DINOv3）提取连续高维特征作为预测目标，信息更丰富。

3. **MoT 架构实现模态隔离**：通过 Mixture-of-Transformers，每个模态（理解/生成/动作/状态）有独立的 attention 权重，但共享底层 transformer 层。块状掩码机制确保模态内双向注意力、模态间因果注意力（图像→语言→图像预测→状态→动作）。

⚡ **Eureka Moment**：**未来状态预测不必走离散化（VQ）路线——用冻结视觉编码器的连续高维特征做 MSE 预测，既能保留丰富语义信息，又能通过同一 MoT 架构与离散语言理解任务无缝共享计算。**

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：

```
L_total = L_continuous_prediction + L_language_understanding + L_flow_matching_action
```

即：**统一表征 = 连续特征MSE预测 + 离散语言交叉熵 + Flow Matching向量场回归**

### 2.1 第一阶段：统一视觉-语言嵌入建模

**目标**：给定当前观测 o_t 和语言指令 l，预测未来 t+h 时刻的联合视觉-文本嵌入。

**连续分支（世界建模）**：用冻结视觉编码器 V 提取未来观测的连续特征，模型预测这些特征。

```
L_cont = (1/n) · Σ_i ‖c_i^pred - c_i‖²₂
其中 c_i = V(o_{t+h}) 的第 i 维特征
```

**离散分支（语言理解）**：自回归生成文本 token 序列。

```
L_lang = -(1/m) · Σ_j log P_θ(d_j | d_{<j}, l, o_t)
```

**第一阶段总损失**：

```
L₁ = L_cont + L_lang
```

**变量说明**：

| 符号 | 含义 |
|------|------|
| o_t | t 时刻的观测图像 |
| l | 语言指令 |
| V | 冻结的视觉编码器（SigLIP / DINOv3） |
| c_i | 未来观测编码的第 i 维连续特征 |
| c_i^pred | 模型预测的第 i 维特征 |
| d_j | 第 j 个离散语言 token |
| n | 连续特征维度 |
| m | 语言 token 数量 |

**直觉**：连续分支学"世界怎么变"（动态建模），离散分支学"任务是什么"（语义理解）。两者共享 MoT 底层表征，互相促进。

### 2.2 第二阶段：统一动作建模

**目标**：在预训练表征基础上，引入动作空间，用 Flow Matching 学习从预测表征到动作的映射。

**Flow Matching 损失**：

```
L_flow = E_{τ,D} [ ‖U_{v,l,a}(A_t^τ, o_t, s_t, l, τ) - (A_t - A_t^τ)‖²₂ ]
其中 A_t^τ = (1-τ)·ε + τ·A_t,  ε ~ N(0, I)
```

**第二阶段总损失**（联合优化生成专家 + 动作专家）：

```
L₂ = L_cont + L_flow
```

**变量说明**：

| 符号 | 含义 |
|------|------|
| A_t | 目标动作序列 (a_t, a_{t+1}, ..., a_{t+h}) |
| A_t^τ | τ 时刻的插值动作（从噪声到目标的轨迹点） |
| τ | Flow Matching 时间步，控制插值进度 |
| ε | 高斯噪声 ~ N(0, I) |
| s_t | 本体感知状态（关节角度等） |
| U_{v,l,a} | 包含动作专家的统一模型 |

**直觉**：Flow Matching 直接学习从噪声到动作的向量场，比扩散模型的多步去噪更高效。连续未来特征 ô_{t+h} 作为额外条件输入动作专家，让动作预测"知道"未来会发生什么。

## 3. 带数字走一遍：玩具例子 (Worked Example)

假设一个简化的 2D 抓取场景：

**场景**：机器人需要从位置 A 抓取物体移动到位置 B。

**输入**：
- o_t: 当前帧，物体在 A 点，机械臂在起始位
- l: "pick up the red block and move it to the right"

**第一阶段推理（预训练后）**：
- 离散分支输出语言理解：d = ["pick", "red", "block", "move", "right"]
- 连续分支预测未来特征：ô_{t+3} 显示物体在 B 点，机械臂在 B 点上方

```
L_cont 计算示例（假设 4 维特征简化）：
真实未来特征 c = [0.8, 0.3, 0.9, 0.1]
预测特征    c^pred = [0.7, 0.4, 0.8, 0.2]
L_cont = (0.1² + 0.1² + 0.1² + 0.1²) / 4 = 0.01
```

**第二阶段推理（微调后）**：
- 动作专家接收 ô_{t+3}（未来特征）+ o_t（当前观测）+ s_t（当前关节角）+ l（指令）
- Flow Matching 采样 τ = 0.3：A^0.3 = 0.7·ε + 0.3·A_target
- 模型预测向量场：U(A^0.3, ...) ≈ A_target - A^0.3
- 积分得到动作序列：A_t = [grip_open, move_right, grip_close, lift]

**关键观察**：连续未来特征 ô_{t+3} 告诉动作专家"目标状态是什么样子"，这比仅靠当前观测 o_t 做动作预测更稳健——模型知道"成功长什么样"。

### 6.3 隐含假设 (Hidden Assumptions)

1. **冻结视觉编码器的特征足够表征动态**：假设 SigLIP/DINOv3 的高维特征能捕捉与动作相关的所有动态信息。但如果编码器在自然图像上预训练，可能对机器人场景的高频细节（如物体形变、接触力）不敏感。

2. **MoT 块状掩码的顺序是最佳的**：图像→语言→图像预测→状态→动作的因果顺序假设了信息只能单向流动。但实际中，动作执行结果可能需要反馈到语言理解（如"我没抓住，换个说法"）。

3. **预训练的连续预测能力可直接迁移到动作**：第一阶段学的是"预测未来长什么样"，第二阶段直接用它做动作条件。但"知道未来长什么样"和"知道如何达到那个未来"之间仍有 gap——论文未直接验证这个 gap 的大小。

4. **单目足够**：所有对比实验都用单目 224×224，但实际部署中深度信息和多视角可能显著影响性能。论文未报告多视图配置的结果。
