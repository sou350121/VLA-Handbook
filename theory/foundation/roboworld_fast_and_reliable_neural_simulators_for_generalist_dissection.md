## 1. 核心架构/方法总览 (Overview / Architecture)

### 1.1 系统对比概览 (System Component Comparison)

| 组件 | 输入 | 输出 | 训练方式 | 推理方式 |
|------|------|------|----------|----------|
| 自回归视频世界模型 | 初始多视角观察帧 x⁰ + 动作序列 a¹:ᴺ | 未来观察帧 x¹:ᴺ | 两阶段：160k Diffusion Forcing 步 + 40k Step Forcing 步 | 闭环：策略预测动作 → 世界模型生成下一帧 → 反馈给策略 |
| 任务进度感知 VLM 评分器 | 生成的 rollout 视频（3 视角） | 0-5 分任务进度评分 | 提示工程（无需训练），GPT-4o | 对完整 rollout 一次性评分 |
| 动作适配器（可选） | 策略原始动作（如关节速度） | 末端执行器笛卡尔位置 | 浅层 MLP，2 层 | 前向传播 |

**训练/推理时序差异**：训练时每个帧独立采样噪声级别（Diffusion Forcing 风格），推理时固定 4 步去噪 schedule；训练用 45 帧 clip，推理用滑动窗口 W=45（开环）或 W=77（闭环）。

### 1.2 关键机制 (Key Mechanism)

**为什么用 Step Forcing？**

传统自回归视频模型面临三个矛盾：

1. **Teacher Forcing**（用真实帧做上下文）：训练-测试不匹配， rollout 时误差累积
2. **Self Forcing**（用自生成帧做上下文）：缩小了上下文差距，但训练需要串行 rollout，成本高；且动作作用在模型生成的状态上而非真实数据状态上，破坏了动作-观察动力学
3. **Diffusion Forcing**（用噪声真实帧做上下文）：对噪声上下文更鲁棒，但外推时仍会漂移

Step Forcing 的核心思路：**取中间态**——用一步自前推（one-step self-forward）得到的先验作为训练起点，既让模型接触到自己的生成误差，又通过锚定步骤（anchor step，概率 p）保留真实数据动力学。

⚡ **Eureka Moment**：用与推理时相同的去噪 schedule 做一步自前推来生成训练先验——训练和推理的噪声 schedule 对齐，消除了 train-test mismatch，使 4 步去噪的自回归 rollout 成为可能。

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：

```
L = E[||xⁱ - x̂ⁱ(x̂ⁱ_{kⁱ⁻¹}, t̃ⁱ, ĥⁱ, aⁱ)||²]
```

**目标**：最小化预测帧与真实帧的 L2 误差，其中预测帧从一步自前推先验出发，在自前推上下文的条件下生成。

**公式分解**：

```
一步自前推:  x̂ⁱ_{kⁱ⁻¹} = xⁱ_{kⁱ} - (t_{kⁱ} - t_{kⁱ⁻¹}) · sg[V_θ(xⁱ_{kⁱ}, t_{kⁱ}, hⁱ, aⁱ)]
干净帧预测:  x̂ⁱ = x̂ⁱ_{kⁱ⁻¹} - t̃ⁱ · V_θ(x̂ⁱ_{kⁱ⁻¹}, t̃ⁱ, ĥⁱ, aⁱ)
训练损失:    L = (1/N) Σᵢ ||xⁱ - x̂ⁱ||²
```

**变量说明**：

| 符号 | 含义 |
|------|------|
| xⁱ | 第 i 帧的真实干净帧 |
| xⁱ_{kⁱ} | 加噪后的帧，噪声级别 t_{kⁱ} |
| kⁱ | 从 {1,...,S} 均匀采样的噪声级别索引 |
| V_θ | 速度网络（rectified flow velocity network） |
| sg[·] | stop-gradient 操作，防止网络优化自身的未来输入 |
| hⁱ | 上下文帧集合 {xʲ_{kʲ}}_{j<i} |
| ĥⁱ | 自前推上下文帧集合 {x̂ʲ_{kʲ⁻¹}}_{j<i} |
| t̃ⁱ | 先验的实际噪声级别 = t_{kⁱ} - Δtⁱ |
| Δtⁱ | 0（锚定步骤）或 t_{kⁱ} - t_{kⁱ⁻₁}（自前推） |
| p | 锚定步骤概率（论文中未明确给出具体值） |

**直觉**：传统 Diffusion Forcing 在训练时用噪声真实帧做上下文，推理时却用自生成帧——这是 train-test mismatch 的根源。Step Forcing 让训练时也从"自己的不完美生成"出发去预测下一帧，但只做一步（而非完整串行 rollout），所以：(a) 训练可以并行，(b) 噪声 schedule 与推理对齐，(c) 锚定步骤防止动作-观察动力学被破坏。

## 3. 带数字走一遍：玩具例子 (Worked Example)

假设一个简化的 3 帧 rollout 场景，去噪步数 S=4，schedule 为 t = [0, 0.25, 0.5, 0.75, 1.0]。

**第 1 帧 (i=1)**：
- 采样 k¹ = 3 → t_{k¹} = 0.75
- 噪声帧：x¹_{0.75} = 0.75·ε + 0.25·x¹
- 上下文 h¹ = {x⁰}（初始帧，无噪声）
- 假设命中锚定步骤（p=0.5）：先验 = x¹_{0.75}（直接用噪声真实帧）
- 从 x¹_{0.75} 预测干净帧 x̂¹，损失 ||x¹ - x̂¹||²

**第 2 帧 (i=2)**：
- 采样 k² = 2 → t_{k²} = 0.5
- 噪声帧：x²_{0.5} = 0.5·ε + 0.5·x²
- 上下文 h² = {x⁰, x¹_{0.75}}
- 假设命中自前推（1-p=0.5）：
  - Δt² = t₂ - t₁ = 0.5 - 0.25 = 0.25
  - t̃² = 0.5 - 0.25 = 0.25
  - 一步自前推：x̂²_{1} = x²_{0.5} - 0.25 · sg[V(x²_{0.5}, 0.5, h², a²)]
  - 从 x̂²_{1}（噪声级别 0.25）预测干净帧 x̂²
  - 损失 ||x² - x̂²||²

**关键对比**：如果用 Self Forcing，h² 会是 {x⁰, x̂¹}（完全自生成的帧），动作 a² 作用在 x̂¹ 而非 x¹ 上——这改变了动作-观察动力学。Step Forcing 中，即使 x̂²_{1} 不完美，它仍然从 x²_{0.5}（噪声真实帧）出发做一步前推，所以动作仍然作用在接近真实数据的状态上。

**推理阶段**（假设用同样的 S=4 schedule）：
- 从 x⁰ 开始，策略输出 a¹
- 世界模型用 4 步去噪从纯噪声生成 x¹
- 策略从 x¹ 输出 a²，世界模型生成 x²
- ... 循环 30 秒（约 300 帧，假设 10fps）
- 每一步的去噪步数固定为 4，与训练时对齐

## 4. 工程视角 (Engineering View)

| 指标 | 数值 | 含义 |

| 世界模型 | Wan2.1-T2V-1.3B（13 亿参数） | 从文本到视频的基础模型改造而来 |

| 批次大小 | 8 | 较小，可能受 GPU 显存限制 |
| 学习率 | 1×10⁻⁵ | 标准微调 LR |
| 推理速度 | 15.3 FPS（4 步去噪） | 比 Ctrl-World/PersistWorld 的 5.7 FPS 快 2.7x |
| 评估 8 个策略成本 | 100 H100 GPU 小时 | 包括策略推理 + 世界模型 rollout 的总成本 |
| 滑动窗口 | W=45（开环）/ W=77（闭环） | KV cache 大小，闭环需要更长上下文 |
| 评分器 | GPT-4o | API 调用成本未披露，但每个 rollout 一次调用 |

**工程含义**：

1. **速度-质量权衡**：Step Forcing 在 4 步去噪下达到最佳 LPIPS（0.0525 ID），而基线需要 8+ 步才能接近。这意味着在相同 GPU 预算下，评估吞吐量提升 2-3x。
2. **KV cache 是关键优化**：自回归架构允许帧间 KV cache 复用，这是 Ctrl-World/PersistWorld（双向注意力）无法做到的。W=77 的闭环窗口意味着模型需要缓存 77 帧的 KV。
3. **动作适配是必要桥梁**：DROID 使用末端执行器笛卡尔位置作为动作空间，而不同 VLA 策略可能输出关节速度。浅层 MLP 适配器（2 层）解决了这个接口问题——但适配器的误差会传播到世界模型中。
4. **GPT-4o 评分成本**：每个 rollout 需要一次 GPT-4o 调用。4186 个 rollout × API 成本 = 不可忽视的开销。TODO: 论文未披露评分成本。

|------|------|

### 6.1 隐含假设 (Hidden Assumptions)

1. **世界模型误差可隔离**：论文假设腕部视角的物理不一致性可以检测并隔离，不影响外部视角的任务进度评估。但如果误差传播到外部视角（如物体从腕部飞出到桌面），这个假设失效。
2. **GPT-4o 评分一致性**：假设 GPT-4o 对同一 rollout 的评分是稳定的。但 VLM 评分本身有方差，论文未报告评分的重复性实验。
3. **动作空间可适配**：假设浅层 MLP 可以无损地将不同策略的动作映射到 DROID 的笛卡尔位置空间。对于输出高维动作（如 gripper 力控）的策略，适配可能引入显著误差。
4. **初始观察覆盖充分性**：相关性高部分因为使用了 RoboArena 的真实初始观察。如果初始观察分布与训练数据差异过大，相关性可能下降。

## 7. 与相关工作对比 (Comparison)

| 方法 | 关注点 | 架构 | 训练方式 | 适用场景 |
|------|--------|------|----------|----------|
| Teacher Forcing | 简单基线 | 自回归视频 | 真实帧上下文 | 短程 rollout，训练简单 |
| Diffusion Forcing | 噪声鲁棒性 | 自回归视频 | 噪声真实帧上下文 | 中等长度 rollout |
| Self Forcing | 缩小 train-test gap | 自回归视频 | 自生成帧上下文 | 长程 rollout，但训练慢 |
| Ctrl-World | 通用世界模型 | 双向注意力 | 非自回归 | 开环预测，不支持闭环策略评估 |
| PersistWorld | 持久化世界模型 | 双向注意力 | 非自回归 | 开环预测 |
| **RoboWorld (Step Forcing)** | **策略评估** | **自回归视频 + VLM 评分** | **自前推 + 锚定** | **大规模策略对比评估** |

**面试 Tip**：如果被问到"Step Forcing 和 Self Forcing 的核心区别是什么"，回答：Self Forcing 用完整自生成帧做上下文，训练需要串行 rollout 且破坏动作-观察动力学；Step Forcing 只做一步自前推，训练可并行且通过锚定步骤保留真实数据动力学。
