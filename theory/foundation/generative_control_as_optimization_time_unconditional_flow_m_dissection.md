## 1. 核心架构/方法总览 (Overview / Architecture)

### 1.1 系统对比概览 (System Component Comparison)

| 维度 | 传统 Flow Matching (时间条件) | GeCO (时间无条件) |
|------|------|------|
| 速度场 | v_θ(x_γ, γ, s_t) — 依赖时间 γ | f_θ(x, s_t) — 稳态，不依赖 γ |
| 推理范式 | 从噪声沿 γ∈[0,1] 固定积分 | 从先验初始化，梯度下降迭代优化 |
| 步数控制 | 固定（如 20 步 Rectified Flow） | 自适应：‖f_θ‖ ≤ τ 即提前退出 |
| 计算分配 | 简单/复杂状态同等预算 | 简单状态 NFE≈1，复杂状态 NFE≈20 |
| OOD 检测 | 需要额外网络/集成 | 场范数 ‖f_θ(â, s_t)‖ 天然信号 |
| VLA 集成 | 原生支持 | 即插即用替换 head，冻结时间通道 |
| 训练损失 | 标准 flow matching MSE | 速度重缩放 MSE（见 §2） |

### 1.2 关键机制 (Key Mechanism)

**为什么去掉时间条件还能收敛？**

传统时间无条件流匹配有一个致命问题：去掉 γ 后，速度场在数据点处不会自然为零，导致优化过程无法停在正确位置（非平衡点）。GeCO 的解决方案是**速度重缩放（velocity rescaling）**：

- 训练时仍然采样 γ ~ U(0,1)，构造插值 x_γ = γ·a + (1-γ)·ε
- 但**不将 γ 输入模型**
- 定义恢复方向 g* = (ε - a) · c(γ)，其中 c(γ) 是一个衰减到 0 的标量调度
- 因为 c(1) = 0，当 x_γ 接近真实动作 a 时，目标场自然趋于零
- 模型被迫学习一个**全局一致的稳态场**，其中专家行为成为稳定吸引子

⚡ **Eureka Moment**：不告诉模型 γ 是多少，但用 c(γ) 重缩放目标场的幅度——模型被迫把不同 γ 的样本组织成一个统一的稳态速度场，而真实动作自然成为场中的零速度平衡点。

### 1.3 信息流/架构图 (Flow / Diagram)

```
训练阶段:
  演示动作 a + 噪声 ε
       ↓
  x_γ = γ·a + (1-γ)·ε    (γ ~ U(0,1)，不输入模型)
       ↓
  目标: g* = (ε - a) · c(γ)    ← 速度重缩放
       ↓
  f_θ(x_γ, s_t) ──MSE──→ g*
       ↓
  学习到的稳态速度场 f_θ(·, s_t)

推理阶段:
  观测 s_t (多视角 RGB + 本体感知 + 语言指令)
       ↓
  初始化 a^(0) ~ N(0, I)
       ↓
  ┌─→ a^(k+1) = a^(k) - η·f_θ(a^(k), s_t)
  │     ‖f_θ‖ ≤ τ_opt ? → 退出 → 输出 â
  │     k ≥ K_max ? → 退出 → 输出 â
  └──────┘
       ↓
  OOD Score = ‖f_θ(â, s_t)‖
```

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：

```
L(θ) = E[(s_t,a), ε,γ] ‖f_θ(x_γ, s_t) - (ε - a)·c(γ)‖²
```

**目标**：学习一个稳态速度场 f_θ，使得在专家动作附近场值为零，在噪声区域场指向专家方向。

**变量说明**：

| 符号 | 含义 |
|------|------|
| f_θ(x, s_t) | 稳态速度场，输入动作序列 x 和条件 s_t |
| x_γ | 插值点 = γ·a + (1-γ)·ε |
| a | 专家演示动作序列 (T_a × d_a) |
| ε | 高斯噪声 ~ N(0, I) |
| γ | 插值系数 ~ U(0,1)，**不输入模型** |
| c(γ) | 速度重缩放系数，c(1) = 0 |
| g* | 恢复方向 = (ε - a) · c(γ) |

**直觉**：c(γ) 在 γ→1 时趋于零，意味着当插值点接近专家动作时，目标场趋于零。模型看不到 γ，所以它必须学习一个对所有 γ 都一致的场——这个场在专家动作处自然为零，在远离专家处指向专家方向。推理时，梯度下降沿着这个场迭代，自动停在零速度点。

> 符号与本文保持一致：s_t 为观测+指令的联合条件信号，a 为动作序列（非单步动作）。

## 3. 带数字走一遍：玩具例子 (Worked Example)

假设一个 2D 动作空间，专家动作 a = [1.0, 0.5]，噪声 ε = [-0.5, 0.8]。

**训练时**（假设 γ = 0.7）：
```
x_γ = 0.7·[1.0, 0.5] + 0.3·[-0.5, 0.8] = [0.55, 0.59]
c(0.7) = 0.3 (假设线性调度 c(γ) = 1-γ)
g* = ([-0.5, 0.8] - [1.0, 0.5]) · 0.3 = [-0.45, 0.09]
```
模型在 x_γ = [0.55, 0.59] 处被训练输出 [-0.45, 0.09]。

**推理时**（从噪声初始化 a^(0) = [0.0, 0.0]）：

| 迭代 k | a^(k) | f_θ(a^(k)) | ‖f_θ‖ | 动作 |
|--------|-------|-----------|-------|------|
| 0 | [0.0, 0.0] | [0.35, 0.20] | 0.40 | 继续 |
| 1 | [0.035, 0.020] | [0.28, 0.15] | 0.32 | 继续 |
| 2 | [0.063, 0.035] | [0.20, 0.10] | 0.22 | 继续 |
| 3 | [0.083, 0.045] | [0.12, 0.05] | 0.13 | 继续 |
| 4 | [0.095, 0.050] | [0.05, 0.01] | 0.05 | < τ=0.08 → 退出 |

最终 â ≈ [0.095, 0.050]（简化示例，实际会收敛到接近 [1.0, 0.5]）。关键观察：迭代 4 次后场范数低于阈值，优化自动停止——不需要预设步数。

## 4. 工程视角 (Engineering View)

| 工程维度 | 传统 Flow Matching | GeCO | 含义 |
|----------|------|------|------|
| 推理步数 | 固定 20 步 | 自适应 1-20 步（LIBERO 平均 11.6） | 简单场景节省 ~42% FLOPs |
| 5 步预算下成功率 | N/A（固定步数不可调） | 91.9% vs RF 90.0% | 低延迟场景优势显著 |
| 每步前向传播 | 1 次 | 1 次 | 单步开销相同，但总步数可变 |
| 内存占用 | 相同 | 相同 | 无额外网络/集成 |
| OOD 检测开销 | 额外网络 | 零开销（复用 convergence check） | 安全部署无需额外推理 |
| VLA 集成改动 | N/A | 冻结时间通道 t=0 | 最小架构修改 |

**工程含义**：GeCO 的可变延迟是其最大工程挑战。在硬实时控制系统中（如 100Hz 控制回路），必须按 K_max 预留最坏情况延迟。但在大多数操作场景中，平均 NFE 远低于 K_max，实际延迟通常更低。

### 6.1 隐含假设 (Hidden Assumptions)

1. **稳态场存在唯一吸引子**：论文假设每个条件 s_t 下，速度场有且只有一个低范数平衡点对应正确动作。但在多模态动作空间中（同一状态有多种正确操作），稳态场可能产生虚假吸引子或鞍点。
2. **c(γ) 调度足够**：速度重缩放系数 c(γ) 的设计（论文使用 c(γ) = 1-γ）是否对所有任务类型都最优？未做消融。
3. **τ_opt 和 τ_OOD 可独立调优**：收敛阈值和 OOD 阈值共享同一个场范数，但论文未讨论两者冲突的场景。
4. **仿真到真实的 gap 可忽略**：所有验证在仿真环境完成，稳态场的几何特性在真实传感器噪声和延迟下是否保持，未知。
