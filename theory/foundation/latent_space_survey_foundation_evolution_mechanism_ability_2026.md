## 0. 为什么 VLA 研究者要读这篇综述

这篇不是 VLA 论文——但它是理解 VLA **下一代架构**的钥匙。

当前 VLA 的痛点（动作 token 化精度差、推理速度慢、长程规划弱）全部指向同一个根因：**在离散 token 空间中做物理连续问题的计算**。这篇综述系统性地论证了解法：**把计算搬到连续潜空间**。

---

## 1. 核心论点：离散 token 的四个致命限制

VLM/VLA 表面上在"生成 token"，但内部计算其实发生在**连续的激活向量空间**中。强制把这些连续表征映射到离散 token 是一种信息瓶颈：

| 限制 | 解释 | 对 VLA 的影响 |
|------|------|-------------|
| **语言冗余** | 自然语言有大量语法结构冗余 | CoT 推理步骤中 80% 的 token 是语法填充，不是有效信息 |
| **离散化瓶颈** | 有限词表量化连续信号 | 动作 token 化（RT-2 的 256 bins）丢失精细控制信息 |
| **顺序低效** | 每个 token 需要完整 forward pass | 一个 8 步动作块 = 8 次 VLM 推理（如果用 token 方式） |
| **语义损失** | 连续激活→离散符号的映射压缩/扭曲信息 | VLM 的 3D 理解被"挤过"离散词表时丢失（[VGA 论文](../vla-core/vga_vision_geometry_action_over_language_video_2026.md)的"3D→2D→3D 瓶颈"） |

> **核心洞察**：Token 是人类的语言，不是机器的语言。模型的"母语"是连续向量——强制用 token 做中间表示是在让模型"用外语思考"。

## 2. 潜空间 vs 显式空间 vs 语言空间

| 空间 | 表示 | 计算方式 | 对 VLA 的例子 |
|------|------|---------|-------------|
| **语言空间** | 自然语言文本 | 逐 token 自回归 | RT-2 的 "1 128 90 ..." 动作 token |
| **显式空间** | 结构化符号/代码 | 符号推理 | 运动规划器的关节角序列 |
| **潜空间** | 连续向量 | 并行矩阵运算 | **Flow Matching 的动作流**（π₀ 的方式） |

**VLA 的演进其实就是从"语言空间"到"潜空间"的迁移**：

```
RT-2 (2023):   动作在语言空间（离散 token）→ 慢、粗
Diffusion (2023): 动作在潜空间（连续去噪）→ 精细但慢
Flow Matching (2024): 动作在潜空间（ODE 直线路径）→ 精细且快
π₀.7 (2026):   推理在潜空间 + 动作在潜空间 → ？
```

综述提出了理解潜空间的四层机制框架：


### 架构（Architecture）

| 类型 | 做法 | VLA 中的例子 |
|------|------|-------------|
| **Backbone** | 在模型内部嵌入循环/环路结构 | Dreamer 世界模型的循环潜空间预测 |
| **Component** | 加模块但保留原始架构 | VAE 动作编码器（ACT 的 CVAE）、LoRA 适配器 |
| **Auxiliary** | 外部模型提供潜空间监督 | VGGT 提供 3D 几何潜表征（VGA） |

### 计算（Computation）

| 方式 | 含义 | VLA 中的例子 |
|------|------|-------------|
| **压缩** | 把推理步骤压缩到稠密向量中 | "潜思维链"——不输出文字，在隐层中完成推理 |
| **扩展** | 在更高维空间中增加表达力 | Diffusion 的 T 步去噪（时间维度扩展） |
| **自适应** | 根据难度动态分配计算量 | 简单任务浅推理，复杂任务深推理 |
| **交错** | 潜空间和显式空间交替 | π₀.₅ 的混合架构（FAST 预训练 + Flow 推理） |

### 优化（Optimization）

| 阶段 | 潜空间优化方法 | VLA 中的例子 |
|------|-------------|-------------|
| 预训练 | 循环架构预训练（Ouro） | VGGT 在 3D 数据上的预训练 |
| 后训练 | 连续空间 RL（HRPO） | **π\*0.6 Recap**——在潜空间做 offline RL |
| 推理时 | 测试时扩展（多次迭代） | WVA 的 K 次潜空间迭代规划 |

## 4. 能力维度：七个方向

综述分析了潜空间赋能的七种能力。对 VLA 最直接相关的是后三个：

### 记忆（Memory）

潜空间可以存储三种记忆：
- **工作记忆**：当前任务的上下文（KV Cache 就是一种潜空间记忆）
- **情景记忆**：过去的经验（[Claude Code Memory → VLA](../frontier/claude_code_memory_architecture_applied_to_vla_2026.md)）
- **程序记忆**：技能的编码（ACT 的 CVAE 隐变量 z 就是一种"技能记忆"）

### 协作（Collaboration）

多智能体可以通过**共享潜空间通信**而不是自然语言。比文字通信：
- 更高效（一个向量 vs 一个句子）
- 更精确（连续 vs 离散）
- 可微分（可以端到端训练通信协议）

### 具身（Embodiment）—— 对 VLA 最关键

综述覆盖了大量潜动作（Latent Action）工作：

| 方法 | 潜动作类型 | 核心思想 |
|------|-----------|---------|
| **LAPA / LAWM** | 从无标注视频学习潜动作 | 不需要动作标签，从视频中自监督学习"什么变了" |
| **UniVLA / OccVLA** | 跨形态潜动作 | 一个潜空间统一不同机器人的动作 |
| **SwiftVLA** | 高效潜动作推理 | 绕过 token 生成，直接在潜空间输出动作 |
| **SSM-VLA** | 世界模型潜状态 | 用状态空间模型在潜空间预测未来 |

> **关键洞察**：潜动作不是"把离散动作变连续"那么简单。它是一种**跨形态的统一表示**——不同机器人（机械臂、人形、四足）的动作可以映射到同一个潜空间中，就像不同语言的句子可以映射到同一个 CLIP 嵌入空间。

## 5. 与 VLA-Handbook 研究主线的深层连接

### 潜空间解释了 Flow Matching 为什么赢

[研究主线](../vla-core/vla_research_mainline.md)赌注 1 说"动作的语言还没找到"。这篇综述给出了一个统一解释：

```
Token (RT-2):    动作在语言空间 → 离散化瓶颈 → 精度差
Diffusion (RDT): 动作在潜空间，但路径弯曲 → 多步去噪 → 慢
Flow Matching (π₀): 动作在潜空间，路径是直线 → 1-5 步 → 快

Flow Matching 赢是因为它在潜空间中找到了最高效的路径
```

### 潜思维链解释了 π₀.₇ 的"可操控"

π₀.₇ 的组合泛化可能依赖**潜思维链**——模型不在 token 层面做推理（"我应该先拿盘子"），而是在潜空间中**直接规划动作轨迹的连续向量序列**。语言指令只是触发潜空间推理的"种子"，不是推理的"媒介"。

这和 [PI 访谈](../vla-core/physical_intelligence_sergey_levine_foundation_model_vision_2026.md)中 Levine 说的"中间层推理可能不是语言"吻合——中间层可能就是潜空间。

### 潜动作解释了跨形态迁移

为什么 π₀ 能在多种机器人上工作？因为不同机器人的动作被映射到了同一个**潜动作空间**。在这个空间中，"抓杯子"这个动作对机械臂和对人形手是同一个向量——只是解码到关节命令时才分化。

### VGA 的"3D→2D→3D 瓶颈"是离散化瓶颈的特例

[VGA](../perception/vga_vision_geometry_action_over_language_video_2026.md) 发现 VLM 的 2D 表征是瓶颈。用这篇综述的框架看：VLM 的 2D token 空间就是一种"离散化瓶颈"——把 3D 几何挤过 2D 词表时丢失了空间信息。VGA 的解法（3D backbone）= 直接在 3D 潜空间中操作。

## 6. 最关键的开放问题

### 可解释性困境

> "潜空间中的计算对人类来说难以进行细粒度的直接评估、控制和解释。"

这是潜空间的核心矛盾：**越高效 = 越不可解释**。Token CoT 虽然慢但人类能读懂。潜思维链快 10x 但人类看不到模型在"想什么"。

对 VLA 的含义：如果机器人的规划全在潜空间中完成，出了事故怎么 debug？怎么审计？这是安全部署的核心障碍。

### 标准化缺失

500+ 篇论文，每篇的"潜空间"定义不同、评估标准不同、优化目标不同。没有统一的 benchmark 来比较"谁的潜空间更好"。

### 探索坍缩

在潜空间做 RL 时，优化过程对设计选择极其敏感。稍有不慎就会坍缩到一个局部最优（所有输出都一样）。π\*0.6 的 Recap 能成功是因为它用了保守的 offline RL，不做激进的探索。

## 7. 待追问的开放问题

❓ **综述的覆盖面 vs 深度**：37 位作者、500+ 引用——这更像是"地图"而不是"分析"。每个方向只有几段描述，缺少深入的方法论对比和实验验证。

❓ **具身章节的深度有限**：VLA 只占了七个能力维度之一。LAPA/UniVLA/SwiftVLA 等方法被列举但没有深入分析它们的优劣和适用场景。

❓ **"潜空间是原生基底"的主张是否过强**：也许对某些任务（精确力控），显式的物理模型仍然不可替代？不是所有问题都适合在潜空间中解决。

❓ **训练成本**：在潜空间中做计算的训练成本（需要学到好的表征）vs 在显式空间中做计算的推理成本（需要多步 token 生成），哪个更贵？综述没有讨论计算经济学。

## 8. Opus 的反思

### 🔮 "潜空间优先"可能是 VLA 的下一个架构转折

综述提出的四个限制（冗余、离散化、顺序、语义损失）**每一个都是当前 VLA 的真实痛点**：

- RT-2 的动作 token 化 = 离散化瓶颈
- CoT 推理的慢速 = 顺序低效
- VLM 的 2D 表征 = 语义损失
- 语言指令的冗余 = 语言冗余

如果把 VLA 的每个组件都迁移到潜空间：
- **感知**：RGB → 潜视觉特征（已有：DINOv2、VGGT）
- **推理**：CoT token → **潜思维链**（新方向）
- **动作**：离散 token → **潜动作**（已有：Flow Matching）
- **通信**：语言指令 → **潜意图向量**（未来方向）

最终的 VLA 可能完全不生成 token——从输入到输出全在潜空间中完成。Token 只在人机接口处出现（人类说话→潜向量，潜向量→人类可读的解释）。

### 🔮 潜动作可能是跨形态问题的终极解法

跨形态迁移的核心困难：不同机器人的动作空间维度不同（6 轴臂 vs 22 自由度手 vs 12 关节四足）。

**如果存在一个"通用潜动作空间"**——所有机器人的动作都是这个空间中的向量——那么跨形态迁移就变成了**不同的解码器**问题（潜动作→机械臂关节 vs 潜动作→人形关节），而不是整个 policy 的重新训练。

这和 NLP 中的多语言嵌入一模一样：所有语言的句子映射到同一个嵌入空间，翻译 = 换解码器。

### 🔮 "潜空间记忆"可能解决 VLA 的无状态问题

当前 VLA 每次推理都是无状态的。但如果在潜空间中维护一个**持久化的记忆向量**（类似 LSTM 的隐状态，但更长期），机器人就有了"经验记忆"——不是存文字日志，而是存潜向量序列。

这比 [OmniMap 记忆方案](../perception/pointcloud_slam.md) 更轻量——不需要维护 3D 地图，只需要一个随时间更新的向量。
