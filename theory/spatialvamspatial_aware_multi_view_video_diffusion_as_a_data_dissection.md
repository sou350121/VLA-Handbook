## 1. 核心架构/方法总览 (Overview / Architecture)

### 1.1 系统对比概览 (System Component Comparison)

| 组件 | 输入 | 输出 | 训练方式 | 参数量 |
|------|------|------|----------|--------|
| **多视图投影模块** | 点云(裁剪至1m³) + 末端位姿 | 3视图RGB图像 + 3视图热图 | 确定性脚本(无训练) | 0 |
| **VAE 编码器** | 多视图RGB+热图拼接 | 共享隐空间表征 | 预训练冻结 | 冻结 |
| **多视图视频扩散 Transformer** | 条件隐变量 + 噪声目标 | 未来多视图RGB+热图序列的噪声预测 | LoRA微调(Wan2.2) | 5B (LoRA适配) |
| **旋转+夹爪预测器** | 去噪后的视频隐变量 | 欧拉角变化(72分类) + 夹爪开闭(2分类) | 交叉熵训练 | 170M |
| **热图反投影** | 3视图热图峰值位置 | 3D末端位置轨迹 | 确定性几何(无训练) | 0 |

**训练 vs 推理差异**：
- 训练时：用 ground-truth 视频隐变量训练旋转/夹爪预测器，注入小噪声增强鲁棒性
- 推理时：用扩散生成的预测隐变量，两分支并行解码（热图→位置，隐变量→旋转+夹爪）

### 1.2 关键机制 (Key Mechanism)

**为什么这样设计——三个核心决策**：

1. **多视图投影代替直接点云编码**：点云直接输入会引入大量冗余信息（论文引用 DP3 的教训），正交投影到固定虚拟视角将 3D 信息压缩为视频模型原生支持的 2D 格式，桥接了预训练表征与动作空间的鸿沟。

2. **热图代替坐标回归**：将末端执行器位置编码为高斯热图（而非直接回归 3D 坐标），使得动作表征与视频像素空间对齐——视频模型"画"热图比"算"坐标更符合其预训练分布。

3. **视频扩散联合预测**：同时预测未来 RGB 帧和未来热图序列，而非分两步。这确保了视觉演化与动作轨迹在隐空间中耦合，避免了"预测了正确的视频但动作不匹配"的问题。

⚡ **Eureka Moment**：把 3D 动作目标编码为多视图热图（而非 3D 坐标），使其与 RGB 视频共享相同的 2D 像素空间格式——这样预训练视频模型可以同时"看见"环境演化和动作目标，无需额外的 3D 表征学习。

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：
```
L_total = λ·L_vid(ε, ε̂_vid) + (1-λ)·L_heat(ε, ε̂_heat) + Σ_{angle∈{rol,pit,yaw}} L_ce(angle) + L_ce(gripper)
```

**目标**：联合训练两个模块——视频扩散 Transformer 预测未来 RGB 和热图序列，轻量预测器从隐变量解码旋转和夹爪状态。

**公式拆解**：

```
L_diff = λ · L_vid + (1-λ) · L_heat
```

| 符号 | 含义 |
|------|------|
| L_vid | 视频序列的扩散 MSE 损失（预测添加的噪声） |
| L_heat | 热图序列的扩散 MSE 损失 |
| λ | 视频损失权重（论文 §4.4 做消融分析） |

```
L_pred = L_rol + L_pit + L_yaw + L_gri
```

| 符号 | 含义 |
|------|------|
| L_rol, L_pit, L_yaw | 欧拉角变化量的交叉熵损失（72 bin 离散化） |
| L_gri | 夹爪开闭的交叉熵损失（2 分类） |

**热图构造**（确定性，无学习参数）：
```
H_i^t(x) = exp(-||x - x̂_i^t||² / (2σ²))   if value ≥ τ, else 0
```

| 符号 | 含义 |
|------|------|
| x = (u, v) | 像素坐标 |
| x̂_i^t | 末端执行器在视图 i、时间步 t 的投影像素位置 |
| σ | 热图空间扩展参数 |
| τ | 概率截断阈值（低于 τ 置零，稀疏化热图） |

**直觉**：扩散损失让模型学会"画"出未来的环境样子（RGB）和动作目标位置（热图）；分类损失让模型学会"转"到手的方向和开闭夹爪。两者互补——位置靠几何反投影精确恢复，姿态靠隐变量特征回归。

> 符号与本文/相关文档保持一致。扩散部分遵循标准去噪扩散概率模型(DDPM)公式；热图部分为本文 §3.1 定义。

## 3. 带数字走一遍：玩具例子 (Worked Example)

假设一个简化场景：桌面 pick-and-place，工作空间 1m³，3 个虚拟视角（前/左/上）。

**步骤 1：投影编码**
- 输入点云：~10K 点，裁剪至 1m³ 立方体
- 末端当前位置：(x=0.3, y=0.2, z=0.15) m
- 正交投影到 3 视图：前视图像素 (u=256, v=384)，左视图 (u=192, v=384)，上视图 (u=256, v=256)
- 生成 3 张热图：σ=4px, τ=0.1，每张热图约 200 个非零像素（稀疏）
- 3 张 RGB + 3 张热图（颜色化后）→ VAE 编码 → 6 个隐变量张量沿视图维度拼接

**步骤 2：扩散去噪**
- 目标：预测未来 T=16 帧的 RGB + 热图
- 加噪：从 20 步噪声调度中随机采样 t=7，添加 ε ~ N(0, I)
- Transformer 预测 ε̂，MSE 损失计算
- 推理时：从纯噪声开始，20 步去噪 → 得到干净隐变量 → VAE 解码

**步骤 3：动作解码（假设数值）**
- 热图反投影：3 视图热图峰值分别为 (258,386), (194,386), (258,258)
  - 三角测量恢复 3D 位置：(0.31, 0.21, 0.16) m（与目标偏差 ~2cm）
- 旋转预测器：从隐变量提取特征 → 4 层 Transformer → MLP head
  - 输出：roll 变化 = +5°（bin 12/72），pitch = -3°（bin 33/72），yaw = +8°（bin 16/72）
  - 夹爪：open（置信度 0.92）
- 最终动作块：16 步 × (3D位置 + 3D旋转 + 夹爪状态) = 16 × 7 维动作

**闭环验证**：如果执行此动作块，末端应从 (0.3, 0.2, 0.15) 移动到约 (0.35, 0.25, 0.20)，同时旋转并张开夹爪——符合 pick 动作的预期。

### 6.1 隐含假设（Hidden Assumptions）

1. **虚拟相机投影足够覆盖目标区域**：论文承认"视角不必正交，只要目标区域观察清晰即可"——但自适应视角选择被留为未来工作。如果目标物体在固定视角下被遮挡，性能会如何退化？论文仅在单相机降级实验中部分回答。

2. **深度估计质量稳定**：真实实验依赖 ZED2i 的深度图转点云。深度噪声（尤其反光/透明物体）会直接影响投影质量，但论文未做深度噪声鲁棒性分析。

3. **热图高斯参数 σ 和 τ 通用**：这两个超参数对所有任务使用相同值——但不同任务可能需要不同热图粒度（精细操作需要窄高斯，大范围移动需要宽高斯）。

4. **Wan2.2 预训练知识可迁移**：Wan2.2 在单视图自然视频上预训练，直接用于多视图机器人视频。论文通过 LoRA 适配，但预训练分布与机器人域之间的 gap 未被量化分析。
