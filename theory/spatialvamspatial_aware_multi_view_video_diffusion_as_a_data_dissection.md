### 1.2 关键机制 (Key Mechanism)

SpatialVAM 的设计围绕三个关键洞察：

1. **3D 信息不需要 3D 网络**：传统 3D 策略（DP3、3D Diffuser Actor）直接编码点云，但 SpatialVAM 用正交投影将点云渲染为 3 个虚拟视图的 RGB 图像，把 3D 信息编码成视频模型"天生会看"的 2D 格式。
2. **动作即热力图**：末端执行器位姿不编码为连续向量，而是生成 3 个视图的高斯热力图（空间截断，峰值在投影像素位置）。热力图经过颜色化后可以直接通过 VAE 编码器，与 RGB 图像共享同一套视觉表征。
3. **表示对齐降低数据需求**：视频基础模型在单视图 RGB 视频上预训练，SpatialVAM 在微调阶段仍然使用 RGB 格式（热力图颜色化后也是 RGB），消除了"预训练看 2D 视频 → 微调预测 3D 动作"的表示鸿沟，这是数据高效的核心原因。

⚡ **Eureka Moment**：把 3D 动作编码成视频模型已经会处理的 2D 热力图格式，而不是让视频模型去学一种全新的 3D 表示——表示格式的对齐比模型架构的复杂度更重要。

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：
```
L_total = λ·L_vid(noise_pred) + (1-λ)·L_heat(noise_pred) + L_rol + L_pit + L_yaw + L_gri
        └─────────── 视频扩散联合预测 ───────────┘ └────── 旋转夹爪分类 ──────┘
```

**目标**：用一个统一模型同时学会预测未来 RGB 视频（环境动态）和未来热力图（3D 动作），以及旋转/夹爪状态。

**核心方程分解**：

1. **扩散损失**（视频 + 热力图联合）：
```
L_diff = λ · L_vid + (1-λ) · L_heat
```
- L_vid: 未来 RGB 帧的噪声预测 MSE 损失
- L_heat: 未来热力图序列的噪声预测 MSE 损失
- λ: 视频损失权重（论文中通过消融实验分析其鲁棒性）

2. **热力图生成**（高斯 + 空间截断）：
```
H_i^t(x) = p_i^t(x)  if p_i^t(x) ≥ τ, else 0
p_i^t(x) = exp(-||x - x̂_i^t||² / (2σ²))
```
- x̂_i^t: 末端执行器在视图 i 时间步 t 的投影像素位置
- σ: 热力图空间扩散范围
- τ: 概率阈值（截断低值区域）

3. **旋转&夹爪预测损失**：
```
L_pred = L_rol + L_pit + L_yaw + L_gri
```
- L_rol, L_pit, L_yaw: 三个 Euler 角分类损失（各 72 bins）
- L_gri: 夹爪开合二分类损失

> 符号与本文保持一致：i 索引视图，t 索引时间步，x=(u,v) 为像素坐标，λ 为视频/热力图损失权重比。

**直觉**：扩散部分负责"想象未来"（视频和热力图同时预测），分类部分负责"精确控制"（旋转和夹爪离散化）。两者共享同一组去噪 latents，因为热力图已经编码了 3D 位置信息，旋转/夹爪可以从同一表征中提取。

## 3. 带数字走一遍：玩具例子 (Worked Example)

假设一个简化的 2D 桌面抓取场景：

**场景设定**：
-  workspace: 1m × 1m × 1m 立方体
- 3 个虚拟视图：前视、左视、俯视（正交投影）
- 末端执行器当前位置: (x=0.3, y=0.5, z=0.2) m
- 目标位置: (x=0.7, y=0.5, z=0.4) m
- 预测 16 个时间步的动作序列

**Step 1 — 热力图生成**：
- 前视图投影: 末端执行器位于像素 (u=256, v=384)
- 左视图投影: 末端执行器位于像素 (u=128, v=384)
- 俯视投影: 末端执行器位于像素 (u=384, v=256)
- 每个视图生成 σ=5 像素的高斯热力图，阈值 τ=0.1 截断

**Step 2 — 扩散去噪**：
- 输入: 3 视图 RGB + 3 视图热力图 → VAE 编码 → 条件 latents
- 加噪: 对未来 16 帧 latents 加高斯噪声 (t=1000)
- 去噪: 5B Transformer 预测噪声 ε_θ，经 50 步 DDIM 采样恢复干净 latents
- 输出: 预测的 16 帧热力图序列，峰值从 (256,384) 逐步移动到 (384,256)

**Step 3 — 回投影**：
- 第 8 帧热力图峰值: 前视(u=320,v=384), 左视(u=256,v=384), 俯视(u=320,v=320)
- 三视图回投影 → 3D 位置: (x≈0.5, y≈0.5, z≈0.3) m
- 16 帧连续回投影 → 平滑 3D 轨迹

**Step 4 — 旋转&夹爪**：
- 从去噪 latents 提取全局+局部特征
- 预测旋转变化: roll=+15°, pitch=+5°, yaw=-10°（相对初始帧）
- 预测夹爪: 前 8 帧 open(1)，后 8 帧 close(0)

**计算闭环验证**：回投影的 3D 位置 (0.7, 0.5, 0.4) 与目标位置一致 → 动作序列正确。

| 数据需求 | 5-10 条演示/任务 | 极低数据门槛，无需大规模预训练 |
| 相机标定 | 必需（回投影依赖） | 标定误差直接影响 3D 位置精度 |
| 内存占用 | 点云裁剪 1m³ | 控制输入规模，避免冗余点云干扰 |

**工程含义**：
- 旋转和夹爪的离散化（72 bins / 2 bins）是精度-效率 trade-off：连续回归更精确但训练不稳定，离散分类更鲁棒但受 bin 粒度限制。
- 1 步去噪仍可用（论文 §4.4 提到）意味着部署时可以大幅降低延迟，适合实时控制场景。
- 虚拟视图 vs 物理相机：虚拟视图可以灵活选择观察方向，但需要精确的 3D→2D 投影映射。

### 6.1 隐含假设 (Hidden Assumptions)

1. **相机标定始终精确**：回投影依赖已知的相机内参和外参。实际部署中相机震动、温度漂移导致的标定偏移会直接转化为 3D 位置误差，论文未讨论此鲁棒性。
2. **虚拟视图方向固定即可**：论文承认"自适应选择投影视图是有前景的方向"但未实现。固定视图可能在某些任务配置下不是最优的。
3. **点云裁剪 1m³ 足够**：对于桌面操作合理，但对更大工作空间（如人形机器人双臂操作）需要重新设计裁剪范围。
4. **SE(3) 数据增强覆盖分布**：训练时对点云和位姿做 SE(3) 增强，但增强范围是否覆盖真实部署的位姿分布未量化验证。
5. **热力图 σ 和 τ 是固定超参**：不同任务可能需要不同的热力图扩散范围和阈值，论文未讨论自适应策略。
