### 1.2 关键机制 (Key Mechanism)

**为什么这样设计？**

1. **单演示数据生成**：实机演示成本高（需力反馈遥操作设备），仿真中用 Laplacian Editing + 力觉虚拟目标可以从 1 条演示生成 303 条 (Block Flipping) 或 210 条 (Bi-manual) 多样化轨迹

2. **点云 + 力双输入**：点云提供 3D 几何理解（比 RGB 对光照鲁棒），力觉提供接触状态感知——两者缺一不可（消融实验证明）

3. **Flow Matching 而非 Diffusion**：Flow Matching 推理频率更高（适合接触丰富任务的高频控制），且训练更稳定

4. **被动阻抗控制器**：传统位置控制会硬跟踪不可达轨迹导致力突变；速度场 + 被动阻尼天然能量耗散，更安全

⚡ **Eureka Moment**：力觉虚拟目标 (Force-Informed Virtual Target) —— 在接触段给期望位姿加上 `kf·F` 的偏移，相当于"往物体内部走"，策略学会这个行为后自然维持接触力。

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：

```
u^ = (d·n^ + t^) / ||d·n^ + t^||   ← 顺应方向由阻抗 d 混合参考方向 t^ 和虚拟目标方向 n^
```

**目标**：在跟踪参考轨迹和顺应接触力之间找到平衡，用单一阻抗参数 d 控制混合比例。

**公式推导**：

```
1. 参考运动方向：t^ = Xref^{t+1} - Xref^t
2. 顺应方向：n^ = Xvt^t - x_curr  (虚拟目标 - 当前位置)
3. 混合方向：u^ = (d·n^ + t^) / ||d·n^ + t^||
4. 期望速度：f(x) = k·u^  (k=0.1 固定速度幅值)
5. 控制力：Fd = D(x)·f(x) = v1·f(x)  (v1 对齐期望方向)
```

**变量说明**：

| 符号 | 含义 | 来源 |
|------|------|------|
| Xref^t | t 时刻参考位姿 | Flow Matching 策略输出 |
| Xvt^t | t 时刻虚拟目标位姿 | Flow Matching 策略输出 |
| d | 阻抗增益 | Flow Matching 策略输出，范围 [d↓, d↑] |
| x_curr | 当前末端位姿 | 机器人状态反馈 |
| t^ | 参考运动方向 | 由相邻参考位姿计算 |
| n^ | 顺应方向 | 指向虚拟目标 |
| u^ | 混合后期望方向 | 公式 (13) |
| k | 期望速度幅值 | 固定 0.1，可在线调整 |

**阻抗调度公式**（训练时 d 由力的大小决定）：

```
        d↑,                          |F| < F↓
d =     d↑ - (d↑-d↓)·(|F|-F↓)/(F↑-F↓),  F↓ ≤ |F| ≤ F↑
        d↓,                          |F| > F↑
```

> 符号与本文/相关文档保持一致：d↑ 和 d↓ 是硬件特定的最大/最小阻尼值，F↓ 和 F↑ 是力阈值。

**直觉**：力小时用高阻抗 (d↑) 保证跟踪精度；力大时降低阻抗 (d↓) 让机器人变"软"，避免硬碰撞。

## 3. 带数字走一遍：玩具例子 (Worked Example)

假设 Block Flipping 任务中某时刻：

```
当前状态:
  x_curr = [0.5, 0.3, 0.2] m  (末端位置)
  Xref^t = [0.51, 0.30, 0.21] m
  Xvt^t = [0.50, 0.32, 0.25] m  (虚拟目标在物体内部)

策略输出:
  d = 0.6  (中等阻抗，因为检测到接触力)

计算:
  t^ = Xref^{t+1} - Xref^t = [0.01, 0.00, 0.01]  (向前上方移动)
  n^ = Xvt^t - x_curr = [-0.00, 0.02, 0.03]  (向右上方顺应)
  
  d·n^ + t^ = 0.6·[-0.00, 0.02, 0.03] + [0.01, 0.00, 0.01]
            = [0.01, 0.012, 0.028]
  
  u^ = [0.01, 0.012, 0.028] / ||[0.01, 0.012, 0.028]||
     ≈ [0.33, 0.40, 0.93]  (归一化)
  
  期望速度：ẋd = k·u^ = 0.1·[0.33, 0.40, 0.93] = [0.033, 0.040, 0.093] m/s
```

**物理含义**：如果没有虚拟目标 (d=0)，机器人会硬跟踪参考轨迹 [0.01, 0.00, 0.01]，可能撞上物体。有了虚拟目标和 d=0.6，运动方向被拉向 [0.33, 0.40, 0.93]，既向前又顺应接触面。

### 6.1 隐含假设 (Hidden Assumptions)

1. **仿真→实机点云差距可被噪声注入覆盖**：论文用"垂直飞点 + 遮挡阴影"模拟实机噪声，但假设这足够覆盖真实差距

2. **关节力矩推算的力足够准确**：Franka 无 F/T 传感器，用关节力矩推算末端力，假设推算误差在可接受范围

3. **单演示覆盖任务本质流形**：假设 1 条演示的轨迹变形能覆盖足够多的初始条件组合（论文用域随机化验证，但物体形状固定）

4. **被动阻抗的 passivity 在实际中成立**：论文承认"this formulation might break passivity"，但假设 state-dependent vector field 足够安全
