## 1. 核心架构/方法总览 (Overview / Architecture)

| 模块 | 输入 | 输出 | 频率 | 训练/推理 |

| EoT (变换期望) | 随机变换 g ~ T (3D/2D 增强) | 增强观测 Ôt | 每优化步 | 提升 sim-to-real |

### 1.2 关键机制 (Key Mechanism)

**为什么这样设计？**

1. **FBD 解决可微性**：MuJoCo 等具身仿真器对物体外观不可微 → 用 Nvdiffrast 渲染前景物体，MuJoCo 渲染背景，通过参数对齐 (MVP 变换 + 光照) 保证一致性，梯度可从 VLA 损失流回纹理

2. **TAAO 解决时序效率**：长轨迹数百帧，不是每帧都同等重要 → 用视觉 encoder 的 latent 速度/加速度识别"行为关键帧"（如抓取瞬间），集中优化压力

3. **顶点参数化解决过拟合**：直接优化像素级纹理 (Ht×Wt×3) 易过拟合 → 改为优化顶点颜色 (Nv≪Ht×Wt)，通过重心插值恢复纹理，约束在平滑低秩流形上

⚡ **Eureka Moment**：**把对抗攻击从"输入图像层面"下沉到"物体表面层面"** —— 攻击不再依赖视角对齐，而是成为物体固有属性，天然鲁棒到视角/姿态变化。

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：

```
T_adv = argmax_T  E_{t~轨迹, m~视角} [ L_π( π(O_{t,m}(M_adv), l), a*_{t,m} ) ]
```

**目标**：找到对抗纹理 T_adv，使 VLA 模型在整条轨迹和多视角下的动作偏差最大化。

**公式拆解**：

| 符号 | 含义 | 来源 |
|------|------|------|
| T_adv | 对抗纹理图 $\in \mathbb{R}^{H_t \times W_t \times 3}$ | 优化变量 |
| M_adv = (V, F, T_adv) | 对抗物体网格 (顶点/面/纹理) | §3.1 |
| $O_{t,m}(M_{\text{adv}})$ | timestep t、视角 m 下的观测 | §3.1 |
| $a^*_{t,m}$ | 干净网格下的参考动作 | §3.1 |
| $L_\pi$ | 动作损失 (L2 距离) | §3.3 |
| w_t | TAAO 帧权重 | Eq.9 |

**直觉**：不是攻击单帧图像，而是攻击"物体本身"—— 无论机器人从哪个角度看、在轨迹的哪一步，纹理都持续产生误导。

### 2.1 前景 - 背景合成 (FBD)

```
O_t(M_adv) = m_t ⊙ x_t^fg(T_adv) + (1 - m_t) ⊙ x_t^bg
```

- m_t：MuJoCo 预计算的物体 silhouette mask
- $\odot$：逐元素乘法
- 等价于在 MuJoCo 中给物体贴 T_adv 纹理，但保持可微路径

### 2.2 轨迹感知帧权重 (TAAO)

```
f_t = E(O_t)                     # 视觉 encoder 提取 latent
v_t = ||f_{t+1} - f_{t-1}||₂/2   # latent 速度
α_t = |v_t - v_{t-1}|            # latent 加速度
s_t = max(v̂_t, α̂_t)              # 关键性得分 (归一化后)
w_t = exp(s_t/τ) / Σ_{t'} exp(s_{t'}/τ)  # temperature-scaled softmax
```

> 符号与本文/相关文档保持一致：v̂ 表示归一化后的速度

### 2.3 顶点纹理参数化

```
T_adv = φ(c),  c ∈ R^{Nv×3}
```

- $\varphi$：重心插值函数
- Nv ≪ Ht×Wt：顶点数远小于像素数，约束在平滑流形上

## 3. 带数字走一遍：玩具例子 (Worked Example)

假设一个简单抓取任务，轨迹 T=200 帧，优化 1 个对抗纹理：

**Step 1: 提取 latent 动力学**
```
帧 0-50 (初始接近):  v_t ≈ 0.1, α_t ≈ 0.02  → s_t ≈ 0.1  → w_t ≈ 0.004
帧 51-80 (抓取形成): v_t ≈ 0.8, α_t ≈ 0.6   → s_t ≈ 0.9  → w_t ≈ 0.025  ← 关键帧
帧 81-150 (转移):    v_t ≈ 0.4, α_t ≈ 0.1   → s_t ≈ 0.4  → w_t ≈ 0.008
帧 151-200 (放下):   v_t ≈ 0.15, α_t ≈ 0.03 → s_t ≈ 0.15 → w_t ≈ 0.005
```

**Step 2: 计算加权损失**
```
L_total = Σ_t w_t · ||π(O_t(M_adv), l) - a*_t||₂
        = 0.004·L_0-50 + 0.025·L_51-80 + 0.008·L_81-150 + 0.005·L_151-200
```

抓取阶段权重是初始阶段的 6 倍+ —— 优化压力集中在行为最敏感的 Moment。

**Step 3: 迭代优化**
```
初始化: c = 随机噪声 (Nv×3)
for step in 1..1000:
    渲染 O_t (多视角 M=8)
    计算 L_total (加权)
    反向传播: ∂L/∂c
    更新: c ← c + η·∂L/∂c
    投影: c ← clip(c, 0, 1)  # 保持颜色合法
```

最终得到 $T_{\text{adv}} = \varphi(c^*)$，3D 打印后贴在物体上。

## 4. 工程视角 (Engineering View)

| 工程维度 | Tex3D 设计 | 含义 |
|----------|-----------|------|
| **吞吐** | 单步优化 ~7.2s (A100) | 全轨迹优化需数小时，但只需做一次 |
| **延迟** | 推理时无额外开销 | 攻击纹理是"被动"的，不影响 VLA 推理速度 |
| **内存** | 顶点参数化降维 100-1000x | 避免像素级优化的显存爆炸 |
| **抖动** | TAAO 平滑权重分布 | 防止单帧过拟合导致轨迹不稳定 |
| **量化误差** | EoT 增强覆盖真实变化 | 3D 打印色差/光照变化已建模 |
| **部署约束** | 需 3D 打印纹理物体 | 物理攻击需制造成本，但可批量复制 |

**关键 trade-off**：
- **L0 (自然性约束)**: $\varepsilon = 64/255$ + MSE loss → 失败率略降但更隐蔽
- **L1-L3 (无约束)**: $\varepsilon = 16/255 \to 64/255$ → 失败率递增，转移性更好

### 6.3 隐含假设 (Hidden Assumptions)

1. **仿真 - 真实 gap 可被 EoT 覆盖**：假设随机变换能充分建模真实世界变化，但极端光照/材质反射可能失效

2. **物体几何固定**：假设攻击只改纹理不改形状，但某些场景下几何变化更自然

3. **VLA 视觉 encoder 稳定**：TAAO 依赖预训练 encoder 的 latent 动力学，若 encoder 变化则关键帧识别可能偏移

4. **单相机设置**：实验用单目 RGB，多相机/深度传感器场景未验证
