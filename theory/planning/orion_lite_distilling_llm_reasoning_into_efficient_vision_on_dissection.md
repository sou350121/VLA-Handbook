### 1.2 关键机制 (Key Mechanism)

**为什么这样设计？**

1. **冻结视觉编码器 + QT-Former**: 教师的视觉编码器已在 VLA 联合训练中学习到驾驶特定的语义和空间先验，直接复用避免重新学习
2. **潜特征蒸馏而非文本蒸馏**: LLM 的最终规划令牌是连续特征而非离散文本，用 L1 回归直接匹配潜空间更高效
3. **联合监督 (蒸馏 + 真值)**: 纯蒸馏损失只能恢复 98% 教师性能，加入轨迹真值监督后突破教师上限

⚡ **Eureka Moment**：LLM 在 VLA 推理中本质上是"过参数化的特征提取器"——它的潜层规划特征可以被轻量解码器模仿，且联合真值监督后学生能超越教师性能天花板。

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：
```
L_total = L_GT + L_mimic = (L_col + λ_bd·L_bd + λ_reg·L_reg + λ_vae·L_vae) + (1/B·Σ||T_student - T_teacher||₁)
```

**目标**: 最小化学生输出与教师潜特征的 L1 距离，同时满足轨迹真值约束。

**变量说明**:

| 符号 | 含义 | 维度 |
|------|------|------|
| T_student | 学生解码器输出的规划令牌 | 1 × Cp |
| T_teacher (Tp) | 教师 LLM 输出的规划令牌 | 1 × Cp |
| L_mimic | 特征模仿损失 (L1 回归) | 标量 |
| L_GT | 真值监督损失 (碰撞 + 边界 + 回归 + VAE) | 标量 |
| λ_bd, λ_reg, λ_vae | 损失权重 | 均为 3 |
| B | 批次大小 | - |
| Cp | 规划令牌通道数 | - |

**直觉**: L_mimic 让学生模仿教师的"思考方式"(潜特征)，L_GT 让学生学会正确的驾驶行为。两者结合时，蒸馏起到正则化作用防止过拟合，真值监督提供任务-specific 信号。

> 符号与本文/相关文档保持一致：T 表示令牌 (Token)，L 表示损失 (Loss)，下标 GT 表示 Ground Truth，mimic 表示模仿蒸馏。

## 3. 带数字走一遍：玩具例子 (Worked Example)

假设一个训练批次 B=4，规划令牌维度 Cp=256：

**步骤 1: 前向传播**
- 教师处理输入后输出 Tp = [0.23, -0.15, 0.89, ..., 0.42] (4 个样本 × 256 维)
- 学生处理相同输入后输出 T_student = [0.21, -0.18, 0.85, ..., 0.39]

**步骤 2: 计算 L_mimic**
```
L_mimic = (1 / 4×256) × Σ|T_student - Tp|
        = (1/1024) × (|0.21-0.23| + |-0.18-(-0.15)| + |0.85-0.89| + ... + |0.39-0.42|)
        ≈ 0.042  (假设平均绝对误差 0.043)
```

**步骤 3: 计算 L_GT** (假设单样本值)
```
L_col = 0.5  (有轻微碰撞风险)
L_bd = 0.3   (接近边界)
L_reg = 0.8  (轨迹 L1 误差)
L_vae = 0.6  (VAE KL 散度)

L_GT = 0.5 + 3×0.3 + 3×0.8 + 3×0.6 = 0.5 + 0.9 + 2.4 + 1.8 = 5.6
```

**步骤 4: 总损失与反向传播**
```
L_total = 5.6 + 0.042 = 5.642
```
梯度同时更新学生解码器和 VAE 规划器，视觉编码器保持冻结。

**关键观察**: L_mimic 仅占总损失 ~0.7%，但它的正则化效应防止学生过拟合到硬性的轨迹真值，使模型在未见场景下泛化更好。

- 视觉编码器仍是瓶颈：EVA-02-L 占学生总延迟的 ~60%，未来可蒸馏视觉编码器

- 开源权重：代码和权重将公开，复现门槛低

**Trade-off**: 用 20 小时训练时间换取 3 倍推理加速和 74% 显存节省，对部署场景是划算的交换。

### 6.3 隐含假设 (Hidden Assumptions)

**X-Ray 批判视角**:

1. **假设 1**: "自动驾驶的因果推理不需要 LLM 在推理时显式存在"
   - 验证：在 Bench2Drive 上成立，但未测试需要常识推理的长尾场景
   - 风险：若场景超出训练分布，学生可能缺乏教师的泛化能力

2. **假设 2**: "教师的潜特征是学生最优蒸馏目标"
   - 验证：L1 回归有效，但未对比其他中间层特征
   - 风险：可能存在更好的蒸馏层 (如 attention map)

3. **假设 3**: "视觉编码器的驾驶特定先验不可通过真值监督学习"
   - 验证：Table 6 显示冻结教师编码器 77.4 DS vs 微调 EVA-02-L 72.4 DS
   - 风险：若用更多数据微调，差距可能缩小
