### 1.2 关键机制 (Key Mechanism)

PRTS 的三个核心技术设计：

**① 语言条件对比强化学习（Language-Conditioned Contrastive RL）**

标准 CRL（Eysenbach 2022）在状态空间中对未来状态做几何采样（Δt ~ Geom(1-γ)），每个 (s, a) 对应一个正样本目标状态。但 PRTS 中目标是语言指令 l，在整个轨迹中共享——打破了"单正样本"假设。

解决方案：将几何采样转化为**时间加权**（temporal weighting）。对于同一任务中所有正样本 j ∈ S(i)，定义权重：

```
q_ij = γ^(T_j - t_j) / Σ_{j'∈S(i)} γ^(T_j' - t_j')
```

其中 T_j 是轨迹总长度，t_j 是当前时间步。离终点越近，权重越大，模拟几何分布的衰减特性。

**② 双向对比目标（Bidirectional Contrastive Objectives）**

PRTS 同时优化两个方向：

- **s,a → l（状态-动作到语言）**：每个 (s, a) 只有一个正目标 l，做标准 InfoNCE 分类。主要捕获**任务身份**（哪个任务）。
- **l → s,a（语言到状态-动作）**：语言 l 有多个正样本（同一任务的所有时间步），用软目标 q_ij 做加权交叉熵。主要捕获**任务进度**（离完成多远）。

两者的组合确保表示空间同时编码任务识别和时间进度。

**③ 单前向传播设计（Single-Forward-Pass Design）**

在输入序列尾部追加两个辅助 token 块：
- `<CRL_action>` 块：重复动作 token + 可学习 token `<|action_end|>` → 编码 ϕ(s, a)
- `<CRL_goal>` 块：重复指令 token + 可学习 token `<|goal_end|>` → 编码 ψ(l)

通过**角色感知因果掩码**（role-aware causal mask，集成到自定义 FlashAttention-4 kernel 中）实现信息隔离：
- `<CRL_action>` token 只关注视觉和 proprioception
- `<CRL_goal>` token 只关注自身块内
- AR 动作 token 保持标准因果注意力

BC 损失不受影响，CRL 表示在同一前向传播中产出。

⚡ **Eureka Moment**：语言指令作为全局共享目标打破了标准 CRL 的单正样本假设，但通过时间加权 γ^(T-t) 可以将多正样本的软目标分布映射到几何采样的理论等价物——内积 ϕ(s,a)⊤ψ(l) 直接编码 log-discounted goal occupancy，无需任何奖励标注。

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：

```
ϕ(s,a)⊤ ψ(l) = log Q^π_l(s,a) + C(l)
```

**目标**：让状态-动作嵌入 ϕ 与目标嵌入 ψ 的内积，等于从 (s,a) 出发到达语言目标 l 的 Q 值的对数（up to 目标依赖的常数偏移）。

**完整公式链**：

```
// 目标可达奖励（Eysenbach 2022）
r_g(s_t, a_t) = (1 - γ) · p(s_{t+1} = s_g | s_t, a_t)

// Q函数 = 折扣状态占据概率（Lemma 1）
Q^π_{s_g}(s, a) = p^π(st+ = s_g | s, a)

// 对比学习最优解（InfoNCE 极限）
f*(s, a, s_g) = log Q^π_{s_g}(s, a) - log p(s_g) + c(s,a)

// PRTS 定理 1（语言条件 + 时间加权）
ψ*(l)⊤ ϕ*(s,a) = log Q^π_l(s,a) + C(l)
```

**变量说明**：

| 符号 | 含义 |
|------|------|
| ϕ(s, a) ∈ ℝ^d | 状态-动作嵌入（来自 `<|action_end|>` hidden state + MLP） |
| ψ(l) ∈ ℝ^d | 目标嵌入（来自 `<|goal_end|>` hidden state + MLP） |
| Q^π_l(s, a) | 语言条件 Q 函数：从 (s,a) 出发按策略 π 到达语言目标 l 的概率 |
| γ ∈ (0,1) | 折扣因子（控制时间衰减） |
| T, t | 轨迹总长度 / 当前时间步 |
| q_ij | 时间权重 = γ^(T_j - t_j) / 归一化 |
| C(l) | 仅依赖目标 l 的偏移函数 |

**直觉**：内积 ϕ⊤ψ 不是简单的"语义相似度"，而是物理可达性的对数概率。当机器人离目标越近，内积越大；当目标从当前状态几乎不可达时，内积趋向负无穷。这给了 System 2 一个定量的"任务进度计"。

> 符号与本文保持一致：ϕ 为状态-动作编码器输出，ψ 为目标编码器输出，Q 为折扣占据测度（即到达目标的概率）。

## 3. 带数字走一遍：玩具例子 (Worked Example)

假设一个 5 步轨迹任务："把红色积木放进蓝色盒子"。

```
时间步:   t=0      t=1      t=2      t=3      t=4(终)
状态:    初始     看到积木  抓住积木  移动到盒  放入完成
动作:    转向     接近     抓取     移动     释放
```

设 γ = 0.9，计算各时间步的时间权重：

```
γ^(T-t) 值:
  t=0: γ^5 = 0.9^5 = 0.590
  t=1: γ^4 = 0.9^4 = 0.656
  t=2: γ^3 = 0.9^3 = 0.729
  t=3: γ^2 = 0.9^2 = 0.810
  t=4: γ^0 = 0.9^0 = 1.000

归一化权重 q_i (Σ = 3.785):
  t=0: 0.590/3.785 = 0.156
  t=1: 0.656/3.785 = 0.173
  t=2: 0.729/3.785 = 0.193
  t=3: 0.810/3.785 = 0.214
  t=4: 1.000/3.785 = 0.264
```

在 l → s,a 方向，语言锚点 l 的软目标要求：

```
ψ(l)⊤ ϕ(s_0, a_0) ≈ log(0.156) + C ≈ -1.86 + C   (最不可能完成)
ψ(l)⊤ ϕ(s_4, a_4) ≈ log(0.264) + C ≈ -1.33 + C   (最可能完成)
差值: 0.53 个单位
```

这意味着：在表示空间中，靠近终点的状态-动作对与目标嵌入的内积比初始状态大约 0.53。模型学会了"进度感"——不是简单的"剩余步数"，而是**到达目标的折扣概率的对数**。

在实际推理中，System 2 可以用这个内积值做决策：如果内积持续下降（说明当前动作序列正在远离目标），可以触发重规划。

## 4. 工程视角 (Engineering View)

| 工程维度 | PRTS 设计 | 含义 |
|----------|-----------|------|
| **训练开销** | 相比 vanilla BC 可忽略 | 两个小 token 块 + 轻量 MLP head，无额外前向传播 |
| **推理延迟** | 无额外开销（推理时 CRL head 可丢弃） | CRL 表示仅在预训练阶段使用，post-training 阶段 attach DiT flow-matching head |
| **显存** | 增加 <5%（token 序列尾部追加少量 token） | 自定义 FlashAttention-4 kernel 处理角色掩码 |
| **吞吐量** | 64 H100 × 1 周，167B tokens | 序列打包（sequence packing）+ CuTe 优化 |
| **动作表示** | FAST tokenization（离散化动作 chunk） | 动作先离散为 token，再参与 AR 预测和 CRL 编码 |
| **两阶段训练** | Stage 1: 预训练（BC + CRL）→ Stage 2: post-training（DiT flow-matching head） | Stage 1 产出表示，Stage 2 产出连续动作 chunk |
| **部署约束** | 推理时只需 backbone + DiT head | CRL token 和 head 可完全移除，不增加推理延迟 |

**关键 trade-off**：CRL 表示在预训练阶段注入，但在推理时不直接使用。这意味着目标可达性感知被"蒸馏"进了 backbone 的表示中，而非作为独立的推理模块。好处是零推理开销；风险是表示中编码的可达性信息可能不如显式价值网络精确。

## 6. 能力与失败模式 (Capabilities & Failure Modes)

### 能做什么

| 能力 | 原因 |
|------|------|
| 长视野任务规划 | 表示空间编码了时间进度，System 2 可评估中间步骤的价值 |
| 零样本新指令泛化 | 对比学习迫使 backbone 学习任务相关的功能可供性（functional affordances），而非记忆特定动作序列 |
| 接触密集操作 | 目标可达性感知帮助区分"看似简单但方向错误"和"看似困难但可达"的状态 |
| 人类干预恢复 | 当人类改变环境状态后，内积 ϕ⊤ψ 可快速评估新状态下的可达性，指导重规划 |

### 不能做什么 / 局限

| 局限 | 原因 |
|------|------|
| 仅基于 Qwen3-VL-4B（未测试更大 backbone） | 4B 规模的表示容量可能限制对比学习的上限；CRL 在更大模型上的 scaling behavior 未知 |
| 真实实验仅在 2 个机器人平台上验证（RealMan + Flexiv） | 泛化到其他机器人平台（如人形、移动操作）的能力未验证 |
| 时间加权依赖专家演示的轨迹结构 | 如果演示数据质量差（非专家轨迹），γ^(T-t) 近似可能失效 |
| CRL 表示仅在预训练阶段使用 | 推理时不显式使用可达性估计，可能浪费了一部分学到的信息 |

### 6.1 隐含假设 (Hidden Assumptions)

1. **专家演示假设**：时间加权 γ^(T-t) 近似 discounted occupancy 的前提是演示来自接近最优策略。如果数据中包含大量低质量轨迹，时间距离与可达性的对应关系会被破坏。

2. **语言目标唯一性假设**：同一任务的所有时间步共享同一个语言指令。这在多子任务场景中可能过于简化——一个"把积木放进盒子"的任务可能包含"找到积木"→"抓取"→"移动"→"释放"多个子目标，但 PRTS 用单一语言表示所有子目标。

3. **对比学习 batch 内负样本充分性**：InfoNCE 的质量依赖于负样本的多样性和数量。如果 batch 中任务种类少，负样本区分度不足，对比学习效果会下降。论文未报告 batch 中平均任务数。

4. **角色掩码不损害 BC 表示**：虽然论文声称 BC loss 与有无 CRL token 时"identical"，但角色掩码改变了 attention pattern，可能间接影响共享 backbone 的表示质量。消融实验（TODO: 查阅附录）可能揭示这一点。
