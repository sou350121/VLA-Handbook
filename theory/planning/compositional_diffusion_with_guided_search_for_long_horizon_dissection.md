💡 **X-Ray 开场**
长程规划中，用短程扩散模型拼接长计划时，每个短程段都有多种可行模式（比如"先抓A再抓B"或"先抓B再抓A"）。传统方法简单平均这些模式的分数，结果产生既不在A路径也不在B路径上的"中间态"——计划不可行。CDGS 的核心发现是：把群体搜索（维护多个候选计划、每步淘汰差的）和迭代重采样（让远距离段通过重叠变量交换信息）嵌入扩散去噪过程，就能在推理时自动找到一致的模式组合，无需任何长程训练数据。

### 1.2 关键机制 (Key Mechanism)

CDGS 在标准组合扩散的去噪循环中嵌入了两个核心组件：

1. **迭代重采样（Iterative Resampling）**：在每一步去噪时，交替执行前向加噪和去噪 U 次。这类似于因子图链上的信念传播——每个局部段 y_m 通过重叠变量从其邻居 y_{m-1} 和 y_{m+1} 接收信息。经过 U 次迭代后，远距离段之间的信息得以传播。

2. **基于似然的剪枝（Likelihood-based Pruning）**：用 DDIM 反演计算每个局部段的"平滑度"（扩散轨迹曲率），曲率越低说明该段越接近训练分布的高似然区域。维护 B 个候选计划，每步保留 K 个最优（J 值最小）的精英计划，淘汰其余。

⚡ **Eureka Moment**：**"全局计划可行的充要条件是所有局部转移都可行"——因此不需要全局奖励模型，只需评估每个局部段是否在短程模型的似然高区内，就能剪掉不一致的模式组合。**

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：

```
p_J(τ^{(t-1)} | τ^{(t)}) ∝ p(τ^{(t-1)} | τ^{(t)}) · exp(-J(τ̂₀^{(t-1)}) / λ_t)
```

**目标**：修改标准扩散转移分布，使采样更倾向于产生全局一致的候选计划。

**公式拆解**：

```
J(τ^{(0)}) = ∏_{m=1}^{M} exp(-g(y_m^{(0)}))

其中:
  g(y^{(0)}) = Σ_{i=1}^{T} ||∂ε_θ(y^{(i-1)}, i) / ∂i||₂
```

| 符号 | 含义 |
|------|------|
| τ | 全局计划，由 M 个局部段 y_1...y_M 拼接 |
| y_m | 第 m 个局部段（短程扩散模型的输出） |
| ε_θ | 预训练的局部计划分数网络 |
| g(y^{(0)}) | 局部段的平滑度——扩散轨迹的曲率之和 |
| J(τ^{(0)}) | 全局计划评分——所有局部段平滑度的乘积 |
| λ_t | 探索-利用权衡系数（随 t 衰减） |
| B | 候选计划数（群体大小） |
| K | 精英计划数（每步保留） |
| U | 迭代重采样步数 |

**直觉**：g(y^{(0)}) 衡量局部段 y 离训练分布最近模式的"距离"——高似然样本在 DDIM 反演时走的是低曲率路径（平滑），低似然样本需要高曲率才能拉回分布内。J 越小表示全局计划的所有局部段都在高似然区域内，越可能是可行计划。

> 符号与本文/相关文档保持一致。扩散调度 α_t 和噪声 σ_t 遵循标准 DDIM 定义。

## 3. 带数字走一遍：玩具例子 (Worked Example)

假设一个简化场景：

- 全局计划 τ 由 M=3 个局部段拼接：y₁, y₂, y₃
- 每个局部段覆盖 3 个时间步（重叠 1 步）
- 候选数 B=4，精英数 K=2，重采样步数 U=2
- 在去噪步 t=50（共 T=100 步）

**步骤 1 — ComposedScore（U=2 次迭代）**：

```
第 1 次迭代:
  ε_composed = score(y₁) + score(y₂) + score(y₃)  [组合分数]
  τ̂₀ = denoise(τ^{(50)}, ε_composed)
  固定 x_start 和 x_goal（边界条件不变）
  τ^{(50)} ← forward_noise(τ^{(49)})  [信息回传]

第 2 次迭代:
  重复上述过程，此时 y₂ 的分数已隐含 y₁ 和 y₃ 的信息
  返回最终 ε_composed
```

**步骤 2 — 剪枝评分**：

假设 4 个候选计划的局部段平滑度如下：

```
候选 A: g(y₁)=0.3, g(y₂)=0.5, g(y₃)=0.2 → J = exp(-1.0) = 0.368  ← 精英 ✓
候选 B: g(y₁)=0.4, g(y₂)=0.3, g(y₃)=0.4 → J = exp(-1.1) = 0.333  ← 精英 ✓
候选 C: g(y₁)=0.3, g(y₂)=2.8, g(y₃)=0.2 → J = exp(-3.3) = 0.037  ← 淘汰 ✗
候选 D: g(y₁)=1.5, g(y₂)=0.4, g(y₃)=1.8 → J = exp(-3.7) = 0.025  ← 淘汰 ✗
```

注意：候选 C 的 y₂ 段平滑度极高（2.8），说明该段不在短程模型的高似然区域内——可能是两个不兼容模式的"中间态"。CDGS 通过剪枝将其淘汰。

**步骤 3 — 重填充**：

```
用候选 A 和 B 重新填充 4 个候选（例如加噪声扰动复制）
继续下一步 t=49 的去噪
```

经过 100 步去噪后，最终保留的计划所有局部段都在高似然区域内。

## 4. 工程视角 (Engineering View)

| 工程维度 | 分析 |
|----------|------|
| 推理延迟 | 标准 CD: T 步去噪。CDGS: T × (U + 剪枝开销) 步。U=2 时约 2-3× 延迟 |
| 内存开销 | 需同时维护 B 个候选计划的隐状态。B=4 时内存约 4× 标准 CD |
| 吞吐 | 可并行评估 B 个候选的局部段分数（每个局部段独立） |
| 可扩展性 | B 和 K 可按问题难度自适应调节——简单任务用小 B，复杂任务用大 B |
| 部署约束 | 需要预训练的短程扩散策略模型；无需长程数据或全局奖励模型 |
| 量化误差 | DDIM 反演引入近似误差——平滑度 g(y) 是似然的代理指标，非精确值 |

**工程含义**：CDGS 的推理时计算预算是可调节的——对于简单任务（如 PointMaze Medium），B=2, K=1, U=1 即可；对于困难任务（如 Humanoid-Maze Giant），可能需要 B=8, K=2, U=2。这使其成为一个"自适应 compute"的方案，而非固定开销。

### 6.1 隐含假设 (Hidden Assumptions)

1. **短程模型质量足够**：CDGS 假设预训练的短程扩散模型 p(y) 能产生可行的局部段。如果短程模型本身质量差（如 play 数据噪声大），剪枝也无法挽救——"垃圾进，垃圾出"。

2. **局部可行性 ⇒ 全局可行性**：核心假设"全局计划可行 iff 所有局部转移可行"。这在链式因子图中近似成立，但如果全局约束涉及非局部依赖（如"整个计划中只能碰 A 一次"），该假设可能失效。

3. **DDIM 反演平滑度 ≈ 似然**：g(y) 是似然的代理指标，非精确似然。论文引用 [18] 支持这一假设，但未做系统验证——平滑度与真实似然之间的相关性程度未知。

4. **重叠变量足够传递信息**：迭代重采样依赖重叠变量（如 y_m ∩ y_{m+1}）传递信息。如果重叠区域信息量不足（如仅重叠 1 个时间步），远距离段之间的信息传播可能不充分。
