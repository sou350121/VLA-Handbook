### 1.2 关键机制 (Key Mechanism)

**为什么这样设计？**

1. **物理约束的不对称性**：具身 VLA 的动作空间受物理约束，真正不安全的概念相对 benign 任务空间很小 —— 这使针对性概念控制可行
2. **隐藏激活纠缠**：高维激活中语义因子纠缠，字典学习提供自然解 —— 提取基向量（原子）表示概念方向，激活可分解为稀疏可解释系数
3. **推理时干预优势**：避免训练时对齐的高成本（VLA 数据稀缺、机器人资源有限、过拟合风险），同时比输入/输出过滤更早拦截不安全意图

⚡ **Eureka Moment**：具身 VLA 的安全风险集中在少量可枚举的物理危害概念上（刀、汽油、有毒、小孩等），通过字典学习将这些概念映射到隐藏空间的稳定方向，推理时只需检测并衰减这些方向的激活，即可实现统一防御 —— 无需重训练，无需修改骨干模型。

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：

```
s(h) = Σᵢ∈I_harm wi·|zi|  > τ  →  z'i = (1-γ)zi for top-k risky concepts
```

**目标**：在推理时检测隐藏状态 h 中有害概念的激活强度，超过阈值时选择性衰减，重构安全潜变量。

**公式分解**：

```
1. 稀疏投影:  z* = argmin_z ||h - Dz||²₂ + α||z||₁ + β||z||²₂

2. 有害分数:  s(h) = Σᵢ∈I_harm wi·|zi*|

3. 风险排名:  ri = wi·|zi*|,  K = TopK_{i∈I_harm}(ri, k)

4. 选择性衰减:  z'i = (1-γ)zi*  if s(h)>τ and i∈K,  else zi*

5. 潜权重构:  h̃ = Dz' + (h - Dz*)  ← 保留字典外残差
```

**变量说明**：

| 符号 | 含义 | 维度/范围 |
|------|------|-----------|
| h | VLA 最后解码层隐藏状态 | $\mathbb{R}^d$, $d=$隐藏维度 |
| D | 概念字典 | $\mathbb{R}^{d \times M}$, $M=$概念数 |
| z | 概念系数（稀疏） | $\mathbb{R}^M$ |
| wi | 概念 i 的有害权重 | [0,1] |
| $\tau$ | 触发阈值 | 标量，默认 0.85 |
| $\gamma$ | 衰减强度 | (0,1), 默认 0.6 |
| k | 衰减概念数 | 整数，默认 8 |
| $\alpha,\beta$ | ElasticNet 正则 | α=10⁻², β=5×10⁻⁴ |

**直觉**：把高维隐藏状态投影到 M 个可解释概念方向上，用稀疏系数表示每个概念的参与程度。有害概念的加权和超过阈值时，只衰减风险最高的 k 个，保留其他信息 —— 平滑干预而非二元停止。

## 3. 带数字走一遍：玩具例子 (Worked Example)

假设场景：VLA 收到指令"把装满汽油的油桶放炉灶上"（Libero-Harm 典型危害）。

**步骤 1：提取隐藏状态**
```
h ∈ R^768  ← VLA 最后解码层输出
```

**步骤 2：ElasticNet 投影**（假设 M=128 个概念）
```
z* = ElasticNet(h, D, α=0.01, β=0.0005)
   = [0, 0, 0.82, 0, 0, 0.15, 0, ..., 0.91, 0, ...]  ← 稀疏

假设非零系数对应概念：
  z*[3] = 0.82  → "汽油" (w₃=0.95)
  z*[5] = 0.15  → "炉灶" (w₅=0.30)
  z*[98] = 0.91 → "易燃" (w₉₈=0.90)
```

**步骤 3：计算有害分数**
```
s(h) = w₃·|z*[3]| + w₅·|z*[5]| + w₉₈·|z*[98]|
     = 0.95×0.82 + 0.30×0.15 + 0.90×0.91
     = 0.779 + 0.045 + 0.819
     = 1.643
```

**步骤 4：触发判断**
```
τ = 0.85
s(h) = 1.643 > 0.85  →  触发干预 ✓
```

**步骤 5：选 top-k 风险概念**（k=8）
```
风险分数 ri = wi·|zi*|:
  r₃ = 0.95×0.82 = 0.779  (汽油)
  r₉₈ = 0.90×0.91 = 0.819  (易燃)
  r₅ = 0.30×0.15 = 0.045  (炉灶)

Top-2: {易燃, 汽油}
```

**步骤 6：衰减**（$\gamma=0.6$）
```
z'[98] = (1-0.6)×0.91 = 0.364
z'[3] = (1-0.6)×0.82 = 0.328
z'[5] = 0.15  (未入选 top-k，保持)
```

**步骤 7：重构**
```
h̃ = D·z' + (h - D·z*)
  = D·z' + 残差

残差 (h - D·z*) 保留字典外信息，避免过度干预
```

**结果**：汽油和易燃概念的激活被衰减 60%，VLA 生成安全动作的概率大幅提升。

## 4. 工程视角 (Engineering View)

### 4.1 计算开销

| 操作 | 复杂度 | 实际延迟 (Qwen2.5-VL) |
|------|--------|----------------------|
| ElasticNet 投影 | $O(d \cdot M)$ | ~2ms (d=768, M=128) |
| 有害分数计算 | O(|I_harm|) | <0.1ms (~50 有害概念) |
| Top-k 选择 | O(M log k) | <0.1ms |
| 衰减 + 重构 | $O(d \cdot M)$ | ~1ms |
| **总计额外开销** | | **~3ms/步** |

### 4.2 内存占用

```
字典 D:        768 × 128 × 4 bytes = 393 KB
有害权重 w:    128 × 4 bytes = 512 bytes
ElasticNet 临时: 128 × 8 bytes = 1 KB
─────────────────────────────────────
总计:          ~400 KB (可忽略)
```

### 4.3 部署约束

- **干预点**：最后解码层隐藏状态之后、动作解码器之前
- **适用模型**：end-to-end VLA (OpenVLA, $\pi_{0.5}$) 和 VLM-driven agent (Qwen2-VL, Llama-3.2-Vision)
- **字典迁移**：跨数据集迁移有效但有损耗 —— IS-Bench 字典用于 Libero-Harm 时 ASR 从 $73.4\% \to 27.6\%$（in-domain 可达 $10.9\%$）

### 4.4 超参数调优指南

| 参数 | 默认值 | 调高效果 | 调低效果 | 建议范围 |
|------|--------|----------|----------|----------|
| $\tau$ (阈值) | 0.85 | 更少触发，ASR↑, SR↑ | 更多触发，ASR↓, SR↓ | 0.7-0.9 |
| $\gamma$ (衰减) | 0.6 | 更强干预，ASR↓, SR↓ | 更弱干预，ASR↑, SR↑ | 0.4-0.8 |

### 6.1 能做什么

| 场景 | 能力 | 证据 |

### 6.2 不能做什么

| 局限 | 原因 | 影响 |
|------|------|------|
| 字典外新型危害 | 依赖预定义概念集 | 未知风险无法检测 |
| 低层控制不稳定 | 仅干预语义层 | 感知失败/物理交互风险需系统级防护 |
| 极端分布偏移 | 字典 in-domain 最优 | 跨域迁移性能下降~50% |
| 对抗性刺激 | 刺激模板变化鲁棒，但极端对抗未测 | 待验证 |

### 6.3 隐含假设 (Hidden Assumptions)

1. **概念可枚举性**：假设所有重要安全风险可被概念词汇集覆盖 —— 但开放世界安全仍是未解问题
2. **方向稳定性**：假设 PCA 提取的概念方向在分布内稳定 —— 理论分析依赖概念选择性采样假设
3. **线性可分性**：假设有害/无害概念在隐藏空间线性可分 —— 用 ElasticNet 线性投影，非线性纠缠可能漏检
4. **阈值通用性**：假设 $\tau=0.85$ 跨场景有效 —— 实际需针对具体 VLA 和任务域校准
