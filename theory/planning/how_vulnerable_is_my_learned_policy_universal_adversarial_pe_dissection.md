### 1.2 关键机制 (Key Mechanism)

**攻击流程（Algorithm 1）**：

1. 初始化扰动 $\delta = 0$
2. 对数据集 D 中每个 (s, a) 批次：
   - 计算扰动状态 $\tilde{s} = \operatorname{clip}(s + \delta, 0, 1)$
   - 前向传播得到预测动作 $\hat{a} = \pi_\theta(\tilde{s})$
   - 计算策略特定损失 L_BC(s̃, â)
   - 累积梯度 $G += \nabla_{\tilde{s}} L_{\text{BC}}$
3. 更新扰动 $\delta \gets \operatorname{clip}_{[-\varepsilon,\varepsilon]}(\delta + \alpha \cdot \operatorname{sign}(G))$
4. 重复 $E$ 个 epoch，返回最终 $\delta$

**为什么 UAP 对 BC 策略有效**：
- BC 策略的视觉编码器（ResNet-18）是所有算法共享的组件，扰动针对的是视觉表征空间
- BC 策略是确定性的前向映射（或有限随机性），固定扰动在推理时始终产生相同的方向性偏移
- 与分类任务不同，BC 的"错误"是累积的 — 一个错误动作导致状态偏移，后续动作在分布外状态上继续出错

⚡ **Eureka Moment**：一个离线计算、测试时零开销的固定像素扰动，就能让所有主流BC策略在复杂任务中崩溃 — 而且这个扰动还能跨算法迁移（用DP训练的扰动攻击VQ-BET），说明不同BC算法的视觉表征空间存在共享的脆弱方向。

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：
```
δ* = argmax_{‖δ‖∞≤ε} E_{(s,a)~D} [ L_BC( π_θ(s+δ), a ) ]
```

**目标**：找到一个固定的像素扰动 $\delta$，使得被攻击策略在专家数据分布上的损失最大化（即行为偏离专家最远）。

**变量说明**：

| 符号 | 含义 |
|------|------|
| $\delta$ | 通用对抗扰动，对所有输入共享同一个 $\delta$ |
| $\varepsilon$ | 扰动预算（$L_\infty$ 约束），默认 $\varepsilon=0.0625$（$16/256$） |
| $\pi_\theta$ | 预训练的BC策略网络 |
| L_BC | 策略特定的损失函数（见下方各算法） |
| D | 专家演示数据集 |

**各算法的损失函数**：

```
Vanilla BC:    L = E[ ‖π_θ(s) - a‖² ]              (MSE回归)
LSTM-GMM:      L = E[ -Σ log p(a_t\|s_t, h_{t-1}) ]  (负对数似然)
IBC:           L = E[ InfoNCE对比损失 ]               (能量对比)
Diffusion:     L = E[ ‖ε - ε_θ(s, a^k, k)‖² ]       (噪声预测MSE)
VQ-BET:        L = L_code + ‖a_t - π_resid(s_t)‖_1  (focal + L1残差)
```

**直觉**：UAP 不是对每个输入单独优化扰动（如 PGD），而是找到一个"万能钥匙" — 一个对所有输入都有效的固定扰动。这使攻击在测试时零计算开销，只需将 $\delta$ 叠加到摄像头画面上。

> 符号与原文保持一致。扰动 $\delta$ 作用于图像像素空间（归一化到 $[0,1]$），$L_\infty$ 约束确保扰动不可见。

## 3. 带数字走一遍：玩具例子 (Worked Example)

以 **Lift 任务 + Vanilla BC** 为例，追踪攻击前后的完整闭环：

**未攻击基线**：
- 成功率: 97%（150次rollout中145次成功）
- 策略行为：视觉编码器提取立方体位置 → MLP 回归出抓取动作 $(x, y, z, \text{roll}, \text{pitch}, \text{yaw}, \text{grip})$
- 典型动作误差: $\Vert\pi(s) - a_{\text{expert}}\Vert_2 \approx 0.05$

**施加 UAP 攻击后（$\varepsilon = 0.0625$）**：
- 成功率: 7%（150次rollout中仅11次成功）
- 扰动 $\delta$ 的幅度：每个像素偏移 $\leq 16/256 \approx 6.3\%$（肉眼几乎不可见）
- 典型动作误差: $\Vert\pi(s+\delta) - a_{\text{expert}}\Vert_2 \approx 0.45$（放大9倍）

**逐步推演单次 rollout**：

```
t=0:  s_0 = [立方体在桌子中央, 84×84 RGB]
      s̃_0 = clip(s_0 + δ, 0, 1)  ← δ 在立方体边缘像素叠加了微小扰动
      π(s̃_0) = [抓取位置偏移 (2px右, 3px下), 力度不足]
      → 爪子错过立方体边缘，接触桌面

t=1:  s_1 = [爪子在桌面上方, 立方体未移动]（状态已偏移）
      s̃_1 = clip(s_1 + δ, 0, 1)  ← 同一 δ 作用于新状态
      π(s̃_1) = [继续向错误方向移动]
      → 分布外状态上的动作，策略完全不可靠

t=2...T: 累积偏差 → 任务失败
```

**关键洞察**：即使 $\varepsilon=0.016$（约$4/256$，几乎不可见），Vanilla BC 在 Lift 任务上成功率已从 97% 降至约 40%。扰动不需要大 — 它只需要把策略推向错误的"引力方向"。

## 4. 工程视角 (Engineering View)

| 工程维度 | 分析 |
|----------|------|
| **攻击计算开销** | 离线优化：$E$ 个 epoch $\times$ |D| 次前向传播。一旦 $\delta$ 计算完成，测试时零开销 — 只需 $\text{pixel\_add}(s, \delta)$ |
| **推理延迟影响** | 无影响。扰动是预计算的，推理管线不需要任何修改 |
| **存储需求** | $\delta$ 大小 = 图像尺寸（$84\times84\times3 \approx 21\text{KB}$），可忽略 |
| **部署约束** | 攻击者需要：(1) 访问专家数据集 D（或类似分布数据）(2) 知道目标策略的架构/参数 |
| **量化误差** | 未研究。但量化可能略微增加/减少脆弱性 — 离散化可能破坏或强化扰动方向 |
| **多相机设置** | 论文攻击 front + wrist 两个相机视图。实际部署中更多相机可能增加攻击难度（需同时扰动多路输入） |
| **VLA 外推** | VLA 通常有更大的视觉编码器（ViT-L/14 等）+ 语言编码器。更大的模型可能更脆弱（更多参数 = 更多可攻击方向），但也可能因多模态冗余而更鲁棒 |

**工程含义**：UAP 攻击的威胁模型非常实际 — 预训练的 VLA 模型（如 OpenVLA、RT-X）正在被广泛部署，攻击者只需获取模型权重（很多已开源）和少量演示数据即可构造攻击。

### 6.1 隐含假设 (Hidden Assumptions)

1. **攻击者能访问专家数据集 D**：UAP 优化需要数据。论文假设攻击者能获取与训练数据同分布的数据。实际中，攻击者可能只有少量演示或合成数据。
2. **扰动仅作用于视觉输入**：论文明确只扰动图像，不动本体感知信号。这简化了攻击但可能低估了真实威胁（如果本体信号也可被篡改）。
3. **固定扰动足够有效**：UAP 假设一个固定 $\delta$ 对"大部分"输入都有效。但在长序列任务中，状态分布可能随时间大幅偏移，固定扰动在分布外区域的效果未验证。  
4. **仿真到真实的迁移性**：仿真中的对抗脆弱性是否反映真实世界？真实传感器的噪声可能掩盖也可能放大对抗扰动。
5. **BC $\approx$ VLA 的脆弱性**：VLA 有额外的语言编码器和更大的视觉模型，其脆弱性模式可能与纯视觉 BC 不同。
