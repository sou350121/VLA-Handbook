### 1.2 关键机制 (Key Mechanism)

World2VLM由三个核心组件构成：

1. **世界模型引导的转换构建管线**：从锚点观测 + 参数化自中心相机轨迹出发，用视图一致的世界模型合成几何对齐的未来视图
2. **双向空间推理任务套件**：每个转换同时生成**逆推理**（从视图变化推断动作）和**正推理**（从动作预测后果）任务
3. **两阶段后训练**：SFT（监督蒸馏）→ GRPO（任务感知强化学习精炼）

⚡ **Eureka Moment**：世界模型不应该是推理时的外挂工具，而应该是训练时的教师——把空间想象力蒸馏进VLM参数后，模型本身就学会了"想象"。

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：
```
用世界模型生成动作条件化视图转换: s_{t+1}^WM ~ P_WM(s_{t+1} | s_t, a_t)
  → 蒸馏进VLM: P_θ(a_t | s_t, s_{t+1}) 和 P_θ(y | s_t, a_t)
  → 推理时不再需要世界模型
```

**目标**：训练VLM参数 θ，使其同时掌握逆空间推理（从观测推断动作）和正空间后果预测（从动作预测结果），且推理时不查询世界模型。

**核心方程**：

```
(1) 世界模型转换:
    s_{t+1}^WM ~ P_WM(s_{t+1} | s_t, a_t)

(2) VLM学习目标:
    P_θ(a_t | s_t, s_{t+1})    [逆推理: 从视图变化推断动作]
    P_θ(y | s_t, a_t)          [正推理: 从动作预测空间后果]

(3) SFT联合损失:
    L_SFT = λ_inv · L_inv + λ_fwd · L_fwd
    其中 L_inv = -E_{(x,y)~D_inv} [log P_θ(y|x)]
          L_fwd = -E_{(x,y)~D_fwd} [log P_θ(y|x)]

(4) GRPO奖励:
    r(y_hat, y*) = α_fmt · r_fmt + α_sem · r_sem + ...
```

**变量说明**：

| 符号 | 含义 |
|------|------|
| s_t | 锚点观测（初始图像） |
| a_t | 参数化自中心相机运动 |
| s_{t+1}^WM | 世界模型合成的未来视图 |
| P_WM | 世界模型的条件分布 |
| θ | VLM参数 |
| D_inv / D_fwd | 逆/正推理训练集 |
| λ_inv / λ_fwd | 双向损失权重 |
| r_fmt / r_sem | GRPO格式/语义奖励分量 |

> 符号与本文保持一致。世界模型教师可以是 SVC（Stable Virtual Camera，侧重相机条件化新视图）或 HY-WorldPlay（侧重动作条件化长程动力学）。

## 3. 带数字走一遍：玩具例子 (Worked Example)

```
B_t = {电视: [0.75, 0.30, 0.90, 0.60], 沙发: [0.10, 0.40, 0.50, 0.80]}
B_{t+Δ} = {电视: [0.50, 0.25, 0.70, 0.55], 沙发: [0.05, 0.35, 0.40, 0.75]}
```

**Step 2: 任务构建**

逆推理任务示例（A1-运动距离估计）：
```

A: "约0.5米"

```

正推理任务示例（D2-动作后物体定位）：
```
Q: "相机前进0.5m并右转15°后，电视的边界框在哪里？"
A: "[0.50, 0.25, 0.70, 0.55]"

```

  正推理准确率: ~35% (猜)

Stage 1 (SFT) 后:
  逆推理准确率: ~60% (学会了视图-动作映射)

## 4. 工程视角 (Engineering View)

| 工程维度 | MindJourney (推理时耦合) | World2VLM (训练时蒸馏) |
|----------|-------------------------|----------------------|
| 推理延迟 | 高（每步需图像生成 ~数秒/帧） | 低（标准VLM前向 ~毫秒级） |
| 推理显存 | 高（VLM + 世界模型同时加载） | 低（仅VLM） |
| 训练成本 | 无 | 中-高（SFT + GRPO两阶段） |
| 数据生成 | 无需 | 需世界模型离线生成（一次性） |
| 部署复杂度 | 高（需维护两个模型） | 低（单VLM） |
| 适用场景 | 研究/原型验证 | 生产部署 / 实时控制循环 |

**工程含义**：
- 对于VLA系统，控制循环频率通常在10-30Hz。MindJourney-style推理时耦合完全无法满足实时性要求。
- World2VLM将空间推理"编译"进VLM参数后，感知模块可在标准VLM推理时间内完成动态空间问答，与控制循环兼容。
- 训练管线的一次性成本（世界模型生成数据 + 两阶段训练）远低于持续推理开销。

## 5. 数据与评测 (Data & Eval)

**教师世界模型**（论文使用了两个）：
- **SVC (Stable Virtual Camera)**： specialize in camera-conditioned novel view synthesis
- **HY-WorldPlay**：侧重动作条件化长程动力学预测

**动作空间**：
- 平移（translation）、旋转（rotation）、短多步组合（multi-step compositions）
- 采用**最大位移配对**（max-displacement pairing）：用锚点帧和轨迹中最远的有效端点构成训练对，放大视角变化

**物体级监督**：
- 检测-跟踪器生成归一化物体框 B_t, B_{t+Δ}
- 框坐标序列化进文本prompt（不渲染到图像上），保持视觉输入不变

**评测基准**（4个）：

| 基准 | 类型 | 重点能力 |
|------|------|---------|
| SAT-Real | 真实图像 | 自中心运动、动作后果、视角采纳 |
| SAT-Synthesized | 合成图像 | 运动条件化推理 |
| VSI-Bench | 混合 | 视角变化推理 |
| MindCube | 模拟 | 心理模拟、视角采纳 |

**关键结果**（Table 2, 论文原文）：
- World2VLM-GRPO (SVC教师): SAT-Real 72.67%（基线44.67%，+28.00pp）
- World2VLM-GRPO (HY-WorldPlay教师): SAT-Synthesized 65.20%（基线39.60%，+25.60pp）
- GRPO阶段在SFT基础上持续带来提升（平均 +5.32pp）
- MindJourney-style推理时耦合基线在SAT-Real上反而**下降**13.34pp，说明推理时耦合可能引入干扰

## 6. 能力与失败模式 (Capabilities & Failure Modes)

### 能做什么
- **自中心运动推理**：预测相机移动后场景变化（SAT-Real上+28pp）
- **动作后果预测**：给定动作，预测物体位置/可见性/一致性变化
- **逆运动推断**：从两张图像推断相机做了什么运动
- **跨视图一致性判断**：判断同一物体在不同视角下是否一致

### 不能做什么（局限）
- **仅覆盖相机运动**：动作空间限定为自中心相机轨迹（平移/旋转/组合），未涉及机械臂操作、抓取等VLA核心动作
- **依赖世界模型教师质量**：如果世界模型合成的视图不准确或几何不一致，蒸馏质量直接受损
- **桌面场景为主**：数据集主要来自室内静态场景，对外观变化大的开放场景泛化性未验证
- **短程推理**：多步轨迹为"短"组合，长程心理模拟能力待验证

### 6.1 隐含假设 (Hidden Assumptions)

1. **世界模型合成的视图足够几何一致**：论文假设 SVC/HY-WorldPlay 生成的未来视图在几何上是准确的，但未见对合成视图几何精度的定量评估
2. **相机运动 ≈ VLA所需的空间推理**：论文将动态空间推理等同于相机运动推理，但VLA系统还需要推理机械臂运动、物体交互等更复杂的动作空间
3. **物体框序列化进prompt不会损失空间信息**：将边界框编码为文本坐标而非渲染到图像上，这是一种设计选择，但未与渲染方案做对比实验
4. **SFT + GRPO两阶段是必要的**：GRPO带来持续提升，但未分析单靠更大规模SFT是否能达到相似效果
