### 1.2 关键机制 (Key Mechanism)

DURA 的核心设计围绕三个组件展开：

1. **扩散潜空间搜索**：不直接在像素空间优化补丁，而是将良性种子补丁编码到 Stable Diffusion 的 VAE 潜空间，沿 DDIM 去噪轨迹进行搜索。扩散先验天然约束了补丁的视觉自然性。

2. **锚点轨迹正则化**：预计算一条干净的 DDIM 去噪轨迹作为锚点，每一步将对抗潜变量与锚点加权混合（z_mix = (1-αw)·z_adv + αw·z_anc），防止攻击轨迹偏离自然图像流形。

3. **双模式攻击方向估计**：
   - **白盒**：梯度回传，计算 ∇L_attack 得到精确方向
   - **黑盒**：Score Function Estimator（REINFORCE 风格），通过 K=2048 次扰动查询估计梯度方向

⚡ **Eureka Moment**：把对抗补丁优化从"像素空间的猫鼠游戏"转移到"扩散模型的潜空间去噪轨迹"上——扩散先验自动保证了补丁看起来像真实场景内容，而攻击目标只需在每一步去噪后注入一个小的扰动方向。

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：

```
z_{t-1}^{adv} = DDIM(mix(z_t^{adv}, z_t^{anc})) - s · g_t
```

**目标**：在扩散潜空间中寻找一个对抗补丁，使得 VLA 模型在观察到嵌入该补丁的场景时，输出攻击者指定的目标动作。

**核心方程**：

攻击损失（对 B 帧观察批次求平均）：

```
L_attack(p) = (1/B) · Σ_b Σ_i w_i · L_i(y_{b,i}(p), a_i^*)
```

其中白盒用交叉熵 CE，黑盒用 MSE：

```
L_i = { CE(y_{b,i}(p), a_i^*),         白盒
      { ||y_bar_{b,i}(p) - a_bar_i^*||², 黑盒
```

攻击方向估计（黑盒，Score Function Estimator）：

```
g_t^{BB} = (1/K) · Σ_k (L^{(k)}_attack - b) · sqrt(α_t)/(sqrt(1-α_t)) · ε_k
```

**变量说明**：

| 符号 | 含义 |
|------|------|
| π_θ | 受害者 VLA 策略 |
| p ∈ [0,1]^{h×w×3} | 对抗补丁 |
| a^* | 攻击者指定的目标动作序列 |
| z_t^{adv} | t 时刻对抗潜变量 |
| z_t^{anc} | t 时刻干净锚点潜变量 |
| α_w | 锚点混合权重（论文设为 0.2） |
| s | 攻击步长 |
| g_t | 潜空间攻击方向 |
| t_start | 部分加噪起始时间步（论文设为 0.5） |
| K | 黑盒查询数（论文设为 2048） |

**直觉**：DURA 不是"在像素上叠加噪声"，而是"在扩散模型的去噪轨迹上施加一个微小的推力"。扩散先验确保补丁看起来自然，锚点正则化确保不偏离图像流形太远，攻击方向 g_t 确保 VLA 被引导到目标动作。

> 符号与本文保持一致：π_θ 为 VLA 策略，D/E 为 VAE 解码/编码器，DDIM 为标准去噪步骤。

## 3. 带数字走一遍：玩具例子 (Worked Example)

假设一个简化场景：2D 机器人操作，动作空间为 (x, y, θ, gripper) 四维，目标动作 a^* = (0, 0, 0, 0)（即"冻结不动"）。

**Step 1: 种子编码与部分加噪**

```
p_clean = [一张桌面场景的小块区域, 64×64×3]
z_0^{clean} = E(p_clean)  →  潜空间 8×8×4
z_adv[t_start=0.5] = sqrt(0.5)·z_0^{clean} + sqrt(0.5)·ε
                   ≈ 0.707·z_0^{clean} + 0.707·ε
```

**Step 2: 单步迭代（以 t=100 为例）**

```
# 2a. 锚点混合
z_mix = 0.8·z_adv[100] + 0.2·z_anc[100]

# 2b. DDIM 去噪
u_99 = DDIM(z_mix, t=100; ε_φ)
     = z_mix - η·ε_φ(z_mix, 100)  （简化表示）

# 2c. 解码 + 渲染
p_cand = D(u_99)
x_b = C(o_b, p_cand; m, T_b)  # 对 B=8 帧

# 2d. VLA 查询
y_b = π_θ(x_b, ℓ_b)  # 输出 4 维动作

# 2e. 计算损失（黑盒 MSE）
L = (1/8) · Σ_b ||y_b - a^*||²
  = (1/8) · Σ_b [w_x·(y_{b,x}-0)² + w_θ·(y_{b,θ}-0)² + ...]
  = (1/8) · Σ_b [1.0·(y_{b,x})² + 0.5·(y_{b,θ})² + 0.2·(y_{b,gripper}-0.5)²]

# 假设平均 L ≈ 2.5

# 2f. 黑盒方向估计（K=2048 采样）
g_100 = (1/2048) · Σ_k (L_k - b) · (sqrt(0.99)/sqrt(0.01)) · ε_k
      ≈ (1/2048) · Σ_k (L_k - 2.5) · 9.95 · ε_k

# 2g. 更新
z_adv[99] = u_99 - s · g_100
          = u_99 - 0.1 · g_100
```

**Step 3: 迭代 200 步后**

```
z_adv[0] → p_adv = D(z_adv[0])
```

经过 100 轮 × 200 DDIM 步的优化，最终补丁 p_adv 在视觉上接近原始种子（因为扩散先验和锚点正则化），但当嵌入到任意桌面场景时，VLA 输出的动作接近 (0,0,0,0)。

**效果验证**：论文中黑盒设定下 ASR 从 K=128 时的 49% 提升到 K=2048 时的 100%（LIBERO Spatial 任务），说明查询预算是关键变量。

### 6.1 隐含假设 (Hidden Assumptions)

1. **攻击者能获取目标动作**：论文假设攻击者知道要引导机器人做什么动作（a^*），但在真实场景中，攻击者可能不知道 VLA 的连续动作空间结构。
2. **相机视角固定**：所有实验基于单一固定相机。如果机器人有多个相机或相机可移动，补丁可能只在部分视角有效。
3. **补丁放置位置已知**：攻击者需要知道补丁在图像中的大致位置。如果相机视角变化大，补丁可能不在 VLA 的注意力区域内。
4. **扩散模型与 VLA 无关**：DURA 使用预训练 Stable Diffusion，与 VLA 模型独立。但如果 VLA 的视觉编码器与扩散模型的训练数据有重叠，攻击效果可能被高估。
5. **黑盒查询可行**：K=2048 次查询/步 × 100 步 = 204,800 次查询。对于云端部署的 VLA API，这可能触发速率限制或异常检测。

  2. 部署 VLA 到物理系统的工程师——需要了解你的模型面临什么威胁
  3. 研究扩散模型对抗性的研究者——DURA 的潜空间搜索框架可迁移到图像分类领域

- **建議章節路徑**：
  - 先读 §Method（§3.2-3.3）：理解扩散潜空间优化的核心机制

- **不值得精讀的理由**：
