## ⚡ 高 ΔI 信号 — 三视角辩论

### 信号 1: Xiaomi-Robotics-0 工厂部署 — 4.7B VLA + RL，90.2% 成功率，3 小时连续自主运行

> **来源**: TechNode / CnEVPost, 2026-03-02/03
> **核心**: Xiaomi 在其 EV 工厂自攻螺母装配工位部署人形机器人，使用自研 4.7B 参数 VLA 模型（Xiaomi-Robotics-0），结合端到端数据驱动 + RL，实现 90.2% 双侧同时安装成功率，满足产线 76 秒节拍要求，连续 3 小时自主运行。
> **Belief Graph 冲击**: B0, B1, B2, B3, Phase 2
> **逆共识检查**: 弱反对 C1（架构创新回归）— 4.7B 常规 VLA 在工厂达到可用水平，说明数据+RL路线在工作

#### 🔴 Bull: 这是 VLA 从实验室到工厂的里程碑——B1/B2 的联合验证

这是**第一个有量化指标的 VLA 工厂部署报道**。关键不是 90.2%（还不够高），而是：

1. **飞轮启动信号**: 工厂部署 = 真实生产数据开始流入训练管线。Xiaomi 说"持续在更多工位部署验证"——这就是 B1（数据飞轮）的冷启动过程。一旦多工位上线，数据积累速度将指数增长。
2. **RL 的工业验证**: 明确说"结合 RL 技术，减少对真机遥操作数据的依赖"——这是 B2（RL 后训练突破 BC 天花板）在工业场景的直接验证。76 秒节拍 + 3 小时连续运行意味着 RL 策略的鲁棒性已经过了某个工程阈值。
3. **B3 预演**: 如果 Xiaomi 开始用工厂部署数据回训模型（极有可能），这就是 B3（自我改进闭环）的早期形态。

**对 Phase 2 (RL后训练) 收敛的贡献**: 这是 RL 在工业真机（非实验室 benchmark）上的首个公开量化验证。应计入 Phase 2 收敛信号。

#### 🔵 Bear: 90.2% 在工厂 = 每 10 次 1 次失败 = 远未达产线标准

Bear 精准反驳 Bull 的"里程碑"论：

1. **90.2% ≠ 产线可用**。工业产线标准是 >99.5% 良率。90.2% 意味着每小时大约 5-6 次失败——需要人工干预。这不是"部署"，是**带人工 fallback 的试验**。媒体把"factory trial"包装成"deployment"，Bull 不应该被标题误导。
2. **3 小时 ≠ 持续运行**。产线要求 8-12 小时持续运行。3 小时可能是该机器人到达 MTBF 上限。
3. **选择偏差**: 自攻螺母装配是一个相对标准化、低变异性的任务。Xiaomi 选择这个工位发布是因为它**最容易成功**。在高变异性任务（如柔性线束装配、质检）上，VLA 的表现可能完全不同。
4. **4.7B 不是突破性架构**: 这是中等规模的常规 VLA + RL——与 π0.6 的 Recap 路线本质相同。没有新的技术范式。

**核心论点**: 这是一条**工程里程碑**，不是**科学里程碑**。它确认了已知路线可行，但没有提供关于 VLA 哪条路更好的新信息。

#### 🟢 Arbiter: B2 微弱加强，真正价值在于工业数据飞轮的启动

- **如果 Bull 对了**: Xiaomi 的工厂部署标志着 VLA 进入"deployment-driven improvement"阶段。数据飞轮开始转动。6 个月后，Xiaomi 可能公布第二轮结果（成功率 >95%），届时 B1 应大幅上调。
- **如果 Bear 对了**: 这只是 PR 驱动的"试验"包装，90.2% 到 99.5% 之间的鸿沟可能需要 2-3 年才能跨越，飞轮转速远慢于预期。
- **对你的行动建议**: 不需要改变研究方向。但要密切追踪 Xiaomi 后续公布的数据——**成功率从 90% 到 95% 的速度**是 B1（飞轮速度）的最佳代理指标。如果 3 个月内到 95%，飞轮在工作；如果 6 个月还在 91%，飞轮有摩擦。
- **时间套利**: 低。这是公开新闻，不是逆共识。但 Bear 说的"90% 到 99.5% 的鸿沟"是一个**被主流低估的困难**——大多数人看到 90% 以为快到了，但最后 10% 才是真正的工程挑战。

> **来源**: CnEVPost, 2026-02-25
> **核心**: Xpeng 第二代 VLA 模型，同一模型驱动自动驾驶、Robotaxi、人形机器人（Iron）。100M 视频片段训练，30,000 GPU 集群。广州 11 万㎡工厂 Q1 动工，年底量产。
> **ΔI**: 🔧中 — 支持 Phase 5 (跨形态泛化)

**跟踪理由**:
- **跨平台统一模型**是 Phase 5（跨形态泛化）的一个新变体——不是"跨机器人形态"而是"跨产品品类"（车 + 机器人）。如果同一 VLA 能驱动自动驾驶和人形操作，这暗示 VLA 的视觉-语义层存在跨域复用性。

- **Bear 反驳**: "同一模型"可能是 PR 话术。更可能是共享 VLM backbone + 不同的 action head/policy head。如果是这样，Phase 5 的信号被夸大了。
- **独立性**: ✅ Xpeng 的技术路线独立于 π0/GR00T/CrossFormer 等学术路线。

**Belief Graph**: Phase 5 +0（需要技术细节确认"统一模型"的真实含义）。B0 +0（方向确认）。
